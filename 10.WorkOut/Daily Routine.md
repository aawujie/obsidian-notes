# Daily Routine 作息方案

> 核心原则：**固定起床时间是节律锚点，比入睡时间更重要。**

---

## 标准作息表（工作日）

| 时间 | 事项 | 备注 |
|------|------|------|
| **6:30** | 起床 + 拉开窗帘 | 自然光重置生物钟，禁止赖床 |
| 6:30–6:45 | 喝水 + 换运动装 | 不要看手机，直接进入运动状态 |
| **6:45–7:45** | 健身 / 游泳 | 晨练提升全天精神状态 |
| 7:45–8:30 | 回家 + 洗澡 + 早餐 | 热水澡后体温回升，头脑清醒 |
| 8:30–9:00 | 学习 AI（轻度）/ 通勤 | 晨间大脑高效期 |
| **9:00–10:00** | 上班（弹性开始） | |
| 12:00–13:00 | 午餐 + 午休（≤20min） | 超过 30 分钟会影响夜间睡眠 |
| 13:00–18:30 | 工作 | |
| **18:30–19:00** | 下班 | |
| 19:00–19:45 | **晚餐**（正常时间，七八分饱） | 无需赶时间，从容吃饭 |
| 19:45–21:00 | 放松 / AI 学习 / 深度阅读 | 大脑第二个高效期 |
| **21:00** | 放下手机 | 手机充电放到卧室外 |
| 21:00–22:30 | Wind-down：轻阅读 / 冥想 / 洗澡 | 调暗灯光，纸质书优先 |
| **22:30** | 关灯躺下 | |
| **6:30** | （次日）强制起床 | 无论几点睡着都要起 |

---

## 周末作息

| 规则 | 说明 |
|------|------|
| 起床不晚于 **7:15** | 最多比工作日晚 45 分钟，不能睡到 10 点 |
| 午休可延长至 30 分钟 | 仅周末允许 |
| 运动可移到上午 9–10 点 | 不用赶 6:30，但要在上午完成 |
| 22:30 照常睡 | 周末晚睡是节律崩溃最常见原因 |

---

## 5 条不可破的核心规则

1. **6:30 必须起床**——哪怕只睡了 4 小时
2. **21:00 手机放到卧室外**（充电放客厅）
3. **午休不超过 20 分钟**，需设闹钟
4. **运动必须在上午完成**（工作日 6:45–7:45）
5. **周末起床不晚于 7:15**

---

## 破功应急手册

### 情况一：躺下超过 30 分钟睡不着

```
不要继续躺着（焦虑会加剧失眠）
→ 起床去暗处做一件无聊的事（纸质书、轻音乐）
→ 有困意再回去躺
→ 次日 6:30 照常起床，不补觉
```

### 情况二：预感今晚大概率睡不着（已经很亢奋）

```
20:00 前  停止一切工作和刺激性内容
20:30     洗热水澡（加速体温下降）
21:00     冥想 10 分钟（推荐「潮汐」App）
22:00     上床，接受"不一定睡着"的心态
          → 对失眠的焦虑比失眠本身危害更大
```

### 情况三：已经熬到 1–2 点（彻底破功）

```
✅ 第二天 6:30 仍然起床（最关键！）
✅ 午休补 20 分钟
✅ 当天晚上可提前到 22:00 上床
✅ 3 天内节律自然恢复
❌ 不要第二天睡到 10 点"补觉"——节律会再推迟一天
```

### 情况四：连续 2 天睡眠不足（精神很差）

```
允许一次「重置日」（仅限周六/日）：
→ 最多睡到 7:30
→ 当天不午休
→ 当晚 22:30 上床
→ 这是唯一允许的例外，不可滥用
```

## 渐进式切入（从今天开始）

不要第一天就强行 6:30，否则容易崩溃后彻底放弃。

| 天数 | 起床时间 | 睡觉时间 |
|------|---------|---------|
| 第 1–3 天 | 9:00 | 00:30 |
| 第 4–6 天 | 8:30 | 00:00 |
| 第 7–9 天 | 8:00 | 23:30 |
| 第 10–12 天 | 7:30 | 23:00 |
| 第 13–15 天 | 7:00 | 22:45 |
| 第 16–18 天 | 6:45 | 22:30 |
| 第 19–21 天 | **6:30** | **22:30** |

> 每阶段保持 7–7.5 小时睡眠窗口，同步推进入睡时间。运动从第 13 天起加入（起床时间提前到 7:00 后再开始晨练）。

---

## 一句话总结

> **破功后次日照常 6:30 起床，是恢复节律最快的方式；补觉反而是最慢的。**
