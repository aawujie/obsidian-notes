## 一、人形机器人（双足）

### 🥇 RoboParty ROBOTO ORIGIN（萝博头原型机）

| 项目 | 详情 |
|:---|:---|
| 团队 | 哈工大背景，2025年2月成立 |
| 开源时间 | 2026年1月 |
| 身高/体重 | 1.25m / 34kg |
| 自由度 | 23 DOF |
| 运行速度 | **3m/s**（跑步） |
| 价格 | $6,800 起 |
| 全栈开源 | ✅ 结构图纸、EBOM、供应商清单、AMP运控算法、Know-how知识库 |
| GitHub | [Roboparty/roboto_origin](https://github.com/Roboparty/roboto_origin) |
| 融资 | 经纬创投、小米战投、光源资本等千万美元种子轮 |

**特点：**
- 全球首个全栈开源双足人形机器人

- 公开 sim2real gap 弥补方案、样机测试矩阵
- 配套"动手学人形机器人问题清单"共创知识库
- 仿人步态的 AMP 运控算法
- 120天完成从0到原型机

## 四、关键洞察

1. **2025-2026 是开源人形机器人元年**——RoboParty、AgiBot X1 开创了全栈开源模式，不再只是"给代码"，而是连 BOM、供应商、装配 SOP、避坑指南都公开。

2. **中国团队领先**——RoboParty（哈工大）、AgiBot X1（稚晖君）、EngineAI（小鹏背景）占据了全栈开源人形机器人的第一梯队。

3. **"具身智能 Infra 化"是趋势**——硬件门槛降低后，算法和数据成为核心竞争壁垒。开源生态推动行业从"各自试错"走向"协同共赢"。

4. **如果你想上手，推荐 RoboParty**——价格最低（$6,800），全栈最彻底，社区最活跃，嘉立创可打样。
