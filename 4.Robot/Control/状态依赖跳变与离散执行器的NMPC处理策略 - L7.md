# 1. Metadata

- Title: Numerical MPC for systems with state-dependent jumps and discrete actuators（具有状态依赖跳变与离散执行器的数值模型预测控制）
- Author: 会议演讲摘录（未标注具体作者；演讲中提及多位合作者，如 Benjamin、Armen、Yonas 等）

# 2. Overview

视频核心讨论如何在数值 Model Predictive Control（数值模型预测控制，简称 NMPC）与相关优化求解中，处理“非光滑右端项”（nondifferentiable right-hand sides）和因状态依赖或离散执行器产生的开关/跳变问题。结论性观点包括：将非光滑性显式建模（例如用互补性约束 MPCC）并结合专门的离散化与数值技巧（如有限元带开关检测、时间冻结 reformulation、序列凸规划与惩罚同伦策略）能够在保持高阶积分精度的同时，用导数型方法解决本质非凸非光滑问题，从而在实时 NMPC 中获得可行的高精度实现。

# 3. 按照主题来梳理

## 3.1 非光滑动力学的层级（NSD1、NSD2、NSD3）与本质区别

- 视频先把“非光滑右端项”按严重程度分为几个层级，便于讨论数值与优化处理策略。第一级 NSD1（Non-Smooth Dynamics 1）是右端项不可微但连续的情形；第二级 NSD2 存在右端项在分界处不连续（跳变）；第三级 NSD3 更复杂，是“状态依赖的跳变”（state-dependent jumps），即跳变发生时刻由系统状态本身决定，且常常伴随状态变量本身发生突变（例如速度直接发生跳跃）。
- NSD1（不可微但连续）例子：ẋ = 1 + |x|。该系统的轨迹仍是连续可导（ẋ 在点处依然有定义），但数值积分方法的阶会被破坏（数值精度下降）。常见处理方式是“平滑化（smoothing）”，即人为把不可微项替换为可微近似，但演讲者认为这不是最高效的方法，替代策略是把 NSD1 当作“下一层更光滑问题”的特例，应用为 NSD2/NSD3 发展出的技术以保留高阶积分精度。
- NSD2（右端项跳变，右侧与左侧导数不同甚至函数不连续）例子：ẋ = 2 − sin(x) 在某点发生从 − 到 + 的跳变，ẋ 本身不连续，这在轨迹上表现为“角点（kink）”。角点对求导与灵敏度计算是根本性的问题：一方面可用“拼接”方式定义广义解（generalized solutions）；另一方面数值上这种强非线性会使直接线性化或常规模拟误差剧增。视频指出 NSD2 可通过互补性建模（MPCC）较自然地显式刻画。
- NSD3（状态依赖跳变）是最难的类：例如弹跳球（篮球触地后速度方向与大小即时改变——速度发生跳跃），或阀门/二极管等由状态决定的开关。NSD3 扩展了微分方程概念：严格意义上不是经典 ODE（求解器不能仅靠局部连续导数推进），直接的时步积分策略失效，且常见最优控制/优化框架（基于可微性、连续时间动力学）难以适用。视频强调 NSD3 与离散执行器（discrete actuators）不同之处：离散执行器开关可以由控制者决定（可设计开关时间），而状态依赖跳变则不可控、由系统状态触发，这在 MPC 中既引入强非凸性，也带来事件检测与轨迹中断的难题。
- 在这部分中，演讲者反复强调“不要把非光滑性隐藏起来（不要简单平滑化）”，而应当保留并显式建模非光滑结构，这样才能结合专门方法（例如 MPCC、Filippov convexification、时间冻结等）获得更高效、鲁棒且高精度的数值与优化解。

## 3.2 离散执行器与光伏逆变器示例（工程动机与约束）

- 视频给出一个工程示例：光伏（photovoltaic）直流-交流逆变器（DC power converter），目标是在并网时产生高质量正弦波并在电网故障（grid failures）等极端事件下快速做出正确决策以防止器件损坏或系统失稳。该模型由 Benjamin（博士生）开发：仅三状态、对状态线性（“relatively simple; even linear in the states”），但包含一个二值输入（开关），以及另一个关键的“状态依赖开关”来源于二极管（diode，视频中称 diode 是电子学上的“安全阀”），在 blanking time（空白时间）发生状态相关的切换。
- 该设计的实时控制目标严苛：采样时间仅 25 微秒（25 μs），预测步长短（仅两个采样时刻），因此需要非常高效和手工优化的数值实现。视频指出为此他们并非直接使用通用求解器，而是“hand-tailored methods”（手工定制方法）：包括自实现的隐式欧拉（implicit Euler）积分器、针对这个结构优化的实时算法，以及在 blanking time（非常短的区间）内使用少量显式步骤（“two Euler steps”等）。整体策略是在每个 25 μs 周期内根据具体开关模式组合短步/长步的积分，从而在实时嵌入式工业项目中实现近乎可行的算法。
- 这个工程示例的核心启示是：即便系统状态方程在状态上是线性的，非光滑性（来自状态依赖器件、隔离元件、二极管、开关等）会带来极强的非凸与非可微结构，需要在建模层面显式保留这些结构，进而利用专门的数值策略（例如 MPCC、惩罚方法、序列凸规划、手写模拟器与优化集成）来获得实时可用的 NMPC。

## 3.3 使用互补性约束（MPCC）将非光滑性显式化：建模与求解策略

- 演讲者提出把开关/跳变显式建模为数学规划含互补性约束（Mathematical Programs with Complementarity Constraints，简称 MPCC）。基本符号规则：a ⟂ b 表示向量 a 与 b 内积为零（a^T b = 0），并且通常配合非负约束：0 ≤ a ⟂ b ≥ 0。用这种互补性表达可以刻画“在边界上两个量中至少有一个为零”的逻辑，常常产生类似 L 型可行域（L-shaped feasible set）。
- 示例（二维 toy 问题）展示互补性如何把简单的二次目标变成非凸问题：尽管目标函数是凸的（二次），互补性约束导致整体可行集为非凸（L 形，并在角点处没有常规约束资格条件），从而在优化上出现多个局部极值（甚至局部最大值）。这说明非光滑约束（互补性）本身就能产生非凸性，不能简单地通过凸化消除。
- 为解决 MPCC，视频重点介绍“惩罚方法（penalty method）”与“序列凸规划（SCP）/LCQP（Linear Complementarity QP）”两种实现思路：
    - 惩罚方法：将互补乘积条件 φ(w) = L(w)^T R(w) = 0 从约束迁移入目标，构造带权重 ρ 的惩罚项；逐步增加 ρ（同伦/路径跟踪思想），每一步用标准的 NLP 求解器（如 IPOPT）求解得到局部极值，并以该解热启动下一步带更高权重的 NLP。该策略类似内点的逐步路径：当 ρ 很小，问题被松弛，看起来平滑且更易求解；随着 ρ 增加，问题更接近原 MPCC，但如果初始解良好，能保持在“正确”的局部极小点上。理论上可以证明：如果惩罚权重足够大且求解器找到互补解，则该解满足原 MPCC 的条件；该方法仍是启发式，存在陷入非全局最优或不互补点的风险，但实用性良好。
    - SCP/LCQP 速解：当原问题在去掉互补性乘积后是 QP（线性约束 + 二次目标）时，惩罚后仍然是带互补乘积的二次目标可转为线性互补 QP（LCQP）；此时可用序列凸规划的“梯度调整”策略，在线性子问题（QP）上冷热启动（hot-start）高效 QP 求解器，从而在在线 MPC 场景下获得比通用 NLP 更快的求解。视频提到团队实现的 LCCQP 包（Linear Complementarity Constraint QP）与 Yonas 的硕士工作。
- 演讲用一个单自由度的例子（只用初始值 x0 作为自由度）展示了惩罚同伦路径：当惩罚参数 ρ 从小到大变化时，目标曲线从平滑（对初值的优化景观无多局部极值）逐步逼近真实的非光滑、含多个局部极小的曲线；同伦路径的实用价值在于利用低 ρ 的平滑解作为热启动以避免直接面对复杂的非光滑目标，从而以导数型方法回避组合爆炸式的整数优化。

## 3.4 有开关检测的有限元（Finite Elements with Switch Detection, FE-SD / FE-SwD）——思想与实现要点

- 对于 NSD2（右端项存在不连续）直接暴力离散化（在每个时间步插入积分子段与中间变量并把互补性/代数条件写在每一阶段）会导致高阶积分方法阶数丢失、插值出错（多项式插值穿过角点会产生巨大误差）。因此提出 “有限元带开关检测（FE with switch detection）” 的新型离散化：
    - 首要思想：把每个离散单元（element）的长度视为优化变量（step sizes free），而不是固定步长；只允许在单元边界处发生开关（switches are allowed only at element boundaries），禁止在单元内部出现开关。这样单元内部可以认为右端项在该单元内是光滑的，允许使用高阶多项式/高阶隐式 Runge-Kutta 或 collocation 方法保持高阶精度。
    - 为避免优化器通过不合理地调节单元长度来“作弊”（例如在没有开关时把单元长度随意变换以降低数值误差或目标），引入“步长平衡（step equilibration）”约束：如果区间内没有开关，则希望该区间的子步长保持等距或某种均匀性（详细实现用互补性逻辑约束表达），只有在存在真实开关时才允许套件内步长不等。该平衡约束是为了移除不必要的自由度，减少优化器的可利用空间。
    - 关键技术点（cross-complementarities）：通过一组互补性/逻辑约束把“某区间内部无开关”与“相邻子步长相等”联系起来；利用乘积互补条件和辅助变量（indicator-like 函数）来保证“如果某区间内确无开关，则强制步长均一；否则允许步长改变并在边界处检测开关”。实现代价是引入更多变量（单元步长、互补乘子 λ、θ 等）和复杂的互补性约束，需要求解器处理带互补性的 NLP。
- 方法优势在于：当开关只发生在单元边界处时，高阶 collocation、多项式近似不会横跨角点，从而保留原有高阶精度；在数值模拟与灵敏度计算上获得显著改进，演讲给出数值对比：传统 collocation 在面对跳变时误差难以收敛，FE-SD 在较小的节点数下即可实现 1e-6 量级的高精度。缺点是需要在优化中加入互补性求解环节，且单元步长成为优化变量，导致整体 NLP 规模增大与结构复杂。
- 视频中通过多个测试（例如某不稳定振子与具有切换边界的系统）展示：常规高阶 Runge-Kutta / collocation 在跳变处误差巨大，即使增加节点数也难以收敛；而 FE-SD 能精确检测开关时间并在边界处处理滑动模式（sliding mode），从而获得稳定、可靠且高精度的解。演讲者还指出 FE-SD 的实现需要惩罚型 MPCC 或带互补性求解策略（penalty loop + NLP solver 或 LCQP-SCP 快捷法）配合使用。

## 3.5 时间冻结（Time Freezing）方法：将 NSD3 转化为可处理的 NSD2 形式

- 时间冻结是一种将“状态依赖跳变且伴随状态突变（NSD3）”重写为“只有开关但连续演化（NSD2-like 或带 Filippov 集合）”的方法，且该重写是等价的（not approximation，但是一种重表述）。核心思想包含三步：
    1. 在被禁止/物理不可达或需要做跳变的“私有区域”（prohibited region，例如弹跳球的地下区域 y < 0）引入一个辅助动力学（auxiliary dynamics），该辅助动力学把所需的“跳变”过程在连续路径上实现：本质上用一个虚拟轨道把跳前的状态连续连到跳后的状态（例如把负速度映射到正速度并可能衰减），使得原本发生瞬时跳跃的状态可以通过一段短时的连续轨迹达到跳后状态。
    2. 引入一个“时钟态/时间变量 t”（numerical time），并让这个时钟在辅助动力学活动期间“停止计时”（time freezing）——即在虚拟段不在物理时间累积上增加，从而保证重写后的数值时间与原物理时间一一对应：物理时间的推进只有在真实演化段发生，虚拟连接段不消耗物理时间。
    3. 为了使整体优化问题满足指定的终端物理时间约束，引入一个时间缩放参数 s（s ≥ 1），允许在非冻结时间段加速数值时间以“补偿”被冻结掉的时间，使最终的数值时间累积达到物理时间目标。并在优化中以终端约束形式施加 physical time 达到指定终值。
- 举例（弹跳球）：物理模型中，触地时速度 v 发生瞬时方向变化（并可能按恢复系数衰减），且有“地下”状态是物理不可达的。时间冻结策略在数值上让轨迹进入一个虚拟区域（地下），在该区域内执行辅助动力学将 v 连续从负到正，同时数值时间继续演化但物理时间暂停（t 的增量为零）。当辅助段完成后，物理时间重新开始计数，系统状态即位于跳后条件。由此弹跳球在数值时间上是连续光滑的轨迹，便于高阶积分与灵敏度计算。
- 关键要点与限制：time-freezing 并不是随意构造，而需设计合适的辅助动力学 f_aux，使得从进入 forbidden region 到完成映射的连续轨迹能恰好实现原始跳变效果（例如能量衰减、速度改变）。对此视频说明目前为止为每个示例都能给出合适的 f_aux，但没有一个全面存在性与构造理论。另一个操作性要点是 time-freezing 的实现通常会把“冻结段”当成可行域的一部分并与 MPCC/FE-SD 等方法联合使用，从而在优化中能保持连续性与高阶精度、同时允许状态突变的物理效果出现在解的外观上（物理时间视角）。
- 演示与结果：视频展示多个应用（2D 弹跳球跟踪、受限力驱动的弹跳球利用墙面反射以更高效跟踪移动目标、以及 hopping robot 跳跃机器人示例）。这些示例显示，time-freezing 与 FE-SD 结合后能在优化中发现“创造性”策略（例如刻意利用墙面反弹或弹跳来提高位移效率），并在数值上确保轨迹与灵敏度的高精度计算。部分早期示例（机器人）是 time-freezing 引入后而未完全用 FE-SD 优化的结果，因此在物理接触或穿透处仍有精度欠佳的痕迹，未来结合 FE-SD 后旨在更准确。

# 4. 框架 & 心智模型（Framework & Mindset）

- Framework 1 — 将非光滑显式化并用同伦/惩罚求解（MPCC + Penalty Homotopy）
    - 核心思想：不要把非光滑通过平滑化隐去，而是用互补性约束（complementarity constraints）或基于 Filippov 的集合描述把非光滑结构表达出来。互补性用 0 ≤ L(w) ⟂ R(w) ≥ 0 的形式把“开关逻辑”与“取值为零”条件写在优化问题中，从而让求解器明确知道哪些变量是“选择性的”或“在边界上”。
    - 求解步骤（penalty homotopy）：
        1. 把互补性乘积 φ(w) = L(w)^T R(w) = 0 从约束转到目标，构造带权重 ρ 的惩罚项 ρ·φ(w)；保留 L(w) ≥ 0、R(w) ≥ 0 等其他约束不变。
        2. 从较小的 ρ 开始求解（对应较松弛、较平滑的问题），用成熟的 NLP 求解器（例如 IPOPT）得到解 w^*(ρ_0)。
        3. 逐步增大 ρ（同伦路径），每一步用上一步的解作为热启动（warm start）进入下一个更严格的问题求解。增大 ρ 的过程逐步逼近原始 MPCC。
        4. 在每一阶段利用二阶信息（Newton-type）或 SQP/IPM 求解加速，若问题本身在非互补子问题上是 QP，则可用定制的 LCQP-SCP 热启动策略进一步提升在线性能。
    - 心智模型与优点：低 ρ 时问题平滑且求导信息可信，便于找到“大片”良好的 basin；沿同伦路径逐步逼近真实问题可以避免直接在高度非光滑景观中陷入次优；该方法与经验上证明在若干 MPCC 问题中能找到可用解，且在找到一个互补解时可证其为原问题解的固定点。
    - 风险/局限：始终是局部方法；可能被次优局部极值吸引或停留在非互补点；参数更新策略（如何增加 ρ）与初值选择影响收敛与结果质量。
- Framework 2 — 序列凸规划（SCP）与结构化 LCQP 求解的在线策略
    - 核心思想：在 NMPC 中通常只线性化非凸部分（动力学 f），保留目标与多项式/凸约束，从而得到可在在线环境下快速求解的凸子问题。对于含互补性的线性问题（LCQP），利用梯度（线性项）调整与 QP 的热启动技巧实现高效在线求解。
    - 步骤：
        1. 把连续时间 NMPC 离散化并展开（simultaneous approach）：不消除内部积分阶段变量 z_kj，而把它们作为优化变量（可以在约束中对中间点施加约束或观测）。
        2. 在每次迭代中，把非线性动力学 f 在当前轨迹点线性化（Taylor），形成线性的动力学约束 f_lin，使得子问题成为 QP（若目标为二次且其他约束线性）。
        3. 对含互补性乘积的 LCQP，采用惩罚参数 ρ 和梯度适配策略（SCP 中的梯度修正），每次只修改非凸项的线性近似并求解 QP，用上一次解作为热启动，从而减小每步求解开销。
        4. 重复迭代直至收敛或满足实时预算（适用于 MPC 的有限时间窗）。
    - 心智模型与优点：把复杂的非凸动力学“局部线性化”，并在 LCQP 上应用热启动技巧，能在短时间内求得可用解；与完整 NLP 相比更适合在线嵌入式环境，且可与 MPCC 的惩罚同伦结合以处理互补性。
    - 注意：线性化质量依赖于系统非线性程度与步长，若动力学强非线性或开关深刻影响轨迹，需结合 MPCC 显式建模或更强的离散化策略（如 FE-SD）。
- Framework 3 — 有开关检测的有限元（FE with Switch Detection）离散化
    - 核心思想：通过把单元边界设为“唯一允许开关位置”，把非光滑点限制到数值可控的离散边界上，从而在每个单元内部保留高阶光滑多项式表示，避免多项式穿过角点造成精度崩溃。
    - 实施步骤：
        1. 将时间网格的每一单元长度作为优化变量（h_k 变为决策变量），加总约束保证整体时域一致。
        2. 在约束中强制“单元内部禁止开关”；通过交叉互补条件（cross-complementarities）保证：“若单元内某类开关未发生，则相邻子步长需保持平衡等距（step equilibration）”；若发生开关，则允许相应单元步长断开平衡。
        3. 把互补性条件写进离散优化问题（导致 MPCC 形式），并通过前面提到的惩罚同伦或 LCQP 策略求解。
        4. 使用高阶 collocation（如 Radau、Gauss 等）在单元内构造多项式解与灵敏度求导，从而在单元边界处保留精确的开关时间与灵敏度信息。
    - 思维要点：把“开关检测”从积分器外移入优化器，通过优化器同时选择单元划分与轨迹来保证开关只在单元边界出现，从而恢复高阶导数信息与收敛性；为避免优化器滥用步长自由度，必须引入 step equilibration 类约束以抑制不必要的变形。
- Framework 4 — 时间冻结（Time Freezing）把状态跳变变为开关问题
    - 步骤化描述：
        1. 对原系统增加数值时间状态 t_num（numerical time）并让物理时间（或物理时钟）通过一个独立状态 t_phys（或通过终端约束映射）来表示；数值时间是优化器工作的独立时间尺度。
        2. 在“禁止域/触发跳变区域”设计一个辅助动力学 f_aux（连续矢量场），此动力学描述了从跳变前状态到跳变后状态的连续路径（例如把负速度连续转成正速度并引入能量损耗）。
        3. 在 auxiliary dynamics 激活期间，让物理时间“冻结”（即 t_phys 停止增长或其导数为 0），从外部观测上该段不耗物理时间，但内部状态完成从跳前到跳后的过渡；这保证了重写系统在数值时间下连续演化而在物理时间上保有瞬时跳变效果。
        4. 引入时间缩放因子 s（s ≥ 1），在非冻结段对数值时间加速（或调整），以满足整体物理时间约束（例如终端时刻要求达到给定物理时间）。把这些条件放入优化问题并求解，结果能在物理时间尺度上等价于原有的瞬时跳变解。
    - 心智模型：把瞬时跳变用“短暂的虚拟轨迹 + 冻结物理时间”替代，从而在数值上将 NSD3 映射为 NSD2/filippov 类型问题，使得已有的 MPCC/FE-SD 工具可以直接使用而无需面对瞬时状态不连续带来的积分/灵敏度灾难。
    - 限制与注意：辅助动力学 f_aux 的设计并非通用明确，需根据物理现象、能量守恒/损耗与可达集构造合适的连续映射；对复杂耦合系统，f_aux 构造可能较难或非唯一；time-freezing 会引入更多的优化变量与互补性约束，增加求解复杂度，但往往能换来数值稳定性与精度。

# 总结

演讲的主线是：当系统包含状态依赖跳变或由离散执行器引发的开关时，简单的“平滑化”或“暴力离散化”往往不足以保证高精度与可用的灵敏度信息；更稳妥的路径是显式保留非光滑结构（用 MPCC/互补性约束或 Filippov 表述），并结合专门的离散化与数值策略（有限元带开关检测、时间冻结、惩罚同伦 + SCP/LCQP 等）来在 NMPC 的实时要求下获得精确、鲁棒且可求解的方案。实践中需权衡模型表达、优化问题规模与实时性：对硬件限时的工业应用往往需要手工实现的高效积分器与问题特化的热启动策略。视频强调的心智模型是“显式而非隐藏非光滑性、利用同伦与结构化求解、并在离散化层面把开关控制在可管理的位置（单元边界）”，从而在保持高阶积分精度的前提下把非凸非光滑问题用导数型数值优化工具去处理。
