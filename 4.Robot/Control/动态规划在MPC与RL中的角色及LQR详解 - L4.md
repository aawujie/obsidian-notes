# 3. 按照主题来梳理

## 3.1 最优性原理与动态规划的基本概念

- 动态规划的核心来自贝尔曼（Richard Bellman）提出的“最优性原理”（principle of optimality）。贝尔曼的原话可以概括为：一个全局最优策略的后半段（在给定某一初始状态和初始决策之后）必须在那个中间状态处也是局部最优的；换句话说，任何最优轨迹的子弧也必然是最优的。逻辑上这是显而易见的：如果子弧不是最优的，则将其替换为更优的子弧会使全轨迹更优，从而矛盾。
- 图像化理解：把时间轴分为左右两段，连接处是状态（state）。所有对“过去”和“未来”的耦合仅通过该状态发生；因此，在该接口处，左右两段各自独立地必须是对应子问题的最优解。另一种日常类比是“最短路径问题”：从地点 A 到 Berlin 的最短路径经过某城镇 S，则从 S 到 Berlin 的路径必须是 S 到 Berlin 的最短路径，否则 A 到 Berlin 的路径就非最短。
- 基本定义（有限视界场景）：对于任意时刻 k 与当时状态 x，定义“代价到终点函数”（cost-to-go 或 value function）J_k(x)：表示从时刻 k、状态 x 开始，按照最优策略到终局（或终点时刻 N）的最小累计代价。这个 J_k 函数是参数化的：它是关于初始状态 x 的最优值函数。
- DP 递推关系（贝尔曼方程，有限步）：J_k(x) = min_a { c_k(x,a) + J_{k+1}( f_k(x,a) ) }。其中 c_k 为阶段代价（stage cost），f_k 为动力学。含义清楚：如果已知下一时刻（k+1）的代价函数 J_{k+1}，则当前代价函数 J_k 可以通过对当前动作 a 求最小化（阶段代价加上转移后状态的代价）得到。
- Q 函数的引入：Q_k(x,a) := c_k(x,a) + J_{k+1}( f_k(x,a) )，即在状态 x 采取动作 a 时的“动作-值函数”（action-value）。最佳策略在状态 x 下取使 Q_k 最小的 a： π*_k(x) = argmin_a Q_k(x,a)。Q 函数在强化学习与 Q-learning 中尤为重要。
- 从理论到算法：已知终端代价 J_N（终值或终端成本），可通过从后向前递推的方式计算所有 J_k 的表格（如果状态空间可枚举或离散化）。递推步骤需要遍历每一状态、对每一可选动作计算 Q 并取最小。整个方法等价于对有限状态-动作图做精确穷举搜索，但巧妙地分解成逐时刻的子问题，避免了对完整轨迹空间的直接枚举。
- 要点与限制：贝尔曼原理不依赖连续性或可微性，因此适用于非光滑、非凸问题；但离散化或枚举式的实现需要对状态空间（和动作空间）进行全覆盖，这直接导致“维数的诅咒”（curse of dimensionality）：若每维离散为 m 个点，d 维需要 m^d 个格点，快速不可行。

## 3.2 有限视界 DP 的数值实现、Q 函数、MPC 的关系与维数诅咒

- 有限视界 DP 的实现细节：设终止时刻 N，给定终端代价 J_N（通常是终端成本 E）。从 k = N-1 向后，逐步计算 J_k 对于每一可能的状态 s（或 x），需要对每一动作 a 枚举，计算下一状态 s' = f(x,a)，并计算 Q_k(x,a)=c_k(x,a)+J_{k+1}(s')，取最小，得到 J_k(x) 和对应的 argmin（用于构造最优策略表）。这就是通常所说的“从终端反向迭代并记录策略”。
- 离散化与表格化：该方法在状态与动作离散且规模适中时实施方便——计算得到的策略可以直接用查表（table lookup）实现：策略 π_k: state -> action 的映射就是一个表。对于很多组合优化/有限 MDP 问题，这是理想的做法。
- MPC（模型预测控制）与 DP 的关系：
    - MPC 的通常做法是每一时刻求解一个有限视界最优控制问题（有限步最优轨迹），并实施该最优轨迹的第一个动作（receding horizon control）。这等价于每步在线求解有限视界最优问题（方法二）。
    - 如果我们事先用 DP 完成“对所有初始状态的有限视界最优策略预计算”（即离线构造 π_0(x) 对所有 x），那么在线仅需查表取得第一步动作（方法一，显式 MPC 的思路）。显式 MPC 在某些线性二次问题中可将策略表示成 piecewise-linear（分段线性）映射，离线计算后在线评估便很快，但仍可能需要枚举不同状态分区，面对高维同样困难。
    - 讲师指出 MPC 被称作“动态规划的穷人做法”（poor man's DP）因为 MPC 仅计算一条路径（或仅对当前初始状态求解），避免了遍历全部状态所需的庞大计算，但也因此放弃全局最优性与对随机/鲁棒性的某些处理方式的直接性。
- 维数的诅咒（curse of dimensionality）：DP 的主要瓶颈是需要对状态空间完全表格化（或以某种方式覆盖），若每维分辨率为 n 点，d 维即需 n^d 个格点。示例：仅 5 维若每维 100 点即产生 100^5 = 10^10 个状态。即便动力学简单、非线性不复杂，此指数级增长使得精确 DP 在高维连续控制问题上不可行。
- 折衷与近似：为应对维数诅咒，有两类路径：一是利用结构（如线性系统 + 二次成本）得到解析或高效数值解（如 LQR）；二是使用近似动态规划（Approximate DP / ADP）或基于深度网络的函数逼近来近似 value/Q 函数，从而不必穷举全状态空间。这也正是强化学习（RL）与现代深度学习结合的大方向：学习或逼近价值函数及策略，而非精确表格化。
- 算法复杂度与实际使用：实际应用中既有纯在线每步求解（MPC），也有离线预计算（显式 MPC、DP）或混合方式（离线采样/仿真构造近似策略）。显式 MPC 在某些线性/二次情况下能通过参数化（分区/矩阵）极大地压缩策略表示，但并不能一劳永逸解决维数问题。讲师也调侃地说：如果真的很富有并且问题结构允许，做全状态 DP 离线预计算是“富人的做法”。

## 3.3 示例：疫情早期模型（可控 R）与观察到的策略差异

- 模型设定（最简早期疫情模型）：状态为感染人数 I（取整），控制变量为可控的再生数 R（reproduction number，视频中直接将其视为可由政府政策改变的变量）。动力学为 I_{t+1} = floor( R_t * I_t )（取整以反映离散感染人数），因此模型极为简单、几乎与 R 的定义是同义。控制的代价由两部分构成：一是对实施严格防疫/封锁的社会经济成本，在 R 接近最小值（例如 0.5）时显著增大；二是对感染人数的社会代价（死亡、医疗等）有一个小的线性惩罚系数 epsilon（例如 1e-4），反映相对于封锁成本，感染个人代价在该模型中被赋予较低权重。
- 参数与约束：R 的取值范围 [R_min, R_max]，例子里 R_min = 0.5, R_max = 4。阶段成本 c(I,R) 在 R 低（严格封锁）时非常大；在 R = R_max（放任不管）时阶段成本主要是感染人数带来的微小惩罚 epsilon * I。无终端成本（E = 0）。时间尺度可取周或日，但对动态行为影响不改变总体形态。
- DP 实验与观察（不同预测视界 N 的结果）：
    - 当用较短视界（例如 N = 2）的 MPC/DP，策略表现出“短视但仍能稳定系统”：系统被控制在一个较高但稳定的感染人数平衡点（steady state），因为模型仅预测两步，短期不显现灾难性增长，从而不强制立即严格封锁。代价到终点函数在低感染数处较平缓，导致策略在小感染数时选择较宽松的措施。
    - 当用较长视界（例如 N = 50 或 100），代价到终点函数在小感染数时变得陡峭：长期预测会显示如果现在不果断控制，感染会指数增长，最终带来巨大代价。于是最优策略在检测到一丁点感染（例如 1 或几人）即立即实施严格封锁，把 R 降到接近最低值直到疫情被根除（I 回到 0）。对长视界而言，策略在“有感染”与“无感染”之间几乎是二值的：无感染时放松、发现感染则迅速紧急封锁，直到清零。
    - 一个常见现象：随着视界 N 增大，有限视界 DP 的代价函数 J_0 随 N 单调增加（或收敛），并在 N 足够大时近似收敛到“无限视界”代价值（或折现版本的固定点）。这也是 MPC 的实用依据：当 horizon 足够长时，MPC 的行为接近无限时域最优策略。
- 直观含义与政策解读：
    - 早期疫情阶段（总体易感人群几乎为全部）模型具有“快速压制优点”：因为感染人数小但增长潜能巨大，长视界的最优策略更倾向于尽早、果断介入以防后续指数级成本；这能解释许多国家在疫情早期迅速封锁的合理由来。
    - 而若只使用短视界或给实施封锁的成本非常高，则策略可能倾向“容忍一定感染水平”，试图在经济与卫生之间折中，这在现实中表现为“选择缓和措施而非早期强关停”。
- 方法学说明：该示例演示了 DP 在离散状态（感染人数）情形中易于实施与可视化，但同时也强调模型的简化（无饱和医疗、无自然免疫、无接种、单一人口群体、线性化成本结构等）。讲师强调这是早期情形的简化建模，避免在后期（大规模感染或疫苗普及）使用同一模型。
- 结论：该示例既是 DP 理论的直观教材，也反映了预测视界长度、成本权衡及模型假设如何显著影响控制决策，说明 DP 与 MPC 在公共卫生策略制定中的潜在贡献与局限。

## 3.4 线性二次问题、LQR、黎卡提方程与“向前/向后”算法

- 问题类：Linear Quadratic Regulator（LQR，线性二次调节）问题是动态规划在连续状态/控制下一个极其重要且可解析求解的特例。这里考虑离散时间、时域可有限或无限、动力学线性、阶段成本与终端成本都为二次型（quadratic）。常见符号：状态 x、控制 u、动力学 x_{k+1} = A_k x_k + B_k u_k（可以含时间索引），阶段成本 c_k(x,u) = x^T Q_k x + u^T R_k u + 2 x^T S_k u + linear terms（可扩展含一阶项），终端成本为 x_N^T P_N x_N（或含线性项）。
- 解析推导的核心思想（代数/几何直观）：
    - 在 LQ 设置下，贝尔曼递推的 Q 函数（对 x,u 的二次型）对 u 做最小化仍然给出一个关于 x 的二次型。直观上，二次型在（x,u）空间是抛物曲面（抛物面体），对 u 做最小化相当于在 u 维上进行投影，投影结果在 x 维仍为二次型。这一操作在矩阵代数上对应“Schur 补（Schur complement）”与对 R 的逆运算。
    - 具体代数：若 Q(x,u) = [x;u]^T M [x;u] + linear term，分块矩阵 M = [[M_xx, M_xu];[M_ux, M_uu]]，且 M_uu（对应 u^T R u）正定，则对 u 求最小化得到：
        - 最小值函数在 x 上仍为 x^T P x + ...，其中 P = M_xx - M_xu M_uu^{-1} M_ux（这是 Schur 补表达式）。
        - 最优 u* 为线性函数 u* = K x + c（若含线性项则有偏置），其中 K = - M_uu^{-1} M_ux（含负号，视具体分块排列）。
    - 因此，假设 J_{k+1}(x) = x^T P_{k+1} x（为二次型），阶段成本为二次，则 J_k(x) 通过上述矩阵运算得到 x^T P_k x，且 P_k = Q_k + A_k^T P_{k+1} A_k - (A_k^T P_{k+1} B_k + S_k)^T (R_k + B_k^T P_{k+1} B_k)^{-1} (A_k^T P_{k+1} B_k + S_k)。这一递推就是有限视界的黎卡提（Riccati）递推。
- 算法形式（向后与向前两步）：
    - 向后（backward pass）：从终端 P_N 给定出发，按离散黎卡提递推从 k = N-1 向 0 递推 P_k（矩阵递推）。此过程只涉及矩阵维度为状态/控制维度的运算，不需要枚举状态格点，因而避免了表格化的维数爆炸。
    - 得到 P_k 后可计算增益矩阵 K_k（反馈增益），具体 K_k = (R_k + B_k^T P_{k+1} B_k)^{-1} (B_k^T P_{k+1} A_k + S_k^T)（符号/次序按定义可能有差异）。向前（forward pass）：给定初始状态 x_0，按 u_k = -K_k x_k（或含偏置）计算控制并推进动力学 x_{k+1} = A_k x_k + B_k u_k，得到完整最优轨迹与控制序列。整套方案即为典型的“向后计算 P，向前模拟得到最优轨迹”。
- 无限视界与代数黎卡提（Algebraic Riccati Equation, ARE）：
    - 当系统时间不变、且存在稳定性/可控性条件，有限视界黎卡提递推 P_k 随着 k 递推往前可能收敛到一个固定矩阵 P（P_k -> P），满足代数黎卡提方程（离散情形）：
P = Q + A^T P A - (A^T P B + S^T) (R + B^T P B)^{-1} (A^T P B + S^T)^T。
    - 求解该代数黎卡提方程的数值算法与库函数很多（如 MATLAB 中的 dare、dlyap 等），解得 P 后可直接构造时间不变的线性反馈增益 K，得到无限视界 LQR 策略 u = -K x。这个 K 是在线上实现非常廉价的矩阵乘法，与 MPC 在线求解相比在反应速度和资源需求上具有巨大优势。
- 物理/工程意义与数值注意：
    - LQR 的优点在于其通用性（线性化常见于稳定点附近）、易实现性（仅矩阵乘法）与可解释性（P 的二次型值即为状态的“代价”，K 控制如何映射状态到动作）。
    - 若问题包含线性项/偏置或系统非齐次（有常数项、参考轨迹），可以通过“增广状态”技巧把这些项变成状态的一部分（例如在状态向量中加入一个常数 1 的分量并相应扩展 A,B,Q,R 矩阵），从而仍适用相同的黎卡提递推；这是记忆公式的编程技巧，也是实际工程中常用的处理方法。
    - LQR 作为一种精确 DP 在连续、线性、二次场景中避免了维数的诅咒（因为不表格化），但它对模型线性性和二次成本的假设很敏感：在高度非线性或带强约束（inequality constraints）的实际问题上，LQR 可能表现不佳，需结合非线性 MPC 或近似 DP。

# 4. 框架 & 心智模型（Framework & Mindset）

动态规划与其在控制/强化学习领域的应用可以抽象为若干通用的 framework 与思维模式（mindset）。以下将这些要点系统化为可操作的步骤、设计原则和理解指南，以帮助读者在不同情景下选择方法、设计算法或理解行为差异。每一点都尽量保持可迁移、可操作，并且与视频中讲述的内容保持一致、未增加新事实。

- 核心框架一：贝尔曼分解（问题分解为“现在的决定 + 未来价值”）
    - 思维导向：把一个全局决策问题视为“选择当前动作 + 递归考虑剩余子问题”的组合。在任一时刻 k、状态 x，最优决策的价值可以写作当前阶段代价 c_k(x,a) + 最优剩余代价 J_{k+1}( f(x,a) )。这就是贝尔曼方程的结构。
    - 操作步骤：
        1. 明确阶段代价 c_k(x,a)、动力学 f_k(x,a) 和终端代价 E(x)（若有）。
        2. 定义 J_k(x) 为在时刻 k、状态 x 的代价到终点的最小值。
        3. 写出贝尔曼递推 J_k(x) = min_a [ c_k(x,a) + J_{k+1}( f_k(x,a) ) ]。
        4. 如果可以枚举状态/动作或用逼近代表 J，那么就可通过向后递推得到 J_k，随后通过 π_k(x)=argmin_a Q_k(x,a) 得到策略。
    - 适用情景：任何时间序列优化问题、路径规划、MPC、MDP（马尔可夫决策过程）等。优点是方法通用且不依赖可微性；缺点为表格化时遇到维数诅咒。
- 核心框架二：从递推到算法的两步范式（Backward pass + Forward roll-out）
    - 思维导向：把 DP 求解看成两阶段程序设计模式：离线构造价值函数/控制律（后向递推或参量求解），线上用该策略进行前向仿真/执行。
    - 操作步骤：
        1. 后向递推（离线/批处理）：已知终端 J_N，按时间倒序计算 J_{N-1}, ..., J_0。此阶段得到价值函数或反馈映射（若直接记录 argmin）。
        2. 前向执行（在线/实时）：以当前初始状态 s_0 为起点，按 π_0(s_0) 获取动作并执行、推进系统，得到 s_1，再用 π_1(s_1) 等；或者如果获得的是时间不变的策略（无限视界、或 LQR 得到的 K），直接在线应用。
        3. 好处是将昂贵的“搜索/递推”集中在离线，在线执行快速高效；这是显式 MPC 与 DP 离线表格化的共同思想。
    - 适用场景：需要高频率在线决策但允许大量离线计算的场景（嵌入式控制、车辆/飞控、预计算策略的部署等）。
- 核心框架三：利用结构规避维数诅咒（线性-二次、凸性、分区表示）
    - 思维导向：当问题具备特定代数结构（线性动力学 + 二次代价）时，价值函数在每一步保持二次型，递推可在矩阵维度上操作（黎卡提方程），避免表格化带来的维度暴涨。若问题为凸且线性依赖于不确定项，则 Bellman 操作可能保持凸性，从而可用更紧凑的表示（如支持函数、线性片段最大化表示）。
    - 操作步骤：
        1. 识别问题是否为线性动力学与二次成本（或近似可线性化、二次近似）。若是，使用 LQR/离散黎卡提递推。
        2. 若问题为凸并且系统在不确定参数下保持线性（多面体/多情形），利用凸性保持性可将鲁棒最坏情况归结为顶点搜索（多面体顶点）。
        3. 若目标是在线高效评估策略，则考虑显式 MPC（分段线性策略）或用函数逼近（神经网络）替代完全表格化。
    - 适用情景：工程控制问题、实时控制系统、需要可证明稳定性/性能保证的场景。
- 核心框架四：随机性与对抗性纳入统一视角（期望化与极化化）
    - 思维导向：动态规划对随机系统与鲁棒（对抗）系统的处理方式形式上极其相似：随机性通过在 Bellman 方程中加入期望（期望值操作），对抗性通过将期望替换为最大化（worst-case）操作。两者仅在“额外一层循环”或“额外一次运算”上不同：期望需要积分/采样，对抗需要枚举/取最大。
    - 操作步骤：
        1. 若系统受随机扰动 w_t，以 Bellman 迭代中把后续代价取期望： J_k(x) = min_a E_w[ c_k(x,a,w) + J_{k+1}( f(x,a,w) ) ]。
        2. 若要鲁棒最坏情形设想（adversarial w），把期望换为最大： J_k(x) = min_a max_w [ c_k(x,a,w) + J_{k+1}( f(x,a,w) ) ]。
        3. 实现上期望可用蒙特卡洛采样近似（样本平均），鲁棒极值在多面体不确定集下可简化到顶点搜索（若系统与成本在不确定参数上线性/凸）。
    - 适用场景：含概率扰动的控制问题（滤波、鲁棒控制、风险敏感优化、博弈论类对抗环境）。
- 心智模型（Mindset）总结：在面对序列决策问题时，首先问自己三个问题：
    1. 我有全局结构/先验吗？（线性、二次、凸性、可分性）
    2. 我的状态/动作空间是否能表格化？若不能，我是否能找到函数近似或结构化表示？
    3. 我要解决的是期望型问题还是鲁棒/对抗型问题？（这决定 Bellman 里是 E[·] 还是 max_{w}）
    - 根据回答选方法：结构强 -> 尽量利用解析/矩阵方法（如 LQR）；结构弱但可采样 -> 近似动态规划/强化学习；需要实时简洁控制 -> MPC 或显式策略；含不确定性 -> 期望/鲁棒拓展。
    - 另一个重要心态是“离线/在线分工”思想：把能离线做的计算（如构造价值函数近似、训练策略、显式分区）尽量放到离线，把在线执行简化为查表/乘法/网络前向传播，以满足实时要求。

总结框架的实际建议：

- 工程实践中先尝试线性化 + LQR（若在工作点附近），再评估是否需要更复杂非线性 MPC 或近似 DP。
- 在高维问题优先考虑结构化近似（分解、参数化、神经网络逼近），并用样本验证近似策略的性能与鲁棒性。
- 对随机与鲁棒问题，优先选择能保持凸性或线性特性的建模方式，以便将复杂度降低到可枚举或顶点搜索规模。

# 总结

动态规划是处理时间序列最优决策的基本原理：最优性原理（贝尔曼方程）给出递推、Q 函数给出动作评价，有限视界可用后向递推并使用前向仿真得到最优轨迹。LQR 是线性二次情形的特例，允许用黎卡提递推在矩阵维度上高效求解并得出线性反馈，进而避免状态表格化导致的维数诅咒。对于随机与鲁棒场景，DP 可以通过期望或极大化操作自然拓展；而在高维、连续问题上，需借助结构（LQR、凸性）、显式 MPC 或近似动态规划（函数逼近、深度学习）来实用化。视频通过疫情模型与冬季上坡示例，直观展示了短视与长视界策略差异及非线性系统中 LQR 与精确 DP 的行为差别，强调了理论与实现之间的折衷。
