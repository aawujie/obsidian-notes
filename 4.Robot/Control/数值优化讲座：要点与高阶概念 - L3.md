# 3. 按照主题来梳理

## 3.1 基本定义与概念

- 优化的数学表述与目标
    - 优化（optimization）在数学上即为对一个目标函数 f(x) 做最小化（或最大化，后者等价于最小化 −f）。通常要考虑变量 x 的定义域与附加约束（constraints）。约束可以是等式 g(x) = 0（向量值，可包含多条等式）或不等式 h(x) ≥ 0（向量值，每个分量为一个不等式）。整体问题可写为：minimize f(x) subject to g(x)=0, h(x) ≥ 0。视频强调，不论是最小化还是最大化，核心结构是一致的，常以最小化为主线描述。
- 可行域（feasible set）
    - 可行域被定义为同时满足所有约束的点的集合。几何上可以把每个单约束看作描述一块区域（例如 x2 ≥ 0 描述上半平面，x1^2 + x2^2 ≤ 1 描述单位圆内），可行域即这些单约束区域的交集。明确“可行点”概念是进一步讨论最优性与算法的基础。
- 局部与全局极小值（local / global minimizer）
    - 全局极小点：在整个可行域中，目标值最小（可能存在多个取同一最小值的点，但最小值唯一）；数学表述是 f(x*) ≤ f(x) 对所有可行 x 成立。
    - 局部极小点：存在一个邻域，在该邻域内无更小的可行点。实际问题中多数非凸问题的求解器只能保证或更常常找到局部极小点，且局部解往往在工程上足够好。
- 导数与二阶信息
    - 一阶导数（gradient）∇f：对标量函数 f(x) 的各偏导数组成的列向量（讲者用转置符号强调梯度为列向量或行向量的表示差异）。梯度为零是驻点（stationary point）/必要条件。
    - 二阶导数（Hessian，Hessein 矩阵）：n×n 矩阵，二次微分信息。若在驻点处 Hessian 为正定（positive definite），则该驻点为局部极小值（充分条件）；若为负定则为局部极大值；若为不定（既有正特征值也有负特征值）则为鞍点（saddle）。
    - 对称矩阵的特征值全为实数，因此正定/负定概念有明确定义；“正曲率”可帮助直观理解何为最小点。
- 直观例子：带弹簧的瓶子（机械直观）
    - 讲者用一个挂在弹簧上的瓶子（类似球挂弹簧但有几何约束使其更复杂）来说明约束如何改变系统静止位置（即势能最小化问题受不等式约束时，是否接触约束、接触哪一条边或角，会影响解的结构）。约束可被理解为对系统施加额外“力”，这与后来引入的拉格朗日乘子（Lagrange multipliers）有物理类比。
- 最终要点
    - 优化问题既可以是不受约束（unconstrained）的，也可以包含等式与不等式约束；可以是光滑可微的，也可能是非光滑（nonsmooth）、整数混合（mixed integer）、有限维或无限维（例如最优控制问题），这些性质直接影响可选算法与可证明的结果。

## 3.2 优化问题的类别与实践考量

- 以问题属性分类：变量数目、变量类型、目标与约束的结构
    - 变量维度（dimensionality）：从几十到成千上万，甚至无限维（如函数空间中的最优控制问题）的差别，会决定可行算法与数值线性代数策略。
    - 变量的性质：连续型（实数向量）或离散/混合整数（combinatorial），后者通常更难，依赖专门的分支定界（branch-and-bound）等技术。
    - 目标/约束的代数/解析特性：线性、二次、一般非线性、光滑（可导）或非光滑；是否凸（convex）或非凸（nonconvex）。这些属性影响理论难度与实际求解策略（例如凸问题能保证局部即全局最优）。
- 重要问题类别举例（视频中提到的六大类）
    - 线性规划（LP）
        - 目标为线性函数 c^T x，约束为线性等式/不等式与非负性约束 x ≥ 0。标准形式常写为 minimize c^T x subject to A x = b, x ≥ 0。经典应用包括运输问题、物流、供需分配等（视频提到二战后军事物流是早期推动者）。LP 有强大的专用算法（如单纯形法 Simplex、内点法）。
    - 二次规划（QP）
        - 目标包含二次项 (1/2) x^T Q x + c^T x，约束通常为线性等式/不等式。若 Q 为正定或半正定，则为凸 QP，可有效求全局最优。应用示例：均值-方差投资组合（Markowitz，视频讲者亲身经历）与线性模型预测控制（MPC）。
    - 非线性规划（NLP，Nonlinear Programming）
        - 目标或约束为一般可微非线性函数。视频强调 Rosenbrock 函数（“香蕉谷”）是常见的测试问题，能说明非凸与曲面弯曲导致的优化困难。非线性 MPC 即需在每次控制步在线解 NLP。
    - 非光滑优化（Nonsmooth）
        - 目标或约束在某些点不可导（例如绝对值、max、ReLU 等）。尽管不可微，许多问题仍通过近似或专门技巧（子梯度、bundle 方法、罚函数/互补性技巧）使用基于导数的方法取得可接受结果；在机器学习中，很多研究者对不可微的激活函数仍使用基于梯度的优化并取得成功（例如 ReLU）。
    - 混合整数规划（MIP / MILP）
        - 既有连续变量又有限或无限整数变量。大量实际组合优化、调度与路径规划问题都可建模为线性混合整数问题（MIP），并有极强大的商业/学术求解器（如 Gurobi 提示但不得详述以免新增事实）。讲者强调 MIP 的建模灵活性：很多非线性或离散决策问题可通过分段/引入开关变量转化为 MIP。
    - 最优控制问题（Optimal Control）
        - 原本为无限维最优化：决策变量为时间函数（状态、控制轨迹），约束包含微分方程（动力学）以及状态/控制约束，目标为终端或积分型函数。实用方法通常先离散化（direct methods，如 direct multiple shooting），将无限维问题近似为大规模有限维 NLP（通常是大量等式约束将动态方程离散化后堆叠形成）。
- 凸性的重要性（convexity）
    - 凸函数的定义（函数上的线段位于图像上方或图像在两点连线下方）与凸集的定义（任两点连线都在集合内），以及“凸优化问题 = 凸目标 + 凸可行域”。关键性质：任一局部极小即为全局极小，因而凸问题可以高效且可靠地求解全局最优。
    - 视频引用观点：优化领域的“分水岭”更多是凸 vs 非凸，而非线性 vs 线性。凸性是能否可靠求全局最优的关键判据。
- 实践中的重要判定问题（帮助选算法）
    - 变量数量、变量类型（连续/离散）、问题是否凸、目标是否线性/二次/非线性、平滑性（可微次数）、是否存在等式/不等式约束、约束/目标是否可以逐点或分段逼近等。这些判断决定是否使用专用解法（LP/QP/MIP）、Newton 型导数法或基于样本/启发式的搜索方法。
- 方法论建议
    - 不要把求解当作“搜索”（blind search），而应把优化看成“解方程”——求解最优性条件（例如梯度为零、KKT 条件等），然后使用数值方法（Newton 或其变体）来求解这些非线性方程/非线性系统。这个语言上的区分旨在推动使用基于导数的求解器而非简单的采样或随机试探，因后者在高维空间通常不可行。

## 3.3 Newton 型方法与二次子问题（包含 Gauss–Newton、SQP、内点法与活性集法）

- Newton 型方法的基本思想：线性化（linearization）
    - 核心概念是对非线性函数在当前迭代点 x̄ 做一阶（或二阶）泰勒展开，用线性/二次近似替代原函数以构造子问题并求解得到迭代更新。具体形式是一阶展开：L(x) ≈ L(x̄) + J(x̄)(x − x̄)，其中 J 为雅可比（Jacobian）。讲者引申：若函数是标量，雅可比的转置就是梯度（∇），因此在讲义中出现的梯度符号有时被用于表示雅可比的转置，二者需按情境理解。
- 等式约束问题与拉格朗日乘子（Lagrange multipliers）
    - 对等式约束 g(x)=0 的问题，引入拉格朗日函数 L(x, λ) = f(x) + λ^T g(x)。必要最优性条件（若 f, g 足够光滑）是 ∇_x L = 0 与 g(x)=0。把这看作对未知量 (x, λ) 的非线性方程组，则可用 Newton 方法去解该方程组：每一步对这组方程线性化，求解线性方程组得到增量 (Δx, Δλ)，更新迭代。
    - 线性化+二阶信息（Hessian of L w.r.t x）构造出的子问题等价于一个二次规划（QP）子问题，这是 SQP（Sequential Quadratic Programming）的基本思想：每一步解一个 QP 子问题得到新的 x、λ，然后重复。
- 不等式约束、KKT 与互补性（complementarity）
    - 含不等式 h(x) ≥ 0 时，除了梯度条件与原始约束外，最优条件包括互补性条件（μ ≥ 0, μ_i h_i(x) = 0，且 μ 为不等式乘子），这导致了非光滑性（互补性在几何上形成 L 形曲线）。处理思路有两类主流算法（视频重点描述）：
        - 顺序二次规划（SQP）：将非线性问题线性化/二次近似后，得到带不等式的 QP 子问题；需设计如何求解 QP（活性集法或内点法），并处理互补性导致的非平滑性。迭代通常是：在点 x_k 线性化约束与二次近似目标，求解 QP 得 Δx，线搜索或信赖域更新 x_k+1，再更新乘子估计，重复。
        - 内点法（Interior Point）：通过构造障碍（barrier）函数把不等式转换为对目标的连续惩罚，例如对 x ≥ 0 的约束加 −τ ∑ log(x_i) 项（τ > 0 为障碍参数），得到一系列无不等式的光滑问题。随着 τ → 0，障碍问题解的轨迹近似原问题解。每一固定 τ 的问题通常仍是非线性但凸（若原 QP 凸），可用 Newton 解 KKT 条件；内点法在数值上通常表现为“沿路径（path-following）”逐步减小 τ 并用上次解作为初值，从而整体具有良好收敛与可证明的复杂度（对凸问题可得到多项式复杂度保证）。
- Gauss–Newton 与非线性最小二乘的专用简化
    - 对特殊类目标 f(x) = (1/2) ∑ r_i(x)^2（残差平方和，nonlinear least squares），Hessian 具有特殊结构：H = J^T J + Σ r_i(x) H_i（精确式中有残差乘以每个残差的 Hessian）。当残差较小时（或忽略第二项）可近似用 J^T J（Gauss–Newton Hessian），从而子问题极其简化为带 J^T J 的 QP，通常半正定且更易求解。该方法在轨迹跟踪、参数估计、最小二乘拟合与非线性 MPC（当目标为误差平方和）中极为有效：若模型能很好拟合数据或控制能较好跟踪参考（残差小），Gauss–Newton 的收敛速度与收敛区域都很优。
    - 形式上，Gauss–Newton 算法每步线性化残差 r(x) ≈ r(x_k) + J(x_k)(x − x_k)，然后解线性最小二乘得到 Δx，更新 x。可以把这看成一种专门化的 SQP（因为二次项由 J^T J 给出，忽略了残差乘二阶项）。
- QP 子问题怎么解？活性集法与内点法比较
    - 当得到带不等式的 QP 子问题时，有两种常见解法思路：
        - 活性集法（Active Set Methods）：思想是猜测哪些不等式在最优时为活约束（active，即等号成立），把这些不等式当作等式，求解相应的等式约束 QP（或线性方程），再检查 KKT 条件以调整活性集。此法与单纯形法有亲缘关系，对于稀疏/低维问题、需要热启动（warm start）情形常很有效。
        - 内点法（Interior Point Methods）：如上所述，通过障碍函数把不等式“嵌入”目标中，求解一系列无不等式的平滑问题。每一步仍需解大型线性方程（来自 Newton 线性化），但对于大规模稠密/稀疏问题与需要多次求解不同数据的同构问题（例如MPC），内点法常有更稳定的性能。视频提到的实现策略是逐步减小 τ 并对每个 τ 用 Newton 求解（path-following），每一次 Newton 步本质上也需要解线性系统。
    - 内点法在 1990s 的理论突破（对 LP 和 QP 得到多项式复杂度保证）使其在理论与实践上都极具吸引力。现实中，许多高性能 QP 求解器混合利用结构（如特定最优控制的带状/稀疏结构）以达到微秒级性能（这与视频中提到的快速 MPC 求解器示例有关）。
- 从 SQP 到非线性内点法的桥接
    - 对于非线性问题，有两条常见路线：SQP（每步求解 QP）或直接对原问题加入障碍并用 Newton 求解（非线性内点法，如 IPOPT 的思路）。两者本质上都通过求解带二阶信息的线性/二次子问题来推进，但实现细节（如何构造与求解线性系统、如何处理互补性与可行性、如何进行步长选择）不同。
- 算法收敛性与实用建议
    - Newton 型方法在理论上若起点足够好与 Hessian 或近似 Hessian 合理，则可展现二阶收敛（或很快的线性收敛）；Gauss–Newton 在残差较小时通常有很好的收敛常数（收敛速率与残差大小相关）。视频强调实践中不要“盲目搜索”而应构造与求解最优性方程，利用导数和问题结构以获得数值上可行且快速的解。

# 4. 框架 & 心智模型（Framework & Mindset）

- 优化思维的核心心智模型：把优化“解方程”而非“搜索”
    - 基本观念：当面对一个优化问题时，不应把其视作在高维空间中盲目采样或随机寻找最优点（搜索），而应把它视作求解一组非线性方程（即最优性条件，比如梯度为零、KKT 条件等）。这种转变有两方面的含义：
        - 理论上：最优性条件把最优问题转化为数值解法熟悉的“解方程”问题，使得可用 Newton、准牛顿或其他非线性方程求解器的工具与理论（线性化、二阶导数信息、局部收敛性分析等）来研究收敛性质。
        - 实践上：把重心放在构造良好的初值、利用二阶信息与线性代数结构、并用数值线性代数高效求解线性化子问题，从而在高维情形下仍能实现快速收敛。对比“搜索”方法（如暴力采样或简单启发式）通常在维度增加时效率急剧下降。
- 框架：从模型属性到算法选择的流程（决策步骤）
    - 第一步：识别问题的数学属性
        - 确定变量类型（连续/整数）、维数、目标形式（线性/二次/一般非线性）、约束类型（等式/不等式/无约束）、平滑性（是否可导及阶数）与凸性（是否凸）。
        - 识别特殊结构（例如目标是残差平方和、约束为稀疏线性网络、动态系统带时间维度的可展开稀疏结构等）。
    - 第二步：根据属性选择算法族
        - 若问题是线性或二次且凸：优先使用专用 LP/QP 求解器（可用内点法或活性集法，依据规模与是否需要热启动）。
        - 若问题是凸非线性（凸 NLP）：仍可用内点法或凸专用算法，并可保证全局最优解。
        - 若问题是非凸光滑：优先考虑基于导数的 Newton 型方法（SQP、非线性内点、Gauss–Newton 若为最小二乘结构），接受只寻得局部极小值但通常足够的现实情况。
        - 若问题含整数：考虑混合整数规划（MIP），或者用分支定界、启发式、分段逼近等方法；若可将非线性用分段线性化引入整数变量，则可用 MIP 框架逼近。
        - 若目标/约束非光滑：评估是否可通过平滑、罚函数、互补/惩罚/栈化技巧或用子梯度/包（bundle）方法解决；实务中往往通过技巧将问题转为光滑近似后用基于导数的方法。
    - 第三步：利用结构与线性代数优化实现
        - 在 Newton 型方法中，把大规模子问题转化为线性系统或带结构的 QP，并利用稀疏矩阵技术、分块因式分解、并行等完成数值求解。例如在最优控制的离散化后会产生特殊的带状或块稀疏结构，可被高效利用（减少内存与操作计数）。
    - 第四步：数值实现细节（热启动、障碍参数路径、线搜索/信赖域）
        - 对 MPC 或需频繁在线求解的情形（短时间窗口重复求解带新数据的问题），热启动（warm start）与结构化求解器显得尤为重要；活性集方法在热启动场景中常优于内点法，反之内点法在一次性求解高精度凸问题上表现出色。
        - 对于内点法，要设计逐步减小障碍参数 τ 的路径策略，确保每一阶段 Newton 解算收敛，整体路径跟随稳定。
- 实战心法：优先“求解”，善用问题结构，并且接受局部解在很多工程问题中已足够
    - 不盲目追求全局最优（除非问题凸或能承受全局求解代价），在许多应用（如控制、拟合、工程优化）中，局部极小值若满足性能指标即可采用。现实中很多问题近似凸或“接近可解”，因此基于导数的 Newton 型方法在实际运用中非常强大且高效。
    - 对于含大量残差平方和或轨迹跟踪类问题，优先考虑 Gauss–Newton 类方法，因为它能把复杂的二阶项简化为 J^T J 形式的良性子问题，从而以更低的代价取得快速收敛。
    - 在算法实现层面要重视数值稳定性（例如构造良好的 Hessian 近似、避免病态线性系统直接求解）、利用稀疏性与问题分块，并在需要时采用混合策略（如 SQP 内部用内点法解 QP，但利用热启动和结构化解算器加速）。
- 总结性心智格言（来自视频）
    - “不要把优化当作搜索（searching）；应当把它当作解方程（solving）。” 这一点反复被强调，旨在引导从业者使用更系统的数学工具（导数、线性代数、Newton 型方法）而非随机试验。

# 总结

- 视频从基本定义到问题分类，再到 Newton 型数值方法，构建了一条从理解问题性质到选择合适数值算法的完整链条。凸性是决定能否高效全局求解的关键，而把优化视为求解最优性方程（使用导数与线性化）而非盲目搜索，是实务中能显著提高效率的基本心智。对于工程与控制领域尤其常见的残差平方和问题，Gauss–Newton（或受约束形式的 constraint Gauss–Newton / SQP 变体）提供了既简单又强力的求解套路；QP 子问题的高效求解（活性集法或内点法）是使整体方法可行的核心数值环节。视频还建议阅读几本经典教材来深入（讲者提到的经典书籍名，但在此不新增事实），并以实践案例（如作者在金融公司实习时从暴力搜索切换到专用 QP 求解器带来的巨大加速）说明专用算法的价值。
