# 3. 按照主题来梳理

## 3.1 连续时间与离散时间动力学模型的基本概念

- 视频先定义了动力学系统模型的三要素：动态系统模型本身、约束和目标函数（在 MPC 中称为成本 cost，在强化学习中称为回报 reward，二者在数学上就是最小化或最大化问题）。本讲重心在“动态系统模型”上。
- 状态（state）记为 S（或在工程学中常用 x），状态空间记为大写 S（可连续实向量空间或离散集合，如棋类游戏的状态）；控制/动作（action）记为 A（工程上常称 u）；还引入了扰动/噪声 ε（epsilon）以表示不可控或随机影响（测量噪声、过程噪声，或对抗性输入/游戏对手）。
- 两类基本形式：
    1. 离散时间随机系统：下一时刻状态由函数 f(S, A, ε) 决定，其中 ε 是随机变量（或对抗者的动作）。离散时间索引用下标 K 表示，例如 S_k。
    2. 连续时间确定性系统（常微分方程 ODE）：使用微分方程 ṡ(t) = f^C(s(t), a(t)) 表示（讲者用 FC 标注连续右侧函数以区分离散情形），状态现在是时间的函数 s(t)，导数记作 ṡ。通常在物理与工程中非常常见。讲者约定：离散时间用下标 K 表示，连续时间用括号加 T 表示，且常省略时间参数以简化表达。
- 举例：阻尼谐振子（damped harmonic oscillator）——用两个状态 x1（位置）与 x2（速度）来描述。位置往往可量测但速度不一定直接量测，说明需要把隐藏状态（速度）纳入模型中。状态方程例如：
    - ẋ1 = x2
    - ẋ2 = -k/m * x1 - β/m * x2 + u/m （k 弹簧刚度，β 阻尼系数，u 控制力）
这个例子强调两个点：必须选对状态以能完全描述未来演化；实际测量通常不包含全部状态，会引入可观测性/不可观测性的问题。
- 关于连续→离散的动机：机器学习、MPC 等大多以离散时间模型为主，因此需要把物理连续时间模型转为离散时间以便数值优化与控制器实现。讲者强调这是“重要且常被忽略的”转换步骤，并将后续讨论作为重点。

## 3.2 从连续时间到离散时间：直接多重射击（Direct Multiple Shooting）与数值积分

- 关键思想（直接多重射击/Direct Multiple Shooting / zero-order hold 参数化）：
    1. 选择一个等距采样网格，时间步长 Δt。将在这些离散时间点上采样状态 S。
    2. 控制按区间保持常数（zero-order hold，零阶保持），即在每个采样间隔内 a(t) = 常数 a_k。这是数字控制器中常见的实现。
    3. 在每个时间段上解连续时间 ODE（用数值积分）以得到从初始状态 s_k 在 Δt 后的终点 s_{k+1}。将这终点定义为离散时间映射 f(s_k, a_k)，即 S+ = f(S, A) 的形式。
- 说明：此离散化只在控制上引入误差（零阶保持所致），而连续方程在区间内部被满足（通过数值解）。因此核心在于如何有效准确地数值积分 ODE。
- 数值积分方法概述：
    - Euler（欧拉法）：最简单的一阶方法，做一步 s_{k+1} ≈ s_k + Δt * f(s_k, a_k)。误差较大，不推荐单步使用。可以细分为多子步（相当于减小步长 Δt/n），准确性提升但计算成本成比例增加。
    - Runge-Kutta（龙格-库塔）方法：属于单步多阶段方法（single-step, multi-stage），以经典 RK4（四阶 Runge-Kutta）为代表。RK4 通过在区间内评估多次微分（v1...v4），按加权组合得到高阶精度。RK4 的一次完整步等价于四次函数评估，但误差量级远优于四次 Euler 子步，因此在“人类所需的准确度范围（例如 10% 到 1e-6）”内常常是效率最优的选择，解释了 RK4 在工程与科学计算中广泛使用的“偶然”原因。
- 积分方法的“阶”和效率：
    - 积分阶 p 表示误差随步数/评估次数 M 的衰减速率，大致误差 ∝ M^{-p}。每种方法有内部阶段数 s（例如 RK4 有 s=4），每步的函数评估数为 s，整体评估次数为步数 × s = M。
    - 在低 M（评估次数少）时，低阶方法（如 Euler）可能更优；在中等到高精度需求时，中高阶方法（如 RK4 或更高阶 Runge-Kutta）更具效率。讲者用“效率前沿（efficient frontier）”示意图说明不同方法在不同精度需求下的优劣。
- Runge-Kutta 的通用模板（Butcher tableau，巴特查（Bacha）表）：
    - 通用 Runge-Kutta 的离散表达由两个矩阵/向量 A（阶段系数）和 b（权重）决定，统称为 Butcher tableau。显式方法的上三角为零（可按顺序计算内部阶段），隐式方法有非零对角或上三角，需解代数方程（可能用 Newton 方法），但隐式方法在刚性系统（stiff systems）中更稳定。
    - 讲者强调理解 Butcher tableau 能使你实现任意 Runge-Kutta 方法；此外隐式 RK 与高精度 Gauss-Legendre 积分（例如 2 阶/4 阶 Gauss）在优化与求解含隐式方程的情形（如 collocation）中特别有用。
- 小结：通过“零阶保持 + 数值积分”，连续时间系统可被严格地转化为离散时间映射 f(s, a)。选择合适的积分器（通常 RK4）在精度/计算成本折衷上至关重要；隐式方法在某些刚性/优化场景下不可或缺。

## 3.3 状态空间模型与输入-输出模型（包括 ARX、FIR、IIR 等）

- 两种建模视角：
    1. 状态空间（state-space）模型：保留内部状态 s，使用状态转移与观测函数（f 与 g）：
        - s_{k+1} = f(s_k, a_k, ε_k)
        - y_k = g(s_k, a_k, δ_k)
其中 y 为测量/输出，ε、δ 为噪声。状态空间模型清晰对应物理学建模，适合做状态估计（Kalman filter / 扩展卡尔曼滤波 / MHE）。
    2. 输入-输出（input-output）模型：直接用最近若干个输入 u（a）与输出 y 的历史窗口预测下一个输出 y_{k+1}，形如 y_{k+1} = h(y_{k},...,y_{k-n+1}, a_{k},...,a_{k-n+1}, a_{k+1})。初始条件即历史的输入/输出序列。输入-输出模型不关心内部状态，便于黑箱建模与端到端学习（例如把过去若干帧图像直接映射到下一步动作）。
- 输入-输出与状态空间的相互转换：
    - 任一输入-输出模型都可以构造等价的有限维状态空间表示：把“过去 n 个输入与输出”堆叠成一个向量作为状态 s（滑动窗口），定义状态转移为“左移并插入最新的 y 与 a”，输出由函数 h 给出。这是一种明确的转换方法，适用于将历史窗口法写成状态空间。
    - 反方向（状态空间 → 输入-输出）并不总是可行，但在“线性时不变且可观测/可控（observable & controllable）”的线性系统情形，可以用脉冲响应或传递函数把状态空间等价为一个输入-输出模型。若完全没有测量输出，则无法构成输入-输出模型。
- 线性输入-输出模型的常见子类：
    - ARX（AutoRegressive with eXogenous inputs）或 ARMAX（含噪声项）或 IIR（Infinite Impulse Response）模型：y_{k+1} 线性依赖于过去若干 y 与过去若干 a。若存在对过去输出的回归项（C 部分）就属于 AR 类 / IIR，系统对一次脉冲有无限衰减响应。
    - FIR（Finite Impulse Response，有限冲激响应）模型：若输出仅依赖于过去输入而不依赖过去输出（即 C 部分为零），则为 FIR，系统对脉冲仅有有限长度影响，模型辨识简单，常用于某些 MPC 实现。
- 例子与直观解释：
    - Fibonacci 数列可以看作一个不含输入的简单自回归（AR）模型：下一个数等于前两个的和（窗口大小 n=2，系数 = 1），该系统不适用于控制但直观说明 AR 的含义。其本身是一个不稳定（增长）系统。
    - 工业例子：化工连续搅拌釜（连续流反应器）中可测量的只是某些温度/浓度，且测量可能有延迟（例如 PCR 测试），因此输入-输出建模在处理延迟与易测量量上更现实。
- 应用与辨识实践：
    - 在 MPC 中，常见实践是辨识阶数较低的 FIR 或 ARX 型模型（例如辨识阶跃响应系数），因为只需通过一次阶跃试验就能获得 B 系列（对输入的响应系数），便于在控制器中实时滚动预测并加入校正项。
    - 在机器学习或黑箱模型中，常用神经网络作为 h 函数来直接拟合输入-输出映射（端到端学习），例如把最后 N 帧图像直接映射到下一个动作，这在机器人视觉控制或某些强化学习框架中很常见。
- 小结：状态空间模型更贴近物理且便于状态估计；输入-输出模型更现实（直接基于可测量数据）且便于直接辨识或端到端学习。两者可在一定条件下互相转换，选择依赖于量测可用性、计算/辨识资源与控制目标。

## 3.4 随机（随机性）系统模型、噪声建模与估计任务

- 噪声来源与参数不确定性：
    - 实际系统总有扰动（ε），来源包括未建模动力学、外界扰动、测量误差等。参数（如质量、摩擦系数）虽然在短时间内可视为常数，但通常未知且需估计（例如汽车重量随乘员改变）。这种常数参数在数值处理上常被视为“不会变化的状态”，即 p_{k+1} = p_k（必要时可加入小噪声以允许缓慢漂移），从而能用状态估计方法在线辨识。
- 随机状态空间与输入-输出模型：
    - 最通用形式写成 s_{k+1} = f(s_k, a_k, ε_k)，y_k = g(s_k, a_k, δ_k)，其中 ε_k、δ_k 可以相关或不同。常见的特例是“加性状态噪声 + 加性测量噪声”。
    - 在输入-输出随机模型中，输出 y_{k+1} 可能依赖过去若干噪声项（即噪声有记忆），这导致“方程误差（equation error）”的概念：把噪声加在状态转移或输出方程中，会使得未来的预测包含累积的随机误差。
- 方程误差（equation errors）与输出误差（output errors）的区别：
    - 输出误差：测量噪声只影响观测 y（即测量值有噪声），而不改变系统内部状态。典型情形：传感器测量信息不准确。
    - 方程误差 / 状态噪声：噪声影响状态本身（或模型方程不精确），因此被加入到自回归项中，进而影响未来的输出预测。两者在辨识与预测中的处理方法不同——方程误差会影响模型的自回归迭代，输出误差则常通过滤波处理。
- 两项关键任务（在实现基于模型的控制如 MPC 时必须区分）：
    1. 离线系统辨识（System Identification）：在部署控制器前进行，使用设计好的激励（excitation）输入与长序列数据来估计模型参数（例如线性系统可用最小二乘或更高级的子空间辨识来同时估计模型阶数与矩阵）。这是“离线”阶段，工程师通常在现场做辨识试验后回家处理数据。
    2. 在线状态估计（State Estimation）与在线辨识：在控制器运行时需要估计当前状态 s_k（尤其在部分可观测时），常用方法有卡尔曼滤波/扩展卡尔曼滤波（EKF）或移动窗估计（Moving Horizon Estimation，MHE）。MHE 是基于固定时间窗的优化方法，能在非线性或约束情形下表现良好，也便于同时在线调整参数（模型适应 learning-based MPC）。
- MDP（Markov Decision Process）与可观测性联系：
    - 在强化学习的术语中：如果能直接观测到完整状态则称为“全可观测 MDP（fully observable MDP）”；若无法直接观测则是部分可观测 POMDP（Partially Observable MDP）。输入-输出模型（以过去输入输出窗口作为状态）在设计上等价于“可观测”——因为窗口内包含足够信息以进行预测（假设窗口长度足够）。但在系统理论中“可观测性（observability）”有更严格数学定义，用来判断是否能从测量推断出完整状态，两者概念相关但不完全相同，应区分。
- 概率视角与“条件概率”形式：
    - 在概率模型中，系统由条件概率密度 p(s_{k+1} | s_k, a_k) 与 p(y_k | s_k, a_k) 描述；在加性噪声情况下，这些条件密度通常是“确定性项 + 噪声分布”（例如 Gaussian）。概率形式在 RL 的策略评估与贝叶斯估计中很常用。
- 小结：把参数视作常数状态、明确噪声加在何处（状态/输出/方程）对辨识、滤波与控制设计有直接影响。离线辨识（系统识别）与在线状态/参数估计是实现可靠 MPC 的两大任务；MHE 在参数在线估计与受约束系统中表现良好。理解 POMDP/MDP 的可观测性差异有助于桥接控制工程与 RL 语言。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：建模-离散化-辨识-估计-控制 的工程流程（五大模块，逐步细化）
    1. 建模（Modeling）：先从物理/先验知识决定模型类型：连续时间或离散时间？状态空间（适合物理、便于解释与约束）还是输入-输出（更现实、直接基于测量、便于黑箱学习）？是否需要引入随机项（过程噪声、测量噪声）与未知参数？这一步决定了后续技术栈（ODE 求解、数值积分、滤波、辨识策略）。
    2. 连续→离散（Discretization）：若原模型为连续时间且执行环境为数字控制器或优化器，则采用“采样 + 控制零阶保持 + 在区间内数值积分”的策略得到离散映射 f(s,a)。在这个阶段选择数值积分器（Euler、RK4、隐式 RK 等）并评估精度/计算成本折中，考虑刚性问题需用隐式方法。
    3. 系统辨识（System Identification，离线）：在部署前通过设计激励序列（阶跃、脉冲、随机激励）采集数据，采用线性最小二乘、子空间辨识、或非线性机器学习方法（神经网络）来拟合模型参数。对线性系统可利用 ARX/ARMAX/FIR/IIR 等模型形式简化任务。目标是得到在工作区间内良好的预测性能。
    4. 在线估计（State & Parameter Estimation）：控制器运行时，通过滤波器（卡尔曼/扩展卡尔曼）或移动窗优化（MHE）估计当前状态与慢变参数，处理测量噪声与模型不确定性。MHE 的优势在于处理非线性与约束并能同时进行参数估计（learning-based MPC）。
    5. 控制设计（Control）：基于估计的状态与辨识模型设计最优策略（MPC、反馈控制或强化学习策略 π(s)）。关键环节包括约束处理、闭环稳定性验证与在线优化性能的计算开销。在线控制需要保证估计器与模型的一致性以避免“模型-控制-实际”之间的性能崩溃。
    - 该框架强调一个循环：模型决定离散化和辨识策略；辨识结果影响估计方法；估计为控制提供输入；控制运行时又产生数据可用于进一步辨识/自适应（learning）。
- 心智模型二：选择数值方法的“效率前沿”心法
    - 问题：在给定的计算预算（函数评估次数 M）下，如何选择数值积分方法以最小化时间离散化误差？
    - 思路：
        1. 认识“阶数 p 与误差 ∝ M^{-p}”的关系。高阶方法在 M 足够大时胜出，但每步的内部阶段 s 会增加每步评估数；所以实际效率取决于目标误差范围与可接受的计算量。
        2. 绘制或心中构造“错误 vs 评估次数”的对数图（效率前沿），比较 Euler、RK4、Higher-order RK、隐式 Gauss-Legendre 等方法的曲线；在低精度（误差允许较大），低阶方法可能更划算；在人类常需的中小数量级精度（例如 10% 到 1e-6），RK4 常是计算-精度权衡的拐点，因此被广泛采用。
        3. 若系统刚性或稳定性要求高（刚性系统需要大步长下稳定），优先考虑隐式方法或更稳定的多步法，尽管需要求解隐式代数方程（需要 Newton 或优化器），但能在长时间步下保持稳定性。
        4. 在优化嵌套（例如 MPC 中每步都需积分）情形下，考虑积分器对梯度/灵敏度的影响：隐式法与协方差/灵敏度计算可能更复杂；选用的积分器应兼顾数值稳定性与导数计算（自动微分友好性）。
    - 结论：不要盲目选 Euler 或盲目追求极高阶；基于目标误差、计算预算与系统特性（是否刚性），选择位于效率前沿上的方法（在许多工程问题中，RK4 是常见的合理选择）。
- 心智模型三：可观测性与建模视角选择原则（工程决策树）
    1. 首先明确可测量量（哪些 y 可直接获得、采样延迟、噪声特征）与控制量（可施加/可选的动作 a）。若能直接获得完整状态（或可通过简单测量集合唯一确定状态），优先使用状态空间模型并采用滤波器估计；若无法测全但过去输出/输入的历史窗口能提供充分预测能力，则采用输入-输出模型（ARX/FIR 或黑箱神经网络）。
    2. 若系统物理先验丰富（如机械系统、化学过程），优先使用物理驱动的状态空间模型以便解释性与安全约束；同时考虑把某些未知常数参数当作“常态变量”纳入状态估计，便于在线校准。
    3. 若目标是快速原型或端到端策略（例如深度 RL），且测量空间（如图像）直接映射到动作表现良好，则可采用输入-输出模型/黑箱策略。但仍需关注数据覆盖性（训练数据是否涵盖控制时域）与闭环稳定性风险。
    4. 在资源受限或需要可靠工程保障时（工业 MPC），使用线性 FIR/ARX 作为基线，辨识简单、运行稳定、易于并入约束优化；在需要更高性能且有足够数据与计算资源时，推进到非线性/黑箱模型并配合在线估计与自适应策略。
- 心智模型四：辨识与控制要分清“离线参数学习”与“在线状态估计/自适应”
    - 离线系统辨识重在获取长期稳健参数（用大量实验数据、系统辨识工具），在线估计/自适应重在应对瞬时扰动与慢变参数。混淆两者会导致控制器在部署阶段的不稳定或性能下降。实践中常见流程是先离线辨识得到基线模型，再在运行中用滤波或 MHE 对状态与参数进行微调。

# 总结

视频系统地介绍了动力学系统建模的基本分类与实际处理要点：区分连续/离散时间、状态空间/输入输出、确定性/随机性三对关键维度；从连续到离散的标准做法是“采样 + 零阶保持 + 数值积分”，其中 Runge-Kutta（尤其 RK4）在多数人类可接受的精度区间常为效率最优的选择；输入-输出模型为现实测量提供了直接建模途径（ARX、FIR、IIR 等），且可与状态空间模型互相转换（条件受限）；随机性（状态噪声与测量噪声）要求离线系统辨识与在线状态/参数估计（卡尔曼/EKF/MHE）两类任务分开处理。理解这些模型与数值方法的基本原则，是设计 MPC、RL 与更复杂控制/学习系统的基础。
