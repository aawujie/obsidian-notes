# 2. Overview

本视频的核心论题是：如何从模型预测控制（MPC）的在线优化问题出发，定义并分析由 MPC 生成的闭环系统的稳定性，并证明在合适的设计（尤其是阶段成本、终端约束/代价的选择）下，MPC 的最优值函数可以作为 Lyapunov（莱普诺夫）函数从而保证闭环状态收敛到目标（通常取原点）。结论是：通过设计正定的阶段成本、合适的终端约束或终端代价，并借助动态规划的单调性原理，可以把 MPC 的值函数构造成满足 Lyapunov 条件的函数，从而得到（局部或全球）渐进稳定性保证；零终端约束（terminal constraint s_N = 0）是最直接易实施的一种保证手段，而基于线性二次调节（LQR）局部终端集与终端代价的构造是另一常用的、具构造性的做法。视频同时讨论了定义细节、假设、以及对实际实现的一些备注与限制。

# 3. 按照主题来梳理

## 3.1 MPC 优化问题与 MPC 反馈的定义

- MPC（Model Predictive Control，模型预测控制）在线控制的本质是：在时刻 k（或以离散索引 i 表示）基于当前测得的状态 s0（视频中简称 s_0 或 s0），去求解一个有限时域的最优控制与预测状态序列的优化问题。优化变量通常包括 u（或 a）序列 a_0, a_1, …, a_{N-1} 以及对应的预测状态序列 s_1, s_2, …, s_N（有时 s_0 给定为当前状态）。约束可能包含状态约束 h(s,a) ≤ 0、控制约束、系统动力学 s_{i+1} = f(s_i, a_i) 以及终端约束（terminal constraint）s_N ∈ X_f（视频中举例为 s_N = 0 的零终端约束）。
- 在记号上，视频作者做了一个“记号技巧”：把当前实际的初始状态 s0 看作优化问题的参数而不是变量，从而把优化问题写成 J_N(s0) = min_{a_0..a_{N-1}, s_1..s_N} Σ_{i=0}^{N-1} C(s_i, a_i) + E(s_N)，并记下在这个问题的最优解中第一步的控制 a_0^* = π_MPC^N(s0)。这里 π_MPC^N 表示以时域长度 N 的 MPC 反馈映射：给定初始状态 s0，返回第一步要实施的动作 a_0。
- 讲者强调了一个重要的抽象假设：在这些理论推导中通常假定在每个采样时刻，我们能“即时且完美”地获得该参数化优化问题的最优解（即忽略求解时间或计算延迟），这便于把控制器视为一个确定性的、时间不滞后的反馈映射。在工程实践中这可能不满足（需要近似、热启动或次优求解），但理论分析先在理想化条件下展开。
- MPC 的运作流程简述：测量当前状态 s_i → 以 s_i 为参数在线求解有限时域 NLP（非线性规划）得到最优动作序列 → 应用第一步 a_i = a_0^* 到真实系统 → 系统演化到 s_{i+1} = f(s_i, a_i) → 将时域前移重复上述过程（所谓 receding horizon）。
- 视频反复提示：MPC 仅“看” n 步到未来（有限视野），实际闭环行为涉及无限次重复的有限次优化循环，因此闭环稳定性并非自动成立，需要额外设计与证明。

## 3.2 闭环系统定义与稳定性概念（局部稳定、渐进吸引）

- 闭环系统的定义：当把 MPC 反馈 π_MPC^N（或简称 π_MPC）代入系统动力学 s_{i+1} = f(s_i, a_i) 中后，得到一个只有状态变量的离散时间自治系统 s_{i+1} = f_cl(s_i) = f(s_i, π_MPC(s_i))。此处 f_cl 明确表示“闭环动力学”，而 a 已成为内部量（控制器内部的优化结果），不再作为外部输入出现。
- 视频对“稳定性”给出正式的系统理论（拓扑）定义：原点（s = 0）为稳态，局部稳定（Lyapunov stability）定义为：对于任意给定的 ε > 0（任意小的邻域），存在 δ > 0，使得若初始状态 ||s_0|| < δ，则闭环轨迹 ∀ i ≥ 0 满足 ||s_i|| < ε。这是“保持在小邻域内”的性质（不要求收敛）。
- 渐进稳定（asymptotic stability）或“全局吸引性”（global attractivity）进一步要求：对所有初始状态（局部/全局情形依具体定义），轨迹 s_i 随 i → ∞ 时收敛到原点。一般要证明“稳定 + 吸引性”从而得到渐进稳定性。
- 讲述了常见混淆点：必须指定控制律后才谈系统的稳定性——“开环系统是否稳定”不是完整的问题，需结合具体反馈（例如零控制动作作为一种反馈）来谈“在该反馈下系统是否稳定”。MPC 能够稳定原本开环不稳定的系统，只要系统具备可控性并且 MPC 设计满足相应条件。

## 3.3 莱普诺夫函数（Lyapunov function）的定义与直观语义

- Lyapunov（莱普诺夫）函数的定义：对闭环系统 s_{i+1} = f_cl(s_i)，一个函数 V: 状态空间 → ℝ 被称为 Lyapunov 函数（在原点处），当且仅当它满足以下条件（视频使用较通用的形式，包含上下界和下降量）：
    1. 正定性与上下界：存在比类函数（K_∞ 类，kappa-infinity）α1(·), α2(·)，使得 α1(||s||) ≤ V(s) ≤ α2(||s||)。这里 α1、α2 是从 ℝ_+ 到 ℝ_+ 的连续、严格递增且 α(0)=0 且趋向无穷（radially unbounded）的函数。此条件保证 V 在原点为 0，且 V 随离原点距离有合适的下界与上界，防止奇异/退化行为。
    2. 下降性：存在另一个正定函数 α3(·)（不必是 K_∞，但正定，即 α3(0)=0，且对非零输入为正），使得对任意状态 s，满足 V(f_cl(s)) ≤ V(s) − α3(||s||)。换言之，沿闭环轨道 V 在每一步都会严格下降（除非处在原点）。
- 直观意义：V 的上下界让我们把 V 看作一种“广义距离”或能量量度，下降条件意味着每一步“能量”或“距离度量”减小，从而保证状态不能跑出某个水平集，并且随着时间持续下降最终收敛到原点。视频用“水平集收缩”的图像去说明：若 s 在某一水平集内，V 递减意味着不会退出该水平集，并会进入更小的水平集，最终只能停在原点。
- 重要结论（Lyapunov 理论）：若存在满足上述条件的 Lyapunov 函数，则原点是稳定并吸引的（可得渐进稳定性）。这就是 Lyapunov 函数被广泛用作稳定性证明的原因。

## 3.4 将 MPC 的值函数（value function）作为 Lyapunov 函数的思路与关键步骤

- 基本想法：将 MPC 优化问题的最优成本（value function）V_N(s) = J_N^*(s) 视为候选的 Lyapunov 函数。若能证明 V_N 满足正定性和沿闭环下降性，则可推出闭环渐进稳定性。
- 首步（正定性）：要让 V_N 正定，需要阶段成本 C(s,a) 以及终端代价 E(s_N) 满足正定性质，且系统有使零轨迹可行的假设（即 s=0, a=0 构成一条可行轨迹并且 C(0,0)=0, E(0)=0）。特别地，若阶段成本有下界 α4(||s||)（α4 为正定函数）使得 C(s,a) ≥ α4(||s||)，那么 V_N(s) ≥ α4(||s||)（因第一步阶段成本至少为 α4(||s0||)）。因此在合理的假设下，V_N 在原点为零且对 s≠0 为正，从而可实现 Lyapunov 的 α1、α2 条件（配合上界的常规估计）。
- 核心（下降性）：需要证明对闭环下的下一步状态 s^+ = f(s, π_MPC^N(s))，有 V_N(s^+) ≤ V_N(s) − α3(||s||)。这部分更为微妙，因为 MPC 的 horizon 向前滚动会带来“失去最后一步的预测”的问题（horizon 的“移动”与长度变化）。关键技巧如下：
    - 用动态规划（principle of optimality）的思想：把长度为 N 的最优问题与长度为 N−1 的问题联系起来，观察若在时刻 k 使用 π_MPC^N(s) 并执行一步，得到新的状态 s^+，那么以 s^+ 为起点的 N 步问题的最优值 V_N(s^+) 与以 s 开始的 N 步问题的最优值 V_N(s) 存在关系。
    - 构造可行解并利用最优化单调性（或动态规划算子 T 的单调性）：具体做法是把以 s 为起点的 N−1 步最优轨迹（且满足某终端约束，如 s_{N−1} = 0 的零终端约束）向后延拓一小段（在原点处附加零控制与零状态）得到一个对 N 步问题的可行候选解，从而得到 V_N(s) ≤ cost(candidate)。反过来，竞争地可以用 N 步的最优解的前 N−1 步作为以 s^+ 为起点的 N−1 步可行解，从而得到 V_{N−1}(s^+) ≤ V_N(s) − C(s,a)（采用最优性与分段代价分解）。综合两边并结合 C(s,a) 的下界 C(s,a) ≥ α4(||s||) 可推导出期望的下降量 α3。
    - 但是上面思路成立的关键在于“终端处理”要允许把 N−1 步问题的最优解在 N 步问题中扩展为可行解。最直接、最简单的手段是采用零终端约束 s_N = 0（或在 N−1 步问题中 s_{N−1} = 0，视写法而定）：若较短 horizon 的最优轨迹在末端必须到达原点，则向后扩展 N 步时可以把末端以保持在原点的方式继续扩展（即 append s_N = 0, a_N = 0），使得短 horizon 的可行解在长 horizon 中仍然是可行的且代价相同。于是长 horizon 的最优值 ≤ 用短 horizon 的可行解得到的代价，从而得出动态规划算子单调性产生的关系，最终推导出 V_N 的下降性。
- 因此，证明下降性的另一个路径是：确保终端约束/代价（terminal constraint/cost）具有一种“可延展性”或“可行延拓”属性，使得短 horizon 的最优解能在长 horizon 下被扩展为可行解（通常通过零终端约束或终端集合与终端控制策略的构造实现）。
- 视频总结说法：若阶段成本正定且终端处理（终端约束或终端代价）被设计，使得向前滚动 horizon 时能保证可行解的延拓与代价不增（或满足合适不等式），那么 V_N 可以满足 Lyapunov 的下降性条件，从而作为 Lyapunov 函数证明闭环稳定性。

## 3.5 终端约束与终端代价的设计方法（零终端约束、基于 LQR 的终端集）

- 零终端约束（terminal equality constraint s_N = 0）：这是视频中讲者偏爱的“最容易实现且概念最清晰”的方法。步骤与性质：
    - 在 MPC 优化问题中加入约束 s_N = 0（或 s_{N-1}=0，取决于索引约定），并在终端代价处设置 E(0)=0，其他不可行点赋予 ∞（即扩展值 Ē）。
    - 该约束确保：对短 horizon 问题的最优解，其末端被强制为原点，因此将短 horizon 的解附加上末端的零操作可以作为长 horizon 的一个可行候选解（且代价不变），因此长 horizon 的最优代价不能高于用短 horizon 可行解计算得到的代价。动态规划的单调性就能给出需要的代价不等式来导出 V_N 的下降性质。
    - 优点：概念简单、数学推导直接；对理论证明非常友好。缺点：在高维系统或受限控制能力下，要求在 N 步将任意初始状态驱到原点可能不切实际，需要较长的 horizon 才能满足可行性（尤其状态维数大、控制通道少、受控度不足时）。
- 基于 LQR 的终端集与终端代价（terminal region + LQR terminal cost/feedback）：
    - 适用于在原点附近系统是线性或可线性化并且可以用 LQR（线性二次调节）得到局部最优反馈的情形。构造步骤：
        1. 先在无约束的线性二次问题下求解代价矩阵 P（Riccati 方程得到），得到局部 LQR 反馈 law K 与相应的二次终端代价 V_LQR(s) = s^T P s。
        2. 选取一个半径（或椭球）终端集合 X_f = { s | s^T P s ≤ δ }，并选择 δ 足够小以保证当在这个集合内施加 LQR 反馈时，控制与状态约束不会被违反（即 LQR 的动作在约束下仍然可行）且 LQR 在该集合内能使状态向内收缩。
        3. 在 MPC 优化中加入终端约束 s_N ∈ X_f，并把终端代价设为 E(s_N) = s_N^T P s_N，从而利用 LQR 的性能在终端集内把后续无穷时域的代价界定好。
    - 理由与效果：在终端集合内 LQR 的代价本身是一个 Lyapunov 函数（局部），并且 LQR 控制能保证在该集合内的可行性与收敛，由此可以证明 V_N 的下降性（通过把短 horizon 的末端扩展为在终端集合内由 LQR 控制延续的轨迹），从而获得闭环渐进稳定性。与零终端约束相比，这种方法更实用（允许到达一个小集合而非精确到原点），更接近实际 MPC 设计。
- 设计取舍：零终端约束简单但可能要求 N 很大或不可行，基于 LQR 的终端集更灵活但需要线性化/预解 Riccati、选取合适 δ 并验证约束可行性；两者都是通过确保短 horizon 解可以被延拓为长 horizon 的可行解（或与某个已知稳定策略相连）来建立 V 的下降性。

## 3.6 动态规划视角：算子单调性与延拓性（monotonicity）

- 将 MPC 的 value function 与动态规划（DP）的算子 T 联系起来：延长 horizon 的过程本质上等价于对 value function 应用 DP 的回传算子 T（Bellman 算子）。如果定义 V_k 为 horizon 长度为 k 时的最优代价，则 V_{k+1} = T[V_k]。
- DP 算子的单调性：若对于任意两个代价函数 V ≤ W（按点比较），则 T[V] ≤ T[W]。在 MPC 证明中，构造一种特殊的初始终端代价/扩展值函数 Ē，使得对于某个较短 horizon 的 V_{N-1}，有 T[V_{N-1}] = V_N ≤ V_{N-1} − C(s,a)（借助于候选解的可行性和阶段成本的下界），单调性用于逐步扩展与比较。
- 直观上，若终端处理（终端约束或代价）被设计为“足够收敛”或“把不可能的点赋 ∞”，那么动态规划的回溯会逐步“松弛”出更多可行状态，然后因最优化而使得随 horizon 增长代价不增，进而在闭环步进时诱导出代价下降的不等式。这是用 DP 语言极简洁地概括此前几何扩展（可行解延拓）的论证。
- 视频强调：很多 MPC 稳定性证明都绕不开动态规划的这个思想——把“延长 horizon 等于应用 DP 算子”这个视角，可以快速得出所需的不等式关系，而不必反复做图形化的可行解构造。

## 3.7 实例、局限与实践注记（不稳定点示例、计算与实现的注意事项）

- 不稳定固定点的例子与 Lyapunov 的存在性：若原点是一个不稳定固定点（例如一维映射 s_{i+1} = 2 s_i），则不存在符合 Lyapunov 定义的函数用以证明该点在闭环（若不加控制）下的稳定性；换言之，Lyapunov 函数存在性是稳定性的充分证据，而若点不稳定则必然不存在可用的 Lyapunov 函数（在给定动力学下）。视频用倒立摆（inverted pendulum）作为直观示例——无控制下倒立摆不稳定，但有反馈控制（比如实时测角并施加跟随的控制）则可以稳定。
- 实践中的计算假设：理论证明通常假定“真实系统与 MPC 的预测模型一致（nominal model）”且“优化器可以在每个时刻得到精确最优解且无延迟”。在实践中两者都可能不满足：模型不匹配、扰动、优化计算延迟、次优解等都会影响闭环稳定性，需要额外的鲁棒性分析或离线/在线修正。讲者明确指出这里采用的是理想化的假设（即 nominal MPC 情形）。
- horizon 长度与维度问题：如果状态维度很高、控制通道少，或存在分布式参数系统（如偏微分方程），要求在有限步内到达终点（或小的终端集）可能不现实，因此需要更长的 horizon 才能保证可行性与稳定性。一个简单的经验法则是 horizon 长度应至少在某种意义上不小于状态维度 / 控制自由度，但这只是直观和经验性的说法，实际选择还受可行性、计算负担与性能要求制约。
- 关于无终端代价 / 无终端约束的 MPC：视频提到另一条研究路线是直接证明在没有终端项（或弱终端项）的情况下，通过足够长的 horizon 或其他技术也可以得到稳定性保证；这在文献中是活跃的研究方向，也更接近一些工程实现（因为很多工程实现默认没有显式的终端约束或终端代价）。但这些证明通常更复杂，依赖于更细粒度的可控性/可达性估计或系统结构（例如线性系统、增广系统的可控性半径等）。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架总览：从 MPC 优化问题到闭环渐进稳定性证明可以抽象为以下清晰步骤（每一步都是一个设计或证明模块）：
    1. 明确系统模型与假设（模型 f、约束集、是否存在稳态 0）：第一步要明示你分析的是 nominal system（预测模型与真实系统一致），并且假设零状态与零控制构成可行轨迹（f(0,0)=0，且 C(0,0)=0，E(0)=0）。这为后续把零作为目标态、并让零轨迹具有零代价奠定基础。
    2. 设计阶段成本 C(s,a) 以保证正定性：阶段代价必须在 s≠0 时严格大于零（至少存在下界 α4(||s||)），以确保 V_N 在起始时点对偏离原点的惩罚作用，并为 Lyapunov 的下界提供 α1。这通常通过二次形式（如 C = s^T Q s + a^T R a）实现（Q>0）。
    3. 选择并设计终端处理（终端约束或终端代价）：这是保证沿轨道下降的关键。提供两种主流方法（零终端约束和基于 LQR 的终端集与终端代价）。目标是确保短 horizon 的最优解能被延拓为长 horizon 的可行解（或与已知稳定局部控制策略连接），这是 V_N 下降性质的核心来源。
    4. 利用动态规划（DP）与可行解延拓证明下降性：把“延长 horizon 等于对 value function 应用 DP 算子 T”作为工具，利用单调性和候选解构造，证明 V_N(s^+) ≤ V_N(s) − α3(||s||)。重点是通过合适的终端处理把短 horizon 的可行解扩展为长 horizon 的可行候选，从而通过最优性得出不等式。
    5. 汇总得到 Lyapunov 条件与稳定性结论：结合步骤 2 的正定性与步骤 4 的下降性，得出 V_N 满足 Lyapunov 函数的两大条件，进而可得闭环系统的局部或全局渐进稳定性（取决于 α 函数的定义域及终端集的覆盖范围）。
    6. 工程实现偏差与鲁棒性思考：在实际工程中，放松“即时最优求解”和“模型完全匹配”的假设需要额外分析，例如对计算延迟的处理、次优解的影响、外扰与模型不确定性的鲁棒性设计（例如引入软约束、稳态修正、鲁棒 MPC 变体或延时补偿机制等）。
- 心智模型：将 MPC 的稳定性证明思路一直看作“把最优代价当作能量/广义势能，然后证明这个能量在每一步都会减少”。要做到这一点，关键是“如何保证你在每一步都能比上一步少拿到某个固定的代价值（至少与当前状态的偏离有关）”。从工程设计角度，重点放在（a）让阶段成本对偏离状态有严格惩罚，（b）让终端处理提供一种“可接续的、稳定的”末端策略或约束，从而能够构造出代价下降的不等式。动态规划的单调性则是连接“有限 horizon 优化结构”与“逐步下降”的数学桥梁。
- 实用步骤（可作为设计/证明清单）：
    1. 验证系统模型是否满足 f(0,0)=0 并确保零轨迹可行（若不可行需重新定义稳态目标或加入稳态偏移变量）。
    2. 选择阶段代价 C(s,a)，确保 C(s,a) ≥ α4(||s||)，并且 C(0,0)=0。常用选择 Q>0、R>0 的二次型。
    3. 选择终端处理方案：
        - 若选择零终端约束：检查可行域（是否存在 N 使得从起始集到 0 的可行路径存在），选择 N 足够大以确保可行性。
        - 若选 LQR-based 末端集合：求解线性化的 Riccati 方程得到 P，构造 X_f = { s | s^T P s ≤ δ } 并验证 LQR 在 X_f 内对约束的可行性与收缩性，选择 δ 合适。
    4. 在设计完成后，利用最优性与动态规划算子单调性构造不等式证明：V_N(s^+) ≤ V_N(s) − α3(||s||)（α3 可从阶段代价下界直接选取或通过具体构造获得）。
    5. 根据 α1, α2, α3（K_∞ 或正定函数）判断是局部稳定还是全球稳定（取决于这些函数定义域与终端集合覆盖范围）。
    6. 最后检查实际实现中的计算延迟、模型不确定性，视需要采用次优解容忍分析、鲁棒 MPC 设计或在线修正策略。

# 总结

视频系统地讲解了如何把 MPC 的在线优化问题转换为闭环稳定性证明的问题，并展示了利用 MPC 值函数作为 Lyapunov 函数的典型途径。关键要点是：让阶段成本正定、设计合适的终端约束/代价以保证从短 horizon 到长 horizon 的可行解延拓性，并借助动态规划的单调性推导出值函数沿闭环轨道的下降性，从而满足 Lyapunov 条件并保证闭环渐进稳定性。实际工程中需要注意模型匹配、求解延迟和可行性问题，并可以使用零终端约束或基于 LQR 的终端集作为构造性方法。
