| 维度 | 线性规划（Linear Programming） | 动态规划（Dynamic Programming） |
| --- | --- | --- |
| **核心定义** | 在**线性约束条件**下，优化**线性目标函数**的数值方法（求最大/最小值） | 把**多阶段复杂问题**拆分为**重叠子问题**，通过存储子问题解（备忘录）避免重复计算的优化方法 |
| **数学基础** | 线性等式/不等式约束 + 线性目标函数（变量间无非线性关系） | 最优子结构 + 重叠子问题（核心两大前提），无固定数学形式 |
| **适用场景** | 资源分配（如生产调度、物流配载）、预算规划、混合配料等**静态单阶段问题** | 路径规划（如最短路径）、序列决策（如背包问题）、时间序列优化等**多阶段/动态决策问题** |
| **求解工具** | 单纯形法、内点法（常用软件：Lingo、Excel Solver、Python PuLP） | 递归方程（状态转移方程）+ 备忘录/DP表（手写推导或代码实现） |
| **关键特点** | 变量连续、问题静态、全局最优解唯一（若存在） | 变量可离散/连续、问题动态、分步决策、依赖子问题最优解 |

### 一句话记忆：

- 线性规划是“**静态约束下的线性优化**”，像给固定资源做最优分配；
- 动态规划是“**分阶段拆解决策问题**”，像走多段路每步选最优，还能复用之前的路线经验。

# MPC（模型预测控制）vs RL（强化学习）：核心区别与适用场景

| 维度 | MPC（模型预测控制） | RL（强化学习） |
| --- | --- | --- |
| **核心逻辑** | 基于**精确系统模型**，滚动优化：每步预测未来N步状态，求解当前最优控制输入，仅执行第一步 | **无模型/弱模型依赖**，通过**智能体与环境交互试错**，学习“状态-动作”奖励映射，逼近最优策略 |
| **核心依赖** | 必须有准确的系统数学模型（如线性/非线性状态方程） | 依赖环境反馈（奖励信号）、足够的交互样本量 |
| **优化方式** | 在线实时求解有限时域的优化问题（如二次规划、非线性规划） | **离线/在线训练价值函数/策略网络**，通过迭代更新逼近全局最优 |
| **适用场景** | 工业控制（化工、电机、自动驾驶）、机器人轨迹跟踪等**模型已知、安全性要求高**的场景 | 游戏AI、机器人导航、推荐系统等**模型复杂/未知、允许试错**的动态决策场景 |
| **鲁棒性** | 模型失配时性能下降明显，需结合自适应机制 | 对模型不确定性容忍度高，能通过学习适应环境变化 |
| **计算开销** | 实时求解优化问题，对硬件算力要求较高 | 训练阶段算力消耗大，部署阶段仅需执行策略，开销低 |

### 一句话记忆：

- MPC是“**靠已知模型算最优**”，像拿着地图规划路线，精准但依赖地图准确性；
- RL是“**靠试错学最优**”，像盲人摸路找奖励，灵活但需要足够试错机会。

### 关键补充：

两者可融合使用（如**RL优化MPC的预测模型参数**，或**MPC作为RL的安全约束层**），兼顾精准性与适应性。
