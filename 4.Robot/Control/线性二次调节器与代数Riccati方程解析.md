# 3. 按照主题来梳理

## 3.1 LQR 的问题设定与直观理解

- LQR 的控制设定是典型的线性全状态反馈（full state feedback）问题。系统用线性时不变（LTI）状态空间模型描述：
    - x_dot = A x + B u（状态方程）
    - y = C x + D u（输出方程）
在 LQR 讨论里，通常假设“全状态可观测并反馈”，因此 C 取单位矩阵（identity），D 为零，这样输出 y 就是状态 x 本身，A、B 即系统动力学的关键矩阵。
- “Linear”（线性）在 LQR 名称中指的是系统动力学是线性的；“Quadratic”（二次）指的是代价函数是关于状态和控制输入的二次形式。常见的永久时间（infinite-horizon）代价函数写作：
    - J = ∫ (x^T Q x + u^T R u) dt
这里 Q 是惩罚状态偏差的半正定矩阵（penalty on state deviations），R 是惩罚控制能量或控制努力的正定矩阵（penalty on control effort）。通过调节 Q 与 R 的权重，设计者在“把状态尽快拉到零”和“减少控制输入大小”两者之间权衡。
- 设计目标是找到一个常矩阵增益 K，使得状态反馈 u = -K x 在整个时间范围内使 J 最小化。也就是一个无约束优化问题，但受动态约束（状态方程）。由于问题通过线性动力学和二次代价被严格限定，这一特殊结构允许解析化处理，从而得到比通用优化或学习方法更高效的求解过程。
- 在实际使用中（例如 Matlab 的 lqr 函数），输入是 A、B、Q、R，输出是最优增益 K、闭环特征（如极点）以及一个对偶变量矩阵 P（即 ARE 的解）。这个 P 在推导中起核心作用：K 与 P 之间存在明确代数关系 K = R^{-1} B^T P（或在不同记号下 K = R^{-1} B^T P），P 同时满足一个矩阵代数方程（代数 Riccati 方程），该方程约束了最优代价到状态之间的关系。

## 3.2 三种求解 LQR 的方法对比：暴力穷举、基于学习的梯度法、解析法（Riccati）

- 暴力穷举（Brute Force）
    - 思路：直接在 K 的参数空间（例如二维 K1、K2）上做网格搜索，对每一组 K 通过仿真闭环系统计算 J，并找出使 J 最小的一组 K。视频演示中作者写了一个 Matlab 应用，手动取 K1,K2 在 [0,5] 范围内网格扫描，并画出 J 关于 K1、K2 的成本面（cost surface），得到一个凸形“毯子”状的表面，最低点位置对应 K ≈ [3.4, 2.3]。
    - 优点：概念直观、容易实现、在低维参数空间能直观看到全局成本形状。
    - 缺点：极度低效。参数维度稍高（对复杂系统、更多控制器参数）时计算量呈指数增长，仿真时间和存储都难以承受。因此不实际用于工程规模问题。
- 基于学习的优化（例如基于梯度下降或强化学习）
    - 思路：把 J(K) 看作关于 K 的连续可微函数，从某个初值沿负梯度方向迭代更新 K 来下降成本（或用更复杂的策略，如策略梯度、Q-learning 等）。视频用“把球放到布上让它滚到低点”的比喻来说明梯度下降的轨迹是沿成本表面的下坡路径，不需要计算整个表面，只计算路径上点的梯度。
    - 何时适用：当系统模型未知或不可用、成本函数复杂或不满足解析解的假设时，学习算法很有用；例如非线性动力学、非二次成本、受限信息等场景。
    - 优点：灵活、能处理解析方法不可解的复杂或未知问题；能直接在真实系统或黑盒仿真上迭代学习。
    - 缺点：迭代收敛可能慢、受初值和超参数影响、可能陷入局部最优、收敛到的解不一定稳定，且通常需要大量样本或仿真次数。对于标准 LQR（线性+二次）问题，存在更有效的解析解，不必用学习法。
- 代数 Riccati（解析）方法（效率最高的“正规”作法）
    - 思路概述：利用代价函数与动力学约束，通过引入一个对称矩阵 P（P = P^T）并“完成平方”（completing the square）的技巧，把总体代价 J 重写为两个部分：一部分与控制输入 u 相关、另一部分仅与状态有关。通过合适引入及消去项，可以把关于 u 的那一部分改写为一个完全平方项加上与 P 相关的项。使得当选择 u = -R^{-1} B^T P x 时，那个完全平方项被零化，从而使得控制项对 J 的贡献最小。此时剩下的确保最优的条件是 P 必须满足一个矩阵方程：代数 Riccati 方程（ARE）。
    - 代数 Riccati 方程（形式示例，记号依视频）：
        - A^T P + P A - P B R^{-1} B^T P + Q = 0
这就是要找的 P（对称矩阵），满足后即可得到最优增益 K = R^{-1} B^T P（或写成 K = R^{-1} B^T P 的负号约定视具体推导符号）。
    - 优点：在满足线性系统与二次代价的前提下，此方法是解析且高效的。求解 ARE 的数值方法成熟（比如基于代数特征值分解、Schur 分解、直接迭代法等），并且能在多维情形下稳定地找到唯一产生稳定闭环的“稳定化解”P。
    - 注意事项：虽然 ARE 在分析上是解析表达的，但对高维或边界条件可能需要数值解；方程关于 P 是二次的，理论上可能有多个矩阵解，但只有那个能保证闭环稳定（所谓 stabilizing solution）是工程上关心的解。Matlab 的 lqr 函数内部会数值求解 ARE，在多个候选解中检查对应闭环的稳定性并返回能稳定闭环的增益 K 与对应的 P。

## 3.3 代数 Riccati 方程推导：通过完成平方得到最优反馈律

- 高层思路回顾
    - 我们的目标是从代价函数 J（关于状态轨迹 x(t) 和控制输入 u(t) 的时间积分）出发，直接导出一条闭式的最优控制律 u = -K x，而不是像穷举或迭代那样在 K 空间中搜索。为此，引入一个对称矩阵 P（未定矩阵），把代价重写为包含一项 x(0)^T P x(0) 的形式，然后通过代数变换把关于 u 的部分整理成一个完全平方项，显式求出令该平方项为零的 u，从而得到 K 和 P 满足的方程。
- 具体步骤（按逻辑展开）
    - 原始代价（无限时间）：
        - J = ∫_0^∞ (x^T Q x + u^T R u) dt
    - 引入 P 并加减同一项（不改变 J 的值），即在 J 外加上 x(0)^T P x(0) - x(0)^T P x(0)；将减去的项移入积分，借助微积分的恒等式把它表示为对 x^T P x 的时间导数的积分。利用
        - d/dt (x^T P x) = x_dot^T P x + x^T P x_dot
并用状态方程 x_dot = A x + B u 把导数项展开。
    - 展开后，将全部关于 x 的二次项、关于 u 的二次项以及混合项 x,u 分组。目标是把关于 u 的表达整理成形如 (u + something)^T R (u + something) - something^T R something 的形式（即完成平方），这样原代价中的 u 贡献可以最小化到 -something^T R something，当选择 u = -something 时，那个平方项为零。
    - 在线性-二次的结构下，“something”恰好是 R^{-1} B^T P x 的线性函数，完成平方后，最优控制律导出为：
        - u* = - R^{-1} B^T P x
从而定义 K = R^{-1} B^T P（常数增益矩阵，带负号的反馈律 u = -K x）。
    - 为了使得完成平方后的第一部分（与 x 相关）在积分中不再影响可调的 u 部分，需要令 A^T P + P A + Q - P B R^{-1} B^T P = 0，也就是代数 Riccati 方程。换言之，P 要满足这个矩阵方程，才能保证当控制取 u* 时，J 被最小化。
- 关于 P 的性质与解的选择
    - ARE 是关于对称矩阵 P 的二次矩阵方程。理论上可能存在多个对称解，但并非所有解都会使闭环矩阵 A_cl = A - B K（或 A - B R^{-1} B^T P 的对应形式）稳定。实际控制设计需要选取能稳定化闭环系统的那一个解（stabilizing solution）。
    - 数值求解：尽管方程有解析的代数表示，但求具体的 P 通常借助数值方法（比如基于 Riccati 迭代、解 Hamiltonian 矩阵的稳定子空间等）。Matlab 的 lqr 内部实现会求出 P 的数值解，然后计算 K，并检验得到的闭环是否稳定，从而返回适合的 K（以及 P 和闭环极点等信息）。
- 推导意义与工程直观
    - 完成平方不是简单的代数技巧，而是把最优控制问题转换成“使某个平方项为零”的问题，从而直接给出一个闭式的反馈律。这说明在 LQR 框架下，最优控制具有线性反馈结构，且反馈增益由系统动力学与代价权重的代数耦合（ARE）决定。
    - 这也解释了为什么 LQR 可以被看作是一种状态加权的线性反馈：P 实质上编码了“对于每一维状态的未来代价权重”，K 则是基于这些权重以及控制能量权重 R 所得到的即时控制策略。

# 4. 框架 & 心智模型（Framework & Mindset）

- 抽象的解题框架（适用于标准 LQR 问题）
    - 明确问题结构：确认系统是线性时不变（A,B 已知）且希望最小化的代价是二次形式（Q,Q>=0; R>0）。若任一条件不满足，经典 LQR 的解析解不再直接适用，应考虑数值/学习方法或扩展理论（如有限时域LQR、带约束问题、非线性LQR 等）。
    - 设定与分解：把控制设计问题分为两部分——（1）确定一个对称矩阵 P，使得它同时反映状态的未来代价；（2）基于 P 求出线性反馈增益 K = R^{-1} B^T P。这个分解将原本的动态优化问题简化为求解一个代数方程。
    - 代数化处理：通过代价重排与完成平方技巧将原始变分问题转换为代数方程（ARE），这一步把时间积分优化转化为代数约束问题，显著降低了计算复杂度并使问题可数值化求解。
    - 选择稳定解：注意 ARE 的解可能不唯一。工程上必须选取能够使闭环系统矩阵 A_cl = A - B K 稳定的 P（即闭环极点全部在左半平面）。所以求解 ARE 后应验证闭环稳定性，这是选择正确解的决定步骤。
    - 数值实现与验证：求解 P 时使用成熟的数值方法（例如 Matlab 的 lqr）。求解完成后用仿真或特征值分析验证闭环性能（收敛速度、过冲、控制量峰值等），并调整 Q、R 做权衡。
- 心智模型（decision-making mindset）
    - 面向结构设计：当问题符合 LQR 假设，优先考虑解析方法，因为其高效且能给出全局最优（在所要求条件下）。仅在模型不满足假设或需要更复杂/灵活控制策略时，才转向迭代或学习方法。
    - 权衡与解释：把 Q 与 R 看作设计者对“状态偏差”和“控制能量”的偏好表达；大 Q 会推动更激进的控制以快速抑制状态偏差，而大 R 会限制控制幅度以节约能量或避免过大动作。通过理解 P 与 K 的由来，可以解释为什么调整 Q/R 会改变闭环极点与输入能量。
    - 从局部到全局：LQR 的解析性质意味着找到的解是全局最优（在线性+二次假设下），不像许多非凸优化或复杂学习算法那样可能卡在局部最优。因此在工程上应优先识别是否能把问题转为 LQR 框架以利用全局最优性。
    - 稳健性考量：虽然 LQR 给出最优增益，但在模型不确定性或扰动下的实际表现可能需要额外考虑稳健控制（如 H_infinity、鲁棒控制方法）或在设计阶段通过增加 Q 的某些项来间接考虑容错性。不要把 LQR 当作万能工具，而应把它视为在给定假设下的最优解，并结合仿真/实验验证。
- 实用步骤（工程实施流程）
- 这种框架把复杂的动态优化问题简化为建模、权重选择、求解、验证四个清晰步骤，便于工程实施并保持对结果的解释性。

视频从直观与实践两个角度解释了 LQR 问题：给定线性动力学（A,B）和二次代价（Q,R），目标是找到常数全状态反馈增益 K 使总体代价 J 最小。作者通过对比三种求解思路（暴力穷举、基于学习的迭代、解析的代数 Riccati 方法）强调了 ARE 在效率和可解释性上的重要性。通过“完成平方”的推导，得到最优控制律 u = -R^{-1} B^T P x，并且要求 P 满足代数 Riccati 方程 A^T P + P A - P B R^{-1} B^T P + Q = 0。Matlab 的 lqr 函数实质上数值求解该方程并返回导致稳定闭环的解。视频旨在提供直观理解与工程心智，帮助在遇到控制设计问题时判断何时使用 LQR 及如何实施。
