# 2. Overview

本视频讲座把动态规划（Dynamic Programming，简称DP）作为连接模型预测控制（MPC）与强化学习（Reinforcement Learning，RL）的核心技术来介绍。核心论题是：DP 基于贝尔曼最优性原理，通过递归“代价到达（cost-to-go / value）”函数可以把全局最优的多步决策问题分解为一系列局部（一步）子问题，从而获得最优策略；在离散有限时域可用回溯表格法精确求解，在线性-二次情形（LQR，Linear Quadratic Regulator）可得到解析闭式解并进而推广到无限时域（代数黎卡提方程）；DP 在随机与鲁棒问题上的扩展（期望/最差情形）也很直接，但 DP 的主要限制是“维度诅咒”（状态空间维度大时，需要为所有状态表格化成本函数，计算量与存储量呈指数增长）。讲者通过若干示例（疫情早期防控模型、冬天上坡问题）展示 DP 与 LQR 的行为差异，并讨论了保持单调性与凸性的算子属性及其在实际（MPC/显式MPC/近似DP）中的意义。

# 3. 按照主题来梳理

## 3.1 原理与有限时域动态规划（Principle of Optimality 与有限地平线 DP）

- 贝尔曼最优性原理：视频以 Richard Bellman（理查德·贝尔曼，Bellman）原话开场，核心陈述为“一个最优策略具有这样的性质：不论初始状态与初始决策如何，在随后阶段作出的所有决策必须构成与由初始决策导致的状态相对应的最优策略。”换句话说，最优轨迹的任何子弧（sub-arc）也是从那一子弧起始状态到终点的最优轨迹。这一原则看似显而易见：若剩余决策不是最优的，则原先的整条轨迹不可能是最优的。该原理是动态规划拆解全局优化问题为子问题的逻辑基础。
- 状态作为左右弧的接口：讲者反复强调“状态（state）是左右两段轨迹之间通信的唯一变量”。因此，把未来与过去分割开来处理时，只需把中间状态固定，左侧的最好选择加右侧的最好选择就是整体最优。这个观点明确了 DP 并非只“向后算”或“向前算”，而是一种基于状态接口的通用分解策略。
- 问题表述（有限时域 MPC 风格）：为了更直接地把 MPC 的有限地平线问题放入 DP 框架，讲者先写出典型的有限时域最优控制问题（含阶段费用 C、终端费用 E、动力学 F、路径约束 H、终端约束 R、初始值等）。为简化记号，采用“扩展实数（extended real）”的技巧：将约束通过给不可行点赋 +∞ 来表示，从而把带约束问题转为等价的无约束（但允许 +∞）形式，便于在 DP 中不用特别处理约束。重要提示：扩展值方法与屏障法（interior point）概念上相关，但扩展值的 +∞ 是“严格的”不可行惩罚，不会与有限目标竞争。
- 代价到达（cost-to-go）或值函数（value function）定义：定义 J_k(x)（或 J_k(s)）为在时刻 k、初始状态为 x 时，从 k 到终点采用最优策略所能达到的最小累计费用（最小化问题）。这是一个以状态为参数的参数化优化问题。值函数是 DP 的核心对象。
- 贝尔曼递归（Bellman recursion）：基于最优性原理，刻画 J_k(x) 的一阶递推关系：
    - J_k(x) = min_a [ C_k(x, a) + J_{k+1}( f_k(x,a) ) ]
    - 这里的右侧是阶段费用 + 下一状态的代价到达。若已知 J_{k+1}(·)，可通过对所有可选动作 a 的枚举或求解最小化得到 J_k(·)。这就是向后迭代（backward induction）。
- 实现与复杂度视角：
    - 在离散有限状态/动作空间上，DP 可以通过枚举所有状态并对每个状态枚举所有动作来精确构造 J_k（表格化）。每一步需要遍历所有状态与动作，因此其时间复杂度为 O(|S| * |A| * horizon)，且需要为每个时间步保存 J_k(·)（若保留整个序列）。
    - 对于连续状态/动作空间，需离散化（网格）或采用函数逼近，否则无法逐点表格化。网格的粒度在高维状态空间导致“指数增长”（例如每维 100 点，5 维即 10^10 个状态），这即所谓的“维度诅咒（curse of dimensionality）”。
- Q 函数（action-value function）与最优反馈策略：
    - 定义 Q_k(x, a) = C_k(x,a) + J_{k+1}( f_k(x,a) )，即采取动作 a 后的即时成本加上从下一状态开始的最优后续成本。最优策略在状态 x 的动作是 argmin_a Q_k(x,a)。存储 Q 或直接存储 argmin 的映射就能构造时间依赖的反馈策略 π_k(x)。
    - 在离散情形，π_k 可以用查表实现；在连续情形，若可求解析或参数化（如 LQR 的线性反馈），可直接实现为闭式映射。
- 从 DP 到 MPC 的联系：
    - 单次有限时域 DP 的第一时刻的策略 π_0(x) 正是 MPC 在每个采样时刻在线求解得出的“首个控制动作”的含义。三种获取 MPC 控制律的方式被比较：A）通过 DP 离线表格化（动态规划得到全域 π_0）；B）在线以优化器直接解有限时域优化问题并取第一步控制；C）显式 MPC（explicit MPC）——将优化问题参数化解（在某些线性/二次情形下为分段线性控制律）并离线计算得到对所有可能初值的解析映射。
    - 显式 MPC 与 DP 的联系：显式 MPC 在凸二次情形下产生分段线性（piecewise linear）反馈，这与 DP 在某些情况下的“以线性片段或极大极小表示值函数”有相通之处；但显式 MPC 通常受限于系统/目标的凸线性结构。
- 贝尔曼本人已意识到的限制：虽然 DP “优雅而强大、能求全局最优、可处理非光滑/非凸/随机/鲁棒问题等”，但需要对全状态空间表格化代价函数，因此计算与存储随维度指数增长，这是其致命缺陷。

## 3.2 线性二次调节（LQR：线性-二次问题）与黎卡提递归

- 问题陈述（线性-二次型，LQ）：视频将“线性系统 + 二次成本 + 有限/无限时域”作为 DP 在连续状态空间中能够可解的代表性例子。具体形式：
    - 状态 x_{k+1} = A_k x_k + B_k u_k（线性离散时间动力学，带时间索引以便处理时变情形）
    - 阶段成本 C_k(x,u) = x^T Q_k x + u^T R_k u（或更一般含交叉项与一次项），终端成本为 x_N^T P_N x_N（矩阵 Q_k、R_k、P_N 半正定或正定）
    - 初始值 x_0 给定。目标：使总费用最小化。
- 代价结构与二次型的“投影”性质（Schur complement 主旨）：
    - 在 LQ 问题中，Bellman 递归的核心操作是对 Q 函数（stage cost + 后续代价，其在 (x,u) 上是二次型）对 u 做最小化。一个关于 (x,u) 的二次形式在对 u 最小化后，关于 x 的最小值仍然是一个二次形式（抛物面投影），并且最优 u* 是 x 的线性函数。这是二次型代数的基础性质，也是 LQR 可解析求解的原因。
    - 线性代数陈述：若 Φ(x,u) = 1/2 [x;u]^T M [x;u] + [x;u]^T b + const，且 M 的 u-u 部分（记为 R 或 R̃）正定，则对 u 的最小化可以通过对称矩阵的 Schur complement 给出：最小值函数仍是关于 x 的二次型，其矩阵是 M_{xx} - M_{xu} R^{-1} M_{ux}（这是“消去”u 后得到的矩阵）；对应的最优反馈 u* = - R^{-1} (M_{ux} x + ... )（含线性项时还会有偏置项）。
- 黎卡提递归（Riccati recursion）：
    - 初始化：P_N 给定为终端代价矩阵（正定/半正定）。
    - 递推：对于 k 从 N-1 向 0 递归，P_k = Q_k + A_k^T P_{k+1} A_k - A_k^T P_{k+1} B_k (R_k + B_k^T P_{k+1} B_k)^{-1} B_k^T P_{k+1} A_k。这里的负项来自于对 u 做最小化时消去的部分（Schur complement）。
    - 得到时变反馈增益：K_k = (R_k + B_k^T P_{k+1} B_k)^{-1} B_k^T P_{k+1} A_k，最优控制为 u_k* = - K_k x_k（若含线性项/偏置，会加上相应的常数项）。
    - 前向步：一旦 P_k 与 K_k 都被回溯计算好，便可从 x_0 前向推进：在每一步计算 u_k* = -K_k x_k，x_{k+1} = A_k x_k + B_k u_k*。这回代过程给出最优序列。
- LQR 与线性代数的连接：
    - 讲者强调：从优化问题角度看，LQ 的黎卡提递归就是一种“结构化利用稀疏度的线性方程求解器”。若把整个有限时域问题作为一个大规模的二次型等式约束的凸二次规划（QP）来解，直接用线性代数（KKT）求解也可以得到相同结果；而黎卡提递归等价于对该线性方程组利用带状/时序结构做高效分解（向后矩阵递推 + 向前向量推进）。
    - 拉格朗日乘子解释：乘子 λ_k 可由 P_k x_k 得到（即值函数梯度），这些乘子与 KKT 条件配合共同给出整体最优解的满足性说明。
- 含偏置/非齐次项与“状态扩增”技巧：
    - 实际工程中常遇到非齐次（含线性项）动力学或成本（例如线性化得到的系统带了偏置、跟踪问题、带约束的子问题等）。讲者给出一种记忆/实现的小技巧：把一个常量 1 作为额外的“状态变量”来扩展系统矩阵，把非齐次项编码到扩展矩阵的相应行列，从而把非齐次问题转为齐次矩阵问题——这样黎卡提递归的公式形态保持，但矩阵扩展一阶（维度增加），有助于记忆与编程实现。
- 无穷时域（无限地平线）与代数黎卡提方程（ARE）：
    - 若问题时不变（A,B,Q,R 不随 k 变化），且系统在一定可控/可观区域有良好性质，随着回溯递推 P_k 会收敛到一个稳定的不随时间变化的矩阵 P（P_k → P）。在这种情况下满足固定点方程（离散时间代数黎卡提方程）：
        - P = Q + A^T P A - A^T P B (R + B^T P B)^{-1} B^T P A
    - 解出 P 后，对应的固定增益 K = (R + B^T P B)^{-1} B^T P A 就是无限时域最优线性反馈（LQR），实现上非常简单：u = -K x。这就是 LQR 在工程中广受欢迎的原因——只需存储并计算一次矩阵乘加，在线计算非常廉价。
- LQR 的实际用途与注意事项：
    - LQR 常用于在稳态点附近的线性化控制（例如非线性系统线性化后应用 ILQR、轨迹线性化后做二次近似等）。
    - LQR 输出两个主要对象：P（值函数对应的矩阵，可用于评估或作为 MPC 的终端代价）和 K（反馈增益，直接用于控制实现）。
    - 若存在硬约束或强非线性、阶段成本非二次，LQR 并不是准确解，但常用于局部控制或作为近似初始策略。

## 3.3 两个示例：疫情早期模型与冬季上坡问题（直观行为与策略差异）

- 示例一：疫情早期简单模型（可控传染数 R）
    - 模型构成（极简）：状态 s_t 为感染人数（整数），控制变量为可调的 reproduction number R_t（再生数，R）；下一周感染人数近似 s_{t+1} = floor( R_t * s_t )（向下取整以保留整数并允许“灭绝”情形）。动作 R 的取值区间为 [R_min, R_max]，示例中 R_min=0.5、R_max=4（具体数字为示例设定）。阶段代价包含两部分：对感染人数的极小惩罚（很低的 ε 权重，反映对感染人数的社会成本相对偏小）与对降低 R 的社会经济成本（在 R 接近 R_min 时代价迅速增大，反映强烈封锁/限制的高成本）。无终端代价（E=0）。
    - DP 结果与MPC视角：
        - 当用较长的预测地平线（如 n=100）进行 DP 回溯时，J_0（从初始状态起的代价到达函数）趋于稳定，不再随继续拉长预测窗口显著变化；这说明“预测窗口足够长时得到的代价近似无限时域代价”，这也是 MPC 在实际中经常观察到的性质（窗口只要够长，其 π_0 行为就很接近无限时域策略）。
        - 对应 π_0（MPC 在每步只执行第一步控制的行为）在该示例下表现为：当感染为 0 时放松（最大 R）；一旦出现少量感染（甚至 1、2 人），立即实施严格封锁（将 R 大幅降到某个低水平），这样通过快速干预将感染抑制并最终“根除”。这是因为严格封锁成本在长期内比放任传播导致的指数增长和累积感染成本更优。
    - 短视（短窗口）与长视（长窗口）策略差异：
        - 短窗口（例如 n=2）时的最优策略会更“宽松”——控制器常常允许较高的稳态感染水平，因为短期看来爆发的后果还未完全显现，控制代价（封锁成本）相对高时会避免频繁严控。因此短视策略可稳定系统但在较高感染水平上。长视策略趋向“早关快断”——即使对封锁有高成本，也会在感染初起就迅速采取强力措施以避免长期巨大感染代价。
    - 直觉与现实映射：讲者阐释这与现实中各国策略差异相呼应（一些国家在疫情早期采取严格清零策略，而另一些国家选择较为宽松与长期共存的策略）。示例强调：模型虽然极简（不考虑群体免疫、疫苗、医院饱和等复杂效应），但在早期疫情情境下所得到的“早期迅速封锁是代价更低的策略”这一洞见具有直观性。
- 示例二：冬季汽车上坡问题（非线性动力学下的 LQR vs DP）
    - 问题设置（物理直觉）：车辆在有坡道的路面上行驶，摩擦力随路面倾角和车速等决定且在陡峭冰滑路段摩擦不足时无法保持静止（必会下滑）。目标点处（位置 0）为期望停驻点，但在某些位置（例如在某个负高度 -5 处）若速度为 0，直接向上驱动可能无法克服坡度与摩擦而反复失败。控制输入是驱动力，受限于一上下界（例如 ±1.5），小于需要克服坡度的力。
    - 非线性最优策略与 LQR 的差异：
        - DP 的精确解（通过回溯得到的 J 与 π）在状态平面（位置、速度）上显示出明显的分段行为与不连续边界：在某些区域（陷阱区域）最优策略是先向后倒退（放弃直接向上），利用负向驱动力与重力加速度先获得足够的势能或位置优势，再正向加速上坡；而在其他区域，直接向上行驶是最优。DP 能捕捉这种“倒退换取更高能量以后再上坡”的非平凡策略。
        - LQR（线性二次近似）则给出一条线性反馈（或实用中取限幅后的线性），在深非线性区表现非常差。LQR 不会主动选择“先后退再冲刺”的策略，因为线性化所得到的局部代价/动力结构无法表达“越过某个非线性阈值再能成功上坡”的策略。结果是 LQR 在某些初值下会导致振荡或无法到达目标（比如在临界位置反复尝试上坡而失败）。
    - 可视化与直观结论：
        - 状态-代价图显示在临界位置附近代价陡然上升（即代价函数呈不连续或陡变）：在零速处稍微向后一点就可能从“可直接上坡”转为“必须倒退再冲”的情形，代价因此跃升。
        - DP 给出的闭环轨迹在有问题的初值处会先带车向后运动再前冲，而 LQR 在同一处可能直接尝试向前并陷入振荡或失败。这个示例直观展示了“局部线性策略可能无法处理全局非线性决策边界”的问题。
- 两个示例的教学意义：
    - 疫情模型展示了 DP 或长期视角下的策略逻辑与 MPC 短视与长视的差异，且说明 DP 在离散整数状态下能清晰表格化并解释策略边界。
    - 冬季上坡问题强调在非线性系统中 DP 能发现结构性非直觉策略（如先倒退再冲）而 LQR 作为局部线性近似可能彻底失败，说明在处理强非线性边界或多模态策略时需要全局或更复杂的策略求解手段。
    - 两例共同强调：DP 能处理非光滑、非凸情形，并能给出策略与代价值的直观可视化，但计算规模受限（维度诅咒），实际应用需在精度、计算与近似之间权衡（例如离线表格化、显式 MPC、近似 DP、深度学习逼近等）。

## 3.4 随机性、鲁棒性与算子性质：随机/鲁棒 DP、单调性与凸性保持

- 随机动态规划（Stochastic DP）：
    - 形式扩展：若系统含随机扰动 w（可能影响动力学 f 或成本 C），贝尔曼方程的右侧需要对随机结果取数学期望。即
        - J_k(x) = min_a E_w [ C_k(x,a,w) + J_{k+1}( f_k(x,a,w) ) ]
    - 解释：在做决策时，先选择动作 a，再面临随机扰动的实现。最优决策应最小化对未来随机性的期望代价（若评价指标为期望）。
    - 实践实现：理论上求期望需积分；在实际计算中常用蒙特卡洛采样或样本平均近似来估计期望，从而在 DP 的每一步内加入一个期望估计环（多次实例化下一状态并平均）。这会增加计算成本（循环因子是样本数），但并不会引入像情景树那样的指数爆炸（后者会把每条随机分支扩展为新的时间序列）。
    - 与 MPC 比较：MPC 的情景树方法通常对随机性直接展开所有可能路径，会导致爆炸性增长；而 DP 的期望形式在某些情形反而更直观且可计算。
- 鲁棒动态规划（Robust DP / Minimax DP）：
    - 形式扩展：若假设有一个对手（adversary）选择最坏情况扰动（而非随机），则 Bellman 递归中的期望改为最大化操作（worst-case），即
        - J_k(x) = min_a max_w [ C_k(x,a,w) + J_{k+1}( f_k(x,a,w) ) ]
    - 解释：这等同于一个零和博弈（player chooses a to minimize，adversary chooses w to maximize），并且 DP 构造只需在 Q 函数定义中把求期望替换为求最大值。计算复杂度相对于确定性情形乘以 |W|（如果 w 可枚举）或多出一次最优化循环，但仍然没有出现组合爆炸。
    - 应用语义：鲁棒 DP 适合“必须保证在所有可能扰动下依然安全/稳定”的场景，它对应的策略通常更保守。若不把扰动建模成概率而是把不确定性视为恶意或未知（保守设计时常见），则鲁棒 DP 提供了自然的极小极大框架。
- 动态规划算子 T（Bellman operator）、单调性（Monotonicity）：
    - 定义：将右侧的动作选择与期望/极大运算视为把一个函数 J_{k+1}(·) 映射为 J_k(·) 的操作，这个映射记为 T（一个从函数空间到函数空间的运算符）。Bellman 递归可以写为 J_k = T J_{k+1}。
    - 单调性性质：若对两个函数 J, J' 满足 J(s) ≥ J'(s) 对所有 s 成立，则 T J ≥ T J'（逐点不等式）。证明思路：对固定状态和动作集合，C + J(f(...)) 的点wise 比较保持不等式，再对动作做 min（或 min-max）保持不等式方向。因此 T 是单调算子。单调性可以用于证明递归序列的界或存在性（例如从下界逐步提升到不动点），以及构造稳定性/收敛性证明（MPC 的 Lyapunov 证明确常用该思想）。
    - 单调性在 MPC 中的实际运用：若能设计一个终端成本/终端控制律使得 J_N(x) ≥ T J_N(x)（或满足某种降序条件），则向后迭代产生的值函数序列具有单调递增或递减行为，可用于构造稳定性证明（证明闭环成本随时间递减等）。
- 凸性保持（Convexity preservation）：
    - 结论：在某些结构条件下（动力学在状态与动作上对不确定性是线性的，且阶段成本在状态与动作上是凸的），Bellman 算子会把凸函数映射为凸函数。更具体地，如果 f(x,a,w) 对 (x,a) 是仿射（线性+常数），并且 C(x,a,w) 对 (x,a) 是凸函数，则 T 在保持凸性上成立：若 J_{k+1} 是凸的，T J_{k+1} 也为凸。
    - 证明要点（直观）：对固定 w 与 a，合成 C(x,a)+J_{k+1}(f(x,a)) 是凸（凸函数的仿射变换保持凸性）；再对 a 做最小化（infimum）操作，infimum 操作下对 x 的可得到的下界仍保持凸性（在参数化条件下）。因此整体保持凸性。
    - 工程意义：
        - 若值函数保持凸，则在连续状态空间中我们可以用凸优化工具在对 a 做最小化时更高效地求解（若 Q 函数对 a 是凸的，求最小化可以使用梯度/二阶优化方法）。这使得在连续问题中不必完全网格化状态空间，转而对值函数采用凸函数的参数化或近似（例如凸基函数、最大/最小线性函数展开等）。
        - 在鲁棒情形下若不确定性集合是多面体（polytopic uncertainty）并且系统随不确定性线性变化，由于凸性及极点择优（worst-case 常发生在顶点），可以把鲁棒极大化问题简化为只在多面体顶点枚举 worst-case，使计算变得可行性提高（从而在某些结构化不确定性下，DP 不再需要无穷枚举）。
    - 与显式 MPC 的关系：显式 MPC 在 LQ 与线性约束下得到分段线性最优控制律，这与凸性/多面性理论相连。若值函数为凸且表现为一族线性（仿射）函数的上包（支持函数），则控制律常为分段仿射形式，便于显式存储与在线快速查询。
- 小结性比较：
    - DP 在处理随机性与鲁棒性上形式上非常自然：把期望/最坏操作嵌入 Q 定义即可，保留了 DP 的结构；但计算量会成比例增加（样本数或不确定集顶点数倍）。
    - 单调性与凸性为 DP 提供了数学工具：单调性用于证明收敛与构造稳定性公用证据；凸性使连续空间的求解和近似更可行，并对显式表示与鲁棒顶点简化有直接帮助。
    - 但需要记住的主线：DP 的强大在于其表述的普适性（可处理非光滑、随机、鲁棒问题），其弱点在于规模扩展（状态维数与离散化带来的指数增长），因此实际应用往往需要借助结构（线性、凸、稀疏）、近似（函数逼近、样本化、深度学习）或混合算法（显式预计算 + 在线优化）来折中。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：贝尔曼分治（Bellman Decomposition）——把全局规划分解成阶段性子问题的算子框架（不依赖时间方向）
    - 核心思想：任何多阶段决策问题，其各阶段之间的耦合仅通过“状态”发生；因此可以把“从当前时刻起到终点的最优代价”作为对未来的完整摘要（值函数 / cost-to-go）。贝尔曼原理给出递归关系：当前状态的最优代价等于当前阶段花费与从下一状态开始的最优代价之和的最小化。
    - 操作步骤（算法层面）：
        1. 定义状态空间 S、动作集 A、动力学 f 以及阶段成本 C 和终端成本 E（若有）。
        2. 确定时域（有限时域 N 或无限时域）。若有约束可用扩展实数（+∞）表示不可行，以便统一表述（值函数定义在整个状态域，但不可行点取 +∞）。
        3. 若是有限时域，用回溯法（从 k=N 倒推到 k=0）：J_N(x) := E(x)，对于 k=N-1..0 计算 J_k(x) = min_a [ C_k(x,a) + J_{k+1}( f_k(x,a) ) ]（离散情形通过枚举，连续情形通过求解参数化最小化）。
        4. 若只需在线决策（MPC 风格），在线使用 π_0(x) = argmin_a Q_0(x,a) 并实施第一步，然后滚动时移重解或使用离线得到的 π_0。
        5. 若无限时域且问题时不变，求不动点 J = T J（或用折扣因子γ 使收敛性更易成立），并从 J 得到时间不变策略 π(x)。
    - 心智模型：把“未来成本”视为对未来决策影响的充分统计量（summary statistic）。用 DP 时要在“离线全域表格化可行时优先用 DP”，否则考虑局部/在线/近似方法。记住：DP 是通用的，但代价在于维度。
- 框架二：LQR/黎卡提作为代数化的 DP 框架（线性+二次的高效求解）
    - 核心思想：在系统动力学为线性、成本为二次的情况下，Bellman 运算把二次型映射到二次型，因此可以用矩阵递归（Riccati 递推）来高效得到解析反馈。递推含两步：向后计算 P_k（价值矩阵），向前生成 x_k/u_k（轨迹/控制）。
    - 操作步骤（工程实现）：
        1. 写明 A_k, B_k, Q_k, R_k, P_N。
        2. 向后递推 P_k：P_k = Q_k + A_k^T P_{k+1} A_k - A_k^T P_{k+1} B_k (R_k + B_k^T P_{k+1} B_k)^{-1} B_k^T P_{k+1} A_k。
        3. 计算反馈 K_k = (R_k + B_k^T P_{k+1} B_k)^{-1} B_k^T P_{k+1} A_k。
        4. 前向收敛：x_{k+1} = A_k x_k + B_k u_k*，u_k* = -K_k x_k（或含偏置）。
        5. 在无限时域取定常点 P 并解代数黎卡提方程，得到固定 K，用以在线实现（u = -K x）。
    - 心智模型：把 LQR 看作“在可线性化/局部最优场景中极低成本实现全局近似最优控制”的工具。若目标是在线快速控制实现或嵌入式系统，LQR 是优先选项；若系统强非线性或含多个策略模态，则需慎用或结合更全局方法（DP、MPC 或非线性最优控制）。
- 框架三：随机/鲁棒扩展与算子性质（处理不确定性的策略）
    - 核心思想：把不确定性分别通过“期望（stochastic）”或“最坏（robust/minimax）”纳入 Q 的定义，保持 DP 结构；同时利用 Bellman 算子 T 的数学性质（单调性、在某些条件下的凸性保持）来得到收敛性、稳定性或精确简化（如多面体不确定性的顶点简化）。
    - 操作步骤：
        1. 对于随机扰动，用样本平均或解析期望替代确定性 Q 的定义（Q = E_w[C + J(next)]），并在回溯步骤中计算期望值（可能通过 Monte Carlo）。
        2. 对于鲁棒情形，把期望替换为最大化（Q = max_w [C + J(next)]），对不确定变量进行枚举或优化（若不确定集合是多面体并且函数保持凸性，最坏情形通常在顶点实现）。
        3. 利用单调性证明迭代序列的界和收敛（如从下界 J_0 开始，通过 T 的单调性证明 J_k 上下界渐近）；利用凸性则在连续域上选择更有效的最小化/参数化方法。
    - 心智模型：面对不确定性时，首先问“是概率描述（我接受风险并优化期望）还是对抗性描述（我必须保证极端情形）？”——这决定用期望还是极大化；其次尽量利用结构（线性、凸、多面体）来减少计算负担（例如顶点枚举、凸逼近）。
- 框架四：应对“维度诅咒”的策略与近似心态
    - 核心思想：DP 的根本缺点是全域表格化的代价在高维时不可接受；为此有三类折中策略（视频中提及并讨论）：
        1. MPC（在线优化）——不表格化全域值函数，而是在当前初值附近求解一条最优轨迹并实施首步控制；优点：避免全域枚举，缺点：可能只得局部最优且需在线求解器。
        2. 显式 MPC（explicit MPC）——在可行时离线求解“参数化的优化问题”，得到对所有初值的解析映射（例如分段线性函数）；优点：在线执行快（查表/区域判断），缺点：离线求解可能很昂贵或在高维上不可行，且受限于问题结构（通常线性二次与多面体约束）。
        3. 近似/函数逼近DP（Approximate DP / ADP / Reinforcement Learning）——用函数近似（线性基、径向基、深度神经网络等）逼近值函数或策略，或用样本方法估计期望/梯度；优点：可在高维上有实际可行的方法，缺点：仅近似、需泛化保证与训练数据。
    - 操作建议（心态）：
        - 先识别问题结构：若系统线性且成本二次、维度适中，优先用 LQR 或显式 MPC；若维度高且需保留随机/鲁棒特性，考虑 ADP/RL 或基于结构的分解方法。
        - 在应用近似方法时保留可验证的性能/安全边界（例如用鲁棒化或保守近似保证安全）。
        - 不要把 DP 当作万能解：把它视为“基准”或“理论工具”，在可计算时用以验证或生成训练数据（强化学习中常把 MPC/DPR 策略离线采样用于监督学习）。
- 心智工具汇总（决策树）：
    - 问题特性：线性/非线性？二次/非二次？是否需要处理不确定性（概率/鲁棒）？状态维度大小？
    - 若线性二次且维度适中 → 用 LQR（离线解代数黎卡提方程）。
    - 若线性二次但需要对所有初值快速在线响应且维度不高 → 考虑显式 MPC（分段线性控制律）。
    - 若有强非线性或全局策略边界 → 若维度很小，尽量用 DP；若维度高则用近似 DP / RL 或混合方法。
    - 若有随机性 → 期望 DP（样本平均实现）或情景树（MPC 情形）；若需保证最坏情形 → 鲁棒 DP（min-max）。
    - 辅助工具：利用单调性/凸性/多面体顶点性质来简化或保证结果。
- 综上心态：把 DP 视为“分解-递推 -值函数表格/近似”的普适框架，在结构化情形利用解析/线性代数得到高效解（LQR），在非结构或高维情形采用近似或混合策略，同时利用单调性与凸性来获得理论保证或计算上的简化。

# 总结

视频系统地把动态规划放在 MPC 与 RL 的交叉语境中进行了讲述：从贝尔曼最优性原理出发，介绍了有限时域 DP、Q 函数与策略表格化的实现；在连续与线性-二次情形下，展示了黎卡提递归（Riccati recursion）与 LQR 的解析解法及其向无限时域的收敛（代数黎卡提方程）；通过疫情早期模型与冬季上坡问题直观比较了短视/长视与线性近似/全局最优策略之间的差异；并将随机与鲁棒情形纳入 DP 框架，讨论了 Bellman 算子的单调性与在特定条件下的凸性保持以及这些性质在实现与理论上的用途。核心结论是：DP 在建模复杂性（非光滑、随机、鲁棒）方面非常强大，但受“维度诅咒”限制，实践中常需结合 LQR、MPC、显式方法或近似 DP/深度学习方法共同使用。视频同时给出了若干工程与实现方面的直观建议与记忆技巧（如扩展常数状态处理非齐次项）。
