# 卡尔曼滤波：EKF vs UKF

> 从噪声传感器数据估计真实状态——人形机器人控制栈的基石
> 实验：Unitree G1 / MuJoCo / Phase2 状态估计

---

## 一、卡尔曼滤波 (Kalman Filter)

### 核心思想

你永远不知道真相，但你可以算一个最优猜测。

```
传感器（带噪声）──┐
                  ├─→ 卡尔曼滤波 ──→ 最优状态估计
物理模型（预测）──┘
```

**两步循环：**

| 步骤 | 动作 | 输入 | 输出 |
|:---|:---|:---|:---|
| **Predict** | 用上一时刻状态 + 物理方程，推算"现在该在哪" | 状态 x_{t-1}、控制 u_t、模型 | 预测状态 x̂_{t|t-1}、预测协方差 P_{t|t-1} |
| **Update** | 用传感器实测值，修正预测偏差 | 观测 z_t、预测状态 | 后验状态 x̂_t、后验协方差 P_t |

**卡尔曼增益 K** 是核心：

```
新估计 = 预测 + K × (观测 − 预测)

K = 预测的不确定性 / (预测的不确定性 + 传感器噪声)
```

- 传感器靠谱 → K 大 → 更信观测
- 模型靠谱 → K 小 → 更信预测
- 两者都不靠谱 → 取加权平均，谁方差小谁权重高

### 前提假设

- 系统是**线性的**：`x_t = F·x_{t-1} + B·u_t`
- 噪声是**高斯的**：过程噪声 ~ N(0,Q)，观测噪声 ~ N(0,R)

## 二、EKF（扩展卡尔曼滤波）

### 怎么处理非线性

现实系统中大多数动力学方程是**非线性的**，比如：
- 四元数旋转
- 三角函数（sin/cos）
- 摩擦锥约束

EKF 的做法：在当前估计点对非线性函数做**一阶泰勒展开**，用雅可比矩阵 F 近似替代非线性函数。

```
f(x) ≈ f(x̂) + J_f(x̂) · (x − x̂)
```

本质上就是**局部线性化**——在当前位置把曲线当成直线处理。

### 优点
- 计算快，每步只需一次雅可比计算
- 对轻度非线性足够用
- 实现简单，工业界最广泛

### 缺点
- **强非线性时偏差大**。泰勒展开丢掉了二阶及以上所有信息
- 雅可比需要手动推导或数值近似
- 收敛性不保证（线性化误差可能发散）

## 三、UKF（无迹卡尔曼滤波）

### 怎么处理非线性

**不线性近似函数，而是采样点逼近分布。**

取一组精心构造的 **sigma points**（2n+1 个，n=状态维度）：

```
1. 取中心点 x̂ 和 ±√P 方向的偏移点
2. 把这些点原封不动地送进非线性函数 f()
3. 看变换后点的分布，重新计算均值和协方差
```

相当于用**无迹变换（Unscented Transform）**代替泰勒展开。

### 优点
- **非线性能力远超 EKF**。至少精确到三阶（EKF 仅一阶）
- 无需计算雅可比矩阵
- 姿态估计（四元数）、强非线性动力学场景表现优异

### 缺点
- 每步需 2n+1 次函数评估，计算量是 EKF 的约 2n 倍
- sigma 点参数（α、β、κ）需要调优
- 对严重非高斯噪声仍力不从心（此时需要用粒子滤波）

## 四、G1 Phase2 实测对比

**场景**：G1 在 MuJoCo 中做 10s 随机运动，IMU 加噪声（±0.01 rad/s 陀螺仪漂移、±0.1 m/s² 加速度计噪声），关节编码器 ±0.1°。2000 步仿真，EKF 和 UKF 各自估计基座位姿。

| 估计项 | EKF RMSE | UKF RMSE | 优胜 |
|:---|:---:|:---:|:---:|
| **位置** | **0.025m** | 0.027m | EKF ✅ |
| **姿态角度** | 0.109 rad (6.2°) | **0.038 rad (2.2°)** | **UKF ✅** |
| **线速度** | **0.033 m/s** | 0.142 m/s | EKF ✅ |
| **角速度** | 0.018 rad/s | **0.012 rad/s** | UKF ✅ |
| **加速度计偏置** | 0.018 m/s² | **0.013 m/s²** | UKF ✅ |
| **陀螺仪偏置** | 0.016 rad/s | **0.008 rad/s** | UKF ✅ |

### 模式清晰：

| 量类型 | 谁更优 | 原因 |
|:---|:---|:---|
| **线性量**（位置、速度） | EKF | 系统在这些维度上接近线性，一阶足够 |
| **非线性量**（姿态、IMU bias） | **UKF** | 四元数旋转的强非线性，UKF 的 sigma 点能精确传播 |

## 五、选型指南

```
系统是否接近线性？
 ├─ 是 → EKF（快、简单）
 └─ 否 → 非线性有多强？
          ├─ 轻度 → EKF 够用
          ├─ 中度 → UKF（姿态估计、惯导）
          └─ 严重 + 非高斯 → 粒子滤波
```

### 本项目的策略：融合

| 维度 | 用谁 | 理由 |
|:---|:---|:---|
| 基座位置/速度 | EKF | 位置微分是线性的，EKF 更快更准 |
| 基座姿态 | UKF | 四元数传播是强非线性的，UKF 误差仅 1/3 |
| IMU 偏置 | UKF | 作为 UKF 状态的副产品，自动估计 |

**Phase3 开始**，PID 关节控制需要的基座状态从这里取：位置/速度用 EKF，姿态用 UKF。

## 六、相关公式

**标准卡尔曼：**
```
Predict:
  x̂_k|k-1 = F·x̂_k-1
  P_k|k-1 = F·P_k-1·F^T + Q
Update:
  K = P_k|k-1·H^T·(H·P_k|k-1·H^T + R)^{-1}
  x̂_k = x̂_k|k-1 + K·(z_k − H·x̂_k|k-1)
  P_k = (I − K·H)·P_k|k-1
```

**EKF 差异：** 用雅可比 F = ∂f/∂x 代替线性 F。

**UKF 差异：** 取 2n+1 个 σ 点，计算 f(σ_i)，加权求和得新均值和协方差。
