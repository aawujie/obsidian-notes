## 3.1 函数逼近（Function Approximation）在强化学习中的概念与挑战

- 强化学习早期很多方法基于表格（table-based）表示：对于状态 V(s) 或状态-动作 Q(s,a) 直接用向量或表格记录每个条目。这种方式在状态/动作空间足够小的时候可行，但当问题规模变大时会遇到两个主要瓶颈：内存/存储不足（无法为每个状态或每个状态-动作对保留一项），以及表格表示“泛化能力差”（table-based representation 没有把相近状态的值联系起来——一个格子的数值不会自动告诉你相邻格子的值应该如何变化）。
- 目标：用“光滑的函数表示”去逼近值函数，使得在状态/动作空间中相近的点具有相近的估计值（generalization）。这通常通过选择状态特征（state features）并用函数逼近器（function approximator）去拟合 Vπ 或 Qπ 来实现。记号上，逼近后的值通常写成 V̂(s; w) 或 Q̂(s,a; w)，其中 w 是参数向量（weights）。
- 常见的函数逼近器形式：线性组合（linear combination of features）、神经网络（neural networks）、决策树（decision trees）、高斯过程回归（Gaussian process regression，概率回归模型）、最近邻（nearest neighbor）或核方法（kernel methods）。每种模型有其优缺点：例如决策树非连续不适合基于梯度的方法，高斯过程有良好不确定性估计但计算复杂度高，神经网络能自动学习特征但需要大量数据并且在 RL 环境下可能出现不稳定性。
- 强化学习中的额外挑战（与监督学习不同）：
    - 非独立同分布（non-iid）：在监督学习中常假设样本是 iid，但 RL 的样本通常按时间序列依赖，分布随训练过程改变（非平稳）。
    - 目标的非平稳性（targets shift）：当我们在训练过程中更新参数 w 时，目标（例如 TD 目标、bootstrap 目标）通常也随之改变，导致训练一个自适应系统去拟合随参数改变的目标，增加不稳定性。
    - 引入自举（bootstrapping）：从一个估计去更新另一个估计（例如 TD(0) 用 V̂(s') 来更新 V̂(s)）——如果初始估计不佳，这种自引用更新可能扩散错误并导致发散或不稳定。
- 训练方式：若使用可微分（differentiable）的函数逼近器（如线性模型或神经网络），通常以梯度下降（gradient descent）或随机梯度下降（stochastic gradient descent, SGD）更新参数。以最小二乘误差（mean squared value error）为损失函数时，理想的梯度更新是：
w_{t+1} = w_t − α ∇_w Loss = w_t + α (target − V̂(s; w_t)) ∇_w V̂(s; w_t)
其中“target”可以是 Monte Carlo 返回（unbiased 样本）、TD 目标、或 Q-learning 的目标等。
- 小结：函数逼近给 RL 带来必要的泛化能力，但也同时带来“非平稳性 + 自举 + 数据相关性”等根本性问题，需要在方法和实现上额外注意以增强稳定性和收敛性。

## 3.2 线性方法：特征设计、半梯度、LSTD 与可收敛性分析

- 线性函数逼近的形式：首先用特征向量 x(s) = [x1(s), x2(s), ..., xd(s)]ᵀ 表示状态（这些特征可以是状态维度的非线性组合或通过领域知识构造的 basis functions）。然后用线性参数化的值函数表示：
V̂(s; w) = wᵀ x(s)
因为 V̂ 对 w 的梯度 ∇_w V̂(s; w) = x(s)（梯度正好是特征向量），这极大简化了理论分析与算法推导。
- 梯度下降/随机梯度下降（SGD）与目标替换：
    - 理想情况下，如果能计算到真实的 Vπ(s)（policy evaluation 的真实期望），目标误差平方和为 J(w) = E[(Vπ(s) − V̂(s; w))²]，梯度为 −2 E[(Vπ(s) − V̂(s; w)) ∇_w V̂(s; w)]。但我们通常无法计算 Vπ(s) 的精确值。
    - Monte Carlo：可以用一次完整回合的累积回报 G_t 作为 Vπ(s_t) 的无偏样本，从而用 SGD 更新（这就是基于 Monte Carlo 的更新）。
    - Temporal Difference (TD)：用 TD 目标 r + γ V̂(s'; w) 作为目标，但注意该目标本身依赖 w（自举），在实际中常把依赖目标项的梯度忽略（semi-gradient）——即把目标视作常量，仅对 V̂(s; w) 取梯度，这就是所谓“半梯度方法（semi-gradient methods）”。这并非严格的梯度下降，因此存在理论局限，但在很多情形下能更稳定且计算方便。
- 线性表示的优点与可证收敛性：
    - 在线性、on-policy 且使用半梯度 TD(0) 条件下，有一系列稳定性的理论结果，证明在一定条件下可以收敛到一个固定点（fixed point）。同样，Monte Carlo 预测在使用线性逼近时也存在稳定的收敛性证明。
    - 这些证明依赖线性结构使问题可解析化（矩阵表示、线性代数工具可用）。
- 最小二乘时序差分（Least Squares Temporal Difference, LSTD）：
    - LSTD 试图直接求解上面梯度下降固定点对应的解析解，考虑线性情形下固定点满足 A w = b，其中 A 和 b 是对期望值的矩阵/向量定义（来自特征与 TD 误差的期望）。
    - 实际上 LSTD 用样本估计 A 和 b 的经验和（sum over samples），然后解线性方程 w = A^{-1} b。这样做数据效率高（少量数据即可得到较好解），但需要矩阵逆运算（A 的逆），导致计算复杂度在特征维度 d 上通常为 O(d^3)（直接逆），可用 Sherman-Morrison 等公式把复杂度降低到 O(d^2) 的增量更新形式。
    - LSTD 的伪代码大体：遍历数据集，累积 A 和 b 的经验估计（加上一个小的正则化 ε I 以保证可逆），计算 A^{-1}（或用增量更新维护 A^{-1}），最后求得 w = A^{-1} b。
- 特征选择（feature design）极其关键：
    - 你可以自由选择特征维度 d，从而在一定程度上控制问题的复杂度（减小 d 可降低计算量与样本需求，但会使逼近更粗糙）。特征通常需要靠领域知识设计，常见策略包括：基函数（radial basis functions, 圆形/椭圆形等）、分区/tilings（重叠网格以实现局部泛化）、条带/stripe（对状态空间某方向精细化）等。
    - 特征组合可以是非线性的（例如对状态的非线性投影），但线性方法的最终值函数是线性于参数 w 的。选择不匹配问题的特征会导致表现差；神经网络（neural networks）成功的一个重要原因是它能自动学习适合任务的特征表示。
- 线性方法的一个重要局限：当进入 off-policy 或使用非线性近似时，稳定性证明通常不再适用，容易出现发散例子（后面将讨论 deadly triad）。因此线性方法适用于希望有理论保证和可解析结论的场景，但在大型高维问题上可能不够表达能力。

## 3.3 神经网络（Neural Networks）简介：前向、反向传播与在 RL 中的优化注意点

- 网络结构与前向传播（forward pass）：
    - 一个典型的多层感知器（multi-layer perceptron, MLP）由输入层（state 或 state features）、若干隐藏层（hidden layers）和输出层组成。每一层的一个节点（neuron）将前一层的输入按权重加权求和（z = W x + b），再通过激活函数 h(z) 变换得到输出（activation），该输出成为下一层的输入。整个网络可看作嵌套的复合函数。
    - 在 RL 的值函数逼近中，输入可以是原始状态（例如像素），或特征化后的状态；输出在 Q 函数场景下可以有两种模式：输入 (s,a) 输出标量 Q̂(s,a)，或输入 s 输出对所有动作的 Q̂(s,·)（后者在离散动作空间、使用一次前向传播获得多个动作值时更高效，但各输出需要更多参数）。
- 反向传播（backpropagation）与梯度计算：
    - 为了训练网络，需要对损失函数（例如均方误差）关于权重矩阵求偏导数。由于网络是多层嵌套函数，求导应用链式法则（chain rule），反向传播就是按层从输出到输入逐步计算局部梯度并传播，重复利用中间导数以节省计算。
    - 反向传播的步骤：先做前向传播计算所有中间激活值；计算输出层损失的局部导数；从输出层开始向前逐层计算每层的梯度（利用上一层计算结果）；累积梯度后用梯度下降或其变体（Adam、RMSprop 等）更新权重。
    - 激活函数选择：输出层回归通常用线性激活；分类常用 sigmoid 或 tanh；中间层常见 ReLU、tanh、sigmoid 等（不同激活在梯度流、饱和与稀疏性上表现不同）。
- 在 RL 中训练神经网络的特殊注意：
    - 非平稳目标与自举问题：当用 TD 目标（如 r + γ max_a' Q̂(s',a'; w)）更新网络时，目标依赖当前或近期的参数 w，这会导致训练目标随时间变化，从而使得传统的监督式网络训练假设被破坏。
    - 数据相关性（correlations）：直接按照时间顺序进行训练会使批次样本高度相关，影响优化路径与收敛速度。实践上常用经验回放（experience replay）打乱样本顺序并重用样本，减少相关性并提高数据效率。
    - 梯度信号放大或抖动：自举和网络更新一起可能导致循环影响（更新导致目标变，目标变又导致进一步更新），容易振荡或发散。引入目标网络（fixed target network）可以减缓这一影响，通过在计算目标时使用一个较慢更新或周期性复制的权重集合来稳定目标。
- 工具与实现：现代深度学习库（如 PyTorch）会自动处理前向与反向传播的细节（自动微分），所以实践中不需要手工推导复杂梯度，但理解基本机制仍然重要以便调参与诊断训练问题。
- 总结：神经网络为 RL 提供强大的非线性拟合能力与自动特征学习能力，但在 RL 的设定下需要处理诸如目标非平稳、数据相关性与发散风险等问题。合理使用经验回放、目标网络以及小心的超参调节等工程技巧，能在实践中显著提高稳定性。

## 3.4 记忆型 / 核方法（Memory-based / Kernel Methods）

- 方法概述：记忆型函数逼近（memory-based function approximation）把经验（states, actions, returns）全部或部分保存在记忆（dataset / replay buffer）中，用非参数方法来估计新状态的值。例如最近邻（nearest neighbor）或核回归（kernel regression / radial basis functions）：
    - 最近邻：对一个新状态 s，找到训练集中最近的若干样本 s'，用它们的目标值的加权平均来估计 V̂(s)。加权通常基于距离（距离越近权重越大）。
    - 核方法（kernel）：定义核函数 K(s, s')（常见的 Gaussian kernel / radial basis function），以 K(s, s') 作为相似度权重，然后把已知样本的值按这些权重线性组合来给出估计。形式上 V̂(s) ≈ sum_i K(s, s_i) y_i / sum_i K(s, s_i)。
- 优点：记忆方法直观、在低维情况下表现良好、不需要提前设计固定基函数，能自然保留样本的不确定性信息（尤其是高斯过程等概率模型）。
- 缺点与局限性：
    - 可扩展性差：当样本数 N 很大时，核方法或最近邻需要对每个新查询计算与所有历史样本的距离或核值，计算量为 O(N · d)（d 是状态维度）或更高，这在大规模 RL 场景难以承受。
    - 维度灾难：在高维状态空间中，距离度量失去区分力（curse of dimensionality），最近邻与核权重往往接近均匀，导致泛化能力下降。
    - 与 bootstrap 的结合复杂：记忆方法在与 TD 自举结合时也面临目标依赖性（targets 仍然会变化），需谨慎设计更新方法或采用批量回归策略来避免循环误差放大。
- 在 RL 文献中的位置：记忆/核方法有时用于小规模/中等规模问题或作为基线与理论工具，在现代大规模深度 RL 中，因扩展性与高维问题的限制，直接使用的场景较少。但核方法与 Gaussian process 在特定需要不确定性估计或样本效率要求高的场景（小样本强化学习）仍有价值。

## 3.5 On-policy 控制：用函数逼近做策略改进（以 SARSA 为例）

- 问题设定：预测（policy evaluation）只是估计固定策略的值函数；策略控制（policy control）则要求在评估的同时改进策略，目标是找到最优策略 π*。在带有函数逼近的无模型情形下，通常学习 Q 函数并据此导出贪心策略。
- On-policy 与 off-policy 的区别：on-policy 学习要求收集数据（行为）时所用的策略（behavior policy）就是当前要评估/改进的策略（target policy）。简单说，策略既生成数据又被评估。常见手段是在策略中引入探索（例如 ε-greedy），既能保持 on-policy 的自洽，也能实现探索。
- SARSA 算法（状态-动作-奖励-状态-动作 的缩写）：
    - 更新风格：以 TD 风格进行参数更新，用当前策略选取的下一个动作 a' 构造 TD 目标（而非使用 max_a'）。SARSA 的更新形式（函数逼近下）通常写成：
w ← w + α [ r + γ Q̂(s', a'; w) − Q̂(s, a; w) ] ∇_w Q̂(s, a; w)
这里再次包含半梯度（忽略目标对 w 的显式导数）。
    - 关键点：因为用的是策略当前（带探索）选取的 a' 来构造目标，SARSA 是 on-policy，从而理论上更容易满足某些稳定性条件（尤其配合线性逼近时）。
    - 探索策略：常用 ε-greedy——以概率 1 − ε 选择贪心动作，以 ε 随机探索其他动作；即使目标策略要求贪心，行为策略仍需保留一定的探索，使状态-动作对充分采样以便估计收敛。
- 示例（Mountain Car / Winter Hill）：在视频中用 mountain car 问题演示 SARSA（或基于函数逼近的 on-policy 学习）如何随时间发现“先退后进”的解法（agent 先向反方向加速以累积能量再冲上坡）。展示了不同步长（step size）对收敛速度的影响：步长是调优的关键。
- 小结：on-policy 控制（如 SARSA）在概念上直观且与当前策略一致，但仍面临函数逼近带来的非平稳与自举问题；在实践中需合适选择步长、特征或神经网络结构，并确保足够探索。

## 3.6 Off-policy 学习、重要性采样、致命三联（deadly triad）与 Deep Q-Network (DQN)

- Off-policy 学习定义：行为策略（behavior policy B）生成数据，但我们学习/改进的目标策略（target policy π）不同。优势：可从多种数据源学习（甚至离线数据），能同时学习多个目标策略，但需要统计修正使得以 B 生成的数据能为 π 的期望提供无偏估计。
- 重要性采样（importance sampling）用于在估计期望时从一种分布（行为策略）改写为另一种分布（目标策略）。对于轨迹级 Monte Carlo 返回，重要权为：
ρ_{t:T} = ∏_{k=t}^{T} π(a_k | s_k) / B(a_k | s_k)
用于权重化行为返回以近似目标策略下的期望。权值可以为 0（若目标在某步永不采取行为策略所采取的动作），也可以非常大（若分母接近 0 而分子不为 0），因此重要性采样会产生高方差的问题。
- 致命三联（deadly triad）：在 RL 中，若同时存在（1）函数逼近、（2）自举（bootstrapping，使用估计的值作为目标），以及（3）off-policy 学习，这三个要素的组合常导致不稳定或发散。视频中提到的 Barrett 的反例展示了一个无奖励的 MDP，在 off-policy 学习与特定逼近构造下，即使理论上的真实值为 0，实际迭代可能爆炸性发散（不是通过减小步长即可修复）。
- 为什么会发生问题：关键在于目标与估计的循环依赖，off-policy 的重要性权重可以放大某些更新，而函数逼近（特别是非线性逼近）会把局部更新传播到全局参数，从而放大误差并在后续更新中进一步恶化。
- NFQ（Neural Fitted Q-iteration）：早期用神经网络做 Q 函数逼近的非在线（batch）方法。大致过程：
    - 采集数据（用某个策略，如 ε-greedy）并存入记忆 D。
    - 将数据转为监督学习目标：y = r   或  y = r + γ max_{a'} Q̂(s', a'; w_prev)（若 s' 非终止）。
    - 以 batch 方式用神经网络拟合 (s,a) → y，重复若干迭代，每次使用上一次迭代的参数来计算目标。这是一个批量、拟合型的 Q-迭代思想，数据效率高但计算开销也较大。
- DQN（Deep Q-Network）及若干关键技巧（使 off-policy + 非线性逼近 在实践中较为稳定）：
    - 经验回放（experience replay）：把交互数据存入重放缓冲区 D，从中随机采样小批量 (mini-batch) 来训练，减少时间相关性并提高数据重用率。这样批量训练更接近 iid 假设，有助于优化稳定性。
    - 目标网络（target network）：引入一个参数副本 Q̂(s,a; w^−)（或 w̄），用于计算 TD 目标 y = r + γ max_{a'} Q̂(s',a'; w^−)，而主网络 Q̂(s,a; w) 去拟合这个目标。目标网络参数对主网络固定若干步或用慢速更新（soft update：w^− ← τ w + (1−τ) w^−）来更新，减少目标的快速非平稳变化，从而缓解震荡。
    - 小奖励裁剪（reward clipping）与归一化：把奖励裁剪或缩放到更小范围以避免梯度爆炸或极端更新（这属于工程化的稳定化）。
    - 小批量随机梯度：用 mini-batch 更新（而非一次性用全部数据），结合经验回放提高收敛性与数据效率。
- 实践效果：通过上述技巧，DQN 能在高维输入（例如 Atari 游戏像素）上直接学习 Q 函数并得到与或超越人类表现的策略。关键在于经验回放与目标网络的组合有效缓和了深度网络在 RL 环境下的非平稳问题。
- 局限与谨慎：
    - 虽然 DQN 在很多任务上成功，但理论上的收敛证明并不完备；致命三联仍是理论上的危险信号。工程实践中常需大量调参（学习率、batch size、缓冲区大小、目标网络更新频率等）。
    - Off-policy 的重要性采样在某些场景仍不可避免，但其高方差本质需要额外方法（截断、加权、稳定化技巧）来控制。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：函数逼近下的 RL 设计流程（Function Approximation Workflow）
以上流程既是问题建模的步骤，也是工程实现时应遵循的心智模型：先从目标和数据入手，优先采用有理论保证或低样本需求的方案，再逐渐加复杂模型并配以稳定化手段。
- 框架二：面对“非平稳 + 自举 + off-policy”三联危险时的稳定化心智模型（Stability Toolkit）
这一心智模型提供了一组“可操作”工具和优先级：先用简单、可证的方案；若需要更强表达能力，再引入深度模型并同时启用经验回放、目标网络与其他稳定化措施；持续监控并调节超参。

# 总结

视频系统地讲述了在强化学习中引入函数逼近的必要性、可选技术与带来的新问题。线性方法提供可分析、稳定的基线（例如使用特征向量的线性逼近、LSTD），但在高维与复杂任务中难以胜任。神经网络提供强大的非线性表达能力与自动特征学习，但在 RL 环境中面临目标非平稳、自举与数据相关性导致的稳定性挑战。为了解决这些实践问题，工程化技巧（经验回放、目标网络、奖励裁剪、mini-batch SGD 等）以及理论上更复杂的算法（gradient TD 系列）被提出并广泛使用。视频同时提醒在 off-policy 情形下需用重要性采样进行统计修正，但这又引入高方差与潜在发散风险（deadly triad）。总体心智建议是：以问题与数据为中心选择逼近器；在使用强表达能力的模型时，配合稳定化手段和谨慎的超参调优；在可行的场景优先使用带理论保证的线性/批量方法做基线，再逐步过渡到深度方法并严密监控训练过程。
