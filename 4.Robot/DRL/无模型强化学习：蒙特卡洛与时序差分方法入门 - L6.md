# 2. Overview

本视频核心论题是介绍两类“无模型”（model-free）强化学习方法：蒙特卡洛（Monte Carlo，MC）方法和时序差分（Temporal Difference，TD）方法，并基于它们讨论如何做策略评估（prediction）与策略改进/控制（control）。结论要点包括：MC 通过对整条轨迹的样本回报做经验平均来估值，但需等到回合结束；TD 结合了采样与动态规划的“自举”（bootstrapping），可在每一步更新估计，方差更低但有偏；在控制上，基于 Q 值的算法（如 SARSA、Q-learning）分别对应 on-policy 与 off-policy 学习，Q-learning 能实现离策略学习并逼近 Q*（最优动作值函数）。

# 3. 按照主题来梳理

## 3.1 蒙特卡洛方法：从经验回报估计价值（Prediction）

- 蒙特卡洛（Monte Carlo，MC）方法的核心思想是“直接从经验中学习”：通过在环境中执行给定策略 π，收集状态-动作-奖励的完整轨迹（state, action, reward, ...），并用这些轨迹的终局回报（return G）来估计状态值 Vπ 或动作值 Qπ。与动态规划不同，MC 不需要已知的转移概率模型 P(s', r | s, a)，属于无模型方法。
- 关键约束与限制：MC 通常要求在每一条序列（episode）结束后才能计算完整回报 G（尤其在情景为分集（episodic），存在明确终止点时）。因此它无法在未结束的回合中做更新（不存在 bootstrapping）。这导致 MC 的更新对象是完整回报的经验均值（empirical mean），从样本上直接估计期望回报。
- 实现细节（增量更新与访问计数）：可以有两种实现方式——先把所有轨迹存储起来再批量平均，或用增量形式维护运行均值。增量公式常写为 μ_k = μ_{k-1} + (1/k) * (G_k - μ_{k-1})，其中 k 是对某个状态（或状态-动作对）的访问次数。常用更通用的步长 α（0<α≤1）替代 1/k：V ← V + α (G - V)，这个形式便于在线更新并与收敛性分析衔接；为保证收敛，α 随时间通常需要满足一定的衰减条件（例如 ∑α_t = ∞, ∑α_t^2 < ∞）。
- First-visit 与 Every-visit：两种常见策略评估变体。first-visit MC 只使用轨迹中首次出现某状态（或状态-动作对）之后的回报；every-visit MC 则把轨迹中每一次出现该状态的后续回报都计入平均。理论上两者会有不同的方差与收敛特性，但无普适的“始终更好”选择。
- 伪代码与流程（预测场景）：初始化 V（或 Q）任意值；对每个回合按 π 采样产生轨迹；计算轨迹各时间步的回报 G（通常从轨迹末端反向累加折扣）；对于轨迹中每个（首次/每次）出现的状态，用当前 G 更新该状态的返回集合或使用增量公式更新 V。这套流程是 MC 预测的标准实现。

## 3.2 蒙特卡洛控制：用 Q 值与 ε-贪婪来改进策略（On-policy）

- 蒙特卡洛不仅能评估策略，也能用于控制（即改进策略）。通过估计动作值 Qπ(s,a)，我们可以基于 Q 的最大化来改进策略。然而直接贪婪（always greedy）会带来问题：基于当前的经验数据，某些状态或动作可能从未被访问，若只按当前估计贪婪选择就可能永远不探索这些未见区域，无法保证收敛到最优解。于是必须在策略中保留足够的探索。
- ε-贪婪（ε-greedy）策略：常见的解决办法是在策略中引入随机性：以概率 1-ε 选择当前估计的贪婪动作（argmax_a Q(s,a)），以概率 ε 随机选择任意动作（或均匀分配于其余动作）。这保证每个状态-动作对被无限次访问（理论条件），从而对 Q 值进行充分采样并支持收敛证明。在实践中 ε 可固定或随时间衰减（annealing），两者各有利弊（固定 ε 简单，衰减 ε 有助于后期利用）。
- On-policy first-visit MC control 的流程：初始化 Q 任意值，初始化策略为 ε-贪婪（相对于 Q）；对每个回合按当前策略采样完整轨迹；对轨迹中每个第一次出现的 (s,a) 对，计算该步之后的回报 G 并将其加入该 (s,a) 的返回集合（或用增量公式更新 Q(s,a)）；然后用当前 Q 更新策略（对状态 s，将概率质量分配给 argmax 动作和非贪婪动作按 ε-策略）。重复直到收敛。
- 收敛性与实务注意：在满足每个状态-动作对被无限次访问、步长衰减条件等技术性假设下，on-policy MC 控制能收敛到最优策略的近似。但在有限样本实践中，回报方差高（因为使用整条轨迹回报）会导致学习不稳定，且必须存储整条轨迹并等待回合结束，限制了在线、持续任务应用。

## 3.3 时序差分学习（TD）：自举与逐步更新（Prediction）

- 时序差分（Temporal Difference，TD）方法结合了采样（MC）与动态规划（DP）的思想：既不依赖模型（像 MC），又利用了 DP 的自举（bootstrapping，即用现有估计去构造新的目标）。TD 的核心是用一步的经验奖励 r_{t+1} 加上折扣后的下一状态价值 γ V(s_{t+1}) 作为当前状态的目标（TD target），公式为目标 y_t = r_{t+1} + γ V(s_{t+1})，并以步长 α 更新：V(s_t) ← V(s_t) + α (y_t - V(s_t))。这里 y_t - V(s_t) 被称为 TD 误差（TD error）。
- 优点（可早更新、方差低）：由于目标包含的是下一状态的估计值，TD 不必等待整条回合完成就能更新估计，适用于持续任务、无限时域或希望在线学习的场景。相比 MC 使用整条轨迹回报的高方差，TD 的单步目标方差通常更低，因此学习曲线更稳定。
- 偏差与方差的权衡：TD 的目标带有偏差（因为它依赖于当前的不精确估计 V(s_{t+1})），但方差更小；MC 的目标无偏（直接用真实回报），但方差高。随着更新次数增加，TD 的偏差会被新的数据逐步修正；在实践中，TD 经常更快收敛于可用数据下的良好近似。
- 算法实现（TD(0)预测）：给定需要评估的策略 π，初始化 V 任意值，设定步长 α。每个时间步按 π 选择动作并观察 r_{t+1}, s_{t+1}，然后立即执行 TD 更新 V(s_t) ← V(s_t) + α [r_{t+1} + γ V(s_{t+1}) - V(s_t)]。把 s ← s_{t+1} 并继续直到终止（若存在终止）。
- 与 MC 的数学联系：可以把 MC 的全回报误差（G_t - V(s_t)）分解为一系列折扣后的 TD 误差之和（telescoping sum），该数学等价有助于理解两者之间的关系与差别。

## 3.4 TD vs MC 的比较：偏差-方差与样本效率

- 更新时机：MC 必须等回合结束后才能用 G 更新相应状态价值，适合明确分集任务；TD 能在每一步基于下一状态的估计更新价值，适合持续任务与在线学习。
- 偏差与方差：MC 使用真实的整条回报，估计无偏但方差高（回报受多步随机转移与奖励影响较大）；TD 使用带偏差的自举目标，方差通常较小。换言之，TD 在样本有限时往往更稳定（但可能引入偏差），MC 在回合数足够大且愿意承受高方差时能提供无偏估计。
- 数据利用与模型等价：TD 隐式利用了马尔可夫性（Markov）结构，通过学习不同时间点的估计来间接估计转移结构；在批量（batch）设置下，MC 最终会收敛到对观察到的回报的最小均方误差解，而 TD 在批量回放下等价于最大似然估计下的某种解，二者对有限数据的目标不同。
- 示例说明（驾车预测）：视频中用开车从办公室到家的例子演示两者差异：MC 会把轨迹最终到达时间（例如 43 分钟）反向赋给整个轨迹各状态（使每个状态更新到最终实际回报）；TD 则以相邻时间步的估计逐步调整预测（在每个时间点用下一点的估计作为目标），因此能更快速反映局部变化但受当前估计影响。

## 3.5 TD 控制：SARSA（On-policy）与 Q-learning（Off-policy）

- 基本思路（动作值学习）：控制问题常用 Q(s,a)（动作值函数）而不是 V(s)，因为 Q 能直接比较动作并做贪婪改进。既可将 MC 改造成基于 Q 的方法，也可把 TD 扩展到动作值空间得到 SARSA 与 Q-learning。
- SARSA（State-Action-Reward-State-Action，on-policy）：SARSA 的更新使用真实轨迹中的下一动作 A'（由当前策略 π 决定），更新规则为：
Q(s,a) ← Q(s,a) + α [r + γ Q(s', a') - Q(s,a)]
该算法是 on-policy，因为它评估并提高正在执行的策略（通常是 ε-贪婪策略），采样动作与更新目标一致。若策略保持 ε-贪婪且保证持续探索，SARSA 在某些条件下收敛到该策略对应的动作值。
- Q-learning（off-policy）：Q-learning 使用的数据可以来自任何行为策略，但更新目标使用的是下一个状态的最大 Q 值（greedy target），更新规则为：
Q(s,a) ← Q(s,a) + α [r + γ max_{a'} Q(s', a') - Q(s,a)]
这里的 max_{a'} Q(s',a') 与生成数据的行为策略无关，因此 Q-learning 是离策略（off-policy）方法。理论上在满足探索性（所有 (s,a) 被充分访问）与步长条件下，Q-learning 能收敛到 Q*（最优动作值函数）。
- 实用意义与差别：SARSA 更关注在当前（含探索）策略下的实际回报，容易反映探索带来的风险（例如在有高风险动作时 SARSA 学到的策略可能更保守）；Q-learning 则直接逼近最优策略，适用于想从任意行为数据中学习最优行为的场景（例如从示范或混合行为数据中学习）。然而在有函数逼近（非表格）时，离策略学习（如 Q-learning）可能出现不稳定或发散问题，需要更多技巧（经验回放、目标网络等）。
- 收敛性与初值：表格（tabular）情形下，SARSA 与 Q-learning 在合适的探索与步长条件下都能保证收敛。初始化 Q 值可以任意（终止状态常置为 0）但会影响早期行为。Q-learning 的离策略能力使得它在许多实际场景（例如模仿学习、多策略数据收集）中非常有用。

# 4. 框架 & 心智模型（Framework & Mindset）

- 核心 framework：采样 + 自举 + 探索-利用平衡
    - 采样（Sampling）：无模型强化学习的出发点是假设不知道环境的转移模型 P(s',r|s,a)，只能通过与环境交互获得样本轨迹或单步转移。任何估计都基于这些样本而来，因此对样本效率与方差有敏感性。思考时先问：“我能采集到哪些样本？是整条回合还是在线单步？”
    - 自举（Bootstrapping）：自举是动态规划的核心思想之一，即用已有的估计去构造新的目标（更新“猜测朝向另一猜测”）。TD 就是用下一状态的估计作为当前更新目标，从而无需等待终局。设计算法时要判断是否愿意引入估计偏差以换取更低方差与更早更新。
    - 探索-利用（Exploration-Exploitation）：在控制问题中，必须确保策略不会过早陷入利用而丧失对未见状态-动作对的探索。常见的实现是 ε-贪婪策略或其他软策略（如 Gibbs/softmax）。对于收敛性，理论上需要确保所有 (s,a) 被无限次访问；在实践中，采用逐步减小 ε 或其他调度策略以实现早期探索、后期利用的折衷。
- 心智模型与决策步骤（如何在实际问题中选择方法）
    - 确定任务性质：若是明确分集任务且能接受等待回合结束以获得无偏估计，可考虑蒙特卡洛；若需在线更新、持续任务或希望快速利用中间信息，则 TD 更合适。
    - 考虑方差与偏差：若样本有限且方差问题显著，TD 的低方差特性通常更稳健；若能收集大量完整回报样本且偏差不可接受，则 MC 提供无偏估计。
    - 控制时选择 on-policy 还是 off-policy：若只想评估并改进执行策略（并且行为策略与目标策略一致），使用 SARSA（on-policy）比较直接；若数据来自不同来源或想在不改变采样策略的前提下学习最优策略，Q-learning（off-policy）能从任意行为数据中逼近 Q*，但在函数逼近下需谨慎。
    - 步长与探索调度：无论 MC 还是 TD，学习率（α）设置关键。理论上采用衰减的学习率满足特定条件能保证收敛；实践中常使用固定小步长加上经验回放、目标网络等技巧。探索率 ε 的衰减策略影响样本利用效率与最终性能。
- 实验心态与数据化验证：
    - 在实验中，系统地对比 MC 与 TD（例如在同一环境、相同样本预算下）能揭示偏差-方差权衡带来的表现差异。监测收敛曲线、方差（性能波动）与收敛值。
    - 对于离策略方法（如 Q-learning），尤其在函数逼近时，应关注发散风险并准备引入稳定化手段（经验回放、双 Q、目标网络等）。
    - 理解数学等价（例如 MC 误差可分解为 TD 误差之和）有助于在需要混合策略（如 n-step TD、TD(λ)）时做出合理设计，这些方法试图在纯 MC 与 TD 之间权衡偏差与方差，通过使用多步自举（n 步回报）或衰减权重 λ 达到折中。
- 设计原则总结（便于记忆的步骤）
    1. 明确目标：评估（prediction）还是改进（control）；是否需要离策略学习。
    2. 选择估计风格：整轨迹回报（MC）还是逐步自举（TD）或两者折中（n-step、TD(λ)）。
    3. 设计探索策略：ε-贪婪或其他软策略，并决定是否衰减 ε。
    4. 设置学习率与更新频率：表格方法可使用增量更新；函数逼近时考虑批量、经验回放与稳定化技巧。
    5. 监控与调整：观察方差、偏差与收敛行为，必要时调整 α、ε 或采样策略，并考虑混合多步目标以兼顾方差与偏差。

# 总结

本视频从无模型强化学习出发，首先用蒙特卡洛方法说明了如何通过对整条轨迹的样本回报做经验平均来估计价值与进行控制（需等待回合结束，方差大但无偏）；随后介绍了时序差分方法，它通过自举使用下一状态的估计作为目标，支持逐步在线更新（方差小但带偏）；最后在控制层面介绍了 SARSA（on-policy，使用真实下一动作）与 Q-learning（off-policy，使用下步最大 Q 作为目标），强调了探索-利用与收敛条件，并指出离策略在函数逼近下的挑战与实际重要性。整体心智模型是：在采样、估计偏差与方差、自举能力与探索策略之间权衡，选择适合任务特点的算法与参数调度。
