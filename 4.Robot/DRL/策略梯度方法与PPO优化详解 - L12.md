# 2. Overview

本视频围绕如何使用函数近似器（function approximator）直接参数化策略（policy）展开，介绍了策略梯度（policy gradient）思想与具体算法：从最直接的 REINFORCE（蒙特卡洛策略梯度）到引入 baseline 降低方差，再到 Actor-Critic（使用引导/bootstrap 的值函数估计）方法，最后介绍了近端策略优化（Proximal Policy Optimization，PPO）作为一种稳定且实用的现代策略优化方法。结论是：直接优化参数化策略能自然处理随机策略和连续动作空间，REINFORCE 简单但方差高，加入 baseline 与 Actor-Critic 可显著降低方差并利用 TD 引导提升速度，而 PPO 提供了对更新幅度的约束或裁剪，从而在实践中稳健而高效。

# 3. 按照主题来梳理

## 3.1 用函数近似器直接参数化策略：动机与总体思路

- 视频先从之前的做法对比出发：此前通过函数近似器参数化值函数（value function / Q function）来进行控制（control），现在要讨论的是直接用函数近似器来参数化策略（policy）。本节目的在于直接对策略参数做优化，而不是先估算值函数再从值函数导出策略。直接优化策略的好处包括可以天然支持随机策略（stochastic policies）和连续动作空间（continuous action spaces），这在机器人控制等领域很重要。
- 基本方法是把策略参数记为 θ（theta），并定义一个性能度量 J(θ)（performance measure，或目标函数），目标就是对 θ 做梯度上升（gradient ascent）以增大 J。因为环境通常是随机的或模型不可得，真实的梯度 ∇θ J 通常无法解析计算，所以需要通过采样来估计梯度（stochastic estimate）。视频强调这是一个“采样—估计—更新”的循环：用当前策略采样轨迹，基于这些样本估计目标的梯度，再更新策略参数。
- 视频区分了不同场景下的目标函数定义：在有“终止状态”的情形（episodic），可用初始状态分布上的期望回报作为目标；在持续任务（continuing problems）里，目标应基于由策略诱导的稳态分布（stationary distribution）对各状态价值的加权平均。稳态分布指在给定策略下，马尔可夫过程长时间运行后各状态的访问频率分布，但通常不可精确计算（需要无限时间运行），因此实际也依赖采样。
- 最后指出核心挑战：要估计 ∇θ J，既需要考察策略如何改变动作分布（这来自可微策略本身），又会涉及策略改变后如何影响状态分布（这需要环境转移模型）；为保持模型无关（model-free），策略梯度方法采用一个关键工具——策略梯度定理（policy gradient theorem）并配合采样技巧来回避对环境模型的直接依赖。

## 3.2 策略梯度定理与 score function（对数概率梯度）的推导与含义

- 策略梯度定理（Policy Gradient Theorem）的核心结论是：在可微策略 πθ 下，不论使用哪种合适的目标函数（episodic 的初始状态平均或 continuing 的稳态分布平均），目标关于参数 θ 的梯度可以表示为由策略诱导的期望：E[∇θ log πθ(a|s) · Qπθ(s,a)]（期望在策略分布下）。这个结果非常关键，因为它把梯度表示为只依赖于策略的导数以及当前策略下的状态-动作价值 Q 的乘积，再取策略下的期望，从而便于用采样估计。
- 推导要点（视频以直观而非严格的数学细节说明）：把目标的参数导数中出现的策略概率导数项变换为对数梯度形式（gradient of log π），即 ∇θ πθ(a|s) = πθ(a|s) ∇θ log πθ(a|s)。这样原来的期望可以写成对策略下样本的期望，便于直接用策略生成的样本估计梯度。该对数概率的导数在统计学中也称为 score function（得分函数），是常见的蒙特卡洛无偏估计中使用的技巧（score function estimator / likelihood ratio trick）。
- 给出具体例子以帮助理解：如果策略是高斯分布（Gaussian policy），均值为线性特征组合 μ = θ^T φ(s)，方差固定 σ^2，则动作概率密度为正态分布。取对数并对 θ 求导，许多项与 θ 无关（如方差项）会消失，剩余项化简后得到对数概率梯度的具体表达（与（a − μ）成比例），这演示了如何在连续动作下计算 ∇θ log πθ(a|s)。
- 重要含义：策略梯度表达式把“环境转移如何改变状态分布”这一难题用采样和对数概率技巧隐式处理了——我们不直接求环境模型，而是通过在真实环境中执行策略得到样本，这些样本同时包含了策略与环境交互后的结果，从而间接估计梯度。但该估计通常方差较大，需要进一步的方差减少技巧（例如 baseline、回归值函数等）。

## 3.3 REINFORCE 算法：蒙特卡洛策略梯度实现与特点

- REINFORCE 是最直接的策略梯度实现：用蒙特卡洛（Monte Carlo）采样完整轨迹来构造目标的无偏样本，然后据此对 θ 做梯度上升。伪代码核心步骤：初始化策略参数 θ；对每一集（episode）用当前策略采样一个完整轨迹（s0,a0,r1,s1,a1,r2,...直到终止）；对轨迹中每个时间步 t 计算从 t 开始的折扣回报 Gt（Monte Carlo return）；计算梯度估计 ∇θ log πθ(at|st) × Gt，并按步长 α 做 θ ← θ + α ∑_t ∇θ log πθ(at|st) Gt。
- 优点与直观性：REINFORCE 不需要估计任何值函数即可直接上升策略目标，样本估计是无偏的（Monte Carlo returns 为 Q 的无偏估计），实现简单，理论清晰，易于推广到连续动作和随机策略。
- 主要问题：样本方差大。因为完整蒙特卡洛回报 Gt 包含从 t 到终止所有随机性的累积，若环境或策略有很强随机性，不同轨迹下 Gt 可能变化很大，导致梯度噪声大、更新抖动、收敛慢。视频强调了 MC（无偏但方差高）与 TD（有偏但方差低）间的权衡，REINFORCE 属于前者。
- 实践注意：REINFORCE 在实现时通常还要控制步长、可能采用批量更新、或结合其他方差减少方法（如 baseline）。尽管简单，纯 REINFORCE 在复杂任务上往往不够高效，但作为理解策略梯度的基石非常重要。

## 3.4 引入 baseline：减少方差但不引入偏差的技巧

- 基本想法：在策略梯度估计中可以减去一个与动作无关的 baseline b(s)（通常为状态相关但与动作独立的函数），将原本的 Q 或 G 替换为优势估计 A(s,a) = Q(s,a) − b(s)，再乘以 ∇ log π。只要 baseline 不依赖于动作（仅依赖状态或常数），该修正不会引入偏差（expectation 中关于动作的项加权后消失），但能显著降低方差。
- 为什么有效：对每个状态 s，若 baseline 逼近该状态下的平均回报（即 V(s)），那么 Q(s,a) − V(s)（优势函数 advantage）通常比 Q 更接近零且方差更小。减去这个平均值后，剩下的随机性主要来自动作选择对回报的增减效果，从而让梯度信号更稳定、更能反映动作的相对优劣。
- baseline 的选择：理论上任何与动作无关的函数都可作为 baseline（甚至常数），但常数通常在不同状态间无法合适调整；最佳实践是用状态值函数 V(s) 的估计作为 baseline（用参数化的 v̂(s; w)）。因此出现了“策略参数 θ 与基线参数 w 双轨更新”的思路：同时学习策略参数和价值函数参数，策略更新使用回报与 v̂ 的差（有时是时序差 δ），价值函数参数用回归或 TD 方法更新。
- 在 REINFORCE 中加入 baseline 的伪码变体（reinforce with baseline）就是：用蒙特卡洛计算 Gt，构造 δt = Gt − v̂(st; w)；用 ∇ log πθ(at|st) × δt 更新 θ（上升）；并同时用样本来更新 w（如均方误差最小化或 Monte Carlo 回归）。视频指出这种做法仍保留无偏性（只要 baseline 不依赖动作），但方差大幅下降，实践效果更好。

## 3.5 Actor-Critic（演员-评论家）方法：引导引入 TD bootstrap

- 定位与动机：Actor-Critic 方法把策略（actor）与价值估计（critic）同时参数化，actor 负责给出概率化动作（πθ），critic 用参数化的值函数 v̂(s; w) 来评价当前策略的好坏。与 REINFORCE 不同，Actor-Critic 不依赖完整的 Monte Carlo return，而是使用 TD 引导（bootstrap）来得到低方差但有偏的估计，从而加速学习。
- 算法要点：在单步（one-step）actor-critic 中，按每一步采样（而不是整集），计算 TD 误差 δt = rt+1 + γ v̂(st+1; w) − v̂(st; w)。这个 δt 同时用于更新价值函数参数 w（如 w ← w + αc δt ∇w v̂(st; w)），并用作策略梯度的因子更新策略参数 θ（如 θ ← θ + αa ∇θ log πθ(at|st) · δt）。这里的 δt 起到了优势估计的作用（近似 A(s,a)），因为它衡量了采取动作 a 后比之前估计更好还是更差。
- 优势与稳定性：由于 TD 只使用一步回报并结合 v̂ 进行引导，方差通常比蒙特卡洛小，更新频繁且更稳定。Actor-Critic 将策略梯度与 bootstrapping（我们之前在 value-based 方法中看到的）结合起来，适用于连续/大规模状态-动作空间。视频强调 actor 与 critic 的参数可能同时更新，学习率和收敛性需要调节，且这类方法仍需注意偏差-方差权衡。
- 实践细节与拓展：可以将 one-step 扩展为 n-step 或用 GAE（广义优势估计）等技术进一步平衡偏差与方差；critic 的表示能力与训练质量直接影响 actor 的学习，因为 actor 依赖 critic 提供的信号。此外，actor 可以是随机策略以保持探索，critic 则通常是确定性的值函数估计器。

## 3.6 近端策略优化（PPO）：目标分解、代理目标与裁剪技巧

- 背景与核心思想：PPO（Proximal Policy Optimization）由 John Schulman 等提出，是对早期 TRPO（Trust Region Policy Optimization，信赖域策略优化）的一种更简单且更易实现的替代。PPO 的基本出发点是：在用采样数据更新策略参数时，保障新旧策略不要发生过大偏离，以免估计失真或性能崩塌。为此他们构造了“替代（surrogate）目标”，在实践中通过裁剪（clipping）或自适应 KL 惩罚来避免过大更新。
- 目标函数分解：论文中给出的一个关键等式将新策略 πθ 的目标 η(πθ) 分解为旧策略 η(πθ_old) 加上一项关于新策略下对优势 Aθ_old 的期望：η(πθ) = η(πθ_old) + E_{s∼d_{πθ_old}, a∼πθ}[ ∑_t γ^t A^{πθ_old}(s_t, a_t) ]。这里 A 是相对于旧策略计算的优势。通过梳理远期项，这一分解展示了可以用旧策略下的状态分布与优势来近似评估新策略的改进，但严格等式里有状态分布变化的影响项，PPO 的近似忽略（或用重要采样/裁剪来补偿）这一点。
- 重要采样与裁剪代理（clipped surrogate）：在实践中，我们通常采集数据时使用旧策略 πθ_old，因此想对新策略的期望用旧策略下的样本来估计，就需要重要采样比 r(θ) = πθ(a|s) / πθ_old(a|s)。PPO 的一种实现是定义代理目标 L_CLIP(θ) = E[ min( r(θ) A, clip(r(θ), 1-ε, 1+ε) A ) ]，即在每个样本上取原始重要采样修正乘以优势与裁剪后的重要比率乘以优势之间的较小值。这等于在奖励优势被正向时不允许比率超过 1+ε，在负向时不允许比率低于 1-ε，从而避免大的政策更新带来的损失。
- 自适应 KL 惩罚变体：另一种实现用到自适应惩罚项，即在目标函数上加上 β · KL[πθ_old || πθ]（或其估计），并根据实际的 KL 发散大小调整 β（如果 KL 太大就增大惩罚，反之减小）。这与 TRPO 的信赖域思想相关，但更易于实现与并行化。
- 实践流程（简化描述）：用当前策略 πθ_old 收集若干轨迹并估计优势（可用 GAE、TD 等）；计算重要性比率并构建 PPO 的代理目标（裁剪或惩罚）；对 θ 做多步小批量的随机梯度上升以最大化代理目标，同时（若有）更新价值函数或优势估计器；重复迭代。PPO 在很多任务上表现稳健、实现复杂度适中，是目前广泛使用的策略梯度家族基线算法之一。
- 优缺点总结：PPO 在保证更新不致过大、同时保留单次多次迭代优化能力上取得良好折中；相比传统策略梯度或 REINFORCE 更稳定；相比 TRPO 更易实现和扩展。但仍需注意优势估计、样本效率、超参数（如 ε、学习率、熵项系数等）调节，且在某些高样本效率任务上仍可能不如某些基于值函数的算法。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：采样—估计—更新（Sampling → Estimation → Update）
    - 描述：策略梯度方法的总体心智模型是一个循环系统：先用当前参数化策略 πθ 在环境中执行并采集样本（状态、动作、奖励、下一个状态）；然后基于这些样本估计对策略目标的梯度（或代理目标的梯度），关键估计包括 ∇θ log πθ(a|s)、回报 G 或优势 A、重要性比率等；最后用估计的梯度更新策略参数 θ（梯度上升），同时可能更新价值函数参数 w（若使用 baseline/critic）。这个循环不断迭代以改进策略。该框架强调模型无关（通过真实交互获取信息）和用统计估计替代解析推导。
    - 细节展开与理由：采样阶段必须保证数据代表性且维持必要的探索（随机策略或噪声）；估计阶段需要平衡偏差与方差：Monte Carlo 返回 G 无偏但方差高，TD/bootstrapping 有偏但方差低；baseline（如 v̂(s)）和优势估计（如 A = Q − V）是降低方差的核心工具；在使用旧策略数据更新新策略时要注意分布漂移，重要采样或代理目标（如 PPO 的裁剪）用于修正或限制更新幅度，从而保证估计的可靠性。更新阶段的学习率、批量大小与优化器选择会显著影响收敛性和稳定性。整体上，这是一个以采样为核心的迭代优化循环，任何一步的弱环都能拖累整体效果，因此工程实现上需重视方差减少、稳定性与样本效率的技术配合。
    - 实践建议：使用合适的 baseline（通常是参数化的 V 函数），使用 TD 或 GAE 做优势估计以平衡方差与偏差；在批量训练中执行多次小步参数更新以充分利用样本；监控重要性比率或 KL 发散，避免过大更新；在连续动作问题中使用合适的策略参数化（例如正态分布的均值-方差参数化）并固定或学习方差。
- 框架二：优势—基线—重要性比率（Advantage, Baseline, Importance Sampling）构成的三角关系
    - 描述：在策略梯度方法中，有三个相互关联的核心概念共同决定了估计的有效性：优势（Advantage A(s,a) = Q(s,a) − V(s)）反映某次动作相对于状态平均的好坏；基线（Baseline，常选 V(s)）用来从回报或 Q 中减去某个与动作无关的量以减少方差而不引入偏差；重要性采样比率（πθ / πθ_old）用来用旧策略采样的数据估计新策略下的期望或校正分布差异。这个三角关系在不同算法中以不同方式组合：REINFORCE+baseline 使用 A 或 G−V，Actor-Critic 使用 TD 误差作为近似优势，PPO 使用重要性比率结合裁剪或惩罚来在旧数据上优化新策略。
    - 逻辑与实现要点：优势的质量直接依赖于价值估计器的准确性；若 V 估计良好，优势的方差降低、信号更清晰，使策略更新更高效。重要性比率允许重用旧样本，但会放大方差（当比率很大时），因此需要裁剪或约束（PPO 的做法）或采用小步更新/信赖域（TRPO）以控制风险。使用 TD 作为优势估计器能带来更低方差，但会引入偏差，需在学习速率和估计器复杂度上做权衡。
    - 操作化建议：在离线或批量更新中优先使用重要性比率与裁剪；在在线逐步更新里可更依赖一阶 TD 估计；价值函数的参数化能力（网络规模、正则化）和训练频率要与策略更新频率协调，避免“误导性” critic 导致 actor 学坏。

# 总结

- 策略梯度方法通过直接参数化并优化策略，为连续动作与随机策略问题提供了自然的解决方案。核心数学工具包括策略梯度定理与对数概率（score function）技巧，使得在无模型的情形下可用采样估计梯度。
- REINFORCE 是最直接的实现但方差高，baseline（尤其是状态值函数 v̂(s)）能在不引入偏差的前提下降低方差；Actor-Critic 更进一步引入 TD 引导以平衡偏差与方差，通常更快更稳定；PPO 则着眼于控制策略更新幅度，通过裁剪或 KL 惩罚在样本上做稳定且高效的策略优化，是现代深度强化学习中常用且实践性强的方法之一。
- 实践上常见的工程要点包括选择合适的策略参数化（如高斯策略）、用 v̂(s) 作为 baseline、用 TD 或 GAE 作为优势估计、注意重要性比率或 KL 发散并采用裁剪或信赖域约束，以及调整学习率与批量大小以获得稳健收敛。对于视频中的某些推导或年份等细节若未明确给出，应保持原文意并承认不确定性。
