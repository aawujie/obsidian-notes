# 30年级末日储备清单（系统版）

真正的生存，不是囤一堆零食。

而是构建一个： **能量系统 + 蛋白系统 + 水系统 + 医疗系统 + 流通系统。**

以下是普通家庭可以执行的版本。

# 一、水：第一优先级（高于粮食）

人类：

- 3天无水就会出现生命危险
- 30天无粮仍有生还概率

## ✔ 基础储备量

- 每人每日最低 3升
- 至少准备 3天 = 9升 / 人
- 若有条件，建议准备7–14天

## ✔ 储水方式

- 食品级水桶密封
- 定期更换
- 额外储备日常饮品（能量饮料、电解质粉）

## ✔ 水处理系统（必备）

1. 明矾（物理沉淀） 沉淀用明矾（现在很少人用，但超有效）：脏水塘水加一点点，就能让悬浮颗粒、细菌、寄生虫卵快速结块沉底。
2. 二氧化氯 / 次氯酸钠（消毒） 消毒用二氧化氯或次氯酸钠：一缸水加1克左右，就能杀菌杀病毒，处理后基本可直饮。
3. 便携滤水器 重力式滤水设备优先

水处理能力 = 家庭生存等级。

# 二、碳水系统：长期热量来源

热量才是活下去的底层逻辑。

## 可储存30年级别（合理包装前提）

✔ 大米（关键升级）

普通大米2年左右。

但——

**真空包装 + 脱氧剂 + 干燥剂 + 避光低温储存**

储存期可大幅延长（理论可达10年以上）。

建议：

- 真空密封分装
- 每袋5kg以下
- 放入密闭桶防鼠虫

✔ 稻谷（带壳）

- 5–10年自然储存
- 可发芽种植
- 是“可再生产”的粮

✔ 意大利干面

- 干燥环境可存10年以上
- 比米更耐储

✔ 燕麦片

- 高纤维
- 密封防潮可长期保存

✔ 干豆（大豆、扁豆、鹰嘴豆）

- 轻松20年以上
- 蛋白+碳水双功能

✔ 芝麻

- 理论可存极久（油脂稳定时）
- 高热量高脂肪

# 三、糖与盐：被低估的战略物资

## ✔ 白砂糖 / 冰糖

- 干燥密封几乎不变质
- 能量密集
- 天然防腐剂（高渗抑菌）
- 高浓度白糖还是天然防腐剂，加大量糖就能让很多食物长期保存不坏

糖的作用：

- 保命热量
- 防腐制作果酱
- 情绪稳定
- 交换物资

## ✔ 蜂蜜

- 几乎永久保存
- 天然抗菌
- 能量密集

## ✔ 盐

- 永久储存
- 维持电解质
- 食品腌制核心材料

盐在乱世是硬通货。

# 四、蛋白系统：防止衰弱

单纯吃碳水会迅速虚弱。

必须有稳定蛋白来源。

## ✔ 鱼类罐头（保质期3年左右）

- 富含蛋白和健康脂肪
- 开罐即食
- 口味轮换防止厌食

## ✔ 肉罐头

- 牛肉、猪肉
- 高热量

## ✔ 奶粉 / 脱脂奶粉

- 钙和蛋白来源
- 真空密封储存

## ✔ 干肉饼（牛肉干、鹿肉干）

- 高蛋白
- 易保存

# 五、即食与心理维稳类食品

灾难时食欲低落很常见。

## ✔ 即食饭

- 热水15分钟复原
- 冷水60分钟替代
- 多口味轮换

## ✔ 罐装面包（日本防灾款）

- 长期保存
- 松软口感
- 心理安慰效果强

## ✔ 蛋花粥

- 易吞咽
- 营养丰富
- 适合病弱时

## ✔ 蔬菜汤

- 补充纤维
- 盐分低
- 保存期可达5年以上

维生素缺乏比饥饿更可怕。

# 六、酒类：隐藏物资

烈酒：

- 消毒用途
- 情绪安抚
- 交换物资

高度酒几乎永久保存。

# 七、医疗系统（真正分水岭）

灾难死亡首因不是饿，是感染。

## 必备：

- 合规抗生素
- 止血材料
- 消毒酒精
- 碘伏
- 退烧止痛药
- 抗腹泻药

乱世里虫草、灵芝、人参、石斛、黑枸杞统统鸡肋，没用。

真正能救命的是抗生素——哪怕是养殖场给鸡鸭猪用的兽用药（比如几百块一公斤的四环素），也远比没有强（当然一定提前咨询医生，注意用药安全）。

关键时刻： 感染控制能力 = 生存概率。

# 八、储存环境原则

核心四字：

干燥 避光 低温 密封

建议：

- 真空封装
- 脱氧剂
- 干燥剂
- 放入旧冰箱或密闭柜
- 地下室通风防潮

防鼠虫 > 防过期。

# 九、资产系统：秩序崩溃后的流通能力

当纸币失信时：

小规格金条（太大不方便使用） 稳定币（如USDT、USDC等）

会成为跨境与现实世界之间的桥梁。

还可以准备一些美金现钞，也是要小面额方便极端情况使用

这些东西平时不显山露水，真到用时就是命根子 多货币体系储备相当重要。

流动性 = 安全感。

真正的末日准备不是恐慌。
