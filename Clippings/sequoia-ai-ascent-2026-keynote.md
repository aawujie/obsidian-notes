# This is AGI: Sequoia AI Ascent 2026 Keynote

**Sequoia Capital · 2026年AI攀登峰会主题演讲**
**演讲人: Pat Grady · Sonya Huang · Konstantine Buhler**

## Pat Grady 开场演讲

早上好。大家今天怎么样？

好，好，稍微好一点了。嘿，非常感谢大家来到这里。我们由衷感激。我们把这当作对社区的一项服务，因为我们正生活在一个重要的时代。能够成为大家聚在一起的一个聚集地，这是我们的荣幸。这是我们有史以来最好的议程，也是有史以来最好的参会阵容。所以我们想首先说一声谢谢。我们知道你们都非常非常忙。感谢你们今天来到这里。

话说回来，我们一如既往地准备了一个相当出色的议程。着装无可挑剔的Sonia、Constantine和我，先简单说几句开场。你知道，我们有幸身处大量对话之中，与许多有趣的人交流。所以每年我们都会尝试把这些信息综合一下，把我们听到的东西回馈给大家。那么我先来讲几句整体定位，然后Sonia会讲一讲我们当下看到的情况，接着Constantine会谈谈我们认为未来可能会发生什么。

好，关于定位，我们先拉远视角来看——回到赋予了这个地方名字的硅基晶体管（silicon based transistors）。它们被构建成系统，通过网络连接起来并以互联网的形式走向公众，支撑起社交媒体和云（cloud）等应用，最终以移动设备（mobile devices）的形式出现在我们的口袋里——而今天，这些设备能够做到一件与魔法无异的事情，那就是AI（人工智能）。

我们喜欢展示这张幻灯片——过去来过的人之前也见过——是因为它提醒我们：所有这些浪潮都是叠加的（additive）。我们差不多需要这几十年的全部演进，才能拥有足够的算力（compute）、带宽（bandwidth）、数据和人才来充分利用当下这个时刻。

而这次的AI浪潮在三个方面有些不同。

第一，这是迄今为止最大的浪潮（biggest wave yet）。这大体上是正确的，但关于这次浪潮还有一件更具体的事——它是第一个同时涵盖软件（software）和服务（services）的浪潮。上面一行展示的是云转型（cloud transition）的前15年，软件的TAM（总可寻址市场，Total Addressable Market）从约3500亿美元增长到6500亿美元，其中云占了约4000亿美元。而下面一行是全新的东西——这是现在似乎也可以获取的服务收入（services revenue）。10万亿美元是一个凑整的方便数字。我们不知道是10万亿、5万亿还是50万亿。但我们确切知道，仅美国法律服务市场就有4000亿美元——而这仅仅是一个垂直领域（vertical）加一个地理区域（geo）。这和整个软件市场的规模一样大。所以，这个机会是巨大的。

第二点，这是最快的浪潮（fastest wave yet）。我想我们都能感受到这一点。这意味着——请大家注意这一页AI这边的空白——这块空白正在迅速被填满。这些logo是那些借助云、移动和现在AI这三次板块级变化（tectonic shifts）而达到10亿美元以上收入的公司。按照目前的方向和速度，还有更多公司即将加入。

第三点——这可能是最有趣的一点，我是从我的合伙人Constantine那里借来的——即技术领域存在两种基本的革命。一种是通信革命（revolutions of communication），它关乎信息分发（information distribution）的方式。在座的大多数人只经历过通信革命。互联网、云、移动——这些全都是关于信息分发的。它们都是通信革命。

AI是另一回事。AI是这一类——AI是计算革命（revolution in computation）。它关乎信息处理（information processing）的方式。这听起来可能像是咬文嚼字（semantics），但两者的浪潮形态（shapes of waves）是根本不同的。

要最直观地感受这一点，也许就是想一想这样一个事实：脚下的地板一直在移动。当新能力不断涌现时，每个人赖以建设的技术基础（technology foundation）每天都在变化。

在过去几年里，我们已经经历了三个重大的拐点（inflection points）。

第一个：ChatGPT时刻（ChatGPT moment），2022年11月，世界看到了预训练（pre-training）的力量。

第二个，几年后：o1模型推理（reasoning）。突然间，围绕推理时计算（inference time compute）出现了第二条缩放定律（scaling law）。

第三个，就在最近：Claude Code，分数从45分到47分。世界看到了长程智能体（long horizon agents）的力量。

虽然这三个点看起来像是连续体（continuum）上的三个点，但在第二和第三之间有一个断层（heartbreak）——这是一个非连续性的变化（discontinuous change）。

如果我们可以斗胆说一句：这就是AGI（通用人工智能，Artificial General Intelligence）。好吧，我是经济学专业的，我们是风险投资人（venture capitalists），不打算给AGI下一个技术定义。我们研究的是创始人和市场，以及二者碰撞产生的——也就是企业。但我们确实研究企业。所以从商业角度（commercial standpoint）、从实用角度（practical standpoint）、从功能角度（functional standpoint）来看——如果你能派一个智能体（agent）去执行一项工作，它能从失败中恢复并持续进行直到工作完成——我不知道……这感觉就很像AGI了。

即使你不认为这是AGI，那也没关系。顺带一提，Sonia会在她那一部分详细讲这一点。即使你不认为这是AGI，我想我们都能看到：汽车已经来了。

过去几年我们有过很多"更快的马"——那些能让你生产力提升10%或40%的应用，但并没有从根本上改变你的工作方式。现在我们开始看到"汽车"了——那些让你生产力提升10倍或40倍的应用。而且它们彻底改变了你的工作方式，改变了你工作的本质，改变了你组织的本质。汽车已经来了。

这是红杉（Sequoia）的创始人Don Valentine。他以一个问题闻名。

那又怎样？（So what?）这一切到底为什么重要？

嗯，它之所以重要，是因为就在过去几个月里，比赛已经开始了。而且这是一种不同于我们以往习惯的比赛。开汽车的方式和骑马的方式不同。造汽车的方式和养马的方式也不同。所以这是一场非常不同的比赛。我们想让大家今天聚在这里的原因之一，就是没有人知道所有的答案。我们在一起的时间越多，我们就能学得越多，希望也能逐渐搞清楚这一切正在走向何方。而且我们必须尽快做到这一点，因为利害关系太大了。

仅从商业角度来看，就有10万亿美元的市场待争夺。我们有实验室（labs）从技术向外（tech out）的路径切入。我们也有创业公司在其之上构建，以更偏向客户向后（customer back）的路径切入。这个屋子里确实有所有实验室的代表，但在座的大多数人是在其上构建的。所以，我们花一点时间，谈谈那种客户向后的方法。

那么，对于那些在实验室之上构建的人，我们的建议是免费建议——所以它值你为它付出的每一分钱（笑）。我们的建议是：get MAD。我们其实不需要你生气。你想生气也可以——如果那是驱动你的动力，那也挺好，尽管生气吧。但这只是一个方便的缩略词，代表护城河（MOATS）、可供性（AFFORDANCE）和扩散（DIFFUSION）——这是在模型之上构建策略的三个特征，或者说三大支柱（pillars）。

先说护城河——纯属娱乐。有人记得去年这张幻灯片吗？只有一个人，他是我的合伙人。好吧，那也挺好。嗯，我们不打算……好的，作为提醒，这张幻灯片展示的是商品化周期（merchandising cycle）——也就是将某个东西从一个想法变成满意客户（happy customer）所需要的价值链（value chain）上的各个环节。我们实际上不会逐一讲解产业链中的每个环节。我想说的是：如果你从技术向外（tech out）的角度来看问题，产业链中每个环节的处理方式都会有些不同。如果你从客户向后（customer back）的角度来看问题，产业链中每个环节的处理方式也会有些不同。

而这就是反直觉（counterintuitive）的部分。在一场关乎信息处理（information processing）的计算革命中，你本能想做的是往下看——因为总有很酷的新东西在不断涌现。但为了构建护城河（moats），你真正应该做的是往上看——因为你的客户变化的速度远远赶不上能力（capabilities）变化的速度。你今天构建的东西明天可能就没用了。但你与客户紧密绑定（wrap yourself around your customers）的程度则会更加持久。

这并不是说产品和技术不重要。它们极其重要。而且一般来说，最好的产品会胜出。但在一个产品因能力快速变化而飞速迭代的世界里，考虑护城河时，我们鼓励你尽可能走客户向后的路径，思考所有你能围绕那些客户把自己紧密绑定的方式。

好，MAD中的A代表可供性（affordance）。这是我们从设计领域（design world）借来的一个术语。锤子就是一个具有可供性的物体。我有一个两岁的儿子。如果我给他一把锤子，他会知道该怎么做——他会抓住它然后开始砸东西。这就是我们不给他锤子的原因。明白吗？一个具有可供性的物体是不需要解释的。人们天然就知道怎么用它。

Claude Code非常强大。但你去给一个普通的世界500强（Fortune 500）员工打开一个终端，看看他们能走多远。虽然它很强大，但它并不提供太多可供性。这不是在贬低Anthropic，而是为任何想在其上构建的人提供的机遇——也就是为你的特定客户和他们的特定问题创造阻力最小的路径（paths of least resistance），让他们毫不费力地就能找到实现业务所需结果的方法。这就是可供性的概念。

然后最后，MAD中的D代表扩散（diffusion）。扩散差距（diffusion gap）就是在应用层（application layer）构建的公司所面临的机会。能力向市场扩散的速度，远远落后于这些能力被创造出来的速度。每一天，基础模型（foundation models）前进的速度都快过一般的世界500强企业，这个差距就越大，机会也就越大。

所以，对于护城河，请尝试走客户向后的路径。对于可供性，请思考如何为你的客户创造那些阻力最小的路径。而那个扩散差距，就代表了你的机会。

万一之前那张空白正在被填满的幻灯片让任何人感到气馁——请允许我们提醒你：没有领先是安全的（no lead is safe）。赛车界有句话：你无法在晴天超越15辆车，但你可以在雨天超越15辆车。而现在，基础模型正在倾盆大雨般地释放新能力。这意味着没有领先是安全的，但这也意味着任何人都可以获胜。

活着真好，生逢其时。说到这里，我把话筒交给Sonia。

## Sonya Huang: AI Agent 时代

Sonya。[掌声]

谢谢你，Pat。我只想说，今天看到台下这么多熟悉的面孔，真的非常开心。今天在座的都是非常出色的一群人，我很高兴能与大家共同成为这个生态的一部分。

那么，我这部分要讲的是 AI 领域正在发生的事情——对 2026 年来说，这个主题就是 agent（智能体）。

好了，让我们回到 2022 年。在座的有人记得 AutoGPT 或 BabyAGI 吗？举手看看？好的。这些项目曾一夜之间在 GitHub 上爆红，它们的做法是把 GPT-3 配上一些工具，放在一个循环里，让它自动朝着一个目标运行。

一开始看起来很有希望——直到你看着那些 agent 一遍又一遍、一遍又一遍地失败。

有点可爱，有点招人喜欢，但完全没用。

我把这一页放在这里，是想提醒大家：其实我们早就知道 agent 要来，几年前就能预见到，但在 2022 年，模型还远远没准备好。

快进到今天，大概是今年年初拐点出现了。突然间，我们身边到处都是 agent，而且它们似乎真的开始生效了。

有两个 agent 产品尤其突出。一个是面向技术人员的 Claude Code，另一个是 OpenClaw 及其所有"龙虾兄弟"——它们把 agent 的能力普及到了任何有手机的人手中。所以，不管你是硬核工程师还是普通人，结论是一样的：现在任何人都可以创建 agent。

因此，我们看到人们在为一切事务构建 agent。有一些搞笑的东西，比如有个 OpenClaw agent 会去举报邻居税务欺诈——请大家别这么做。呃，或者也许请这么做吧。

还有一些创业类的，比如用 agent 来运营生成式媒体广告投放，销售建筑服务。

然后是专业层面。我可以告诉大家，红衫内部正在进行一场激烈的竞赛，看谁能打造出最好的 agent 来更好地完成我们的工作。

那么，成为一个 agent 到底意味着什么？这里有一个可能的定义：agent 是一个能够感知环境、选择行动并自主向目标前进的系统。

顺便说一下，这是我用 C dance（注：AI 视频工具）自己做的，我非常为之自豪。
>> [笑声]
视频模型确实进步了很多。

更具体地说，我认为 agent 有三个功能组件。

第一是推理和规划的能力。这是直觉的基础层级，以及临场思考的能力。

第二是执行行动的能力。这就是工具：搜索、编写、编译。

第三是朝着目标不断迭代的能力。这就是让 agent 能够跨越长时间跨度去完成任务的"持久性"。

所以，"agent 能力（agency）"就是把这三样东西结合在一起。简单来说，就是把事情做完的能力。

如果我们把 agent 拆解成它的构成组件——模型、工具、框架（harness）——每个组件在过去一年里都取得了快速的进步。

首先是模型，这是大脑。这是发生的最重要的事情。这个"仪表图"衡量的是一个模型在复杂任务上能持续前进多久而不跑偏。我们从一年前的几十分钟量级，走到了今天的小时量级。

这是最重要的事情：模型终于变得足够强大，能够在长周期任务上保持性能了。

第二是工具，这是手臂和腿。它们让模型能够访问那些让我们在电脑上高效工作的东西。比如终端用于文件系统和开发工具，iMessage，Slack，网页搜索，计算机操作（computer use），应有尽有。

过去二十年我们为人类打造的工具，到头来同样可以移植给 agent 使用，而且非常有用。经常有人说 SaaS（软件即服务）已死，我认为恰恰相反，随着使用这些工具的 agent 数量增长，这些工具的价值将迎来爆发。

模型和工具给了 agent 能力。而框架（harness）赋予它们持久性——保持专注、适应变化、持续前进的能力。这个反馈循环现在真的开始高速运转了。

特别是借助强化学习（reinforcement learning）——我们把这些 agent 送进了"驾校"，在 RL gym（强化学习训练场）里训练它们，推动它们在从机械工程到设计到金融等不同领域的表现不断提升。

我们也看到了自我进化（self-improvement）或"机器造机器"（machine building the machine）的早期曙光。举个例子，Andrej 的另一个研究项目，能在短短 2 小时内自主迭代优化出一个 GPT-2 级别的模型。

那么，agent 无所不在的世界是什么样的？

Agent 存在于一个"自主性滑动刻度尺"上。我们以编程为例来说明。

2023 年，我们有 tab 自动补全——一个 AI 辅助一个人完成一行代码。这有一定用处，但本质上不是变革性的。

现在我们有 agent 驱动的开发（agentic development）——一个人与一个 agent 对话，指示它做什么，甚至管理一整个 agent 团队。

但这个范式还在被进一步推进。我们现在看到后台 agent、异步 agent、agent 生成子 agent（sub agents）。我们认为，在整个体系中，异步 agent 这一范式很可能在体量上超越当前的范式——仅仅因为系统中的杠杆效应如此之大。

最后，把边界推到最前沿，是我称之为"黑灯工厂"（dark factories）的阶段——将人工审查完全从系统中移除。这听起来很疯狂，但我已经看到它在生产环境中发生了，包括在网络安全公司里。只要有足够好的护栏和工程能力，这是可以实现的。

所以，我们正在沿着自主性的刻度尺向上爬。Agent 正从身边帮忙的小助手，变成需要管理的实习生，再变成能管理自己的实习生，最终变成足够值得信赖、可以在没有监督的情况下直接推向生产的实习生。这就是正在发生的演进，不仅限于编程，而是涵盖所有 agent 领域。

对在座的创始人来说，最重要的收获是：服务即新软件（services is the new software）。从我认识 Pat 开始，他就一直在说这句话。我们的合伙人 Julian 今天也在台下，他发表了一篇很棒的文章讨论这个话题。我们已经知道这个趋势很久了，但我觉得它现在真的在发生。

在医疗领域，你可以雇佣一个 agent 来检查你的基因组，给你个性化的建议，开处方药，推荐临床试验。

在法律领域，你可以雇佣 agent 代表你谈判合同，甚至进行诉讼并为你和解。

在数学和科学领域，我们看到 agent 能解决那些悬而未决的难题，或者发现新的超导体。这是多么令人激动的事情？

在消费领域，个人 agent 可以帮你管理收件箱、日历、财务，帮你报税。

我们预计 agent 将无处不在，部分原因在于雇佣 agent 比雇佣员工简单太多了。

人类难以规模化。而 agent 凭借算力可以无限扩展。

人类难以保持快乐（除了我，我一直很快乐）。agent 是低维护成本的。

人类很贵，你要付薪水。你付给 agent 的是 token（代币）。一般来说，用 token 完成一项任务的成本，比支付等量的薪水要低。

今天，人类总体上还更聪明，但"苦涩的教训"仍在继续，很快 agent 就会在很多事情上更聪明。所以这一页的重点不是说我们人类要失业了——我认为适应性是人类的独特特质。但我们确实预期 agent 在应用层的部署会非常迅速，规模史无前例，因为经济学上的优势如此明显，也因为比特（bits）天然的可扩展性。

把所有这一切加在一起，agent 的数量正在以某种指数级甚至超指数级的曲线激增。我觉得我们即将到达一个真正变得……

……奇怪的时间点。

当商业交易在 agent 之间发生时，会怎样？它们能互相支付吗？

当 agent 真的能互相协商交易条款时，会怎样？

我们会不会有成群的 agent 在"监管"我们，阻止类似"网络安全末日"的事情发生？

我们所知道的是，这个世界正在极速变得奇怪。

所以，让我借用一下我内心的贝尼·杰瑟里特（Bene Gesserit）来收尾。

长周期 agent（long horizon agents）已经出现了，它们所处的成长曲线非常清晰。

对于创始人来说，我想每个人都有这样的例子——有人借助 AI 完成了时间线极其紧张的任务。
