### Cover

Every market has a memory.

It is one measurable number, and it decides whether prices keep trending or snap back.

| SNAP BACK | RANDOM | TREND |
|-----------|--------|-------|
| H < 0.5 | H = 0.5 | H > 0.5 |

### The same randomness, three different memories

Identical noise scale, only the correlation between one step and the next changes.

- **MEAN-REVERTING** — built with H = 0.25 — prices snap back
- **RANDOM WALK** — built with H = 0.50 — no memory
- **TRENDING** — built with H = 0.75 — moves persist

### The Hurst exponent is just a slope

From the log-log plot of rescaled range (R/S) vs. window size:

- **Trending:** slope H = 0.67
- **Random walk:** slope H = 0.50
- **Mean-reverting:** slope H = 0.33

### Rolling Hurst reveals regime changes

A single Hurst exponent hides multiple regimes. The article shows synthetic data where one series has two regimes (single H ≈ 0.58 hides both), and real VIX data where rolling Hurst stays mostly below 0.5 — but not always.

Key insight: **regime matters**. A single-point estimate of H can be misleading; use rolling windows to see when the market memory changes.

### Could this memory come from no memory at all?

Statistical significance test via shuffle bootstrap:

- **Trending series:** observed H = 0.67, p < 0.001 (vs shuffled null)
- **Random-walk series:** observed H = 0.50, p = 0.070 (consistent with no memory)

Method: shuffle the original series to destroy any memory structure, compute H for each shuffled copy, and compare the observed H against the null distribution.

### Real markets, measured: where memory actually lives

Variance ratio VR(q) across holding horizons:

- **Above 1** = trends persist
- **Below 1** = prices snap back

Results:
- **VIX volatility index:** z@20d = -3.8 (strong mean-reversion)
- **S&P 500 ETF:** z@20d = -0.9 (mild mean-reversion)
- **Bitcoin:** z@20d = +0.7 (mild trending)

The variance ratio test confirms: different markets have different memory structures, and this single number determines whether prices trend or revert.

## Key Takeaways

1. **The Hurst exponent (H)** is a single number that classifies price series into three regimes: trending (H > 0.5), random walk (H = 0.5), mean-reverting (H < 0.5).
2. **R/S analysis (Rescaled Range)** is the method — the slope of log(R/S) vs. log(window size) gives H.
3. **Rolling Hurst is essential** — a single-point H estimate hides regime changes; use rolling windows.
4. **Shuffle bootstrap** provides statistical significance — is the observed memory real or could it arise from pure noise?
5. **Variance ratio VR(q)** is a complementary tool: VR > 1 = trending, VR < 1 = mean-reverting.
6. **Different markets, different memories** — VIX strongly mean-reverts, S&P 500 mildly mean-reverts, Bitcoin mildly trends.
