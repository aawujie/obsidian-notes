## 第一部分：神经网络实际在计算什么

在构建任何东西之前，你需要理解神经网络在数据上训练时实际发生了什么。大多数解释跳过这一步，直接上代码。这就是为什么大多数实现都会失败。

神经网络是一个参数化的复合函数。你给它一个输入向量。它应用一系列线性变换，中间穿插非线性激活函数。它产生一个输出。其形式化结构是：

$$f(x) = W_n \cdot \sigma(W_{n-1} \cdot \sigma(\dots \sigma(W_1 \cdot x + b_1) \dots) + b_{n-1}) + b_n$$

其中 $W_i$ 是权重矩阵，$b_i$ 是偏置向量，$\sigma$ 是逐元素应用的非线性激活函数。这是每个神经网络底层的数学现实，无论它被如何可视化。

其威力在于训练。你有一个输入-输出对的数据集。网络从随机参数开始。它做出预测。它计算预测与实际观测输出之间的误差。它沿减小误差的方向调整参数。它重复这个过程数百万次。

形式化的目标是最小化损失函数。对于回归任务，标准选择是均方误差：

$$L(\theta) = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

其中 $\theta$ 代表所有可学习参数，$y_i$ 是实际观测值，$\hat{y}_i$ 是模型预测值。优化过程通过计算损失相对于参数的梯度，并沿负梯度方向迈出一步来进行：**$\theta \leftarrow \theta - \alpha \cdot \nabla_\theta L(\theta)$**。其中 $\alpha$ 是学习率。这就是随机梯度下降。每一个现代深度学习优化器都是它的变体，在其上叠加了自适应步长、动量项或二阶近似。

一个前馈神经网络将输入通过加权层传递，产生一个近似目标变量条件期望的输出。

现在，这是一个改变你解释神经网络产生的所有输出的洞察：

当你训练一个网络来最小化目标变量的平方误差时，它学到了什么？它学到了给定你的输入时该变量的**条件期望**。使 $E[(Y - f(X))^2]$ 最小化的函数恰好就是 $E[Y|X]$。这可不是通俗意义上的"预测"。这是数学期望——在所有与观测输入一致的场景下的加权平均结果。

证明很直接。展开平方损失：

$$E[(Y - f(X))^2] = E[(Y - E[Y|X])^2] + E[(E[Y|X] - f(X))^2]$$

第一项是不可约方差。第二项通过设 $f(X) = E[Y|X]$ 来最小化。平方误差下的最优预测器就是条件均值。

这有一个深远的实际含义。当你掷一个公平骰子 10,000 次，训练一个神经网络对结果最小化平方误差，它会预测 3.5。骰子能落在 3.5 吗？不能。但 3.5 是最小化期望平方误差的值。网络在计算的是**期望**，而不是下一次的具体实现值。

为什么神经网络在学习这种条件期望方面特别优于更简单的模型？通用近似定理。一个具有足够神经元的单隐藏层前馈网络可以以任意精度近似 $\mathbb{R}^n$ 紧致子集上的任何连续函数。对于多层深度网络，这种近似在所需参数数量上呈指数级更高效。

这意味着：如果你的输入特征和目标变量之间存在任何平滑的数学关系，一个架构合理的神经网络就能找到它。问题从来不在于网络能否学到这个函数。问题在于你想让它学的函数是否在时间上足够稳定，值得去学。

## 第二部分：为什么价格预测会失败，以及该怎么做

这是本文最重要的一节。这里描述的错误几乎被每一位第一次尝试实现神经网络的交易者所犯。理解它为什么失败，是一切有效方法的前提。

失败模式是这样的：取 500 天的收盘价，喂进一个 LSTM，让它预测第 501 天。

样本内，预测看起来平滑且接近实际价格。样本外，模型预测出一个大致恒定的值，或回归到近期均值，而价格则走向完全不同的地方。模型看起来什么都没学到。

这不是模型的失败，而是数据分布的失败。

决定市场收益的分布在时间上持续变化。在左侧体制上训练的模型学到了错误的期望函数，无法适用于右侧体制。

回顾第一部分：神经网络学到的是 $E[Y|X]$，即给定 $X$ 时 $Y$ 的条件期望。这个期望只有在数据生成分布 $P(Y|X)$ 在时间上稳定时才有意义。如果那个分布发生了偏移，模型从历史数据中学到的条件期望就不再描述当前的期望。

形式化地说，这是**非平稳性**问题。一个时间序列 $\{X_t\}$ 被称为平稳的，如果其联合分布 $P(X_{t_1}, X_{t_2}, ..., X_{t_n})$ 对时间平移具有不变性。金融价格序列在最强的意义上都是非平稳的。决定 2008 年股票收益的分布与决定 2021 年收益的分布结构性地不同。均值、方差、自相关和尾部行为都随着体制、流动性、波动率聚集和宏观条件而变。

其后果在价格预测神经网络的每次回测中都清晰可见。在 2015 到 2019 年数据上训练的模型学到的是那个体制的期望结构。当分布在 2020 年发生偏移时，模型在拟合一个移动目标。它的预测总是以系统性方式错误，这揭示了它在建模的是过去的分布，而不是当前的分布。

**解决方案是什么？**

特征工程，产生平稳或接近平稳的输入。目标变量本身也应该被构造为近似平稳的。

对于**输入**，在不同市场体制下表现出合理平稳性的特征包括：

- 多窗口对数收益率：$r_t = \ln(P_t / P_{t-k})$，其中 $k \in \{1, 5, 20\}$
- 波动率比率：$\sigma_{short} / \sigma_{long}$，其中每个 $\sigma$ 是不同窗口上的滚动已实现波动率
- 经波动率归一化的动量信号：$r_t / \sigma_t$，收益除以已实现风险
- 成交量 z-score：$(V_t - \mu_V) / \sigma_V$，在滚动窗口上计算
- 基于价差的信号：买卖价差相对其历史分布，或从成交价与中间价计算的有效价差
- 体制指标：VWAP 偏离、距滚动高点和低点的距离、隐含波动率与实际波动率之比

对于**目标变量**，不要预测下一期价格，而是将下一期方向预测为二分类问题：经风险调整的收益是否为正？或者预测下一期收益经其近期分布 z-score 标准化后的值。这两个目标都比原始价格甚至原始收益更稳定。

检验一个特征是否可用的实际方法：对它进行**增广 Dickey-Fuller 检验**。若 p 值低于 0.05，说明该序列是平稳的。对于未通过检验的特征，对其进行一阶差分或除以滚动标准差做归一化。

**实现说明：** 在 Python 中，代码如下：

```python
from statsmodels.tsa.stattools import adfuller
import numpy as np

def check_stationarity(series, name):
    result = adfuller(series.dropna())
    print(f"{name}: ADF statistic={result[0]:.4f}, p-value={result[1]:.4f}")
    return result[1] < 0.05

# 特征工程示例
returns = df['close'].pct_change()
vol_20 = returns.rolling(20).std()
vol_5 = returns.rolling(5).std()

features = {
    'return_1d': returns,
    'return_5d': df['close'].pct_change(5),
    'vol_ratio': vol_5 / vol_20,
    'momentum': returns / vol_20,
    'volume_zscore': (df['volume'] - df['volume'].rolling(20).mean()) / df['volume'].rolling(20).std()
}

for name, series in features.items():
    is_stationary = check_stationarity(series, name)
```

每一个未通过平稳性检验的特征，都会导致你的模型学到错误的分布。

## 第三部分：面向序列化市场数据的 LSTM 架构

LSTM 的遗忘门、输入门和输出门控制哪些信息在时间步之间持续存在，使模型能在数周的市场数据中保持上下文。

市场数据是序列化的。事件的顺序承载着快照所无法承载的信息。过去五分钟发生的事通过自相关、动量、均值回归和微观结构动态与接下来五分钟发生的事相连。你所使用的架构必须能够从这种序列结构中学习。

标准前馈网络将每个输入独立对待。当你给它第 100 天的特征向量时，它对第 1 到第 99 天发生了什么一无所知。对于非序列数据（如第一部分的掷骰子例子），这没问题。对于金融市场的时间序列数据，这丢弃了你数据集中最重要的信息。

**循环神经网络（RNN）** 通过将隐藏状态向前传递来应对这一点。在每个时间步 $t$，隐藏状态 $h_t$ 计算为：

$$h_t = \tanh(W_h \cdot h_{t-1} + W_x \cdot x_t + b)$$

隐藏状态编码了网络从第 1 步到第 $t-1$ 步学到的所有内容，并将其与当前输入 $x_t$ 结合。这就是记忆机制。但基本的 RNN 存在**梯度消失**问题：梯度在沿时间反向传播时呈指数级衰减，使得学习跨越超过几个时间步的依赖关系实际上不可能。

**LSTM** 通过门控记忆架构解决了这个问题。LSTM 不是只有一个隐藏状态，而是同时维护隐藏状态 $h_t$ 和细胞状态 $c_t$。细胞状态是长期记忆，隐藏状态是工作记忆。三个学习的门控制信息流动：

**遗忘门**：$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$
这个门决定丢弃上一细胞状态的多少比例。当市场在体制之间转换时，遗忘门允许模型释放过时的模式并重置其理解。

**输入门**：$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$，$g_t = \tanh(W_g \cdot [h_{t-1}, x_t] + b_g)$
这些门决定将什么新信息写入细胞状态。

**输出门**：$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$，$h_t = o_t \odot \tanh(c_t)$
这个门决定从细胞状态输出什么。

细胞状态更新结合了遗忘和新写入：$c_t = f_t \odot c_{t-1} + i_t \odot g_t$

这种架构使 LSTM 能够在 50、100 或更多时间步的序列中保持相关上下文，而不会出现梯度消失问题。对于日频交易策略，这意味着模型可以学到"三周前的某种波动率压缩模式预示着今天的某种特定突破行为"。没有任何基于指标的系统能够捕捉到这种复杂度下的关系。

**完整的 PyTorch LSTM 实现：**

```python
import torch
import torch.nn as nn
import numpy as np
from sklearn.preprocessing import StandardScaler

class TradingLSTM(nn.Module):
    def __init__(self, input_size, hidden_size=64, num_layers=2, dropout=0.2):
        super(TradingLSTM, self).__init__()
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        
        self.lstm = nn.LSTM(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            dropout=dropout,
            batch_first=True
        )
        
        self.dropout = nn.Dropout(dropout)
        self.fc = nn.Linear(hidden_size, 1)
        self.sigmoid = nn.Sigmoid()
    
    def forward(self, x):
        h0 = torch.zeros(self.num_layers, x.size(0), self.hidden_size)
        c0 = torch.zeros(self.num_layers, x.size(0), self.hidden_size)
        
        out, _ = self.lstm(x, (h0, c0))
        out = self.dropout(out[:, -1, :])
        out = self.fc(out)
        return self.sigmoid(out)

def prepare_sequences(features, target, lookback=10):
    X, y = [], []
    for i in range(len(features) - lookback):
        X.append(features[i:i+lookback])
        y.append(target[i+lookback])
    return np.array(X), np.array(y)
```

回溯窗口是一个关键的超参数。对于日频策略，从 10 到 20 个交易日的窗口开始。对于在 5 分钟 K 线上操作的日内策略，24 个周期的回溯覆盖了两个交易小时的上下文。最优回溯取决于你试图捕捉的模式的时间尺度，必须通过验证性能来经验性地确定。

## 第四部分：在不欺骗自己的前提下训练

当训练损失持续下降而验证损失上升时，模型已经越过了过拟合的阈值。早停法在验证损失最低点保存权重。

构建模型是容易的部分。危险的部分是评估它是否真的学到了真实的模式，还是只是记住了训练数据中的噪声。

**过拟合**是机器学习在金融中的核心失败模式。一个过拟合的模型在其训练数据中找到了不能泛化的模式。在训练数据上它表现优异。在新数据上它表现如同随机或更差。关键问题是，过拟合的样本内表现看起来和真正的 alpha 优势一模一样。你无法仅通过看训练指标来区分它们。

解决方案是严格的**三路数据划分**，按特定的顺序使用。

**训练集**是梯度下降运行的地方。模型在训练过程中反复看到这些数据并据此调整参数。永远不要在这个集上评估泛化性能。

**验证集**是模型从未在其上训练，但你在训练过程中持续监控的数据。每个 epoch 之后，计算验证损失。当验证损失停止改善并开始上升，而训练损失持续下降的那一刻，你就找到了过拟合阈值。立即停止训练，并保存验证损失最低的那个 epoch 的模型权重。这就是**早停法**，它是你对抗过拟合的主要防线。

**测试集**是模型从未以任何形式影响过的数据。你只用它**一次**：在所有架构决策、所有超参数选择和所有特征工程决策都已使用训练集和验证集最终确定之后。测试集的结果才是你对实盘表现的诚实估计。使用测试集来做额外的设计决策会使它失效。

对于金融时间序列，这些划分必须是**顺序的**。训练期在时间上最早。验证期紧随其后。测试期是最近的。随机化划分会让未来信息污染训练过程，这是一种前视偏差，将保证你的回测看起来比实盘表现更好。

**完整的带早停法的训练循环：**

```python
def train_model(model, train_loader, val_loader, epochs=100, lr=0.001, patience=10):
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    criterion = nn.BCELoss()
    scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
        optimizer, patience=5, factor=0.5
    )
    
    best_val_loss = float('inf')
    best_weights = None
    patience_counter = 0
    
    for epoch in range(epochs):
        model.train()
        train_loss = 0
        for X_batch, y_batch in train_loader:
            optimizer.zero_grad()
            predictions = model(X_batch).squeeze()
            loss = criterion(predictions, y_batch)
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
            optimizer.step()
            train_loss += loss.item()
        
        model.eval()
        val_loss = 0
        with torch.no_grad():
            for X_batch, y_batch in val_loader:
                predictions = model(X_batch).squeeze()
                loss = criterion(predictions, y_batch)
                val_loss += loss.item()
        
        val_loss /= len(val_loader)
        scheduler.step(val_loss)
        
        if val_loss < best_val_loss:
            best_val_loss = val_loss
            best_weights = model.state_dict().copy()
            patience_counter = 0
        else:
            patience_counter += 1
            if patience_counter >= patience:
                print(f"Early stopping at epoch {epoch}")
                break
    
    model.load_state_dict(best_weights)
    return model
```

此实现中包含梯度裁剪有特定原因。当学习序列较长时，LSTM 梯度可能在训练期间爆炸。将梯度范数裁剪到最大值 1.0 可以防止此问题，而不会显著影响收敛速度。

对于交易而言，最严格的评估框架是**滚动前向验证**。与单一的训练-验证-测试划分不同，你将一个训练窗口在时间上向前滚动，训练，在紧接的后续时期上测试，然后推进窗口并重复。所有窗口拼接起来的样本外预测，给你一个模型如果在每个历史时刻实盘部署将如何表现的现实估计。

**滚动前向验证：**

```python
def walk_forward_validation(features, target, train_size, test_size, step):
    all_predictions = []
    all_actuals = []
    
    for start in range(0, len(features) - train_size - test_size, step):
        train_end = start + train_size
        test_end = train_end + test_size
        
        X_train = features[start:train_end]
        y_train = target[start:train_end]
        X_test = features[train_end:test_end]
        y_test = target[train_end:test_end]
        
        scaler = StandardScaler()
        X_train_scaled = scaler.fit_transform(X_train.reshape(-1, X_train.shape[-1]))
        X_test_scaled = scaler.transform(X_test.reshape(-1, X_test.shape[-1]))
        
        model = TradingLSTM(input_size=X_train.shape[-1])
        # 在此训练模型
        
        with torch.no_grad():
            preds = model(torch.FloatTensor(X_test_scaled))
        
        all_predictions.extend(preds.numpy())
        all_actuals.extend(y_test)
    
    return np.array(all_predictions), np.array(all_actuals)
```

一个构建良好的模型在优质特征上的预期方向准确率是 **52% 到 57%**。这听起来不起眼。一个 54% 的方向信号，配合 1.0 以上的夏普比率，在数百笔交易中以正确的凯利推导仓位规模一致应用，其复利回报在多年度时间周期上超过大多数主观交易者。优势在于一致性和规模，而不在于任何单一信号的幅度。

```python
def build_features(df):
    features = pd.DataFrame(index=df.index)
    
    close = df['Close']
    volume = df['Volume']
    returns = close.pct_change()
    
    features['return_1d'] = returns
    features['return_5d'] = close.pct_change(5)
    features['return_20d'] = close.pct_change(20)
    
    vol_5 = returns.rolling(5).std()
    vol_20 = returns.rolling(20).std()
    features['vol_ratio'] = vol_5 / vol_20
    features['momentum_norm'] = returns / vol_20
    
    features['volume_zscore'] = (
        (volume - volume.rolling(20).mean()) / volume.rolling(20).std()
    )
    
    high_low_range = (df['High'] - df['Low']) / close
    features['range_norm'] = high_low_range / high_low_range.rolling(20).mean()
    
    sma_5 = close.rolling(5).mean()
    sma_20 = close.rolling(20).mean()
    features['sma_ratio'] = sma_5 / sma_20 - 1
    
    target = (returns.shift(-1) > 0).astype(int)
    
    features = features.dropna()
    target = target.loc[features.index]
    
    return features, target
```

**第 4 步：模型评估**

除了方向准确率，使用对交易有实际意义的指标来评估你的模型。

```python
from sklearn.metrics import accuracy_score, roc_auc_score
import pandas as pd

def evaluate_trading_signal(predictions, actuals, returns):
    pred_direction = (predictions > 0.5).astype(int)
    
    accuracy = accuracy_score(actuals, pred_direction)
    auc = roc_auc_score(actuals, predictions)
    
    signal = np.where(pred_direction == 1, 1, -1)
    strategy_returns = signal * returns
    
    sharpe = strategy_returns.mean() / strategy_returns.std() * np.sqrt(252)
    
    cumulative = (1 + strategy_returns).cumprod()
    rolling_max = cumulative.cummax()
    drawdown = (cumulative - rolling_max) / rolling_max
    max_drawdown = drawdown.min()
    
    print(f"方向准确率: {accuracy:.4f}")
    print(f"AUC-ROC: {auc:.4f}")
    print(f"年化夏普比率: {sharpe:.4f}")
    print(f"最大回撤: {max_drawdown:.4f}")
    
    return accuracy, sharpe, max_drawdown
```

**第 5 步：从信号到仓位管理**

一个神经网络信号本身不是交易策略。你需要仓位管理。凯利分数将你模型的优势转化为最优下注规模：

> **$f^* = (p \times b - q) / b$**

其中 $p$ 是方向准确率，$q = 1 - p$，$b$ 是平均盈亏比。在实践中，使用半凯利以考虑参数估计误差。无论凯利公式建议什么，永不在单一信号上冒超过 2% 资金的风险。

**第 6 步：持续监控与重训练**

一个在历史数据上训练的模型从部署的那一刻起就开始退化。市场体制会转移。模型学到的条件期望越来越差地近似当前的期望。你必须实现一个监控系统，追踪实盘表现对比你的验证基线，并在分布偏移超出可接受阈值时触发重训练。

标准指标是 Kolmogorov-Smirnov 统计量，比较你最近的实盘预测分布与历史验证分布。当 KS 统计量超过 0.1 时，用最新数据重训练并在继续部署前重新评估。

对于预测市场和加密货币，体制变化比股票市场更频繁也更剧烈。在 90 天滚动窗口上重训练，每 30 天做一次滚动前向重评估，是一个合理的基线。

神经网络不会给你一个水晶球。它们给你的是一个系统化的、数学严谨的框架，用于从历史数据中提取市场行为的条件期望。当特征是平稳的，架构适合序列数据，训练是规范且经过正确验证的，信号以适当的仓位管理来调整规模时，结果就是一个一致的、可扩展的、可复现的 alpha 优势。
