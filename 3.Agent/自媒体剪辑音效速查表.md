# 自媒体剪辑音效速查表

来源：济南大杉（IP打造），抖音。按场景匹配常用音效。

## 场景 × 音效对照

| 场景 | 音效 | 用途 |
|:---|:---|:---|
| 说脏话 | 消音/哔声 | 遮挡敏感词，制造幽默效果 |
| 轻松转场 | 小鸟声 | 切换轻松话题，自然过渡 |
| 想骂人 | 快板声 | 节奏感强，制造吐槽氛围 |
| 超无语 | 开枪声 | 吐槽重击，强调无力感 |
| 强调/震惊 | 特效声 | 信息突出，吸引注意 |
| 搞笑/荒诞 | 牛叫声 | 离谱场景，荒诞效果 |
| 问问题 | 疑问声 | 抛出问题，引导思考 |
| 再思考 | 计算声 | 思考过程，侦探感 |
| 打字幕 | 键盘声 | 文字弹出，信息同步 |
| 要转场 | 嗖呼声 | 画面切换，节奏变化 |
| 悬疑感 | 长音咚 | 制造悬念，紧张氛围 |
| 做开场 | 空旷咚 | 开场定调，大场面感 |
| 说惊吓 | 心头震 | 恐怖/惊悚，心跳加速 |

## 使用原则

- 一个视频不要超过 3-4 种音效，否则噪音化
- 音效的音量要低于人声，压到背景层
- 同一类场景用同一音效，形成观众的条件反射
- 音效的节奏点要卡在画面切换或台词落点
