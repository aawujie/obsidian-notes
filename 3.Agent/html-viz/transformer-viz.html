2编码器单层详解

数据流经一个编码器层：输入与输出形状相同 (n × d)，便于堆叠。点击每步查看说明。

(n × d) → 输入：n 个词，每个 d 维向量
(n × d) → Multi-Head Self-Attention：每个词关注句中所有词
(n × d) → 残差连接 + LayerNorm
(n × d) → 前馈网络 (FFN)：每个位置独立通过 2 层 MLP
(n × d) → 残差连接 + LayerNorm → 输出

4残差连接与 LayerNorm

残差连接：梯度高速公路

类比：像绕过城镇的高速公路，梯度可以直接"抄近路"流回，避免深层网络梯度消失。

输入 x → 子层 F(x) → 输出
x ──────────────→ + ← 残差：输出 = x + F(x)

LayerNorm vs BatchNorm

5前馈网络 (FFN)

FFN 是简单的 2 层 MLP，对每个位置独立施加相同变换。类比：每个词都经过同样的"思考流程"。

输入 (d) → Dense(4d) → ReLU → Dense(d) → 输出 (d)

扩展 4 倍 → 非线性 → 压缩回原维度。参数量大但计算简单（无注意力矩阵）。
