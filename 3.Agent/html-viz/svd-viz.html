奇异值分解 SVD

Singular Value Decomposition — 任意矩阵的终极分解

1为什么需要 SVD？EVD 的局限

特征值分解 (EVD) 很强大，但有致命限制：只能处理方阵，且要求可对角化。

现实中遇到的矩阵往往是 m×n 的"非方阵"：图像像素矩阵、词向量矩阵、神经网络权重矩阵……

⚠️ EVD 的限制

  • 只能处理 n×n 方阵
  • 需要 n 个线性独立的特征向量
  • 可能有复数特征值
  • 不能保证特征向量正交

✅ SVD 的优势

  • 适用于任意 m×n 矩阵
  • 永远存在，不会失败
  • 奇异值永远是非负实数
  • U 和 V 都是正交矩阵
SVD 是 EVD 的"超级升级版"。对于方阵，两者有深刻联系：A 的奇异值 = AᵀA 的特征值的平方根。

2SVD 公式：A = UΣVᵀ

A = U Σ Vᵀ
任意 m×n 矩阵 A 都可以这样分解
U

左奇异向量矩阵

列向量是 AAᵀ 的特征向量

形状: m × m（正交矩阵）
Σ

奇异值对角矩阵

对角线上是奇异值 σ₁ ≥ σ₂ ≥ … ≥ 0

形状: m × n（非方形对角）
Vᵀ

右奇异向量矩阵

行向量是 AᵀA 的特征向量

形状: n × n（正交矩阵）
奇异值 σᵢ = √λᵢ(AᵀA)，它们衡量各方向上的"拉伸强度"。最大奇异值 = 矩阵的谱范数。

3几何核心：单位圆变椭圆

SVD 最美的几何含义：任何矩阵变换都把单位球变成椭球。椭球的半轴长度 = 奇异值，方向 = 奇异向量。

💡 动画在做什么？
单位圆上采样了 200 个点，每个点是一个向量 [cos θ, sin θ]。
滑动 t：每个点从"原始位置"线性插值到"矩阵 A 作用后的位置"。

💡 矩阵的列是什么？
矩阵 A 的每一列是一个列向量，代表"标准基向量被变换后落在哪里"：
  • 第一列 = [1, 0] 变换后的位置
  • 第二列 = [0, 1] 变换后的位置

任意向量 [x, y] 变换后 = x × 第一列 + y × 第二列
例：A = [[3,1],[1,2]]，变换 [2, 1]：
  = 2×[3,1] + 1×[1,2] = [6,2] + [1,2] = [7, 4]

所以两列是"积木"，任何点的变换结果都是它们的线性组合，权重就是该点的 x 和 y。

5截断 SVD：低秩近似

SVD 最强大的应用：只保留前 k 个奇异值，得到最优的低秩近似矩阵 Aₖ。

A ≈ Aₖ = u₁σ₁v₁ᵀ + u₂σ₂v₂ᵀ + … + uₖσₖvₖᵀ
Eckart–Young 定理：Aₖ 是所有秩-k 矩阵中最接近 A 的（按 Frobenius 范数）

Σ 是怎么从这张 32×32 图算出来的？
1
把图像当作矩阵 A（32×32）
每个像素亮度值 = 矩阵的一个元素，第 (i,j) 行列 = 第 i 行 j 列像素。
2
计算 AᵀA（32×32 对称矩阵）
AᵀA 的 (i,j) 元素 = A 的第 i 列和第 j 列的点积，即 ∑ₖ A[k][i]·A[k][j]。结果一定是对称半正定矩阵，特征值 ≥ 0。
3
对 AᵀA 做特征值分解 → 得到 λ₁ ≥ λ₂ ≥ … ≥ λ₃₂ ≥ 0
本页代码用 Jacobi 迭代法：每轮找最大的非对角元素 a[p][q]，用一个旋转消掉它，反复 20 轮后矩阵趋近对角形式，对角元素就是特征值 λᵢ。
4
取平方根 → σᵢ = √λᵢ
λᵢ 是"拉伸量的平方"，σᵢ 是实际拉伸幅度。32 个 σᵢ 填入 Σ 的对角线，其余全为 0。
为什么要绕道 AᵀA？ 因为 A 是 32×32 方阵时可以直接求特征值——但如果 A 是 m×n 非方阵（如 100×200 的图），就无法直接特征值分解，而 AᵀA 始终是 n×n 方阵，可以正常求。SVD 本质上是把任意形状矩阵的分解问题，转化成一个方阵的特征值问题。
💡 图像怎么变成矩阵的？
灰度图像每个像素 = 一个 0~1 的亮度值（0=黑，1=白）。32×32 图像 = 32×32 矩阵。
k 越小，左侧矩阵数值越模糊（接近全图均值）；k=32 时近似 = 原图。
存原图需 1024 个数字，k 秩近似只需 k×(32+32+1) 个数字。

6SVD 与 LoRA 的关系

LoRA 训练时不计算 SVD——SVD 是理论依据，LoRA 是工程实现。

LoRA：用低秩矩阵近似权重变化 ΔW
W = W₀ + ΔW  ≈  W₀ + BA
W₀ 冻结不训练  |  B: m×r  |  A: r×n  |  r ≪ min(m,n)  |  参数量 m×n → r×(m+n)
① SVD 分析（理论来源）

研究者对微调完的模型取出 ΔW，对它做 SVD，发现大多数奇异值接近 0——说明 ΔW 天然低秩，少量方向就能描述微调效果。

② LoRA 约束（工程实现）

既然 ΔW 反正低秩，直接把它写成 B×A，训练时只更新 B 和 A。不显式算 SVD，但 B×A 在充分训练后会自动对齐最重要的 r 个奇异值方向。

为什么"前 r 个奇异值方向"是最重要的？  SVD 算完后奇异值按 σ₁ ≥ σ₂ ≥ … 降序排好，σᵢ 越大 = 这个方向携带信息越多。 Eckart–Young 定理：在所有秩-r 矩阵里，截断前 r 个奇异值得到的 Aᵣ 是最接近原矩阵的（Frobenius 范数最小）。LoRA 的 B×A 在理想训练下收敛到同样的 r 个方向。

奇异值 σᵢ 是怎么算出来的？

关键思路：把"非方阵无法求特征值"的问题转化成方阵特征值问题。

1 构造 AᵀA（n×n 对称半正定矩阵）
AᵀA → 对称矩阵，特征值 λᵢ ≥ 0 永远成立
A 是 m×n，AᵀA 是 n×n。无论 A 是什么形状，AᵀA 都是方阵且可以做特征值分解
为什么 λᵢ ≥ 0？对任意向量 x：  xᵀ(AᵀA)x = (Ax)ᵀ(Ax) = ‖Ax‖² ≥ 0，所以 AᵀA 是半正定的，特征值不可能为负。
2 对 AᵀA 做特征值分解，取平方根
σᵢ = √ λᵢ (AᵀA)
奇异值 = AᵀA 特征值的平方根，按降序排列 σ₁ ≥ σ₂ ≥ … ≥ 0
3 奇异向量的来源
右奇异向量 vᵢ（V 的列）
AᵀA · vᵢ = λᵢ · vᵢ

vᵢ 就是 AᵀA 的特征向量，描述输入空间的主方向

左奇异向量 uᵢ（U 的列）
uᵢ = A·vᵢ / σᵢ

直接由 vᵢ 推出来，描述输出空间的主方向

⚙ 代码用的算法：Jacobi 迭代
Jacobi 法对 AᵀA 反复做旋转消元：每次找最大的非对角元素 aₚq，用一个 2×2 旋转矩阵 G 把它消成 0。
迭代若干轮后矩阵趋近于对角形式，对角元素 = λᵢ，旋转矩阵的乘积 = 特征向量矩阵 V。

G(p,q,θ)ᵀ · AᵀA · G(p,q,θ) → 消掉 (p,q) 处的元素
不断重复，直到所有非对角元素 < ε，本页代码迭代 20 轮。

8在深度学习中的应用

LoRA / QLoRA 微调

用低秩矩阵近似权重更新。LoRA 的 r 参数直接对应 SVD 中保留的奇异值数量。

权重矩阵压缩

对训练好的权重矩阵做 SVD，只保留前 k 个奇异值，减少模型大小同时保留核心信息。

谱范数 (σ₁) 归一化

用最大奇异值 σ₁ 归一化权重矩阵，控制模型 Lipschitz 常数，稳定 GAN 训练。

推荐系统矩阵分解

用 SVD 分解用户-物品交互矩阵，发现隐含的"主题"，实现协同过滤推荐。

词向量 / 语义分析

LSA（潜在语义分析）对词频矩阵做 SVD，降维提取语义主题。Word2Vec 间接使用类似思想。

梯度裁剪 & 初始化

分析权重矩阵的奇异值谱，设计更好的初始化方案（如正交初始化），避免梯度消失。
