> 硅谷101播客 | 2026-04-17 | 主播 Yiwen，嘉宾 房天语（哈佛科技史博士生）、李狄皓

## 一、斯坦福评论：思想网络的起点

1987年，大三学生 Peter Thiel 与 Norman Book 创办《斯坦福评论》。背景：80年代加州校园左翼进步主义盛行，全国层面里根执政。

**资金来源**：欧林基金会——军火商 John Olin 在80岁时创立，目标是在全美大学扶持右翼学生独立媒体。基金会死后25年内全部散尽并关停。

**风格**：强烈挑衅性，指名道姓批评教授和同学，故意制造冲突。这种风格成为 Thiel 整个网络的文化基因。

## 二、Thiel 的哲学三支柱

### 1. 勒内·吉拉尔（René Girard）—— 模仿欲望理论

核心：人没有自发欲望，所有欲望都是模仿他人而来。一切人际冲突和暴力源自模仿导致的竞争。

**商业落地：**

| 决策 | 吉拉尔理论解释 |
|:---|:---|
| PayPal vs X.com 合并 | 两人做相似产品 = 模仿竞争 → 合并垄断 |
| 投资Facebook | 社交网络 = 模仿性增长机器 |
| 《从零到一》 | 不要竞争，要垄断 |
| PayPal 原始意图 | 货币 = 模仿欲望载体 → 创造不受政府控制的货币 |

Thiel 的态度：承认模仿根植人性，但刻意拒绝模仿他人，同时利用模仿机制从中获利。

### 2. 卡尔·施密特（Carl Schmitt）—— 敌我划分 + 例外状态

核心：自由主义最大问题是否认/掩盖"敌我关系"。主权 = 决定何为例外状态的人，在例外状态下可绕过民主程序。

**商业落地——Palantir 的哲学基础：**

- 911 = Thiel 眼中的"例外状态"——敌人已被恐怖分子划定
- 《爱国者法案》大规模侵犯公民隐私 → Thiel 认为绕过程序是必须的
- Palantir 从海量数据中检索情报 = 例外状态下的工具
-近年深度介入美国军方和政府行动（ICE 移民执法、委内瑞拉/伊朗军事行动）

### 3. 列奥·施特劳斯（Leo Strauss）—— 隐微写作 + 深层政治

核心：哲学与政治必须分开。哲学家采用"隐微写作"——两层含义：字面意思和隐藏深层意思，只有少数天选之人能读懂。

**Thiel 的施特劳斯主义实践：**

- 民主制度需保留，但必须有一套制度之下运行的隐性政治（deep state）
- Thiel 自认为"暗中操作社会进展"的人
- Palantir 的技术能力正是在海量数据中提取浅层之外的深层信息
- **关键矛盾**：公开行为和真实信念可能毫无关系 → 2016 高调支持 Trump 令人费解

## 三、战术导师：David Horowitz——用左派的办法打败左派

Horowitz：共产党员家庭出身 → 60年代左翼大知识分子 → 180度转向右派。

核心教导：
- 不要守规矩，不要绅士辩论
- 创造叙事，主动挑衅，指名道姓攻击
- 用左派的办法打败左派

## 六、岩桥网络与 1789 资本：从媒体到政治

| 投资组合 | 说明 |

策略从传统精英（Vance）扩展到新时代网红经济——影响力 = 政治筹码。

## 七、King Maker 角色与选拔机制

选拔漏斗：斯坦福评论 → Thiel Fellowship → 风投 → 政治捐赠

**Thiel Fellowship 申请名问**："什么事情大多数人都同意，但你反对？"——思想过滤机制，筛选敢于跟别人想得不一样的人。

- 为 Vance 参议员竞选花 1500 万美元 + 拉拢 Trump 背书
- 同时给 Hawley、Blake Masters 多人下注
- Vance 只是众多棋子之一

**Thiel 不亲自从政原因**：
1. 施特劳斯主义者：真正掌权的人不能暴露在前台
2. 缺乏选民亲和力
