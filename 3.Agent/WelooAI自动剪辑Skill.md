# WelooAI 自动剪辑 Skill——AI 剪辑的落地实践

## 一句话总结

WelooAI 做了一套本地自动剪辑 Skill，可以被 Agent（OpenClaw/Claude Code）调用，从素材理解到剪辑规划到生成剪映草稿工程，全链路自动化。

## 工作流程

```
素材目录 → 视频内容理解 → 自动筛选片段 → 剪辑规划 → 生成剪映草稿工程
```

1. **素材输入**：指定素材文件夹，Agent 读取视频
2. **内容理解**：通过 Twelve Labs API 分析视频，识别主体、动作、场景、情绪、适合剪辑的片段
3. **自动筛选**：根据提示词匹配主题，筛选出相关片段（不是看文件名，是真正读懂内容）
4. **剪辑规划**：LLM 根据提示词生成结构化的剪辑方案和可复用的剪映配置文件
5. **输出草稿**：直接生成剪映草稿工程，可以在剪映里继续手动修改

## 技术架构

| 组件 | 作用 | 必需？ |
|:---|:---|:---|
| 本地 Skill | 核心逻辑，素材管理、剪辑规划、草稿生成 | 必需 |
| Twelve Labs API | 视频内容理解引擎，识别画面中的主体/动作/情绪 | 可选（无素材分析需求可跳过） |
| 剪映专业版 | 本地运行，接收草稿工程 | 必需 |
| Agent（OpenClaw/Claude Code） | 调用 Skill，LLM 驱动提示词指令 | 必需 |

## 关键特性

- **真正读懂内容**：不是盲剪，是分析视频画面内容后筛选片段
- **灵活可控**：提示词指定需要什么就调什么，不需要的自动跳过（如"不要字幕"则字幕功能不触发）
- **本地化**：跑在本地，不依赖云端剪辑服务
- **输出草稿非成品**：最终生成剪映草稿，人工可以继续调整，不是一键出片
- **提示词驱动**：Agent 核心是 LLM，提示词越清晰，结果越完美

## 局限

1. 需要本地安装剪映专业版
2. 需要 Twelve Labs API Key（视频理解能力的前提）
3. "现阶段这个工具还不是特别完美"——作者自述
4. 本质是 Skill 不是独立产品，依赖 Agent 生态

## 与之前讨论的关联

之前我们讨论过"剪映有没有 API"→ 结论是没有。WelooAI 这条路径走的是**绕过去的方案**：不通过剪映 API，而是通过理解素材 + LLM 规划 + 直接写入剪映草稿文件来模拟"自动剪辑"。这可能是目前最接近"把素材丢给 AI 自动剪辑"的实践。
