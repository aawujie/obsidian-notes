# AI 编码自主性进化曲线

![[ai-coding-autonomy-timeline.jpg]]

---

## 一、图表核心信息

这张图追踪的是 **AI 模型从辅助工具到独立工程师的进化轨迹**，衡量标准不是跑分，而是**能独立完成多长周期的编码任务**。

纵轴采用对数尺度——每个刻度的跨越代表一个数量级的跃迁，不是渐进式的。

---

## 二、三条趋势线

| 颜色     | 代表              | 关键数据点                                                      |
| :----- | :-------------- | :--------------------------------------------------------- |
| 🔵 蓝色  | **OpenAI 系**    | GPT-3 → GPT-4 → o1 → GPT-5 → Agent-0/1/2                   |
| 🔴 红色  | **Anthropic 系** | Claude 2 → Claude 3 → Claude 4.6 Sonnet/Opus → Agent-0/1/2 |
| ⚪ 延伸虚线 | **预测趋势**        | 2026 年后两线趋于汇合，进入 "Agent 时代"                                |

### 蓝色（OpenAI 系）每个点的含义

| 数据点 | 时间 | 能力跃迁 |
|:---|:---|:---|
| **GPT-3** | 2021 | 首次展示 LLM 可以写代码，但只能做单个函数，需要精确 prompt |
| **GPT-4** | 2023 | 多文件理解、调试能力、完整脚本编写，从"补全"变成了"解决问题" |
| **o1** | 2024 | 引入推理链（chain-of-thought），能在执行前做规划，任务完成率大幅提升 |
| **GPT-5** | 2025-2026 | 大幅扩展上下文窗口 + 自主工具调用，能独立完成小时到天级的工程任务 |
| **Agent-0/1/2** | 2027-2028 | 不是单一模型，而是**Agent 系统**——模型 + 规划 + 工具链 + 记忆 + 自我纠错的整合体 |

### 红色（Anthropic 系）每个点的含义

| 数据点 | 时间 | 能力跃迁 |
|:---|:---|:---|
| **Claude 2** | 2023 | 长上下文先驱（100K tokens），能处理完整代码库，但推理深度有限 |
| **Claude 3** | 2024 | 多模态能力加入，代码生成质量追平 GPT-4，在长文档理解上领先 |
| **Claude 4.6 Sonnet** | 2025 | 编码速度与准确率大幅提升，Cursor/CC 的主力模型，可独立完成小时级任务 |
| **Claude 4.6 Opus** | 2025-2026 | 更强的深度推理和规划能力，逼近天级任务的自主完成阈值 |
| **Agent-0/1/2** | 2027-2028 | 与 OpenAI 线汇合——两家的终点是一样的：模型退居幕后，Agent 框架走上前台 |

### 延伸虚线（Agent-0/1/2）的含义

虚线不是某个具体模型，而是**三个 Agent 成熟度里程碑**：

| 层级 | 含义 | 类比 |
|:---|:---|:---|
| **Agent-0** | 模型能自主使用工具，在一个会话内完成多步骤任务 | 今天的 CC 模式——但不需要人类派任务 |
| **Agent-1** | 能拆分子任务、并行执行、处理失败重试，跨越多个会话 | 一个 junior engineer，能独立推进整个 feature |
| **Agent-2** | 长期目标驱动——给定一个目标，自行规划、分解、执行、调整，持续数周到数月 | 一个 senior engineer，能独立负责整个项目 |

**关键观察**：两条线高度平行之后汇合，说明这不是某一家的运气，而是**整个行业的系统性趋势**——模型层面趋同后，竞争转移到 Agent 框架和生态。

## 三、四个进化阶段

### Phase 1：辅助工具（2021–2023）→ 分钟级

- **代表模型**：GPT-3、Claude 2
- **能做什么**：单个函数、修一个 bug、解释一段代码
- **工作模式**：人类主导，AI 辅助
- **任务时长**：秒到分钟

### Phase 2：协作伙伴（2024–2025H1）→ 小时级

- **代表模型**：GPT-4、Claude 3.5、Claude 4.6
- **能做什么**：完整模块开发、测试驱动迭代、数据分析与可视化、独立调研与写作
- **工作模式**：人类派任务，AI 独立执行并汇报
- **任务时长**：几十分钟到几小时

这就是当前状态。我们用 CC 做投研调研、写脚本、生成报告的模式，落在这个阶段。

### Phase 3：独立承担（2025H2–2026）→ 天到周级

- **代表模型**：GPT-5、Claude 4.6 Opus + Agent-0/1
- **能做什么**：完整的 sprint 交付、多模块联调、独立的项目管理和依赖处理
- **工作模式**：给定方向和约束，Agent 自主拆解、执行、验收
- **任务时长**：数天到数周

### Phase 4：自主工程（2027–2028）→ 月到年级

- **代表模型**：Agent-2 及以后
- **能做什么**：从需求到上线的完整产品、自主决策架构选型、长期的维护和迭代
- **工作模式**：只需给定目标，Agent 承担全部工程过程
- **任务时长**：数周到数月甚至跨年

## 四、为什么曲线加速上翘？

对数尺度下仍能看到加速上翘，说明增长不是"每代加一点"，而是**每代跳一个数量级**：

```
GPT-3 → GPT-4：    分钟 → 十分钟（~10x）
GPT-4 → o1：       十分钟 → 小时（~6-10x）
o1 → GPT-5：       小时 → 天/周（~10-100x）
GPT-5 → Agent-2：  天/周 → 月/年（~30-100x）
```

**本质原因**：每一代模型不仅在知识量和推理能力上提升，更在**自主性、上下文窗口、工具使用、长期规划**四个维度上叠加进化。这些能力相乘而非相加。

---

## 五、曲线合并的含义

2026 年后 OpenAI 和 Anthropic 两条线开始靠拢并最终汇合——不是一家超过了另一家，而是**两条路径通向同一个终点**：

- LLM 的能力天花板足够高，两家都能够到
- 差距收窄 → 竞争从模型本身转向 Agent 框架和生态
- "谁家的模型更强" 变得不那么重要，更重要的是 "谁能把模型组织成有效的 Agent"

这正好解释了 Anthropic FSI 项目的设计逻辑——他们不卖"最强的模型"，而是卖**把模型嵌入金融工作流的完整方案**。

## 六、对我们调度模式的影响

| 时间 | 调度模式 | 举例 |
|:---|:---|:---|
| **今天** | 人类拆解任务 → 派给 CC → 验收结果 | "调研这 9 只核能标的，写报告" |
| **半年后** | 给定方向 → CC 自己拆解子任务 → 并行执行 → 汇总 | "把因子库的工程架构整理一遍，该重构的列方案" |
| **两年后** | 给目标 → Agent 自主规划 → 执行 → 维护 | "搭建一套完整的量化投研助手系统，覆盖数据/因子/回测/报告" |

---

## 七、一句话总结

> AI 编码能力正以**数量级为单位**跨越，从辅助工具到独立工程师的路径已经可见。我们现在的调度模式是过渡态——目标不是让人更会用 AI，而是让 AI 自己干完所有工程。
