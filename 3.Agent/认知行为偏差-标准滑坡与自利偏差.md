# 认知行为偏差：标准滑坡与自利偏差

> "人的自利偏差会导致你的标准滑坡"
> —— 浙江杭州交警，劝导外卖小哥闯红灯

这段话出自一段交通执法视频，外卖小哥辩称"两边没车、能确保安全"时不用等红灯。交警从四个维度逐层拆解，其中行为学部分点出了一个极具普适性的认知陷阱。

---

## 一、核心概念拆解

### 1. 自利偏差（Self-Serving Bias）

**定义：** 人倾向于把有利于自己的结果归因于自身能力，把不利结果归因于外部因素。

**在闯红灯中的体现：**
- "我能判断安全" = 高估自身感知能力
- "两边没车" = 忽视系统复杂性，只摘取支持自己结论的局部信息

**更广泛的应用：**
- 投资赚钱 → "我眼光好"；亏钱 → "市场不理性"
- 项目成功 → "我能力强"；失败 → "队友拖后腿"
- 考试考好 → "我认真复习"；考差 → "题出得偏"

---

### 2. 标准滑坡（Standards Slippage）

**定义：** 由自利偏差驱动的行为退化链条。一次"成功的例外"会降低下一次的执行标准，直至标准彻底崩塌。

**闯红灯的退化路径：**
```
第1次：认真观察四周，左看右看，确认无车 → 通过
第2次：大概扫一眼就好了，上次没事 → 通过
第N次：习惯性直接过，看都不看 → 出事
```

**关键机制：** 每次"成功"都成为降低标准的证据，过度自信逐步积累，直到某次误判造成不可逆后果。

**其他场景中的标准滑坡：**

| 场景 | 第一次 | 退化后 |
|:---|:---|:---|
| 代码质量 | 认真写测试 | "这个功能简单，不写了" |
| 健身计划 | 严格按计划练 | "今天累，少做几组" → 不去了 |
| 饮食控制 | 严格执行 | "就这一次例外" → 破防 |
| 工作汇报 | 认真准备 | "差不多就行了" |
| 安全规范 | 严格执行 | "老司机了，这步省了" |

---

### 3. 过度自信（Overconfidence Bias）

**定义：** 系统性高估自己的判断能力、预测准确度和风险控制能力。

**数据支撑：**
- 90%+ 的司机认为自己的驾驶水平高于平均水平（统计上不可能）
- 投资者普遍高估自己选股的能力
- 创业者普遍低估失败概率

**和自利偏差的关系：**
自利偏差是**归因方向**的扭曲（把好结果归功于自己），过度自信是**能力评估**的扭曲（高估自己的水平）。两者相互强化：自利偏差积累的"成功归因"，持续喂养过度自信。

---

### 4. 选择性规则遵守（Selective Compliance）

**定义：** 用个人判断决定哪条规则该遵守、哪条不用，本质是把自己的认知凌驾于系统规则之上。

**交警的反驳逻辑：**
> "如果允许你确认安全后可以闯红灯，那就等于赋予每个人自由解释安全的权利，法律的统一性就被破坏了。"

**为什么规则不能选择性遵守：**
- 规则的价值在于**可预期性**——所有人都知道红灯必停，系统才能稳定运行
- 一旦允许例外，每个人都会认为自己的例外是合理的（自利偏差）
- 社会规则是**纳什均衡**的产物，个人偏离会破坏整体均衡

---

### 5. 局部信息谬误（Partial Information Fallacy）

**交警原话：**
> "你车上看到的空旷路口，只是复杂动态系统里的一个切片，而非全部条件。"

**定义：** 人在某一时刻只能感知局部信息，却误以为掌握了全局，进而做出错误决策。

**为什么"看起来没车"不等于安全：**
- 视野盲区（柱子、大车遮挡）
- 速度感知误差（远处快速来车）
- 系统协调（绿灯期间设计了多方向联动，红灯时段有隐含通行权分配）

**投资中的类比：**
- "这只股票基本面很好" = 只看了局部信息
- 看不到的：主力资金意图、宏观政策变化、行业竞争格局...

---

### 6. 负强化陷阱（Negative Reinforcement Trap）

**定义（行为主义视角）：** 每次闯红灯没出事 = 危险信号被移除 = 行为被负强化 = 下次更容易重复。

**和标准滑坡的关系：**
负强化是标准滑坡的**机制根源**。行为被强化 → 标准降低 → 再次被强化 → 标准继续降低，形成正反馈循环，直到某次强化失效（出事）。

---

## 二、交警论证的完整逻辑链

交警从四个维度逐层反驳，层层递进：

```
法律维度：规则不具备选择性遵守
    ↓
安全维度：你的感知不等于客观安全（局部信息谬误）
    ↓
行为学维度：自利偏差 → 标准滑坡 → 过度自信积累 → 某天失误
    ↓
交通工程维度：路口是动态系统，你的闯红灯使自己成为不可控因素
```

高明之处：**没有说教"违法就是不对"，而是帮对方真正理解为什么自己的逻辑是错的。**

---

## 三、核心启示

### 对自己

1. **识别自利偏差的触发点：** 每当你觉得"就这一次例外没关系"，警惕标准滑坡的起点
2. **用系统替代判断：** 规则、checklist、流程的价值在于绕过个人判断的偏差
3. **追踪标准的变化：** 定期回问自己，某件事的执行标准有没有在悄悄降低
4. **成功不等于判断正确：** 闯红灯没出事不代表判断对了，只代表这次运气好

### 对决策

> 当一件事"感觉没问题"时，恰恰是最需要检查认知偏差的时候。
