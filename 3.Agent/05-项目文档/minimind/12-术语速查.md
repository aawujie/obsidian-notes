# 术语速查

一句话搞懂，不讲细节。

## 训练流水线

```
预训练（自监督）→ SFT（监督微调）→ DPO/PPO/GRPO（对齐）
     学语言              学对话              学品味
```

| 阶段 | 全称 | 一句话 |
|------|------|--------|
| **Pretrain** | Pre-training 预训练 | 喂海量文本，让模型学会"接下一个字"，像小孩学说话 |
| **SFT** | Supervised Fine-Tuning 监督微调 | 用人标注的问答对教模型"怎么好好回答问题" |
| **LoRA** | Low-Rank Adaptation 低秩适配 | SFT 的省钱版，只动一小部分参数就能适配新领域 |
| **DPO** | Direct Preference Optimization 直接偏好优化 | 给模型看"好回答 vs 差回答"，直接学人类偏好 |
| **PPO** | Proximal Policy Optimization 近端策略优化 | 让模型自己生成回答，裁判打分，哪个好就强化哪个 |
| **GRPO** | Group Relative Policy Optimization 分组相对策略优化 | PPO 去掉裁判助手（Critic），一组回答里互相比谁好 |
| **CISPO** | — | GRPO 的变体，loss 裁剪方式不同 |
| **蒸馏** | Knowledge Distillation 知识蒸馏 | 大模型（老师）教小模型（学生），把能力压缩到小身板里 |
| **Agent RL** | Agent Reinforcement Learning | 让模型在"多轮调工具"的场景里做强化学习 |

## 模型架构

| 术语 | 全称 | 一句话 |
|------|------|--------|
| **Transformer** | — | 大语言模型的骨架，核心是 Attention 机制 |
| **Attention** | Self-Attention 自注意力 | 每个字看一眼所有其他字，决定该关注谁 |
| **GQA** | Grouped Query Attention 分组查询注意力 | 多个查询头共享一组 KV，省显存又快 |
| **RoPE** | Rotary Position Embedding 旋转位置编码 | 用旋转的方式告诉模型每个字在第几个位置 |
| **YaRN** | Yet another RoPE extensioN | 让 RoPE 在推理时能处理训练时没见过的超长文本 |
| **RMSNorm** | Root Mean Square Normalization | 一种归一化方法，比 LayerNorm 快 |
| **SwiGLU** | Swish-Gated Linear Unit | FFN 层的激活函数，比 ReLU 效果好 |
| **MoE** | Mixture of Experts 混合专家 | 同一层放多个"专家"，每次只激活一部分，总参数大但计算少 |
| **KV Cache** | Key-Value Cache | 推理时缓存已算过的 KV，避免重复计算，加速生成 |
| **Flash Attention** | — | Attention 的高效实现，省显存跑得快 |
| **Weight Tying** | 权重共享 | 输入 Embedding 和输出 Head 用同一份权重，省参数 |

## 训练技巧

| 术语 | 一句话 |
|------|--------|
| **NTP** (Next Token Prediction) | 预训练的唯一目标：猜下一个 token |
| **Label Masking** | SFT 里只对 assistant 的回复算 loss，用户的提问不算 |
| **AMP** (Automatic Mixed Precision) | 混合用 fp16/bf16 和 fp32，省显存不掉精度 |
| **GradScaler** | 配合 fp16 用，防止梯度太小变成 0 |
| **Gradient Accumulation** | 小 batch 多攒几次梯度再更新，等效大 batch |
| **Gradient Clipping** | 梯度太大就裁掉，防止训练爆炸 |
| **Cosine LR** | 学习率按余弦曲线从高到低衰减 |
| **DDP** (Distributed Data Parallel) | 多卡并行，每张卡一份模型，数据切开各算各的 |
| **Warmup** | 开始几步 lr 从 0 慢慢涨上去，稳定起步 |

## 数据相关

| 术语 | 一句话 |
|------|--------|
| **BPE** (Byte Pair Encoding) | Tokenizer 的算法，把常见字组合成一个 token |
| **vocab_size** | 词表大小，minimind 是 6400（很小，中文够用就行） |
| **Chat Template** | 把多轮对话格式化成 `<\|im_start\|>user\n...<\|im_end\|>` 的固定格式 |
| **System Prompt** | 告诉模型"你是谁"的角色设定 |
| **`<think>`** | 思考标签，让模型先想再答（Chain of Thought） |
| **`<tool_call>`** | 工具调用标签，模型输出调用指令让外部执行 |

## 对齐相关

| 术语 | 一句话 |
|------|--------|
| **RLHF** (RL from Human Feedback) | 用人类反馈做强化学习的总称，PPO 是经典实现 |
| **RLAIF** (RL from AI Feedback) | 用 AI 打分代替人类打分 |
| **Reward Model** | 裁判模型，给回答打分（PPO 和 GRPO 都要用） |
| **Actor-Critic** | PPO 的架构：Actor 生成回答，Critic 估计价值 |
| **GAE** (Generalized Advantage Estimation) | PPO 里算"这个回答比平均水平好多少"的方法 |
| **KL Penalty** | 惩罚模型偏离原始版本太远，防止"过度优化" |
| **chosen / rejected** | DPO 数据格式：同一个问题的好回答和差回答 |
