# 位置编码：让模型知道"在哪里"

Transformer 的 Attention 是**位置无关**的——打乱 token 顺序，Attention 计算结果不变。但语言是有顺序的，"我爱你"和"你爱我"意思完全不同。

位置编码的作用：**给每个位置一个独特的"指纹"，让模型感知顺序**。

---

## 为什么需要位置编码

### 问题：Attention 的天然缺陷

```
句子 A: [我, 爱, 你]
句子 B: [你, 爱, 我]

对 Attention 来说，这两个句子完全一样！
因为 Attention 只关心"谁和谁有关系"，不关心"谁在谁前面"
```

### 解决：给每个位置打标签

```
位置 0: [我] + 位置0的编码
位置 1: [爱] + 位置1的编码  
位置 2: [你] + 位置2的编码

现在打乱顺序，编码也会跟着变，模型就能区分了
```

---

## 位置编码的演进路线

```
位置编码发展
├── 绝对位置编码
│   ├── Sinusoidal（Transformer 原版）
│   └── Learnable Positional Embedding（BERT/GPT）
│
├── 相对位置编码
│   ├── Transformer-XL（相对位置偏置）
│   ├── T5（相对位置偏置简化版）
│   ├── RoPE（旋转位置编码）← minimind 采用
│   └── ALiBi（线性偏置）
│
└── 长上下文扩展
    ├── 线性插值 (PI)
    ├── NTK-aware Scaling
    ├── YaRN ← minimind 推理采用
    └── LongRoPE
```

## 1. Sinusoidal 位置编码（Transformer 原版）

### 核心思想

用不同频率的正弦/余弦函数给每个位置编码，高频捕捉局部关系，低频捕捉全局关系。

### 公式

对于位置 `pos` 和维度 `i`：

$$
PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)
$$

$$
PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)
$$

### 直观理解

```
维度 0 (低频): 周期很长，缓慢变化 → 捕捉远距离关系
维度 1 (高频): 周期很短，快速变化 → 捕捉近距离关系

位置 0:  [0.0,  1.0,  0.0,  1.0, ...]
位置 1:  [0.1,  0.9,  0.2,  0.9, ...]
位置 2:  [0.2,  0.8,  0.4,  0.8, ...]
...
位置 1000: [...]

每个位置都有独特的"波形指纹"
```

### 优点

- 无需学习参数
- 理论上可以外推到任意长度（没见过也能算）
- 有明确的数学性质：$PE_{pos+k}$ 可以由 $PE_{pos}$ 线性变换得到

### 缺点

- 外推效果差（虽然能算，但模型没学过）
- 绝对位置，不直接表达相对关系

## 2. Learnable Positional Embedding

### 核心思想

把位置编码当可学习的参数，和词嵌入一样训练。

```python
# PyTorch 伪代码
pos_embedding = nn.Embedding(max_position, hidden_size)
```

### 优点

- 简单直接
- 模型自己学最优编码

### 缺点

- 有最大长度限制（`max_position`）
- 外推能力差（超出训练长度就懵了）
- 参数量增加（虽然很小）

### 应用

BERT、GPT-2/3 早期版本使用。

## 3. RoPE：旋转位置编码（minimind 采用）

### 核心思想

**用旋转矩阵给 Q、K 注入位置信息**。

不是把位置编码加到输入上，而是让 Q 和 K 在计算 Attention 时 "自带" 位置信息。

### 直觉：二维旋转

想象每个 token 的向量是平面上的一个点：

```
位置 0: (x, y)
位置 1: 把 (x, y) 旋转 θ 角度
位置 2: 把 (x, y) 旋转 2θ 角度
位置 m: 把 (x, y) 旋转 mθ 角度
```

旋转后的点积天然包含相对位置信息！

### 数学推导

对于二维向量 $(x, y)$，旋转矩阵：

$$
R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}
$$

推广到 $d$ 维，每两个维度一组，用不同频率旋转：

$$
\theta_i = \text{base}^{-2i/d}
$$

其中 `base` 是基底（minimind 用 $10^6$）。

### RoPE 的精妙之处

**旋转后的 Q 和 K 点积，只依赖于它们的相对距离**：

$$
q_m^T k_n = f(q, k, m - n)
$$

这意味着：
- 模型天然学到"相对位置"而非"绝对位置"
- 外推能力比绝对编码强
- 可以扩展到长上下文

### minimind 中的实现

```python
# model/model_minimind.py

def precompute_freqs_cis(dim: int, end: int, rope_base: float = 1e6):
    # 计算每维的旋转频率
    freqs = 1.0 / (rope_base ** (torch.arange(0, dim, 2)[: (dim // 2)].float() / dim))
    
    # 与位置做外积
    t = torch.arange(end)
    freqs = torch.outer(t, freqs)  # [position, dim//2]
    
    # 计算 cos 和 sin
    freqs_cos = torch.cat([torch.cos(freqs), torch.cos(freqs)], dim=-1)
    freqs_sin = torch.cat([torch.sin(freqs), torch.sin(freqs)], dim=-1)
    return freqs_cos, freqs_sin

def apply_rotary_pos_emb(q, k, cos, sin):
    def rotate_half(x):
        # 把向量后半部分取负，和前半部分交换
        return torch.cat((-x[..., x.shape[-1] // 2:], x[..., : x.shape[-1] // 2]), dim=-1)
    
    # 旋转公式: [x cos - y sin, x sin + y cos]
    q_embed = (q * cos) + (rotate_half(q) * sin)
    k_embed = (k * cos) + (rotate_half(k) * sin)
    return q_embed, k_embed
```

### RoPE 的超参数

| 参数                        | minimind 值 | 作用            |
| ------------------------- | ---------- | ------------- |
| `rope_theta`              | $10^6$     | 旋转基底，越大高频分量越多 |
| `max_position_embeddings` | 32768      | 预计算的 RoPE 表长度 |

**`rope_theta` 的影响**：
- 值大 → 高频多 → 短距离区分度好
- 值小 → 低频多 → 长距离外推能力强

## 4. 长上下文扩展技术

训练时上下文有限（如 2048），怎么让模型处理更长的文本（如 32768）？

### 4.1 线性插值 (Positional Interpolation, PI)

**思想**：把位置"压缩"进训练范围。

```
训练时最大位置: 2048
推理时要处理: 32768 (16倍)

做法: 把实际位置除以 16
位置 32768 → 当作位置 2048 处理
位置 16000 → 当作位置 1000 处理
```

公式：

$$
\theta'_i = \theta_i \cdot \frac{L_{train}}{L_{target}}
$$

**缺点**：所有频率同等缩放，高频信息损失大。

### 4.2 NTK-aware Scaling

**思想**：高频分量少压缩，低频分量多压缩。

**基于神经正切核（NTK）理论**，只缩放低频，保留高频：

```
高频维度 (捕捉局部): 几乎不压缩
低频维度 (捕捉全局): 大幅压缩
```

效果比线性插值好，但实现稍复杂。

### 4.3 YaRN（minimPE 推理采用）

**思想**：NTK-aware + 平滑过渡 + 注意力温度缩放。

minimind 中的 YaRN 实现：

```python
def precompute_freqs_cis(dim, end, rope_base, rope_scaling):
    freqs = 1.0 / (rope_base ** (torch.arange(0, dim, 2)[: (dim // 2)].float() / dim))
    
    if rope_scaling is not None:
        orig_max = rope_scaling["original_max_position_embeddings"]  # 2048
        factor = rope_scaling["factor"]  # 16
        beta_fast = rope_scaling["beta_fast"]  # 32
        beta_slow = rope_scaling["beta_slow"]  # 1
        
        if end / orig_max > 1.0:  # 需要外推
            # 计算哪些维度属于高频/低频
            inv_dim = lambda b: (dim * math.log(orig_max / (b * 2 * math.pi))) / (2 * math.log(rope_base))
            low = max(math.floor(inv_dim(beta_fast)), 0)
            high = min(math.ceil(inv_dim(beta_slow)), dim // 2 - 1)
            
            # 线性 ramp: 高频(0) → 低频(1)
            ramp = torch.clamp((torch.arange(dim // 2) - low) / max(high - low, 0.001), 0, 1)
            
            # 频率缩放: f'(i) = f(i) * ((1-γ) + γ/s)
            freqs = freqs * (1 - ramp + ramp / factor)
    
    # ... 后续计算 cos/sin
```

**YaRN 的三个关键**：

1. **分段缩放**：高频少缩、低频多缩（NTK-aware）
2. **平滑过渡**：用 ramp 函数避免硬边界
3. **注意力缩放**：`attention_factor` 调整 Attention 温度

### 4.4 各方案对比

| 方案 | 训练需求 | 外推倍数 | 效果 | 复杂度 |
|------|---------|---------|------|--------|
| 线性插值 (PI) | 微调 | 2-4× | 一般 | 简单 |
| NTK-aware | 微调 | 4-8× | 较好 | 中等 |
| **YaRN** | 微调 | 8-16× | **最好** | 中等 |
| LongRoPE | 微调 | 8×+ | 很好 | 复杂 |
| 原生长文本训练 | 从头训练 | 任意 | **最佳** | 昂贵 |

## 5. 其他位置编码方案

### 5.1 ALiBi (Attention with Linear Biases)

**思想**：不给 Q/K 加位置编码，而是在 Attention Score 上直接加位置偏置。

```
score = Q @ K.T / sqrt(d) + bias

bias = -|i - j| * slope  (i, j 是位置)
```

距离越远，偏置越负（注意力越弱）。

**优点**：
- 外推能力极强（没见过的长度也能用）
- 实现简单

**缺点**：
- 长距离衰减太快，可能丢失远距离依赖

### 5.2 相对位置编码 (Transformer-XL, T5)

不编码绝对位置，而是编码"两个 token 之间的距离"。

```
不是 "token A 在位置 5"
而是 "token A 和 token B 相距 3 个位置"
```

适合需要灵活长度变化的场景。

## 6. minimind 的位置编码选择

### 训练时

```python
# 标准 RoPE
rope_theta = 1e6
max_position_embeddings = 32768  # 预计算表长度
rope_scaling = None  # 不使用 YaRN
```

- 上下文长度：~768 token（实际训练数据）
- 位置编码：标准 RoPE
- 基底较大 ($10^6$)，适合短文本精细区分

### 推理时（可选 YaRN）

```python
# 启用 YaRN 外推
inference_rope_scaling = True
rope_scaling = {
    "type": "yarn",
    "factor": 16,  # 16倍外推
    "original_max_position_embeddings": 2048,
    "beta_fast": 32,
    "beta_slow": 1,
    "attention_factor": 1.0
}
```

- 理论最大上下文：32768 token（16× 外推）
- 实际效果取决于微调程度

## 7. 实践建议

### 选择位置编码的决策树

```
项目阶段
├── 从头预训练
│   └── 用 RoPE，选合适的 rope_theta
│       ├── 短文本为主 (≤2K): theta = 10000
│       └── 长文本为主 (>8K): theta = 1e6 (minimind 选择)
│
├── 已有短文本模型，想扩展长上下文
│   ├── 不想训练: 用 YaRN / NTK-aware 直接推理
│   └── 可以微调: YaRN + 长文本继续训练
│
└── 需要极强外推能力（如处理整本书）
    └── 考虑 ALiBi 或原生长文本训练
```

### 调试技巧

1. **外推效果差？**
   - 检查 `rope_theta` 是否合适
   - 尝试启用 YaRN
   - 考虑长文本继续训练

2. **短文本精度下降？**
   - `rope_theta` 太大，高频信息不足
   - 减小 theta 或不用外推

3. **显存不够？**
   - 减小 `max_position_embeddings`（只影响预计算表大小）
   - 使用 GQA 减少 KV Cache

## 小结

| 概念 | 一句话总结 |
|------|-----------|
| **位置编码** | 给 token 加"位置指纹"，让模型感知顺序 |
| **Sinusoidal** | 用正弦函数编码，无需学习但外推差 |
| **RoPE** | 旋转 Q/K，天然表达相对位置，minimind 采用 |
| **YaRN** | RoPE 的长上下文扩展，分段缩放频率 |
| **ALiBi** | 在 Attention Score 上加位置偏置，外推强 |
