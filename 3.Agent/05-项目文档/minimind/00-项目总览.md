# MiniMind 项目总览

[MiniMind](https://github.com/jingyaogong/minimind) 是一个**从零开始构建的最小化中文大语言模型**教学项目。其核心目标是用**最少的代码**与**最少的算力资源**，完整走通大语言模型的全链路训练：**Tokenizer 训练 → 预训练 → SFT → LoRA → DPO → PPO → GRPO → 知识蒸馏 → Agent RL**。适合作为理解 LLM 训练流水线与工程实现的入门参考。

## 训练流水线全景

训练在概念上是一条**串行链路**：每一步产出的权重通常作为**下一步的起点**（具体衔接以脚本与 README 中的默认路径为准）。

| 顺序 | 阶段 | 脚本 | 要点 |
|:---:|:---|:---|:---|
| 1 | Tokenizer 训练 | `train_tokenizer.py` | BPE，`vocab_size=6400`，兼容 Qwen 生态习惯 |
| 2 | 预训练 | `train_pretrain.py` | Next Token Prediction，建立基础语言建模能力 |
| 3 | 全参数 SFT | `train_full_sft.py` | 在预训练权重上学习指令跟随与对话格式 |
| 4 | LoRA 微调 | `train_lora.py` | 在 SFT 之上轻量适配垂直领域（如医疗） |
| 5 | DPO | `train_dpo.py` | 基于 SFT 权重，偏好对齐（chosen vs rejected） |
| 6 | PPO | `train_ppo.py` | 基于 SFT 权重，Actor-Critic + Reward Model |
| 7 | GRPO | `train_grpo.py` | 基于 SFT 权重，Group Relative Policy Optimization |
| 8 | 知识蒸馏 | `train_distillation.py` | MoE Teacher → Dense Student |
| 9 | Agent RL | `train_agent.py` | 多轮工具调用场景的强化学习 |

> **阅读建议**：先通读 `model_minimind.py` 与 `train_pretrain.py`，再按上表顺序对照各 `train_*.py`，可建立「结构—数据—损失—优化器」的一致心智模型。

## 关键设计特点

1. **Weight Tying**：`embed_tokens` 与 `lm_head` 共享权重，减少参数量与显存占用。
2. **QK Norm**：对 Query / Key 施加 RMSNorm，有利于训练稳定与收敛。
3. **YaRN RoPE Scaling**：支持推理阶段对位置编码做外推（文档中常见表述为约 **4×** 扩展能力，具体以配置与实现为准）。
4. **Flash Attention**：当 `config.flash_attn=True` 且 PyTorch 提供 `torch.nn.functional.scaled_dot_product_attention` 时走 SDPA 快路径（见 `Attention.forward` 中的条件分支）。
5. **Router Aux Loss**（MoE）：路由负载均衡辅助损失，缓解专家坍塌与利用不均。
6. **手工 LoRA**：手写低秩矩阵 A/B，不绑定 PEFT，便于阅读与魔改。
7. **可插拔 Rollout Engine**：Torch 原生与 SGLang 后端可切换，便于在「教学简洁」与「吞吐优化」之间取舍。
