回想一下我们在[14.1节](word2vec.html#sec-word2vec)中的讨论。跳元模型的主要思想是使用softmax运算来计算基于给定的中心词\\(w\_c\\)生成上下文字\\(w\_o\\)的条件概率（如[(14.1.4)](word2vec.html#equation-eq-skip-gram-softmax)），对应的对数损失在[(14.1.7)](word2vec.html#equation-eq-skip-gram-log)给出。

由于softmax操作的性质，上下文词可以是词表\\(\\mathcal{V}\\)中的任意项，[(14.1.7)](word2vec.html#equation-eq-skip-gram-log)包含与整个词表大小一样多的项的求和。因此，[(14.1.8)](word2vec.html#equation-eq-skip-gram-grad)中跳元模型的梯度计算和[(14.1.15)](word2vec.html#equation-eq-cbow-gradient)中的连续词袋模型的梯度计算都包含求和。不幸的是，在一个词典上（通常有几十万或数百万个单词）求和的梯度的计算成本是巨大的！

为了降低上述计算复杂度，本节将介绍两种近似训练方法：_负采样_和_分层softmax_。 由于跳元模型和连续词袋模型的相似性，我们将以跳元模型为例来描述这两种近似训练方法。

## 14.2.1\. 负采样[¶](#subsec-negative-sampling "Permalink to this heading")

负采样修改了原目标函数。给定中心词\\(w\_c\\)的上下文窗口，任意上下文词\\(w\_o\\)来自该上下文窗口的被认为是由下式建模概率的事件：

(14.2.1)[¶](#equation-chapter-natural-language-processing-pretraining-approx-training-0 "Permalink to this equation")\\\[P(D=1\\mid w\_c, w\_o) = \\sigma(\\mathbf{u}\_o^\\top \\mathbf{v}\_c),\\\]

其中\\(\\sigma\\)使用了sigmoid激活函数的定义：

(14.2.2)[¶](#equation-eq-sigma-f "Permalink to this equation")\\\[\\sigma(x) = \\frac{1}{1+\\exp(-x)}.\\\]

让我们从最大化文本序列中所有这些事件的联合概率开始训练词嵌入。具体而言，给定长度为\\(T\\)的文本序列，以\\(w^{(t)}\\)表示时间步\\(t\\)的词，并使上下文窗口为\\(m\\)，考虑最大化联合概率：

(14.2.3)[¶](#equation-eq-negative-sample-pos "Permalink to this equation")\\\[\\prod\_{t=1}^{T} \\prod\_{-m \\leq j \\leq m,\\ j \\neq 0} P(D=1\\mid w^{(t)}, w^{(t+j)}).\\\]

然而，[(14.2.3)](#equation-eq-negative-sample-pos)只考虑那些正样本的事件。仅当所有词向量都等于无穷大时，[(14.2.3)](#equation-eq-negative-sample-pos)中的联合概率才最大化为1。当然，这样的结果毫无意义。为了使目标函数更有意义，_负采样_添加从预定义分布中采样的负样本。

用\\(S\\)表示上下文词\\(w\_o\\)来自中心词\\(w\_c\\)的上下文窗口的事件。对于这个涉及\\(w\_o\\)的事件，从预定义分布\\(P(w)\\)中采样\\(K\\)个不是来自这个上下文窗口_噪声词_。用\\(N\_k\\)表示噪声词\\(w\_k\\)（\\(k=1, \\ldots, K\\)）不是来自\\(w\_c\\)的上下文窗口的事件。假设正例和负例\\(S, N\_1, \\ldots, N\_K\\)的这些事件是相互独立的。负采样将[(14.2.3)](#equation-eq-negative-sample-pos)中的联合概率（仅涉及正例）重写为

(14.2.4)[¶](#equation-chapter-natural-language-processing-pretraining-approx-training-1 "Permalink to this equation")\\\[\\prod\_{t=1}^{T} \\prod\_{-m \\leq j \\leq m,\\ j \\neq 0} P(w^{(t+j)} \\mid w^{(t)}),\\\]

通过事件\\(S, N\_1, \\ldots, N\_K\\)近似条件概率：

(14.2.5)[¶](#equation-eq-negative-sample-conditional-prob "Permalink to this equation")\\\[P(w^{(t+j)} \\mid w^{(t)}) =P(D=1\\mid w^{(t)}, w^{(t+j)})\\prod\_{k=1,\\ w\_k \\sim P(w)}^K P(D=0\\mid w^{(t)}, w\_k).\\\]

分别用\\(i\_t\\)和\\(h\_k\\)表示词\\(w^{(t)}\\)和噪声词\\(w\_k\\)在文本序列的时间步\\(t\\)处的索引。[(14.2.5)](#equation-eq-negative-sample-conditional-prob)中关于条件概率的对数损失为：

(14.2.6)[¶](#equation-chapter-natural-language-processing-pretraining-approx-training-2 "Permalink to this equation")\\\[\\begin{split}\\begin{aligned} -\\log P(w^{(t+j)} \\mid w^{(t)}) =& -\\log P(D=1\\mid w^{(t)}, w^{(t+j)}) - \\sum\_{k=1,\\ w\_k \\sim P(w)}^K \\log P(D=0\\mid w^{(t)}, w\_k)\\\\ =&- \\log\\, \\sigma\\left(\\mathbf{u}\_{i\_{t+j}}^\\top \\mathbf{v}\_{i\_t}\\right) - \\sum\_{k=1,\\ w\_k \\sim P(w)}^K \\log\\left(1-\\sigma\\left(\\mathbf{u}\_{h\_k}^\\top \\mathbf{v}\_{i\_t}\\right)\\right)\\\\ =&- \\log\\, \\sigma\\left(\\mathbf{u}\_{i\_{t+j}}^\\top \\mathbf{v}\_{i\_t}\\right) - \\sum\_{k=1,\\ w\_k \\sim P(w)}^K \\log\\sigma\\left(-\\mathbf{u}\_{h\_k}^\\top \\mathbf{v}\_{i\_t}\\right). \\end{aligned}\\end{split}\\\]

我们可以看到，现在每个训练步的梯度计算成本与词表大小无关，而是线性依赖于\\(K\\)。当将超参数\\(K\\)设置为较小的值时，在负采样的每个训练步处的梯度的计算成本较小。

## 14.2.2\. 层序Softmax[¶](#softmax "Permalink to this heading")

作为另一种近似训练方法，_层序Softmax_（hierarchical softmax）使用二叉树（[图14.2.1](#fig-hi-softmax)中说明的数据结构），其中树的每个叶节点表示词表\\(\\mathcal{V}\\)中的一个词。

图14.2.1 用于近似训练的分层softmax，其中树的每个叶节点表示词表中的一个词[¶](#id5 "Permalink to this image")

用\\(L(w)\\)表示二叉树中表示字\\(w\\)的从根节点到叶节点的路径上的节点数（包括两端）。设\\(n(w,j)\\)为该路径上的\\(j^\\mathrm{th}\\)节点，其上下文字向量为\\(\\mathbf{u}\_{n(w, j)}\\)。例如，[图14.2.1](#fig-hi-softmax)中的\\(L(w\_3) = 4\\)。分层softmax将[(14.1.4)](word2vec.html#equation-eq-skip-gram-softmax)中的条件概率近似为

(14.2.7)[¶](#equation-chapter-natural-language-processing-pretraining-approx-training-3 "Permalink to this equation")\\\[P(w\_o \\mid w\_c) = \\prod\_{j=1}^{L(w\_o)-1} \\sigma\\left( \[\\!\[ n(w\_o, j+1) = \\text{leftChild}(n(w\_o, j)) \]\\!\] \\cdot \\mathbf{u}\_{n(w\_o, j)}^\\top \\mathbf{v}\_c\\right),\\\]

其中函数\\(\\sigma\\)在[(14.2.2)](#equation-eq-sigma-f)中定义，\\(\\text{leftChild}(n)\\)是节点\\(n\\)的左子节点：如果\\(x\\)为真，\\(\[\\!\[x\]\\!\] = 1\\);否则\\(\[\\!\[x\]\\!\] = -1\\)。

为了说明，让我们计算[图14.2.1](#fig-hi-softmax)中给定词\\(w\_c\\)生成词\\(w\_3\\)的条件概率。这需要\\(w\_c\\)的词向量\\(\\mathbf{v}\_c\\)和从根到\\(w\_3\\)的路径（[图14.2.1](#fig-hi-softmax)中加粗的路径）上的非叶节点向量之间的点积，该路径依次向左、向右和向左遍历：

(14.2.8)[¶](#equation-chapter-natural-language-processing-pretraining-approx-training-4 "Permalink to this equation")\\\[P(w\_3 \\mid w\_c) = \\sigma(\\mathbf{u}\_{n(w\_3, 1)}^\\top \\mathbf{v}\_c) \\cdot \\sigma(-\\mathbf{u}\_{n(w\_3, 2)}^\\top \\mathbf{v}\_c) \\cdot \\sigma(\\mathbf{u}\_{n(w\_3, 3)}^\\top \\mathbf{v}\_c).\\\]

由\\(\\sigma(x)+\\sigma(-x) = 1\\)，它认为基于任意词\\(w\_c\\)生成词表\\(\\mathcal{V}\\)中所有词的条件概率总和为1：

(14.2.9)[¶](#equation-eq-hi-softmax-sum-one "Permalink to this equation")\\\[\\sum\_{w \\in \\mathcal{V}} P(w \\mid w\_c) = 1.\\\]

幸运的是，由于二叉树结构，\\(L(w\_o)-1\\)大约与\\(\\mathcal{O}(\\text{log}\_2|\\mathcal{V}|)\\)是一个数量级。当词表大小\\(\\mathcal{V}\\)很大时，与没有近似训练的相比，使用分层softmax的每个训练步的计算代价显著降低。

## 14.2.3\. 小结[¶](#id3 "Permalink to this heading")

* 负采样通过考虑相互独立的事件来构造损失函数，这些事件同时涉及正例和负例。训练的计算量与每一步的噪声词数成线性关系。
* 分层softmax使用二叉树中从根节点到叶节点的路径构造损失函数。训练的计算成本取决于词表大小的对数。
