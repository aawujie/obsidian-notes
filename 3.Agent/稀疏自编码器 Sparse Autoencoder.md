# 稀疏自编码器 Sparse Autoencoder

> 用于解释神经网络内部特征的可解释性工具

---

## 什么是自编码器？

**基本结构**：
```
输入 → 编码器 → 低维表示 → 解码器 → 重建输入
```

**目标**：学会压缩（编码）和解压（解码）数据

---

## 稀疏自编码器的特殊之处

### 核心思想

**强制稀疏性**：让低维表示中大部分值为 0，只有少数非零

```
普通自编码器的隐藏层: [0.3, 0.7, 0.2, 0.9, 0.1]  (全部激活)
稀疏自编码器的隐藏层: [0.0, 0.0, 2.1, 0.0, 0.0]  (稀疏激活)
```

### 为什么需要稀疏性？

| 优势 | 解释 |
|------|------|
| **特征分离** | 每个特征由特定神经元表示 |
| **可解释性** | 能看到模型学到了什么 |
| **避免冗余** | 不同神经元学习不同特征 |

---

## 在 Transformer 中的应用

### 问题背景

Transformer 使用**叠加（Superposition）**：
- 一个概念不由单个神经元表示
- 由**一组神经元组合**表示
- 难以解释模型学到了什么

### 稀疏自编码器的解决方案

**训练一个稀疏自编码器来解释 Transformer 的激活**：

```
Transformer MLP 激活向量 (高维)
    ↓
[稀疏自编码器编码器] → 稀疏表示 (哪些特征激活)
    ↓
[稀疏自编码器解码器] → 重建激活向量
```

**结果**：
- 发现可解释的特征方向
- 例如：某个神经元专门响应"迈克尔·乔丹"

## 直观例子

### 图像领域

训练稀疏自编码器识别图像：

```
输入: 猫的图片
隐藏层激活: [0, 0, 3.2, 0, 0, 1.5, 0, ...]
           ↑      ↑
        耳朵特征  胡须特征
```

### 语言模型领域

```
输入: "Michael Jordan plays basketball"
MLP 激活 → 稀疏自编码器 → 发现激活的特征:
- 特征 #42: "迈克尔·乔丹" (激活值 2.1)
- 特征 #157: "篮球运动员" (激活值 1.8)
- 特征 #89: "NBA" (激活值 0.5)
- 其他特征: 0 (未激活)
```

## 数学形式

### 损失函数

```
总损失 = 重建误差 + 稀疏惩罚项

L = ||x - x̂||² + λ · sparsity_penalty(h)
```

其中：
- `x`: 原始输入
- `x̂`: 重建输出
- `h`: 隐藏层（低维表示）
- `λ`: 稀疏性权重

### 稀疏惩罚

常用 **L1 正则化**：
```
sparsity_penalty = Σ|h_i|
```

或使用 **KL 散度**约束平均激活度接近目标值（如 0.05）。

## 为什么对 LLM 很重要？

### 可解释性挑战

LLM 是"黑盒"：
- 1750亿参数
- 不知道它在"想"什么
- 不知道知识存储在哪里

### 稀疏自编码器的作用

| 能力 | 说明 |
|------|------|
| **特征发现** | 找到模型实际使用的概念 |
| **知识定位** | 定位特定知识存储的神经元 |
| **故障分析** | 理解模型为什么会犯错 |
| **安全研究** | 发现潜在的有害行为模式 |

|------|-----------|
| **自编码器** | 学习压缩和解压数据的神经网络 |
