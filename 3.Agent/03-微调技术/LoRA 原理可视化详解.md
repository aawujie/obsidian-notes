# LoRA 原理可视化详解

> 来源：可视化风格 LoRA 原理讲解视频整理

## 一、为什么需要 LoRA？

### 核心问题
如何让已训练好的模型获得新的信息知识？

### 方案演进

| 方案 | 做法 | 问题 |
|------|------|------|
| 全量微调 | 在原模型基础上继续训练所有参数 | 参数量巨大（亿级），训练成本极高 |
| 部分层微调 | 冻结前几层，只训练特定层 | 仍需保存整个模型文件，体积笨重 |
| **LoRA** | 训练低秩矩阵对，叠加到原模型 | ✅ 计算量小 + 体积极小 + 即插即用 |

---

## 二、数学基础：奇异值分解（SVD）

### 矩阵乘法回顾

- 左矩阵的某行 × 右矩阵的某列 → 结果矩阵对应位置的值
- 一个 `m×n` 的矩阵可以拆解为多个秩-1 矩阵的加权叠加

### 矩阵低秩分解技巧

```
原矩阵 W (m×n)
= Σ [σᵢ × (列向量 uᵢ) × (行向量 vᵢᵀ)]
  其中 σ₁ ≥ σ₂ ≥ ... 为奇异值（重要程度权重）
```

**关键洞察**：前几个权重最大的分量就能近似还原原矩阵的绝大部分信息。

### 灰度图像示例

- 原图：30×30 矩阵 = **900 个数字**
- 拆分后只取重要程度最高的 4 组：`30×4` 与 `4×30` 两个矩阵
- 仅用 **240 个数字** 就近似还原了原图绝大部分内容

---

## 三、LoRA 核心原理

### 思路

对神经网络中各层间的参数矩阵，用**低秩矩阵对**来高度近似表示：

```
原始参数矩阵 W (m×n)
≈ A (m×r) × B (r×n)
其中 r << min(m, n)，r 即为 LoRA 的 rank
```

### 参数量对比示例

网络结构 `8×12×12×8`，全连接参数矩阵：

| 方式 | 表示形式 | 参数数量 |
|------|---------|---------|
| 原始 | 8×12, 12×12, 12×8 | **336 个** |
| LoRA (r=2) | (8×2,2×12), (12×2,2×12), (12×2,2×8) | **128 个** |

节省约 **62%** 的参数量。

## 四、LoRA 训练过程

### 网络结构

```
输入
 ├──→ 原始模型（参数冻结，不更新）──→ 原始输出
 └──→ LoRA 模型（低秩矩阵，只训练这部分）──→ LoRA 输出
                                                      ↓
                                              两者输出相加 → 最终输出
```

### 训练步骤（以学习"加菲猫"为例）

1. 将"加菲猫"文本和加菲猫图像分别置于网络两端
2. 同时输入两个网络，得到输出（初始输出 = 普通猫）
3. 计算输出与目标（加菲猫图像）的差异
4. **只将差异回传到 LoRA 网络**，冻结原模型
5. 反复迭代，LoRA 学会表示"加菲猫 - 普通猫"的差值信息

> 原模型持续输出"普通猫"，LoRA 负责输出"加菲猫与普通猫的差值"，两者相加 = 加菲猫

---

## 五、LoRA 推理过程

### 方式一：矩阵叠加（merge）

```
W_merged = W_原始 + A × B
```

将 LoRA 矩阵对 `A×B` 恢复为与原模型同尺寸后直接叠加，**不影响推理速度**。

### 方式二：并行推理

前向传播时同时走原模型和 LoRA 分支，输出相加。

---

## 六、LoRA 的关键参数

### 1. Rank（r）

- LoRA 矩阵对的中间维度
- r 越大 → 表达能力越强，但参数量也越大
- 常用值：`8, 16, 32, 64`

### 2. LoRA Weight（权重/强度）

```python
# 叠加时对 LoRA 参数乘以权重系数
W_merged = W_原始 + alpha × (A × B)
```

- `alpha = 1.0`：完整使用 LoRA 知识
- `alpha = 0.5`：LoRA 影响减半，风格减弱
- 可以**对每层单独设置不同权重**，精细控制各层影响程度

### 3. 多 LoRA 叠加

```
W_final = W_原始 + A₁×B₁ + A₂×B₂ + ...
```

- 同时叠加多个 LoRA（如加菲猫 LoRA + 米老鼠 LoRA）
- 各 LoRA 矩阵对全部累加到原模型参数上
- **不影响推理性能**，无论叠加多少个速度相同

---

## 七、LoRA 优势总结

| 优势 | 说明 |
|------|------|
| 低训练算力 | 只更新低秩矩阵参数，计算量大幅降低 |
| 超小体积 | 只需保存 A、B 两个小矩阵，文件极小 |
| 即插即用 | 推理时直接叠加，不修改原模型 |
| 可组合 | 多个 LoRA 可同时叠加，互不干扰 |
| 可调权重 | 可精细控制每个 LoRA 的影响强度 |

---

## 八、直觉理解

> LoRA 不是在"修改"模型，而是在模型上"叠加一层知识增量"。  
> 原模型 = 基础知识  
> LoRA = 增量知识（差值）  
> 两者之和 = 具备新知识的模型

这与 Git 的 diff/patch 机制在哲学上非常类似。

## 九、低秩矩阵也可以做 SVD

任何矩阵都可以做奇异值分解，低秩矩阵也不例外。

低秩矩阵的 SVD 有个特别性质：**非零奇异值的数量 = 矩阵的 rank**。

例如一个 $30 \times 30$、rank = 4 的矩阵，它的 $\Sigma$ 长这样：

$$\Sigma = \begin{bmatrix} \sigma_1 & 0 & \cdots \\ 0 & \sigma_2 & \cdots \\ 0 & 0 & \sigma_3 & \cdots \\ 0 & 0 & 0 & \sigma_4 & \cdots \\ & & & & 0 \\ & & & & & \ddots \end{bmatrix}$$

只有前 4 个奇异值非零，其余 26 个全是 0。

| | 满秩矩阵 | 低秩矩阵（rank = r） |
|---|---|---|
| 非零奇异值数量 | $d$ 个 | $r$ 个 |
| 信息量 | 占满整个空间 | 只在 $r$ 维子空间里 |

## 十、两个低秩矩阵相乘还是低秩矩阵

$$\underbrace{B}_{30 \times 4} \underbrace{A}_{4 \times 30} = \underbrace{\Delta W}_{30 \times 30,\ \text{rank} \leq 4}$$

### 为什么方向不会叠加？

乘法是**串联**，数据必须通过中间的 4 维瓶颈：

```
输入(30维) → A → 中间(4维) → B → 输出(30维)
```

不管输入多丰富，经过 A 之后只剩 4 个方向；B 再展开，原料还是 4 个方向，输出最多也只有 4 个方向。

**水管比喻**：

```
宽河(30) → 细管(4根) → 宽河(30)
```

水必须通过 4 根细管，出来最多 4 股，不可能变成 8 股。

### 乘法 vs 加法的区别

| 操作 | 效果 | 公式 |
|---|---|---|
| $BA$（相乘，串联） | 方向取**瓶颈**，不叠加 | $\text{rank}(BA) \leq \min(\text{rank}(B), \text{rank}(A))$ |
| $C + D$（相加，并联） | 方向**叠加** | $\text{rank}(C+D) \leq \text{rank}(C) + \text{rank}(D)$ |

两个 rank-4 矩阵相乘 → rank ≤ 4；相加 → rank 最多 8。

## 十一、为什么不直接训练 30×30 低秩矩阵？

直接训练一个 $30 \times 30$ 的矩阵并强迫它低秩，有两个致命问题：

**问题一：没法保证低秩**

梯度会把它推向满秩，必须额外加 rank 约束，优化极难。

用 $B \times A$ 的方式，低秩是**结构上天然保证**的，无需任何约束。

**问题二：参数没省**

| 方式 | 参数量（$d=30, r=4$） |
|---|---|
| 直接训练 $30 \times 30$ | 900 个 |
| 拆成 $30 \times 4$ 和 $4 \times 30$ | 240 个 |

$B \times A$ 同时解决了两件事：**省参数 + 天然保证低秩**。

---

## 十二、A 和 B 各自的角色

$$\Delta W = \underbrace{B}_{30 \times 4} \underbrace{A}_{4 \times 30}$$

**A（4×30）**：在 30 维输入里"挑出" 4 个方向

> A 的每一行是一个方向，决定"我关注输入空间的哪 4 个方向"

**B（30×4）**：把这 4 个方向的变化"投影回" 30 维

> B 的每一列是一个方向，决定"这 4 个变化怎么影响输出空间的每一维"

### 对比 SVD 更清晰

$$\Delta W = U \Sigma V^T$$

| SVD 分量 | LoRA 对应 | 作用 |
|---|---|---|
| $V^T$ | A | 在输入空间**选方向** |
| $\Sigma$ | 吸收进 B 或 A | 每个方向的强度 |
| $U$ | B | 在输出空间**表达结果** |

> LoRA 本质上是手动做了一个低秩 SVD，只是 A 和 B 通过训练自己学出来，而不是从原矩阵分解出来。

## 十三、B 单独的奇异值 vs BA 乘积的奇异值

对 $30 \times 4$ 矩阵 B 单独做 SVD，和对 $30 \times 30$ 乘积 BA 做 SVD，结果有什么关系？

| | B（30×4） | BA（30×30） |
|---|---|---|
| 非零奇异值数量 | **4 个**（相同） | **4 个**（相同） |
| 实际数值 | 只和 B 有关 | 同时取决于 B、A 以及两者的方向关系 |

**个数相同，数值不同。**

展开 BA 的 SVD：

$$BA = \underbrace{U_B}_{30 \times 4} \underbrace{\Sigma_B \overbrace{V_B^T U_A}^{M} \Sigma_A}_{\text{B 和 A 的混合}} \underbrace{V_A^T}_{4 \times 30}$$

各矩阵 shape（使用 thin SVD）：

| 矩阵 | Shape | 说明 |
|---|---|---|
| $U_B$ | $30 \times 4$ | B 的左奇异矩阵，输出空间的 4 个方向 |
| $\Sigma_B$ | $4 \times 4$ | B 的奇异值对角矩阵 |
| $V_B^T$ | $4 \times 4$ | B 的右奇异矩阵的转置 |
| $M = V_B^T U_A$ | $4 \times 4$ | B 和 A 的"方向混合"矩阵，是正交矩阵 |
| $U_A$ | $4 \times 4$ | A 的左奇异矩阵 |
| $\Sigma_A$ | $4 \times 4$ | A 的奇异值对角矩阵 |
| $V_A^T$ | $4 \times 30$ | A 的右奇异矩阵的转置，输入空间的 4 个方向 |

验证：$(30 \times 4)(4 \times 4)(4 \times 4)(4 \times 4)(4 \times 30) = 30 \times 30$ ✓

中间的 $M = V_B^T U_A$ 是 B 和 A 之间的"混合矩阵"：
- 若 $M = I$（完全对齐）：BA 的奇异值 = $\sigma_i^B \times \sigma_i^A$
- 一般情况：是两者的复杂组合，没有简单公式

> **B 的奇异值只说了"一半故事"，BA 的奇异值才是完整结果。**

## 十四、深入理解混合矩阵 $M = V_B^T U_A$

### 什么是"混合"？

机制上是**行 × 列（点积）**，但"混合"的含义在于它度量的是什么。

$$M_{ij} = \underbrace{(\text{行 } i \text{ of } V_B^T)}_{\text{B 的第 } i \text{ 个输出方向}} \cdot \underbrace{(\text{列 } j \text{ of } U_A)}_{\text{A 的第 } j \text{ 个输入方向}}$$

每个元素是一个点积，衡量 **B 的第 $i$ 个方向** 和 **A 的第 $j$ 个方向** 有多对齐。

### 两种极端情况

#### 情况一：$M = I$（完全对齐）

B 的输出方向和 A 的输入方向一一对应，互相不干扰：

```
A 的方向1 → B 的方向1（直接传递）
A 的方向2 → B 的方向2（直接传递）
```

奇异值直接相乘：$\sigma_i^{BA} = \sigma_i^B \times \sigma_i^A$

#### 情况二：M 是其他正交矩阵（方向歪了）

A 的方向1 出来之后，进入 B 时已经不是 B 的方向1 了，而是 B 的多个方向的混合：

```
A 的方向1 → B 的方向1 × 0.7 + B 的方向2 × 0.3 + ...
A 的方向2 → B 的方向1 × 0.3 + B 的方向2 × 0.6 + ...
```

这就是**"混合"**——A 的每个方向都混进了 B 的多个方向里，奇异值没法简单相乘了。

### 一句话总结

> **$M$ 的每个元素 = 一次点积 = A 的某个方向和 B 的某个方向"对上了多少"。**
> 
> $M$ 越接近 $I$，两者越对齐，信号越干净；$M$ 越偏，方向越混乱。
