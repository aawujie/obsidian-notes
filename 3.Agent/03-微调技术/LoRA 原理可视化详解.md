# LoRA 原理可视化详解

> 来源：可视化风格 LoRA 原理讲解视频整理

## 一、为什么需要 LoRA？

### 核心问题

如何让已训练好的模型获得新的信息知识？

### 方案演进

| 方案 | 做法 | 问题 |
|------|------|------|
| 全量微调 | 在原模型基础上继续训练所有参数 | 参数量巨大（亿级），训练成本极高 |
| 部分层微调 | 冻结前几层，只训练特定层 | 仍需保存整个模型文件，体积笨重 |
| **LoRA** | 训练低秩矩阵对，叠加到原模型 | ✅ 计算量小 + 体积极小 + 即插即用 |

---

## 二、数学基础：奇异值分解（SVD）

### 矩阵乘法回顾

- 左矩阵的某行 × 右矩阵的某列 → 结果矩阵对应位置的值
- 一个 `m×n` 的矩阵可以拆解为多个秩-1 矩阵的加权叠加

### 矩阵低秩分解技巧

```
原矩阵 W (m×n)
= Σ [σᵢ × (列向量 uᵢ) × (行向量 vᵢᵀ)]
  其中 σ₁ ≥ σ₂ ≥ ... 为奇异值（重要程度权重）
```

**关键洞察**：前几个权重最大的分量就能近似还原原矩阵的绝大部分信息。

### 灰度图像示例

- 原图：30×30 矩阵 = **900 个数字**
- 拆分后只取重要程度最高的 4 组：`30×4` 与 `4×30` 两个矩阵
- 仅用 **240 个数字** 就近似还原了原图绝大部分内容

## 三、LoRA 核心原理

### 思路

对神经网络中各层间的参数矩阵，用**低秩矩阵对**来高度近似表示：

```
原始参数矩阵 W (m×n)
≈ A (m×r) × B (r×n)
其中 r << min(m, n)，r 即为 LoRA 的 rank
```

### 参数量对比示例

网络结构 `8×12×12×8`，全连接参数矩阵：

| 方式 | 表示形式 | 参数数量 |
|------|---------|---------|
| 原始 | 8×12, 12×12, 12×8 | **336 个** |
| LoRA (r=2) | (8×2,2×12), (12×2,2×12), (12×2,2×8) | **128 个** |

节省约 **62%** 的参数量。

## 四、LoRA 训练过程

### 网络结构

```
输入
 ├──→ 原始模型（参数冻结，不更新）──→ 原始输出
 └──→ LoRA 模型（低秩矩阵，只训练这部分）──→ LoRA 输出
                                                      ↓
                                              两者输出相加 → 最终输出
```

### 训练步骤（以学习"加菲猫"为例）

1. 将"加菲猫"文本和加菲猫图像分别置于网络两端
2. 同时输入两个网络，得到输出（初始输出 = 普通猫）
3. 计算输出与目标（加菲猫图像）的差异
4. **只将差异回传到 LoRA 网络**，冻结原模型
5. 反复迭代，LoRA 学会表示 "加菲猫 - 普通猫" 的差值信息

> 原模型持续输出 "普通猫"，LoRA 负责输出 "加菲猫与普通猫的差值"，两者相加 = 加菲猫

## 五、LoRA 推理过程

### 方式一：矩阵叠加（merge）

```
W_merged = W_原始 + A × B
```

将 LoRA 矩阵对 `A×B` 恢复为与原模型同尺寸后直接叠加，**不影响推理速度**。

### 方式二：并行推理

前向传播时同时走原模型和 LoRA 分支，输出相加。

---

## 六、LoRA 的关键参数

### 1. Rank（r）

- LoRA 矩阵对的中间维度
- r 越大 → 表达能力越强，但参数量也越大
- 常用值：`8, 16, 32, 64`

### 2. LoRA Weight（权重/强度）

```python
# 叠加时对 LoRA 参数乘以权重系数
W_merged = W_原始 + alpha × (A × B)
```

- `alpha = 1.0`：完整使用 LoRA 知识
- `alpha = 0.5`：LoRA 影响减半，风格减弱
- 可以**对每层单独设置不同权重**，精细控制各层影响程度

### 3. 多 LoRA 叠加

```
W_final = W_原始 + A₁×B₁ + A₂×B₂ + ...
```

- 同时叠加多个 LoRA（如加菲猫 LoRA + 米老鼠 LoRA）
- 各 LoRA 矩阵对全部累加到原模型参数上
- **不影响推理性能**，无论叠加多少个速度相同

## 七、LoRA 优势总结

| 优势 | 说明 |
|------|------|
| 低训练算力 | 只更新低秩矩阵参数，计算量大幅降低 |
| 超小体积 | 只需保存 A、B 两个小矩阵，文件极小 |
| 即插即用 | 推理时直接叠加，不修改原模型 |
| 可组合 | 多个 LoRA 可同时叠加，互不干扰 |
| 可调权重 | 可精细控制每个 LoRA 的影响强度 |

---

## 八、直觉理解

> LoRA 不是在"修改"模型，而是在模型上"叠加一层知识增量"。  
> 原模型 = 基础知识  
> LoRA = 增量知识（差值）  
> 两者之和 = 具备新知识的模型

这与 Git 的 diff/patch 机制在哲学上非常类似。
