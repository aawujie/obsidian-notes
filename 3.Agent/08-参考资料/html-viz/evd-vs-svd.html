特征值 vs 奇异值

EVD 找"特例"，SVD 量"全体"

SVD（奇异值分解）是特征值分解的"通用版"

当特征值分解做不了——非方阵、无实数解——SVD 依然能工作。

1核心关系：奇异值从哪来？

奇异值是特征值的"推广"，通过 AᵀA 联系：

σᵢ = √ λᵢ(AᵀA)
奇异值 = 矩阵 AᵀA 的特征值开平方根
为什么必须用 AᵀA？

A 可能是矩形矩阵，直接求特征值无效。但 AᵀA 是 n×n 方阵，且有三条保证：

性质说明作用
总是方阵 n×n，无论 A 什么形状 可以求特征值
对称半正定 所有特征值 ≥ 0 可以安全开平方
实数特征值 对称矩阵特征值必是实数 σᵢ 总有定义
所以 σᵢ = √λᵢ(AᵀA) 对任意形状的 A 都成立，不论方阵、矩形、甚至奇异矩阵。

2定义与本质

■ 特征值 (EVD)

Av = λv
  • v 经过 A 后方向不变，只缩放 λ 倍
  • 仅适用于方阵
  • 可能无实数解（如旋转矩阵）
  • 非对称矩阵特征向量不一定正交
  • 描述的是"固定方向"——幸运儿

■ 奇异值 (SVD)

A = UΣVᵀ
  • V（输入正交基）→ 缩放 σ → U（输出正交基）
  • 适用于任意矩阵（m×n）
  • 总是存在实数奇异值
  • U、V 列向量总是正交
  • 描述的是"所有方向"——普查员

3几何可视化：单位圆的命运

矩阵 A 将单位圆变成椭圆。特征向量是"不动方向"，奇异向量是"主轴方向"——两者描述同一变换的不同侧面。

矩阵 A
单位圆（输入）
变换椭圆（输出）
特征向量 v
右奇异向量 V
σ·左奇异向量 U

4数值示例：同一矩阵，两种分解

用 A = [[3, 1], [0, 2]] 分别做特征值分解和奇异值分解：

特征值分解
λ₁ = 3, λ₂ = 2
特征向量：
v₁ = [1, 0]
v₂ = [−1, 1] / √2
v₁ · v₂ = −1/√2 ≠ 0  ⚠ 不正交
奇异值分解
σ₁ ≈ 3.257, σ₂ ≈ 1.842
右奇异向量（正交）：
v₁ ≈ [0.881, 0.471]
v₂ ≈ [0.471, −0.881]
v₁ · v₂ = 0  ✓ 完全正交
关键观察
对比项 特征值/向量 奇异值/向量
数值含义 3, 2（固定方向的缩放） 3.257, 1.842（主轴伸缩量）
向量组数 1 组 {v₁, v₂} 2 组：输入 V + 输出 U
正交性 不正交（此矩阵为例） V、U 都正交（总是）
一定存在？ 不保证（旋转矩阵无实数解） 总是存在
注意：奇异值 ≠ 特征值绝对值，奇异向量 ≠ 特征向量。即使同一个矩阵，两套分解算出来的数值和方向都不同。

5信息量：找"特例" vs 量"全体"

特征值：找"幸运儿"

约束极强：Av = λv（方向完全不变）
旋转矩阵：一个幸运儿也找不到
即使有，向量组也可能不完备

奇异值：量"所有人"

问的是：每个方向被拉伸多少？
每个维度都有答案
总是正交完备

特征值 奇异值
关注范围 特殊方向（方向不变的向量） 所有方向（每维最大伸缩）
完备性 可能缺失 总是完整
向量组 1 组（V） 2 组（U 和 V）
空间描述 单一空间 输入空间 + 输出空间
特征值找"特例"，奇异值量"全体"。
特例可能不存在，但全体一定有度量。

6特殊情况：对称矩阵

当 A 是实对称矩阵（A = Aᵀ）时，两者直接合一：

关系
奇异值 σᵢ = |λᵢ|（特征值的绝对值）
左奇异向量 = 右奇异向量 = 特征向量
结论：对称矩阵的 SVD 本质上就是特征值分解。 试试上方可视化里的"对称矩阵"按钮，切到"双视角对比"——紫色特征向量和绿色奇异向量会完全重合。

8应用场景

特征值分解的主场

PCA（协方差矩阵是对称的）、谱聚类、PageRank（方阵迭代）、物理振动/稳定性分析

奇异值分解的主场

图像压缩（低秩近似）、推荐系统（矩阵分解）、降噪、LSA 潜在语义分析、LoRA 参数压缩

记忆口诀
方阵找特征，任意用奇异；
正交选 SVD，复数要避免。
