## 核心创新

> [!tip] 一句话总结
> **LEX Transformer 提出 XPOS（外推式位置编码），结合旋转与指数衰减，实现"短训练、长推理"。**

| 方法 | 短文本性能 | 长文本外推 | 机制 |
|------|-----------|-----------|------|
| RoPE | 好 | 困惑度爆炸 | 纯旋转 |
| ALiBi | 较差 | 好 | 纯衰减 |
| **XPOS** | **好** | **好** | **旋转 + 衰减** |

---

## 问题背景

### Transformer 的长度困境

> [!warning] 核心问题
> Transformer 在训练长度 L 上训练，无法处理更长的输入 L' > L。

**设计原则**：

| 原则 | 说明 | 满足情况 |
|------|------|---------|
| **顺序变异性** | 模型能区分词序 | 大多数方法满足 |
| **平移不变性** | 位置平移不影响语义 | 相对位置编码满足 |
| **长度外推** | 处理任意长度输入 | 仅 ALiBi、XPOS 满足 |

---

## 关键概念：注意力分辨率（Attention Resolution）

> [!important] 核心创新
> 作者定义了**注意力分辨率**来量化位置建模能力。

**定义**：

```math
R(s) = Σ e^{s[i]} (e^{s[i]} - e^{s[i+1]}) / (Σ e^{s[i]})^2
```

其中 `s[n]` 是距离为 n 的注意力分数期望。

**意义**：
- 分数越高 → 模型能更好区分位置
- RoPE：分辨率高但不稳定（震荡）
- ALiBi：分辨率稳定但整体低
- XPOS：分辨率高且稳定

---

## XPOS 方法详解

### 核心公式

**在 RoPE 基础上加入指数衰减**：

```math
f_q(q, n) = q × e^{ξn + iθn}
f_k(k, n) = k × e^{-ξn - iθn}
```

其中：
- `θ`：旋转角度（同 RoPE）
- `ξ`：指数衰减系数（新增）

**几何解释**：
- RoPE：纯旋转（角度 θ）
- XPOS：旋转 + 缩放（角度 θ + 缩放 ξ）

---

### 为什么需要衰减？

**RoPE 的问题**：

```math
注意力期望 = Σ cos(m-n)θ_i
```

> [!warning] 长距离震荡
> 当相对距离 > π 时，cos 值震荡，模型无法稳定区分位置。

**XPOS 的解决**：

```math
注意力期望 = Σ cos(m-n)θ_i × e^{(m-n)ξ_i}
```

衰减因子 `e^{(m-n)ξ}` 使长距离注意力单调下降。

---

### ξ 的设计

**手动设置公式**：

```math
ζ_i = (i/(d/2) + γ) / (1 + γ)
```

**解释**：
- i 大（低频）→ ζ 接近 1（少衰减）
- i 小（高频）→ ζ 接近 γ/(1+γ)（多衰减）

**目的**：
- 高频维度震荡严重 → 加强衰减
- 低频维度较稳定 → 减少衰减

---

### 完整 XPOS 实现

```python
# 算法实现
def xpos_attention(Q, K, V, M):
    # 初始化
    θ = [1/10000^(2i/d)]  # RoPE 频率
    ζ = [(i/(d/2) + γ)/(1 + γ)]  # 衰减系数
    
    # 计算 cos/sin
    C = cos(n × θ)
    S = sin(n × θ)
    T = ζ^n
    
    # 应用 XPOS
    Q = (Q × C + rot(Q) × S) × T
    K = (K × C + rot(K) × S) × T^{-1}
    
    # 注意力计算
    output = softmax(Q × K^T / sqrt(d) × M) × V
    return output
```

## Blockwise Causal Attention (BCA)

### 问题

即使有 XPOS，直接处理超长序列仍有问题。

### 解决方案

**训练阶段**：正常因果注意力

**推理阶段**：块状因果注意力

```
训练长度 l = 1024
推理时：
  - 将 query 分成 l/2 的块
  - 每块 query 只关注：
    1. 自己所在的块
    2. 前一个块
```

**优势**：
- 缓存友好（KV cache 可复用）
- 窗口约束提升分辨率
- 无需修改训练代码

|------|-----|------|------|------|------|
| Transformer | 46.34 | 36.39 | 29.94 | 132.63 | 1283.79 |
| ALiBi | 37.66 | 29.92 | 24.99 | 23.14 | 24.26 |

| **LEX (XPOS)** | **34.3** | **27.55** | **23.31** | **21.6** | **20.73** |

> [!success] 关键发现
> - 短文本（<1024）：LEX 性能最优
> - 长文本（>1024）：LEX 困惑度继续下降，其他方法爆炸或饱和

## 代码实现要点

### XPOS 的关键参数

```python
# 推荐设置
d = 1024  # hidden dimension
γ = 0.5   # decay parameter

# 衰减系数
ζ = [(i/(d/2) + γ) / (1 + γ) for i in range(d//2)]

# 注意：高频维度（i小）衰减更强
```

### BCA 的实现

```python
def blockwise_causal_attention(Q, K, V, block_size):
    # 将 query 分成块
    Q_blocks = split(Q, block_size)
    
    # 每块只关注自己 + 前一块
    for i, q_block in enumerate(Q_blocks):
        if i == 0:
            k_block = K[:block_size]
        else:
            k_block = K[max(0, i-1)*block_size : i*block_size + block_size]
        
        # 正常注意力计算
        output = attention(q_block, k_block, V)
```

## 我的理解

### XPOS vs YaRN

| 维度 | XPOS | YaRN |
|------|------|------|
| **核心思想** | 衰减系数 | 温度 + 分维度 |
| **修改位置** | RoPE 公式 | RoPE 频率 + attention |
| **推理修改** | 需要 BCA | Dynamic scaling |
| **行业采用** | 较少 | 广泛 |

### XPOS 的价值

> [!note] 个人分析
> 1. **理论性强**：从分辨率出发，推导出衰减必要性
> 2. **简洁优雅**：一个公式解决问题
> 3. **训练不变**：只改 embedding，不改训练代码
> 4. **与 ALiBi 对比**：ALiBi 损失短文本性能，XPOS 保留

---

## 局限性

作者承认的局限：

1. **仅限因果 LM**：双向注意力（如 BERT）需要额外适配
2. **推理开销**：XPOS 比 Absolute PE 多 6% 推理开销
3. **BCA 需求**：长文本推理需要 BCA 配合
