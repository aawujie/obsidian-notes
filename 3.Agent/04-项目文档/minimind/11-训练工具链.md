# 总览：`trainer_utils.py`

`trainer_utils.py` 聚合了 **模型构建、学习率、断点续训、分布式、采样器、奖励模型封装、日志与随机种子** 等横切逻辑，是各 `train_*.py` 脚本的共同基础设施。

---

## 模型初始化：`init_model`

1. 从 **`tokenizer_path`** 加载 **`AutoTokenizer`**（词表与 special tokens 与训练数据一致）。
2. 用配置构造 **`MiniMindForCausalLM(config)`**。
3. 若 **`from_weight != 'none'`**：从对应 **`.pth` 预训练/中间权重** 加载（通常 **`strict=False`**，允许头部维度或新增模块不完全对齐时的部分加载）。
4. **日志**：打印参数量；若为 **MoE**，区分 **总参数量** 与 **激活参数量（active）**，避免把专家全量都算成「每步都算」的误解。

---

## 学习率调度：`get_lr`

使用 **自定义余弦退火**（非简单 linear warmup+cosine 的默认 PyTorch 形态），形式可写为：

$$
\text{lr}(t) = \text{lr}_0 \cdot \Bigl(0.1 + 0.45 \cdot \bigl(1 + \cos(\pi \cdot t / T)\bigr)\Bigr)
$$

直觉：

- **最低约 \(0.1\times\)** 基准学习率（训练末期仍保留一定步长）。
- **最高约 \(1.0\times\)** 基准学习率附近（由系数和余弦形状共同决定）。
- 中间按 **余弦** 平滑下降，避免学习率抖动过大。

## Checkpoint：`lm_checkpoint`

### 保存（双文件）

- **轻量权重**：**`.pth`**，便于拷贝、评测、转换为 HF 格式等。
- **完整 resume 文件**：除权重外，包含 **`optimizer` / `scaler` / `epoch` / `step` / `wandb_id`** 等，用于 **精确续训**。

### 原子写入

- 先写入 **`.tmp`** 临时文件，再 **`os.replace`** 覆盖目标文件，降低 **断电/并发写入** 导致 **checkpoint 损坏** 的概率。

### 加载与多卡变化

- 读取 resume 后，若 **world_size（GPU 数）变化**，可按 **新 world_size 对 step 等计数做比例调整**（避免日志与调度器相位与真实数据遍历不一致）。具体比例逻辑以代码为准。

### 扩展字段（`kwargs`）

- 通过 **`kwargs`** 额外传入 **`scheduler` / `critic_model`** 等对象引用，在统一入口一并序列化/反序列化，减少各训练脚本重复代码。

---

## 分布式：`init_distributed_mode`

- 通过环境变量 **`RANK`** 等判断是否处于 **DDP**。
- **`nccl`** 后端；按 **`LOCAL_RANK`** **绑定本进程可见 GPU**。

---

## 续训采样：`SkipBatchSampler`

- 用途：在 **batch 粒度**上跳过前 **`skip_batches` 个** 完整 batch（`train_agent.py` 将 **已完成的 `start_step`** 传入该参数），避免续训重复同一段数据。
- 实现：包装 **`DistributedSampler`** 或 **普通 index 列表**，凑满 `batch_size` 即决定是否丢弃或 `yield`。

---

## 奖励模型封装：`LMForRewardModel`

- 包装 **`internlm2-1_8b-reward`**（`AutoModel` 家族）等 **RM 骨干**。
- **`get_score`**：将 **user / assistant** 消息对拼成模型输入，调用底层 **`model.get_score()`**（或等价 forward）得到 **标量偏好分**。
- **分数 clip**：输出 **clip 到 \([-3.0, 3.0]\)**，与部分 RL 脚本的 reward 尺度对齐，抑制极端值。

---

## 其他常用工具

| 符号 / 函数 | 作用 |
|-------------|------|
| `setup_seed` | 统一设置 **Python / NumPy / PyTorch / CUDA / cuDNN** 相关随机性，提升复现性（注意多进程下仍需独立 `worker_init_fn` 等配合）。 |
| `Logger` | **仅主进程** 打印，避免 DDP 下 **重复刷屏**。 |
| `is_main_process` | 基于 **DDP rank==0** 判断是否为 **主进程**（写日志、写 wandb、存 checkpoint 等 gate）。 |

---

## 使用建议

- **训练前**：确认 **`tokenizer_path` / `from_weight` / world_size** 与数据管线一致。
- **训练中**：依赖 **`lm_checkpoint` 原子写** + 周期性保存，减少「刚好写在半截」事故。
- **换 GPU 数续训**：留意 **step 缩放** 与学习率调度相位是否仍符合预期，必要时用更小验证 run 先试一轮 epoch 边界。
