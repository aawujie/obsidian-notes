# 知识蒸馏

`train_distillation.py` 用 **Teacher** 模型的软标签监督 **Student**：典型配置为 **MoE Teacher → Dense Student**（脚本也支持更一般的「大 → 小」蒸馏设定）。

---

## 蒸馏损失（KL with temperature）

设 Teacher logits 为 \(z_t\)，Student logits 为 \(z_s\)，温度 \(T\)（默认 **1.5**）。

概率分布：

$$
p_t = \mathrm{softmax}(z_t / T),\quad p_s = \mathrm{softmax}(z_s / T)
$$

蒸馏项采用 **KL 散度**（实现上用 `F.kl_div` 等，注意 **log-prob 与 prob 的顺序** 与 API 约定一致）：

$$
\mathcal{L}_{\text{distill}} = T^2 \cdot \mathrm{KL}\bigl(p_t \,\|\, p_s\bigr)
$$

**\(T^2\)** 用于 **补偿** 温度缩放对梯度幅度的影响，使不同 \(T\) 下学习率可比性更好。

实现上常见写法：对 student 侧使用 **log-softmax**，teacher 侧为 **detach 后的 softmax 概率**，`reduction='batchmean'` 等在 batch 维归约。

---

## 总损失

$$
\mathcal{L} = \alpha \cdot \mathcal{L}_{\text{CE}} + (1 - \alpha) \cdot \mathcal{L}_{\text{distill}}
$$

默认 **\(\alpha = 0.5\)**：**硬标签交叉熵** 与 **软标签 KL** 各占一半。

---

## Vocab 对齐

Teacher 与 Student **词表大小** 可能不同：对 **`teacher_logits`** 在 **词表维** 上 **截断到 `student.vocab_size`**，保证与 student 的 logits 维一致后再算 KL。

---

## Loss Mask

与 `train_distillation.py` 一致：`loss_mask = (labels[..., 1:] != -100).float()`，与 **`student_logits[..., :-1, :]`**（实现里再取 `[:, :-1]` 后与 `labels[..., 1:]`）**对齐的 shift 位置**上，**仅在 mask 为 1 处**取展平后的子集参与 **蒸馏 KL**；CE 分支对 `shift_labels` 使用 **`ignore_index=-100`** 并与同一 `loss_mask` 加权。

---

## 实现要点

| 项目 | 说明 |
|------|------|
| **Teacher** | `eval()` + **`requires_grad_(False)`**，全程冻结 |
| **Student 初始化** | `from_student_weight` 默认 **`full_sft`**（`init_model` 加载后再训） |
| **MoE Student** | 若 student 为 MoE，CE 路径上需加上 **router 的 `aux_loss`**（负载均衡等），与预训练/SFT 中 MoE 训练一致 |

---

## 默认超参数（要点）

| 超参数 | 默认值 |
|--------|--------|
| `student_use_moe` | `0`（Dense Student） |
| `teacher_use_moe` | `1`（MoE Teacher） |
| `alpha` | `0.5` |
| `temperature` | `1.5` |
| `lr` | `5e-6` |
| `epochs` | `6` |

---

## 小结

蒸馏在 **logits 空间** 用高温软分布传递 Teacher 的「暗知识」；**\(T^2\)KL**、**词表截断**、**label mask** 与 **Teacher 冻结** 是保证训练稳定与可复现的关键工程细节。
