# 预训练（`train_pretrain.py`）

预训练阶段的目标是让模型掌握 **语言建模基础能力**：给定前文，预测下一 token。实现上为标准 **Next Token Prediction (NTP)**，数据来自大规模 **JSONL** 文本字段。

---

## 训练目标与数据

| 维度       | 说明                                                                  |
| -------- | ------------------------------------------------------------------- |
| 任务       | **Next Token Prediction (NTP)**                                     |
| 数据文件（要点） | `pretrain_t2t_mini.jsonl`                                           |
| 字段       | 每行 **`text`**，由 `PretrainDataset` 等组件做 BOS/EOS、padding 与 label mask |

---

## 默认超参数（要点）

| 超参数                   | 典型取值                                               |
| --------------------- | -------------------------------------------------- |
| `batch_size`          | **32**                                             |
| 学习率 `--learning_rate` | **5e-4**                                           |
| `epochs`              | **2**                                              |
| `max_seq_len`         | **340**（传给 `PretrainDataset(..., max_length=...)`） |
| `accumulation_steps`  | **8**                                              |
| `grad_clip`           | **1.0**                                            |
| `log_interval`        | **100**                                            |
| `save_interval`       | **1000**                                           |

实际训练时仍建议以仓库内 argparse / 配置文件为准，并按显存与数据量微调。

- **实验追踪**：`--use_wandb` 为真且为主进程时，`import swanlab as wandb` 初始化 SwanLab（变量名沿用 `wandb`，并非 Weights & Biases）。
- **总损失**：`loss = res.loss + res.aux_loss` 后再除以 `accumulation_steps`；Dense 下 `aux_loss` 通常为 0，MoE 时含路由辅助项。

---

## 学习率调度（余弦退火）

采用余弦形式，将学习率从初始值平滑衰减，**最低点约为初始学习率的 10%**（`cos(\pi)=-1` 时括号因子为 `0.1`）。

与 `trainer_utils.get_lr` 一致的公式：

$$
\text{lr}(t) = \text{lr}_{\text{init}} \cdot \left(0.1 + 0.45 \cdot \left(1 + \cos\left(\frac{\pi \cdot t}{\text{total\_steps}}\right)\right)\right)
$$

其中 **`t = epoch * iters + step`**：`iters` 为传入 `train_epoch` 的每 epoch 步数（续训首轮可能为 `len(loader) + skip`），`step` 来自 `DataLoader` 枚举且 **`enumerate(..., start=start_step + 1)`** 从 **1** 起；**`total_steps = epochs * iters`**（与 `get_lr` 第二参数相同）。括号内因子落在 **`[0.1,\,1.0]`**；公式在 **`t=0`** 时为 **1.0**、**`t=\text{total\_steps}`** 时为 **0.1**，而脚本里首个 batch 对应 **`t \ge 1`**，首个学习率因子略低于 1.0。

---

## 混合精度与稳定性

| 技术 | 说明 |
|------|------|
| **AMP** | `torch.cuda.amp.autocast` 使用 **`--dtype`** 指定的 **bf16**（默认）或 **fp16**；**`GradScaler` 仅在 `dtype=float16` 时启用**，bf16 一般不做 loss scaling |
| **梯度裁剪** | `grad_clip = 1.0`，抑制偶发大梯度 |

---

## 损失函数

- 主损失：**`cross_entropy`**（自回归下一词预测）。
- **辅助损失 `aux_loss`**：当模型为 **MoE** 等带辅助项结构时，该项有非零值，用于负载均衡等；Dense 模型常为 0 或不使用。

---

## 分布式训练（DDP）

- 使用 **`DistributedDataParallel` (DDP)** 多卡训练。
- **旋转位置编码缓存** **`freqs_cos` / `freqs_sin`**（若存在）应 **排除在 DDP 参与同步的参数之外**，避免重复 buffer 被错误地当作可训练参数或产生冗余梯度钩子问题（以仓库注释与 `no_sync`/自定义 `DistributedDataParallel` 配置为准）。

---

## Checkpoint 与断点续训

| 内容 | 说明 |
|------|------|
| 权重精度 | 保存 **`half()`**（fp16）权重以降低体积 |
| Resume | `*_resume.pth` 中除权重外，包含 **optimizer**、**GradScaler**、**epoch**、**step**、**wandb_id**（SwanLab run id）等，支持无缝续训 |
| **SkipBatchSampler** | 续训时可 **跳过已在上一轮训练中消费过的 batch**，避免重复数据导致有效 epoch 计数与学习率曲线偏移 |

---

## 性能：`torch.compile`

- 可选开启 **`torch.compile`** 对 PyTorch 2.x 图进行编译优化（需与当前 PyTorch / CUDA / 动态形状策略兼容）。

---

## 训练循环结构（概念）

与 SFT 等脚本在「循环、AMP、裁剪、日志」层面保持一致，仅 **Dataset / loss mask** 不同：预训练对 **除 pad 外整段 token** 计算 NTP loss。
