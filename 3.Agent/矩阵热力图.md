## 是什么

**热力图** = 把二维表格数据用颜色渲染的图。值越大颜色越深（或越红），值越小颜色越浅（或越蓝）。

大脑处理颜色是并行的、直觉的，处理数字是串行的、费力的。这就是热力图存在的唯一理由：<span style="color:rgb(255, 77, 77)"><b>用颜色替代数字，把表格变成图片</b></span>。

## 核心概念

### 矩阵 vs 热力图

| 对比 | 普通矩阵/表格 | 热力图 |
|------|-------------|--------|
| 阅读方式 | 逐行扫描数字 | 一眼看颜色分布 |
| 发现异常 | 需要逐个对比 | 深色/亮色区域自动跳出来 |
| 适合场景 | 精确读取数值 | 快速找规律、找瓶颈 |

同一份数据：

```
表格形式：              热力图形式：
        A   B   C   D          A  B  C  D
第1行   10  20  30  40    第1行 ░  ▒  ▓  █
第2行   05  15  25  35    第2行 ·  ░  ▒  ▓
第3行   80  90  70  85    第3行 █  █  █  █
第4行   12  88  18  22    第4行 ░  █  ░  ▒
```

热力图一眼看出：第3行全是热点，第4行B列异常。

### 配色逻辑

三种常见色板：

- **顺序色板**（sequential）：浅→深，适合 0 到 N 的单向数值
- **发散色板**（diverging）：蓝→白→红，适合有正负或需突出偏差的场景
- **定性色板**（qualitative）：不同颜色代表不同类别，不表大小

热力图默认用顺序色板，但**发散色板往往更有用**——冷色=正常，暖色=问题，零值=透明。

### 聚类

热力图通常搭配**层次聚类**：行和列按相似度重新排列。比如对"车型 × 功能域 × 通过率"聚类后，问题相似的车型和功能域会排在一起，形成明显的红块和蓝块。

## 典型用例

### 1. 测试矩阵

行=车型，列=功能域，值=通过率。红块=高风险组合，蓝块=稳定组合。一眼看谁能跑谁不能跑。

### 2. 相关性矩阵

行=列=变量，值=相关系数。对角线永远是红色（自己和自己相关=1），关注对角线之外的红/蓝块。

### 3. 时间热力图

行=日期，列=小时，值=请求量/错误数。GitHub 的 contribution graph 就是个变种——行列压缩成日历，颜色=提交次数。

### 4. 混淆矩阵

行=真实类别，列=预测类别，值=样本数。对角线越深越好（预测对了），非对角线越浅越好。

### 5. 地理热力图

严格来说不叫 heatmap 叫 choropleth，但大众混着叫。底层是地图，区域颜色=人口/收入/病例数。和矩阵热力图原理一样，只是图形载体不同。

## 怎么画

**Python**（最常用）：
```python
import seaborn as sns
sns.heatmap(data, annot=True, cmap='RdBu_r')
```

**Excel**：条件格式 → 色阶

**Grafana**：Heatmap panel 原生支持时间桶 + 数据桶

## 一句话总结

> 热力图 = 给表格披了一层温度色的皮。你的眼睛比你的逻辑脑更快，先看到红块，再去看具体数字。就是靠这个快，热力图才有价值。
