# 市场择时信号 Loop

## Loop 流程（六步闭环）

```
① Automation 触发（工作日 15:30 收盘后）
    ↓
② 读 state file（上期仓位建议 vs 实际涨跌验证 + 参数表现）
    ↓
③ 根据近期准确率自动调参（阈值偏移/权重调整）
    ↓
④ 拉当日市场数据 → 计算六大指标 → 综合评分 → 输出仓位建议
    ↓
⑤ 对比今日建议 vs 明日实际走势 → 记录验证 → 更新准确率
    ↓
⑥ 产出择时信号表 + 市场状态 → 写入 state file → 发送结果
    ↓
第二天 → ①
```

## 六大择时指标

每天收盘后计算以下指标，综合评分输出仓位建议（满分 100）。

| # | 指标 | 数据源 | 计算方式 | 权重 |
|:---|:---|:---|:---|:---|
| 1 | 涨跌比 | 东方财富行情 | 上涨家数/下跌家数 | 15 |
| 2 | 成交量趋势 | 东方财富行情 | 两市成交额 vs 20日均量 | 15 |
| 3 | 北向资金 | 东方财富 north API | 当日北向净流入/流出 | 20 |
| 4 | 融资余额 | 东方财富 margin API | 融资余额变化方向 | 10 |
| 5 | 指数趋势强度 | 东方财富行情 | MA5/MA20/MA60 多空排列 | 20 |
| 6 | 波动率 | 东方财富行情 | 20日年化波动率百分位 | 20 |

## 评分规则

每项指标 0-100 分，加权求和：

```
综合评分 = 涨跌比×0.15 + 量能×0.15 + 北向×0.20 + 融资×0.10 + 趋势×0.20 + 波动×0.20
```

| 评分区间 | 市场状态 | 仓位建议 |
|:---|:---|:---|
| 80-100 | 🟢 强势 | 重仓 70-100% |
| 60-79 | 🟡 偏强 | 中等 50-70% |
| 40-59 | ⚪ 震荡 | 中性 30-50% |
| 20-39 | 🟠 偏弱 | 轻仓 10-30% |
| 0-19 | 🔴 弱势 | 空仓/防御 0-10% |

## 补充：Regime 分类

如果本地 MongoDB 有足够数据，额外运行 `panda_factor.regime.classifier.DualGridClassifier`：
- 趋势维度：CPI + 价格 MA60 方向
- 波动维度：20日波动率百分位
- 输出：2×3=6 种 regime（牛市高波/牛市常态/牛市低波/熊市高波/熊市常态/熊市低波）

## 自优化规则

读取 state file 验证记录，自动调整：

| 触发条件 | 调整动作 |
|:---|:---|
| 连续 5 天评分方向正确 | 参数锁定，标记稳定 |
| 连续 3 天评分 >60 但指数跌 | 趋势权重 0.15→0.25，北向 0.20→0.15 |
| 连续 3 天评分 <40 但指数涨 | 解除北向依赖，各指标均分权重 |
| 单日评分骤变 >40 点 | 标记异常，不做调参（可能是突发事件） |
| 连续 3 天准确率 < 40% | 暂停 loop，通知人工排查 |

## Gate（停止条件）

- /goal "连续 10 天方向判断正确率 > 70%" → 参数稳定
- 连续 3 天准确率 < 30% → 暂停，排查指标失效原因

## 执行步骤

1. 搜索当日市场概况（涨跌家数、成交额、指数涨跌）
2. 获取北向资金当日净流入（东方财富 north API）
3. 获取融资余额变动（东方财富 margin API）
4. 计算指数趋势（MA5/MA20/MA60 关系）
5. 计算波动率（20日年化标准差及百分位）
6. 六项评分加权汇总
7. 产出仓位建议 + 市场状态
8. 写入 state file
9. 如果本地数据充足，跑 regime classifier 补充分析
10. 发送结果

## 注意事项

- 北向资金数据 15:30 后可用
- 融资余额 T 日数据通常 T+1 日公布，可用前一日数据
- 极端事件（战争、政策突变）模型不适用
- 这是辅助判断工具，不是全自动交易系统
- 每次参数调整必须记录原因
