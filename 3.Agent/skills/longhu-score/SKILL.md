# 龙虎榜量化评分 Loop

## Loop 流程（六步闭环）

```
① Automation 触发（工作日 17:00）
    ↓
② 读 state file（上期验证结果 + 准确率趋势）
    ↓
③ 根据验证结果自动调参（准确率低于阈值→调整技术面权重/追高风险系数）
    ↓
④ 拉当日龙虎榜数据 + 个股行情 → 调用 composite_longhu_score 评分
    ↓
⑤ 对比今日预测 vs 昨日实际涨跌 → 记录验证结果 → 更新准确率
    ↓
⑥ 产出排名表 + 信号等级 → 写入 state file → 发送结果
    ↓
第二天 → ①
```

## 数据来源

1. 东方财富龙虎榜 API / 证券时报龙虎榜报道
2. 东方财富行情 push API（个股实时数据）
3. `/home/dr/code/panda_factor/panda_factor/factors/longhu.py`

## 评分模型

- 资金流评分 × 0.4
- 技术面评分 × 0.3
- 量价评分 × 0.2
- 追高风险惩罚（减法，上限 15）

信号等级：>=70 强 | >=42 中 | >=32 弱 | <32 过滤

## 自优化规则

读取 state file 中前三天的验证结果，按以下规则自动调整：

| 触发条件 | 调整动作 |
|:---|:---|
| 连续 3 天弱信号票涨幅 > 中信号票 | 技术面扣分权重 × 0.8（减少保守） |
| 连续 3 天过滤票涨停 | 追高风险惩罚上限从 15 → 10 |
| 连续 3 天准确率 < 50% | 资金流权重从 0.4 → 0.5，技术面从 0.3 → 0.2 |
| 连续 5 天准确率 > 70% | 参数锁定，标记为稳定状态 |

所有调整记录到 state file 的参数变更日志中。

## 验证方式

- 次日对比：预测信号 vs 实际涨跌
- 指标：准确率、中信号命中率、弱信号过滤命中率
- 每周末汇总周报

## Gate（停止条件）

- /goal "连续 5 天准确率 > 65%" → 参数稳定，降低审查频率
- 连续 3 天准确率 < 40% → 暂停 loop，通知人工排查

## 注意事项

- 龙虎榜数据盘后 16:30-17:00 公布
- 不要直接用于交易决策，这是筛选工具
- 每次参数调整必须记录原因到 state file
- 如果 loop 产出明显异常（全部过滤/全部强信号），自动暂停并通知
