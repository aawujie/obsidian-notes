# 🧠 8 个 Gemini 提示词技巧：把任何视频变成你的私人智囊团

> 别复制专家说什么，复制他们**怎么思考**的。

在信息爆炸的时代，如何从海量视频内容中提取真正有价值的知识？这 8 个提示词技巧能帮你把 YouTube 视频、播客、大师课变成可执行的知识资产。

---

## 1️⃣ 🧠 心智模型提取器

**用途：** 提取专家的思维方式，而非表面知识

**提示词：**
```
分析此视频 [链接]。忽略表面趣事。提取 3-5 个发言人用于决策或解决问题的心智模型、框架或基本原则。
每个模型给我 [你的领域] 的具体应用例子。
```

**适用场景：** 学习行业大佬的思维方式、拆解成功人士的决策逻辑

---

## 2️⃣ 🕵️‍♂️ 烟雾检测器（批判性思维）

**用途：** 识别逻辑漏洞，保护自己免受骗子伤害

**提示词：**
```
深入分析此视频 [链接]。识别作者使用的认知偏差、谬误、过度概括和利益冲突。
给我「事实」vs「观点或操纵」的清单。
```

**适用场景：** 验证投资建议、识别营销话术、批判性学习内容

---

## 3️⃣ 🧬 留存率克隆器（创作者用）

**用途：** 逆向工程爆款视频的成功密码

**提示词：**
```
作为 YouTube 留存率专家。分析此病毒视频 [链接] 的叙事结构。
逐分钟分解脚本：如何构建开场钩子、放置「悬念」和管理节奏。
给我基于此结构的空白模板用于我的 [主题]。
```

**适用场景：** 内容创作者学习爆款公式、提升视频完播率

---

## 4️⃣ ⚙️ 微型 SaaS 或商业翻译器

**用途：** 把哲学视频变成可变现的商业想法

**提示词：**
```
此视频 [链接] 的嘉宾提出多个行业痛点。隔离最痛的问题。
然后提议我 3 个商业想法（微 SaaS、代理或信息产品）来精确解决此问题，各配一句价值主张。
```

**适用场景：** 从播客/访谈中发现创业机会、将洞察转化为产品

---

## 5️⃣ 🥷 蓝海生成器（内容策略）

**用途：** 找到被忽视的盲点，脱颖而出

**提示词：**
```
分析此热门视频 [链接] 的主要论点。共识是什么？
找到盲点（作者未谈及的）。生成 5 个对抗此论点的极端或反主流观点想法。
```

**适用场景：** 内容差异化定位、寻找独特视角、避免同质化竞争

---

## 6️⃣ 📅 日常计划创建器（大规模行动）

**用途：** 把理论转化为可执行的日常计划

**提示词：**
```
把此视频 [链接] 的建议变成 30 分钟日常计划。
第 1 天、第 7 天、第 30 天我该做什么才能获作者结果？
用 Markdown 给我习惯追踪表。
```

**适用场景：** 自我提升、技能学习、将知识转化为行动

---

## 7️⃣ 🗣️ 「潜台词」阅读器（行为分析）

**用途：** 读懂言外之意，理解未说出口的信息

**提示词：**
```
做此采访 [链接] 的语义和行为分析。
嘉宾何时似乎怀疑、防御或特别热情？这些语调变化说明了什么隐瞒或真正在乎的？
```

**适用场景：** 谈判分析、访谈研究、理解真实意图

---

## 8️⃣ 📞 口袋导师（通过 Gemini Live）

**用途：** 把 AI 变成可实时对话的专家导师

**提示词：**
```
吸收此大师课 [链接] 的内容。现在采用视频专家的确切角色。
我会分享或解释情况，用「仅限」视频方法、语调和哲学来指导我。
准备好了？
```

**适用场景：** 实时咨询、角色扮演学习、个性化指导

## 📋 使用建议

| 技巧 | 最佳输入 | 预期输出 |
|------|---------|---------|
| 心智模型 | 专家访谈/演讲 | 3-5 个思维框架 |
| 烟雾检测 | 说服性内容/广告 | 事实 vs 观点清单 |
| 留存率克隆 | 爆款视频 | 脚本结构模板 |
| 商业翻译 | 行业痛点讨论 | 3 个商业想法 |
| 蓝海生成 | 热门内容 | 5 个差异化角度 |
| 日常计划 | 自我提升内容 | 30 天行动计划 |
| 潜台词阅读 | 采访/对话 | 行为分析报告 |
| 口袋导师 | 大师课/教程 | 实时专家指导 |

---

## 💡 进阶用法

1. **组合使用**：先用「心智模型提取器」学习，再用「日常计划创建器」落地
2. **批量处理**：一次性分析同一主题的多个视频，获取全面视角
3. **建立知识库**：将提取的内容保存到笔记系统（如 Obsidian/Notion）
4. **定期复盘**：用「烟雾检测器」重新审视之前学习的内容

---

## ⚠️ 注意事项

- 🔗 **视频链接**：确保 Gemini 能访问该链接（公开视频或提供转录文本）
- 📝 **具体化**：将 `[你的领域]`、`[主题]` 替换为你的具体情况
- 🎯 **迭代优化**：根据输出质量调整提示词细节
- 🧪 **验证输出**：AI 可能产生幻觉，关键信息需二次验证
