# Transformer MLP 如何存储知识

> 基于 3Blue1Brown 视频整理，讲解 MLP 层如何存储"迈克尔·乔丹打篮球"这类事实

---

## 核心问题

大型语言模型如何记住海量事实？
- 输入："迈克尔·乔丹从事的运动是____"
- 输出："篮球"

这些事实存储在哪里？
→ **多层感知器 MLP** 是主要存储位置

---

## Transformer 架构回顾

```
输入文本 → Tokenize → 嵌入向量
              ↓
    ┌─────────────────────┐
    │  注意力机制 (Attention) │ ← 让向量互相传递信息
    └─────────────────────┘
              ↓
    ┌─────────────────────┐
    │     MLP 层           │ ← 存储和检索知识 (本章重点)
    └─────────────────────┘
              ↓
         (重复 N 层)
              ↓
         预测下一个 Token
```

**关键概念**：所有向量都处于极高维空间，不同方向编码不同含义。

---

## 高维空间的语义方向

经典例子：
```
woman - man + uncle ≈ aunt
```

说明：向量空间中存在"性别"这个方向。

**核心思想**：
- 超高维空间中，很多方向对应各种特征
- 向量在网络中流动时，会吸收上下文信息和模型知识
- 最终每个向量编码的内容远超单个单词

---

## MLP 层内部结构

### 简化假设

为了理解，假设存在三个正交方向：

| 方向  | 含义    |
| --- | ----- |
| M   | "迈克尔" |
| J   | "乔丹"  |
| B   | "篮球"  |

**点积规则**：
- 向量与某方向的点积 = 1 → 编码该特征
- 点积 = 0 或负数 → 不匹配该特征

如果向量表示 "迈克尔·乔丹"，则：
- 与 M 方向点积 = 1
- 与 J 方向点积 = 1
- 与 B 方向点积 = 0 (还未编码)

---

## MLP 计算流程

```
输入向量 E (嵌入维度)
    ↓
[上投影] E @ W_up + b_up  → 中间向量 (4×维度)
    ↓
[非线性激活] ReLU/GELU
    ↓
[下投影] @ W_down + b_down → 输出向量 (嵌入维度)
    ↓
残差连接: 输出 + E
```

### 第一步：上投影 (W_up)

```python
# W_up 形状: (嵌入维度, 4×嵌入维度)
# 以 GPT-3 为例: (12288, 49152)

intermediate = E @ W_up + b_up
```

**理解方式**：把 W_up 的每一行看作一个 "探测器"
- 第 i 行与 E 的点积 → 探测 E 是否含有某特征

**例子**：
- 如果某行 = "迈克尔 + 乔丹" (M+J)
- 与 E 点积 = M·E + J·E
- 如果 E 是"迈克尔·乔丹"，结果 = 2
- 如果只是"迈克尔"或只是"乔丹"，结果 = 1

**偏置的作用**：
```
b_up[0] = -1
→ 只有 M·E + J·E = 2 时，结果为正
→ 实现"与门"逻辑：必须同时满足两个条件
```

---

### 第二步：非线性激活 (ReLU)

```python
activated = torch.relu(intermediate)
# 负数 → 0
# 正数 → 保持不变
```

**作用**：
- 实现"开关"效果
- 只有满足特定条件的神经元才会激活
- 在我们的例子中：只有"迈克尔·乔丹"会输出1，其他都是0

**实际使用**：GELU (更平滑的变体)

---

### 第三步：下投影 (W_down)

```python
# W_down 形状: (4×嵌入维度, 嵌入维度)
# 以 GPT-3 为例: (49152, 12288)

output = activated @ W_down + b_down
```

**理解方式**：把 W_down 的每一列看作一个"信息向量"
- 第 j 列 × 第 j 个神经元激活值 → 加到输出
- 不激活的神经元 → 不贡献信息

**例子**：
- 第 0 列 = "篮球"方向
- 当"迈克尔·乔丹"神经元激活时，这一列被加入输出
- 输出向量获得"篮球"方向的成分

---

### 第四步：残差连接

```python
final_output = output + E
```

**结果**：
- 输入向量 E 原本编码"迈克尔·乔丹"
- 经过 MLP 后，自动添加了"篮球"信息
- 现在向量同时编码：人名 + 运动

---

## 完整流程图示

```
输入: [迈克尔·乔丹] 向量
        ↓
┌─────────────────────────────────────┐
│  W_up 第 i 行 = [迈克尔 + 乔丹]      │
│  点积 = 2, 加偏置 -1 = 1 (>0)        │
│  → 第 i 个神经元激活                 │
└─────────────────────────────────────┘
        ↓
┌─────────────────────────────────────┐
│  ReLU: 保持正值                     │
│  其他神经元: 未满足条件 → 0          │
└─────────────────────────────────────┘
        ↓
┌─────────────────────────────────────┐
│  W_down 第 i 列 = [篮球] 方向        │
│  激活值 1 × [篮球] = [篮球]          │
│  加到输出向量                        │
└─────────────────────────────────────┘
        ↓
输出: [迈克尔·乔丹] + [篮球] = [迈克尔·乔丹打篮球]
```

## 真实模型 vs 玩具例子

### 玩具例子的问题

我们的简化假设：
- 存在清晰的"迈克尔·乔丹"神经元
- 每个概念对应一个独立神经元

**现实**：
- 单个神经元很少对应清晰概念
- 概念由**一组神经元组合**表示

### 叠加 (Superposition) 理论

**核心思想**：
- N 维空间中，严格正交的方向最多 N 个
- 但如果允许**近似正交**（90°左右），能存储的方向数量**指数级增长**

**Johnson-Lindenstrauss 引理**：
- 高维空间中，大量随机向量天然接近正交
- 经过优化，可以几乎全部集中在 90° 附近

**对 LLM 的意义**：
- 用远少于特征数的维度，存储海量独立概念
- 规模扩大时，容量提升远快于维度增长
- 单个特征 = 一组神经元的**叠加激活**

---

### ⚠️ 重要修正 (来自作者)

原视频中关于 Johnson-Lindenstrauss 引理的演示代码存在错误：

> "我使用的成本函数（计算 “猜得有多不准”）没有充分惩罚那些点积接近 ±1 的向量对。实际上，在 100 维空间中塞入 10 万个向量，让它们都保持在 (89°, 91°) 范围内是**不可能**的。"

**修正后的关键发现**（来自 Nick Yoder 的研究）：

| 角度约束          | 维度                 | 可容纳向量数                              |
| ------------- | ------------------ | ----------------------------------- |
| 89° (极严格)     | > 250,000          | 才开始有显著效果                            |
| **85°** (较宽松) | 12,288 (GPT-3)     | **> 130 亿** (可能 > 10^41)            |
| **85°**       | 116,000 (GPT-4 级别) | **> Googol (10^100)** (可能 > 10^160) |

**核心结论仍然成立**：
- 近似正交向量的数量确实**指数级增长**
- 但具体在什么维度开始显现效果，取决于角度约束的严格程度
- 对于实际 LLM 的维度（12K+），即使 85° 的宽松约束，容量也是天文数字

参考博客：https://nickyoder.com/johnson-lindenstrauss/

## 关键结论

1. **MLP 是知识存储的主要位置** (占参数 2/3)

2. **存储机制**：
   - W_up：探测特征组合（"与"逻辑）
   - ReLU：非线性筛选
   - W_down：检索关联信息并添加

3. **叠加现象**：
   - 高维空间允许超线性容量增长
   - 特征以分布式方式存储
   - 解释模型的扩展性和难解释性

4. **与注意力机制的分工**：
   - 注意力：整合上下文信息
   - MLP：存储和检索事实知识
