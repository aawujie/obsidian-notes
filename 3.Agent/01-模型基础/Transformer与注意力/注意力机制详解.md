## 二、Query-Key-Value：数据库类比

### 2.1 基本定义

考虑一个数据库 $\mathcal{D} = \{(\mathbf{k}_1, \mathbf{v}_1), \ldots, (\mathbf{k}_m, \mathbf{v}_m)\}$，注意力的核心定义：

$$\text{Attention}(\mathbf{q}, \mathcal{D}) = \sum_{i=1}^{m} \alpha(\mathbf{q}, \mathbf{k}_i) \, \mathbf{v}_i$$

- $\mathbf{q}$：**查询（Query）**，你想要什么
- $\mathbf{k}_i$：**键（Key）**，数据库中每条记录的索引
- $\mathbf{v}_i$：**值（Value）**，数据库中每条记录的内容
- $\alpha(\mathbf{q}, \mathbf{k}_i)$：**注意力权重**，query 与第 $i$ 个 key 的匹配程度

本质：**对所有 value 做加权求和，权重由 query 和 key 的相似度决定。**

### 2.2 权重的几种特殊情况

| 情形 | 含义 |
|---|---|
| $\sum \alpha = 1, \alpha \geq 0$（凸组合） | 深度学习最常见设定 |
| 仅一个 $\alpha = 1$，其余为 0 | 退化为传统数据库精确查询 |
| 所有 $\alpha = 1/m$ | 退化为平均池化（Average Pooling） |

### 2.3 Softmax 归一化

为了保证权重非负且归一，引入任意评分函数 $a(\mathbf{q}, \mathbf{k})$，然后用 softmax：

$$\alpha(\mathbf{q}, \mathbf{k}_i) = \frac{\exp(a(\mathbf{q}, \mathbf{k}_i))}{\sum_j \exp(a(\mathbf{q}, \mathbf{k}_j))}$$

## 三、注意力评分函数

### 3.1 缩放点积注意力（Scaled Dot-Product Attention）

Transformer 使用的核心评分函数：

$$a(\mathbf{q}, \mathbf{k}_i) = \frac{\mathbf{q}^\top \mathbf{k}_i}{\sqrt{d}}$$

**为什么除以 $\sqrt{d}$？**

假设 $\mathbf{q}, \mathbf{k} \in \mathbb{R}^d$，各分量独立同分布、均值 0、方差 1，那么：
- 点积 $\mathbf{q}^\top \mathbf{k}$ 的均值 = 0
- 点积 $\mathbf{q}^\top \mathbf{k}$ 的方差 = $d$

如果不缩放，$d$ 很大时点积值会很大，softmax 会进入**梯度极小的饱和区**。除以 $\sqrt{d}$ 让方差回到 1。

**矩阵批量形式**（$n$ 个 query，$m$ 个 key-value 对）：

$$\text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d}}\right) \mathbf{V} \in \mathbb{R}^{n \times v}$$

### 3.2 加性注意力（Additive Attention）

当 query 和 key **维度不同**时使用（Bahdanau 2014）：

$$a(\mathbf{q}, \mathbf{k}) = \mathbf{w}_v^\top \tanh(\mathbf{W}_q \mathbf{q} + \mathbf{W}_k \mathbf{k})$$

- $\mathbf{W}_q \in \mathbb{R}^{h \times q}$，$\mathbf{W}_k \in \mathbb{R}^{h \times k}$，$\mathbf{w}_v \in \mathbb{R}^h$ 均可学习
- 本质：query 和 key 分别线性映射到同一空间后相加，过一个单隐藏层 MLP

### 3.3 两者对比

| | 缩放点积 | 加性注意力 |
|---|---|---|
| 要求 | $d_q = d_k$ | $d_q$ 和 $d_k$ 可不同 |
| 参数量 | 0（无额外参数） | $\mathbf{W}_q, \mathbf{W}_k, \mathbf{w}_v$ |
| 计算效率 | 更高（矩阵乘法） | 略低 |
| 使用场景 | Transformer | 早期 seq2seq |

## 四、Masked Softmax

处理变长序列的 padding 问题：
- 将超出有效长度的位置的 score 设为 $-10^6$
- 经 softmax 后这些位置的权重趋近于 0
- 比 if-else 条件判断更高效（GPU 友好）

```python
# 示意
X[~mask] = -1e6
softmax(X)  # 被 mask 的位置权重 ≈ 0
```

## 五、多头注意力（Multi-Head Attention）

### 5.1 动机

单个注意力头只能学习一种模式。多头注意力让模型在**不同的表示子空间**中并行学习不同的依赖关系（如局部语法 vs 长距离语义）。

### 5.2 数学形式

每个注意力头 $\mathbf{h}_i$（$i = 1, \ldots, h$）：

$$\mathbf{h}_i = f(\mathbf{W}_i^{(q)}\mathbf{q}, \mathbf{W}_i^{(k)}\mathbf{k}, \mathbf{W}_i^{(v)}\mathbf{v}) \in \mathbb{R}^{p_v}$$

拼接所有头并线性变换：

$$\text{MultiHead} = \mathbf{W}_o \begin{bmatrix}\mathbf{h}_1 \\ \vdots \\ \mathbf{h}_h\end{bmatrix} \in \mathbb{R}^{p_o}$$

### 5.3 参数设置

为控制计算量，令 $p_q = p_k = p_v = p_o / h$，这样总参数量与单头大致相当。

### 5.4 实现技巧

通过 **reshape + transpose** 将多头并行化为 batch 维度，复用 `DotProductAttention`：

```
(batch_size, seq_len, num_hiddens)
→ reshape: (batch_size, seq_len, num_heads, num_hiddens/num_heads)
→ transpose: (batch_size, num_heads, seq_len, num_hiddens/num_heads)
→ reshape: (batch_size * num_heads, seq_len, num_hiddens/num_heads)
```

## 六、自注意力 vs 交叉注意力

### 6.1 两种注意力的区别

注意力机制按 Q、K、V 的来源分为两大类：

| | 自注意力（Self-Attention） | 交叉注意力（Cross-Attention） |
|---|---|---|
| **Q 来自** | 同一个序列 | 序列 A（如解码器） |
| **K, V 来自** | 同一个序列 | 序列 B（如编码器） |
| **核心问题** | "句子里哪些词对理解**我**最重要？" | "另一个序列里哪些部分与**我**最相关？" |
| **典型场景** | 编码器内部、解码器内部 | 翻译（解码器关注编码器）、图文匹配 |
| **权重矩阵形状** | $n \times n$（序列自身长度） | $n \times m$（目标长度 × 源长度） |
| **在 Transformer 中** | 编码器的每一层 + 解码器的第一个注意力子层 | 解码器的第二个注意力子层 |

### 6.2 直觉对比

**自注意力**（Self-Attention）：
- "小明因为太累了所以他睡着了" → "他"关注"小明"（代词指代），"睡着"关注"累"（因果）
- 每个词去**同一句话**里找相关的词

**交叉注意力**（Cross-Attention）：
- 翻译 "The cat sat on the mat" → "猫"关注 "cat"，"垫子"关注 "mat"
- 目标句的每个词去**源句**里找对应的词

### 6.3 Transformer 中的三种注意力

在完整的 Transformer 架构中，实际使用了**三种**注意力：

1. **编码器自注意力**：编码器内部，源序列的每个 token 互相关注
2. **解码器自注意力（带掩码）**：解码器内部，目标序列的每个 token 只能关注**之前**的 token（不能偷看未来的答案）
3. **编码器-解码器交叉注意力**：解码器的每个 token 去关注编码器的所有 token

> 详见 [[注意力机制入门图解]] 中的翻译演示和自注意力演示

### 6.4 自注意力的数学定义

Q、K、V 全部来自**同一个序列**：

$$\mathbf{y}_i = f(\mathbf{x}_i, (\mathbf{x}_1, \mathbf{x}_1), \ldots, (\mathbf{x}_n, \mathbf{x}_n))$$

每个 token 都可以直接"看到"序列中所有其他 token。

### 6.5 CNN vs RNN vs Self-Attention 对比

| 架构 | 计算复杂度 | 顺序操作 | 最长路径 |
|---|---|---|---|
| CNN（核大小 $k$） | $O(knd^2)$ | $O(1)$ | $O(n/k)$ |
| RNN | $O(nd^2)$ | $O(n)$ ❌ | $O(n)$ |
| Self-Attention | $O(n^2 d)$ | $O(1)$ ✅ | $O(1)$ ✅ |

**Self-Attention 优势**：
- 最短路径 $O(1)$：任意两个 token 一步直达，利于长距离依赖
- 完全并行：无顺序依赖

**代价**：$O(n^2)$ 复杂度，对超长序列不友好。

## 七、位置编码（Positional Encoding）

### 7.1 问题

自注意力具有**置换不变性**，对 token 顺序完全不敏感。

### 7.2 固定三角函数编码（Vaswani 2017）

位置编码矩阵 $\mathbf{P} \in \mathbb{R}^{n \times d}$，直接加到输入 $\mathbf{X}$ 上：

$$p_{i,2j} = \sin\left(\frac{i}{10000^{2j/d}}\right), \quad p_{i,2j+1} = \cos\left(\frac{i}{10000^{2j/d}}\right)$$

### 7.3 为什么这个设计有效？

**绝对位置信息**：
- 不同维度频率从高到低递减
- 类似二进制计数器：低位翻转快，高位翻转慢
- 可以唯一标识每个位置

**相对位置信息**：
对于固定偏移 $\delta$，位置 $i + \delta$ 的编码可以通过位置 $i$ 的编码经旋转矩阵线性变换得到：

$$\begin{bmatrix} \cos(\delta\omega_j) & \sin(\delta\omega_j) \\ -\sin(\delta\omega_j) & \cos(\delta\omega_j) \end{bmatrix} \begin{bmatrix} p_{i,2j} \\ p_{i,2j+1} \end{bmatrix} = \begin{bmatrix} p_{i+\delta,2j} \\ p_{i+\delta,2j+1} \end{bmatrix}$$

旋转矩阵**仅依赖 $\delta$**，不依赖位置 $i$，模型可以学习这个变换来捕获相对位置。

## 八、从 Nadaraya-Watson 到现代注意力

### 8.1 核回归（1964）

Nadaraya-Watson 估计器：

$$f(\mathbf{q}) = \sum_i \mathbf{v}_i \frac{\alpha(\mathbf{q}, \mathbf{k}_i)}{\sum_j \alpha(\mathbf{q}, \mathbf{k}_j)}$$

常用核函数：

| 核 | 公式 | 特点 |
|---|---|---|
| Gaussian | $\exp(-\frac{1}{2}\|\mathbf{q}-\mathbf{k}\|^2)$ | 平滑，无界 |
| Boxcar | $\mathbb{1}[\|\mathbf{q}-\mathbf{k}\| \leq 1]$ | 硬截断 |
| Epanechnikov | $\max(0, 1 - \|\mathbf{q}-\mathbf{k}\|)$ | 线性衰减 |

### 8.2 演进关系

```
核回归（手工核函数，不可学习）
    ↓
Bahdanau Attention（加性评分函数，可学习权重）
    ↓
Scaled Dot-Product Attention（高效，Transformer 标配）
    ↓
Multi-Head Attention（多个子空间并行）
    ↓
Self-Attention + 位置编码 → Transformer
```

## 九、关键洞察

1. **注意力 = 可微的、可学习的加权平均**。动态决定"关注什么"
2. **缩放点积是效率和效果的最佳平衡**。距离函数更直观但计算更贵，点积 + softmax 在 GPU 上极其高效
3. **多头让模型同时捕获不同粒度的模式**。一些头关注局部语法，另一些头关注长距离语义
4. **位置编码解决"注意力没有位置感"的问题**。三角函数编码同时提供绝对和相对位置信息
5. **Self-Attention 的 $O(1)$ 路径长度是 Transformer 成功的关键**——但 $O(n^2)$ 代价催生了 Linear Attention、Flash Attention 等优化
