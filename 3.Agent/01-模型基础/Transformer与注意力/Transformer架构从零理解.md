## 0. Transformer 是什么？

一句话：**Transformer = 编码器 + 解码器，全部由注意力机制构成，不用 RNN 也不用 CNN。**

它是 2017 年 Google "Attention Is All You Need" 论文提出的架构，后来成为 BERT、GPT、ChatGPT 等所有大模型的骨架。

---

## 1. 整体架构：左边编码，右边解码

```
输入序列（如英文）                    输出序列（如法文）
    ↓                                    ↓
 词嵌入 + 位置编码                    词嵌入 + 位置编码
    ↓                                    ↓
┌─────────────┐                   ┌──────────────────┐
│  编码器层 ×N │                   │   解码器层 ×N     │
│             │                   │                  │
│ ┌─────────┐ │                   │ ┌──────────────┐ │
│ │自注意力  │ │                   │ │掩码自注意力   │ │
│ │+Add&Norm │ │                   │ │+Add&Norm     │ │
│ └─────────┘ │                   │ └──────────────┘ │
│ ┌─────────┐ │    编码器输出      │ ┌──────────────┐ │
│ │前馈网络  │ │ ──────────────→  │ │交叉注意力     │ │
│ │+Add&Norm │ │   (K, V)         │ │+Add&Norm     │ │
│ └─────────┘ │                   │ └──────────────┘ │
└─────────────┘                   │ ┌──────────────┐ │
                                  │ │前馈网络       │ │
                                  │ │+Add&Norm     │ │
                                  │ └──────────────┘ │
                                  └──────────────────┘
                                          ↓
                                    线性层 + Softmax
                                          ↓
                                      输出词概率
```

### 关键点

| 组件 | 编码器有 | 解码器有 | 作用 |
|---|---|---|---|
| 自注意力 | ✅ | ✅（带掩码） | 序列内部建模 |
| 交叉注意力 | ❌ | ✅ | 解码器关注编码器 |
| 前馈网络 (FFN) | ✅ | ✅ | 对每个位置独立变换 |
| Add & Norm | ✅ | ✅ | 残差连接 + 层归一化 |
| 位置编码 | ✅ | ✅ | 注入位置信息 |

## 2. 编码器：一层的内部

编码器由 N 个相同的层堆叠而成（原论文 N=6）。每层包含两个子层：

### 子层 1：多头自注意力

```
输入 X (n×d)
  ↓
MultiHead Self-Attention(Q=X, K=X, V=X)  ← Q、K、V 都是自己
  ↓ 输出 Y (n×d)
  ↓
X + Y  ← 残差连接（把输入加回来）
  ↓
LayerNorm  ← 层归一化
  ↓
输出（形状不变，还是 n×d）
```

### 子层 2：前馈网络 (FFN)

```
输入 Z (n×d)
  ↓
Linear(d → 4d) → ReLU → Linear(4d → d)  ← 两层 MLP
  ↓ 输出 W (n×d)
  ↓
Z + W  ← 残差连接
  ↓
LayerNorm
  ↓
输出（形状不变，还是 n×d）
```

**重要特性**：每一层都**不改变形状**。输入是 n×d，输出还是 n×d。这使得层可以任意堆叠。

---

## 3. 解码器：比编码器多一个子层

解码器每层有**三个**子层：

### 子层 1：掩码自注意力（Masked Self-Attention）

和编码器的自注意力一样，但有一个关键区别：**不能看未来的词**。

为什么？因为在生成翻译时是逐词生成的：
- 生成第 1 个词时，只能看到 `<开始>` 
- 生成第 2 个词时，只能看到 `<开始>` 和第 1 个词
- 生成第 3 个词时，只能看到 `<开始>`、第 1 个词、第 2 个词
- ...

如果能看到未来的词，那就是"作弊"了！

**实现方式**：用一个下三角掩码矩阵：

```
      位置0  位置1  位置2  位置3
位置0 [  1     0     0     0  ]  ← 只能看自己
位置1 [  1     1     0     0  ]  ← 能看位置0和自己
位置2 [  1     1     1     0  ]  ← 能看位置0、1和自己
位置3 [  1     1     1     1  ]  ← 能看所有已生成的
```

0 的位置在 softmax 前被设为 -∞，softmax 后变成 0 权重。

### 子层 2：交叉注意力（Cross-Attention）

- **Query** 来自解码器（"我正在翻译什么？"）
- **Key, Value** 来自编码器（"原文说了什么？"）

这就是解码器"查看原文"的方式。

### 子层 3：前馈网络

和编码器完全一样。

---

## 4. 残差连接：为什么要把输入加回来？

### 问题

深层网络训练时容易出现**梯度消失**——反向传播的信号经过太多层后变得极小，前面的层几乎学不到东西。

### 解决方案

```
输入 X → [子层处理] → 输出 Y
           ↓
      最终输出 = X + Y（把原始输入直接加到输出上）
```

### 直觉类比

想象你在写论文的第五版修改稿：
- **没有残差**：每次修改都完全重写 → 容易丢失好的部分
- **有残差**：每次修改 = 上一版 + 增量修改 → 保留好的部分，只修改需要改的

### 数学好处

梯度可以通过残差连接**直接回传**到前面的层，不会被中间的变换"稀释"。这就是为什么 Transformer 可以堆叠很多层（GPT-3 有 96 层！）。

---

## 5. Layer Normalization：稳定训练

### 是什么？

对每个样本的**特征维度**做归一化（减均值、除标准差），让每层的输入分布稳定。

### 和 Batch Normalization 的区别

| | BatchNorm | LayerNorm |
|---|---|---|
| 归一化方向 | 跨 batch（同一特征） | 跨特征（同一样本） |
| 依赖 batch 大小 | 是 | 否 |
| 适合场景 | CV（图像大小固定） | NLP（序列长度变化） |

LayerNorm 不依赖 batch 大小，更适合序列长度不固定的 NLP 任务。

---

## 6. 前馈网络 (FFN)：每个位置独立"思考"

```
FFN(x) = ReLU(x · W₁ + b₁) · W₂ + b₂
```

- 就是一个两层的 MLP（多层感知机）
- 中间维度通常是 4 倍（d → 4d → d）
- **关键**：对序列中的每个位置**独立**应用同一个 MLP

### 为什么需要 FFN？

自注意力擅长**混合信息**（把不同位置的信息加权组合），但不擅长**变换信息**（对单个位置做复杂计算）。FFN 弥补了这一点。

### 类比

- 自注意力 = 开会讨论（大家交流信息）
- FFN = 会后各自思考（每个人独立消化信息）

## 7. 完整数据流示例

以翻译 "I am a student" → "我 是 学生" 为例：

### 编码阶段

```
"I am a student"
    ↓
词嵌入: 每个词 → 512维向量
    ↓
+ 位置编码
    ↓
编码器第1层:
  自注意力: "I"看到所有词 → 综合理解
  FFN: 每个位置独立变换
    ↓
编码器第2层: 同上
    ↓
...
    ↓
编码器第6层: 输出 4×512 矩阵（4个词，每词512维）
```

### 解码阶段（逐词生成）

```
步骤1: 输入 <开始>
  掩码自注意力: 只看 <开始>
  交叉注意力: 看编码器输出 → 关注 "我"
  FFN → 预测: "我"

步骤2: 输入 <开始> 我
  掩码自注意力: 只看 <开始> 和 "我"
  交叉注意力: 看编码器输出 → 关注 "am"
  FFN → 预测: "是"

步骤3: 输入 <开始> 我 是
  掩码自注意力: 只看 <开始>、"我"、"是"
  交叉注意力: 看编码器输出 → 关注 "student"
  FFN → 预测: "学生"

步骤4: 预测出 <结束> → 停止
```

## 8. 重要超参数

| 参数 | 原论文 (Base) | 原论文 (Big) | 含义 |
|---|---|---|---|
| d_model | 512 | 1024 | 词嵌入和隐藏层维度 |
| N | 6 | 6 | 编码器/解码器层数 |
| h | 8 | 16 | 注意力头数 |
| d_ff | 2048 | 4096 | FFN 中间维度 |
| d_k = d_v | 64 | 64 | 每个头的维度 = d_model / h |

## 9. 关键洞察总结

1. **Transformer = 编码器 + 解码器**，但也可以单独使用：
   - 只用编码器 → BERT（理解类任务）
   - 只用解码器 → GPT（生成类任务）
   - 编码器 + 解码器 → T5（翻译等 seq2seq 任务）

2. **残差连接**是能训练深层网络的关键——梯度可以直通回传

3. **掩码自注意力**保证解码时不会"偷看未来"

4. **FFN 补充了注意力的不足**——注意力混合信息，FFN 变换信息

5. **所有层都不改变形状**（n×d → n×d），所以可以任意堆叠
