# 熵、交叉熵与 KL 散度：大模型的数学基础

> 来源：Artem Kirsanov - The Science of Surprise  
> 视频：https://youtu.be/KHVR587oW8I

---

## 引言：概率思维的本质

想象你在雾中行走，前方有一个模糊的移动物体——是流浪狗？是猫？还是风吹的垃圾袋？

在这种不确定的情况下，你的大脑不会只选一个答案，而是会同时考虑多种可能性，每种都有自己的概率。这就是**概率思维**的本质：面对不完整信息时，自然地用可能性和不确定性来思考。

这种概率视角也是现代机器学习的核心。许多计算问题——从生物大脑到人工智能——都可以归结为三个步骤：
1. **学习**数据的概率分布
2. **推断**（inference）
3. **采样**生成新数据（生成式建模）

描述概率和不确定性的语言建立在几个关键概念上：**熵**、**交叉熵**、**KL 散度**。这些概念如此基础，以至于它们出现在从最新的扩散模型到生物大脑的感知理论（如自由能原理）等各个领域。

## 一、概率分布基础

### 1.1 什么是概率分布

概率分布是一个抽象概念：
- 有一组**可能的状态**（outcomes）
- 给每个状态分配一个 0 到 1 之间的正数
- 这个数反映了我们对该状态发生可能性的 **信念程度**

### 1.2 两种概率解释

| 学派                    | 核心观点        | 适用场景           |
| --------------------- | ----------- | -------------- |
| **频率派 (Frequentist)** | 概率是长期实验中的比例 | 掷骰子、抛硬币（可重复实验） |
| **贝叶斯派 (Bayesian)**   | 概率是信念程度     | 天气预报（一次性事件）    |

**关键区别：**
- 频率派："明天下雨概率 70%" 无法解释（明天只发生一次）
- 贝叶斯派："明天下雨概率 70%" 表示我们对"下雨"这个结果的信念程度是 0.7

### 1.3 概率分布的基本性质

**归一化约束：** 所有可能状态的概率之和必须等于 1

$$
\sum_i P(x_i) = 1
$$

这意味着：**调整一个状态的概率必然影响其他状态** —— 概率分布是一个整体。

### 1.4 高维分布

**一维例子：** 身高分布（连续变量）
- 服从钟形的高斯分布
- 曲线下面积 = 1（连续版本的归一化）

**高维例子：** 图像生成
- 100×100 像素的图像位于 **10,000 维空间**
- 每个像素是一个维度
- 生成模型需要学习这个高维空间中的概率分布

**采样（Sampling）：**
从分布中生成新样本的过程。例如：
- 掷骰子 = 从均匀分布采样
- 图像生成 = 从高维图像分布采样（生成真实图像而非噪声）

## 二、惊讶度（Surprisal）

### 2.1 直觉理解

- 有人猜中硬币结果 → 有点惊讶，但不太多（概率 50%）
- 有人猜中骰子结果 → 更惊讶（概率 16.7%）
- 有人猜中彩票号码 → 极度惊讶（概率极低）

**规律：** 事件概率越低，惊讶度越高。

### 2.2 数学定义

惊讶度需要满足两个关键性质：

1. **单调性**：**概率越小，惊讶度越大**；概率为 1 时，惊讶度为 0
2. **可加性**：独立事件的联合惊讶度等于各自惊讶度之和

满足这两个性质的函数是：**对数**

$$
\text{Surprisal}(x) = -\log P(x) = \log \frac{1}{P(x)}
$$

**验证可加性：**
- 两个独立事件：$P(A \cap B) = P(A) \cdot P(B)$
- 惊讶度：$-\log(P(A) \cdot P(B)) = -\log P(A) - \log P(B)$
- 确实相加！

## 三、熵（Entropy）

### 3.1 定义

**熵是概率分布的平均惊讶度。**

$$
H(P) = \mathbb{E}_{x \sim P}[\text{Surprisal}(x)] = -\sum_i P(x_i) \log P(x_i)
$$

### 3.2 直观理解

**例子：厚硬币**
- 正面：49%
- 反面：49%
- 侧面：2%

计算：
- 正面/反面的惊讶度：$-\log(0.49) \approx 0.7$
- 侧面的惊讶度：$-\log(0.02) \approx 4$
- 平均惊讶度（熵）：$0.98 \times 0.7 + 0.02 \times 4 \approx 0.8$

**对比：公平硬币**
- 熵 = 1（更高）

**结论：** 厚硬币的熵更低，因为侧面虽然惊讶度高但发生概率低，大部分时间（98%）都是低惊讶度的正面/反面。

### 3.3 熵的意义

- **熵衡量分布中固有的不确定性**
- 均匀分布熵最大（最不确定）
- 确定性分布（一个状态概率为1）熵为0

## 四、交叉熵（Cross-Entropy）

### 4.1 现实问题：我们不知道真实分布

计算熵需要知道真实的概率分布 $P$，但现实中：
- 真实分布通常是隐藏的、极其复杂的
- 我们只有**内部模型** $Q$ —— 我们认为的概率分布

### 4.2 交叉熵的定义

**交叉熵衡量：用模型 $Q$ 去解释真实分布 $P$ 时的平均惊讶。**

$$
H(P, Q) = -\sum_i P(x_i) \log Q(x_i)
$$

**关键区别：**
- 真实结果按 $P$ 分布
- 但惊讶度按 $Q$ 计算（因为我们相信的是 $Q$）

### 4.3 惊讶的两个来源

当我们观察到结果时，惊讶可能来自：

1. **数据固有的不确定性**（熵 $H(P)$）
2. **模型与现实的偏差**（模型错误）

**公式关系：**

$$
H(P, Q) = H(P) + D_{KL}(P \| Q)
$$

交叉熵 = 熵 + KL散度

### 4.4 关键性质：非对称性

交换 $P$ 和 $Q$ 会得到不同的交叉熵！

**例子 1：相信公平硬币，实际是作弊硬币**
- $P$：99% 正面，1% 反面（作弊）
- $Q$：50% 正面，50% 反面（公平）
- 交叉熵 $H(P, Q) \approx 0.7$

**例子 2：相信作弊硬币，实际是公平硬币**
- $P$：50% 正面，50% 反面（公平）
- $Q$：99% 正面，1% 反面（作弊）
- 交叉熵 $H(P, Q) \approx 2.3$

**为什么差异大？**
- 例子 2 中，看到反面时极度惊讶（模型预测概率仅 1%）
- 这种极端惊讶主导了平均值

### 4.5 重要不等式

$$
H(P, Q) \geq H(P)
$$

**含义：** 相信错误的模型只会增加惊讶，永远不会减少。

## 五、KL 散度（Kullback-Leibler Divergence）

### 5.1 动机

交叉熵包含两部分：
1. 数据固有的不确定性（我们无法控制）
2. 模型带来的额外惊讶（我们可以改进）

能否**分离出纯模型偏差**？

### 5.2 定义

**KL 散度 = 交叉熵 - 熵**

$$
D_{KL}(P \| Q) = H(P, Q) - H(P) = \sum_i P(x_i) \log \frac{P(x_i)}{Q(x_i)}
$$

**直观理解：**
- 使用模型 $Q$ 而非真实分布 $P$ 所带来的**额外惊讶**
- 隔离了模型错误造成的惊讶

### 5.3 性质

| 性质 | 说明 |
|------|------|
| **非负性** | $D_{KL}(P \| Q) \geq 0$ |
| **非对称性** | $D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$ |
| **零点** | $D_{KL}(P \| P) = 0$（完美模型） |

### 5.4 在机器学习中的应用

**目标：** 训练神经网络逼近真实数据分布

**过程：**
1. 用神经网络参数化一个分布 $Q_\theta$（$\theta$ 是可学习参数）
2. 目标：使 $Q_\theta$ 尽可能接近真实分布 $P$
3. 优化目标：最小化 $D_{KL}(P \| Q_\theta)$

**为什么代码里看到的是交叉熵而非 KL 散度？**

$$
\min_\theta D_{KL}(P \| Q_\theta) = \min_\theta [H(P, Q_\theta) - H(P)]
$$

由于 $H(P)$ 是常数（真实数据的固有属性，与模型无关），最小化 KL 散度 **等价于** 最小化交叉熵！

**实践中：**
- 使用交叉熵作为损失函数
- 不关心 KL 散度的具体数值，只关心它是否最小
- 省去估计 $H(P)$ 的计算开销

## 六、总结与联系

### 6.1 概念层次

```
惊讶度 (Surprisal)     : -log P(x)  —— 单个事件的惊讶
    ↓
熵 (Entropy)           : E[Surprisal]  —— 平均惊讶（固有不确定性）
    ↓
交叉熵 (Cross-Entropy) : 用模型Q解释真实分布P的平均惊讶
    ↓
KL散度 (KL Divergence) : CrossEntropy - Entropy  —— 纯模型偏差
```

### 6.2 核心公式

$$
\boxed{H(P, Q) = H(P) + D_{KL}(P \| Q)}
$$

**交叉熵 = 数据不确定性 + 模型偏差**

### 6.3 在生成模型中的作用

| 概念 | 作用 |
|------|------|
| **熵** | 衡量数据本身的复杂度/多样性 |
| **交叉熵** | 训练时的实际损失函数 |
| **KL 散度** | 理论上的优化目标，衡量模型与真实的差距 |

### 6.4 直观记忆

- **熵**：上帝视角的平均惊讶（知道真实分布）
- **交叉熵**：凡人视角的平均惊讶（用模型猜测）
- **KL 散度**：凡人比上帝多惊讶的部分（模型错误的代价）

## 七、关键问题：实际计算中 P 从哪里来？

### 7.1 理论 vs 实践

**理论定义：** P 是完美的、未知的真实分布  
**实际问题：** 我们不知道 P，怎么计算交叉熵和 KL 散度？

**答案：用经验分布（Empirical Distribution）代替真实分布**

### 7.2 经验分布是什么？

从训练数据中统计得到的分布：

$$
P̂(x) = \frac{\text{训练数据中 } x \text{ 出现的次数}}{\text{总样本数}}
$$

### 7.3 不同任务中的 P

#### 分类任务（监督学习）

**P 是 one-hot 标签：**
```
真实标签是"猫" → P = [1, 0, 0]
真实标签是"狗" → P = [0, 1, 0]
真实标签是"鸟" → P = [0, 0, 1]
```

**实际计算：**
```python
# PyTorch 示例
loss = F.cross_entropy(logits, target_label)
# 内部：用 target_label 构造 one-hot P，然后计算 H(P, Q)
```

#### 生成任务（无监督学习）

**P 是真实数据样本：**
- 从 ImageNet、CelebA 等数据集中采样真实图像
- 模型生成图像（分布 Q）
- 比较两者的差异

**挑战：** 高维空间（如 10000 维图像空间）中 P 极其复杂，无法显式表示

**解决方案：**
| 方法 | 思路 |
|------|------|
| **GAN** | 用判别器区分真实图像和生成图像 |
| **VAE** | 变分推断，近似后验分布 |
| **扩散模型** | 直接学习得分函数，无需显式 P |

### 7.4 数学细节：样本平均代替期望

**理论公式：**

$$
H(P, Q) = -\sum_i P(x_i) \log Q(x_i)
$$

**实际计算（用 N 个样本估计）：**

$$
H(P, Q) \approx -\frac{1}{N} \sum_{n=1}^{N} \log Q(x_n)
$$

其中 $x_n$ 是从训练数据中采样的样本。

### 7.5 具体示例：图像分类

```python
# 3 类分类：猫、狗、鸟
# 输入图片的真实标签是"猫"

# P（经验分布）：one-hot
P = [1, 0, 0]  # 100% 是猫

# Q（模型预测）：softmax 输出  
Q = [0.7, 0.2, 0.1]  # 模型认为 70% 猫，20% 狗，10% 鸟

# 交叉熵计算
H(P, Q) = -[1·log(0.7) + 0·log(0.2) + 0·log(0.1)]
        = -log(0.7)
        ≈ 0.357
```

### 7.6 核心总结

| 概念 | 理论定义 | 实际实现 |
|------|---------|---------|
| **真实分布 P** | 完美的、未知的理论分布 | **经验分布**（从训练样本统计） |
| **模型分布 Q** | 神经网络参数化的分布 | softmax 输出、高斯分布等 |

**一句话理解：**
> 理论上 P 是完美的真实分布，实践中 P 是我们从训练数据中观察到的**经验分布**。我们用经验分布代替真实分布来计算交叉熵，用样本平均代替期望。

## 核心要点回顾

1. **概率分布**是描述不确定性的语言
2. **惊讶度** $-\log P$ 满足概率相乘时惊讶相加的直觉
3. **熵**是平均惊讶度，衡量分布的固有不确定性
4. **交叉熵**是用错误模型时的平均惊讶，包含数据和模型两部分不确定性
5. **KL 散度**分离出纯模型偏差，是机器学习的核心优化目标
6. 实践中用**交叉熵**作为损失函数，因为它与 KL 散度等价且更易计算

> 下次遇到"最小化交叉熵"时，记住它不是在优化某个神秘公式，而是在**最小化我们的模型与现实之间的差距**。
