> 整理日期：2026-03-19

## 0. 前置概念：什么是"维度"？

在深度学习里，**每个词不是一个数字，而是一组数字**。

### 类比 RGB 颜色
- 红色 = `[255, 0, 0]` → 有 **3 个维度**（R, G, B）
- 每个维度描述颜色的一个"方面"

### 词也一样
- "猫" = `[0.3, -0.5, 0.8, 0.1]` → 有 **4 个维度**
- 每个维度描述这个词的一个"语义方面"（模型自己学出来的，人类不一定能解释）
- 实际 Transformer 用 **512 维** 或 **768 维**

### 一句话 = 一个矩阵

5 个词、每词 4 维 → 一个 **5×4 的表格**：

| | 维度0 | 维度1 | 维度2 | 维度3 |
|---|---|---|---|---|
| 猫 | 0.3 | -0.5 | 0.8 | 0.1 |
| 坐 | 0.7 | 0.2 | -0.3 | 0.6 |
| 在 | -0.1 | 0.4 | 0.5 | -0.2 |
| 垫子 | 0.5 | -0.3 | 0.6 | 0.4 |
| 上 | 0.2 | 0.1 | -0.1 | 0.3 |

总数据量 = 词数 n × 维度数 d。BERT 中：512 个 token × 768 维 ≈ **40 万个数字**（GPU 轻松处理）。

## 1. 为什么需要位置编码？

### 问题所在

Self-Attention 做的事情是：每个词和**所有词**算相似度，然后加权求和。

这个过程**完全不关心词的顺序**：
- "猫吃鱼" 和 "鱼吃猫" 对模型来说是同一个词集合 {猫, 吃, 鱼}
- 打乱顺序，计算结果不变

### 这很要命

语言中顺序至关重要："我打你" ≠ "你打我"。

### 解决思路

给每个**位置**（第 0 个词、第 1 个词、第 2 个词…）一个独特的"身份证"，**加到**词的表示上。这样模型就知道谁在前、谁在后。

---

## 2. 最简单但有问题的方案

### 方案 A：直接用数字编号

位置 0 → 加 0，位置 1 → 加 1，位置 2 → 加 2 …

**问题**：
1. 数值范围不固定（句子 10 个词 vs 1000 个词，数值差太大）
2. 没有泛化性（训练时见过 100 个词的句子，推理时遇到 200 个词就不认识"位置 150"）
3. 数值可能和词嵌入本身的数值量级不匹配

### 方案 B：归一化到 [0, 1]

位置 0 → 0.0，最后一个位置 → 1.0

**问题**：同一个"0.5"，在 10 个词的句子里是第 5 个，在 100 个词的句子里是第 50 个。同一个数字表示不同的位置，模型会混淆。

---

## 3. Transformer 的方案：用"波"标记位置

### 核心思路：从二进制时钟出发

数 0~7 的二进制表示：

```
位置 0: 0 0 0
位置 1: 0 0 1  ← 最右位每次翻转（快）
位置 2: 0 1 0  ← 中间位每 2 次翻转
位置 3: 0 1 1
位置 4: 1 0 0  ← 最左位每 4 次翻转（慢）
位置 5: 1 0 1
位置 6: 1 1 0
位置 7: 1 1 1
```

**关键观察**：
- 每一位（维度）有**不同的翻转频率**
- 组合起来，**每个数字都有唯一编码**

### 从二进制到正弦波

| 二进制时钟 | 正弦/余弦编码 |
|---|---|
| 每一位用 0/1 翻转 | 每一维用 sin/cos 波动 |
| 不同位有不同的翻转频率 | 不同维有不同的波动频率 |
| 组合 → 唯一编码 | 组合 → 唯一编码 |
| **缺点**：不连续（跳跃式） | **优点**：连续且平滑（可微分） |

### 具体公式

位置 $i$、维度 $2j$ 和 $2j+1$ 的编码：

$$p_{i,2j} = \sin\left(\frac{i}{10000^{2j/d}}\right), \quad p_{i,2j+1} = \cos\left(\frac{i}{10000^{2j/d}}\right)$$

不需要记公式，理解要点：
- **分子 $i$**：位置越大，角度越大，sin/cos 值就不同
- **分母 $10000^{2j/d}$**：维度 $j$ 越大，分母越大，频率越低（波越慢）

---

## 4. 不同维度的波形

### 高频维度（维度 0-1）

- 波动**非常快**
- 相邻位置（如位置 3 和 4）的编码值差异很大
- 作用：**区分近距离位置**

### 低频维度（维度 4-5）

- 波动**非常慢**
- 相邻位置的编码值几乎一样，但位置 0 和位置 50 的值很不同
- 作用：**区分远距离位置**

### 类比 GPS

GPS 用**多颗卫星**定位：每颗卫星提供一个维度的信息，合在一起就能精确定位。

位置编码也一样：每个维度提供一个"频率"的信息，**合在一起就能唯一标识每个位置**。

## 5. 实际数值示例

假设用 6 维位置编码（实际用 512 维），前几个位置的值：

| 位置 | sin(ω₀) 高频 | cos(ω₀) 高频 | sin(ω₁) 中频 | cos(ω₁) 中频 | sin(ω₂) 低频 | cos(ω₂) 低频 |
|---|---|---|---|---|---|---|
| 0 | 0.000 | 1.000 | 0.000 | 1.000 | 0.000 | 1.000 |
| 1 | **0.841** | **0.540** | 0.046 | 0.999 | 0.002 | 1.000 |
| 2 | **0.909** | **-0.416** | 0.093 | 0.996 | 0.004 | 1.000 |
| 3 | 0.141 | -0.990 | 0.139 | 0.990 | 0.006 | 1.000 |

**观察**：
- 高频列（前两列）：位置 0→1→2，值变化**剧烈**
- 低频列（后两列）：位置 0→1→2，值**几乎不变**（只有 0.002 的微小变化）
- 每一行组合起来是**唯一**的

## 6. sin/cos 的独特优势：可表示相对位置

### 核心性质

**从位置 i 到位置 i+δ，只需要一个固定的旋转矩阵，而且这个矩阵只跟偏移量 δ 有关。**

举例：
- 位置 3 → 位置 5：偏移 δ=2，用旋转矩阵 R(2) 变换
- 位置 10 → 位置 12：偏移也是 δ=2，用**同一个**旋转矩阵 R(2)
- 位置 100 → 位置 102：还是用 R(2)

### 这意味着什么？

模型不需要分别学习"位置 3 到位置 5 的关系"和"位置 10 到位置 12 的关系"。它只需要学会**一个**关于 δ=2 的变换，就能处理所有间距为 2 的位置对。

> 这就像学会了"加 2"这个概念，不管起点是 3 还是 100。

---

## 7. 位置编码怎么用？

**直接加到词嵌入上**（逐元素相加，不是拼接）：

```
输入 = 词嵌入 + 位置编码
```

比如 "猫" 在位置 0：
```
猫的词嵌入：  [0.3, -0.5, 0.8, 0.1]
位置 0 编码：  [0.0,  1.0, 0.0, 1.0]
————————————————————————
最终输入：    [0.3,  0.5, 0.8, 1.1]
```

**不增加维度**！维度还是 4。

---

## 8. 位置距离 ≈ 编码相似度

| 位置 A | 位置 B | 距离 | 编码相似度 |
|---|---|---|---|
| 5 | 6 | 1 | 很高（~0.99） |
| 5 | 10 | 5 | 中等（~0.85） |
| 5 | 50 | 45 | 较低（~0.30） |
| 5 | 95 | 90 | 很低（~0.05） |

## 总结

| 问题 | 答案 |
|---|---|
| 为什么需要位置编码？ | Self-Attention 不关心顺序，需要额外告诉模型位置信息 |
| 怎么编码？ | 每个位置 = 一组不同频率的 sin/cos 值 |
| 为什么用 sin/cos？ | 连续、可微分、能通过旋转矩阵表示相对位置 |
| 高频维度的作用？ | 区分相邻位置（近距离） |
| 低频维度的作用？ | 区分远距离位置 |
| 怎么用？ | 直接加到词嵌入上，不增加维度 |
