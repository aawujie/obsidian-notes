# 2. Overview

视频讲者回顾自己从教师到创业者、投资人的人生轨迹，核心论题是“有意愿并有能力做出主动选择，才是真正的活着”，并提出一套可操作的方法论来创造“serendipity（意外的好运）”。结论为：通过开放信息输入、主动出击、制造随机、保持乐观与耐心，以及与身边人建立沟通协议，你可以在多次“重生”与领域切换中发现方向并收获长期的回报。

# 3. 按照主题来梳理

## 3.1 个人职业转折与关键节点回顾

- 讲者回忆了自己在人生中做过几次重大决定，每一次都是在放弃熟悉擅长的事情去做不擅长但认为更重要的事情时发生的。最早的例子是他在“最重”的时候（生活或家庭压力大到夫妻住院）做出去新东方（New Oriental）应聘的决定，这个决定并非理所当然，而是经过挣扎之后的主动选择。之后，他在新东方工作了七年，用“七年是一辈子”来形容那段时间对他的深刻意义——在他的生命周期里，那七年几乎占据了全部精力与成长轨迹。
- 2008 年，当讲者 35 岁时，他再次做出重大决定：离开新东方去做别的事情。原因在于他的能力结构发生了变化——从过去擅长的“销售”转向了“讲课”这一核心能力，而且他已经开始有自己的产品。讲者提到他第一本产品书是《托福核心词汇21天突破》，并指出书的版税“几乎一分钱都没有懂（不太清楚？）”，但后来这成为他人生第一个税后被动收入来源。随后又写了托福作文书和《把时间当做朋友》这样具有个人风格和思想积累的作品。由此可见，讲者在职业路径的选择上，既有对能力方向的自我觉察，也有把知识产品化、变成长期收入的意识。
- 到了 2013 年，环境与机遇让讲者开始涉足投资和创业。那年他在为自己的创业项目 NewOne 融资时，意识到融资的代价与心理差异：当你没钱时融资是正确的；当你有钱时融资会带来高成本（因为别人投的是别人的钱，你投的是自己的）。基于这种认知，他暂停了当时的融资活动，后续在某一轮中把创始人股份的一部分拿出来换取了外部投资，个人实现了纪念性套现约 200 万人民币。从此他开始参与投资，并在这过程中遇到了后来成为朋友的投资人刘靖（Liu Jing），对方告诉他放弃某些过于赚钱但会让人“变傻”的生意的决定，这让讲者深有共鸣并更加坚持“主动选择”这一人生准则。
- 这一节的核心在于：讲者通过回顾多次职业转折，展示了“主动选择”如何在具体节点上触发重大人生改变。每个决定背后有对自身能力的判断、对外部形势的感知以及承受来自亲近人群的压力与沟通成本。总的来说，职业转折不是偶然，而是由对自己技能、市场机会和人生目标的主动评估驱动的，并伴随着知识产品化与资本化的实践。

## 3.2 投资与创业的策略与经历（以 2013 年为中心）

- 在 2013 年，讲者的创业与投资经历进入一个新的阶段。具体过程包括：为了 NewOne 做过一轮融资谈判，意识到融资对不同处于不同资金状况的人有不同的含义，最终决定停止融资并在后来的一轮中进行了股权让渡，从而在当时实现了个人的套现。这个过程揭示了创业时对“资本-控制-成本”之间关系的权衡：融资会带来外部资本但同时降低创始人的控制权和承担不同的决策成本。
- 在这一年里，讲者也开始以更主动的姿态去做天使投资或创业旁支持。他提到在这一过程中遇到的一个重要人物刘靖（莲花创投的创始人，原先做育民生意），对方分享了自己放弃高利润但可能让人“变傻”的生意的决定。讲者对这一决定深感敬佩，因为这与他自己早期主动放弃某些熟悉且高回报路径以追求更有意义的工作的行为是一致的。这里可以看到一个价值层面的投资视角：并非所有赚钱的事都值得持续投入，有时放弃也是一种成熟。
- 讲者还讲了一个纪念性的套现数字：约 200 万人民币。这个数字在叙述中不仅表示一种财务上的里程碑，更代表他从“只做教师”到“能通过创业与投资获取资本回报”的身份转变。接着他开始更系统地参与投资活动，逐渐由一个“纯粹的内容创作者/教师”转型为内容+产品+资本运作的复合型个体。
- 这一节的要点：创业并非单一轨迹，资金的获取、股权的稀释与控制权的权衡、以及对长期发展方向的判断，都需要在实践中不断调整。讲者通过个案说明：聪明地选择融资时机、在对的节点套现、以及在价值观驱动下选择或放弃商业模式，都是投资创业中重要的策略性行为。

## 3.3 “有主动选择才是真正活着”的核心命题

- 讲者提出一个核心判断标准来衡量一个人是否“真的活着”：那就是“是否有能力做出属于你的主动的选择”。这句话在视频里被反复强调，讲者认为若人生中缺乏主动选择的能力与意愿，那么对他来说“生不如死”（虽承认也可能生活得很好，但在他价值判断中不算真正活着）。这个判定包含两个要素：意愿（你要愿意选择）和能力（你能选择并承担后果）。
- 讲者进一步用比喻和影视台词来增强表达：引用电影（周润发台词与姜文笑嘻嘻的引述）来说明“表面活着与真正活着”的差别。他指出每个人都有多次“重生”的机会，即在不同阶段转换职业或方向，不应被“这一辈子做好一件事”的陈旧观念所束缚。这里的逻辑是反对单线终身职业观，鼓励多次尝试与主动调整。
- 他举例描述自己的成长节奏模式：入门的第一年是学习与适应，第二年开始掌握基本技能并拼命成长，第三到第五年为收获期，第六年继续收获，第七年则是“休息”，用以总结与准备下一次重生。这个节奏式的描述强调了主动选择在时间维度上的节律性：你可以设定一个循环，在不同周期里采取不同策略（探索、专注、收获、休整）。
- 对“主动选择”的实践难点也被提及：很多时候最大压力并不是来自外界陌生人，而是来自最亲的人（家庭、伴侣、父母），因为他们更难理解你突然放弃熟悉的优势去做不擅长的事情。讲者建议：在做这些主动决定时，需要用耐心去教育和说服身边重要的人，或签订类似“工作协议”的沟通方式，让他们理解你的工作模式与边界，从而减少摩擦与误解。
- 小结：这一节的意义在于把人生选择上升到价值判断层面，主张把“是否能并愿意做主动选择”作为自我衡量的核心标准，并提供了节律化的人生实践样本（探索、成长、收获、休息循环），同时指出要处理好与亲近人的沟通与协约。

## 3.4 苍蝇模式与蜜蜂模式：进入新领域的具体方法论

- 讲者提出了两种进入新领域的行为模式：苍蝇模式（Fly mode）与蜜蜂模式（Bee mode），并用一个简单实验来说明差异。实验是把透明瓶子放在有阳光的地方，把苍蝇和蜜蜂分别放进去。蜜蜂看到光就朝着固定方向撞，直到耗尽力气可能致死；苍蝇则四处乱撞、碰碰撞，最终会凭运气或随机路径逃离瓶子。由此隐喻在陌生领域中的两种策略：
    - 苍蝇模式：在进入某个新领域的初始阶段（比如第一年的一季度或两季度），要像苍蝇一样无头拼命尝试、多方试错、不设限地撞墙。这个阶段强调大量探索、快速试错和宽泛实验，目标是尽快找到某种“方向性”或可行的路径。讲者明确说“撞不死你的就不要怕”，因为早期的撞击是信息获取与方向发现的重要方式。
    - 蜜蜂模式：一旦你在探索阶段找到方向（某种方法、主题或路径），就要像蜜蜂一样具备方向性和聚焦力，顺着那个方向进行集中式、深度的成长与突破。这个阶段强调持续投入、构建声誉（build my reputation）、产品化和规模化收获。
- 讲者用自身经验例证：他到新东方讲课后很快找到了讲课的方向与风格，于是进入“蜜蜂模式”，通过持续输出和教学实践构建口碑与产品，随后开始收获。整个过程体现了“先广泛探索、再深度聚焦”的方法学。
- 方法论的操作建议（可视为步骤）：
    1. 初入领域：把时间分块（例如第一年的一季度或两季度），在短时间内尽可能多地做不同尝试，收集反馈，尽量不设心理负担，允许失败与碰壁。
    2. 识别方向：通过这些尝试找到相对稳定或能不断改善的路径，判断一个方向是否值得长期投入。
    3. 快速切换心态：一旦确认方向，立即从“随机试错”的苍蝇模式切换到“定向增长”的蜜蜂模式，集中资源与精力进行深耕。
    4. 收获与调整：在蜜蜂模式下收获口碑、收入或产品化成果；设置周期（如七年一轮）用于总结与准备下一次的探索周期。
- 这套模型简洁而实用，强调试错成本在早期是可以承受的，但聚焦时必须坚定与持续，以实现规模化的成长和长期回报。

## 3.5 如何创造“意外的好运”（serendipity）：开放、主动、随机、乐观、耐心与沟通

- 讲者把 serendipity（意外的好运）作为他职业与人生中持续获益的核心概念，并给出了多项具体实践要点，解释如何“制造”或“增加”这种意外好事发生的概率：
    - 开放（Open）：讲者强调信息输入的开放性。他举了一个极端例子：自己在社交媒体上关注了很多人（关注 18000 人），并把信息流通过大屏幕分栏来浏览。目的是避免用当前已有的思维模式去筛选信息，因为这样会错过潜在的未来机会。开放意味着你愿意接受各类信息、观点与领域交叉的刺激，从而有更高概率遇到意想不到的机会（例如他后来通过某篇文章注意到比特币价格突破 1 美元的消息）。
    - 主动（Active）：不仅被动接受信息或机会，而是主动出击、主动创建接触点和关系。主动包括投身于新的实践、参加不同圈子的交流、主动联系潜在合作者或投资对象。主动是制造 serendipity 的行动维度。
    - 随机（Randomness）：刻意给生活制造随机性，例如跨界交朋、无特定目的去参与社交活动、接触与本职工作无关的圈子。随机增加了“碰撞概率”，也就是不同信息与资源在非预设路径上的组合，可能带来意外火花。
    - 乐观（Optimism）：讲者定义自己的乐观为“相信我一定会进步”（I believe I will improve）。乐观并非盲目，而是建立在对学习能力和持续改进的信心上。乐观让人愿意多次尝试、容忍失败并长期坚持，从而使得长期机会更易转化为成就。
    - 耐心（Patience）：很多人缺乏耐心，尤其在需要耐心积累的领域。讲者强调耐心是将随机的、小概率机会累积成稳定成果的关键。耐心也体现在对身边人的教育上：如果你的选择让最亲的人难以理解，你需要用时间去教育和适应，让他们理解你的工作方式与节奏。举例来说，他把手机设为静音、两小时内按优先级回电，这一工作习惯最初引发争议，但通过半年左右的坚持与沟通，让身边人习惯并接受，从而形成新的高效协作方式。
    - 沟通协议（Agreement）：讲者提出一个实用技巧，即与身边人“签订协议”来说明自己的工作方式（How you work）。这个概念类似计算机通讯协议，用来减少误解并建立可预期的行为准则。实践中可以通过明确规则（什么时候打扰、什么场景需要即时回应、什么场景可以等待）来管理期望，减少因主动选择引起的关系冲突。
- 讲者还讨论了“迷信”与“自证预言（self-fulfilling prophecy）”的相互作用：例如他在 2014 年断定次年有经济危机，于是暂停投资，这个决定看似迷信（提到犹太人的安息年与喜年），但实际上属于对集体行为的预测——如果大量人都相信并采取相同行动，那么这种行为本身会影响宏观经济走势，从而成为自证预言。讲者用这个例子说明：有方法论的人可以理解并利用集体信念的力量，而不是被其迷信属性所左右。
- 总结性步骤（如何实践创造 serendipity）：
    1. 保持信息输入开放，不局限于既有圈子或既定偏好。
    2. 主动出击，制造接触与机会，不等待别人来找你。
    3. 刻意引入随机性，让不同领域、人脉与想法发生碰撞。
    4. 维持乐观心态，相信自己能不断进步并承受试错。
    5. 保持耐心，给长期积累与教育身边人的时间。
    6. 与重要人群建立明确的沟通协议，降低因选择带来的摩擦。
- 这一节将讲者的个人行为与心态流水化为可操作步骤，目的是把“意外的好运”从偶然变为可增加概率的结果。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：探索—聚焦—收获—休整的周期模型（七年一轮的时间感）
    - 描述：讲者把个人职业发展拆成若干周期，常见的节奏是：第一年主要用于学习与适应；第二年完成基本技能习得并开始快速成长；第三到第五年进行持续收获；第六年继续巩固；第七年则进入休整、反思与准备下一轮重生。用“七年是一辈子”来强调每个周期的完整性和深刻性。
    - 应用步骤：
        1. 初入阶段（Year 0–1）：大量吸收、观察、实验，用苍蝇模式试错，目标是快速识别可能的方向。
        2. 成长期（Year 2–3）：一旦方向明确，切换到蜜蜂模式，集中资源、建立品牌或产品，努力积累核心竞争力。
        3. 收获期（Year 3–6）：规模化输出、变现、扩展影响力或团队。
        4. 休整期（Year 7）：总结、学习新知识、恢复能量，并评估是否进行下一次领域转换或重生。
    - 心智要点：把职业看作多个可管理的周期，而非单一终身轨迹。允许在周期末做出主动转向，以适应能力与兴趣的变化。
- 框架二：苍蝇—蜜蜂两阶段进入法（探索优先，确认后聚焦）
    - 描述：当进入新领域时，先用苍蝇模式随机试错，以低成本快速获取方向性信息；一旦找到有效路径，立即转为蜜蜂模式，用方向性与持续投入去深耕与突破。
    - 操作流程：
        1. 设定短期时间窗（比如一季度或两季度）作为“苍蝇试验期”；
        2. 在试验期内尽可能多地尝试不同方法、话题和交互，并记录反馈；
        3. 根据反馈与直觉选出最有潜力的方向；
        4. 进入蜜蜂模式，集中时间与资源长期投入，追求深度与规模。
    - 心智要点：容忍早期失败，快速识别高赔率方向，并且在确认方向后勇敢且专注地去扩展。
- 框架三：创造 serendipity 的五要素（Open、Active、Random、Optimism、Patience）加上沟通协议
    - 描述：讲者将“意外的好运”拆解为可控的行为与心态，强调通过环境设计与个人习惯来提升偶然性带来机会的概率。
    - 具体要素与实践：
        - Open（开放）：广泛接触不同信息源，避免自我信息过滤；技术层面可采用信息流分栏、大屏监控等工具来增加接触几率。
        - Active（主动）：主动建立联系、参与活动与项目，不做“被动好事发生者”。
        - Random（随机）：刻意制造非目的性社交或跨界互动，提升意外碰撞的机会。
        - Optimism（乐观）：相信自己会进步并敢于长期投入；乐观带来更多尝试，从而积累更多可能性。
        - Patience（耐心）：给策略和关系足够时间，不在短期波动中止损过早。
        - Agreement（沟通协议）：与重要他人达成关于工作方式和回应节奏的约定，减少误解与摩擦。
    - 心智要点：把“意外”视为概率事件，通过长期的行为策略系统性地提升其发生概率，而不是单纯等待运气降临。
- 框架四：对集体信念的利用（自证预言理论）
    - 描述：讲者提到“安息年”、“喜年”或群体信念会导致行为上的集体变化，从而改变经济或社会结果。这一观点与学术术语 self-fulfilling prophecy（自证预言）一致。
    - 实用推论：有方法论的人可以观察并利用这些群体信念的力量（例如预测某年金融市场的集体行为），通过提前调整自己的投资或行动节奏来获益或规避风险。但同时讲者提醒，这并非迷信，而是理解心理与行为反馈在宏观层面的影响力。
    - 心智要点：社会信念能成为实际力量，懂得识别并理性利用这些信念，是一种社会洞察力与风险管理技能。

# 总结

视频核心在于用讲者本人的多次职业转折与创业投资经历，来论证“主动选择”的重要性，并把如何制造“意外的好运”系统化为可执行的方法论：保持开放的视野、主动创造机会、刻意引入随机性、保持乐观与耐心，以及通过沟通协议管理与亲近人的期望。此外，讲者提出了进入新领域的两阶段法（苍蝇模式先试错，蜜蜂模式后聚焦）与周期化的人生发展观（探索—成长—收获—休整），这些框架可以直接被个人用于职业规划与实践。整体主张是：人生可以多次重生，关键在于是否愿意并有能力去做出那些属于你的主动选择，从而使“意外的好运”成为可提高发生概率的成果。
