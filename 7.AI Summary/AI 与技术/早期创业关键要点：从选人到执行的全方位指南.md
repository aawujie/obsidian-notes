# 概要

文章面向创业者，集中讨论联合创始人选择、招聘与留人、团队组织、解雇、以及公司执行力（专注与强度）。这些因素对早期创业公司的成败至关重要：选对人、招对人、执行到位，才能保持增长和势头。

# 如何判断一个市场是否具备长期快速增长潜力

1. 观察身边：
    - 年轻人正在使用的产品与服务往往预示未来主流市场。信任直觉，关注自己和同龄人的行为变化。
2. 验证信号：
    - 用户粘性、增长率、口碑传播（自然推荐）、频繁使用场景等都是早期指标。
3. 补充说明：
    - 长期增长判定还需结合宏观趋势（技术进步、成本下降、政策驱动）与可扩展性（能否复制并触达大量用户）。

# 创始人倦怠（burnout）的应对

4. 现实判断：
    - 创始人承担着真实后果，无法像学生那样“放弃一次”。倦怠感普遍且难避免。
5. 可行做法：
    - 建立支持网络（合伙人、导师、家人、专业心理支持）；面对问题并逐项解决；适度休息但优先处理公司核心风险。
6. 重要提醒：
    - 创始人抑郁与心理健康问题必须重视，及时寻求专业帮助与团队支持。

# 选择联合创始人（Co-founder）

7. 优先级：
    - 选择联合创始人是创业过程中最重要的决策之一，不可草率。不要把它当作“随便认识的人一起做”。
8. 最好来源：
    - 长期认识的朋友、大学同学、或在优秀公司（Facebook/Google等）工作的同事。长期共事能验证默契与能力。
9. 人格特质：
    - 具备“relentlessly resourceful”（不服输、能变通、快速解决问题）的能力；
    - 冷静、抗压、果断、有创造力（被形象化为“像James Bond”那样在关键时刻能做出正确决定）；
    - 技术公司应优先考虑技术合伙人；传媒/内容企业应优先媒体背景合伙人。
10. 团队规模：
    - 2–3位联合创始人通常最理想；一人创办风险高，超过3人协调成本升高。
11. 合作历史：
    - 最好有数年认识与合作经验；若不了解彼此，早期合伙失败率高。

# 招聘原则与实操

12. 招人节奏：
    - 早期应尽量少招人，只在“迫切需要”时才雇人。错误的早期雇佣成本极高，可能致命（首批5–10人尤其关键）。
13. 招聘优先级：
    - 当处于招聘阶段，招人应是创始人第一要务（可占用大量时间，通常25%或更多）。
14. 候选人来源：
    - 个人与员工推荐最有效；主动向认识的优秀人才索要候选人名单；
    - 考虑非硅谷地区的人才以降低竞争和成本。
15. 评价标准：
    - 核心考量三点——聪明、能把事做成（执行力）、愿意与你长期共事（文化契合）。对早期岗位，能力与学习力（aptitude）通常比年资更重要。
16. 面试方法：
    - 以项目合作或短期试用优先于一次性面试；实操远比脑筋急转弯更能判断能力；
    - 深入询问候选人参与过的具体项目，核对细节并打电话核实推荐人；
    - 注重沟通能力与抗压、冒险精神、坚韧性（maniacal determination）。
17. 面对“招不到最好的人”的现实：
    - 优秀人才会等“火箭舰”（已见到突破迹象的公司），因此先把产品做对、把增长做起来，会更容易吸引顶尖人才。
18. 招聘妥协：
    - 早期对中庸雇员的妥协代价大，可能破坏文化并最终致命。尽量把好前几次面试与入职门槛。

# 员工股权、激励与留人

19. 股权分配建议：
    - 作为粗略准则，前10位关键员工合计可预留约10%公司股权，分期（通常4年）归属（vesting）。创始人应更慷慨地对待早期员工，投资者的股份可适当争取压缩，员工能长期创造更大价值。
20. 归属机制：
    - 联合创始人与员工都应有四年归属并设一年悬崖期（1-year cliff），以避免早期合作者离开带来股权僵尸问题。
21. 留人方法：
    - 大额度或有竞争力的股权激励；
    - 建立清晰的职业发展路径与不断赋权（autonomy、mastery、purpose）；
    - 及时反馈与表扬，避免微观管理；
    - 基本管理技能（one-on-one、明确目标、清晰反馈）对降低人员流失非常有效。
22. 早期文化塑造：
    - 招人慢、标准高，确保每个人都像“早期合伙人”一样投入。公司面临危机时共同承担会凝聚团队。

# 解雇与冲突处理

23. 何时解雇：
    - 对反复持续做错决策、长期低绩效、制造办公室政治或系统性负面影响的员工应迅速处理。偶发错误应宽容、辅导。
24. 解雇原则：
    - 越早越快。对公司与该员工都是负责的做法；长时间拖延往往伤害士气与效率。
25. 平衡安全感：
    - 让员工在可接受失败的边界内试错，但当错误成为常态或影响面广时必须果断替换。清楚沟通预期与考核周期，做到有证可依。
26. 联合创始人关系破裂：
    - 及早沟通并尝试修复；
    - 联合创始人股权应设归属条款，预先约定离开后的处理；
    - 股权分配应尽早确定（最好在公司启动数周内），且接近平均，否则会埋隐患。

# 执行：专注、强度与保持增长势头

27. 创始人职责（早期五项核心）：
    - 设定愿景、融资、招募与管理团队、对外传达（招人/客户/合作伙伴）、设定并亲自维护执行标准。
28. 专注（Focus）：
    - 创业每天面对上百个重要任务，必须识别并只做当下两到三件最关键的事；
    - 设定明确公司目标（如发布时间、增长指标、重要招聘），全公司围绕这些目标执行；
    - 每周召开例会复盘关键指标，防止注意力分散。
29. 强度（Intensity）：
    - 创业通常要求高投入与长时间持续努力；少量额外投入在关键环节常能带来指数回报（例如把病毒系数从0.99提升到1.01）；
    - 速度与质量并行：既要“快速行动”，又要保持高质量标准（从产品到流程都要严格）；
    - 决策偏向执行：避免拖延与过度讨论，快速试错、快速迭代。
30. 保持与恢复势头（Momentum）：
    - 成功的创业公司不断取得小胜，从而积累大胜；增长与势头是创业生命线；
    - 丧失势头时，要通过小规模可实现的胜利（比如销售）快速恢复；远离空洞愿景演讲，优先可衡量的短期成果；
    - 建立“运营节奏”：定期上线、定期复盘、持续跟踪KPI。董事会可作为推动节奏与目标的强制力。
31. 竞争与媒体噪音：
    - 只在竞争对手拿出已发布且实际可用的产品时才真正担心；别被公关噪音分心。

# 其他常见问题（简答）

32. 远程联合创始人可以吗？
    - 早期强烈不建议。共处一地有助于快速沟通、决策与节奏；远程会显著拖慢早期迭代速度。
33. 招不到顶尖人才与失去客户该取舍？
    - 对于早期关键岗位，宁可放弃部分客户也不要招入会伤害公司长期发展的次优员工。早期以保持团队质量与文化为优先。
34. 创始人如何分配时间在招聘与其他任务间？
    - 在需要招人时，招聘可占据创始人大量时间（25%甚至更多）；在产品或筹资阶段，相关活动优先。

# 落地建议（可执行清单）

35. 招联合创始人前：
    - 优先选择有长期交往或共事史的人，明确分工与近乎平均的股权分配，并设置4年归属与1年悬崖期。
36. 招人前：
    - 列出必须解决的最少问题（2–3项），确认无法用现有人力解决再招人；优先内部与熟人推荐。
37. 面试流程：
    - 以短期合作/试岗为金标准；打电话核实推荐人，重点问能否回聘与具体贡献。
38. 团队管理：
    - 定期one-on-one、公开目标与指标、及时表扬、少做微观管理。
39. 解雇原则：
    - 建立清晰的绩效与纠偏期，若在合理辅导后仍持续不达标或有毒性行为，果断替换。
40. 执行节奏：
    - 设周度指标复盘、月度/季度目标，优先增长指标（对软件公司而言）与按期交付（对硬件公司而言）。

# 结语

早期创业的核心是“以少量高质量的人做对的事并持续快速执行”。慎重选择合伙人与早期员工、保持团队专注与高强度的执行节奏，是构建长期成功公司的关键。
