## 🧠 2. 核心概念学习顺序

### 建立因子投资世界观

```
统一视角公式 → 因子定义 → 定价因子 vs 异象因子 → 截面 vs 时序维度
     ↓
E[R_i^e] = α_i + β_i'λ
     ↓
α (定价误差/异象) + β (因子暴露) + λ (因子风险溢价)
```

### 详细概念顺序

| 顺序 | 概念 | 说明 | 关键理解 |
|------|------|------|---------|
| 1️⃣ | **统一视角公式** | $E[R_i^e] = \alpha_i + \beta_i' \lambda$ | 全书灵魂，理解α、β、λ的含义 |
| 2️⃣ | **因子的定义** | 驱动资产收益的系统性风险 | 必须长期获得风险补偿 |
| 3️⃣ | **定价因子 vs 异象因子** | 学术界严谨区分，业界统称"因子" | 理解不同立场的命名习惯 |
| 4️⃣ | **截面维度 vs 时序维度** | 截面回归研究收益率差异，时序回归研究波动与风险 | 区分两种研究范式 |

## 📐 3. 因子投资的方法论框架

### 五步研究流程

```
1. 数据准备
   ├─ 确定股票池
   ├─ 剔除"黑名单"（ST、退市股）
   └─ 处理异常值、计算财务指标
         ↓
2. 因子构建（排序法）
   ├─ 单变量排序
   ├─ 双重排序
   └─ 构建因子模拟投资组合，计算因子收益率
         ↓
3. 统计检验
   ├─ Fama-MacBeth 回归
   ├─ Newey-West 调整
   └─ 检验因子是否被显著定价
         ↓
4. 模型比较
   ├─ GRS 检验
   ├─ α检验
   └─ 均值—方差张成检验，评价多因子模型优劣
         ↓
5. 组合优化
   ├─ 收益模型 + 风险模型（Barra）
   ├─ 约束条件设定
   └─ 求解最优权重
```

### 关键方法详解

| 步骤 | 方法 | 说明 |
|------|------|------|
| **数据准备** | 剔除 ST/退市股 | 避免"黑名单"污染回测结果 |
| **因子构建** | 单变量排序 | 按因子值排序，分组计算收益 |
| **因子构建** | 双重排序 | 控制其他变量（如市值）后检验目标因子 |
| **统计检验** | Fama-MacBeth | 截面回归，逐期估计因子溢价 |
| **统计检验** | Newey-West | 调整自相关和异方差，得到稳健标准误 |
| **模型比较** | GRS 检验 | 检验模型定价误差是否联合为零 |
| **组合优化** | Barra 风险模型 | 结构化风险模型，用于风险归因 |

**核心任务**：深度解读六大主流因子

**学习内容**：

#### 六大因子
| 因子 | 英文 | 逻辑 | 构建方法 |
|------|------|------|---------|
| **市场因子** | Market | 市场风险溢价 | 市场收益 - 无风险利率 |
| **规模因子** | SMB (Small Minus Big) | 小市值溢价 | 小市值组合 - 大市值组合 |
| **价值因子** | HML (High Minus Low) | 价值股溢价 | 高 BM - 低 BM |
| **盈利因子** | RMW (Robust Minus Weak) | 高盈利溢价 | 高盈利 - 低盈利 |
| **投资因子** | CMA (Conservative Minus Aggressive) | 保守投资溢价 | 低投资 - 高投资 |
| **换手率因子** | Turnover | 低换手溢价 | 低换手 - 高换手 |

#### 主流多因子模型
- ✅ **CAPM** (1 因子)
- ✅ **FF3** (Fama-French 3 因子：市场 + 规模 + 价值)
- ✅ **FF5** (Fama-French 5 因子：+ 盈利 + 投资)
- ✅ **q-因子模型** (4 因子：市场 + 规模 + 盈利 + 投资)

## 🌏 6. A 股 vs 美股市场的特殊性

### 关键差异对比

| 差异点 | A 股特点 | 美股特点 | 应对方法 |
|--------|---------|---------|---------|
| **壳价值污染** | IPO 制度使微型股有极高壳价值 | 壳价值较低 | 剔除市值最小 30% 股票 |
| **规模因子** | 小市值溢价被壳价值污染 | 小市值溢价显著 | 剔除微型股后检验 |
| **价值因子** | 受壳价值干扰，表现不稳定 | 价值溢价显著 | 结合盈利因子使用 |
| **换手率因子** | 在 A 股极其显著 | 相对较弱 | 可作为重要选股因子 |
| **投资因子** | 与美股理论大相径庭，受盈利因子干扰严重 | 投资因子显著 | 需谨慎使用，考虑与盈利正交化 |
| **动量因子** | 表现较弱，甚至出现反转 | 动量效应显著 | 关注短期反转而非长期动量 |
| **数据披露** | 财务数据有时滞 | 披露及时 | 使用 Snapshot/季报数据，避免前瞻偏差 |
| **做空机制** | 不完善，多空对冲难落地 | 做空便利 | 关注多头端 Smart Beta |
| **交易成本** | 印花税、佣金较高 | 相对较低 | 控制换手率，考虑成本 |

### A 股实证注意事项

```
⚠️ A 股实证必须注意：

1. 剔除"黑名单"
   - ST/*ST 股票
   - 退市股票
   - 上市不满 6 个月的新股

2. 壳价值处理
   - 剔除市值最小 30% 的股票
   - 或使用市值中性化方法

3. 数据时滞
   - 使用财报公布日后的数据
   - 避免使用财报季前的前瞻数据

4. 交易限制
   - 考虑涨跌停限制
   - 考虑停牌股票
   - 多空对冲不可行，聚焦多头策略
```

## 💡 学习方法建议

### ✅ 应该做的

1. **理论与实践结合** - 每学一个因子，立刻用代码复现
2. **从简单到复杂** - 先单因子，再多因子，最后组合优化
3. **重视数据质量** - 仔细处理缺失值、异常值、前瞻偏差
4. **理解经济逻辑** - 不要只看统计显著性，要理解背后的经济学含义
5. **对比 A 股 vs 美股** - 理解市场差异，不要生搬硬套

### ❌ 应该避免的

1. **不要忽视交易成本** - 高换手策略在 A 股可能不赚钱
2. **不要过度拟合** - 避免数据挖掘偏误和 p-hacking
3. **不要忽视风险** - 高收益可能来自高风险，而非 alpha
4. **不要生搬硬套美股结论** - A 股有特殊性
5. **不要只看回测** - 要考虑实盘的可执行性

### 💡 学习提示

> **数据质量第一**：
> - 仔细处理缺失值、异常值
> - 避免前瞻偏差（使用财报公布日后的数据）
> - 剔除 ST、退市、新股等"黑名单"

> **A 股特殊性**：
> - 剔除市值最小 30% 的股票（壳价值污染）
> - 换手率因子在 A 股极其显著
> - 投资因子需谨慎使用（与美股理论不同）
> - 聚焦多头策略（做空不便）

> **避免过拟合**：
> - 不要过度挖掘因子（因子动物园陷阱）
> - 使用样本外检验
> - 考虑交易成本和换手率
> - 理解经济学逻辑，不要只看统计显著性

> **工具选择**：
> - 初学者：聚宽/优矿（数据 + 回测一体化）
> - 进阶：本地 Python 环境（灵活定制）
> - 数据源：Tushare（性价比高）、AKShare（免费）
