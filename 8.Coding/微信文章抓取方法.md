# 微信文章抓取方法

微信公众平台文章（`mp.weixin.qq.com`）因为 JS 动态渲染，普通的 HTTP 抓取经常只拿到标题和作者，正文全空。以下是实测有效的几种方法。

---

## 方法对比

| 方法 | 成功率 | 速度 | 依赖 | 备注 |
|:---|:---|:---|:---|:---|
| Tavily Extract (advanced) | ⭐⭐⭐⭐⭐ | ~8s | Tavily API | 最稳，推荐 |
| web_fetch (readability) | ⭐ | <1s | 无 | 基本拿不到正文 |
| web_fetch (text) | ⭐ | <1s | 无 | 同样失败 |
| 浏览器截图/OCR | ⭐⭐⭐⭐ | 慢 | Puppeteer | 费劲，最后手段 |

---

## 方法一：Tavily Extract（推荐）

**原理**：Tavily 走浏览器渲染引擎，能执行 JS 后再提取内容，微信文章正文完全可见。

**调用方式**：

```python
# 使用 tavily_extract
from tavily import TavilyClient

client = TavilyClient(api_key="your_key")
result = client.extract(
    urls=["https://mp.weixin.qq.com/s/xxxxx"],
    extract_depth="advanced"
)
```

**OpenClaw 中直接调用**：

```
tavily_extract:
  urls: ["https://mp.weixin.qq.com/s/-w2eyytB0_JbDggVAUyYIw"]
  extract_depth: advanced
```

**优点**：
- 一次成功，完整原文
- 不需要额外配置
- 自动清洗成 Markdown 格式

**缺点**：
- 需要 Tavily API key
- 比普通 fetch 慢（~8-10s）
- 有调用次数限制

---

## 方法二：web_fetch（基本无效）

**原理**：直接 HTTP GET，用 readability 提取正文。

**结果**：微信文章页面正文是 JS 动态加载的，静态 HTML 里只有标题和作者名，正文区域是空的 `<div>` 占位。

```bash
# 实测结果
curl -s "https://mp.weixin.qq.com/s/xxxxx" | grep -c "article"
# → 0
```

**结论**：微信文章不走 JS 渲染拿不到正文，web_fetch 本质是静态抓取，所以**基本无效**。

---

## 方法三：搜狗微信搜索（间接）

**原理**：搜狗有微信搜索入口（`weixin.sogou.com`），可以搜到文章标题，但正文同样被限制。

**状态**：不稳定，且经常被反爬拦截。**不推荐。**

---

## 方法四：RSS 中转（不靠谱）

**原理**：一些第三方服务（如 WeRSS、今天看啥）将微信公众号转为 RSS。

**状态**：多数已死，微信封杀严重。**已不可用。**

---

## 核心原因分析

微信文章页面结构：

```html
<!-- 静态 HTML 中只有这些 -->
<div id="js_content" style="visibility: hidden;">
  <!-- 正文内容由 JS 动态填充 -->
</div>
```

普通 HTTP 客户端不会执行 JS，所以 `#js_content` 永远是空的。只有浏览器引擎（Chromium/WebKit）渲染后才能拿到完整 DOM。

这就是为什么：
- **web_fetch** → ❌ 失败（不执行 JS）
- **Tavily** → ✅ 成功（执行 JS）
- **curl/wget** → ❌ 失败（不执行 JS）

---

## 结论

**抓微信文章，记住一条：用 Tavily Extract，advanced 模式。**

其他方法都是浪费时间。微信的反爬策略就是"不执行 JS 就别想看正文"，唯一绕过去的方法就是乖乖执行 JS。Tavily 帮你做了这件事。
