# pyJianYingDraft — 剪映自动化草稿生成工具

> [!info] 项目信息
> - **GitHub**: https://github.com/GuanYixuan/pyJianYingDraft
> - **安装**: `pip install pyJianYingDraft`
> - **推荐 Python 版本**: 3.8 / 3.11
> - **Stars**: 2.8k｜**Forks**: 527

## 一句话描述

用 Python 代码生成剪映草稿文件（`draft_content.json`），实现**全自动视频剪辑/混剪流水线**。库本身不出视频，只生成草稿 → 用剪映打开渲染导出。

---

## 核心能力

### 1. 草稿生成（支持剪映 5+ 所有版本）

| 类别 | 能做什么 |
|------|---------|
| 视频/图片 | 添加素材、设置时间段、调速、旋转缩放、亮度等调节 |
| 音频 | 添加音频、淡入淡出、音量关键帧 |
| 文本/字幕 | 添加文本、设置字体样式、从 `.srt` 批量导入字幕 |
| 特效/滤镜/转场 | 画面特效、人物特效、滤镜、入场出场动画、转场 |
| 蒙版 | 线性、圆形等蒙版 |
| 关键帧 | 透明度、位置、旋转、缩放、音量等属性动画 |
| 贴纸 | 根据元数据添加贴纸 |

### 2. 模板模式（仅支持剪映 5.9 及以下）

> [!warning] 剪映 6+ 对草稿文件加密，模板模式不支持

- 加载已有草稿作为模板
- 替换音视频素材（按名称 / 按片段）
- 替换文本内容（保留原格式）
- 导入模板轨道到新草稿

### 3. 批量自动导出（仅 Windows + 剪映 6 及以下）

通过 UI 自动化控制剪映客户端，自动导出指定草稿，支持调节分辨率和帧率。

---

## 典型使用场景

| 场景 | 说明 |
|------|------|
| 批量混剪 | 批量替换素材模板，一键生成多个版本 |
| 自动字幕视频 | 导入 SRT + 背景视频，自动生成带字幕草稿 |
| 内容矩阵 | 电商产品视频、短视频矩阵自动化生产 |
| 数据可视化视频 | 用代码驱动关键帧，生成数字变化动画 |
| 每日播报视频 | 结合数据源自动生成日报/新闻类视频草稿 |

## 核心局限

1. **剪映 6+ 加密**：模板模式（替换素材）完全不可用
2. **自动导出限制**：仅 Windows + 剪映 6 及以下
3. **不支持曲线变速**
4. **付费资源需 VIP**：约一半转场、部分滤镜需付费
5. **资源文档缺失**：哪些能用、哪些要 VIP，README 没说清楚，需自查源码

## 快速上手

```python
import pyJianYingDraft as draft
from pyJianYingDraft import trange, TransitionType, FilterType, FontType

# 创建草稿
script = draft.ScriptFile(1920, 1080)
script.add_track(draft.TrackType.video)
script.add_track(draft.TrackType.audio)

# 添加视频片段
seg = draft.VideoSegment("video.mp4", trange("0s", "5s"))
script.add_segment(seg)

# 添加转场
script.add_transition(TransitionType.叠化)

# 保存草稿
script.dump("path/to/JianyingPro Drafts/my_draft/draft_content.json")
```
