# 1. Metadata

- Title: Random Forests Part 2 — 处理缺失数据与样本聚类（Reading 版）
- Author: Josh Starmer（视频原作者）

# 2. Overview

本视频主要讨论随机森林（Random Forests）在处理缺失数据（missing data）时的两类问题：一是训练数据集中存在缺失值的情况，二是对新样本分类时新样本本身有缺失值的情况。核心思路是先做一个初步猜测（即粗略填补缺失值），用该数据构建随机森林，通过森林中样本在叶节点共同出现的频率来构建“邻近度矩阵”（proximity matrix），再以邻近度作为权重对缺失值进行加权重估计（对分类变量做加权频率，对数值变量做加权均值）。将估计结果代回数据后重复上述过程若干次，直到缺失值估计收敛。视频还展示了如何把邻近度矩阵转换为距离矩阵并用于可视化（heat map、MDS），以及当只有新样本缺失某个特征时，如何通过构造两种可能标签的副本并比较被随机森林正确标注次数来确定类别。

# 3. 按照主题来梳理

## 3.1 数据与问题设定：示例数据与两类缺失数据情形

- 视频用一个非常简化的示例数据集来说明问题：共有四个样本（四个病人），其中病人 4 的两个特征缺失——一个是是否有堵塞的动脉（blocked arteries，离散/分类变量），另一个是体重（weight，数值变量）。目标是基于这些数据构建随机森林并能够对是否有心脏病（heart disease）等标签进行判别，但必须先处理缺失值。
- 视频将“缺失数据”分成两类情形并逐一处理：
    1. 训练集中有缺失值：也就是用来建森林的那批数据本身含有缺失项（本例中病人4的 blocked arteries 和 weight）。需要用一种方法先填补这些缺失，才能把这批数据用于构建随机森林。
    2. 新样本有缺失值：已经用完整数据建好了随机森林，但现在有一个要分类的新样本，该新样本缺少某些特征（例如 blocked arteries），此时需要在不重建森林的前提下填补新样本的缺失，并得到最终的预测。
- 视频强调的关键思想是“先猜一个可能很糟糕的值，然后不断改进”：初始填补可以很粗糙，但通过随机森林产生的邻近度信息，可以逐步用相似样本的加权信息来更新这些猜测，迭代直到稳定。这一策略既适用于训练集中缺失，也适用于新样本缺失（两者在细节上有所不同，但核心步骤相近：填补→建树→基于树的相似性重新估计→重复）。

## 3.2 初始填补（initial guess）与为何要迭代

- 初始猜测的做法：对分类变量（例如 blocked arteries）采用“在同一类（例如没有心脏病）的样本中最常见的类别”作为初始填补；对数值变量（例如 weight）采用同类样本的中位数（median）作为初始填补。视频示例中，因为在“不患心脏病”的样本里 blocked arteries 最常见的值是 “no”，所以对病人4 的 blocked arteries 初始猜测为 no；对 weight 因为是数值型，所以取“不患病”样本的中位数，示例中记为 167.5（视频发音为“160 7.5”，此处合并为 167.5）。
- 为什么需要迭代：单纯用最常见类别或中位数进行填补忽略了样本之间更细致的相似性。随机森林提供了一种基于树结构的相似度度量：如果两个样本在同一棵树的同一叶节点（leaf node）落在一起，说明在那棵树构建所基于的特征切分下它们被视为“相似”。通过多棵树的统计，可以得到更稳健的样本间相似性度量（邻近度）。用这个邻近度作为权重，可以对分类变量做加权频率估计，对数值变量做加权平均，通常比初始粗略猜测更好。因此采用“初始化→建森林→基于邻近度重新估计→把重新估计的值填回→重复”的迭代策略，直到填补值不再变化（收敛）。
- 迭代次数与收敛准则：视频中提到通常迭代 6 至 7 次直至缺失值收敛，但这不是严格规则，实际应用中可以根据是否进一步改变或某种容忍阈值来停止。视频保持原话并未给出更具体的停止准则，只说明“直到缺失值不再每次改变”。

## 3.3 构建邻近度矩阵（proximity matrix）与用法详解

- 什么是邻近度矩阵：对 N 个样本，邻近度矩阵是一个 N×N 的对称矩阵，其中矩阵元素 prox(i, j) 表示样本 i 与样本 j 在随机森林中“共同出现在同一叶节点”的频率。具体做法是：对每一棵树，若样本 i 与样本 j 在该树的同一叶节点出现，则在 (i, j) 和 (j, i) 的位置上加 1；当所有树都处理完后，将矩阵中的每个元素除以树的总数 T，则得到每对样本在树集合上落入同一叶节点的比例，范围在 0 到 1 之间。视频示例中假设有 10 棵树，某对样本若在所有 10 棵树都同叶，则 prox = 1；若只有 1 棵树同叶则 prox = 0.1。
- 用邻近度计算分类变量的加权频率：当目标样本 k 的某个分类变量缺失时，找出所有其他样本的该分类变量值，计算每种类别的“加权频率”。权重由邻近度给出：对于某一类别 c，先取在其他样本中属于 c 的那些样本 j，将它们与样本 k 的邻近度 prox(k, j) 求和，得到该类别在 k 周围的邻近度总和；再把该邻近度总和除以所有 j 对 k 的邻近度之和（即归一化权重），得到该类别的权重，然后乘以该类别在附近样本中的相对频率（视频中把“频率”与“权重”结合表示，实际效果是按邻近度的加权频率）。在视频示例，针对 blocked arteries，附近样本中 yes 出现一次且对应 prox 权重为 0.1，no 出现两次且对应 prox 权重合计为 0.9，从而得到加权频率 yes ≈ 0.03，no ≈ 0.6，no 明显更大，因此将缺失值更新为 no。
- 用邻近度计算数值变量的加权均值：对数值型缺失值，用邻近度作为加权系数，计算加权平均。具体为：选取其它样本的数值 v_j 和它们与样本 k 的邻近度 prox(k, j)，先对每个 j 计算权重 w_j = prox(k, j) / sum_j prox(k, j)，然后计算 weighted_mean = sum_j w_j * v_j。视频示例给出样本 1、2、3 的体重及对应邻近度权重（分别 0.1、0.1、0.8 等，示例中最终得到加权平均 198.5），并说明“这里的 weight（用于加权）与样本的 weight（体重）是两个不同的概念”以避免混淆。
- 迭代更新的具体流程（在训练集中有缺失值时的完整步骤）：
    1. 对缺失值做初始填补（分类变量用最常见值，数值变量用中位数）。
    2. 用已经被初步填补的数据构建随机森林（T 棵树）。
    3. 将所有样本通过每棵树，记录哪些样本在同一叶节点，累加得到未归一化的邻近度计数矩阵。
    4. 将计数矩阵除以树的总数 T 得到邻近度矩阵 prox。
    5. 用 prox 对缺失变量做加权估计（分类变量做加权频率以决定类别，数值变量做加权均值）。
    6. 将新的估计填回数据；若填补值与前一次相同（或达到收敛准则），停止；否则返回步骤 2 继续迭代。
- 视频示例中给出了一轮计算的数值示范（权重 0.1、0.9；加权频率 0.03 与 0.6；加权平均 198.5）来显示方法的可操作性，但并未给出普适阈值或性能保证。

## 3.4 从邻近度到可视化：距离、热图（heat map）与 MDS（多维尺度）

- 将邻近度转换成距离：邻近度 prox(i, j) 的值域在 [0, 1]，proxy 越大表示样本越接近。可用 distance(i, j) = 1 - prox(i, j) 将邻近度转换为距离矩阵（distance matrix）。当 prox = 1 时，distance = 0，表示两样本在树上的相似性最大；当 prox = 0 时，distance = 1，表示完全不靠近。
- 利用距离矩阵可做多种可视化：视频提到可以画 heat map（热图）来显示样本之间的相似性/距离矩阵；也可以做 MDS（多维尺度，Multidimensional Scaling）散点图，把高维或复杂关系嵌入到 2D 或 3D，以便直观观察哪些样本彼此靠近、哪些远离。视频强调这一点很酷的原因在于：不论原始特征是类别型、排序型或数值型，只要能用它们来构建树（即随机森林），就能得到一个可用于可视化和聚类的邻近度/距离表示，因此随机森林提供了一种基于模型的通用相似性度量。
- 可视化的实用场景与限制：这种基于树的距离度量适合揭示在当前模型结构下哪些样本被认为相似，适合用于探索性分析、找出群体结构或检测异常样本。但视频并未扩展到如何选择色标、聚类算法或如何将该可视化与统计显著性联系起来，所以这些细节需要在实际应用时谨慎设计，并视任务需求补充相应方法。

## 3.5 对新样本缺失特征时的策略（在已有森林的情况下）

- 情形设定：已经用完整的训练数据构建好了随机森林，现在需要把一个新样本送入森林进行分类，但这个新样本缺失某一关键特征（例如 blocked arteries ），这会影响其在树中的路径，因此需要先给该缺失特征一个合适的值再运行分类。
- 视频提出的解决方法（两步法与迭代）：
    1. 生成两个备选副本（copies）：把新样本复制两份或更多份，每份对缺失特征赋不同的可能值（例如 one copy 假设 blocked arteries = yes，另一个 copy 假设 blocked arteries = no）。如果类别可能有多于两个取值，则为每个可能取值生成一个副本。
    2. 对每个副本应用之前介绍的迭代填补方法：因为其他特征也可能缺失，或者需要基于邻近度的估计进行微调，所以对这些副本也可进行和训练集中缺失一致的迭代填补，直到这些副本的缺失特征或数值收敛。
    3. 将多个已填补并收敛的副本分别送入已建好的随机森林，记录每棵树对每个副本的分类结果（即该副本在那棵树上被正确标注为“有心脏病”或“无心脏病”的次数）。
    4. 计数比较：选择被随机森林正确标注次数最多的那个副本对应的假设作为新样本最终的类别（视频用“哪个副本被正确标注的次数更多，哪个就赢”来表述）。在示例中，假设“blocked arteries = yes”的副本在三棵树中都被正确标注为“有心脏病”，而“blocked arteries = no”的副本只有一棵树正确标注，所以前者胜出，最终选择 yes。
- 该方法的直觉与优点：本质上把“缺失特征导致路径不确定”的问题转化为“对不同可能值分别评估并比较其在现有模型下的表现”，避免了在没有重建森林的情况下直接用模型之外的规则决定该特征值。优点是直接利用已有模型的判别能力，并通过比较模型对不同假设的偏好来选择缺失值的填补与最终分类。
- 局限与注意：视频没有详细讨论如果多个特征同时缺失有多少组合的情况（组合数可能呈指数增长），也没有讨论在类别较多或连续特征缺失时如何枚举或近似处理，因此实际使用时需要考虑计算成本和可行性（例如用随机抽样或先验限制可能值范围）。

# 4. 框架 & 心智模型（Framework & Mindset）

- 抽象的处理缺失值框架（适用于训练集内或新样本）：这个框架可以被表述为一个“迭代估计-基于模型相似性加权-更新”循环，详细步骤如下：
    1. 初始估计（Initialization）：对每个缺失项做一个初始、简单、可计算的估计。对于分类变量，可以用在同一标签组或整组数据中最常见的类别；对于数值变量，可以用中位数或均值。初始估计不要求准确，只要能启动后续流程。
    2. 基于当前数据构建模型（Modeling）：用已经用初始估计填好的完整数据来训练随机森林。随机森林在这一步不仅是一个预测器，它更重要的角色是在训练数据上定义“基于树的相似性”。
    3. 从模型提取相似性（Extract similarity）：把所有样本通过森林的每一棵树，统计哪些样本在同一叶节点出现。累计并归一化得到邻近度矩阵 prox，prox(i, j) 即样本 i 和 j 在整棵森林中落在同一叶节点的比例（0~1）。
    4. 基于邻近度做加权估计（Weighted estimation）：使用 prox 作为权重，对缺失的分类变量做加权频率估计（从而选择某个类别）或对数值变量做加权均值估计。这一步把“局部相似样本的特征加权汇总”作为更新值。
    5. 更新并检查收敛（Update & Convergence）：将新的估计值替换回数据，若缺失值已收敛（即更新前后没有变化或变化很小），结束；否则返回步骤 2 继续迭代。通常迭代若干次（例如 6-7 次）可达到稳定。
    6. 应用或可视化（Application & Visualization）：一旦邻近度矩阵可用，可进一步把它转换为距离矩阵（distance = 1 - prox）用于热图或 MDS 可视化，以帮助理解样本间的关系或群体结构。
- 心智模型（mindset）与设计理念：
    - 用模型来定义相似性而不是用简单的距离度量：相比直接用欧氏距离或特征间的标准化差异，随机森林通过树的分裂机制给出一种更语义化的相似性（在相同叶子代表在模型构建时被视为相似）。这种方法优势在于它能自然地融合数值与分类变量，并适应非线性边界与交互效应。
    - 将缺失值看作不确定性问题，用概率/加权的方式处理：视频强调用邻近度作为权重来做加权频率或加权均值，这体现了一种将不确定性“平滑”而不是“硬填补”的心态。通过迭代，这种不确定性的估计会被逐步精炼。
    - 用既有模型来评估不同假设（对新样本缺失情况）：当新样本缺失关键特征时，采用“生成不同假设副本并评估哪个在现有模型下表现更好”的策略，体现了“用模型的偏好作为决策依据”的思路。这比盲目使用先验更能反映模型在现有训练经验下的判断。
    - 关注可解释的中间产物：邻近度矩阵不仅用于缺失值填补，也可转化为可视化工具（heat map、MDS），从而把黑箱模型的内部相似性信息用于探索性数据分析。这种把模型输出转化为可解释结构的思路有助于检查模型是否合理、能否用于群体划分或异常检测。
- 实用建议（基于视频逻辑的原则性建议）：
    - 初始猜测不必求精，但要合乎逻辑（例如在同一类别/组中取众数或中位数），以便给模型一个稳定的起点。
    - 迭代到收敛为止，但要设定上限以防循环死循环或计算开销过大（视频未给界限，但现实中可加上 max_iter 和 tol）。
    - 当新样本缺失多个特征时，直接枚举所有可能组合可能不可行，可采用启发式或随机采样的方法来近似比较不同假设的表现。
    - 使用邻近度得到的距离可做进一步分析，但要意识到它反映的是“在当前森林结构下”的相似性，若更改模型参数或特征选择，邻近度可以发生显著变化。

# 总结

视频通过一个小而具体的示例系统地演示了随机森林处理缺失数据的实操方法：用简单合理的初始填补启动，基于随机森林的叶节点共同出现频率构建邻近度矩阵，再以邻近度作为权重对缺失的分类或数值变量做加权估计，重复该过程直到收敛。邻近度矩阵还能被转化为距离用于热图或 MDS 可视化，从而把模型内部的相似性信息用于探索性分析。当只有新样本缺失时，可通过为每种可能值构造副本并比较它们在现有森林下被正确标注的频率来决定最终填补与分类。总体思想是：用模型驱动的相似性来逐步改善对缺失值的不确定性估计，并把这一过程形成可重复的迭代框架。
