# 语言模型与 N 元语法

> 视频学习笔记 | 2026-03-14

---

## 核心定义

**语言模型（Language Model）** 是 NLP 领域的经典模型：

- **本质**：估计文本序列的**联合概率**
- **类型**：序列模型的一种
- **目标**：计算 $P(w_1, w_2, ..., w_T)$

---

## 典型应用

| 应用场景 | 说明 |
|---------|------|
| **预训练模型** | 作为基础模型，下游任务微调 |
| **文本生成** | 根据前文逐词生成后续内容 |
| **序列合理性判断** | 评估文本是否自然流畅 |
| **语音识别纠错** | 纠正识别错误的词序列 |
| **输入法补全** | 预测下一个输入的词 |
| **输入法纠错** | 纠正拼写或输入错误 |

---

## 基础统计建模方法

通过**统计词或序列的出现次数**计算概率：

```
P(词) = 该词出现次数 / 总词数
P(序列) = 该序列出现次数 / 总序列数
```

可拓展到不同长度序列的概率计算。

---

## N 元语法（N-gram）

### 马尔科夫假设

为降低长序列建模复杂度，引入**马尔科夫假设**：当前词只依赖于前 N-1 个词。

| N 元语法 | 依赖关系 | 公式 |
|---------|---------|------|
| **一元语法 (Unigram)** | 词相互独立 | $P(w_i)$ |
| **二元语法 (Bigram)** | 依赖前 1 个词 | $P(w_i \| w_{i-1})$ |
| **三元语法 (Trigram)** | 依赖前 2 个词 | $P(w_i \| w_{i-1}, w_{i-2})$ |

### 概率计算

$$P(w_1, w_2, ..., w_T) \approx \prod_{i=1}^{T} P(w_i | w_{i-N+1}, ..., w_{i-1})$$

---

## N 元语法优缺点

### ✅ 优点

- 可处理**长序列**
- 计算复杂度为 **O(T)**，线性增长
- 适合**实时场景**（输入法、语音识别）

### ❌ 缺点

- N 增大时**空间复杂度指数上升**
- 存储所有 N 元组合需要大量内存
- **二元、三元语法最常用**（平衡效果与开销）

---

## 核心总结

| 要点 | 内容 |
|------|------|
| **核心任务** | 估计文本序列的联合概率 |
| **统计实现** | 常用 N 元语法 |
| **理论基础** | 马尔科夫假设 |
| **计算方法** | 统计子序列出现次数 |
| **实用选择** | Bigram / Trigram 最常用 |

---

## 关键公式

**链式法则**（完整形式）：
$$P(w_1, w_2, ..., w_T) = \prod_{i=1}^{T} P(w_i | w_1, ..., w_{i-1})$$

**N 元语法近似**：
$$P(w_i | w_1, ..., w_{i-1}) \approx P(w_i | w_{i-N+1}, ..., w_{i-1})$$
