# ResNet 残差网络

> 李沐讲解 | 深度学习经典架构

## 📌 核心研究背景

卷积神经网络中存在的问题：
- **加深层数未必带来性能提升**
- <span style="color:rgb(195, 117, 255)"><b>复杂模型可能偏离最优值</b></span>
- **存在模型偏差问题**

<span style="color:rgb(195, 117, 255)">ResNet 的设计目标</span>：让<span style="color:rgb(255, 77, 77)">加层后的模型<b>不会变差</b></span>，甚至更好。

---

## 💡 核心思想

<span style="color:rgb(195, 117, 255)">让复杂模型包含小模型作为子模型：</span>

- 新函数 = <span style="color:rgb(255, 77, 77)"><b>输入 + 新学习的内容</b></span>
- <span style="color:rgb(195, 117, 255)">即便新层无学习效果，也能保留原有模型的输出</span>
- 保证模型性能 **至少不下降**

### <span style="color:rgb(255, 77, 77)">残差连接的本质</span>

```
输出 = F(x) + x
```

其中：
- `x` 是输入（捷径连接）
- `F(x)` 是新层学习的内容

---

## 🔧 残差连接的实现方式

在串联的网络层中加入 <span style="color:rgb(255, 77, 77)"><b>捷径连接</b>（shortcut connection）</span>：
- 将输入直接跳转到后续层
- 做 <span style="color:rgb(255, 77, 77)"><b>加法运算</b></span>
- <span style="color:rgb(195, 117, 255)">新加层无作用时，原有结果仍能传递</span>

---

## 🧱 残差块的设计细节

### 基本结构

<span style="color:rgb(255, 77, 77)">借鉴 VGG 设计</span>，包含：
- <span style="color:rgb(195, 117, 255)">3×3 卷积层</span>
- <span style="color:rgb(195, 117, 255)">批量归一化（Batch Normalization）</span>
- <span style="color:rgb(195, 117, 255)">ReLU 激活函数</span>

### 通道数不匹配的处理

<span style="color:rgb(255, 77, 77)">使用 <b>1×1 卷积</b> 调整通道数，使输入输出维度一致。</span>

### 跳转位置的灵活性

残差连接的跳转位置可灵活尝试，但 **原始设计效果相对更好**。

---

## 🏗️ 整体架构

### 结构特点

- 核心：**残差加法连接**
- 架构类似 VGG 和 GoogLeNet
- 包含 <span style="color:rgb(255, 77, 77)"><b>五个 stage</b></span>

### 残差块类型

| 类型    | 步幅  | 通道数变化 |
| ----- | --- | ----- |
| 高宽不减半 | 1   | 不变    |
| 高宽减半  | 2   | 翻倍    |

### 末端处理

设有 **全局平均池化层**（Global Average Pooling）。

---

## 📊 不同层数版本

| 版本        | 层数  | 特点   | 应用场景    |
| --------- | --- | ---- | ------- |
| ResNet18  | 18  | 轻量级  | 快速实验    |
| ResNet34  | 34  | 平衡   | 常用      |
| ResNet50  | 50  | 精度较高 | **最常用** |
| ResNet101 | 101 | 高精度  | 复杂任务    |
| ResNet152 | 152 | 超高精度 | 刷分      |

### 选择建议

- **ResNet34/50**：实际应用中最常用
- **ResNet152**：多用于刷分，计算成本高

---

## 🌟 影响力与意义

### 历史地位

- <span style="color:rgb(195, 117, 255)">很多高性能网络都是 ResNet 的<b>变种</b></span>
- 残差连接思想成为<span style="color:rgb(195, 117, 255)"><b>标配</b></span>
- 被应用在 BN、Transformer 等众多模型中

### 技术贡献

- 让**超深网络**的训练更轻松
- 可训练到 <span style="color:rgb(195, 117, 255)"><b>1000 层</b></span>
- 对深度神经网络发展影响深远

---

## 🔑 关键知识点总结

1. **残差学习**：学习输入与输出之间的残差，而非直接学习输出
2. **捷径连接**：解决梯度消失问题，使深层网络可训练
3. **恒等映射**：<span style="color:rgb(195, 117, 255)">当残差为 0 时，退化为恒等映射</span>，保证性能不下降
4. **模块化设计**：残差块可堆叠，便于构建不同深度的网络
