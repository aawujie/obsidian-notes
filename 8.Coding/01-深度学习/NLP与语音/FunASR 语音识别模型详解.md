## 📌 核心概念

> **FunASR 模型 = 把语音（音频）转换成文字的 AI 神经网络权重文件**

就像你说话，它能听写成文字！

## 🔧 FunASR 模型是什么

### 模型 = 训练好的神经网络权重文件

```
┌─────────────────────────────────────────────────────────────┐
│                  FunASR 模型结构                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【训练阶段】                                                │
│  大量音频数据 + 文字标注 → 训练 → 模型文件 (.pt/.onnx)      │
│         ↓                                                   │
│  数据：数万小时录音 + 人工标注文字                          │
│  训练：GPU 集群训练数周                                      │
│  输出：神经网络权重文件                                     │
│                                                             │
│  【使用阶段】                                                │
│  新音频 → 模型 → 特征提取 → 神经网络推理 → 识别结果 (文字)  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 模型文件特点

| 特性 | 说明 |
|------|------|
| **格式** | `.pt` (PyTorch) / `.onnx` (通用) |
| **大小** | 几十 MB 到几 GB 不等 |
| **跨平台** | ✅ 同一模型文件可在 Windows/macOS/Linux 使用 |
| **语言支持** | 中文、英文、日语、韩语等 |
| **场景** | 通用、电话、会议、音乐等 |
| **离线运行** | ✅ 无需联网，本地推理 |

## 📦 FunASR 主要模型

### 中文语音识别模型

| 模型名                         | 大小     | 参数量   | 特点       | 适用场景     |
| --------------------------- | ------ | ----- | -------- | -------- |
| **paraformer-zh**           | ~200MB | ~200M | 高精度、快速   | 通用场景     |
| **paraformer-zh-streaming** | ~200MB | ~200M | 流式识别     | 实时语音     |

| **paraformer-zh-ws**        | ~300MB | ~300M | 带标点、时间戳  | 字幕生成     |

## 🚀 FunASR 使用示例

### Python 调用

```python
from funasr import AutoModel

# 加载模型
model = AutoModel(model="paraformer-zh")

# 识别音频
result = model.generate(input="test.wav")
print(result[0]["text"])
# 输出："你好，这是一个语音识别测试"
```

### 批量识别

```python
from funasr import AutoModel

model = AutoModel(model="paraformer-zh")

# 批量识别多个文件
files = ["audio1.wav", "audio2.wav", "audio3.wav"]
results = model.generate(input=files)

for r in results:
    print(f"{r['filename']}: {r['text']}")
```

### 流式识别（实时）

```python
from funasr import AutoModel

# 加载流式模型
model = AutoModel(model="paraformer-zh-streaming")

# 实时识别（边说边识别）
result = model.generate(input="microphone", chunk_size=5000)
```

## 🏗️ 模型工作原理

### 识别流程

```
┌─────────────────────────────────────────────────────────────┐
│                  FunASR 识别流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 音频输入                                                 │
│     🔊 麦克风/文件 → WAV/MP3 格式                            │
│         ↓                                                   │
│  2. 音频预处理                                               │
│     重采样 → 降噪 → 音量归一化                               │
│         ↓                                                   │
│  3. 特征提取                                                 │
│     音频 → MFCC/Fbank 特征 → 频谱图                          │
│         ↓                                                   │
│  4. 编码器 (Encoder)                                         │
│     频谱图 → 深度神经网络 → 上下文向量                       │
│         ↓                                                   │
│  5. 解码器 (Decoder)                                         │
│     上下文向量 → 文字序列 → 最终识别结果                     │
│         ↓                                                   │
│  6. 后处理                                                   │
│     添加标点 → 纠错 → 输出文字                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 核心技术

| 技术                 | 说明                          |
| ------------------ | --------------------------- |
| **Transformer**    | 注意力机制，捕捉长距离依赖               |
| **Conformer**      | CNN + Transformer，兼顾局部和全局特征 |
| **CTC Loss**       | 解决音频和文字长度不一致问题              |
| **Beam Search**    | 搜索最优文字序列                    |
| **Language Model** | 语言模型，提高识别流畅度                |

### FunASR 优势

| 优势 | 说明 |
|------|------|
| **中文精度高** | 阿里训练数据多，中文识别第一梯队 |
| **完全离线** | 无需联网，隐私安全 |
| **开源免费** | 商业可用，无授权费 |

| 劣势 | 说明 |
