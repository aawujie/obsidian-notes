## 一、声音基础原理

### 1.1 三频段与发音部位

声音由三个频段叠加而成，每个频段对应不同的发音部位：

| 频段 | 频率范围 | 发音部位 | 决定什么 |
|------|---------|---------|---------|
| 低频 | 20-250Hz | **胸腔** | 厚度、底气、权威感 |
| 中频 | 250-2kHz | **喉咙 + 口腔** | 饱满度、自然度、声音的"身体" |
| 高频 | 2k-8kHz | **口腔前部 + 嘴唇 + 舌尖** | 清晰度、亮度、穿透力、咬字 |

### 1.2 腹部/丹田的角色

腹部不直接产生任何频率，它是**所有频率的动力源（发动机）**：

```
腹部（丹田）→ 提供气息，推动声音
    ↓
胸腔 → 把气息振动放大 → 低频
喉咙/口腔 → 塑造声音主体 → 中频
舌尖/嘴唇 → 咬字和亮度 → 高频
```

腹部气息不够 = 发动机没油 = 三个频段都响不起来。腹式呼吸是所有发声练习的基础。

### 1.3 各频段如何发出

**低频（胸腔）**
- 手按胸口，发低沉的"嗯——"，感受胸腔振动
- 刻意让声音"沉下去"，像从胸口深处发出

**中频（喉咙 + 口腔）**
- 正常说话的主要频段，口腔自然张开即可
- 问题：太强会闷，太弱会薄

**高频（口腔前部 + 舌尖）**
- 打开口腔后部（软腭抬起，像半打哈欠）
- 辅音用舌尖和嘴唇用力"爆破"（t、s、sh、ch、k）
- 想象声音从眉心、额头出来，而不是闷在喉咙里

## 五、练习方法

### 5.1 气息训练（发动机）

**腹式呼吸**（每天 5 分钟，最重要）
- 平躺，手放腹部，吸气肚子鼓起（不是胸部），呼气肚子收缩
- 进阶：站立，双手叉腰，感受腰间一圈扩张
- 目标：说话时声音从腹部"推"出来，不是从喉咙挤
- 检验：录一段话，对比"喉咙说"和"腹部说"

**长音练习**（每天 3 分钟）
- "啊——"平稳发出 20 秒以上
- 进阶："嘶——"（s 音），控制气息均匀

**数数练习**（每天 2 分钟）
- 一口气从 1 数到 30，目标 40 以上

### 5.2 低频训练（胸腔共鸣）

**胸腔振动**（每天 3 分钟）
- 手按胸口，发"哈——"，感受胸腔振动
- 低沉念"大江东去，浪淘尽"，每个字在胸腔里"震"
- 对比录音：喉咙发声 vs 胸腔发声

**低音哼鸣**
- 闭着嘴，用最低的音哼"嗯——"，手摸胸口确认振动

### 5.3 中频训练（口腔打开）

**半打哈欠**（每天 2 分钟）
- 打哈欠，感受软腭（上颚后部）抬起
- 保持半打哈欠状态说话，声音立刻变宽

**检验方法**
- 捏住鼻子说话，如果声音闷了说明软腭没抬起来

### 5.4 高频训练（咬字 + 亮度）

**辅音爆破**（每天 3 分钟）
- p/b："八百标兵奔北坡"
- t/d："调到敌岛打特盗"
- k/g："哥挎瓜筐过宽沟"
- s/sh："四是四，十是十，十四是十四，四十是四十"
- 每个辅音都要"喷"出来，嘴唇和舌头用力

**哼鸣滑音**（每天 3 分钟）
- 闭嘴哼"嗯——"，手指触鼻梁感受振动
- 从低到高滑音，再滑回来
- 开口："咪——嘛——"（mi—ma—），感受鼻→口过渡

**声音前送**
- 想象声音从眉心、额头出来，不是闷在喉咙里

### 5.5 综合练习

**新闻跟读**（每天 5 分钟，最有效）
- 跟读口播博主，模仿音量、咬字力度、节奏
- 录下来与原声对比

**慢速朗读**（每天 3 分钟）
- 1.5 倍慢速朗读，每个字口型做到位
- 慢速练好了，正常速度自然会清晰

### 5.6 每日 30 分钟计划

| 时间 | 内容 | 主攻 |
|------|------|------|
| 5分钟 | 腹式呼吸 + 长音 + 数数 | 气息（发动机） |
| 3分钟 | 胸腔振动 + 低音哼鸣 | 低频（厚度） |
| 3分钟 | 半打哈欠 + 口腔打开 | 中频（饱满度） |
| 3分钟 | 辅音绕口令 + 哼鸣滑音 | 高频（亮度） |
| 5分钟 | 新闻跟读 | 综合模仿 |
| 3分钟 | 慢速朗读 | 口型到位 |
| 5分钟 | 录一条短视频，用自检清单打分 | 检验效果 |
| 3分钟 | 声音前送 + 软腭抬起 | 巩固 |

坚持 2 周见效，1 个月形成肌肉记忆。

## 六、录制习惯

- 罗德麦克风离嘴 **15-20cm**
- 说话音量比平时大 30%，目标录到 **-20~-15dB**
- 防风罩不要遮挡拾音孔
- 罗德接收器：**Merged 模式**
- 录前试 10 秒，看电平表在 -12~-6dB 跳动

## 七、达芬奇/ffmpeg 后期优化

### 7.1 标准处理链（降噪 + 话音 EQ + 配乐）

```bash
# 1. 降噪 + 话音优化
ffmpeg -i input.wav -af "\
highpass=f=60,\
asendcmd='0.0 afftdn@n sn start; 0.6 afftdn@n sn stop',\
afftdn@n=nr=40:nf=-30:tn=1:ad=0.7,\
equalizer=f=2500:t=q:w=2:g=4,\
equalizer=f=5000:t=q:w=2:g=5,\
equalizer=f=600:t=q:w=1:g=-2,\
equalizer=f=120:t=q:w=0.5:g=1,\
highpass=f=70,\
compand=attacks=0.001:decays=0.05:\
points=-90/-90|-50/-50|-35/-25|-20/-15|0/-6:\
gain=10:volume=0" \
output.wav

# 2. 立体声 + 配乐 + 合成视频（见完整流程）
```

### 7.2 EQ 参数速查

| 频率 | 调整 | Q 值 | 效果 |
|------|------|------|------|
| 70Hz | 高通 | — | 切除无效低频 |
| 120Hz | +1dB | 0.5 | 保留胸腔厚度 |
| 600Hz | -2dB | 1.0 | 减少闷感 |
| 2.5kHz | +4dB | 2.0 | 提升清晰度 |
| 5kHz | +5dB | 2.0 | 增加空气感和亮度 |

### 7.3 处理参数速查

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 降噪强度 | 40 | 范围 20-90，太高会有金属声 |
| 音量增益 | 8-10dB | 目标人声 -20~-15dB |
| BGM 混合 | -18dB, 权重 0.15 | 不抢人声 |
| BGM 来源 | 轻松明朗 | 可换叙事抒情、大气深沉等 |

## 八、总结

| 维度 | C0021(前) | C0022(后) | 目标 | 下一步 |

| 低频(胸腔) | ✅ | ✅ | 保持 | 腹式呼吸加深 |
