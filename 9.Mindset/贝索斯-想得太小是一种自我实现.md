# 贝索斯：想得太小，本身就是一种自我实现

## 核心观点

有人问贝索斯，为什么敢去做亚马逊和蓝色起源这种规模巨大的公司。

> "人天生会高估风险，低估机会。风险可能没有你想象得那么大，机会也可能比你看到的更大。"

所以别人眼中的自信，在他看来，更像是在**主动纠正这种认知偏差**。

## 逻辑链条

**目标定小了 → 招更普通的人 → 接受更保守的方案 → 错过更大的市场 → 结果刚好印证"当初想小是对的"**

这不是谨慎，是**自我实现的预言**。你没有验证风险有多大，你只是假设它很大，然后按这个假设行动，最终证明自己是对的。

反过来也一样：

**目标定大了 → 倒逼你找更强的人 → 逼出更优方案 → 打开更大市场 → 结果证明"当初想大是对的"**

- 核心共识：人对风险的直觉系统性地偏高，对机会的直觉系统性地偏低。主动把目标放大，是在做认知纠偏，不是在吹牛。
