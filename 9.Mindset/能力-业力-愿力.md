# 能力、业力、愿力

> 罗振宇短视频片段提出的三层框架

## 三层框架

```
愿力（顶层）→ 排出业力 → 释放能力
```

### 能力

> 能力没那么重要。

你会的技能、你的专业能力、你的智商——单独拿出来很强，但放到现实中往往被对冲得差不多。

### 业力（对冲能力的东西）

> 你能力很强，但是你会被你的环境、期待、被你的历史的记忆、你自己身上的坏习惯——其实能力基本上被制约和对冲的差不多。

**业力包含：**
- **环境**：你所在的组织、文化、土壤
- **期待**：别人对你的期待、社会对你的期待
- **历史的记忆**：过去的失败、创伤、固化认知
- **坏习惯**：拖延、逃避、自我怀疑

这些东西像沙袋一样绑在能力上。能力再强，拖着沙袋也跑不快。

> 参见 [[静达道士-让你舒服的方式才是改命的开始]] 中对业力的讨论：**业力就是惯性思维**。习惯本身无好坏，但把你推向极端就出问题了。

### 愿力（真正让一个人状态好的东西）

> 真正能让一个人状态好的，其实是愿力。有愿力，把业力排出，能力才发挥得出来。

**愿力 = 内在驱动力**，你真正想要什么、你为什么而做。

愿力够强，才能挣脱业力的束缚，让能力释放出来。

## 与静达道士的业力观点对照

| 概念 | 罗振宇 | 静达道士 |
|:---|:---|:---|
| 业力 | 环境/期待/历史/坏习惯，对冲能力 | 惯性思维，习惯推向极端 |
| 排业力 | 靠愿力排出 | 接受情绪、找回节奏、做回血的事 |
| 核心 | 愿力 > 能力 | 舒服的方式 > 努力 |

## 实践含义

- 能力强但状态差 → 检查业力（环境、期待、历史包袱、坏习惯）
- 提升状态 → 不是学更多能力，是找到愿力
- 愿力来源 → 你真正在乎什么？你愿意为什么付出代价？
- 管理者 → 你能做的不是"培养能力"，是帮人排除业力
