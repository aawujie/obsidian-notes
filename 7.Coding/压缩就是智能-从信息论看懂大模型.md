# 压缩就是智能？从信息论看懂大模型

> 3Blue1Brown | 压缩与智能三部曲 Part 1 | Claude Opus 4.8 精译 | 全程中英双语字幕

## 一、开场：压缩与预测是同一枚硬币的两面

当你把文字编码成二进制时，自然想用尽可能少的数据。ASCII默认编码很浪费——每个字符8位。稍微聪明一点（让更常见的字符对应更短的比特串），可以降到约4位/字符。更聪明的方法（利用长序列中的模式），还能更好。

**但极限是什么？**

这个问题追溯到1940年代，Claude Shannon的开创性工作——信息论。而他发展出的数学，如今出人意料地适用于机器学习：

- 大语言模型训练时，预训练部分通常被描述为"下一个token预测"，使用**交叉熵损失**
- "交叉熵"这个词根植于信息论
- 但信息论的一个核心结论是：**预测和压缩是数学等价的**——它们是同一枚硬币的两面

这意味着，你可以完全重新理解预训练目标：不是"下一个token预测"，而是**创造最高效的文本压缩器**。

> 有些人甚至说："压缩就是智能。"虽然这个说法难以严格判断（因为"智能"本身定义模糊），但更安全的说法是：**压缩的数学理论与人工智能有着令人惊讶的关联**。

## 二、热身题：月球机器人编码

想象一个远在月球上的机器人，接收四种移动指令：上、下、左、右。分布不均匀：50%上，25%下，12.5%左，12.5%右。每个指令独立采样。

**问题：用比特流编码这些指令，最高效的方法是什么？**

### 三个学生的方案

**朴素学生**：每个指令用2位（00=上，01=下，10=左，11=右）→ 平均2位/指令

**聪明学生**：让常见指令用更少位：
- 上=0（1位），下=10（2位），左=110（3位），右=111（3位）
- 平均：0.5×1 + 0.25×2 + 0.125×3 + 0.125×3 = **1.75位/指令**

**关键约束**：前缀自由码（prefix-free code）——没有任何码字是另一个码字的前缀。否则接收方无法确定分隔线在哪。

用二叉树可视化：选择码字"0"代表上 → 消耗了左半部分所有可能码字（1/2空间）；"10"代表下 → 消耗1/4；"110"代表左 → 消耗1/8；"111"代表右 → 消耗1/8。

**注意到：这些比例恰好等于各指令出现的概率！** 这就是信息论的创始直觉——**数据长度与概率之间的对应关系**。

### 理论学生：完美压缩看起来像随机噪声

第三位学生从理论出发：**随机噪声是不可压缩的**，因此完美压缩算法输出的比特流应该和随机噪声无法区分——每个bit独立地50%为0或50%为1。

这意味着：
- n位的压缩消息 → 共 $2^n$ 种可能，每种概率 $1/2^n$
- 如果试图让某个消息用更少位（向下移一层）→ 就会与其他消息冲突 → 必须把其他消息推到更高层 → **省1位，代价是其他消息多2位**（压地毯凸起效应）
- **等概率消息的最优方案：给每个消息相同位数**

## 三、信息量（Information）的定义

完美压缩中，n位消息的概率 = $2^{-n}$，取log₂并取负：

$$\text{信息量} = -\log_2(p)$$

这就是信息论的基础公式。直觉解读：**把可能性空间砍半多少次才能到达某个事件**。

| 性质 | 含义 |
|:---|:---|
| 小概率事件 → 信息量大 | 稀有消息包含大量信息 |
| 大概率事件 → 信息量小 | 预期中的消息几乎不含信息 |
| 可以是分数 | 即使不是完美2的幂，仍然有用 |

Shannon将此定义为**一个事件的信息量（information）**。

## 四、熵（Entropy）：平均信息量

熵 = 符号序列的平均信息量 = $\sum p_i \cdot (-\log_2 p_i)$

可视化：每个概率条上方放一个矩形，高度=信息量，总面积=熵。

| 分布特征 | 熵 |
|:---|:---|
| 均匀分布 | 高（最大不确定性） |
| 极度偏斜（一个事件主导） | 低（几乎没有不确定性） |
| 更多符号 | 更高（每个符号信息量更大） |

> Von Neumann据说告诉Shannon："你应该叫它熵，因为1)它和统计力学中的熵公式很像；2)没人真正知道熵是什么，所以你在争论中总是占优势。"

**熵的含义**：不是模糊的"不确定性"，而是精确的——**遵循此分布的消息，每个符号至少需要的位数**。这就是Shannon无噪编码定理的核心。

## 五、自然语言的信息量

机器人例子太干净（概率都是2的幂），但真实语言远非如此：

1. **概率严重依赖上下文**：每个新字母的概率高度依赖之前的内容
2. **概率不是干净的2的幂**：信息量是分数

用小GPT模型分析一段文本，每个字母的Shannon信息量（-log₂p）都是小数。**4.19位的"i"、0.31位的"o"**——这不是说某个编码能给单个字母分配分数位，而是说：

**整条消息的概率 = 各字母条件概率的乘积**
**整条消息的信息量 = 各字母信息量的求和**（因为log把乘法变加法）

## 六、Shannon如何测量语言的信息量

### n-gram统计方法

扫描书籍，记录特定字母组合后面常出现什么。问题：长字符串可能从未在语料中出现。

### Betty猜字母实验

Shannon让妻子Betty逐个猜测下一个字母：
- 猜对了 → 记为横线（-）
- 猜错了 → 写下正确字母

缩减版文本包含相同信息量——如果有Betty的复制品，只需提供缩减文本就能复原原文。

### 1950年改进实验

记录每个字母需要多少次猜测才能猜对，从中推断隐含的概率分布。**关键洞察：Shannon不是做纯数据分析——他在探测语言模型，即被采访者的大脑。**

> 这些大脑是处理语言的黑盒，拥有对语言的复杂且不可描述的理解，能基于上下文预测字符。

## 七、从黑盒到设计黑盒

现在（2020年代），我们从仅仅**询问**语言处理黑盒，进化到了**设计**它们。

现代机器学习大量利用信息论公式。除了信息量本身，还有三个关键表达式需要理解——熵（已完成）、交叉熵、以及它们与LLM训练的关系。

**熵 = 信号的理论压缩极限**

> 无噪编码定理：没有任何编码能超过这个极限，但总能无限接近。

## 八、熵率（Entropy Rate）

熵只适用于每个符号遵循相同分布的情况（如机器人）。但自然语言中，每个新符号的分布依赖上下文——需要**熵率**的概念：

$$H_{\text{rate}} = \lim_{n\to\infty} \frac{H(X_1, X_2, ..., X_n)}{n}$$

这是更一般的"平均每符号信息量"，对整个消息空间取平均。

## 九、核心总结

| 概念 | 公式 | 含义 |
|:---|:---|:---|
| 信息量 | $-\log_2(p)$ | 一个事件的"惊讶程度"，完美编码中等于其位数 |
| 熵 | $\sum p_i(-\log_2 p_i)$ | 平均信息量 = 理论压缩极限（位/符号） |
| 前缀自由码 | 无码字是另一码字的前缀 | 可唯一解码的必要条件 |
| 随机噪声 = 不可压缩 | 完美压缩的输出应像随机噪声 | 理论最优性的判断标准 |
