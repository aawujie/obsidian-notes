# 布朗运动 (Brownian Motion)

---

## 一、什么是布朗运动

**布朗运动**是指悬浮在液体或气体中的微小颗粒所做的**无规则随机运动**。

### 发现历史

| 时间 | 人物 | 贡献 |
|------|------|------|
| 1827 | 罗伯特·布朗 (Robert Brown) | 首次观察到花粉颗粒在水中的无规则运动 |
| 1905 | 爱因斯坦 (Albert Einstein) | 提出理论解释，证明原子存在 |
| 1908 | 佩兰 (Jean Perrin) | 实验验证爱因斯坦理论，获诺贝尔奖 |
| 1923 | 维纳 (Norbert Wiener) | 建立严格的数学理论 |

---

## 二、物理本质

### 产生原因

布朗运动的本质是**液体/气体分子对微粒的随机碰撞**：

```
液体分子 → 不断撞击微粒 → 各个方向撞击力不平衡 → 微粒随机运动
```

### 关键特征

1. **永不停息**：只要温度高于绝对零度，运动就持续
2. **无规则**：运动轨迹不可预测
3. **与温度相关**：温度越高，运动越剧烈
4. **与颗粒大小相关**：颗粒越小，运动越明显
5. **与粘度相关**：介质粘度越低，运动越明显

---

## 三、数学定义（维纳过程）

### 标准布朗运动 W(t)

满足以下条件的随机过程：

1. **初始条件**：W(0) = 0
2. **独立增量**：不相交时间区间的增量相互独立
3. **正态增量**：W(t) - W(s) ~ N(0, t-s)，其中 0 ≤ s < t
4. **连续路径**：轨迹几乎处处连续（但处处不可导）

### 数学性质

| 性质 | 表达式 |
|------|--------|
| 期望 | E[W(t)] = 0 |
| 方差 | Var[W(t)] = t |
| 协方差 | Cov[W(s), W(t)] = min(s, t) |
| 自相似性 | W(at) ≜ √a · W(t) |

---

## 四、核心公式

### 爱因斯坦关系

**扩散系数**：
```
D = k_B · T / (6π · η · r)

其中：
- D = 扩散系数
- k_B = 玻尔兹曼常数 (1.38×10^-23 J/K)
- T = 绝对温度
- η = 介质粘度
- r = 颗粒半径
```

### 均方位移

```
⟨x²⟩ = 2 · D · t  (一维)
⟨r²⟩ = 6 · D · t  (三维)

其中：
- ⟨x²⟩ = 时间 t 内的均方位移
- D = 扩散系数
- t = 时间
```

### 斯托克斯 - 爱因斯坦方程

```
D = μ · k_B · T

其中：
- μ = 迁移率 = 1 / (6π · η · r)
```

## 五、布朗运动的特性

### 1. 标度不变性（自相似性）

布朗运动在不同时间尺度下看起来相似：

```
放大或缩小时间轴，轨迹的统计特性不变
```

### 2. 分形特性

- **分形维数**：2
- 轨迹长度：无限（测量尺度越小，长度越长）
- 处处连续但**处处不可导**

### 3. 马尔可夫性

```
P(W(t+Δt) | W(t), W(t-1), ...) = P(W(t+Δt) | W(t))

未来状态只依赖于当前状态，与历史无关
```

### 4. 二次变差

```
[W, W](t) = t

这是布朗运动区别于其他过程的重要特征
```

## 六、模拟布朗运动

### Python 代码示例

```python
import numpy as np
import matplotlib.pyplot as plt

def brownian_motion(T=1, n=1000):
    """生成标准布朗运动路径"""
    dt = T / n
    # 生成独立正态增量
    dW = np.sqrt(dt) * np.random.randn(n)
    # 累加得到布朗运动路径
    W = np.cumsum(dW)
    # 添加初始点 W(0) = 0
    W = np.insert(W, 0, 0)
    t = np.linspace(0, T, n+1)
    return t, W

# 生成并绘制
t, W = brownian_motion()
plt.figure(figsize=(10, 6))
plt.plot(t, W, linewidth=0.8)
plt.xlabel('Time t')
plt.ylabel('W(t)')
plt.title('Brownian Motion Path')
plt.grid(True, alpha=0.3)
plt.show()
```

### 多维布朗运动

```python
def brownian_motion_2d(T=1, n=1000):
    """生成二维布朗运动路径"""
    dt = T / n
    dW_x = np.sqrt(dt) * np.random.randn(n)
    dW_y = np.sqrt(dt) * np.random.randn(n)
    
    W_x = np.cumsum(dW_x)
    W_y = np.cumsum(dW_y)
    
    W_x = np.insert(W_x, 0, 0)
    W_y = np.insert(W_y, 0, 0)
    
    return W_x, W_y

# 绘制二维轨迹
W_x, W_y = brownian_motion_2d()
plt.figure(figsize=(8, 8))
plt.plot(W_x, W_y, linewidth=0.5)
plt.scatter([0], [0], c='red', s=50, label='Start')
plt.xlabel('X')
plt.ylabel('Y')
plt.title('2D Brownian Motion')
plt.legend()
plt.grid(True, alpha=0.3)
plt.axis('equal')
plt.show()
```

## 七、应用领域

### 1. 物理学

- **统计力学**：连接微观分子运动与宏观现象
- **扩散现象**：气体扩散、热传导
- **证明原子存在**：爱因斯坦的理论解释

### 2. 金融学（核心应用）

**布莱克 - 斯科尔斯模型**的基础：

```
股票价格模型（几何布朗运动）：
dS = μ·S·dt + σ·S·dW

其中：
- S = 股票价格
- μ = 期望收益率（漂移率）
- σ = 波动率
- dW = 布朗运动增量
```

**期权定价公式**依赖布朗运动理论。

### 3. 生物学

- **分子扩散**：细胞内物质传输
- **种群动态**：生物种群的随机波动
- **神经科学**：神经元放电的随机模型

### 4. 工程学

- **信号处理**：噪声建模
- **控制系统**：随机扰动分析
- **图像处理**：随机纹理生成

### 5. 计算机科学

- **随机算法**：蒙特卡洛方法
- **机器学习**：随机梯度下降的噪声分析
- **网络流量**：数据包到达的随机模型

## 八、扩展概念

### 几何布朗运动 (GBM)

```
dX = μ·X·dt + σ·X·dW

特点：
- 始终为正（适合建模股票价格）
- 对数收益率服从正态分布
```

### 布朗桥 (Brownian Bridge)

```
条件布朗运动：W(0) = 0, W(T) = 0

应用：
- 路径积分
- 统计检验
```

### 分数布朗运动 (fBm)

```
Hurst 指数 H ∈ (0, 1)

- H = 0.5：标准布朗运动
- H > 0.5：持久性（趋势增强）
- H < 0.5：反持久性（均值回归）

应用：金融市场、网络流量、地貌分析
```

### 朗之万方程

```
m·dv/dt = -γ·v + ξ(t)

其中：
- m = 质量
- γ = 阻尼系数
- ξ(t) = 随机力（白噪声）

描述：布朗粒子的速度演化
```

## 九、重要定理

### 伊藤引理 (Itô's Lemma)

随机微积分的基本定理：

```
对于函数 f(t, X)，其中 dX = μ·dt + σ·dW：

df = (∂f/∂t + μ·∂f/∂x + ½·σ²·∂²f/∂x²)·dt + σ·∂f/∂x·dW

关键：多了 ½·σ²·∂²f/∂x² 项（伊藤修正项）
```

### 反射原理

```
P(max_{0≤s≤t} W(s) ≥ a) = 2·P(W(t) ≥ a)

应用：计算布朗运动的最大值分布
```

### 停时定理

```
对于有界停时 τ：E[W(τ)] = 0

应用：期权定价、赌博问题
```

## 十、可视化理解

### 一维布朗运动特征

```
时间 t →
     |
W(t) |     ╱╲    ╱╲╱
     |   ╱  ╲╱╲╱  ╱
     | ╱      ╲  ╱
     |/        ╲╱
     +----------------
     0
```

- 起点：W(0) = 0
- 路径：连续但极其不规则
- 位移：随 √t 增长（不是 t）

### 均方位移增长

```
⟨x²⟩ ∝ t

不是 ⟨x⟩ ∝ t（普通运动）
而是 ⟨x²⟩ ∝ t（扩散运动）

这意味着：典型位移 ∝ √t
```
