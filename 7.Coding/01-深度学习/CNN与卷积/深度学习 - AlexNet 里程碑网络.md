## 📊 二、深度学习前的主流机器学习方法

### 核方法时代（2000 年代初期）

```
核方法的核心思想：

1. 提取特征
   原始数据 → 特征向量

2. 核函数计算
   特征向量 → 核矩阵（相似度）

3. 凸优化求解
   核矩阵 → 最优解（有数学定理保证）
```

### 核方法的特点

| 特点 | 说明 |
|------|------|
| **数学基础** | 有完整的数学定理支撑 |
| **凸优化** | 转化为凸优化问题，保证全局最优 |
| **调参友好** | 对调参不敏感，易于使用 |
| **特征依赖** | 严重依赖人工特征工程 |

### SVM（支持向量机）

```
SVM = 核方法的代表

优势：
✅ 至今仍被广泛使用
✅ 对小数据集效果好
✅ 理论完备
✅ 对调参不敏感

局限：
❌ 依赖人工特征
❌ 难以处理大规模数据
❌ 无法端到端学习
```

## 🔧 七、AlexNet 的核心改进点

### 1. <span style="color:rgb(255, 77, 77)">Dropout 正则化</span>

```
问题：
深度神经网络容易过拟合
全连接层参数过多

解决方案：Dropout

原理：
训练时随机"丢弃"部分神经元
（将其输出设为 0）

效果：
✅ 减少神经元之间的共适应
✅ 相当于训练多个子网络的集成
✅ 显著降低过拟合风险
```

```python
# PyTorch 实现
import torch.nn as nn

# 全连接层后加 Dropout
self.fc1 = nn.Linear(9216, 4096)
self.dropout1 = nn.Dropout(p=0.5)  # 丢弃 50% 神经元

self.fc2 = nn.Linear(4096, 4096)
self.dropout2 = nn.Dropout(p=0.5)
```

### 2. <span style="color:rgb(255, 77, 77)">ReLU 激活函数</span>

```
之前的激活函数：Sigmoid / Tanh

Sigmoid 问题：
❌ 梯度消失（深层网络梯度趋近于 0）
❌ 输出不是零中心
❌ 计算复杂（指数运算）

ReLU (Rectified Linear Unit):
f(x) = max(0, x)

优势：
✅ 缓解梯度消失问题
✅ 计算简单（阈值操作）
✅ 稀疏激活（部分神经元输出为 0）
✅ 支撑更深模型训练
```

```python
# 激活函数对比
import torch
import torch.nn as nn

# Sigmoid（旧方法）
self.activation = nn.Sigmoid()
# 问题：深层网络梯度消失

# ReLU（AlexNet 采用）
self.activation = nn.ReLU()
# 优势：梯度不消失，训练更深网络
```

### 3. <span style="color:rgb(255, 77, 77)">最大池化</span>

```
之前的池化方式：平均池化

平均池化：
取窗口内所有值的平均值
→ 输出值较小
→ 梯度较小

AlexNet 采用：最大池化

最大池化：
取窗口内的最大值
→ 输出值更大
→ 梯度更大
→ 训练更容易进行
```

```python
# 池化方式对比
import torch.nn as nn

# 平均池化（旧方法）
self.pool = nn.AvgPool2d(kernel_size=3, stride=2)

# 最大池化（AlexNet 采用）
self.pool = nn.MaxPool2d(kernel_size=3, stride=2)
# 优势：梯度更大，训练更容易
```

### <span style="color:rgb(255, 77, 77)">改进点对比表</span>

| 改进点 | LeNet | AlexNet | 效果 |
|--------|-------|---------|------|
| **激活函数** | Sigmoid | ReLU | 缓解梯度消失 |
| **正则化** | 无 | Dropout | 减少过拟合 |
| **池化方式** | 平均池化 | 最大池化 | 梯度更大 |
| **数据增强** | 无 | 有 | 提升鲁棒性 |

## 🔄 八、深度学习的端到端学习理念

### 观念上的改变

```
传统方法（多阶段）：
原始图像 → 人工特征提取 → 分类器训练 → 结果
     ↓           ↓              ↓
   独立步骤    独立步骤       独立步骤
   特征与分类器分开优化

深度学习（端到端）：
原始图像 → CNN 自动学习特征 + 分类 → 结果
     ↓_____________________________↓
              一起训练，端到端优化
```

### 端到端学习的优势

| 优势 | 说明 |
|------|------|
| **自动特征学习** | 不再依赖人工特征提取 |
| **联合优化** | 特征提取与分类器一起训练 |
| **特征适配** | 学习到的特征更适配分类任务 |
| **跨领域使用** | 可跨问题、跨学科使用 |
| **高效** | 减少人工干预，自动化程度高 |

### 特征学习对比

```
人工特征工程：
专家设计 → SIFT/HOG 特征 → 固定特征表示
局限：特征质量依赖专家经验

CNN 自动学习：
数据驱动 → 网络自动学习 → 任务优化特征
优势：特征针对任务优化，质量更高
```

## 📐 九、AlexNet 与 LeNet 的架构对比

### 输入对比

| 特性 | LeNet | AlexNet |
|------|-------|---------|
| **图像尺寸** | 32×32 | 224×224 |
| **通道数** | 1（灰度） | 3（RGB 彩色） |
| **输入类型** | 手写数字 | 自然图像 |
| **像素数** | 1,024 | 150,528 |

### 卷积层对比

```
LeNet 卷积层：
├── 2 个卷积层
├── 卷积核：5×5
├── 通道数：6 → 16
└── 结构较简单

AlexNet 卷积层：
├── 5 个卷积层（新增 3 个 3×3 卷积层）
├── 卷积核：11×11, 5×5, 3×3
├── 通道数：64 → 192 → 384 → 256 → 256
└── 结构更深更复杂
```

### 全连接层对比

| 层 | LeNet | AlexNet |
|----|-------|---------|
| **FC1** | 120 | 4096 |
| **FC2** | 84 | 4096 |
| **输出** | 10 | 1000 |

### 完整架构对比

```
LeNet-5 架构：
输入 (32×32×1)
  ↓
Conv1 (5×5, 6 通道) + AvgPool
  ↓
Conv2 (5×5, 16 通道) + AvgPool
  ↓
FC1 (120) → FC2 (84) → 输出 (10)

AlexNet 架构：
输入 (224×224×3)
  ↓
Conv1 (11×11, 96 通道，S=4) + ReLU + MaxPool + Dropout
  ↓
Conv2 (5×5, 256 通道) + ReLU + MaxPool + Dropout
  ↓
Conv3 (3×3, 384 通道) + ReLU
  ↓
Conv4 (3×3, 384 通道) + ReLU
  ↓
Conv5 (3×3, 256 通道) + ReLU + MaxPool
  ↓
FC1 (4096) + ReLU + Dropout
  ↓
FC2 (4096) + ReLU + Dropout
  ↓
输出 (1000) + Softmax
```

## 🛠️ 十、AlexNet 的其他重要优化手段

### 1. Dropout 正则化（详细）

```
位置：全连接隐藏层后

配置：
- FC1 后：Dropout(p=0.5)
- FC2 后：Dropout(p=0.5)

作用：
✅ 训练时随机丢弃 50% 神经元
✅ 测试时所有神经元保留（输出×0.5）
✅ 降低过拟合风险
✅ 提升泛化能力
```

### 2. 数据增强

```
数据增强方法：

1. 随机截取（Random Crop）
   原图：256×256
   随机裁剪：224×224
   → 增加位置不变性

2. 随机水平翻转
   50% 概率水平翻转
   → 增加数据量 2 倍

3. 颜色抖动
   调整亮度、对比度、饱和度
   → 增加光照不变性

4. 色温调整
   改变图像色温
   → 增加颜色不变性
```

```python
# 数据增强示例（PyTorch）
from torchvision import transforms

train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),      # 随机裁剪
    transforms.RandomHorizontalFlip(),      # 随机翻转
    transforms.ColorJitter(                 # 颜色抖动
        brightness=0.4,
        contrast=0.4,
        saturation=0.4
    ),
    transforms.ToTensor(),
    transforms.Normalize(                   # 标准化
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225]
    )
])
```

### 数据增强的效果

| 增强方式 | 作用 | 提升鲁棒性 |
|----------|------|------------|
| 随机裁剪 | 增加样本变种 | 位置不变性 |
| 水平翻转 | 数据量×2 | 方向不变性 |
| 亮度调整 | 模拟不同光照 | 光照不变性 |
| 色温调整 | 模拟不同环境 | 颜色不变性 |

## 📊 十一、AlexNet 与 LeNet 的复杂度对比

### 参数量对比

```
LeNet 参数量：
├── 卷积层：约 20 万
├── 全连接层：约 40 万
└── 总计：约 60 万参数

AlexNet 参数量：
├── 卷积层：约 250 万
├── 全连接层：约 4350 万
└── 总计：约 4600 万参数

对比：AlexNet 是 LeNet 的约 77 倍！
```

### 参数量详细计算

```
AlexNet 参数分解：

Conv1: 11×11×3×96 = 34,848
Conv2: 5×5×96×256 = 614,400
Conv3: 3×3×256×384 = 884,736
Conv4: 3×3×384×384 = 1,327,104
Conv5: 3×3×384×256 = 884,736

FC1: 9216×4096 = 37,748,736  ← 最多！
FC2: 4096×4096 = 16,777,216
FC3: 4096×1000 = 4,096,000

总计：约 62,367,776 参数
（实际约 4600 万，部分优化）
```

### 计算量对比

```
单次前向运算浮点计算量 (FLOPs)：

LeNet: 约 400 万次 FLOPs
AlexNet: 约 10 亿次 FLOPs

对比：AlexNet 是 LeNet 的 250 倍！
```

### 计算量增加的原因

```
为什么计算量大幅增加？

1. 卷积层的参数相乘特性
   每个卷积核要与输入窗口逐元素相乘

2. 输入尺寸增大
   32×32 → 224×224 (7×7 倍)

3. 通道数增加
   1/6/16 → 3/64/192/384/256

4. 网络更深
   2 卷积层 → 5 卷积层

结果：
计算量呈指数级增长
需要 GPU 才能训练
```

### 复杂度对比表

| 指标 | LeNet | AlexNet | 倍数 |
|------|-------|---------|------|
| **参数量** | 60 万 | 4600 万 | 77× |
| **计算量 (FLOPs)** | 400 万 | 10 亿 | 250× |
| **输入尺寸** | 32×32 | 224×224 | 49× |
| **卷积层数** | 2 | 5 | 2.5× |
| **全连接层神经元** | 204 | 8192 | 40× |
