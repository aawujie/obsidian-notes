# 2. Overview

视频核心在解释什么是 regression tree（回归树），为什么在某些回归问题上（特别是数据呈非线性、分段行为或有多个预测变量时）回归树比简单的线性回归更合适。视频通过一个“药物剂量 vs. 疗效”的示例演示了回归树如何把连续预测变量切分成若干区间（leaf/叶子节点对应数值输出），以及如何基于最小化 sum of squared residuals（SSR，残差平方和）来选择最优切分阈值。还讨论了过拟合问题与常用的控制策略（如设置最小分割样本数），并扩展到多预测变量时如何比较不同变量的最佳切分候选来选择根节点。

# 3. 按照主题来梳理

## 3.1 示例与问题背景：药物剂量与疗效（为何需要回归树）

- 视频一开始用一个直观的临床试验情境说明问题。设想我们开发了一种治疗普通感冒的新药，但不知道最佳剂量（dose）。我们在临床试验中尝试不同剂量并记录每个剂量对应的药物有效率（effectiveness，数值型）。在理想的线性关系情形下，随剂量增加疗效单调上升，简单地对数据拟合一条直线可以用来为任意剂量（例如27 mg）预测疗效（例如预测为62%）。但实际数据可能并非单调或线性：视频举了一个非线性、分段行为的例子——低剂量无效（near 0%），中等剂量非常有效（接近100%），稍高剂量效果回落到约50%，而高剂量完全无效。对于这种“分段”或“阶梯”式行为，线性回归显然不能很好地捕捉真实关系（例如对20 mg线性拟合可能预测45%但观测值是100%），因此需要其他方法来做预测。
- 在这种情况下，回归树（regression tree）是一个直观的选择。回归树把连续变量通过阈值切分成若干区间（节点），每个叶子（leaf）保存一个数值预测，通常是该叶子内训练样本目标值的平均值。通过这种分段平均的方法，回归树能更好地反映数据的局部结构，比如把中等剂量区间预测为高疗效、低或高剂量区间预测为低疗效。
- 视频还指出回归树的一个重要实际优势：当自变量不止一个（例如含有剂量、年龄、性别等）时，用肉眼画图观察关系几乎不可能，但回归树可以自然地对多个变量进行分割（每次比较不同变量的阈值效果），从而在多维空间中生成可解释的分段预测规则（例如先问年龄是否大于50，再问剂量是否大于等于29，再问性别是否为女性，最终落到某个叶子并输出某个平均疗效预测值）。

## 3.2 回归树的结构与单一预测变量下的构造示例

- 回归树是决策树（decision tree）的一类，用于回归问题（目标变量是连续数值）。与分类树在叶子里放离散类别不同，回归树在每个叶子放一个数值（通常是训练集中该叶子内目标变量的平均值）。视频用具体阈值示范了一个回归树结构：根节点判断 dosage < 14.5；如果是，落入左侧叶子群且该分支对应训练集中六个观测点，这六个观测点的平均疗效为 4.2%，因此该叶子预测值为 4.2%；如果 dosage >= 14.5，则继续判断是否 dosage >= 29，若是则落入另一个叶子，该叶子包含训练集中四个观测，其平均疗效为 2.5%，因此预测为 2.5%；如果 14.5 <= dosage < 29，则进一步按是否 >= 23.5 分裂，23.5 <= dosage < 29 的五个观测平均疗效为 52.8%（预测值 52.8%），而 14.5 <= dosage < 23.5 的四个观测平均疗效为 100%（预测值 100%）。这种分裂使树能够对不同剂量区间赋予不同的预测平均值，从而更贴合原始数据分布。
- 视频强调了叶子内数值为“该簇观测的平均值”的概念，并用图示说明残差（observed - predicted）如何表现为点与该叶子平均值之间的垂直差。每个观测的残差平方（squared residual）表示该观测对总体误差度量的贡献。用残差平方和（SSR, sum of squared residuals）来衡量在某个给定分裂（或整个树结构）下的拟合质量：SSR 越小，表示预测误差总体越小。
- 构造树的要点（单一预测变量的逐步构造）：从顶层开始考虑所有可能的阈值（通常用相邻两观测剂量的平均作为候选阈值），对每个阈值按照左/右子集分别计算叶子预测（即每边的平均目标值），然后计算全数据的 SSR（把所有观测的残差平方相加）。遍历所有候选阈值后，选择能使 SSR 最小的阈值作为当前节点的最佳分裂（root 或某个内部节点）。在视频示例中，遍历了阈值 3、5、7、…… 直到找到 SSR 最小的阈值 14.5，因此把剂量小于 14.5 作为第一个分裂点（根节点）。这个逐步搜索候选阈值并比较 SSR 的过程就是回归树构造的核心操作（在单变量情形下直观且可视化）。
- 选定根节点后，对左右子集重复相同过程：对左侧剂量 < 14.5 的那部分样本再次尝试所有可能阈值并计算 SSR，选择能最小化 SSR 的阈值继续分裂，若某个子节点包含太少样本（见后文的停止条件）或没有更优的分裂则停止并设为叶子。视频中对左侧 6 个样本尝试分裂，发现有些子集最终会分成含单个观测的叶子（不能再分）；但因为训练数据量较小且若完全分割会导致每个叶子拟合训练数据“完美”但泛化能力差（过拟合），所以实际使用时需要设置最小叶子样本数（min samples）来阻止过细分裂，本示例中将最小样本数设置为 7（通常默认值是 20），因此左侧 6 个样本不再继续分裂，而是直接作为叶子，预测值为这 6 个样本的平均 4.2%。

## 3.3 用 SSR（残差平方和）挑选分裂：具体步骤与可视化

- 在每一次候选分裂的评估中，计算 SSR 是核心。具体步骤如下：
    1. 列出所有可能的分裂阈值。在单变量情境中，常用的候选阈值是相邻两个训练样本预测变量值的平均。例如两个相邻剂量为 1 和 5，则候选阈值可以取 (1+5)/2 = 3。依次对所有相邻对计算平均，形成一组候选阈值。
    2. 对每个候选阈值，把数据分为左/右两组（例如 dosage < threshold 与 dosage >= threshold）。在每组内部，计算目标变量的平均值，该平均值作为该组的预测输出（叶子值）。
    3. 对所有观测计算残差（observed - predicted），求残差平方并对所有观测求和，得到该候选阈值下的 SSR（sum of squared residuals）。
    4. 在所有候选阈值中选择 SSR 最小的那个，作为当前节点的最佳分裂阈值。图形化地，把 SSR 值画成纵轴、候选阈值画成横轴，可以直观看到哪个阈值使 SSR 最小。
- 视频用一系列候选阈值（例如 3, 5, 7, …, 14.5, …）逐步计算 SSR，并在图上展示 SSR 随阈值变化的曲线，从而找到 SSR 最小的阈值 14.5 作为根节点分裂。选定根节点后，对每个子节点重复同样的候选阈值与 SSR 评估流程，直到满足停止条件。
- 这种以 SSR 最小化为目标的分裂策略，实质上在贪婪地局部最优化：每次分裂都选择当前最能减少总体误差（SSR）的阈值，但并不保证全局最优（即并非一定得到全局最小的树结构）。这也是多数决策树算法的常规做法：通过贪心拆分快速构建树，而非穷尽全局组合。

## 3.4 停止条件、过拟合与如何防止过拟合

- 视频强调一个关键风险：如果允许无限制地分裂节点，树最终可能把每个训练样本单独分进一个叶子，导致训练集上“完美拟合”（预测与观测完全一致、残差为零）。虽然训练误差变为 0，但这种模型通常过拟合（overfit），在新数据上的泛化性能很差。用机器学习术语来说，这样的模型“几乎没有 bias（偏差）但有很大的 variance（方差）”——训练数据拟合太精细而对噪声敏感。
- 为了防止过拟合，需要引入停止规则或正则化策略，常见方法包括：
    - 最小叶子样本数（min samples）：在当前示例中，视频采用了“只有当某节点包含至少某个最小样本数（通常是 20，但示例里因数据少设为 7）时才允许分裂”。如果节点内样本数小于该阈值，则该节点直接变为叶子，输出其内部样本的平均值。这样可以防止生成很多包含极少样本的叶子，从而降低方差、提高泛化。
    - 最大树深度（max depth）：限制树的最大分裂层数，避免过深的树结构。
    - 最小信息增益或最小 SSR 减少量：要求分裂带来的误差下降（例如 SSR 的减少）必须超过某个阈值，否则不进行分裂。
    - 剪枝（pruning）：先生长一棵大树，再通过交叉验证或代价复杂度（cost-complexity）等方法剪去对验证误差没有帮助或导致过拟合的分支。
- 视频在示例中演示了设置 min samples = 7 的效果：尽管纯粹按局部 SSR 可能会分出一些单样本叶子（导致训练误差为 0），但因为阈值 7 阻止了这些分裂，左侧包含 6 个观测的节点就成了叶子并输出平均 4.2%，从而避免了对训练数据的完全记忆。视频同时提醒常见实际默认值为 20，但在样本量少的教学示例中会调小为 7，以便能演示更多分裂步骤。

## 3.5 多个预测变量时的分裂策略（如何选择根与后续分裂）

- 回归树不仅可以用于单一预测变量，也适合多个预测变量（例如 dosage、age、sex）。在多变量情形下，构建树的核心思想与单变量相同，但在每一步需要在多个变量上寻找最优分裂阈值，然后在这些候选中选择使 SSR 最小的那一个作为实际分裂。具体流程：
    1. 对每个候选预测变量（例如 dosage、age、sex），分别枚举该变量的可能阈值（对于数值变量如 dosage、age，可用相邻样本值的平均形成候选；对于二元变量如 sex，只有一个天然的阈值划分，例如 male vs female）。
    2. 对每个变量的每个候选阈值，计算将数据分为两组后整体的 SSR（按两组内平均值预测并加和残差平方）。
    3. 对所有变量和阈值组合，找出 SSR 最小的组合——对应变量与阈值的那一分裂成为当前节点的实际分裂（例如视频中 age > 50 可能比 dosage 的某个分裂或 sex 的分裂减少更多的 SSR，因此 age > 50 被选为根节点）。
    4. 对分裂生成的左右子节点重复以上过程（在每个子节点的局部数据上，重新对所有变量尝试分裂），直到满足停止条件（最小叶子样本数、最大深度等）。
- 视频给出了一个具体的多变量推断示例：若我们要为某个病人预测疗效（给定 age、dosage、sex），我们从树根开始回答树上的问题。例如根节点是 age > 50，如果病人 age <= 50，则沿右侧分支；接着在该子节点可能的分裂是 dosage >= 29，如果该病人的 dosage < 29 再沿右分支；接着分裂可能是 sex==female，如果为女性则到对应叶子并给出该叶子平均疗效（例如预测 100%），并指出实际观测接近 98%，说明树的预测还比较合理。这个例子展示了回归树如何通过一系列“是/否”的问题（变量阈值判断）在高维空间里定位到一个叶子并给出预测。
- 重要的是，树的构造过程在多变量情形下仍然是“贪心”的：每一步选择当前最能减少 SSR 的分裂，而不是全局最优。实际算法（如 CART）都遵循这种局部最佳的迭代分裂策略，但可能结合剪枝等后处理来改善泛化。

# 4. 框架 & 心智模型（Framework & Mindset）

- 回归树的核心框架可抽象为“局部分割 + 局部均值预测 + 贪心最小化残差”三个要素。下面将这一框架分步骤描述，并说明每一步的心智模型（mindset）与直觉：
    1. 局部分割（Partitioning）：
        - 心智模型：把复杂的全局关系拆解为一系列更简单的局部关系。与把整体函数逼近为一条多项式不同，回归树认为不同输入子集可能有不同的“常数”或局部均值行为，因此通过阈值切分将样本空间划分为互不重叠的矩形（或区间）区域。
        - 实践步骤：在当前节点上，枚举每个候选自变量及其候选阈值，计算把数据按该阈值分成两组后的效果。候选阈值通常取连续变量相邻样本值的平均；离散或二元变量则用其本身划分（例如 sex）。
        - 直觉：通过切割划定“相似”的样本子集，使得每个子集内的目标值更趋于一致，从而用一个常数（平均值）就能较好地预测。
    2. 局部均值预测（Leaf Prediction）：
        - 心智模型：在一个子集内部，最稳健且最简单的预测是该子集目标的平均值（在 L2 损失下这是最优常数预测）。回归树在叶子处把该平均当作该区域的预测输出。
        - 实践步骤：树在每个叶子计算内部样本目标的均值并保存；对新样本，只需按树的分裂规则走到叶子并返回该均值。
        - 直觉：用常数表示该局部行为，避免过度拟合复杂函数形状，保持可解释性。
    3. 贪心最小化残差（Greedy SSR Minimization）：
        - 心智模型：每一次分裂都试图最大限度地减少当前数据在 L2 意义下的误差（即 SSR）。这是一种逐步改进的过程：先在全数据上做一次最优的局部分割，然后在每个子集上继续重复，像“二分法”一样不断细化划分。
        - 实践步骤：对每个候选分裂计算全样本的 SSR，选择 SSR 最小的那个分裂并应用，然后对子节点重复。该过程是贪婪的（local optimum），不是全局搜索。
        - 直觉：把复杂问题分成许多小决策，每个决策都朝着减少总体预测误差的方向前进。这种贪心策略在多数情况下能快速得到足够好的模型，但需要后续策略（如剪枝或最小样本数）来控制过拟合。
- 控制复杂度的心智与策略：
    - 心智模型：树越深、叶子越多，模型越复杂、方差越大；树越浅、叶子越少，模型偏差越大。需要在偏差（bias）与方差（variance）之间权衡。
    - 实践做法：通过设置 min samples（最小分裂样本数，如视频示例用 7，常见实践用 20）、设置最大深度、或在生长后用剪枝（pruning）和交叉验证（cross-validation）来选择最佳复杂度。若叶子个数过多要警惕训练集上的“完美拟合”，此时验证集/交叉验证的误差会指出泛化下降。
    - 直觉：把树生长成“刚好”能捕捉主要模式而不是记忆噪声的程度。用验证集来选择复杂度参数（min samples、max depth、prune strength），而不是只看训练误差。
- 可扩展性与多维解释性的心智：
    - 心智模型：回归树通过一系列阈值判断形成可读的规则（if...then...），因此在多变量情况下仍然可解释；每条预测路径都是一组易于理解的条件组合。
    - 实践：在有多个预测变量时，对每个变量独立地寻找最佳分裂阈值并比较 SSR，从而在每个节点选择最有信息量的变量与阈值。这使得树能天然处理数值及类别变量，并生成可追溯的决策路径（例如 age > 50 → dosage < 29 → sex == female → predict 100%）。
    - 直觉：把高维预测问题转化为一系列一维判断，便于解释与落地（例如将决策规则直接应用于临床推荐或业务规则）。
- 总结心智模型：回归树是一种“局部常数建模 + 贪心分割 + 控制复杂度”的方法论。设计回归树时应始终用 SSR（或其他损失）评估分裂收益、设置合适的停止/正则化策略来控制方差，并在多变量情形下比较各变量的分裂潜力以形成可解释的分支规则。

# 总结

- 回归树（regression tree）是决策树在回归问题上的应用，每个叶子输出一个数值（通常是该叶子内目标值的平均）。它适合捕捉非线性、分段或分簇的关系，并能方便地处理多个预测变量。
- 树的构造过程是自顶向下的贪心分裂：在每个节点枚举候选阈值（对于每个预测变量），计算用该阈值分裂后全样本的 SSR（残差平方和），选择能让 SSR 最小的分裂作为当前节点的实际分裂。对每个子节点重复此过程直至满足停止条件。
- 为防止过拟合，需要设置最小叶子样本数（示例中用 7，实际常见值为 20）、最大深度或采用剪枝与交叉验证来控制树的复杂度。
- 多变量情形下，每一步都比较不同变量的最优分裂候选，选出能最大降低 SSR 的变量与阈值作为该节点分裂，从而得到一组可解释的规则路径，用以对新样本进行预测。
