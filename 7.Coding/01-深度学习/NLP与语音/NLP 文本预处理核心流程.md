# NLP 文本预处理核心流程

> 视频学习笔记 | 2026-03-14

---

## 核心思想

将文本视作**时序序列**：
- 把字符、字或词作为样本
- 将文本转化为可训练的格式

---

## 完整流程

### 1. 数据集选择与读取

- 选用无版权的《时间机器》英文文本
- 读取 txt 文件，避免版权问题

### 2. 英文文本暴力清洗

```
非字母字符 → 空格
换行符 → 去除
统一转为小写
仅保留 26 个字母与空格
```

**目的**：简化处理，聚焦核心流程

### 3. Tokenization（分词）

把文本转为 token 单元：

| 语言 | Token 级别 |
|------|-----------|
| 英文 | 词级 / 字符级 |
| 中文 | 需额外分词处理 |

### 4. 词汇表（Vocabulary）构建

- 将 token 映射为数字索引
- 过滤低频 token
- 加入未知 token `<unk>`
- 支持 token 与索引互转

### 5. 文本转数字序列

```
token → 词汇表索引 → 整数序列 → 时序张量
```

最终生成可用于模型训练的时序张量。

### 6. 预处理打包函数

封装完整流程：

```
读取 → 清洗 → 分词 → 建表 → 转索引
```

**输出**：
- 语料数字序列
- 词汇表

---

## 关键概念

| 概念 | 说明 |
|------|------|
| Token | 文本处理的基本单元（字符/词） |
| Vocabulary | token 到数字索引的映射表 |
| `<unk>` | 未知 token，处理词汇表外的词 |
| 时序张量 | 模型可接受的数字序列格式 |

---

## 代码实现要点

1. **清洗函数**：正则表达式过滤非字母字符
2. **分词器**：split() 或自定义字符级切分
3. **词频统计**：Counter 或字典计数
4. **索引映射**：两个字典（token→idx, idx→token）
5. **序列化**：列表推导式批量转换
