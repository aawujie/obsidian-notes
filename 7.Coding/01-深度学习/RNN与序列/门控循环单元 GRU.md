# 门控循环单元（GRU）

> 视频学习笔记 | 2026-03-14

---

## 定位与背景

**GRU（Gated Recurrent Unit）** 门控循环单元：

- **提出时间**：在 LSTM 之后提出
- **结构特点**：比 LSTM 更简单
- **效果对比**：与 LSTM 相近，实际使用可任选
- **讲解顺序**：因结构简单，通常在 LSTM 之前讲解

---

## 普通 RNN 的缺陷

### 问题描述

| 问题          | 说明                                                        |
| ----------- | --------------------------------------------------------- |
| **无法处理长序列** | <span style="color:rgb(255, 77, 77)">序列过长时效果急剧下降</span>   |
| **信息堆积**    | <span style="color:rgb(255, 77, 77)">隐藏状态会堆积过多信息</span>   |
| **早期信息丢失**  | <span style="color:rgb(255, 77, 77)">难以提取序列早期的重要信息</span> |
| **无选择性**    | <span style="color:rgb(255, 77, 77)">无法区分重要与无关内容</span>   |

### 核心需求

需要一种机制能够 <span style="color:rgb(255, 77, 77)"><b>选择性保留/遗忘信息</b></span>。

---

## 门控机制的核心作用

**门控（Gating）** 解决 RNN 缺陷：

```
┌─────────────────────────────────────┐
│  门控机制 = 信息过滤器                 │
│                                     │
│  • 选择性保留重要信息                  │
│  • 选择性遗忘无关内容                  │
│  • 在历史与当前之间灵活调整             │
└─────────────────────────────────────┘
```

---

## GRU 的两个核心门控

| 门控      | 符号    | 功能                                                            |
| ------- | ----- | ------------------------------------------------------------- |
| **重置门** | $R_T$ | <span style="color:rgb(255, 77, 77)">控制候选隐藏状态中保留多少历史信息</span> |
| **更新门** | $Z_T$ | <span style="color:rgb(255, 77, 77)">控制最终隐藏状态中历史与候选的占比</span> |

### 共同特点

- 均为 **向量**，与隐藏状态等长
- 经 **sigmoid 激活**，输出 0~1 之间数值
- 实现 **软控制**（连续值，非硬开关）

---

## 重置门（Reset Gate）

### 计算公式

$$R_T = \sigma(W_{XR} X_T + W_{HR} H_{T-1} + b_R)$$

### 功能说明

| $R_T$ 值  | 含义                                                   |
| -------- | ---------------------------------------------------- |
| **接近 0** | <span style="color:rgb(255, 77, 77)">遗忘历史信息</span>   |
| **接近 1** | <span style="color:rgb(255, 77, 77)">完整保留历史信息</span> |
| **中间值**  | 部分保留                                                 |

**作用**：控制候选隐藏状态计算时，<span style="color:rgb(255, 77, 77)">对历史隐藏状态的读取程度</span>。

---

## 候选隐藏状态（Candidate Hidden State）

### 计算公式

$$\tilde{H}_T = \tanh(W_{XH} X_T + R_T \odot (W_{HH} H_{T-1}) + b_H)$$

### 关键要点

- 结合重置门 $R_T$ 对历史状态的控制
- 经 **tanh 激活**生成
- 是<span style="color:rgb(255, 77, 77)">最终隐藏状态的 <b>备选值</b></span>
- $\odot$ 表示逐元素乘法（Hadamard 积）

---

## 更新门（Update Gate）

### 计算公式

$$Z_T = \sigma(W_{XZ} X_T + W_{HZ} H_{T-1} + b_Z)$$

### 功能说明

| $Z_T$ 值  | 含义                                                                           |
| -------- | ---------------------------------------------------------------------------- |
| **接近 1** | <span style="color:rgb(255, 77, 77)">保留历史，忽略当前</span>（$H_T \approx H_{T-1}$） |
| **接近 0** | <span style="color:rgb(255, 77, 77)">采用新信息</span>（$H_T \approx \tilde{H}_T$） |
| **中间值**  | <span style="color:rgb(255, 77, 77)">历史与候选的加权组合</span>                       |

---

## 最终隐藏状态计算

### 核心公式

$$H_T = (1 - Z_T) \odot \tilde{H}_T + Z_T \odot H_{T-1}$$

### 解读

```
最终隐藏状态 = (1 - 更新门) × 候选状态 + 更新门 × 历史状态

当 ZT = 1 时：HT = HT-1        ← 完全保留历史
当 ZT = 0 时：HT = ~HT         ← 完全采用新信息
```

---

## GRU 与普通 RNN 的关系

| 对比项       | 普通 RNN | GRU                                                |
| --------- | ------ | -------------------------------------------------- |
| **参数量**   | 基准     | <span style="color:rgb(255, 77, 77)">约 3 倍</span>  |
| **门控机制**  | 无      | 重置门 + 更新门                                          |
| **长序列处理** | 差      | <span style="color:rgb(255, 77, 77)">优</span>      |
| **灵活性**   | 固定     | <span style="color:rgb(255, 77, 77)">可自适应调整</span> |

### 退化情况

<span style="color:rgb(255, 77, 77)">GRU 在极端情况下可 <b>退化为普通 RNN</b>：</span>
- <span style="color:rgb(195, 117, 255)">当更新门始终接近 0 时</span>
- <span style="color:rgb(195, 117, 255)">能在保留历史与关注当前之间 <b>灵活调整</b><br></span>
---

## 核心总结

| 要点            | 内容                     |
| ------------- | ---------------------- |
| **核心创新**      | 引入门控机制解决长序列问题          |
| **门控数量**      | 2 个（重置门 + 更新门）         |
| **激活函数**      | sigmoid（门控）、tanh（候选状态） |
| **信息控制**      | 软控制（0~1 连续值）           |
| **与 LSTM 对比** | 结构更简单，效果相近             |
| **参数量**       | 约为普通 RNN 的 3 倍         |

---

## 公式汇总

**重置门**：
$$R_T = \sigma(W_{XR} X_T + W_{HR} H_{T-1} + b_R)$$

**更新门**：
$$Z_T = \sigma(W_{XZ} X_T + W_{HZ} H_{T-1} + b_Z)$$

**候选隐藏状态**：
$$\tilde{H}_T = \tanh(W_{XH} X_T + R_T \odot (W_{HH} H_{T-1}) + b_H)$$

**最终隐藏状态**：
$$H_T = (1 - Z_T) \odot \tilde{H}_T + Z_T \odot H_{T-1}$$

---

## 📝 背诵精简版

**GRU 核心要点（5 句话）**：

1. **定位**：GRU 是简化版 LSTM，效果相近，结构更简单
2. **问题**：普通 RNN 无法处理长序列，<span style="color:rgb(195, 117, 255)">信息堆积难提取早期内容</span>
3. **方案**：引入 2 个门控——重置门（控制历史信息读取）、更新门（控制历史/当前占比）
4. **机制**：sigmoid 输出 0~1 软控制，tanh 生成候选状态
5. **公式**：$H_T = (1-Z_T)\odot\tilde{H}_T + Z_T\odot H_{T-1}$（历史与候选的加权组合）
