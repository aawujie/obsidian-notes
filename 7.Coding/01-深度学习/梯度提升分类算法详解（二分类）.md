# 3. 按照主题来梳理

## 3.1 数据集、目标与总体算法轮廓

- 数据集与建模目标：
    - 视频采用一个极小的训练集作为教学示例：三个样本，属性包括“是否喜欢爆米花（likes popcorn）”、“年龄（age）”、“最喜欢的颜色（favorite color）”，目标变量 y 表示是否“喜欢电影 Troll 2（loves Troll 2）”，取值为 0 或 1。两个样本 y=1（喜欢），一个样本 y=0（不喜欢）。
    - 目标是训练一个梯度提升分类器，预测给定 X（每行特征）时某人喜欢 Troll 2 的概率，或者更直接地预测其对数赔率（log-odds）。
- 梯度提升分类算法的总体轮廓（高层次步骤）：
    - 选择一个可微的损失函数 L(y, f(x))，其中 f(x) 在分类问题中通常表示预测的“对数赔率（log-odds）”而非直接概率。这里选定的损失是负对数似然（negative log-likelihood），其本质上是 logistic 回归中的负对数似然，但写成对 log-odds 的函数以便梯度推导。
    - 初始化模型为常数函数 F_0(x)（对所有 x 相同），该常数为使得训练集上损失函数之和最小的 log-odds 值。视频通过对目标损失求导与求解得出初始概率为 2/3（因为训练集里 2 个正例、1 个负例），相应的对数赔率为 log(2/1) ≈ 0.69。这一步与常见实现（用全局初始预测）一致。
    - 对于 m=1,...,M（M 为树的数量）重复：
        - 计算伪残差 r_i,m：这是损失函数对于当前预测 f(x_i) 的负梯度，常写为 -∂L(y_i,f(x_i))/∂f(x_i)。对于该损失，伪残差可以写成 y_i - p_i，其中 p_i 是当前预测的概率（由当前对数赔率 f 转换得到）。因此伪残差表示“观测概率（0 或 1）减去当前预测概率”的差值。
        - 用回归树拟合这些伪残差 r_i,m（以特征 X 为输入），得到叶子划分（terminal regions R_jm）。每个叶子 j 对应一组样本。
        - 对每个叶子 j 计算最佳输出值 gamma_jm，使得将 gamma_jm 加到该叶子所有样本的当前对数赔率上能最小化局部损失（这里使用二阶泰勒展开近似来简化求解，得到 closed-form 的近似解），具体形式为 gamma_jm = sum_i in leaf r_i,m / sum_i in leaf p_i (1 - p_i)。（当做二阶牛顿更新时分子为一阶导和残差，分母为二阶导）
        - 用学习率 nu（视频中记作 0.8 的示例值）逐步更新整体模型：F_m(x) = F_{m-1}(x) + nu * sum_j gamma_jm * 1_{x in R_jm}（对落在多个叶子的情形有累加，但通常每颗树的叶子是互斥的）。
    - 最终输出 F_M(x)，可将其通过 sigmoid 函数转换为概率 p = 1 / (1 + e^{-F_M(x)})，并以阈值（例如 0.5）决定分类标签。
- 教学设计要点与简化说明：
    - 视频之所以用极小数据集并采用 stump（单层树）而非更复杂的多叶树，是为了方便逐项演算、揭示每一步标量计算的细节，但作者注意到在实际应用中，梯度提升通常用更深或带 8–32 叶子的树作为基学习器（base learners）。
    - 整体思想与回归版本相似：先用一个常数模型初始化，然后按负梯度拟合残差，逐步累加树的输出。分类问题的差别在于损失函数的选择与其对数赔率形式，使得导数与二阶导数会出现概率 p（由对数赔率转换）和 p(1-p) 这样的项，从而影响葉子输出 gamma 的具体计算公式。

## 3.2 损失函数选择与从概率到对数赔率（log-odds）的变换（含详细推导）

- 损失的动机与可视化理解：
    - 分类问题（有 y=0 或 y=1）常用的似然是 Bernoulli 模型下的对数似然。视频先以概率轴（纵轴为“喜欢 Troll 2 的概率”）来直观展示：在示例中两点是蓝色（y=1），一点是红色（y=0），而模型以某一预测概率 p（示例 p=0.67）去评估数据的似然。对数似然（log-likelihood）就是对每个观测依照其真实 y 值取 log(p) 或 log(1-p) 并求和： sum_i [ y_i log(p_i) + (1-y_i) log(1-p_i) ]。
    - 为了把“更好拟合对应更小的损失”的设定统一起来，通常使用负对数似然（negative log-likelihood）作为损失： L = - sum_i [ y_i log(p_i) + (1-y_i) log(1-p_i) ]。这样较小的 L 表示较好拟合。
- 从概率 p 到对数赔率 f 的转换：
    - 在梯度提升分类实现中，模型通常直接预测对数赔率（log-odds），记作 f(x)（视频中也记为 gamma 在某些步骤）。对数赔率定义为 log(p / (1-p))。同时，概率 p 可以由 f 通过 sigmoid 函数得到： p = e^{f} / (1 + e^{f}) = 1 / (1 + e^{-f})。
    - 视频中逐步把负对数似然用 f 表示（即把所有以 p 的表达式替换为 f 的形式），以便对 f 求导。关键代换步骤包括：
        - 将 -[ y log p + (1-y) log(1-p) ] 展开并利用对数的性质组合得到 -y log(p) - (1-y) log(1-p) = -y log(p) - log(1-p) + y log(1-p) = -y [log(p) - log(1-p)] - log(1-p)。
        - 注意 log(p) - log(1-p) = log( p / (1-p) )，即对数赔率 f，本质上把第一部分替换成 -y * f。
        - 进一步将 log(1-p) 用 f 的函数表示： 1-p = 1 - e^{f} / (1 + e^{f}) = 1 / (1 + e^{f})，所以 log(1-p) = - log(1 + e^{f})。把这个代入后，负对数似然变为 -y f + log(1 + e^{f})。这是常用的 logistic 损失： L(y,f) = - y f + log(1 + e^{f})。
    - 这一步很关键：它把损失写成 f 的函数（而不是 p），便于对 f 求导，之后把负梯度翻译回概率空间也是直接的。
- 对损失求导（得到伪残差的形式）：
    - 对 L(y,f) = - y f + log(1 + e^{f}) 关于 f 求一阶导，得到 ∂L/∂f = -y + e^{f} / (1 + e^{f})。注意 e^{f} / (1 + e^{f}) 就是 p（当前预测概率），因此一阶导简化为 ∂L/∂f = -y + p = p - y。
    - 伪残差常定义为负梯度： r = - ∂L/∂f = y - p。所以伪残差就是“观测值减去当前预测概率”的差。这也给出了直观含义：如果模型低估了正类（p 过小，y=1），残差为正，树会朝增加概率的方向修正；反之若过高则残差为负。
- 二阶导（必要时用于二阶近似 / Newton 更新）：
    - 对 L 再求一阶导的导数（二阶导），得到 ∂^2 L/∂f^2 = p(1-p)。这是 logistic 损失的标准结果，且在二阶牛顿或二阶泰勒展开的近似中作为分母出现，用以缩放一阶信息。
- 总结损失与导数的关系：
    - 损失（对 f 的函数）： L(y,f) = - y f + log(1 + e^{f})。
    - 一阶导（负梯度即伪残差）： r = y - p。
    - 二阶导： p(1-p)。
    - 这些关系让后续用回归树拟合负梯度并使用一阶/二阶信息来计算叶子输出成为可能与清晰的步骤依据。

## 3.3 初始化常数预测 F_0(x) 的推导与直观

- 为什么需要初始化常数模型：
    - 梯度提升算法需要从某个起点开始。对于回归，这是通常使用训练集标签的平均值；对于分类（使用上面定义的损失），我们需要找到对所有样本都相同的对数赔率 f = gamma，使得训练集的总损失最小。这个常数即 F_0(x)，对所有 x 相同，作为后续树叠加的基线预测。
- 用示例数据计算初始概率与对数赔率（视频演示）：
    - 我们想找到 gamma（即初始对数赔率）使得 sum_i L(y_i, gamma) 最小。将 L(y,gamma) 写为 - y gamma + log(1 + e^{gamma}) 并对 gamma 求导并令其和为 0，得到方程 sum_i ( -y_i + e^{gamma}/(1+e^{gamma}) ) = 0。把 e^{gamma}/(1+e^{gamma}) 记作 p （即常数概率），方程简化为 sum_i ( -y_i + p ) = 0 ⇒ -sum y_i + n p = 0 ⇒ p = (sum y_i)/n。
    - 对应视频示例：有 3 个样本，2 个正例（y=1），1 个负例（y=0），所以 p = 2/3。把 p 换回对数赔率 f = log(p/(1-p)) = log( (2/3) / (1/3) ) = log(2) ≈ 0.693。这就是 F_0(x)。视频将其展示为 F_0(x) = 0.69（约）。
- 直观解释：
    - 这个初始化等价于在只用一个常数预测的情形下，选择让整体负对数似然最小的概率预测，即训练集中正类比例的 log-odds。若训练集正负类比例不平衡，这一步直接把模型的起点放在 class imbalance 的反映上。
- 使用初始化的后续影响：
    - 之后的每一次树拟合都基于当前 F_{m-1}(x) 来计算伪残差并做更新，若 F_0 已经是按训练集总体比例合理初始化，则算法更快收敛且每次树的修正更加有意义。
    - 视频强调了把概率 p 和对数赔率 f 互相转换的重要性：有时用 f 更方便（因为模型直接预测 f），有时用 p 更直观或简化运算（例如伪残差 y-p，二阶导 p(1-p)）。
- 小结：
    - 初始化步骤给出了确定的、可推导的 closed-form 值：初始概率等于训练集正类比例，初始对数赔率等于该概率的 log-odds。这个结果源于对损失求导并设零的基本优化条件。

## 3.4 伪残差计算、用回归树拟合残差（步骤 A 与 B 的细节）

- 伪残差（Pseudo-residuals）计算（步骤 A）：
    - 定义：伪残差 r_i,m = - ∂L(y_i, f(x_i)) / ∂f(x_i) 在当前模型 F_{m-1}(x) 下求得。对 logistic 损失，这等于 y_i - p_i，其中 p_i 是当前预测概率（由 f 转换得到）。
    - 计算流程：
        - 对于每个样本 i，取当前的对数赔率预测 f_i = F_{m-1}(x_i)（初始时 F_0(x) 是常数）。
        - 用 sigmoid 转换计算当前概率 p_i = e^{f_i} / (1 + e^{f_i})。
        - 计算伪残差 r_i = y_i - p_i（观测 - 预测）。视频在示例中逐一给出三个样本的 r 值：例如对于第一个样本，y=1，p=2/3，r = 1 - 2/3 = 1/3 ≈ 0.33；对另外两个类似计算。
    - 含义：伪残差是模型在概率层面的“误差”量度，指示模型应增加或减少对数赔率（或概率）以减小损失。若 r>0 表示需要提升该样本预测的概率，若 r<0 表示需要降低。
- 用回归树拟合残差（步骤 B）：
    - 任务：用给定的特征（likes popcorn、age、favorite color）拟合伪残差值 r_i。也就是说，把残差当作回归目标，用回归树（例如 stump 或更深的树）去拟合。
    - 为什么用回归树：树可以学习哪些特征区域需要增加或减少预测，从而针对不同特征子集给出不同的修正量。梯度提升的每棵树实际上是拟合损失的负梯度（残差），树的叶子给出在该区域应加上的常数修正（gamma）。
    - 叶子（terminal regions R_jm）的定义与命名：拟合完成后，树将训练样本划分到若干互斥的叶子（例如在视频中有两个叶子：R_1,1 和 R_2,1，表示第 1 棵树的第 1 和第 2 个叶子）。每个叶子对应一组样本，后续只使用叶子内的样本来计算该叶子的输出值 gamma。
    - 举例说明与注意事项：
        - 在视频的简化树（因样本极少，采用 stump）中，一个叶子可能只包含一个样本（例如 R_1,1 只包含 X1），另一个叶子包含剩余两个样本（R_2,1 包含 X2 与 X3）。
        - 在实际情形中使用更复杂的树（带多个叶）时，每个叶子通常含有若干样本，计算 gamma 需要聚合叶子内所有样本的残差与二阶信息。
    - 输出：拟合好残差的回归树和每个叶子的样本集合（R_jm），为步骤 C（计算叶子输出）做准备。
- 小结：
    - 伪残差是每次迭代的“目标”，回归树在特征空间上拟合这些目标并划分叶子。结果是每个叶子代表一个“局部”修正方向，后面计算出的 gamma 给出了该叶子应施加在当前对数赔率上的数值修正。

## 3.5 叶子输出 （gamma）的计算：一阶二阶近似与闭式解

- 计算叶子输出的目标：
    - 对于树的第 m 棵的某个叶子 R_jm，需计算一个常数输出 gamma_jm，使得把 gamma_jm 加到该叶子内所有样本的当前对数赔率上后，叶子内样本的总损失最小。形式上就是最小化 sum_{i in leaf} L(y_i, f_{i}^{(old)} + gamma).
    - 直接对该目标按 gamma 求导并解方程是可行的，但在分类损失的情形下代数会变得复杂。视频采用的是对损失的二阶泰勒近似（相当于 Newton-Raphson 的局部二阶近似）来得到近似的闭式解，便于高效计算。
- 二阶泰勒近似的思想：
    - 对于每个样本 i，在当前点 f^{(old)}_i 处将 L(y_i, f) 关于 f 用二阶泰勒展开至二阶项，然后把这些样本的泰勒多项式求和并关于 gamma 求导、解出最小化 gamma。这等价于在叶子内用残差和二阶导信息做一次 Newton 更新的合并。
    - 具体的代数推导（概念性说明）：
        - 单样本的二阶近似： L(y_i, f_i^{old} + gamma) ≈ L(y_i, f_i^{old}) + g_i * gamma + 0.5 * h_i * gamma^2，其中 g_i = ∂L/∂f |*{f_i^{old}}（一阶导），h_i = ∂^2 L/∂f^2 |*{f_i^{old}}（二阶导）。
        - 对叶内样本求和并忽略与 gamma 无关的常数项： sum_i ( g_i * gamma + 0.5 * h_i * gamma^2 ).
        - 对 gamma 求导并令其为 0： sum_i ( g_i ) + gamma * sum_i ( h_i ) = 0 ⇒ gamma = - sum_i g_i / sum_i h_i。注意 g_i = ∂L/∂f = p_i - y_i（等于 -residual），所以 - sum_i g_i = sum_i (y_i - p_i) = sum_i residuals，而 h_i = p_i (1 - p_i)。
        - 因此最终给出叶子输出的近似闭式解为 gamma_jm = sum_{i in leaf} r_i / sum_{i in leaf} p_i (1 - p_i)，其中 r_i = y_i - p_i（残差）且 p_i 是在 f^{old} 时的预测概率。
    - 视频对两种叶子情形（包含一个样本的叶子以及包含两个样本的叶子）分别演示了上述推导，并具体带入了示例数据的数值以得到 gamma 的数值解。例如单样本叶子（R_1,1）得到 gamma = residual / (p(1-p))，插入数值得到 1.5；对于包含两个样本的叶子（R_2,1），gamma 是两个残差之和除以两个样本 p(1-p) 之和，计算后约为 -0.77。
- 直观理解 gamma 的作用：
    - gamma 是一个“局部修正量”：将 gamma 加到叶子中所有样本当前的对数赔率上，等于是对该特征分区的一致性提升或抑制。gamma 的正负与叶子内残差符号相一致（若大多数样本需要上调概率，则 gamma 为正）。
    - 分母 p(1-p) 的存在是因为根据损失的二阶曲率，这个项衡量了损失对 f 的敏感度（越接近 0 或 1 的 p 导致 p(1-p) 较小，对误差的校正步长需要相对更大）。因此该分母起到缩放作用，类似于牛顿步长中的 Hessian。
- 数值稳定性与近似：
    - 使用二阶近似而非直接数值最优化有两个好处：计算闭式解更快且每个叶子只需聚合一阶、二阶信息（sum g_i, sum h_i）；此外，二阶信息提供了“自适应步长”，减少了训练不稳定性。但这是近似，理论上存在误差（视频指出未来可能专门讨论二阶泰勒逼近为何是好的近似）。
- 小结：
    - 叶子输出的核心公式（近似）为 gamma_jm = sum residuals / sum p(1-p)（对叶内所有样本求和）。这个公式将一阶残差信息和二阶曲率信息结合，是分类任务下梯度提升中常见的更新方式（等价于对负梯度做叶子级别的牛顿更新）。

## 3.6 用学习率更新预测、迭代多棵树的流程（步骤 D 与重复过程）

- 用 gamma 更新模型预测（步骤 D）：
    - 更新公式：对于每个样本 x，若其落在第 m 棵树的叶子 j（记为 R_jm），则把对应的叶子输出 gamma_jm 乘以学习率 nu（视频记作 0.8）后加到当前模型预测上： F_m(x) = F_{m-1}(x) + nu * gamma_jm 。更一般地，如果样本可能出现在多个叶（例如集合化的情形或 ensemble 的并列），则对这些叶子的输出求和，但通常每棵树对样本只有一个叶子。
    - 学习率 nu 的作用：缩小每棵树的贡献，使模型每一步更保守，帮助泛化并需要更多的树以达到相同拟合水平。视频示例选了相对大的 nu=0.8（用于教学容易观察效果），但实际常用较小值（如 0.1 或更小）以减缓过拟合并提高泛化。
- 示例更新的逐样本计算（视频演示）：
    - 对于第一棵树（m=1），把 F_0(x)（常数 0.693）加上 nu * gamma_j1（样本所在叶子的 gamma）。举例中，X1 在叶子 1，gamma_1,1=1.5，因此 F_1(X1) = 0.693 + 0.8 * 1.5 = 1.89（对数赔率）。将其转为概率，p ≈ sigmoid(1.89) 得到一个更高的概率，说明模型对该样本的预测强化了。
    - 对 X2 与 X3 相应地使用叶子 2 的 gamma（例如 -0.77）更新，这可能会降低或提高其对数赔率。视频指出对于某些样本更新后预测会更差，但这是为什么需要多棵树的原因：整体学习是累积修正，单棵树可能在一些样本上产生负面影响，但随后的树会继续修正。
- 重复迭代的完整流程：
    - 将 m 增加到 2 再次执行：用 F_1(x) 计算新的 p_i、残差 r_i，拟合回归树以拟合新的残差，计算叶子 gamma，再用学习率更新得到 F_2(x)。
    - 如视频所示，若我们将 M 设为 2（教学简化），最后的模型即 F_2(x)。真实应用中 M 通常为几十到几百甚至更多（例如 100 或更多）。
- 最终预测与概率转换：
    - 对新样本 x* 使用最终模型 F_M(x*) 得到对数赔率，转换为概率 p* = sigmoid(F_M(x*))，再按阈值（例如 0.5）判断分类标签。
    - 在视频示例中，若得到对数赔率对应概率 0.97，则认为该人喜欢 Troll 2（因为 0.97 > 0.5）。
- 实践提示与注意事项（视频含暗示）：
    - 学习率、树的复杂度（叶子数）与树的数量 M 之间存在折中：较小的学习率需更多的树；树更复杂（更多叶）可能更快拟合但更容易过拟合；通常实际实现（如 XGBoost/LightGBM）提供二阶近似与多种正则化手段以控制过拟合。
    - 视频用小数据与 stump（单层树）来说明每一步细节，但在真实场景中会用更大的树（例如 8–32 叶）来捕获更复杂的非线性与交互效应。
- 小结：
    - 更新预测、重复迭代是梯度提升的核心循环：每棵树拟合当前模型的负梯度，叶子输出由一阶、二阶信息给出，学习率控制每棵树的影响，最终累积得到 F_M(x)。虽然单步更新可能局部不完美，但多步累加通常能逐步降低总体损失并提升预测性能。

# 4. 框架 & 心智模型（Framework & Mindset）

- 可抽象出的 framework（步骤化模型）：
    1. 选定合适的可微分损失函数 L(y, f)：对于二分类问题，常用的负对数似然（negative log-likelihood）或 logistic 损失 L(y,f) = -y f + log(1 + e^{f})。选择损失时要考虑其可导性、对概率与对数赔率(f) 的关系以及是否便于计算导数与二阶导数。
    2. 模型以对数赔率 f(x) 为输出：决定模型预测的是对数赔率（log-odds，f）而不是直接概率 p。这样可以直接在实线域上做累加（树的输出是对数赔率的加法部分），并最终通过 sigmoid 将 f 转换为概率 p。
    3. 初始化常数预测 F_0：在训练集上找到使总损失最小的常数 f（通常对应于训练集中正类的比例），即 p_init = mean(y)，F_0 = log(p_init/(1-p_init))。这个初始点是所有后续迭代的基线。
    4. 迭代训练（对 m=1 到 M）：
        - 计算伪残差 r_i = - ∂L/∂f_i = y_i - p_i，其中 p_i = sigmoid(F_{m-1}(x_i))。
        - 用回归树拟合 r_i（把残差当作回归目标），得到树的叶子划分 R_jm。
        - 对每个叶子 j，用叶子内样本的一阶与二阶信息（sum g_i 与 sum h_i，其中 g_i = ∂L/∂f = p_i - y_i，h_i = p_i (1 - p_i)）通过二阶泰勒近似求出最佳近似输出 gamma_jm = - sum g_i / sum h_i = sum residuals / sum p_i(1-p_i)。
        - 更新模型：F_m(x) = F_{m-1}(x) + nu * gamma_jm（若 x 落在叶 j），其中 nu 是学习率（0<nu≤1）。
    5. 终止与预测：迭代到 M 止，或使用验证集早停（early stopping）。对新样本先计算 f = F_M(x)，然后 p = sigmoid(f)，再以阈值给定类别。
- 心智模型（如何理解与直觉化算法）：
    - 负梯度即“方向指示器”：在每一步，损失函数对 f 的负梯度告诉我们在 f 空间应沿哪个方向调整以减少损失。把负梯度当作“残差”去拟合，树学到的就是“哪里需要增加 f、哪里需要减少 f”。
    - 二阶信息作为“自适应步长调节器”：二阶导 h_i = p_i(1-p_i) 衡量损失在 f 方向上的曲率。p 越接近 0 或 1，p(1-p) 越小，代表对 f 的小变化会对概率和损失产生更大的影响，因此分母变小会放大 gamma 的绝对量，这在 Newton 更新中相当于自适应地放大或缩小步长以加速收敛或防止震荡。
    - 将分类问题转化为对数赔率回归的问题：把模型的目标设为预测对数赔率 f 而非直接概率，能让后续的“加法模型”（树的输出按加法累积在 f 上）具有线性可加性与可微的优化空间，从而使得按负梯度拟合树成为合理且直接的方案。
    - 学习率、树深度与迭代次数的三角权衡：理解这三者之间的权衡对实践至关重要。较小的学习率需要更多树来逼近复杂函数，但能提升泛化；更复杂的树每棵能带来更大的拟合能力但易过拟合；较多的树能逐渐逼近更复杂目标但训练与推断代价更高。一个常见心态是把 learning rate 设小、树相对浅并允许更多的树（慢学）来获得更稳定、泛化更好的模型。
    - 局部修正的累积视角：把每棵树看成“局部修正器”而非完整模型。每棵树只在特征空间的某些区域施加有限的修正（由叶子定义），整个模型通过许多小的修正累加来逼近复杂的目标函数。
    - 解释能力与叶子输出：叶子的 gamma 给出该区域应加到对数赔率上的常数修正，从解释角度可以查看哪些组特征被提高或降低概率以及修正的相对强度（通过 gamma 及其乘以学习率的值）。
    - 数学近似背后的稳定性考量：实务中使用的二阶泰勒近似（即用 sum g 和 sum h 形成 gamma 的公式）是对损失在叶子处的局部二次近似，这在多数情形下是稳健且高效的，但它是近似，且在极端概率值（p 接近 0 或 1）或数据稀疏的叶子中可能产生较大的 gamma，因此通常还会配合正则化（如对 sum h 加上常数、限制叶子最小样本数等）以增强稳定性。
- 实战建议（心智模型下的策略）：
    - 先从较浅的树（如 8–32 叶）和较小的学习率（如 0.1 或 0.05）开始，结合早停法在验证集上调优树的数量 M。
    - 关注叶子样本量与稳定性：避免让叶子太小从而导致 gamma 过极端。通常通过 min_child_weight、min_samples_leaf 等参数控制。
    - 使用二阶信息时考虑正则化：在分母上加小正数（如 L2 正则）以避免除以接近零的值。
    - 将残差拟合视作“逐步改进”的过程，而非一次性得到完美模型：接受每棵树可能在某些点上损坏短期预测，但整体趋势应推动损失下降。

# 总结

本视频以一个极小的示例数据集逐步演示了梯度提升用于二分类的完整算法：选择 logistic（负对数似然）损失、把模型输出视为对数赔率 f、初始化常数预测 F_0、在每次迭代中计算伪残差 y-p 并用回归树拟合它们、为每个叶子用二阶泰勒近似得到闭式的 gamma 输出（gamma = sum residuals / sum p(1-p)），并通过学习率逐步更新预测。虽然数学看起来繁琐，但每一步都有明确的直观含义：伪残差指示修正方向，二阶信息提供尺度，树作为局部修正器把这些修正应用到特征空间的不同区域。最终多棵树的累积预测 F_M(x) 可被 sigmoid 转换为概率并用于分类决策。视频强调了理论推导与实务（如使用更复杂树、更多迭代、较小学习率）之间的一致性与差异。
