## 核心原则：看后面接什么，不是看前面

> **`'d + have + 名词` → 一律按 `would have` 理解，说当前的事。**
> **`'d + have + 过去分词` → 唯一涉及过去反事实，说"本该"的事。**

判断依据是 `have` 后面的词性：

```
you'd have time          → have + 名词 → would have = 你会有时间
you'd have called        → have + done  → would have called = 你本该打电话
you'd have a car         → have + 名词 → would have = 你会有辆车
you'd have known         → have + done  → would have known = 你本该知道
```

## 三种 would have 场景

| 场景 | 结构 | 举例 | 判断 |
|:---|:---|:---|:---|
| **1. 礼貌询问（现在）** | would have + 名词 | I was wondering if you **would have time**. | have = 有（实义动词） |
| **2. 虚拟假设（现在/将来）** | would have + 名词 | If I quit my job, I **would have more freedom**. | have = 有（实义动词） |
| **3. 虚拟过去** | would have + 过去分词 | If I had known, I **would have come**. | have = 助动词 |

**场景 1 和 2 跟过去完全无关，说的都是当下。**

## 场景 1：礼貌询问（最常见）

口语里的 `you'd have time` → 展开为 `you would have time`，`have` 是实义动词"有"。

```
I was wondering if you'd have time to hop on a call.
直译：不知道你方不方便抽空打个电话。
```

> 注：语法上 `you'd` 也可展开为 `you had`（had 过去式表客气），但口语里模糊不上心，怎么展开都对。不影响理解。

## 场景 2：虚拟假设

Second conditional，跟过去无关：

```
If I woke up earlier, I would have more time.
如果她申请的话，she would have a better chance.
你写测试的话，you would have fewer bugs.
```

## 场景 3：虚拟过去

Third conditional，唯一跟过去事实相反的情况：

```
If I had known, I would have called.           （当时不知道→所以没打）
If we had left earlier, we would have caught it. （实际没赶上→错过了）
```

### 变体

| 变体 | 含义 | 例句 |
|:---|:---|:---|
| could have done | 有能力但没做 | I could have helped. |
| should have done | 应该做但没做 | You should have told me. |
| might have done | 可能发生了（不确定） | He might have forgotten. |

## 一句话总结

```
名词跟 have → "有"，虚拟现在。
过去分词跟 have → 助动词，虚拟过去。
其他 case 不用管。
```
