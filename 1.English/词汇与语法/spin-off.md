## 核心含义

**spin off** = 分拆 / 剥离

## 词源逻辑

从物理动作引申到抽象概念：

- **spin** = 旋转
- **spin off** = 从主体上旋转着甩出去 → 母公司把业务部门「甩」出来独立成新公司

意象：像陀螺甩出水珠，或车轮甩出泥巴。

## 商业用法

一家公司把某个业务部门或子公司独立出来，成为全新的独立公司。

**典型操作：**
- 母公司把子公司股权分给现有股东
- 新公司单独上市
- 原股东自动获得新公司股份，无需额外掏钱

**经典案例：**
- eBay 分拆 PayPal（2015）
- 通用电气分拆 GE Healthcare（2023）
- 阿里分拆菜鸟、盒马（推进中）

**与其他拆分方式的区别：**

| 操作 | 区别 |
|:---|:---|
| Spin off | 分给现有股东，新公司独立上市 |
| Carve out（IPO） | 卖一部分给公众，母公司可能还控股 |
| Split off | 股东用母公司股票换新公司股票 |
| 直接卖掉 | 卖给第三方，跟原股东无关 |

## 相关短语

| 短语 | 含义 |
|:---|:---|
| Spin out | 也是分拆，强调「甩出来」的动作 |
| Spin up | 启动（转起来），如 spin up a server |
| Spin doctor | 政治公关顾问，把消息「旋转」成对自己有利的叙事 |
| Put a spin on it | 换个角度解读，说得更好听
