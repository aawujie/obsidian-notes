## 第 1 步：购买腾讯云服务器

### 1.1 注册账号

```
访问：https://cloud.tencent.com
   ↓
点击右上角"免费注册"
   ↓
使用微信扫码或手机号注册
   ↓
完成实名认证（需要身份证）
```

### 1.2 选择云服务器

```
控制台 → 云服务器 CVM
   ↓
点击"新建"
   ↓
选择配置：
```

### 1.3 推荐配置

| 项目 | 推荐选择 | 说明 |
|------|----------|------|
| **地域** | 广州/上海 | 离用户近，速度快 |
| **机型** | 标准型 S5 | 性价比高 |
| **CPU** | 2 核 | 起步配置 |

| **系统** | CentOS 7.9 | 稳定，兼容性好 |
| **数据盘** | 50GB SSD | 存储网站文件 |
| **带宽** | 3Mbps | 起步带宽 |
| **购买时长** | 1 年 | 年付有优惠 |

### 1.4 安全组配置

```
防火墙设置：

✅ 放行 443 端口（HTTPS）
✅ 放行 22 端口（SSH）
✅ 放行 3306 端口（MySQL）
```

### 1.5 设置登录密码

```
登录方式：设置密码
   ↓
用户名：root
   ↓

   ↓

```

## 第 2 步：配置服务器

### 2.1 登录服务器

```
腾讯云控制台 → 云服务器
   ↓
找到刚购买的实例
   ↓
点击"登录"
   ↓
选择"标准登录"
   ↓
输入 root 密码
   ↓
进入命令行界面
```

### 2.2 更新系统

```bash
# 更新软件包列表
yum update -y

# 安装必要工具
yum install -y wget curl vim git
```

### 2.3 检查防火墙

```bash
# 查看防火墙状态
systemctl status firewalld

# 如果没运行，启动
systemctl start firewalld
systemctl enable firewalld
```

## 第 3 步：安装宝塔面板（推荐）

### 为什么用宝塔？

```
✅ 图形界面，不用敲命令
✅ 一键安装 WordPress
✅ 可视化管理数据库
✅ 文件管理器
✅ 自动备份
✅ SSL 证书管理
```

### 3.1 安装宝塔

```bash
# 复制宝塔安装命令
yum install -y wget && wget -O install.sh http://download.bt.cn/install/install_6.0.sh && sh install.sh

# 等待安装完成（5-10 分钟）
```

### 3.2 获取面板信息

```
安装完成后会显示：
├─ 外网面板地址：http://服务器 IP:8888/xxxx
├─ 用户名：xxxxx
└─ 密码：xxxxx

⚠️ 复制保存这些信息！
```

### 3.3 登录宝塔面板

```
浏览器访问：http://服务器 IP:8888/xxxx
   ↓
输入用户名和密码
   ↓
首次登录会推荐安装套件
   ↓
选择：
├─ Nginx 1.20
├─ PHP 7.4
├─ MySQL 5.7
├─ phpMyAdmin 5.0
└─ 纯 FTP（可选）
   ↓
点击"一键安装"
   ↓
等待安装完成（10-15 分钟）
```

## 第 4 步：安装 WordPress

### 4.1 添加网站

```
宝塔面板 → 网站 → 添加站点
   ↓
填写：
├─ 域名：your-domain.com（先填服务器 IP）
├─ 数据库：MySQL
├─ 数据库名：wordpress
├─ 用户名：wordpress_user
├─ 密码：设置强密码（记下来！）
└─ PHP 版本：7.4
   ↓
点击"提交"
```

### 4.2 下载 WordPress

```bash
# SSH 登录服务器
ssh root@服务器 IP

# 进入网站目录
cd /www/wwwroot/你的网站目录

# 下载 WordPress
wget https://cn.wordpress.org/latest-zh_CN.zip

# 解压
unzip latest-zh_CN.zip

# 移动文件到网站根目录
mv wordpress/* .
mv wordpress/.htaccess .

# 清理
rm -rf wordpress latest-zh_CN.zip

# 设置权限
chown -R www:www .
chmod -R 755 .
```

### 4.3 访问 WordPress

```
浏览器访问：http://服务器 IP
   ↓
看到 WordPress 安装向导
   ↓
选择语言：简体中文
   ↓
点击"现在就开始"
```

### 4.4 配置数据库

```
数据库名：wordpress
用户名：wordpress_user
密码：刚才设置的密码
数据库主机：localhost
表前缀：wp_（默认）
   ↓
点击"提交"
   ↓
点击"运行安装"
```

### 4.5 设置管理员

```
网站标题：你的商店名称
用户名：admin（或自定义）
密码：设置强密码（记下来！）
电子邮箱：你的邮箱
   ↓
点击"安装 WordPress"
   ↓
✅ WordPress 安装完成！
```

## 第 5 步：迁移本地 WooCommerce 网站

### 5.1 本地导出

```
本地 WordPress 后台 → 插件 → 安装插件
   ↓
搜索：All-in-One WP Migration
   ↓
安装并启用
   ↓
左侧菜单 → All-in-One WP Migration → 导出
   ↓
选择"导出到" → "文件"
   ↓
下载 .wpress 文件
```

### 5.2 服务器安装插件

```
服务器 WordPress 后台 → 插件 → 安装插件
   ↓
搜索：All-in-One WP Migration
   ↓
安装并启用
```

### 5.3 导入网站

```
服务器后台 → All-in-One WP Migration → 导入
   ↓
选择"导入自" → "文件"
   ↓
选择刚才下载的 .wpress 文件
   ↓
等待上传完成（大文件可能需要时间）
   ↓
点击"完成"
   ↓
WordPress 会提示重新保存固定链接
   ↓
后台 → 设置 → 固定链接 → 保存更改
   ↓
✅ 迁移完成！
```

### 5.4 检查迁移

```
检查项目：
├─ 商品是否正常显示
├─ 图片是否正常加载
├─ WooCommerce 设置是否正确
├─ 主题是否启用
└─ 插件是否激活
```

## 第 6 步：配置域名

### 6.1 购买域名

```
推荐：
├─ 腾讯云 DNSPod：https://www.dnspod.cn
├─ 阿里云万网：https://wanwang.aliyun.com
└─ Namecheap：https://www.namecheap.com

价格：¥50-100/年（.com 域名）
```

### 6.2 添加 DNS 记录

```
登录域名管理后台 → DNS 设置
   ↓
添加 A 记录：
├─ 主机记录：@
├─ 记录类型：A
├─ 记录值：服务器 IP 地址
└─ TTL：自动（或 600）
   ↓
添加 www 记录：
├─ 主机记录：www
├─ 记录类型：CNAME
├─ 记录值：your-domain.com
└─ TTL：自动
   ↓
保存设置
```

### 6.3 等待 DNS 生效

```
生效时间：
├─ 国内域名：5-30 分钟
├─ 国际域名：10 分钟 -48 小时
   ↓
测试是否生效：
ping your-domain.com
   ↓
应该显示你的服务器 IP
```

### 6.4 宝塔面板更新域名

```
宝塔面板 → 网站
   ↓
找到你的网站 → 设置
   ↓
域名管理
   ↓
添加域名：
├─ your-domain.com
└─ www.your-domain.com
   ↓
保存
```

### 6.5 WordPress 更新 URL

```
WordPress 后台 → 设置 → 常规
   ↓
修改：
├─ WordPress 地址 (URL)：https://your-domain.com
└─ 站点地址 (URL)：https://your-domain.com
   ↓
保存更改
   ↓
⚠️ 保存后需要重新登录
```

## 第 7 步：配置 SSL 证书

### 方案 A：宝塔自动申请（推荐）

```
宝塔面板 → 网站 → 设置 → SSL
   ↓
选择"Let's Encrypt"
   ↓
填写邮箱
   ↓
勾选域名：
├─ your-domain.com
└─ www.your-domain.com
   ↓
点击"申请"
   ↓
等待申请完成（1-2 分钟）
   ↓
开启"强制 HTTPS"
   ↓
✅ SSL 配置完成！
```

### 方案 B：腾讯云免费 SSL

```
腾讯云控制台 → SSL 证书
   ↓
申请免费证书
   ↓
填写域名
   ↓
验证域名所有权（DNS 验证）
   ↓
下载证书（选择 Nginx）
   ↓
宝塔面板 → 网站 → SSL → 其他证书
   ↓
粘贴证书和密钥
   ↓
保存并开启强制 HTTPS
```

### 检查 SSL

```
浏览器访问：https://your-domain.com
   ↓
应该看到：
├─ 地址栏有锁图标
└─ 显示"https://"
```

## 🔍 故障排查

### 问题 1：网站无法访问

```bash
# 检查服务器状态
ping 服务器 IP

# 检查防火墙
telnet 服务器 IP 80

# 检查 Nginx
systemctl status nginx

# 重启 Nginx
systemctl restart nginx
```

### 问题 2：数据库连接失败

```bash
# 检查 MySQL 状态
systemctl status mysqld

# 重启 MySQL
systemctl restart mysqld

# 检查数据库配置
cat /www/wwwroot/你的网站/wp-config.php
```

### 问题 3：SSL 证书无效

```
宝塔面板 → SSL → 重新申请
   ↓
检查域名解析是否正确
   ↓
清除浏览器缓存
```

### 问题 4：网站速度慢

```
1. 检查带宽使用
2. 启用缓存插件
3. 优化图片
4. 考虑升级带宽
5. 配置 CDN
```
