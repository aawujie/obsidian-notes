# SSH 端口转发用法

> 记录常用的 SSH 端口转发命令和场景
> 整理日期：2026-03-28

---

## 基础概念

SSH 端口转发（Port Forwarding）可以让你通过 SSH 隧道安全地访问远程网络中的服务。

### 三种类型

| 类型 | 命令 | 用途 |
|------|------|------|
| **本地转发** | `-L` | 把远程服务映射到本地端口 |
| **远程转发** | `-R` | 把本地服务暴露到远程端口 |
| **动态转发** | `-D` | SOCKS 代理 |

---

## 常用选项

| 选项 | 含义 |
|------|------|
| `-N` | 不执行远程命令，只建立隧道 |
| `-f` | 后台运行 |
| `-L 本地端口:远程主机:远程端口` | 本地端口转发 |
| `-R 远程端口:本地主机:本地端口` | 远程端口转发 |

---

## 实战场景

### 场景1：访问远程内网路由器

```bash
ssh -N -L 8080:192.168.8.1:443 dr@10.24.99.65
```

- 本地访问：`http://localhost:8080`
- 实际访问的是：`https://192.168.8.1`（远程内网路由器）

### 场景2：同时转发多个端口

```bash
ssh -N \
  -L 8080:192.168.8.1:443 \
  -L 8002:192.168.8.108:8002 \
  dr@10.24.99.65
```

| 本地端口 | 远程目标 | 用途 |
|---------|---------|------|
| 8080 | 192.168.8.1:443 | 路由器管理页面 |
| 8002 | 192.168.8.108:8002 | Marimo 服务 |

访问方式：
- 路由器：`http://localhost:8080`
- Marimo：`http://localhost:8002?access_token=xxx`

### 场景3：后台运行

```bash
ssh -fN -L 8080:192.168.8.1:443 dr@10.24.99.65
```

- `-f`：后台运行，不占用当前终端
- 适合长期保持的隧道

### 场景4：把本地服务暴露到公网

```bash
# 在本地机器执行
ssh -R 8080:localhost:3000 dr@公网服务器
```

- 别人访问 `http://公网服务器:8080`
- 实际访问的是你本地的 `http://localhost:3000`

## 查看和管理隧道

### 查看当前 SSH 连接
```bash
ps aux | grep ssh
ss -tn | grep 8080  # 查看端口监听
```

### 关闭隧道
```bash
# 找到进程并杀死
pkill -f "ssh.*-L 8080"

# 或找到具体 PID
kill <PID>
```

## 常见问题

### Q: 连接后终端卡住？
**A:** 这是正常的，`-N` 表示不执行命令。用 `-f` 后台运行，或新开终端。

### Q: 如何保持连接不中断？
**A:** 在 `~/.ssh/config` 中添加：
```
Host *
    ServerAliveInterval 60
    ServerAliveCountMax 3
```

### Q: 访问被拒绝？
**A:** 检查：
1. SSH 是否成功登录
2. 远程主机和端口是否正确
3. 防火墙是否放行
