# 长短期记忆网络（LSTM）

> 视频学习笔记 | 2026-03-14

---

## 基础定义

**LSTM（Long Short-Term Memory）** 长短期记忆网络：

- **发明时间**：<span style="color:rgb(195, 117, 255)">1990 年代</span>
- **结构特点**：设计复杂，但实际应用广泛
- **历史背景**：<span style="color:rgb(195, 117, 255)">发明者与 Hinton 等深度学习巨头存在学术矛盾</span>
- **地位**：序列建模的经典模型，工业界广泛应用

---

## 核心门控结构

<span style="color:rgb(255, 77, 77)">LSTM 包含<b>三个门控</b>，比 GRU 更多</span>：

| 门控      | 符号    | 功能                                                        |
| ------- | ----- | --------------------------------------------------------- |
| **遗忘门** | $F_T$ | 控制<span style="color:rgb(255, 77, 77)">是否保留上一时刻的记忆</span> |
| **输入门** | $I_T$ | 控制<span style="color:rgb(255, 77, 77)">是否采用当前候选记忆</span>  |
| **输出门** | $O_T$ | 控制<span style="color:rgb(255, 77, 77)">是否输出当前记忆</span>    |

### <span style="color:rgb(195, 117, 255)">门控计算逻辑</span>

与 GRU 的 $Z_T$、$R_T$ 门一致：

$$\text{Gate} = \sigma(W_X X_T + W_H H_{T-1} + b)$$

- 使用 **sigmoid 激活**
- 输出 0~1 之间的值
- 实现软控制

---

## 候选记忆单元

### 新增组件

LSTM 引入<span style="color:rgb(195, 117, 255)"><b>候选记忆单元</b> </span>$\tilde{C}_T$：

$$\tilde{C}_T = \tanh(W_{XC} X_T + W_{HC} H_{T-1} + b_C)$$

### 特点

- 计算方式与传统 RNN 的 $H_T$ 更新逻辑相同
- **未使用门控机制**
- 经 **tanh 激活**，输出范围 -1~1
- 是记忆单元的**候选值**

---

## 双状态结构

LSTM 有**两个状态**，这是与 GRU/RNN 的核心区别：

| 状态                                                        | 符号    | 含义           |
| --------------------------------------------------------- | ----- | ------------ |
| <span style="color:rgb(195, 117, 255)"><b>记忆单元</b></span> | $C_T$ | 长期记忆，存储序列信息  |
| <span style="color:rgb(195, 117, 255)"><b>隐藏状态</b></span> | $H_T$ | 短期输出，用于传递和预测 |

---

## 记忆单元更新

### 核心公式

$$C_T = F_T \odot C_{T-1} + I_T \odot \tilde{C}_T$$

### 解读

```
新记忆 = (遗忘门 × 旧记忆) + (输入门 × 候选记忆)

• 遗忘门 FT 控制保留多少历史记忆
• 输入门 IT 控制采用多少新候选记忆
• 两者相互独立，可分别调节
```

### 门控值含义

| 门控         | 值接近 0                                                | 值接近 1                                              |
| ---------- | ---------------------------------------------------- | -------------------------------------------------- |
| **遗忘门 FT** | <span style="color:rgb(195, 117, 255)">遗忘历史记忆</span> | 保留历史记忆                                             |
| **输入门 IT** | 忽略候选记忆                                               | <span style="color:rgb(255, 77, 77)">采用候选记忆</span> |

---

## 隐藏状态计算

### 核心公式

$$H_T = O_T \odot \tanh(C_T)$$

### 计算步骤

```
1. 对记忆单元 CT 做 tanh 归一化 → 范围 -1 到 1
2. 经输出门 OT 控制 → 决定是否输出
3. 输出为 0 时可重置隐藏状态
```

### 输出门功能

| $O_T$ 值                                                 | 含义         |
| ------------------------------------------------------- | ---------- |
| <span style="color:rgb(255, 77, 77)"><b>接近 0</b></span> | 不输出，隐藏状态重置 |
| <span style="color:rgb(255, 77, 77)"><b>接近 1</b></span> | 完整输出记忆内容   |
| **中间值**                                                 | 部分输出       |

---

## 完整计算流程

```
┌─────────────────────────────────────────────────────┐
│  输入 XT + 上一时刻隐藏状态 HT-1                      │
│                    ↓                                │
│  ┌─────────────────────────────────────────────┐    │
│  │  三个门控计算（sigmoid）                       │    │
│  │  • 遗忘门 FT                                 │    │
│  │  • 输入门 IT                                 │    │
│  │  • 输出门 OT                                 │    │
│  └─────────────────────────────────────────────┘    │
│                    ↓                                │
│  候选记忆单元 ~CT（tanh）                            │
│                    ↓                                │
│  记忆单元更新：CT = FT⊙CT-1 + IT⊙~CT                 │
│                    ↓                                │
│  隐藏状态计算：HT = OT⊙tanh(CT)                      │
│                    ↓                                │
│  输出 OT（用于预测或传递）                           │
└─────────────────────────────────────────────────────┘
```

## LSTM vs GRU 对比

| 对比项 | GRU | LSTM |
|--------|-----|------|
| **门控数量** | 2 个（重置门 + 更新门） | 3 个（遗忘门 + 输入门 + 输出门） |
| **状态数量** | 1 个（隐藏状态） | 2 个（记忆单元 + 隐藏状态） |
| **结构复杂度** | 简单 | 复杂 |
| **参数量** | 较少 | 更多 |
| **计算速度** | 较快 | 较慢 |
| **实际效果** | 与 LSTM 相近 | 与 GRU 相近 |
| **应用场景** | 通用 | 工业界广泛使用 |

### 核心共识

- **功能一致**：都是平衡当前输入与历史状态
- **效果相近**：实际任务中表现差异不大
- **选择建议**：
  - 追求效率 → GRU
  - 工业部署/成熟方案 → LSTM

## 公式汇总

**遗忘门**：
$$F_T = \sigma(W_{XF} X_T + W_{HF} H_{T-1} + b_F)$$

**输入门**：
$$I_T = \sigma(W_{XI} X_T + W_{HI} H_{T-1} + b_I)$$

**输出门**：
$$O_T = \sigma(W_{XO} X_T + W_{HO} H_{T-1} + b_O)$$

**候选记忆单元**：
$$\tilde{C}_T = \tanh(W_{XC} X_T + W_{HC} H_{T-1} + b_C)$$

**记忆单元更新**：
$$C_T = F_T \odot C_{T-1} + I_T \odot \tilde{C}_T$$

**隐藏状态计算**：
$$H_T = O_T \odot \tanh(C_T)$$

## 📝 背诵精简版

**LSTM 核心要点（5 句话）**：

1. **定位**：90 年代发明的经典序列模型，结构复杂但工业界广泛应用
2. **核心结构**：3 个门控（遗忘门 F、输入门 I、输出门 O）+ 2 个状态（记忆 C、隐藏 H）
3. **记忆更新**：$C_T = F_T \odot C_{T-1} + I_T \odot \tilde{C}_T$（遗忘门控历史，输入门控新候选）
4. **隐藏状态**：$H_T = O_T \odot \tanh(C_T)$（输出门控制记忆的输出）
5. **vs GRU**：功能效果一致，LSTM 更复杂参数更多，GRU 更简洁效率更高
