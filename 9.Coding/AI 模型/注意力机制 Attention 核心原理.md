# 注意力机制 Attention 核心原理

> 视频学习笔记 | 2026-03-15 | 从心理学起源到深度学习实现

---

## 🎯 一句话核心

**注意力 = 用 Query（随意线索）有偏向地选择 Key-Value（环境信息）**

---

## 🧠 心理学起源

### 动物本能
复杂环境中 → 关注重点信息 → 忽略次要信息

### 两种线索

| 类型 | 定义 | 例子 | 对应概念 |
|------|------|------|---------|
| **不随意线索** | 被动、下意识关注 | 看到红色咖啡杯（颜色显著） | Key-Value |
| **随意线索** | 主动、有意识关注 | 主动找书阅读 | Query |

> 💡 **核心洞察**：传统网络层（卷积/全连接/池化）只建模不随意线索；注意力机制**首次显式建模随意线索**

---

## 🔑 核心概念映射

```
心理学概念  →  注意力机制  →  作用
─────────────────────────────────────
随意线索    →   Query(Q)   →  查询需求（我想要什么）
环境信息    →   Key(K)     →  索引标识（这是什么）
            →   Value(V)   →  实际内容（具体信息）
```

### 注意力池化（Attention Pooling）

```
普通池化：对所有输入一视同仁
    ↓
注意力池化：根据 Query 有偏向地筛选
    ↓
输出 = Σ(注意力权重 × Value)
```

---

## 📐 计算原理

### 非参数化注意力（统计方法，1960s）

```
1. 计算 Query 与 Key 的距离
2. 用核函数转换为权重
3. 加权求和 Value

权重公式：αᵢ = K(Q, Kᵢ) / Σⱼ K(Q, Kⱼ)
```

**高斯核函数：**
$$ \alpha_i = \frac{\exp(-\frac{(q-k_i)^2}{2\sigma^2})}{\sum_j \exp(-\frac{(q-k_j)^2}{2\sigma^2})} $$

> 经指数映射 + Softmax → 权重∈[0,1] 且和为 1

### 参数化注意力（深度学习，2010s+）

```
加入可学习参数 W，让模型自主学习：
- 哪些维度重要
- 如何计算相似度

注意力分数 = Softmax(Q·K^T / √d)
输出 = 注意力分数 × V
```

## ⚡ 注意力机制 vs 传统网络层

| 特性 | 卷积/全连接/池化 | 注意力机制 |
|------|-----------------|-----------|
| **线索类型** | 仅不随意线索 | 随意 + 不随意 |
| **选择方式** | 固定权重/局部连接 | 动态加权 |
| **全局依赖** | 需要多层堆叠 | 单层捕获 |
| **可解释性** | 低 | 高（可视化权重） |

## 🧠 面试高频问题

**Q1: 注意力机制的核心创新是什么？**
> A: 引入 Query 作为随意线索，实现有偏向的信息选择，而非对所有输入一视同仁。

**Q2: 为什么注意力权重需要 Softmax？**
> A: 
> - 保证权重∈[0,1]
> - 保证权重和为 1（概率分布）
> - 便于梯度反向传播

**Q3: 非参数化 vs 参数化注意力的区别？**
> A: 
> - 非参数：核函数固定（如高斯核），无学习能力
> - 参数化：加入可学习参数 W，模型自适应最优权重计算

**Q4: 注意力机制的计算复杂度？**
> A: $O(n^2)$ —— 需要计算所有 Query-Key 对，这是长序列的主要瓶颈。

**Q5: 如何可视化注意力？**
> A: 绘制注意力权重热力图，横轴 Key、纵轴 Query，颜色深浅表示关注强度。
