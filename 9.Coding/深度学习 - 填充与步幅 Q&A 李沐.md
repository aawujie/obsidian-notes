## 🎯 二、卷积三大超参数重要程度及设置原则

### 三大超参数

| 超参数 | 重要程度 | 设置原则 |
|--------|----------|----------|
| **卷积核大小** | ⭐⭐⭐ 最关键 | 根据任务选择（通常 3×3） |
| **填充** | ⭐ 较次要 | 设为卷积核减一，让输入输出尺寸一致 |
| **步幅** | ⭐⭐ 中等 | 默认 1，需要快速缩小特征图时取 2 |

### 填充设置原则

```
填充一般设为：P = K - 1

目的：让输入输出尺寸一致
好处：仅为计算方便，避免尺寸过快缩小

示例：
3×3 卷积核 → P = 2
5×5 卷积核 → P = 4
```

### 步幅设置原则

```
默认情况：S = 1

使用 S = 2 的场景：
- 控制计算量
- 需要快速缩小特征图

最佳实践：
将步幅为 2 的层均匀插入网络中
避免连续多层 S=2 导致信息丢失过快
```

## 🔢 三、卷积核边长选奇数的原因

### 核心原因：对称填充

```
奇数卷积核（如 3×3）：
┌─────────────┐
│  0  0  0  0  0  │  ← 上填充 1 行
│  0 [1  2  3] 0  │
│  0 [4  5  6] 0  │  ← 中心对称
│  0 [7  8  9] 0  │
│  0  0  0  0  0  │  ← 下填充 1 行
└─────────────┘
填充对称：上下左右各 1 行/列

偶数卷积核（如 2×2）：
┌─────────────┐
│  0  0  0  0  │
│  0 [1  2] 0  │  ← 无法完美中心对称
│  0 [3  4] 0  │
│  0  0  0  0  │
└─────────────┘
填充不对称：上下/左右可能不一致
```

### 实际影响

| 方面 | 说明 |
|------|------|
| **效果差异** | 奇数 vs 偶数卷积核效果相近 |
| **填充对称** | 奇数卷积核填充时上下左右对称 |
| **主流选择** | 3×3 卷积核是绝对主流 |
| **实际原因** | 为了方便，而非效果差异 |

## 📏 四、特征图尺寸并非需每次减半

### 常见误解

```
❌ 误解：卷积层应该每次都让特征图尺寸减半

实际情况：
若输入为 224 的特征图每次减半：

第 1 层：224 → 112
第 2 层：112 → 56
第 3 层：56 → 28
第 4 层：28 → 14
第 5 层：14 → 7
第 6 层：7 → 3  ← 快消失了！

无法搭建深层网络！
```

### 正确做法

```
✅ 绝大部分情况：保持输入输出尺寸不变

使用策略：
- 大部分层：S=1, P 合适 → 尺寸不变
- 少数层：S=2 → 尺寸减半

示例（ResNet 风格）：
Conv1: 224→224 (S=1)
Conv2: 224→224 (S=1)
Conv3: 224→112 (S=2)  ← 仅这里减半
Conv4: 112→112 (S=1)
Conv5: 112→112 (S=1)
Conv6: 112→56 (S=2)   ← 仅这里减半
```

| 原因 | 说明 |
|------|------|
| **架构设计一部分** | 属于神经网络架构设计的固定部分 |
| **效果不敏感** | 对模型最终效果相对不敏感 |
| **经典模型已给出** | 经典网络模型会直接给出设置方式 |
| **无需自行调节** | 直接套用即可 |

### 实际工作流程

```
日常使用：
1. 选择经典网络（如 ResNet、VGG、EfficientNet）
2. 使用预设参数
3. 微调学习率、batch size 等更敏感的超参数
   ↓
无需调节：填充、步幅、卷积核大小
```

## 💻 七、框架中填充和步幅的灵活设置方法

### PyTorch 参数设置

```python
# 方法 1：单个整数（对称填充）
conv = nn.Conv2d(1, 64, kernel_size=3, padding=1)
# padding=1 表示：左右各填 1，上下各填 1

# 方法 2：元组/列表（分别设置）
conv = nn.Conv2d(1, 64, kernel_size=(3, 5), 
                 padding=(1, 2),  # (高度填充，宽度填充)
                 stride=(2, 3))   # (高度步幅，宽度步幅)

# 方法 3：4 元组精细控制（使用 F.pad）
import torch.nn.functional as F
X_padded = F.pad(X, pad=(1, 2, 3, 4))  
# pad=(左，右，上，下)
```

### 框架 vs 讲义表述差异

| 来源 | 表述方式 | 示例 |
|------|----------|------|
| **框架（PyTorch）** | 单侧填充量 | `padding=1` → 左右各 1，上下各 1 |
| **讲义/公式** | 总填充量 | $P_h$ → 上下总共填充 $P_h$ 行 |

**注意**：框架中单个整数的 padding 参数代表左右、上下同时填充对应行数/列数，与讲义中总填充量的表述不同。

## 🔢 八、张量形状必为整数的处理原则

### 核心原则

```
张量的形状代表像素/元素数量
必然是整数！

计算形状时若出现非整数：
→ 通过向上或向下取整来处理
```

### 向下取整示例

```python
# 输出尺寸公式
H_out = floor((H_in + 2P - K) / S) + 1

# 示例：非整数结果
H_in = 10, K = 3, P = 0, S = 2

H_out = (10 + 0 - 3) / 2 + 1
      = 7 / 2 + 1
      = 3.5 + 1
      = 4.5  ← 非整数！

实际处理：
H_out = floor(4.5) = 4  ← 向下取整
```

### PyTorch 行为

```python
import torch
import torch.nn as nn

# 输入 10×10，卷积核 3×3，步幅 2，无填充
conv = nn.Conv2d(1, 1, 3, stride=2, padding=0)
x = torch.randn(1, 1, 10, 10)
y = conv(x)

print(y.shape)  # torch.Size([1, 1, 4, 4])
# 自动向下取整
```

## 👁️ 九、3×3 小卷积核的实际作用原理

### 感受野的线性扩大

```
单个 3×3 卷积核：
感受野 = 3×3  ← 视野很小

多层 3×3 卷积堆叠：

第 1 层：感受野 3×3
第 2 层：感受野 5×5  (3 + 2)
第 3 层：感受野 7×7  (3 + 2 + 2)
第 4 层：感受野 9×9  (3 + 2 + 2 + 2)
...
第 N 层：感受野 (2N+1)×(2N+1)

公式：感受野 = 1 + N × (K - 1)
其中 K=3，N=层数
```

### 小卷积核的优势

| 优势 | 说明 |
|------|------|
| **感受野扩大** | 多层堆叠后单个输出能覆盖整张输入图片 |
| **计算高效** | 3×3 参数量少，运算快 |
| **非线性增强** | 多层带来更多激活函数，表达能力更强 |
| **深层网络** | 配合深层网络实现大视野特征提取 |

### 等效性对比

```
2 层 3×3 卷积 vs 1 层 5×5 卷积：

感受野对比：
2 层 3×3: 感受野 = 5×5
1 层 5×5: 感受野 = 5×5
→ 感受野相同！

参数量对比：
2 层 3×3: 2 × (3×3) = 18 参数
1 层 5×5: 1 × (5×5) = 25 参数
→ 3×3 更省参数！

非线性对比：
2 层 3×3: 2 次 ReLU 激活
1 层 5×5: 1 次 ReLU 激活
→ 3×3 表达能力更强！
```

## 🤖 十、网络结构可通过 NAS 自动搜索训练

### 什么是 NAS？

```
NAS (Neural Architecture Search) = 神经网络架构搜索

让网络参数/结构参与训练，自动找到最优架构
```

### 两种主要方法

| 方法 | 说明 | 特点 |
|------|------|------|
| **离散搜索** | 尝试不同网络结构，筛选最优 | 计算量大，但可并行 |
| **连续优化** | 构建大网络，让模型自动选择路径 | 可梯度优化，效率高 |

### 使用场景

```
✅ 适合使用 NAS：
- 输入数据特殊
- 硬件定制化场景（移动端、边缘设备）
- 追求极致性能

❌ 无需使用 NAS：
- 常规场景
- 标准数据集
- 直接使用经典网络即可
```

## 📊 十一、卷积操作的信息处理本质

### 信息论视角

```
从信息论角度：
卷积乃至整个机器学习 = 极端的压缩算法

过程：
原始像素信息 → 卷积压缩 → 语义特征空间

特点：
- 会丢失原始信息
- 但提取出有意义的语义特征
- 即使输入输出形状相同，也存在信息筛选和压缩
- 并非简单的无损失传递
```

### 信息流动

```
输入层（原始像素）：
- 包含所有细节信息
- 冗余度高
- 语义信息低
    ↓ 卷积压缩
中间层（特征图）：
- 部分信息被过滤
- 提取边缘、纹理等特征
- 语义信息增加
    ↓ 继续压缩
输出层（高级特征）：
- 高度抽象的语义信息
- 原始信息大量丢失
- 但包含分类/检测所需的关键信息
```

## ⚖️ 十三、多层小卷积核与大卷积核的等效性及优势

### 等效性

```
多层 3×3 卷积 ≈ 层数更少的大卷积核

具体等效关系：
2 层 3×3 ≈ 1 层 5×5  （感受野 5×5）
3 层 3×3 ≈ 1 层 7×7  （感受野 7×7）
```

### 小卷积核的优势

| 优势 | 3×3 多层 | 大卷积核 |
|------|----------|----------|
| **参数量** | 少（2 层 3×3 = 18 参数） | 多（1 层 5×5 = 25 参数） |
| **计算速度** | 更快 | 较慢 |
| **非线性** | 更多激活函数 | 较少激活函数 |
| **表达能力** | 更强 | 较弱 |
| **网络深度** | 可构建更深 | 层数受限 |

### GoogLeNet 的核心设计思路

```
GoogLeNet (Inception) 设计理念：

1. 多用小卷积核（3×3, 1×1）
2. 增加网络深度
3. 减少参数量
4. 提高计算效率

成果：
- ImageNet 竞赛冠军
- 参数量仅为 AlexNet 的 1/12
- 精度更高
```

## 🎯 十四、多尺度目标检测的卷积核选择策略

### 不同层次的选择

```
底层（靠近输入）：
- 可选用 5×5、7×7 等稍大的卷积核
- 原因：输入尺寸大，需要较大感受野捕获信息
- 示例：第一层用 7×7 快速降维

上层（靠近输出）：
- 以 3×3 卷积核为主
- 原因：特征图已较小，小卷积核足够
- 优势：计算高效，可堆叠更深
```

### 统一用 3×3 的优势

```
✅ 统一使用 3×3 卷积核：

1. 更易构建深层模型
   - 结构简单，易于堆叠
   - 感受野线性扩大

2. 计算更高效
   - 参数量少
   - 运算速度快

3. 实现更简单
   - 代码统一
   - 调试方便

4. 更易推广使用
   - 简单结构易被接受
   - 复杂结构易用性低
```

### 简单 vs 复杂

```
简单网络结构：
✅ 易被推广使用
✅ 社区支持好
✅ 预训练模型多
❌ 可能在特定数据集效果略差

复杂网络结构：
✅ 可能在特定数据集有好效果
❌ 易用性低难以普及
❌ 社区支持少
❌ 预训练模型少

结论：简单的往往更好用
```

## 🔬 十五、多层卷积的特征提取本质

### 单层 vs 多层

```
单个卷积层：
→ 可匹配图片的一种特定纹理特征
→ 例如：检测垂直边缘

多层不同卷积层：
→ 能够提取图片中多种不同的纹理特征
→ 实现多维度的特征表征
```

### 特征层次

```
第 1 层卷积：
├── 边缘检测（垂直、水平、对角）
├── 颜色对比
└── 简单纹理

第 2-3 层卷积：
├── 角点检测
├── 简单形状（圆形、方形）
└── 纹理组合

第 4+ 层卷积：
├── 物体部件（眼睛、轮子）
├── 复杂形状
└── 语义概念
```

### 多维度特征表征

```
通过多层卷积：
- 每层学习不同的特征
- 多个卷积核并行提取多种特征
- 最终形成丰富的特征表示

示例（64 个卷积核）：
卷积核 1: 检测垂直边缘
卷积核 2: 检测水平边缘
卷积核 3: 检测 45°边缘
...
卷积核 64: 检测特定纹理

输出：64 通道的特征图
→ 64 种不同的特征表示
```

## 💡 十六、深度学习并非"有钱人的游戏"

### 成本对比

```
传统方法成本：
├── 人工特征提取：高（专家时间）
├── 手工调参：高（经验依赖）
└── 数据标注：高（人力密集）

深度学习方法：
├── 算力成本：中高（GPU/TPU）
├── 自动特征提取：低（网络学习）
├── 自动调参：低（优化算法）
└── 数据标注：中（但可半自动）

整体对比：
深度学习实现了总成本下降！
```

### NAS 等高端技术

```
现阶段：
- NAS 等技术成本高
- 不通用
- 属于高端需求

未来趋势：
- 随技术发展降低成本
- 逐渐普及
- 如同其他科技的发展规律

历史类比：
- GPU 曾经昂贵 → 现在普及
- 云计算曾经高端 → 现在平价
- NAS 也将经历类似路径
```

### 核心观点

> 深度学习虽提升了算力成本，但替代了传统方法中高昂的人工特征提取、调参成本和数据标注成本，整体实现了成本下降。

## 📝 总结

### 关键要点速查

| 主题 | 核心结论 |
|------|----------|
| 超参数重要性 | 卷积核大小 > 步幅 > 填充 |
| 填充设置 | P = K-1，保持尺寸一致 |
| 步幅设置 | 默认 1，需要缩小用 2 |
| 卷积核边长 | 选奇数（对称填充），3×3 主流 |
| 特征图尺寸 | 大部分保持不变，偶尔减半 |
| 网络选择 | 优先套用经典网络 |
| 小卷积核 | 多层 3×3 优于大卷积核 |
| NAS/AutoML | 成本高，常规场景无需使用 |
| 深度学习成本 | 整体成本下降，非"有钱人游戏" |

### 实践建议

```
✅ 推荐做法：
1. 使用经典网络（ResNet 等）
2. 统一用 3×3 卷积核
3. 填充保持尺寸一致
4. 步幅默认 1，偶尔用 2 降维
5. 多层堆叠扩大感受野

❌ 避免做法：
1. 自行设计复杂架构（除非必要）
2. 每层都减半特征图尺寸
3. 使用偶数卷积核
4. 过度依赖 AutoML/NAS
```
