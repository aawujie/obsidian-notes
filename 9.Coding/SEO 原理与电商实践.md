## 🎯 什么是 SEO？

**SEO (Search Engine Optimization)** = 搜索引擎优化

> **核心目标**: 让网站在搜索引擎结果页 (SERP) 中获得更高排名，从而获得更多免费流量

---

## 📊 SEO 工作原理

### 搜索引擎的 3 个核心步骤

```
┌─────────────────────────────────────────────────────────┐
│                    搜索引擎工作流程                      │
│                                                         │
│  1️⃣ 爬取 (Crawling)                                     │
│     ───────────────                                     │
│     Googlebot 等爬虫程序                                │
│     ↓                                                   │
│     发现网页、读取内容、跟随链接                         │
│     ↓                                                   │
│     靠 sitemap.xml + 内部链接发现页面                    │
│                                                         │
│  2️⃣ 索引 (Indexing)                                     │
│     ─────────────                                       │
│     分析页面内容                                        │
│     ↓                                                   │
│     理解页面主题、关键词、质量                           │
│     ↓                                                   │
│     存入搜索引擎数据库                                   │
│                                                         │
│  3️⃣ 排名 (Ranking)                                      │
│     ─────────———                                        │
│     用户搜索关键词                                      │
│     ↓                                                   │
│     算法匹配最相关的页面                                 │
│     ↓                                                   │
│     按相关性排序展示                                     │
└─────────────────────────────────────────────────────────┘
```

## 🛒 电商 SEO 特殊性

### 电商网站 vs 普通网站

| 维度 | 普通网站 | 电商网站 |
|------|----------|----------|
| **页面类型** | 文章/介绍页 | 商品页/分类页 |
| **关键词** | 信息类 | 交易类 |
| **转化目标** | 阅读/留资 | 购买 |
| **内容更新** | 低频 | 高频（价格/库存） |
| **重复内容** | 少 | 多（相似商品） |

---


## 🏗️ 电商 SEO 架构设计

### 网站结构优化

```
                    首页 (权重 100%)
                       │
        ┌──────────────┼──────────────┐
        │              │              │
    分类页 1        分类页 2        分类页 3
   (权重 80%)      (权重 80%)      (权重 80%)
        │              │              │
    ┌───┴───┐      ┌───┴───┐      ┌───┴───┐
    │       │      │       │      │       │
  商品 1   商品 2  商品 3   商品 4  商品 5   商品 6
 (权重 60%) (权重 60%) ...
```

**权重传递规则**:
- 首页权重最高
- 每点击一次，权重传递约 80%
- 重要页面距离首页不超过 3 次点击

---

### URL 结构设计

```
✅ 推荐的电商 URL 结构:

首页：https://yoursite.com/
分类页：https://yoursite.com/men/shoes/
商品页：https://yoursite.com/men/shoes/nike-air-max-90

❌ 避免的结构:

首页：https://yoursite.com/index.php
分类页：https://yoursite.com/cat?id=123
商品页：https://yoursite.com/product.php?id=456
```

**最佳实践**:
```
✅ 包含关键词：/men/shoes/nike-air-max-90
✅ 使用连字符：nike-air-max-90 (不是 nike_air_max_90)
✅ 小写字母：避免大小写混淆
✅ 避免参数：?id=123&color=red
✅ 包含分类路径：/分类/子分类/商品
```

## 📝 页面 SEO 元素详解

### 1️⃣ Title 标签（页面标题）

**最重要的 SEO 元素**

```html
<!-- ✅ 好的 Title -->
<title>Nike Air Max 90 运动鞋 | 男士跑步鞋 | Nest Travel</title>

<!-- ❌ 差的 Title -->
<title>商品详情</title>
<title>Nike Air Max 90</title>
<title>首页 - 最好的运动鞋商店</title>
```

**Title 优化公式**:
```
商品名 + 核心属性 + 品牌名 | 站点名
例：Nike Air Max 90 红色运动鞋 男士跑步鞋 | Nest Travel
```

**最佳实践**:
- 长度：50-60 字符（中文 30-40 字）
- 关键词靠前放置
- 每个页面唯一
- 包含品牌名

---

### 2️⃣ Meta Description（页面描述）

**影响点击率，不直接影响排名**

```html
<!-- ✅ 好的 Description -->
<meta name="description" content="Nike Air Max 90 男士跑步鞋，经典气垫设计，舒适缓震。
多色可选，免费配送。立即选购享受 30 天无理由退换。" />

<!-- ❌ 差的 Description -->
<meta name="description" content="这是一款很好的运动鞋，欢迎购买。" />
```

**最佳实践**:
- 长度：150-160 字符
- 包含行动号召 (CTA)
- 突出独特卖点
- 自然包含关键词

---

### 3️⃣ Heading 标签（标题结构）

**内容层次结构**

```html
<!-- ✅ 好的结构 -->
<h1>Nike Air Max 90 男士跑步鞋</h1>
  <h2>产品特点</h2>
    <h3>气垫缓震技术</h3>
    <h3>透气网面设计</h3>
  <h2>尺码指南</h2>
  <h2>用户评价</h2>

<!-- ❌ 差的结构 -->
<h1>欢迎访问我们的商店</h1>
<h3>产品特点</h3>  <!-- 跳过 h2 -->
<h2>尺码指南</h2>  <!-- 顺序错误 -->
```

**最佳实践**:
- 每页一个 `<h1>`
- 按顺序使用 `<h2>`, `<h3>`, `<h4>`
- 包含关键词（自然）
- 描述性、有意义

---

### 4️⃣ 图片优化

**图片 SEO 三要素**

```html
<!-- ✅ 好的图片标签 -->
<img 
  src="/images/nike-air-max-90-red.jpg"
  alt="Nike Air Max 90 男士跑步鞋 红色款侧面图"
  width="800"
  height="600"
  loading="lazy"
/>

<!-- ❌ 差的图片标签 -->
<img src="/img/IMG_1234.jpg" alt="" />
<img src="shoe.jpg" />  <!-- 缺少 alt -->
```

**图片命名规则**:
```
✅ nike-air-max-90-red-side-view.jpg
❌ IMG_1234.jpg
❌ shoe.jpg
❌ nike_air_max_90.jpg (用连字符，不用下划线)
```

---

### 5️⃣ 内部链接

**权重传递 + 用户体验**

```html
<!-- ✅ 好的内部链接 -->
<a href="/men/shoes/nike-air-max-90">Nike Air Max 90 跑步鞋</a>
<a href="/collections/running-shoes">查看全部跑步鞋</a>

<!-- ❌ 差的内部链接 -->
<a href="/product?id=123">点击这里</a>
<a href="/shoes">鞋</a>  <!-- 描述不清晰 -->
```

**内部链接策略**:
- 相关文章/商品推荐
- 面包屑导航
- 分类页互链
- 避免孤立页面

## 🔬 结构化数据 (Schema.org)

### 什么是结构化数据？

> **机器可读的页面内容描述**，帮助搜索引擎更好地理解页面

### 电商必备 Schema 类型

| 类型 | 用途 | 展示效果 |
|------|------|----------|
| **Product** | 商品信息 | 价格、库存、评分 |
| **BreadcrumbList** | 面包屑导航 | 搜索结果中的路径 |
| **Review** | 用户评价 | 星级评分 |
| **Offer** | 商品信息 | 价格、可用性 |
| **Organization** | 公司信息 | 品牌标识 |

---

### Product Schema 示例

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Nike Air Max 90 男士跑步鞋",
  "image": [
    "https://yoursite.com/images/nike-air-max-90-1.jpg",
    "https://yoursite.com/images/nike-air-max-90-2.jpg"
  ],
  "description": "经典气垫设计，舒适缓震...",
  "sku": "NK-AM90-RED-42",
  "brand": {
    "@type": "Brand",
    "name": "Nike"
  },
  "offers": {
    "@type": "Offer",
    "url": "https://yoursite.com/men/shoes/nike-air-max-90",
    "priceCurrency": "CNY",
    "price": "899.00",
    "priceValidUntil": "2026-12-31",
    "availability": "https://schema.org/InStock",
    "itemCondition": "https://schema.org/NewCondition"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.8",
    "reviewCount": "125"
  }
}
```

**展示效果**:
```
Google 搜索结果:
Nike Air Max 90 男士跑步鞋 | Nest Travel
⭐⭐⭐⭐⭐ 4.8 (125 条评价)
¥899.00 · 有货
```

## 📱 移动端 SEO

### 移动端优先索引

> **Google 使用移动版网页进行索引和排名**

### 移动端优化要点

| 优化项 | 说明 |
|--------|------|
| **响应式设计** | 自适应各种屏幕 |
| **触摸友好** | 按钮足够大 (>44px) |
| **字体大小** | 正文至少 16px |
| **视口配置** | `<meta name="viewport">` |
| **避免弹窗** | 不影响内容的插页式广告 |
| **加速移动页面** | AMP (可选) |

## 💡 SEO 常见误区

### ❌ 避免这些错误

| 误区 | 正确做法 |
|------|----------|
| 堆砌关键词 | 自然分布，1-3% 密度 |
| 复制商品描述 | 写原创描述 |
| 忽略移动端 | 移动端优先 |
| 只关注首页 | 所有页面都优化 |
| 期望立竿见影 | SEO 需要 3-6 个月见效 |
| 忽视用户体验 | SEO + UX 并重 |
| 购买外链 | 自然获取高质量外链 |

## 🎯 总结

### SEO 核心公式

```
高排名 = 技术 SEO + 内容质量 + 外部权威 + 用户体验
```

### 电商 SEO 优先级

```
1. 技术 SEO (基础) → 2. 页面 SEO (内容) → 3. 外部 SEO (权威)
```

### 最重要的一点

> **SEO 不是一次性工作，而是持续优化的过程**
