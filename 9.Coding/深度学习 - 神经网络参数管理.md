# 深度学习 - 神经网络参数管理

> 视频学习笔记：深度学习中神经网络的参数访问、初始化及参数共享

## 📌 核心概念

### 单隐藏层 MLP 参数基础访问

以包含两个线性层和 ReLU 激活函数的单隐藏层 MLP 为基础：

- **Sequential 结构**：可看作 Python 列表，能按索引获取网络层
- **state_dict**：提取网络层的权重（weight）和偏置（bias）参数
- **参数类型**：有序字典类型（OrderedDict）

```python
# 示例结构
model = nn.Sequential(
    nn.Linear(input_size, hidden_size),
    nn.ReLU(),
    nn.Linear(hidden_size, output_size)
)
```

---

## 🔍 参数的具体访问与属性查看

### Parameter 类型特性

网络层的参数为 `Parameter` 类型，是可优化的核心模块：

| 属性 | 说明 |
|------|------|
| `.data` | 访问参数本身的值 |
| `.grad` | 访问参数梯度 |

```python
# 访问参数
weight = layer.weight.data
bias = layer.bias.data

# 访问梯度（反向传播前为 None）
gradient = layer.weight.grad
```

**注意**：未进行反向计算时梯度为 `none`，反向传播后可获取梯度元素。

## 🌐 全网参数的批量获取方式

### named_parameters 函数

```python
# 获取整个网络的所有参数
for name, param in model.named_parameters():
    print(f"{name}: {param.shape}")
```

**特点**：
- ✅ 返回参数的字符串名称和对应 Parameter 对象
- ✅ 无参数的层（如 ReLU）不会被提取
- ✅ 可通过参数名称精准获取对应参数的数值

## 🧩 嵌套网络的参数表示与模块化优势

### 定义 block 模块并嵌套构建复杂网络

```python
# 使用 add_module 为模块自定义字符串名称
block.add_module('linear1', nn.Linear(10, 5))
block.add_module('relu1', nn.ReLU())
```

**模块化优势**：
- ✅ 可使用 `add_module` 为模块自定义字符串名称
- ✅ 打印网络能以字符串形式查看嵌套结构
- ✅ 将复杂网络模块化，更方便地进行打印和参数访问
- ❌ 复杂网络直接打印则可读性较差

## 🎯 参数初始化的通用方法

### 自定义初始化函数

```python
def init_weights(m):
    if isinstance(m, nn.Linear):
        nn.init.normal_(m.weight, mean=0, std=0.01)
        nn.init.zeros_(m.bias)

# 应用到网络的所有模块
net.apply(init_weights)
```

**常用初始化方法**（通过 `init` 模块）：
- `normal_` - 正态分布初始化
- `zeros_` - 零值初始化
- `xavier_uniform_` - Xavier 均匀分布
- `xavier_normal_` - Xavier 正态分布

---

## 🎨 不同层的差异化参数初始化

### apply 函数的灵活应用

`apply` 函数可对网络中不同层单独调用，实现差异化初始化：

```python
# 对第一个线性层用 Xavier 初始化
nn.init.xavier_uniform_(net[0].weight)

# 对最后一个线性层用常数初始化
nn.init.constant_(net[-1].weight, 1.0)

# 自定义个性化初始化逻辑
def custom_init(m):
    if isinstance(m, nn.Linear):
        if m.in_features == 128:
            nn.init.kaiming_normal_(m.weight)
        else:
            nn.init.normal_(m.weight)
```

---

## ✏️ 参数的直接修改方式

除了通过初始化函数，还能直接对参数进行操作：

```python
# 给参数整体加一
net.weight.data += 1

# 修改指定位置的参数值
net.weight.data[0, 0] = 999

# 直接赋值
net.bias.data = torch.zeros_like(net.bias.data)
```

## 🔗 网络层的参数共享（参数绑定）实现

### 实现方法

```python
# 先构造需要共享的层
shared_layer = nn.Linear(10, 5)

# 在定义网络时多次使用该层实例
model = nn.Sequential(
    shared_layer,      # 第一次使用
    nn.ReLU(),
    shared_layer       # 第二次使用（参数绑定）
)
```

### 绑定特性

- ✅ 绑定后的层指向同一个 Parameter 实例
- ✅ 修改其中一个层的参数，其他共享层的参数会同步改变
- ✅ 参数更新时也始终保持一致

```python
# 验证参数共享
print(model[0].weight is model[2].weight)  # True
```

## 📝 总结

| 主题 | 关键方法 |
|------|----------|
| 参数访问 | `state_dict`, `.data`, `.grad` |
| 批量获取 | `named_parameters()` |

| 初始化 | `apply()`, `init.normal_`, `init.zeros_` |
| 差异化初始化 | 按层单独调用初始化函数 |
| 直接修改 | 对 `.data` 直接赋值/运算 |
| 参数共享 | 复用同一层实例 |
