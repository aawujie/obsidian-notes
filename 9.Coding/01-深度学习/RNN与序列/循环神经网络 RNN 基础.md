# 循环神经网络（RNN）基础

> 视频学习笔记 | 2026-03-14

---

## 基本定义

**RNN（Recurrent Neural Network）** 循环神经网络：

- **定位**：处理序列数据的神经网络
- **前身**：由浅变量自回归模型简化演变而来
- **核心创新**：引入**隐变量（Hidden Variable）** 存储序列信息

---

## 隐变量概念

| 术语 | 含义 |
|------|------|
| **Hidden Variable** | 现实存在但未观测到的变量 |
| **Latent Variable** | 人为设定用于建模的变量 |
| **深度学习领域** | 二者可通用 |

RNN 中隐变量是**向量形式**，用于存储历史序列信息。

---

## 信息传递逻辑

```
┌─────────────┐
│  HT-1  XT-1 │  ← 上一时刻隐状态 + 输入
│      ↓      │
│     [RNN]   │  ← 计算得到当前隐状态 HT
│      ↓      │
│      OT     │  ← 当前输出
│      ↓      │
│   预测 XT    │  ← 语言模型中用于预测下一词
└─────────────┘
```

**关键关系**：
- 输出 $O_T$ 由当前隐状态 $H_T$ 生成
- 隐状态 $H_T$ 由 $X_{T-1}$ 和 $H_{T-1}$ 计算得到
- 损失函数：对比 $O_T$ 与真实 $X_T$

---

## 核心计算原理

RNN 本质是**带时序信息的 MLP**：

### 隐状态计算

$$H_T = \phi(W_{HX} X_{T-1} + W_{HH} H_{T-1} + b_H)$$

| 符号 | 含义 |
|------|------|
| $W_{HX}$ | 输入到隐状态的权重 |
| $W_{HH}$ | 隐状态到隐状态的权重（**存储时序信息**） |
| $b_H$ | 偏置项 |
| $\phi$ | 激活函数（如 tanh, ReLU） |

### 输出计算

$$O_T = W_{QH} H_T + b_Q$$

## 语言模型评估指标

RNN 用于语言模型时属于**分类任务**：

| 指标 | 公式 | 说明 |
|------|------|------|
| **平均交叉熵** | $\frac{1}{T}\sum_{t=1}^{T} -\log P(x_t \| x_{1:t-1})$ | 衡量预测准确性 |
| **困惑度 (Perplexity)** | $\exp(\text{平均交叉熵})$ | 交叉熵的指数形式 |

**困惑度解读**：
- 数值**越小**，模型预测越精准
- 理想情况：Perplexity = 1（完美预测）

## 训练技巧：梯度剪裁

### 问题背景

RNN 反向传播易出现**梯度爆炸**（Gradient Explosion）

### 解决方案

**梯度剪裁（Gradient Clipping）**：

```
if ||gradient|| > threshold:
    gradient = gradient * (threshold / ||gradient||)
```

- 将梯度向量长度限制在阈值内
- 超阈值则按比例缩放至阈值
- 保障数值稳定性

## 核心总结

| 要点 | 内容 |
|------|------|
| **输出依赖** | 当前输入 + 前序隐变量 |
| **隐变量作用** | 存储历史序列信息 |
| **训练关键** | 需梯度剪裁防止爆炸 |
| **模型定位** | 基础序列处理神经网络 |
| **时序信息** | 由 $W_{HH}$ 权重矩阵存储 |

**隐状态更新**：
$$H_T = \phi(W_{HX} X_{T-1} + W_{HH} H_{T-1} + b_H)$$

**输出预测**：
$$O_T = W_{QH} H_T + b_Q$$

**困惑度**：
$$\text{Perplexity} = \exp\left(\frac{1}{T}\sum_{t=1}^{T} -\log P(x_t \| x_{1:t-1})\right)$$
