# 1Password 密码管理器

## 概述

1Password 是一个流行的**密码管理器**（Password Manager），用于安全存储和管理各类敏感信息。

## 核心功能

| 功能 | 说明 |
|------|------|
| 🔐 **密码存储** | 安全加密存储所有账号密码，只需记住一个主密码 |
| 🔄 **自动填充** | 浏览器/APP 自动填充登录信息 |
| 🎲 **密码生成** | 生成高强度随机密码 |
| 📱 **多端同步** | 手机、电脑、浏览器插件数据同步 |
| 🏢 **团队版** | 企业/团队共享密钥、权限管理 |
| 🗝️ **密钥管理** | 存储 API Keys、数据库凭证、SSH 密钥等 |

## 为什么开发者用它？

1. **不再重复使用密码** - 每个账号都是独立强密码
2. **安全共享** - 团队间共享数据库凭证不用发微信/Slack
3. **集成开发工具** - 像 Cursor 插件，可以直接把密钥注入开发环境
4. **审计日志** - 谁访问了什么密钥，有记录
5. **泄露监控** - 监控暗网，告诉你哪些账号密码已泄露

## 1Password Cursor 插件

### hooks.json 配置

```json
{
  "version": 1,
  "hooks": {
    "beforeShellExecution": [
      {
        "command": "./scripts/validate-mounted-env-files.sh"
      }
    ]
  }
}
```

### 作用

- **拦截 shell 执行** - 每当 Cursor 准备运行 shell 命令时，会先执行这个验证脚本
- **检查环境变量文件** - 验证从 1Password 注入的环境变量文件是否合法、完整、未被篡改
- **防止泄露** - 确保敏感信息在传递给 shell 之前是安全的

## 1Password vs Google 密码管理器

### 详细对比表

| 对比维度 | **1Password** | **Google 密码管理器** |
|----------|---------------|----------------------|
| **平台支持** | 全平台（Win/Mac/Linux/iOS/Android）+ 所有浏览器 | 主要 Chrome/Android，其他浏览器支持有限 |
| **独立应用** | ✅ 有独立 APP，不依赖浏览器 | ❌ 绑定 Chrome 浏览器 |
| **密码生成** | 高级自定义（长度、符号、可读性） | 基础随机生成 |
| **安全密钥** | ✅ 支持 WebAuthn/安全密钥存储 | ⚠️ 有限支持 |
| **双重验证** | ✅ 内置 2FA 生成器（TOTP） | ❌ 需单独 APP |
| **安全共享** | ✅ 团队/家庭共享，细粒度权限 | ⚠️ 仅家庭组，功能简单 |
| **隐私保护** | ✅ 零知识架构，公司也无法查看 | ⚠️ Google 可访问（用于安全检查） |
| **泄露监控** | ✅ Watchtower 实时监控 | ✅ 基础泄露提醒 |
| **离线访问** | ✅ 本地加密存储，可离线使用 | ⚠️ 依赖 Google 账号同步 |
| **导入导出** | ✅ 支持多种格式，完整导出 | ⚠️ 导出功能有限 |
| **旅行模式** | ✅ 隐藏敏感保险库过海关 | ❌ 无 |
| **价格** | 💰 付费（~$3/月） | 🆓 免费 |

### 🔐 核心区别

#### 1. 隐私模型

| 1Password | Google |
|-----------|--------|
| **零知识加密** - 你的主密码只有你知道，公司也无法解密 | **Google 可访问** - 用于安全检查、自动填充等 |
| 数据加密后存储，服务端看不到明文 | Google 可以扫描密码是否泄露 |

#### 2. 跨平台体验

**1Password:**
```
iPhone ←→ Mac ←→ Windows ←→ Linux ←→ Android
   ↓        ↓         ↓          ↓         ↓
所有浏览器（Safari/Chrome/Firefox/Edge/Brave...）
```

**Google:**
```
Chrome 浏览器生态内体验好
非 Chrome 浏览器 → 功能受限/无法使用
```

#### 3. 团队/家庭功能

**1Password:**
- 家庭版：5 人共享，独立保险库 + 共享保险库
- 团队版：权限分级、审计日志、onboarding/offboarding
- 安全共享：可以分享单个账号，不暴露密码

**Google:**
- 家庭组：简单共享
- 无企业级功能

## 如何选择？

### ✅ 选 Google 密码管理器，如果：
- 只用 Chrome + Android
- 不想花钱
- 需求简单（存密码 + 自动填充）
- 信任 Google 生态

### ✅ 选 1Password，如果：
- 多平台混用（Mac + Windows + iPhone + Android）
- 用多个浏览器
- 需要团队/家庭共享
- 重视隐私（零知识加密）
- 需要存储更多敏感信息（API Keys、SSH 密钥、护照号等）
- 想要内置 2FA 生成器（少装一个 APP）

> **一句话总结**  
> **Google 密码管理器** = 免费、够用、绑定 Chrome 生态  
> **1Password** = 付费、专业、独立、全平台、隐私优先

- 只用 Safari 浏览器
- 需求简单（存密码 + 自动填充）
- 不想额外花钱
- 信任 Apple 生态

### ✅ 选 Google 密码管理器，如果：
- 只用 Chrome + Android
- 不想花钱
- 需求简单（存密码 + 自动填充）
- 信任 Google 生态

### ✅ 选 1Password，如果：
- 有 Windows/Android 设备（或未来可能用）
- 用多个浏览器（Chrome/Firefox/Edge...）
- 需要内置 2FA 生成器
- 需要存储更多类型敏感信息（SSH 密钥、数据库凭证等）
- 需要团队/家庭共享功能

## 安全建议

- ✅ 使用强主密码（12+ 字符，含大小写、数字、符号）
- ✅ 开启双重验证（2FA）
- ✅ 定期导出备份
- ✅ 团队版设置合理的权限分级
- ✅ 监控安全警报（密码泄露、弱密码等）
