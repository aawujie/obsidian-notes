# 新增车型适配指南

#HIL #onboarding #guide #车型适配

> 本文档记录在 `software_in_loop` 仓库中新增一个车型支持时，需要改动的所有文件和步骤。
> 每步均以真实车型 **B26A1**（GWM ThorU 平台，复用 DE09 系列）为例说明。

## 前置条件

在开始适配前，需要准备好：

1. **DBC 文件**: 新车型的 CAN/FlexRay 通信矩阵定义
2. **vehicle-config 包**: 新车型的 vehicle-config deb 包（已发布到 apt.deeproute.cn）
3. **sim-orin-tools 包**: 对应平台的 sim-orin-tools deb 包
4. **车辆参数**: 整备质量 (`vehicle_mass`)、轮胎半径 (`wheel_radius`)
5. **域控连接信息**: hostname、IP、用户名、密码/密钥

## 第一步：确定车型所属系列

首先判断新车型属于哪个 **品牌/平台系列**：

| 品牌 | 底盘仿真器 | 平台标识 | 代表车型 |
|---|---|---|---|
| GWM (长城) | `GwmSimulatorFactory` | `ORINX_60120` / `GWM_ORINY_60120` / `GWM_THORU_7002` | C01, P03, DE09 |
| Geely (吉利/银河) | `GlSimulatorFactory` | `YINHE_ALL_ORINY` | P177, P789 |
| Smart | `GwmSimulatorFactory` | `SMART_ORINX` | HY11, HY11P |
| LeapMotor (零跑) | `LpSimulatorFactory` | `QNX_QUALCOMM_8650` / `QNX_QUALCOMM_8790` | LPA10, LPD19A |

然后确定 **可复用的基准车型**：

- 如果新车型与 DE09 共用同一套 DBC → 复用 DE09 系列配置
- 如果新车型有全新 DBC → 需要新建数据目录和枚举文件

> **B26A1 实例**：B26A1 属于 GWM 品牌，使用 GWM_ORINY_60120 平台（OrinY），DBC 与 DE09 共用。

## 第二步：配置层改动

### 2.1 `config/vehicle_integration.jsonnet`

这是 **最核心的车型配置文件**，定义了每个车型的所有运行参数。

**情况 A：复用已有车型**（最常见）

> **B26A1 实例**：直接引用 DE09 的配置，一行即可：

```jsonnet
B26A1: self.DE09,
```

实际代码位于 `config/vehicle_integration.jsonnet` 第 239 行。

**情况 B：需要自定义部分参数**

如 P03 在 DE09 基础上覆盖了网卡名：

```jsonnet
P03: self.DE09 {
  ETH_NAME: 'mgbe2_0',
},
```

**情况 C：全新配置**

参考已有车型段落（如 HY11），完整填写所有字段。

### 2.2 `config/packages.json`

在 `vehicle_config` 段新增车型的 deb 包下载链接。

> **B26A1 实例**：

```json
"B26A1": "https://apt.deeproute.cn/repository/deeproute-release-2004/pool/d/deeproute-vehicle-config-yr-b26a1-1-dev/deeproute-vehicle-config-yr-b26a1-1-dev_1.0.13_all.deb"
```

## 第三步：底盘仿真层改动

### 3.1 底盘仿真器 JSON 配置

根据车型所属系列，编辑对应的 JSON 配置文件：

| 系列 | 配置文件路径 |
|---|---|
| GWM | `src/chassis/simulator/gwm/config/gwm_vehicle_config.json` |
| Geely | `src/chassis/simulator/gl/config/gl_vehicle_config.json` |
| LeapMotor | `src/chassis/simulator/lp/config/lp_vehicle_config.json` |

需要添加 3 处：

> **B26A1 实例**（在 `gwm_vehicle_config.json` 中）：

**① vehicle_mappings** — 车型到数据家族的映射：

```json
"B26A1": "DE09"
```

**② vehicle_processor_mappings** — 动力学处理器映射：

```json
"B26A1": "DE09ModelBridgeProcessor"
```

> 选择处理器：`P03ModelBridgeProcessor`（分体控制）或 `DE09ModelBridgeProcessor`（一体控制）。B26A1 使用一体控制。

**③ vehicle_param** — 车辆物理参数：

```json
"B26A1": {
  "vehicle_mass": 2400.0,
  "wheel_radius": 0.383
}
```

## 第四步：工具层改动

### 4.1 `tools/driver/car_config.py` — CAR_PLATFORM_MAP

在 `CarConfigManager.CAR_PLATFORM_MAP` 中，将新车型添加到对应平台列表。

> **B26A1 实例**：添加到 `GWM_ORINY_60120` 平台：

```python
"GWM_ORINY_60120": [
    "P03", "P03A", "P02", "P02A", "EC15", "EC15S",
    "B26A1",  # ← 新增
    "C061",
],
```

### 4.2 `src/utility/dcu_connect_config_factory.cpp` — DCU 连接配置

在 `car_type_to_config_` 静态初始化列表中添加。

> **B26A1 实例**：使用 Tank 系列的默认密码配置：

```cpp
{"B26A1", DCUConnectConfigFactory::GetInstance().GetTankSeriesConfig()},
```

选择匹配的 `Get*Config()` 方法：

| 方法 | 适用系列 | 默认密码 |
|---|---|---|
| `GetGWMOrinXConfig()` | GWM OrinX（C01） | `W8k3L2@m;` |
| `GetTankSeriesConfig()` | GWM Tank（P03, B26A1 等） | `#7F7d8or` |
| `GetThoruSeriesConfig()` | GWM ThorU（DE09, C01T） | `G7#kL2@m` |
| `GetYinheSeriesConfig()` | Geely 银河（P177 等） | `5mcGMs4n8M` |
| `GetSmartSeriesConfig()` | Smart（HY11） | `nvidia` |
| `GetLeapMotorASeriesConfig()` | 零跑 A 系列（LPA10） | 密钥认证 |
| `GetLeapMotorDSeriesConfig()` | 零跑 D 系列（LPD19A） | 密钥认证 |

### 4.3 `src/utility/carplus_config.h` — CarType 枚举

**如果新车型可复用已有 CarType**（如 DE09）→ 无需修改。

> **B26A1 实例**：复用 `CarType::DE09`，不修改此文件。

**如果是全新信号定义** → 需要新增枚举值：

```cpp
enum class CarType { C01, HY11, P03, P177, DE09, HY11P, LPA10, LPD19A, XXX };
```

### 4.4 `src/utility/carplus_config.cpp` — DBC 通道名映射

**如果复用已有 CarType** → 无需修改。

> **B26A1 实例**：复用 `CarType::DE09`，不修改此文件。
> DE09 的 DBC 通道为：`ADAS1`（底盘）、`ADAS2`（左右毫米波）、`SUB`（前毫米波）、`PDC`（超声波）。

### 关键观察

1. **B26A1 的改动分布在 20+ 个文件中**，但每个文件只添加了 1-3 行
2. 由于复用 DE09 的 DBC，`carplus_config.h/cpp` 完全不用动
3. **最容易遗漏的地方**：`src/server/sim-*/main.cc` 的 4 个传感器服务和 `pipeline/scripts/hil_gui` 的启动脚本
4. 改动模式高度一致：绝大多数是在 `if/else if` 链或字符串列表中追加车型名
