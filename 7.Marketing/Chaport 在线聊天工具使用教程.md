## 📌 什么是 Chaport？

**Chaport** = 全渠道客户消息平台（Live Chat Software）

一个**网站在线客服系统**，支持实时聊天、聊天机器人、多渠道集成等功能。

> **核心优势**：简单易用，功能全面，适合中小企业快速部署客服系统。

## 🚀 快速开始（5 分钟上线）

### Step 1: 注册账号

```
1. 访问官网：https://www.chaport.com
2. 点击 "Try Free" 或 "Get Started"
3. 填写信息：
   ├── 邮箱地址
   ├── 密码
   ├── 公司名称
   └── 网站地址
4. 验证邮箱 → 登录后台
```

**免费计划**：
- ✅ 永久免费
- ✅ 最多 3 个客服账号
- ✅ 无限聊天
- ❌ 部分高级功能受限

---

### Step 2: 添加网站聊天窗口

```
1. 登录 Chaport 后台
2. 进入 Settings → Installation
3. 复制安装代码（JavaScript）

示例代码：
<script type="text/javascript">
  window.chaport = window.chaport || {};
  window.chaport.appId = 'YOUR_APP_ID';
  
  (function() {
    var s = document.createElement('script');
    s.type = 'text/javascript';
    s.async = true;
    s.src = 'https://app.chaport.com/javascripts/insert.js';
    var x = document.getElementsByTagName('script')[0];
    x.parentNode.insertBefore(s, x);
  })();
</script>

4. 粘贴到网站 <head> 或 <body> 标签内
5. 保存 → 刷新网站 → 看到聊天窗口
```

## 🛠️ 核心功能配置

### 1️⃣ 在线聊天设置

```
后台 → Live Chat → Settings

基础配置：
├── 自动邀请 (Auto-invitations)
│   ├── 触发条件：访客停留时间/访问页面数
│   ├── 邀请消息：自定义欢迎语
│   └── 排除页面：不触发邀请的页面
│
├── 工作时间 (Working Hours)
│   ├── 设置时区
│   ├── 工作日时间（如 9:00-18:00）
│   └── 离线时显示留言表单
│
├── 快捷回复 (Saved Replies)
│   ├── 创建常用回复模板
│   ├── 使用快捷键快速发送
│   └── 支持变量（如 {customer_name}）
│
└── 文件传输
    ├── 允许/禁止文件上传
    ├── 文件大小限制
    └── 支持的文件类型
```

**快捷回复示例**：

```

非工作时间请留言，我们会尽快回复您！
```

### 2️⃣ 聊天机器人配置

```
后台 → Chatbots → Create Bot

机器人类型：
├── FAQ 机器人（自动回答常见问题）
├── 线索收集机器人（获取客户信息）
├── 预约机器人（安排会议/演示）
└── 反馈机器人（收集客户评价）

配置步骤：
1. 选择机器人类型
2. 设置触发条件（关键词/页面/时间）
3. 编写对话流程
4. 配置转人工规则
5. 测试 → 启用
```

**FAQ 机器人示例**：

```
问题：价格
回答：我们的定价如下...
       需要了解更多吗？
       [是] [否]

问题：工作时间
回答：我们的工作时间为周一至周五 9:00-18:00
       现在是非工作时间，您可以留言...

问题：退换货
回答：我们支持 30 天无理由退换货
       详情查看：[退换货政策链接]
       
无法回答时：
→ 转接人工客服
→ 或请客户留言
```

## ⚠️ 注意事项

### 1. 隐私合规

```
需要配置：
├── 隐私政策链接（聊天窗口）
├── Cookie 同意提示
├── 数据存储位置（GDPR 合规）
└── 客户数据导出/删除功能

建议：
✅ 在聊天窗口添加隐私声明
✅ 获取客户同意后再收集信息
✅ 定期导出备份聊天记录
```

### 2. 客服培训

```
培训内容：
├── 快捷回复使用
├── 转接流程
├── 离线处理
├── 敏感问题应对
└── 系统操作培训

最佳实践：
✅ 制定标准回复模板
✅ 设置响应时间要求（如<2 分钟）
✅ 定期查看聊天记录质检
✅ 收集客户反馈改进服务
```

### 3. 性能优化

```
网站加载优化：
├── 聊天脚本异步加载
├── 延迟加载（用户滚动后）
├── 排除特定页面（如结账页）
└── 移动端单独配置

建议配置：
<script>
  // 延迟 3 秒加载，避免影响首屏
  setTimeout(function() {
    // Chaport 代码
  }, 3000);
</script>
```

## 🎯 最佳实践

### 提高转化率技巧

```
1. 主动邀请
   - 访客停留 30 秒后弹出
   - 访问定价页时主动询问
   - 购物车放弃时介入

2. 个性化问候
   - 使用客户姓名
   - 根据来源页面定制问候
   - 显示客服真实头像

3. 快速响应
   - 设置响应时间目标（<2 分钟）
   - 使用快捷回复
   - 移动端推送通知

4. 跟进策略
   - 未回复对话 24 小时内跟进
   - 离线消息邮件回复
   - 重要线索标记追踪
```

### 聊天机器人优化

```
1. 明确机器人身份
   "您好，我是智能助手，可以帮您解答常见问题..."

2. 提供转人工选项
   每个对话节点都要有"转人工"选项

3. 持续优化话术
   定期查看机器人对话记录，优化回答

4. 设置合理预期
   明确告知机器人能力范围
```
