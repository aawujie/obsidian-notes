# 深度学习公式直觉速通指南

> **目标：** 用 20 分钟建立对全书数学的整体认知，之后读到任何公式都不慌。

---

## 核心洞察：全书只有 5 个数学动作

整本书看起来有上百个公式，但本质上翻来覆去就是 **5 个基本动作** 的排列组合。一旦你认出它们，所有公式都是纸老虎。

```
┌─────────────────────────────────────────────────┐
│                 深度学习的 5 个数学动作             │
├─────────────────────────────────────────────────┤
│  ① 加权求和    →  所有"层"的本质                   │
│  ② 非线性变换  →  让模型能拟合复杂函数               │
│  ③ 概率归一化  →  把数字变成"概率"                  │
│  ④ 算损失      →  衡量"预测有多差"                  │
│  ⑤ 梯度更新    →  "往好的方向调一调"                │
└─────────────────────────────────────────────────┘
```

### 动作 ① 加权求和 —— 出现频率最高

$$y = \sum_i w_i x_i + b = \mathbf{w}^\top \mathbf{x} + b$$

**你会在这些地方反复遇到它：**
- 线性回归、全连接层 → $\mathbf{W}\mathbf{x} + \mathbf{b}$
- 卷积层 → 只是在局部做加权求和
- 注意力机制 → $\sum_i \alpha_i \mathbf{v}_i$（值的加权平均）
- RNN → $\mathbf{W}_{xh}\mathbf{x}_t + \mathbf{W}_{hh}\mathbf{h}_{t-1}$（输入+记忆的加权和）

**读书心法：** 看到一大串求和号 $\sum$，别慌——它就是在做加权平均。问自己：**谁是权重，谁是被加权的对象？**

---

### 动作 ② 非线性变换 —— 就那么几个函数

| 函数 | 长什么样 | 一句话 |
|------|---------|--------|
| ReLU | $\max(0, x)$ | 负数归零 |
| Sigmoid | $\frac{1}{1+e^{-x}}$ | 压到 (0,1) |
| Tanh | $\frac{e^x - e^{-x}}{e^x + e^{-x}}$ | 压到 (-1,1) |

**读书心法：** 看到 $\sigma(\cdot)$、$\phi(\cdot)$、$\tanh(\cdot)$ → 就是"过一遍激活函数"，跳过细节继续读。

---

### 动作 ③ 概率归一化 —— Softmax 一招鲜

$$\hat{y}_j = \frac{\exp(o_j)}{\sum_k \exp(o_k)}$$

**一句话：** 把任意实数变成概率分布（非负，和为 1）。

**你会在这些地方反复遇到它：**
- 分类输出 → softmax 后得到各类概率
- 注意力权重 → softmax 把评分变成权重
- 语言模型 → 预测下一个词的概率

---

### 动作 ④ 算损失 —— 就两种核心 Loss

| 场景 | 损失函数 | 本质 |
|------|---------|------|
| 回归 | $\frac{1}{2}(\hat{y} - y)^2$ | 差多少，平方一下 |
| 分类 | $-\log \hat{y}_\text{正确类}$ | 对正确类的预测概率取负对数 |

**读书心法：** 看到 $-\log(\cdot)$ → 交叉熵损失。看到 $(\hat{y} - y)^2$ → 均方误差。其他变种都是在这两者上微调。

---

### 动作 ⑤ 梯度更新 —— 万变不离其宗

$$\theta \leftarrow \theta - \eta \cdot \text{某种梯度}$$

**全书所有优化器都是这个模板：**

| 算法 | "某种梯度"具体是什么 |
|------|-------------------|
| SGD | 直接用 $\nabla L$ |
| 动量法 | 过去梯度的加权平均 |
| AdaGrad/RMSProp | 按维度缩放后的梯度 |
| Adam | 动量 + 自适应缩放 |

**读书心法：** 第 11 章整章就在讲"怎么计算这个'某种梯度'"。知道了这个框架，每个优化器只需关注它的独特之处。

---

## 全书公式的"故事线"

把全书公式串成一条故事线，你会发现它有清晰的递进逻辑：

```
第 2 章：数学工具箱（向量、矩阵、求导、概率）
    │
    ▼
第 3 章：最简单的模型——一层加权求和
    │  y = wx + b → softmax → 交叉熵
    │
    ▼
第 4 章：多层叠加 + 非线性 = MLP
    │  加上 ReLU/Sigmoid，就能拟合非线性了
    │  顺带学反向传播（链式法则的应用）
    │
    ▼
第 6-7 章：加权求和的空间版 = CNN
    │  全连接太浪费 → 局部加权求和（卷积）
    │  + BN（标准化中间层）+ ResNet（捷径连接）
    │
    ▼
第 8-9 章：加权求和的时间版 = RNN
    │  h_t = f(x_t, h_{t-1})  ← 核心就这一句
    │  GRU/LSTM = 加了"门"的 RNN（门也是 sigmoid + 逐元素乘）
    │
    ▼
第 10 章：加权求和的注意力版 = Attention
    │  Attention(Q,K,V) = softmax(QK^T/√d) V
    │  Transformer = 自注意力 + FFN + 残差 + 层归一化
    │
    ▼
第 11 章：怎么更好地做 θ ← θ - η·梯度
    │  从 SGD → 动量 → AdaGrad → Adam 的进化
    │
    ▼
第 13-14 章：以上工具的应用
    目标检测（IoU, 锚框）、词向量（word2vec, GloVe）
```

## 六个"读公式"的实战技巧

### 技巧 1：先看输入输出，跳过中间

任何公式，先问：
- **输入是什么？**（$\mathbf{x}$? 图片? 词序列?）
- **输出是什么？**（概率? 下一个隐状态? 损失值?）

中间的数学操作可以之后再细看。

### 技巧 2：用"维度分析"检验理解

看到矩阵公式，追踪维度：
```
X: (n×d)  ×  W: (d×h)  +  b: (1×h)  =  H: (n×h)
```
如果维度能对上，你就基本理解了这个公式在做什么。

### 技巧 3：遇到 $\sum$ 想"加权平均"

90% 的求和都是在做某种形式的加权平均。问自己：
- **权重是谁？** → $w_i$? $\alpha_i$? $\frac{1}{n}$?
- **被平均的是谁？** → $x_i$? $y_i$? $\mathbf{v}_i$?

### 技巧 4：遇到门控机制想"开关"

GRU/LSTM 公式看着吓人，但每个门 = sigmoid × 某个值：
```
sigmoid 输出 ≈ 1  → 开关打开，信息通过
sigmoid 输出 ≈ 0  → 开关关闭，信息被屏蔽
```

### 技巧 5：遇到新符号查"符号速查表"

别因为一个不认识的符号卡住。先翻 `数学符号速查表.md`：
- $\odot$ = 逐元素乘
- $\|\cdot\|$ = 范数（长度）
- $\nabla$ = 梯度
- $\hat{y}$ = 预测值
- $\mathbf{W}^{(l)}$ = 第 $l$ 层权重

### 技巧 6：关注"变体"相对于"基础版"改了什么

| 基础版 | 变体 | 变了什么 |
|--------|------|---------|
| 全连接 | 卷积 | 加权和从"全局"变"局部" |
| RNN | GRU | 多了重置门和更新门 |
| GRU | LSTM | 再多一个输出门 + 独立记忆单元 |
| SGD | 动量 | 梯度从"当前"变"历史平均" |
| AdaGrad | RMSProp | 梯度平方从"累积"变"指数平均" |
| RMSProp | Adam | 同时用动量和自适应缩放 |
| 注意力 | 多头注意力 | 做 $h$ 次注意力再拼接 |
| 注意力 | 自注意力 | Q=K=V 都来自同一序列 |

## 一页纸"公式全景图"

```
         ┌──────────────────────────────────────────────┐
         │        y = f(Wx + b)  ← 全书的原子操作         │
         └──────────┬───────────────────────┬───────────┘
                    │                       │
         ┌──────────▼──────────┐   ┌────────▼────────────┐
         │  空间上做 → CNN      │   │  时间上做 → RNN      │
         │  局部滑窗加权求和    │   │  h_t = f(x_t, h_{t-1})│
         └──────────┬──────────┘   └────────┬────────────┘
                    │                       │
                    └───────────┬───────────┘
                                │
                    ┌───────────▼───────────┐
                    │  动态加权 → Attention   │
                    │  α = softmax(QK^T/√d)  │
                    │  output = αV           │
                    └───────────┬───────────┘
                                │
                    ┌───────────▼───────────┐
                    │  Transformer           │
                    │  = 自注意力 + FFN       │
                    │  + 残差 + LayerNorm    │
                    └───────────────────────┘

  训练这些模型统一用：
  ┌────────────────────────────────────────────────┐
  │  Loss = -log P(正确答案)  或  (预测-真实)²       │
  │  θ ← θ - η · (某种处理后的梯度)                  │
  │       SGD → 动量 → AdaGrad → RMSProp → Adam    │
  └────────────────────────────────────────────────┘
```

## 建议的学习顺序

1. **第一遍（30 分钟）：** 只读本指南，建立全局框架
2. **第二遍（读书时）：** 遇到公式先用"5 个动作"归类，搞不清的查 `数学符号速查表.md`
3. **第三遍（需要时）：** 对特定公式想深入理解，查 `全书数学公式详解.md` 看逐项解释
4. **实践中：** 跑代码时对照公式，看代码和公式的一一对应关系

**记住：理解公式的含义比记住公式的形式重要 100 倍。**
