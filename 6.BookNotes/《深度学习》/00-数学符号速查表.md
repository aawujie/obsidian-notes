# 《深度学习》数学符号速查表 (Cheat Sheet)

> 汇总自《动手学深度学习》全书笔记（第 1–15 章），覆盖所有出现的数学符号。

## 1. 数字与基本表示

| 符号 | LaTeX | 含义 |
|------|-------|------|
| $x$ | `x` | 标量 |
| $\mathbf{x}$ | `\mathbf{x}` | 向量 |
| $\mathbf{X}$ | `\mathbf{X}` | 矩阵 |
| $\mathsf{X}$ | `\mathsf{X}` | 张量（高阶） |
| $\mathbf{I}$ | `\mathbf{I}` | 单位矩阵 |
| $\mathbf{1}$ | `\mathbf{1}` | 全 1 向量 / 指示函数 |
| $x_i$, $[\mathbf{x}]_i$ | `x_i`, `[\mathbf{x}]_i` | 向量第 $i$ 个元素 |
| $x_{ij}$, $[\mathbf{X}]_{ij}$ | `x_{ij}`, `[\mathbf{X}]_{ij}` | 矩阵第 $i$ 行第 $j$ 列元素 |
| $[\mathsf{W}]_{i,j,a,b}$ | `[\mathsf{W}]_{i,j,a,b}` | 四阶张量元素 |
| $\mathbf{x}^{(i)}$ | `\mathbf{x}^{(i)}` | 第 $i$ 个样本 |
