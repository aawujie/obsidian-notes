## 📋 项目概述

制作一个**拇指尖大小的 4G 水滴形项链录音器**，核心功能：
- 按住按钮录音（30 秒）
- 松开自动通过 4G 上传到服务器
- 无需 WiFi/蓝牙，独立工作
- 待机续航 3-5 天
- 外观像普通饰品，可日常佩戴

## 🔧 第一阶段：MVP 硬件方案

### 核心元件选型

| 组件 | 选型型号 | 尺寸 | 理由 |
|------|---------|------|------|
| **主控模组** | 合宙 Air780E（移芯 EC618） | 16×18×2.3mm | 最小 Cat.1 模组，内置音频 Codec |
| **SIM 卡** | 贴片 eSIM | 5×6mm | 直接焊接，省 80% 空间 |
| **麦克风** | 高灵敏度驻极体咪头 | Φ4×1.5mm | 模拟麦克风，无需外围电路 |
| **天线** | 定制 FPC 软板天线 | 25×10mm | 贴外壳内壁，利用弧面空间 |
| **电池** | 软包锂电 402025 | 20×25×4mm | 150mAh，扛 4G 峰值电流 |
| **LED** | 0603 绿色 | 1.6×0.8mm | 状态指示 |
| **按钮** | 2×3mm 轻触开关 | 2×3×2mm | 侧按 |

## 💻 软件逻辑（LuatOS）

### 工作流程

```
1. 开机 → 注册 4G 网络 → 进入 DeepSleep（心跳包维持）
2. 按下按钮 → 唤醒 → LED1 亮（红灯）→ 开始录音
3. 录音 30 秒 → 存储为 AMR 格式（约 45KB）
4. 松开按钮 → LED2 闪（绿灯）→ 建立 4G 连接
5. HTTP POST 上传 AMR 文件到服务器
6. 服务器返回 200 OK → LED2 常亮 1 秒
7. 上传失败 → LED2 快闪 3 次
8. 返回 DeepSleep
```

## 🎯 第二阶段：极致裁剪方案

### 如何削减 30-40% 体积？

| 技术 | MVP 方案 | 量产方案 | 收益 |
|------|---------|---------|------|
| **芯片封装** | Air780E 模组 | EC618 裸芯片 + COB | 面积 -40%，厚度 -1.5mm |
| **PCB** | 硬质 FR4 | 软硬结合板 | 空间 +100%，厚度 -40% |
| **电池** | 150mAh 软包 | 80mAh 纽扣 + 法拉电容 | 体积 -30% |
| **天线** | FPC 软板 | LDS 激光成型 | 厚度 -1mm |
