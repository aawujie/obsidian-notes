## 核心理念

这些技术来自 Renaissance Technologies（Jim Simons 创建的最高表现量化基金）等顶级量化机构使用的核心原则。Susquehanna（最大量化机构之一）也明确提到这些方法。

四大法则的核心目的：**区分真实边缘（real edge）和统计噪声（statistical noise）**。

---

## 一、参数敏感性测试（Parameter Sensitivity）

### 定义
测试参数小幅变化对策略表现的影响。

### 为什么重要
- 如果参数从20改到22就彻底杀掉收益（从20%跌到-10%），说明策略**过拟合**
- 鲁棒策略在参数范围内表现**平滑**，不会出现悬崖式下跌
- 市场 constantly 变化，今天的"完美参数"明天不会完美
- 如果策略只在唯一一个参数设置有效 → 不是边缘，是历史数据中的偶然

### 热力图（Heatmap）可视化
- 两个参数维度分别作为X轴和Y轴
- 颜色越暖（黄）→ 利润越高；颜色越暗 → 利润越低
- **理想模式**：一个最优区域，周围缓慢递减，然后完全不工作
- **过拟合模式**：参数之间无连贯性，随机散布

### RSI策略示例

| 参数 | 过拟合策略 | 鲁棒策略 |
|:---|:---|:---|
| RSI 12 | - | +18% |
| RSI 14 | +50% | +22% |
| RSI 15 | -10% | - |
| RSI 16 | +5% | +20% |
| RSI 18 | - | +17% |

过拟合：参数间无连贯性，50%→-10%→+5%的跳跃
鲁棒：18%→22%→20%→17%，平滑递减

### 实操建议
- 这是作者最喜欢、最常跑的测试
- 对**所有策略**都跑参数敏感性
- 可以覆盖大多数过拟合问题

## 二、过拟合（Overfitting）详解

### 定义
策略**记住了噪声**而非学习了真实模式。

### 核心比喻
> 过拟合 = 背诵考试答案而非理解学科知识
> 你不会真正掌握知识，只知道那一份试卷的答案

### 表现
- 为回测中的每一天创建独特规则 → 历史上完美，实盘彻底失效
- 在2年历史数据上尝试所有组合（10种均线×20种指标）→ 总能找到"看起来不错"的东西
- 但这不是"发现alpha"，而是**折磨数据**（torture the data）

### 本质
区分历史数据中的：
- **真实逻辑**（real patterns）→ 可持续
- **随机噪声**（statistical noise）→ 不可持续

## 三、滚动窗口优化（Walk Forward Optimization）

### 定义
将数据分为**训练期（in-sample）**和**测试期（out-of-sample）**，然后按时间滚动。

### 示例
- 1年训练数据 → 0.5年测试数据
- 滚动前进：训练窗口和测试窗口一起移动
- 在每个步骤中，策略**从未见过**其前面的测试数据

### 关键原则
1. **样本外表现的一致性**是策略实战能力的关键指标
2. 样本外表现必然低于样本内 → **正常**
   - 样本内年化20%，样本外7-8% → 可接受
   - 样本内20%，样本外-10% → **完全不可接受**
3. 你没有对样本外做任何优化，所以表现自然较低

### 大多数人的错误
- 在全部数据上优化 → 然后惊讶为什么实盘失败
- 本质上：**记住了考试答案，不理解学科本身**

### 延伸思考
> 如果我有2年历史数据，尝试10种均线+20种指标的所有组合 → 总能找到"看起来不错"的结果
> 但这不是发现alpha，而是折磨数据让它说出你想听的答案

## 四、压力测试（Stress Testing）

### 定义
把最糟糕的情况扔给你的策略。

### 为什么重要
- 大多数回测看起来很棒，因为是在**正常市场条件**下测试的
- 但正常不会永远持续
- 你需要知道策略在极端条件下的表现

### 测试内容

| 压力类型 | 方法 | 目的 |
|:---|:---|:---|
| **极端市场** | 2008金融危机、2020疫情、闪崩 | 看策略能否存活 |
| **滑点增加** | 从0.01%→0.1%→1%→10% | 看策略对交易成本的容忍度 |
| **手续费翻倍** | 2x → 3x 佣金 | 验证成本鲁棒性 |
| **执行延迟** | 信号到执行：即时→1天→5天 | 看信号持续性 |

### 执行延迟示例
作者的加密货币动量策略：
- Day 0执行：不是最好表现
- Day 1延迟执行：**反而更好**
- 说明信号持续足够长的时间窗口 → 即使有延迟也能捕捉收益

### 执行延迟的重要性
- 没有任何执行是完全即时的
- 策略放大时延迟更常见
- 更舒服的策略：有延迟仍盈利（鲁棒）vs 不即时执行就亏钱（脆弱）

### 实操方法
1. 翻倍佣金 → 策略能否存活？
2. 三倍滑点 → 表现如何？
3. 增加执行延迟 → 信号是否持续有效？

## 五、蒙特卡洛模拟（Monte Carlo Simulation）

### 定义
将历史交易序列**随机打乱顺序**，进行成千上万次模拟。

### 为什么重要
- 你的回测只是**一种可能的历史路径**
- 在那个特定回测中，交易恰好以一种对你有利的顺序发生
- 但如果同样的交易以**不同顺序**发生呢？

### 可视化
- 每条线 = 一条净值曲线（不同的交易顺序）
- 100次交易 → 把第99次交易移到第22次的位置，以此类推
- 结果看起来像"蜡笔乱画" → 但每条线都是合法的可能路径

### 揭示的内容
1. **真实风险范围** — 不是单一净值曲线，而是范围
2. **最坏情况** — 有些净值曲线大幅回撤
3. **心理承受力** — 你能承受最坏的心理压力吗？
4. **账户存活** — 你的仓位管理能在最坏情况下存活吗？

### 判断标准
- 大多数净值曲线向上 → 好
- 但如果有10条直线下跌 → 担忧
  - 说明仓位太激进
  - 不幸运的序列可能直接爆仓
  - 需要减半仓位或调整

### 实战意义
实盘没有固定路径，任何序列都可能发生。蒙特卡洛给你**现实的期望**。

## 总结：四大技术的层次关系

```
参数敏感性 → 过拟合了吗？
    ↓
滚动窗口 → 样本外还有效吗？
    ↓
压力测试 → 极端情况下能活吗？
    ↓
蒙特卡洛 → 最坏情况能承受吗？
```

每一层都是前一层的深化验证。只有全部通过的策略才值得实盘。

## 与战争因子项目的关联

我们的LSTM因子项目正好验证了这些原则：

| 技术 | 我们的验证结果 |
|:---|:---|
| 参数敏感性 | 未做 → 应该测试hidden_dim 16/32/48等 |
| 滚动窗口 | 80/20 split后IR从0.70→0.04（衰减94%）→ **严重过拟合** |
| 压力测试 | 真实回测加了千二成本和涨跌停过滤 → 超额年化19%（但这是样本内结果） |
| 蒙特卡洛 | 未做 → 应该做 |

**结论**：我们的LSTM因子在滚动窗口验证上失败了。下一步应按照这些技术系统性地重新验证。
