# 卡尔曼滤波在量化中的应用

## 一句话理解

站在雾里看移动的车。拿上一秒的推测预测下一秒，再用当前目测修正。两个信息融合，结果比单纯相信眼睛准。

核心优势：**边看边猜边修正**，vs 均线的"死记硬背"、静态权重的"一本书定终身"。

---

## 三大应用

### 1. 去噪股价（信号提取）

**问题**：股价 = 真实趋势 + 噪声。均线滞后严重。

**做法**：
- 隐状态：此刻的真实趋势水平
- 观测：市场报价（带噪声）
- 过程噪声 vs 观测噪声 → 滤波自动决定信自己多少、信市场多少

**效果**：比均线快、比裸价稳。急涨急跌不跟风，趋势转向比均线早识别。

### 2. 动态对冲比（配对交易）

**问题**：两条腿的对冲比会随时间漂移。OLS回归算出来是死的。

**做法**：
- 隐状态：实时对冲比（缓变量）
- 观测：两资产每日价格
- 每天更新一次猜测

**效果**：对冲比随市场演化自适应，不需要手动换参数。

### 3. 因子动态权重（最契合我们的管线）

**问题**：5因子目前用静态IR加权。不同市场环境下因子有效程度不同，但权重不变。

**做法**：
- 隐状态向量：5个因子的真实alpha强度（随时变）
- 测量：每月截面的IC值
- 过程方程：alpha_t = alpha_t-1 + 漂移噪声（假设alpha缓变）
- 测量方程：IC_t = alpha_t + 采样噪声

每个月底出了新一期IC → 滤波更新5个alpha → 下个月权重自动调整：
- 最近生效的因子 → 自动加重
- 最近失效的因子 → 自动降权

**不需要判断"现在是什么市场"，滤波自己推理。**

## 与现有方法的对比

| 方法 | 均线 | 静态权重 | 卡尔曼 |
|:---|:---|:---|:---|
| 核心思路 | 历史等权平均 | 历史IR定权重 | 贝叶斯推理+实时更新 |
| 滞后性 | 高 | 极高 | 低 |
| 自适应 | 否 | 否 | 是 |
| 过拟合风险 | 低 | 中（IR是样本内） | 低（在线不拟合） |
| 参数调优 | 窗口长度 | 回溯期 | 过程/观测噪声比 |

## 下一步实验建议

**优先级最高：方案3（因子动态权重）**

不造新因子，把现有5因子的合成方式从固定IR加权升级到卡尔曼自适应加权。

预期改善场景：
- 2023下半年 → roe/gm因子正在失效时自动降权，可能避免部分亏损
- 行业轮动剧烈期 → 快速跟上有效因子方向

## 数据流示意

```
每个月底:
  IC测量(t) = corr(因子值, 下月收益)  ← 测量方程
  
  卡尔曼更新:
    预测: alpha先验(t) = alpha后验(t-1) + 漂移噪声
     修正: alpha后验(t) = alpha先验(t) + K × (IC测量 - alpha先验)
  
  权重: w(t) = softmax(alpha后验(t))
  
  下月持仓: 按加权因子分选 top 50
```

## 实盘回测结果（2026-04-27）

在796只A股池上对比静态IR加权 vs 卡尔曼动态加权，月频调仓含风控，2023-2025回测：

| 方法 | 年化超额 | 夏普 | 最大回撤 | 月频IR |
|:---|:---|:---|:---|:---|
| 静态IR加权 | 22.8% | 2.00 | 12.5% | 0.58 |
| 卡尔曼动态 | 26.4% | 2.07 | 14.7% | 0.60 |
| 改善 | +3.6% | +0.07 | ⚠️ +2.2% | +0.02 |

### 发现

1. **超额有提升但不显著**：3.6%的超额改善在统计上微小，IR从0.58→0.60几乎没动
2. **回撤反而更高**：卡尔曼太灵敏，alpha是缓变量，等发现因子失效时亏损已发生——反应速度不够快
3. **权重切换符合预期**：2023H2确实下调了gm/roe权重，但幅度不够（alpha后验降得太慢）

### 核心瓶颈

**不是权重怎么合成，是因子本身的alpha高度有限。** 当前5因子已逼近上限，进一步改进需要新的alpha源：
- 分析师一致预期（真正的surprise因子）
- 北向资金流向
- 龙虎榜机构席位
- 股东增减持

### 模型细节

- 隐状态(5维)：每个因子的真实alpha强度
- 过程方程：`alpha_t = alpha_t-1 + Q`（Q=diag(0.01)，alpha缓变）
- 测量方程：`IC_t = alpha_t + R`（R用历史IC方差估计）
- 初始化：前12个月IC均值
- 实现：pykalman库，代码 `factor_mining/kalman_weight.py`
- 结果：`evaluation/kalman_weight/`

### 过程 vs 测量 vs 预测（大白话）

| | 是什么 | 你看见了吗 | 怎么用 |
|:---|:---|:---|:---|
| **过程(Process)** | 真实alpha | ❌ 看不见 | 它自己随时间漂移 |
| **测量(Measurement)** | 每月IC | ✅ 算得出来 | 拿来修正你对alpha的猜测 |
| **预测(先验)** | 对alpha的猜测 | — | 上月后验→这月先验 |
| **修正(后验)** | 更新后的猜测 | — | 用IC修正完→就是这月权重依据 |
