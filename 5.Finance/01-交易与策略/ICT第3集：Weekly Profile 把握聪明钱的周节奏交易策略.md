# 1. Metadata

- Title: 用 Weekly Profile（周期形态）抓住「聪明钱」的一周节奏 — ICT 周期节奏教学（完整版系列 第三季）
- Author: Alan

# 2. Overview

本视频核心论题是：单靠判断方向（bias）不够，关键在于掌握市场的时间节奏（Weekly Profile 周期形态），了解聪明钱（Smart Money）或大户如何安排一周的动作，才能把正确的方向转化为稳定的盈利。结论是：使用 Weekly Profile（周期形态）可以把一周分成节奏节点（动能累积、流动性扫描、流动性释放、回归平衡），并据此在合适的时间框架（最低15分钟，常用1小时、4小时、日线）寻找入场与出场点，从而提高胜率并控制贪心导致的回撤。

## 3.1 课程定位与学习前提

- 这一集属于 ICT（Inner Circle Trader）完整版系列的延伸教学，重点引入 Market Profile（市场轮廓）中的 Weekly Profile（周周期形态）。作者 Alan 是做交易教育与辅导多年（14年从业、5-6年专注教育指导），并且在教学中观察到很多学员“方向对但仍亏钱”的普遍问题，归因之一是没有理解市场具有时间逻辑与节奏。
- 学习前提与使用的时间框架：本方法需要同时观察较大级别的图表（至少日线、4小时）来判断总体偏向，同时在入场时最低使用 15 分钟时框，但作者建议“用 1 小时入场”已经足够（1小时为常用入场时框），4小时与日线用于确认趋势与偏向（bias）。因此学习前需要会看日线、4小时、1小时及15分钟指标/结构。
- 核心概念与关键词（保留原文并括注中文解释）：MarketProfile（市场轮廓），WeeklyProfile（周轮廓 / 周周期形态），PDarray（可能指 Price Distribution Area 或 Price Discovery Area — 视频中使用为判断贵/便宜区域的概念），FVG（Fair Value Gap，公平价值缺口），OrderBlock（订单块），Smart Money（聪明钱 / 大户资金），Liquidity Scan（流动性扫描），Liquidity Release（流动性释放 / 流动性释放阶段）。
- 方法目标：通过识别周一到周五在不同日子的价格行为（横盘/累积、扫描高低、释放动能、回归平衡），判断何时应参与交易、以何种逻辑入场（例如：假突破后入场、打破结构后等待回调至 OrderBlock 或 FVG），并在合适的 PDarray 出场以锁定利润，避免因贪心持仓导致最终被逆转而亏损或爆仓。
- 学习建议：先看前一集关于“流动性（liquidity）”的内容，因为视频多次引用“流动性扫描”与“寻找失衡后回到平衡（reversion to mean）”的逻辑。作者强调不应新增事实，但反复指出——没有流动性扫描就不要交易；若一整周没有明显的流动性结构（持续动能而非循环累积/扫描/释放），则放弃该品种，换其他品种练习和找例子来训练识别能力。

## 3.2 Weekly Profile 的三种主要形态（总体描述与共性逻辑）

- 本节把 Weekly Profile（周期形态）分成三类常见形态，并给出共性流程，便于在实盘中识别与应用。三种形态分别是：经典扩张形态（Classic Expansion）、周中反转形态（Mid-week Reversal）、红盘震荡形态（Range / 横盘震荡形态）。作者强调这三种形态会反复出现，掌握之后就能知道“什么时候该做什么事”。
- 共性流程（周节奏的四个阶段，便于记忆与操作）：
    1. 周一：动能累积或形成初始高低（price builds initial high/low）。周一常为横盘或建立该周的参照高低位。
    2. 周二：通常会出现流动性扫描（Liquidity Scan），即价格去触碰或“扫掉”周一所建立的高位或低位，以获取挂单/流动性，然后开始反转或继续累积。周二常创该周最高或最低（new weekly high/low），但不是绝对，总体为扫描行为的高峰之一。
    3. 周三至周四：流动性释放（Liquidity Release）与动能显现，价格在被扫描后出现较大方向性移动（往某一方向冲），这段时间常是主升/主跌的区间，也是交易者抓趋势的主窗口。
    4. 周五：回归平衡或回调（seek balance / mean reversion），常见价格寻找平衡点并收敛。许多交易者会在周五前后考虑减仓或出场。
- 这四阶段并非每周严格发生，有周二或周三才形成扫描，有时周一就有足够动能直接推动，也有一周完全无明显扫描与结构改变（整周为持续动能），因此必须灵活判断、若无扫描就停止交易该品种。
- 时间与时框应用：判断偏向（bias）用日线/4小时，入场用1小时或15分钟确认结构或回调。入场技术多以“假突破后直接入场”或“等待破位后回调至 OrderBlock / FVG 再进入”为主。出场原则以到达下一个 PDarray（贵/便宜区间）或达到预先设定的盈亏比为目标，避免贪心继续持仓到最后被逆转。

## 3.3 经典扩张形态（Classic Expansion）详解、典型流程与实盘入场/出场规则

- 形态描述：经典扩张（Classic Expansion）通常表现为周一横盘或累积动能，周二通过流动性扫描创该周最高或最低，之后周三到周四开始释放动能（快速冲高或冲低），周五则进入回调寻找平衡。换句话说就是：周一建立参照位，周二扫描周一高低（扫流动性），周三起释放方向性动能，周五回平衡。
- 典型流程（可当作步骤来操作）：
    1. 监测周一：记录周一的高位与低位（作为当周的参照点）。观察是否形成横盘或初步动能累积，日线或4小时确认偏向（若无偏向则等待）。
    2. 周二关注流动性扫描：若价格突破并“扫掉”（take out）周一的高点或低点，则视为流动性扫描，通常这个被扫点会成为该周的最高或最低（weekly high/low）。此时标记被扫位与附近的 OrderBlock、PDarray、FVG。
    3. 流动性释放阶段（周三起）：若周二的扫描后产生明显方向性（例如向上大量动能），等待价格在 1 小时或 15 分钟结构上确认（例如打破结构后回调到 FVG/OrderBlock），可根据风险偏好选择入场方式：保守者等打破高位/低位后再入，激进者在假突破时较早入场。
    4. 出场规划：把 Profit Target 设在下一个 PDarray（视频中称为“比较贵的 PDarray”或“比较便宜的 PDarray”）或在达到预期盈亏比（比如作者示例至少有 1:2、1:3 的隐含盈亏比）时逐步出场。若动能速度过快，可能会错过某些入场机会，但无需执着。
- 实盘示例要点（作者的观察与建议）：
    - 有时周二到周三流动性释放速度非常快，筹码消耗快、回撤也可能很剧烈，因此若以较宽目标追逐，容易遇到高回撤或被反向洗出。建议在 PDarray 或 OrderBlock 逐步分批离场。
    - 若周二出现假突破（false breakout）并回调到 OrderBlock，是常见的入场机会。若是周三打破结构后再确认回调，也是更保守而常用的入场方式。
    - 若在一小时框架上入场，确保风险/回报比合理，且不要贪心持仓过久。视频多次提醒：很多人亏钱是因为“太贪”，持仓想赚更多反而被市场回冲洗掉。

## 3.4 周中反转形态与震荡型（Mid-week Reversal & Range）详解与操作建议

- 周中反转形态（Mid-week Reversal）：
    - 描述与节奏：在这种形态中，周一会建立高低位并可能累积动能，周二进入动能累积阶段但不一定立即扫位，周三才会对周一的某个高位或低位进行“取流动性”（take out / 少掉高低位），随后价格出现明显的反转并在周三至周五形成方向性走势。换言之，流动性扫描与释放可能被延后到周三，动能在中周才爆发。
    - 操作步骤：
        1. 周一记录结构并留意日线/4小时偏向。
        2. 周二耐心观察是否继续横盘或动能累积，不急于入场。
        3. 周三密切监控是否扫掉周一的高低位；若发生扫位并立即出现结构反转（例如价位立刻改变方向），可在 1 小时或 15 分钟图上等待回调至 OrderBlock 或 FVG 后进场。
        4. 若周三打破周一高位然后继续反转并形成趋势，周四、周五是主要盈利窗口。相反若周三没有明显扫描则继续等待。
    - 风险管理：由于反转时机可能来得较晚（周三），须注意剩余交易日（周四、周五）的时间风险与波动性；设置合理止损、分批止盈在 PDarray 处。
- 红盘震荡形态（Range / 横盘震荡形态）：
    - 描述与节奏：周一到周三价格持续横盘且未出现明显的流动性扫描或结构被取走，直到周四才发生扫位或动能释放（也可能是周四才做突破），或整周都处于震荡状态。作者称这种形态较少见，但存在。
    - 操作建议：
        1. 若周一至周三完全横盘并无扫描，通常建议放弃该品种（不要强行交易），转去寻找其他品种或等待周四的动作。
        2. 若周四才扫位并出现动能释放，入场逻辑回归到“假突破/回调到 OrderBlock 或 FVG 后进场”的常规方法，但要记得剩余交易日时间有限，目标与风险要更保守。
        3. 若整周都无明确扫描且持续单向动能（没有明显累积-扫描-释放的循环），也应避免介入，等待清晰结构或换品种。
    - 关键判断：是否交易的核心条件不是“有方向”，而是“有时间节奏的结构（累积→扫描→释放）”。一旦缺乏这一节奏，就意味着聪明钱可能未在该周按可预测的模式操作，散户介入风险更高。

## 3.5 实例应用细节：入场、止损与出场的具体操作细节

- 常见入场方式（两类）：
    1. 激进型：在周二或周三出现假突破/流动性扫描时，直接在较高时框（1小时）或结构上较早的点位入场。优点是进场早可拿到更大波幅；缺点是风险高，容易被假动能吞噬。
    2. 保守型：等待打破结构（Break）之后，等待回调到 FVG（Fair Value Gap，公平价值缺口）或 OrderBlock（订单块）再入场。优点是确认度高、胜率高；缺点是可能错过部分快速释放的波段。
- 止损设置：
    - 止损应设在结构无效或超过 OrderBlock / FVG 的对面位置，即当价格真正破坏你所依据的结构时出局。作者强调不要因贪心而过度延长止损或把止损位置不断放宽。
    - 若以一小时入场，止损通常放在该入场对应的结构外侧（例如上破/下破后回调的极端点之外），并根据风险承受度计算仓位大小。
- 出场策略：
    - 主要目标为到下一个 PDarray（视频示范：到达“比较贵的 PDarray”即为合理止盈区），或在达到预设的隐含盈亏比（例如 1:2、1:3）时逐步离场。
    - 强调分批出场：尤其在扩张形态动能强劲时，先在较安全的目标处部分落袋，再把剩余头寸交给趋势，但切忌贪心一直不出场直到被回冲。
    - 若周五到来且未达到目标，应评估是否回归平衡（可能会回调）并选择减仓或完全出场以规避周末持仓风险。
- 时间框与结构确认：
    - 1小时用于入场与结构确认；15分钟用于更精细的回调与 OrderBlock / FVG 的精确执行；4小时与日线用于确认大方向（bias）。
    - 在入场之前，务必在较高时框确认该周是否已发生“流动性扫描”并明确哪一侧的流动性被取走（上方或下方），从而决定做多还是做空。

# 4. 框架 & 心智模型（Framework & Mindset）

- 周节奏框架（Weekly Rhythm Framework）：这是从视频中可以抽象出的主要 framework，包含四个步骤，每步都对应可操作的市场观察与行动：
    1. 周一：观察与标记（Observe & Mark）
        - 在周一完成对该品种的日线/4小时偏向确认，并在日内或1小时图上标记周一的高点与低点。周一通常为“信息收集”与“动能累积”阶段，不贸然入场，除非有日内独立的 trade setup。
    2. 周二：流动性扫描阶段（Liquidity Scan）
        - 重点观察是否有“扫高/扫低”的动作（take out 周一高点或低点）。一旦发生扫位，标注出被扫的高/低位、附近的 OrderBlock 与 FVG，因为这些是后续回调与入场的重要参考。
    3. 周三至周四：动能释放阶段（Liquidity Release / Momentum）
        - 若发生扫描，市场将在接下来的一到两天释放动能形成趋势。此时可依据保守或激进策略选择入场：直接在1小时观察到冲击时进场，或等待打破结构后回调到 FVG/OrderBlock 再入场。下单需严格设置止损并把目标放在下一个 PDarray。
    4. 周五：回归平衡与风险管理（Balance & Risk Management）
        - 观察是否出现回调寻找平衡，考虑逐步离场或减仓以规避周末持仓风险。若动能仍强烈且目标未达成，可采取分批出场策略，但必须严格执行止盈计划，避免贪心。
- 心智模型（Mindset）：
    - 时间逻辑优先于方向逻辑：即使方向判断正确，若不尊重市场的周期节奏（何时扫流动性、何时释放动能），也常会被洗出或遭遇爆仓。交易决策应基于“什么时候市场会动”而不是“市场可能会去哪里”单一想法。
    - 谨慎对待“没有流动性扫描”的周：若一周内看不出典型的累积→扫描→释放结构，应选择放弃该品种。此为避免“强行交易”的纪律原则。
    - 出场纪律胜过预测未来：作者反复强调“不要贪心”，入场容易，出场难。把出场点（PDarray 或预设比率）写在交易计划里，并严格执行，避免因期待更多利润而被市场反向清算。
    - 学习与练习的心态：以大量寻找例子的方式训练眼睛与节奏感（搜集周例子、标注周一高低、追踪周二是否扫位、周三释放的走势），通过重复练习把理论内化为直觉。作者建议不断练习并积累交易样本来掌握聪明钱的一周节奏。
- 操作上要点（整合心智与框架为可执行步骤）：
    1. 每周开始前在日线/4小时确认大偏向；在1小时/15分钟标注周一高低；
    2. 周二观察是否发生流动性扫描，若是则在图上标注被扫位、相关 OrderBlock、FVG 与 PDarray；
    3. 若周二扫位后周三出现动能释放，等待合规入场条件（假突破后回调或结构确认后回调）进行分批布局；设置止损在结构无效点；
    4. 设置出场在下一个 PDarray 或按事先设定的盈亏比分批离场，并避免周五持仓过夜（或提前减仓）。
- 总结的心智要点：以“周为单位的节奏感”作为交易决策的主导逻辑；用时间窗口（周一到周五的不同角色）来过滤交易机会；入场有方法（假突破或回调到 OrderBlock / FVG），出场有纪律（在 PDarray 或预定比率离场），并且永远以谨慎而非贪婪的态度面对变化。

# 总结

- 本视频的核心在于把不确定的“方向判断”变成可操作的“时间节奏判断”。通过 Weekly Profile（周周期形态）识别聪明钱安排一周的节奏：周一累积并建立高低、周二常常扫流动性（创造周高或周低）、周三至周四释放动能、周五回归平衡。掌握这套节奏框架后，在合适的时间窗（1小时入场、15分钟精细执行、4小时或日线确认偏向）进行入场与出场，可以有效提高交易成功率并降低被洗出或爆仓的风险。
- 实务要点：标记周一高低，观察周二是否发生流动性扫描，若发生则在后续动能释放期（周三起）按保守或激进策略入场，止损放在结构失效处，出场目标放在下一个 PDarray 或预设盈亏比，并谨防贪心导致亏损扩大。若整周无明显扫描或结构，则选择放弃该品种，继续训练寻找下一个可操作的例子。
