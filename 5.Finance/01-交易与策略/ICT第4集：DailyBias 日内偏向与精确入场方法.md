# 1. Metadata

- Title: ICT Daily Bias（第4集）读本 — 日内偏向与精确入场方法
- Author: Alan（交易轮值）

# 2. Overview

本视频核心论题是介绍并演示一套名为 DailyBias 的日内偏向判断与入场规则（结合 ICT/价格行为理念），目的在于通过多时间框架与会话（Session）切分，判定当天的偏向（多或空），并给出具体的入场位置与时机（包括使用 FVG、Order Block、流动性扫描/liquidity scan、结构破坏/structure break 等概念），从而提高入场精确度与胜率。结论是：准确的偏向判断（DailyBias）是稳定获利的核心，配合清晰的入场条件与多时间框架配合，可以避免因偏向判断错误而持续亏损，即使会错过部分交易也优于频繁亏损。

# 3. 按照主题来梳理

## 3.1 DailyBias 是什么、为什么重要（含概念与核心结论）

- DailyBias 的基本定义与目标DailyBias（每日偏向）在视频中被描述为一种以日线或高时框为基础，结合较低时框确认的偏向判定方法。它不是单纯看某一根日线的涨跌，而是通过一整套步骤判断当天或当前周期内市场偏向是“做多优先”还是“做空优先”。这个偏向会作为交易决策的第一层过滤条件：若偏向是多头，则只寻找做多的入场机会；若偏向是空头，则只考虑做空。这能大幅降低“与大势对抗而被震荡吃掉资金”的概率。视频强调：偏向判断正确时，后续入场与风控更容易实现稳定获利；若偏向判断错误，即便其他入场条件再严格，也可能导致持续亏损。
- DailyBias 与 ICT 框架的关系作者认为 ICT（Inner Circle Trader）所讲的价格行为、流动性与结构等概念，是透过不同故事或方式呈现价格动作。DailyBias 是把这些核心概念—高位/低位（high/low）、流动性扫描（liquidity scan）、结构破坏（structure break）、Order Block（订单区块）或 FVG（Fair Value Gap，价值缺口）—组织成每日使用的清单。作者既传承 ICT 精髓，也加入个人经验与观点，以便让读者能更有效地把理论落地。
- 为什么比 Market Profile（市场剖面）更适合某些品种（如加密货币）视频中特别举例加密货币（如比特币）因为交易是 7 天无休的，Market Profile 常假设周一至周五结构会更适用，但对周末交易活动覆盖不足，因此在加密市场上实际应用受限。DailyBias 则强调高位/低位与流动性扫描为核心，适应性强于 Market Profile 在持续交易市场的适用性。作者因此认为对加密市场 DailyBias 实操价值更高。
- 重要性总结（对交易者的实际影响）
    1. 作为第一道过滤：避免逆势交易、降低无谓风险；
    2. 提供入场思路：什么时候找 FVG/Order Block，什么时候等待结构破坏；
    3. 提高执行效率：明确在高时框等待偏向确认，再到低时框寻找具体入场，减少频繁盲目下单；
    4. 帮助复盘与成长：DailyBias 给出清晰的复盘路径（记录偏向、入场是否符合规则、结果如何），利于在做了几十单后总结出稳定盈利的方法。
视频强调一个实践观念：宁可错过几笔交易也不要在偏向不明或偏向错误时频繁参与。长期看这种纪律比短期追求高胜率更有利于稳定获利。

## 3.2 判定偏向的具体步骤（可执行流程）

- 总体流程概述DailyBias 的判定与执行可以拆成高时框（如日线/4H/1H）判定偏向、识别关键流动性位与结构、再切换到低时框（如 15m/5m）寻找结构破坏或入场信号。下面按步骤详细说明：
- 第一步：在高时框确认主要结构与流动性分布（Daily / 4H / 1H）
    1. 标记明显的高位与低位（高位指价格曾多次停留或形成阻力的区域，低位相反）。这些高低可以是在日线或 4H 上观察到的关键点位。
    2. 识别“流动性扫描”区域（liquidity scan）：即价格以前尚未触及但可能被市场去“扫”以触发止损/引流的区域。把这些未被扫的流动性点画出来，作为后续价格目标或潜在反转区域。
    3. 找到 FVG（Fair Value Gap，价值缺口）与 Order Block（订单区块）：FVG 是价格在急速移动后留下的不对称区间（通常由三根烛台形成），Order Block 是机构下单后留下的关键供需区间。画出这些位置，作为可能的入场点或利润目标。
- 第二步：根据高时框位置判断 DailyBias（偏向）
    1. 若高位未被扫且价格在形成上升结构（高低点不断抬高），偏向仍倾向多头。
    2. 若出现对上位的流动性扫描并且随之结构被破坏（下破关键低位），偏向会从多转空；反之亦然。
    3. 以“是否有新的流动性扫描导致结构被打破”为核心判断，若出现新的流动性扫描并伴随结构破坏，则当天偏向可能改变。
    4. 在无法明确时，保持中性或等待更多确认，不强行猜测偏向。
- 第三步：切换至低时框寻找入场（1H→15m/5m）
    1. 使用高时框定位好的 FVG、Order Block 作为“候选区”。
    2. 在低时框上等待“结构破坏（structure break）”或回踩到 FVG/Order Block 的低风险入场位。结构破坏即小级别的高低点被突破，确认方向后可以布局顺势单。
    3. 若在低时框看到明显的流动性被扫（例如上方高点被扫掉的引线），可考虑在该区域做多（若整体偏向多），但要严格按照止损位置管理风险。
    4. 推荐把止损放在 FVG/Order Block 外侧的合理位置，目标基于高时框下一个流动性区域或结构位。
- 第四步：入场大小与持仓管理（与偏向挂钩）
    1. 若偏向明确且入场符合多级时间框确认，可以按计划分批进场（部分头寸在保守目标锁利润，剩余持仓看更高时框目标）。
    2. 若偏向仅在高时框成立但低时框入场信号不充分，则宁可等待更高概率的入场或缩小仓位。
    3. 若偏向被逆转（出现对立流动性被扫且结构改变），立即调整策略：减少多头仓位或撤出，等待新的偏向确认。
- 第五步：复盘与规则修正
    1. 每日或每次交易后记录偏向判断是否正确、入场是否符合规则、最终盈亏、是否出现被动止损或被行情吃掉等信息。
    2. 做 10、20、100 单复盘后，统计哪些情境下判断容易错、哪些入场类型胜率高，从而逐步微调规则（例如对 FVG 的入场宽容度、止损位置、持仓分配）。
    3. 视频多次强调：复盘是把 DailyBias 从理论变成可持续盈利系统的关键步骤。

## 3.3 入场形态、关键概念与实战示例（以比特币为例的多时间框架演练）

- 关键概念简述（在实战中必须识别）
    1. 流动性扫描（liquidity scan）：通常指价格去扫掉某个明显的高位或低位（例如上方的震荡高点止损集中处），扫完后有可能迅速反转或延续至下一个流动性区域。
    2. FVG（Fair Value Gap，价值缺口）：价格快速推进后遗留的缺口区间，常被视为回调的吸引力点。视频中多次用 FVG 作为“更便宜”的入场位。
    3. Order Block（订单区块）：机构成交集中区，通常是一组带有明显买卖意图的 K 线组合，作为供需转变点。
    4. 结构破坏（structure break）：小级别或高时框的高低点被破，代表原有结构被打破，可能意味着偏向变化或确认。
- 实战示例一（高位尚未被扫、多头偏向示范）作者以比特币日线与 4 小时图为例：画出近期的最低点、出现引线后上冲的结构、然后回落再上冲。观察到某个低位被扫后价格回升且未触及高位的上方流动性。此时可以在 4 小时或 1 小时去寻找 FVG 或 Order Block 来做多。演示中，当把入场点挂在 FVG 上，若价格顺势冲上，可能直接命中目标，形成高盈亏比（例如提到理论上的 1:45），但作者也指出这类极端盈亏比往往需要持仓很长时间（例如 40 天左右），现实中不太容易达成。实例教学要点：画结构、标注未扫流动性、在 FVG/Order Block 等待回调入场、分批锁利或依据日线新流动性扫描决定是否出场。
- 实战示例二（结构破坏后寻找反向入场）在另一个例子中，作者展示若某一结构被打破（例如 4 小时的多头结构被破），则偏向可能由多转空，此时在该被破位置寻找 Order Block 或 FVG 去做空是合理的选择。示例中还演示了在更低时框（1 小时或 15 分钟）找不到合适入场时，有时需要回到更高或更低的时框去寻找更合适的角（entry angle）。实例教学要点：当高时框结构被破，偏向改变；寻找与高时框配套的低时框入场点（如 FVG、orderblock），并注意不要在噪音（低于 15 分钟）内频繁交易。
- 会话（Session）层面的日内入场示范（Asian/London/NewYork）作者引入 Session（交易时段）指标，至少区分亚洲盘（Asian）、伦敦盘（London）与纽约盘（NewYork）。用颜色标注出各时段的高低位，并观察在某一会话中是否触发了高位或低位的“被扫”行为。示例中以亚洲盘为重点：亚洲盘形成的高低位若在后续伦敦或纽约盘被扫，便可能触发明显的结构破坏，从而在 5 分钟或 15 分钟图上产生入场机会（例如回踩 Order Block 或 FVG 后的顺势交易）。实例教学要点：会话带来短期流动性集中或波动率上升，用会话高低位作为短线入场参考能提高日内机会的辨识度。作者建议低于 15 分钟的时框不太可靠，5 分钟可使用但须谨慎。
- 关于错过交易与胜率的现实考量视频强调，DailyBias 的方法会“错过”一些交易（例如没有在某个 FVG 抓到入场就错过了上涨），但这是可接受的代价。重要的是即便偏向判断正确但入场条件未满足，也不要强行入场；入场规则是保护资本的关键。作者还提醒：超级高的盈亏比案例虽吸引人，但现实中较难实现，尤其需考虑持仓时间与资金管理。

## 3.4 交易执行、风控与复盘方法（入场/出场、仓位与复盘流程）

- 入场执行细则（如何下单与设置止损/止盈）
    1. 挂单策略：基于高时框画出的 FVG 或 Order Block 在低时框（如 15m 或 5m）上挂买/卖单，优先在结构支持的区位挂单。作者示例中直接在 FVG 较“便宜”的边界挂单，等待价格回补触发。
    2. 止损设置：止损应放在明显的结构外侧，不要放得太近以免被常规波动击中，但也不要过大使得风险不可控。举例中作者提到若想要极高盈亏比（如 1:45），往往需要极低的风控比例（1%风险换取极高盈利），但这在现实交易中难以维系。
    3. 止盈策略：可以分层止盈：第一层在小级别流动性或结构位锁部分利润（用以回收交易成本并降低心理压力），第二层对剩余头寸追求更高时框目标（下一个未扫的流动性区域或日线级别目标）。
- 仓位管理与持仓时间考量
    1. 分批进场/分批出场：当偏向与入场信号都很强时，建议分批建仓（例如先小部分确认，后续补仓），并在不同目标处分批减仓。
    2. 持仓时间：高盈亏比目标往往对应更长持仓时间（视频举例需持仓数周），交易者需衡量是否能承担资金占用与心理压力。若以日内或短线策略为主，应调整目标为较接近的流动性位或结构点，降低持仓天数。
    3. 风险比控制：作者强调不要盲目追求极高风险回报比（如 1:45）而忽略实现概率及持仓时间；更现实的是追求稳定且可持续的风险回报设计（例如 1:2 至 1:5，根据策略与市场波动调整）。
- 出场规则与偏向改变时的应对
    1. 若在持仓过程中日线或高时框出现新的流动性扫描并导致结构被破坏，应考虑部分或全部出场，防止原本的偏向被逆转后带来损失。
    2. 若价格到达日线画出的新流动性位且形成明显的供需作用（例如出现大幅回撤或反转信号），可选择在这些位点撤出剩余头寸。
    3. 对于在小级别（如 15m）入场的头寸，若日内波动过大并出现对偏向的迹象，作者建议以较快的手动方式锁定利润或平仓，而不是执拗守住初始目标。
- 复盘流程（如何把 DailyBias 转化为稳定系统）
    1. 记录每笔交易的高时框偏向判定（对/错）、入场类型（FVG/Order Block/结构破坏/会话触发）、止损与止盈位置、盈亏结果、是否符合规则。
    2. 按批次（例如每 10 单、每 50 单）统计胜率、期望收益、偏向判断的准确率、不同入场类型的表现差异。
    3. 找出常见错误：偏向误判的常见情形、低时框噪音导致的早退或被止损的模式、会话切换时未调整策略等。
    4. 修正规则：例如若 FVG 在某类市场环境胜率低，则调整入场宽容度或放弃该类型；若 Asian Session 的噪音导致过多错单，则限制在该时段的仓位大小或完全避开。
视频强调复盘是把理论变成实际盈利的关键，建议持续重复看、反复练习直到熟练。作者推荐用“做 10 单、100 单复盘”这种阶梯式练习方式。

# 4. 框架 & 心智模型（Framework & Mindset）

- DailyBias 框架（可执行系统化步骤）
    1. 高时框定位（Identify）：在日线或 4H 上标注主要高低点、未被扫的流动性区域（liquidity scan）、FVG 与 Order Block。此步骤为策略提供宏观方向。
    2. 偏向确认（Bias）：基于高时框结构判断偏向（多/空/中性）。偏向判断以结构是否连续、关键位是否被扫为核心依据。若结构不断创新高且未被扫，则偏向为多；若结构被向下破坏，则偏向改为空。
    3. 低时框筛选（Refine）：下移至 1H、15m 或 5m，利用高时框标注的 FVG/Order Block 作为候选入场区，观察小级别的结构破坏或回踩确认入场时机。注意：不建议使用小于 15 分钟作为主要决策时框，5 分钟可做短线微调但风险与噪音更高。
    4. 会话考量（Contextualize）：结合交易时段（Asian/London/NewYork）来判断流动性何时集中、波动率何时上升。视频中以亚洲盘为例示范如何利用会话高低来做短线机会识别。
    5. 交易执行（Execute）：在低时框明确的入场点挂单或市价进场，设置合理止损与分层止盈；如果偏向强烈且入场条件完备，可以分批加仓；若偏向与入场信号不一致则放弃。
    6. 复盘（Iterate）：记录每笔交易数据（偏向、入场类型、会话、盈亏、情形说明），定期分析与修正规则。
- 心智模型（Mindset）
    1. 偏向优先、入场次之：先判断偏向，再找入场。不要在偏向不明或偏向相反时强行参与市场。
    2. 容忍错过、拒绝亏损：策略会错过一些机会，这是正常且必要的代价。长期稳定胜利优先于短期高频中奖。
    3. 多时间框架思维：用高时框控制方向和范围，用低时框寻找更低风险入场。每一次入场都要和高时框偏向一致或有明确理由。
    4. 数据与复盘导向：交易不是凭直觉长期成功的活动，必须通过大量复盘把规则系统化、可量化并持续优化。
    5. 风险决定生存：即便所有技术条件都满足，若风险管理不到位（仓位过大、止损设置不合理），也会导致长期失败。把“能不亏”放在首位，再去优化盈利。
    6. 灵活但有纪律：在不同市场（如传统品种与加密货币）需要微调规则（例如加密货币 7×24 特性），但任何调整必须经复盘验证，而非随性改变。
    7. 耐心与等待：很多机会需要等待结构破坏或流动性扫描，耐心是把高概率交易转化为盈利的关键。追求快速但高概率的入场比追求瞬时利润更重要。

以上 Framework & Mindset 的要点都强调从宏观方向到微观入场的层层把控，以及以复盘为驱动的持续改进文化。作者反复提到：DailyBias 并非万能工具，但若严格执行并长期复盘，它能显著提高偏向判断准确度并为入场提供稳定的规则集合，从而帮助交易者实现更高概率的稳定获利。

# 总结

本视频的核心在于把 ICT 的价格行为与流动性概念组织成 DailyBias 的实操流程：先在高时框判断偏向，标注流动性、FVG、Order Block，再到低时框等待结构破坏或回踩进行入场；配合会话识别短期流动性与波动；严格的入场、止损与分层止盈规则，以及持续的复盘与规则修正，才是把这套理论转为长期可盈利策略的关键。作者强调宁可错过交易也不在偏向不明或入场条件未满足时贸然出手；同时加入了对加密货币市场特点的实际建议（例如 DailyBias 比 Market Profile 更适用于 7×24 市场）。最终要点是：纪律、复盘、风险管理与多时间框架配合，构成稳定交易的核心。
