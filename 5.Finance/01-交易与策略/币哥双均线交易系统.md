# 3. 按照主题来梳理

## 3.1 什么是双均线交易系统与适合人群、时间级别、标的选择

- 双均线交易系统定义与组成：
    - 双均线系统在作者定义下包含两类均线指标：MA（简单移动平均线）与EMA（指数移动平均线），每类三条，分别为20、60、120周期（即MA20、MA60、MA120与EMA20、EMA60、EMA120）。这六条均线共同构成作者口中的“双均线交易系统”。
- 适合的人群：
    - 作者认为该系统“适合所有人”：新手、小白、以及老手。理由是系统提供了明确的识别与交易框架，不需要频繁盯盘，便于学习与执行。作者特别强调初学者应从中周期开始（如1小时、4小时、日线），避免短线时间级别导致频繁亏损。
- 推荐时间周期与交易频次：
    - 作者建议至少交易一小时及以上级别：常用级别为1小时、4小时、日线与周线四档。原因包括：时间级别越高，信号越可靠、波动噪音越小，初学者把握机会更稳；低于1小时级别会带来过多干扰，容易频繁止损、情绪化操作。
    - 交易频次不需要很高：实现月均3,000美元并不要求每天都交易，只要在一个月捕捉到一到三次高赔率机会即可。作者本人一个月在Backpack上只交易了两笔就达成目标。
- 标的选择原则（在Backpack上的实践）：
    - 任何有K线的标的理论上都能用双均线系统，但实际操作要考虑流动性。作者在Backpack上只建议交易比特币（BTC）、以太坊（ETH）、Solana（SOL）三种代币，因为其它代币成交量和深度不足，会造成严重滑点与开仓受限。
    - 作者展示了Backpack合约的24小时成交量数据：BTC、ETH、SOL位列前列，其余代币流动性差。并指出若在Backpack充入大量资金，可能因为流动性限制无法有效开仓，因此他在Backpack仅作为小账户使用，较大资金部署在Binance与Bitget。
- 对于想进阶做短线的备注：
    - 作者并非完全否定用此系统做短线，但前提是交易者对系统理解极为深入且心态与风控稳定，因此建议先在中长周期内建立稳定盈利能力再尝试短线。

## 3.2 两种核心开仓方法（均线密集开仓法与回踩20均线不破开仓法）

- 总体逻辑（共同目标：寻找高赔率机会）：
    - 作者把开仓机会简化为两类方法，其本质都是在寻找高赔率（risk/reward）交易：一旦信号成立，止损点相对较近、止盈空间较大，从而提供良好赔率（常以1:3为基准）。
- 方法一：均线密集开仓法（定义与步骤）
    - 定义：在所选时间级别（例如4小时或日线）中，MA与EMA的三条均线（20/60/120）缠绕在一起——“均线密集”或“均线纠结”，短时间内难以分出上下。
    - 逻辑：当均线密集形成后，市场处于筹码重新分配或方向未定状态。待价格向上突破或向下跌破该均线密集区并形成方向性后（即行情“走出来”），顺势进场。止损设在“有效跌破/站上均线密集区”的位置。
    - 步骤（示例以4小时级别为例）：
        1. 在4小时图上识别均线密集区（多条均线缠绕，视觉上分不清谁在上谁在下）。
        2. 等待价格从密集区向上突破（做多）或向下跌破（做空），并确认突破不是假突破（后续K线确认）。
        3. 开仓后止损设置在“该时间级别均线密集被有效突破/跌破”的位置（即若价格回到并穿透密集区则认错止损）。
        4. 止盈可采用分批在上一个或下一个时间级别的均线密集区止盈，或按固定赔率止盈。
    - 举例（作者实盘示范）：SOL在4小时级别出现均线密集并伴随三角收敛，向上突破后作者直接开多，止损放在均线密集下方。另一个4小时密集向下跌破并回弹未站回则继续下跌，符合做空机会。
- 方法二：均线密集突破后第一次回踩20均线不破开仓法（简称回踩20不破开仓法）
    - 定义：在更高级别（如日线）出现均线密集并向上突破后，若你错过首次突破，可等待价格第一次回踩该时间级别的20均线（MA20或EMA20）并未有效跌破，即“回踩不破”，此时为重新参与的高赔率机会。
    - 逻辑：直接追高时止损点往往较远，风险大；等待第一次有效回踩并且20均线支撑成立，能获得更近的止损位和更大盈利潜力，因此属高赔率交易。
    - 步骤（示例以日线为例）：
        1. 在日线图上识别均线密集并等待价格向上突破并确认趋势方向。
        2. 若错过初始突破，等待价格回调至日线级别的20均线（作者常用黑色线标注），观察是否“回踩不破”——即支撑有效，价格没有跌破该20均线。
        3. 在回踩不破时开仓（可买现货或做多合约），止损设置为“有效跌破日线20均线时”止损。
        4. 若价格回踩并跌破20均线，则该信号失效，应止损并等待下一个高赔率机会。
    - 举例：作者演示SOL日线级别的上涨，若第一次突破时未介入，则在第一次回踩并未跌破日线20均线时买入，止损放在20均线下方。此策略同样适用于下跌趋势（回踩20均线不破则可以做空的对应逻辑）。

## 3.4 如何止损与止盈（包含固定赔率与均线密集止盈）

- 止损规则（两类对应开仓法）
    - 对均线密集开仓法：止损为“有效跌破（或有效站上）开仓时参照的均线密集区”。换言之，若你是基于4小时均线密集做多，则当4小时均线密集被有效跌破时立刻止损认错。
    - 对回踩20不破开仓法：止损为“有效跌破该时间级别的20均线”。如果你是日线回踩20不破开多，若日线20均线被有效向下突破则止损出场。
    - 作者强调的关键点：止损位置与开仓依据一致——“根据什么开仓就以什么来设置止损”，这让止损逻辑清晰且可执行。
- 止盈方法一：上一个时间级别均线密集止盈法（分批止盈）
    - 原理：在你交易的时间级别（例如日线）上，向上（或向下）寻找之前同级别的均线密集区作为潜在阻力/坑位，分批在这些密集区附近止盈。
    - 操作步骤：
        1. 在图上标出“上一个/上几个”同级别的均线密集区（可以有多个）。
        2. 分批出场：当价格到达第一个密集区时卖出一部分并保留剩余仓位；到达第二、第三个密集区时继续分批卖出。
        3. 分批止盈可以保证吃到“鱼身”与“鱼腹”的大部分利润，避免贪心导致错失落袋为安的机会。
    - 逻辑优势：不追求完美高点，而是追求“可实现的最大化平均收益”，减少情绪影响。
- 止盈方法二：固定赔率止盈法（交易前设定risk/reward）
    - 定义：在开仓前就设定亏损与盈利比率（如1:3），按此执行。作者常态只接受1:3或更高的赔率。
    - 操作步骤：
        1. 计算从开仓到止损的百分比亏损（例如2%）。
        2. 将目标盈利设为亏损的若干倍（例如3倍，即目标6%）。在达到目标时分批或全部止盈。
        3. 若行情继续超出目标，可选择保留少量仓位搏更大收益，但需严格管理剩余仓位比例。
    - 作者示例：在4小时SOL的一个空单，止损约2%，第一个目标6%（1:3），若突破首目标并继续下行可再继续按分批策略止盈以追求更高收益。
- 情绪与执行纪律：
    - 作者反复强调：交易不是看对次数（胜率），而是看赔率；交易计划制定后必须严格执行。止盈时要克服贪婪（赚一点想赚更多），否则容易回吐利润并转为亏损。卖出能力（止盈纪律）才是“师傅级能力”。

## 3.5 杠杆使用、实盘结果与注意事项

- 表面杠杆 vs 真实杠杆（关键区分）
    - 表面杠杆：交易平台界面显示的可设置倍数（10x、20x、50x等），是可视化的参数，不代表你实际承担的杠杆风险大小。
    - 真实杠杆：作者定义为“开仓名义价值 / 自身持有本金”。举例说明：你账户有100美金，若用1美金保证金开了价值100美金的仓位（100倍表面杠杆），但你的真实杠杆其实是1倍（因为你有100现金覆盖100仓位）；若你用全部100美金作为保证金并开10倍表面杠杆，仓位价值1000美金，真实杠杆就是10倍。
    - 结论：交易时应以真实杠杆为风险评估核心。
- 作者实际杠杆策略与实操数据：
    - 作者通常不超过10倍真实杠杆，常用为5倍；Backpack实盘两笔赚钱记录分别使用约6倍与5倍真实杠杆。作者强调小账户用较低真实杠杆，避免被单次波动清仓。
    - 作者演示账户：起始权益约7,000USD，后增长到16,000USD；一个月只交易两笔实仓（分别盈利约1,178USD与2,193USD），合计约3,300USD，满足月赚3,000目标。
    - 他展示了每笔仓位的名义价值（~5万至7万美金），结合账户本金计算出真实杠杆较低。
- 注意事项与平台流动性风险：
    - 不要梭哈（全仓搏命）：作者强调每笔交易只用小部分资金，避免高杠杆与全部资金投入。分为两个维度：
        1. 交易维度：每笔不全仓操作、不频繁使用高真实杠杆。
        2. 交易所维度：不要把全部资金放在新或流动性有限的交易所（如Backpack），应保留大部分资金在主流大型交易所（Binance、OKX/欧易、Bitget等）。
    - Backpack流动性限制：平台上仅几个主流标的流动性较好（BTC、ETH、SOL），其他代币流动性差，容易滑点与开仓受限，故作者只在Backpack用小账户交易这三种代币。
    - 资金配置建议：Backpack适合小额试水与低频交易；大仓位与日常主力仓仍需放在流动性更高的大所。

# 4. 框架 & 心智模型（Framework & Mindset）

- 核心框架概述（双均线识别→等待方向→高赔率入场→止损/止盈执行）
    - 识别阶段：在你选定的时间级别（建议≥1小时）上安装6条均线（MA20/60/120与EMA20/60/120），观察“均线密集”现象，这是潜在能量积累与方向选择前的信号。均线密集意味着筹码或趋势方向尚未被市场广泛确认，随后若突破则常伴随方向性的强势表现。
    - 等待方向阶段：不要在均线密集阶段猜方向；耐心等突破或方向被市场“选定”（例如价格有效突破密集区并有确认K线）。另外，如果初次突破时你错过，等待第一次回踩20均线不破也是高概率再入场机会。
    - 高赔率入场：只选择风险/回报比≥1:3的交易机会——也就是说你的止损范围相对小，而潜在目标空间大。高赔率意味着即使胜率不高，长期仍能获利。作者强调他更注重赔率而非胜率。
    - 止损与止盈执行：根据你入场的依据设置止损（若以均线密集开仓，则止损放在该密集区的无效化；若以回踩20均线不破开仓，则止损放在20均线被有效突破时）。止盈采用分批在上一个同级别均线密集区止盈或按开仓前设定的固定赔率（1:3）执行。
- 心态模型与纪律（交易者应具备的心态）
    - 等待优于频繁交易：心态上要接受“机会并不每天都有”，学会等待并耐心执行高赔率策略。作者自己的实操经验是一个月只交易两次就达标，说明耐心与选择优质机会更重要。
    - 按规则执行，别靠直觉或贪婪：在开仓前明确止损/止盈规则，并严格执行。亏损不可怕，可怕的是因贪婪扭曲止盈计划导致回吐既得利润。纪律比预测更重要。
    - 控制真实杠杆与仓位：真正的风险来自于真实杠杆，而不是平台显示的表面倍数。以实际持仓价值和账户权益来衡量杠杆与风险，保持较低真实杠杆（作者常用5倍、最多不超10倍）。
    - 风险分散与平台信任度：不要把所有筹码放在一个新平台；即使平台看似合规，也要逐步试水并保持资金分散。这既是对平台风险的防范，也是对流动性限制的应对。
- 实操流程化步骤（便于复盘与复制）
    1. 平台与标的选择：在流动性允许的前提下选择交易所与标的（Backpack上只选BTC/ETH/SOL）。
    2. 指标布局：在图表中添加MA/EMA各20/60/120，选择合适时间级别（优先1小时、4小时、日线）。
    3. 识别信号：发现同级别的均线密集或确认已有均线密集被突破；记录时间、价格与密集区边界用于止损参照。
    4. 交易计划制定：在入场前设定止损位置、目标止盈点（上方的同级别均线密集或按1:3赔率设定），决定仓位比例与真实杠杆。
    5. 执行与风险控制：按既定计划下单，使用限价或条件单以控制滑点；若市场触发止损规则，严格止损并记录复盘要点。
    6. 分批止盈与复盘：按计划分批止盈，保留小仓位搏进一步收益；交易结束后复盘信号是否符合规则、止损/止盈是否按规矩执行，逐步优化。
- 思维层面要点（mindset）
    - 赔率优先、胜率次之：以系统性获利为目标，而非单次或短期的对错。高赔率意味着长期正期望值。
    - 规则化与机械化：把“何时进、何时出、如何止损/止盈”规则化，减少情绪干扰。规则一旦形成并经过回测或实盘验证，就尽量机械执行。
    - 谦逊与分散：承认信息不完备、市场不确定，采取保守杠杆和分散资金的方式来减少单一失败的影响。
