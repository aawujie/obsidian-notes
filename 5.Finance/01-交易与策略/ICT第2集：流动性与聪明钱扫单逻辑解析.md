# 1. Metadata

- Title: ICT（Inner Circle Trader）系列第2集：流动性（Liquidity）与聪明钱的扫单逻辑
- Author: Alan交易人

# 2. Overview

本视频核心论题是解释市场中“流动性”（liquidity）是什么、交易者常用的订单类型如何形成流动性，以及所谓“聪明钱”（Smart Money）如何通过扫描并吃掉散户的止损单（stop orders）来制造“流动性扫描”（liquidity scan）从而推动价格反转或加速单边。结论是：理解流动性分布、常见止损聚集区与如何等待“假突破/扫单”后再布局，是提高交易命中率与风险回报比的关键。

# 3. 按照主题来梳理

## 3.1 什么是流动性（Liquidity）的概念与市场参与者

- 流动性在视频里的定义：流动性即市场中有多少人愿意买、多少人愿意卖。可以把市场想像成一条热闹的街道，参与者越多（交易越活跃），成交越容易、越快，市场流动性就越高。反之，参与者少、挂单少时，成交困难，流动性低。
- 市场参与者构成：视频强调在现代市场中，不只是普通零售交易员，还有银行（Bank）、机构（Institutions）、投资者（Investors）、基金（Funds）等，它们共同创造市场流动性。聪明钱通常指的是这些能影响价格、掌握大量订单流的参与者（作者并未给出精准定义，但按视频语境为有能力扫描并吃掉散户止损的资金方）。
- 对流动性的进一步解释：在图表上，流动性会以“止损单密集区”、“挂单密集区”（限价单/现价单）等形式隐含存在。视频强调要先理解订单如何匹配（matching），因为流动性本质上由订单的存在与被触发决定。
- 流动性与市场结构：当价格达到某些显眼的高点或低点（可能是日线高点、周线高点、或某一时间段的结构高低点），很多交易者会把止损或止盈放在这些位置。大量的止损或挂单集中在这些水平上，就形成了潜在的流动性池（liquidity pool）。聪明钱会针对这些池进行扫描与吃单操作，从而触发价格的短期加速并为后续更大方向变盘创造条件。
- 补充不确定性说明：视频中称“流动性”包含上方下方、高低压力等多种分类，但并未在一开始给出严格学术定义，更多是基于交易实务的经验分类。因此下面各小节将沿用视频的实际用语与举例描述，不作外部事实扩充。

## 3.2 市场上的订单类型与止损/止盈如何形成流动性

- 三种主要订单类型（视频描述）：
    - 市价单（Market Order）：你以市场给出的当前价格“吃价”成交，立即成交，不用等待。优点是成交确定，缺点是价格可能瞬间跳过想要的位置（滑点）。
    - 限价单 / 现价挂单（Limit Order，也被视频称为“现价单”）：你把买单挂在比市场更低的价格，或卖单挂在比市场更高的价格。挂到价位才会触发成交。优点是保证价格，缺点是无法保证会被成交（可能错过）。
    - 突破单 / 挂价止入单（Stop Order，也称为 Buy Stop / Sell Stop 或作者称BuyStop、SellStop）：你把单挂在当前价的上方（Buy Stop）或下方（Sell Stop），当价格触碰后转为市价单并成交。常用于跟随突破或作为止损触发机制。
- 止损（Stop Loss）与止盈（Take Profit）的本质：
    - 止损通常是一个突破单（stop order）。例如你做空时，为限制亏损在更贵的价位会挂一个“买入止损”（Buy Stop），当价格上涨触碰后买回平仓，从而止损出场。
    - 止盈通常是一个限价单（limit order）。例如做空时，把“买入限价单”挂在更低价格处，价格触碰后以较低价买回并实现盈利。
    - 对做多的情形对称：做多时出场赚钱是“现价卖出”（market sell），亏钱出场是“卖出止损”（Sell Stop）。
- 止损/止盈的交互与市场撮合逻辑：
    - 在过去的老平台上，交易者可能需要分开下多单与平仓单；现代平台通常允许在单一持仓上设置 Stop Loss（止损）与 TP（Take Profit/止盈），但本质上止损仍为止入触发（Buy Stop/Sell Stop），止盈仍为限价单。
    - 这些止损与限价在图表上以特定价位集中，形成可被识别的流动性簇。当价格到达这些价位时，止损被触发（变成市价），如果对面没有足够的限价单去“接盘”，价格会继续朝被触发方向运动，造成快速移动或失衡（imbalance）。
- 举例说明（视频图示说明的流程）：
    - 若许多交易者在一个高位挂空单并把止损放在更高处，当价格上探触及这些买入止损（Buy Stop）时，这些止损会自动买回导致多单量瞬时增加；若市场上没有足够的卖单（限价单）匹配，这部分买单会推高价格，随后触发更多在更高位的限价卖出或Break orders，从而助长一波上冲，最终可能导致反转或形成新的阻力区。
    - 相反情形：许多做多者的止损集中在一个低位，价格下杀触发这些Sell Stop后继续下探，直到出现愿意在更低位接单的一方，价格才会反弹。
- 核心要点汇总：
    - 止损是流动性的来源（stop orders 提供流动性）；限价（limit orders）是流动性的接收端。
    - 聪明钱会“吃掉”这些stop orders来制造价格的短期加速（liquidity sweep / liquidity scan），然后借助被制造出的无流动性区（liquidity void）去推动更远的结构移动。
    - 理解这些匹配与触发关系，是辨识哪里是“被扫单区域”、哪里是“流动性池”的前提。

## 3.3 聪明钱如何扫描止损单与形成流动性扫描（Liquidity Scan）

![[imgs/image 26.png]]

- 什么是“聪明钱的扫单”：
    - 视频中多次强调“聪明钱”（Smart Money）会识别并利用图表上散户止损的集中地（stop orders clusters）。他们会推动价格去触碰这些止损（即“扫单”或“吃掉_stoporders”），触发大量止损市价成交，然后在流动性被耗尽或价格失衡后反方向参与，获取利润。
    - 简单描述为：聪明钱先制造或等待一个价格触发区，把散户止损“吃掉”，之后借助缺乏对手盘（no limit orders to absorb）形成单边移动，他们再按自己的方向入场或出场。
- 为什么扫单后常伴随反转或加速：
    - 当大量止损被触发而没有足够的限价单来承接时，价格在短时间内会呈现“单边”移动（imbalance），因为“买/卖”一侧的市价单量远大于另一侧的限价可成交量。价格只能继续朝有订单的一侧走，直到有人愿在更贵或更低的价格成交（这时形成新的平衡点）。
    - 举例：若多头的买入止损已被触发但图上并没有大量的限价卖单去接这些买单，价格会被推高（越来越贵），直到有卖方愿意在这些更高价位接单，才会出现回调或继续趋势。
- 流动性扫描的时机与识别：
    - 视频建议判断“散户止损大概率聚集在哪儿”是第一步。通常止损会放在明显的结构高位/低位、前高/前低、日线/周线高低点等显著位置。
    - 其次，要观察价格是否出现假突破（fake breakout）：价格突破高位触发上方止损后未能持续上行，反而回落，这通常意味着先被吃掉的止损由聪明钱完成扫描，之后价格转向。
    - 做法：等待假突破后再布局——也就是不在初次突破时仓位进场（避免被首波扫掉），而是在确认“扫单”已发生、结构出现反转信号后再接入。
- 聪明钱的典型操作流程（根据视频描述整理为步骤）：
    1. 识别止损高度聚集的区域（如结构高点/低点、区间边界、日/周/月关键价位）。
    2. 推动价格去触碰这些区域以触发大量stop orders（这一步可由大资金主导，或自然成交推动达成）。
    3. 在止损被触发导致短时价格失衡时，迅速完成自身的入场或出场（例如在高位现价卖出，或在低位现价买入，具体方向取决于其意图）。
    4. 利用触发后形成的单边运动，继续推动价格到下一个流动性目标或进行反向获利退出。
- 对普通交易者的启示：
    - 主要是“不要在止损密集区盲目承接突破”，而是应学会等待价格扫单完毕并回归到有益结构（例如 order block、FB/FS、供需区）再寻找入场机会。
    - 视频多次提到聪明钱并不会急于在这些区域全部出手，而是等大部分散户止损被触发后再利用缺口进出，从而获得更高胜率与更好的风险回报比。

## 3.4 实战布局：时间框架、Order Block 与等待假突破（操作流程）

- 时间框架的层级思路：
    - 视频强调多时间框架（multi-timeframe）观察：从中期（例如日线或4小时）判定主要结构或关键高低位，再下钻到小时级或更短（例如30分钟、15分钟）去寻找具体的入场信号。核心想法是用高周期确定重要流动性池与结构，然后在低周期等待价格回撤或结构反转的具体进场点。
- Order Block 与 FVG（Fair Value Gap）等概念的结合：
    - 视频提到在上集学习的 order block（订单区块）能作为“聪明钱进场的常见位置”。当价格在更高周期结构上发生流动性扫描并回撤到 order block 或 FVG 区域，出现反转信号时可以考虑顺势建仓。
    - 举例流程：在中期图上识别到某个高位被击穿（可能是假突破），判断是否会形成流动性扫描；若判断会形成，则下钻到4小时或30分钟寻找 order block 或 FVG；当价格回到该 block 并出现结构转折或确认信号（例如K线形态、支撑阻力确认），则入场并把止损放在合理的结构外。
- 假突破等待法（核心实操要点整理为步骤）：
    1. 在高周期确定关键高位/低位及潜在止损聚集区。
    2. 观测价格是否出现突破并触发大量止损（注意不要立即追单）。
    3. 等待若干根K线确认（视频建议等待更多根K线，视时间框架而定，例如突破后等待几根4小时或小时K线的表现），若出现“假突破并回撤”或“流动性被扫完后结构反转”的迹象，则进入低周期寻找具体做单点。
    4. 在低周期确认 order block / FVG / 结构破坏后跟进开仓，止盈目标设在下一个流动性区域（liquidity pool），止损放在明显的结构外（以避免被无意义的波动扫掉）。
- 案例说明与纪律：
    - 视频举了多张图说明：有时价格突破后会继续上行并不回踩（这时可能是趋势延续，不能武断做反向）；有时会假突破并回到 order block 做出反转（这是做反向或顺势回撤的机会）。
    - 重要纪律：若判断不明确，可继续等待（例如等待更明显的流动性扫描或结构确认）。不要在不确定时加仓，避免成为被扫的对象。
- 风险管理与止盈设置：
    - 视频强调要知道流动性在哪，在何处布局加大风险/回报比（R:R）。例如在确认了某个流动性池被扫后，若布局正确可以把止损设相对小而止盈设在下一个流动性区，使RR优于1:2或更好（视频并未给出具体数值作为硬规定）。
- 补充说明：
    - 视频中使用了多个具体时间点与图表示例（如某些中期图、30分钟、15分钟的实际案例），这些具体图像在文本中无法逐帧还原，但步骤与原则在上文已被整理为可实际操作的流程。

## 3.5 高压力（High Pressure）与低压力（Low Pressure）流动性及其转换

- 什么是低压力流动性（Low Resistance / Low Pressure Liquidity）：
    - 视频描述此为“高位没被完全打破但形成更低的高点”（highs getting lower）时，图表上会出现某些高位成为“低压力流动性”区。通俗理解是：价格曾多次探及但未能形成强阻力、空方/多方意愿薄弱的区域，这类区域较容易被后续价格扫掉（被触及并且不提供足够的接盘），因此称之为低压力。
    - 价格通常会从“高压力流动性”走向“低压力流动性”，即从被“撕掉”（被扫描）的位置朝那些承受力较弱的位置发展。
- 什么是高压力流动性（High Pressure / High Resistance Liquidity）：
    - 高压力流动性通常指之前的买方或卖方流动性被扫之后，形成的一个“新的高阻力区域”。比如某处的买方流动性（Buy-Side Liquidity）被扫掉后，这个位置变成了高压力/高阻力，因为原有的流动性消失，市场在此再想突破或回到该价位需要更强的力量。
    - 换言之，某个区域的limit orders或stop orders在被消耗（被扫描）后，价格会在其上/下留下一段不平衡（imbalance），这些区域可视为新生成的“高压力”或“重要阻力/支撑”。
- 高压力与低压力之间的动态与实操含义：
    - 视频的结论是：价格会从高压力区走到低压力区，这个过程涉及止损被触发、限价单被吃掉以及结构被重塑。
    - 对交易者的意义：识别哪些区域是“低压力（容易被吃掉）”可以帮助判断价格是否会被扫；识别哪些区域是“高压力（被扫后形成阻力/支撑）”可以帮助判断什么时候趋势可能结束或反转。
- 实战判断与示例：
    - 举例：若在某段行情中，多个高点依次变低（higher highs 变为 lower highs），说明价格上方的供给在加强（或需求在减少），上方的流动性可能相对“低压力”，因此一旦被推动，价格会扫掉这些位置。
    - 视频给出的交易策略是：在确认某个区域被视为高压力或低压力之后，等待结构上的破坏或回测，再结合 order block / FVG 等确认入场点。例如在低压力位被逐个吃掉后，若价格形成新的高压力位置并被突破且回测成功，则可以顺势进场做多或做空（视方向）。
- 总结性观点：
    - 高压力/低压力并非固定属性，而是随着扫单（liquidity scans）与结构变化而相互转换。理解这种动态转换能帮助交易者判断“哪里会被扫”、“哪个位置适合等待反向布局”以及“怎样设止损/止盈更合理”。

# 4. 框架 & 心智模型（Framework & Mindset）

- 总体心智模型：把市场看成由订单构成的生态系统，价格是订单撮合的结果。关键在于识别哪里有“可被吃掉的订单”（stop orders clusters / limit orders scarcity），并据此判断短期内价格会如何移动。这个心智模型要求交易者从“人群行为与订单位置”的角度而非单纯的K线图形或指标来观察市场。
- 具体框架（分步骤详述，方便实战应用）：
    1. 上位结构识别（高周期定位）
        - 目标：在日线/4小时/周线等高周期上识别显著的高点与低点、区间边界、前高前低、以及重要的支撑阻力。
        - 为什么：高周期的结构定义了主要的流动性池（大多数散户更倾向于在这些显著位置放止损/止盈）。
    2. 流动性密集区预判
        - 目标：判断散户止损最可能聚集在哪里（通常在明显的高点/低点、结构边界、前高/前低、昨日/上周高低点等）。
        - 为什么：这些位置一旦被触及就可能引发大量 stop orders 的触发，为聪明钱提供可利用的“流动性”。
    3. 不追突破，等待“扫单”完成（耐心等待）
        - 操作思维：当价格接近这些关键区位时不要急于追进突破。先观察是否出现假突破（即扫掉止损却未能持续），或者等待几根K线确认是否为真正突破。
        - 为什么：许多亏损来自在市场被聪明钱利用时仓位过早进入，成为被吃掉的对象。
    4. 下钻低周期寻找具体入场（精确化入场点）
        - 目标：在小时/30分钟/15分钟级别寻找 order block、FVG（Fair Value Gap）或结构破坏与回测等具体信号作为入场点。
        - 操作细节：当确认高周期的流动性被扫或假突破成立后，下钻观察是否有明显的“smart money 进场痕迹”（例如密集的现价成交、迅速回抽到 order block 并反转）。
    5. 风险管理（止损与目标设定）
        - 止损：放在结构外、能容纳合理波动但不会被随意扫掉的位置（例如低周期的结构外），并考虑止损本身会被视为流动性的可能性。
        - 目标：以下一个流动性池或明显的结构高低点作为止盈目标，追求合理的风险回报比（例如不低于1:2，视频没有给绝对数值，但强调RR要优）。
    6. 复核与纪律执行
        - 在任何入场前复核是否符合“高周期识别→流动性预判→假突破确认→低周期确认”的流程。若其中任何一步不满足，则放弃或延后交易。
        - 为什么：纪律化执行能防止因情绪而在不利位置入场，减少被扫单的概率。
- 心态层面的要求（Mindset）：
    - 耐心：许多最佳的交易机会来自等待“扫单”完成并在结构确立后进场。短期的波动与假突破是常态，耐心胜过频繁交易。
    - 逆向思维：不要盲目和散户择点同向下单（即在显著止损池附近冲动追突破）。要学会站在“聪明钱”的角度去思考：他们会在哪里寻找流动性？会如何触发并利用这些流动性？
    - 风险意识：理解止损既是防守工具，也可能成为被人利用的流动性源。设置止损时既要防范大损失，又要避免因过小止损而被常规波动扫掉。
    - 学习与复盘：多看图、多复盘那些被扫单与假突破的案例，训练识别止损聚集区和order block的能力。
- 实战检验与注意事项：
    - 框架本身基于对订单流与图形的推断（作者未提供直接的订单簿数据），因此仍具有一定的不确定性。交易者应在小仓位或模拟账户中验证策略并逐步放大。
    - 市场并非总按规则运行：有时突破会持续，或流动性结构在极端新闻/事件下被重塑。因此框架应与风险管理、资金管理配合使用。
    - 不要过度依赖单一信号：将流动性分析与结构、order block、价格行为等多重信号结合，提高成功概率。
- 总结一句话的心智模型：把市场看成订单的“供需匹配场”，聪明钱通过扫描并触发散户的止损来制造可利用的流动性。我们的任务是识别流动性在哪儿、等待扫单发生后在合理的低周期位置加入，严格执行止损与资金管理。

# 总结

本视频核心在于教你如何识别图表上潜在的流动性池（主要是散户的止损聚集区）、理解不同订单（市价单、限价单、突破/止入单）的本质，并用“等待假突破/流动性扫描完成后再布局”的方法减少被扫单的风险。实战上要结合多时间框架（从中期到短期）、order block 与 FVG 等工具去精确找点，并配合严格的止损与止盈规则。视频强调的心智模型是：市场由订单驱动，聪明钱会利用这些订单制造行情，懂得等待和识别这种行为的交易者将更容易获得稳定收益。
