# 2. Overview

本期视频围绕 ICT（Inner Circle Trader）体系展开，先回答了“ICT 是不是骗子？他的系统是否可用？”的疑问，然后介绍并示范了一个可重复的入场模型：在明显下跌趋势中，等待“结构破坏（structure break）”以强动能突破低位后，寻找价格回调到高概率入场区域（如 PD Array 的 50% 以下、FEG、Order Block、FVG 等），并以大级别的买/卖方流动性（Buy-Side/Sell-Side Liquidity）或前高前低作为止盈目标。视频同时详细说明了需要的图表工具与时间窗（亚洲、伦敦、纽约时段），并通过多个实盘例子展示如何判定、挂单或现价进场与止损止盈布置。结论是：ICT 的很多概念源自传统价格行为、道氏理论与韦科夫（Wyckoff）等学说，但经过整理后形成一套可操作的系统；若严格遵守每个条件与步骤，能得到高盈亏比的交易机会。

# 3. 按照主题来梳理

## 3.1 ICT 系统的定位与可行性

- 视频一开始回答了观众普遍关心的问题：“ICT 是不是骗术？他的交易系统能不能用？”讲者的结论是，ICT 并非单纯的新发明者，也不是什么骗人的快速致富把戏。ICT 的很多要素其实是把多种传统交易理论（例如价格行为、道氏理论（Dow Theory）、威科夫理论（Wyckoff Theory）等）混合并用自己的叙述方式重新包装成一个故事化的教学系统。因此，ICT 的系统并非凭空产生的新神话，而是把历史上已存在的有效概念整理、命名并系统化，便于传播和教学。
- 讲者指出，系统本身“没有问题而且蛮厉害的”。他还举了一个支持性证据：他的一个朋友（曾在 Goldman Sachs 学过交易）也在实战中采用了 ICT 的概念并结合个人经验管理资金，取得了可行的交易操作。这一块是用来回应怀疑者的合理顾虑，说明理论是否“可用”还需要结合严格执行、风险管理与个人经验。
- 视频强调一个重要观念：不要盲信标签式的褒贬。ICT 的教学里有价值的核心是“价格结构+流动性+动能”的判断，这些是许多传统理论都在强调的点。ICT 的特殊之处在于把这些元素以一套可辨认的术语（例如 Order Block、FEG、FVG、PD Array 等）和操作流程串起来。
- 进一步的隐含建议是：系统是否有效，不在于名字，而在于是否能够被严格记录、重复执行并长期经营。讲者建议观众把每个步骤写成清单、在真实交易中日复一日地执行，从长期累计结果来评估系统有效性。
- 最后，讲者点明了视频目标：把之前学到的工具整合，教会观众“如何每天找到高质量、提供大盈亏比（risk-reward ratio）且步骤明确的交易机会”。因此，判断一个体系可不可靠的方式是：把它的每一个条件、每一个步骤都落实到实盘的交易计划和风险控制中，而不是听信网络上片段化的评价。

## 3.2 入场模型：从趋势到结构破坏再到入场区域（详细步骤）

- 总体模型概述：当市场处于下跌趋势时，价格会跌到某个支撑位置（视频称为 Sell-Side Liquidity 或 支撑位置），出现表面反转后，有许多人会匆忙进场做多，期待“反转”。这些早入场者常赚一点后被新的下跌动能打穿低位而被止损，或在结构被破坏后陷入混乱。因此，不要在表面回弹处追多，而是要等待明确的结构破坏并以强动能突破为前提，然后寻找回撤到良好入场区域再做多。
- 步骤 1：确认趋势与关键位置
    - 先确认大方向（例：下跌趋势），关注近期低位与高位是否不断被刷新（若低位不断被突破且高位未被触及，则趋势仍然是下跌，引用道氏理论规则）。
    - 标注重要的买方/卖方流动性位置（Buy-Side/Sell-Side Liquidity），以及大级别的高低位（昨日、上周、上月的大级别高低位）。这些位置作为日后止盈或关键判断点。
- 步骤 2：等待“结构破坏（structure break）”并要求“强动能”
    - 并非任何突破都有效，必须是“强动能的突破（strong momentum break）”。若突破呈现低动能（slow, lack of conviction），则很可能是假突破或价格会再回到原趋势。只有当突破伴随明显放量或快速猛烈的价格移动，才能被认定为值得信赖的结构破坏。
    - 一旦观察到强动能突破前高（若从下跌转为上涨）或突破前低（若从上涨转为下跌），就可以认为趋势可能已改变或至少出现结构转换（structure change）。
- 步骤 3：定位高概率入场区域（PD Array 的 50% 以下、FEG、Order Block、FVG 等）
    - 以 PD Array（视频所称的 PDarray）从低位到高位间的 50% 以下区域作为“便宜价格”区间，即首选入场范围。
    - 在该区间进一步寻找：FEG（Fair Value Gap，价值缺口）、Order Block（机构订单区块）、FVG（同为价值差距）等结构化不连续区间，这些区域常是机构回补订单与流动性聚集区，具有较高的概率吸引价格回撤并发生反转。
    - 可选择两种进场方式：① 挂单（预设限价单等待价格触及）或 ② 等待价格真实回探并在触及关键区域后现价进场（市价）。
- 步骤 4：止损与止盈设置
    - 止损（Stop Loss）位置建议放在入场所参考的 Order Block 之外，视频中示范为离开 Order Block 大约 5-10 个点为安全距离，或直接设置为离开整个结构转换位置（U 转位置）之外。
    - 止盈（Take Profit）建议放在下一重要的 Buy-Side Liquidity 或主力位置，也就是前述标注的大级别高地（例如昨日/上周/上月的高位）。这些大级别的价位通常有较强的作用力，适合作为目标位。
- 步骤 5：盈亏比与仓位管理
    - 视频中多个示例展示了高盈亏比的实际数值：像 1:8、1:7、1:2.4 等，说明若严格等待条件则单笔交易可获得高风险回报比。
    - 但同时也提醒：并非每次都能命中入场区域或达到目标，因此仍需保有交易偏向与持续寻找下一次机会的心态。总体强调长期执行与复利效果才是系统有效性的关键。

## 3.3 图表设置、工具与时间窗（实操准备）

- 必备工具与指标概述：
    - HiLo Yesterday/LastWeek/LastMonth 工具：用于自动绘制昨日、上周、上月的高点与低点。视频中作者用不同线型与颜色区分：昨日高低位用黑色虚线（点点线），上周高低位用红色实线，上月高低位用蓝色实线。目的在于一眼识别这些大级别高低位与现价的距离，从而评估潜在的止盈位或关键阻力/支撑。
    - ICT Killzone and Pivot（ICT Killzone 与枢轴时段工具）：用于标注重要的交易时段（亚洲盘、伦敦盘、纽约盘）以及相应的高低位。这些时段依据纽约时间标注，视频作者常以纽约时间区分：例如纽约晚上 8 点到凌晨 12 点、纽约凌晨 2 点到凌晨 5 点、纽约 9 点半到 11 点之间的关键时段。作者本人会从纽约时间 8 点开始看盘至 11 点，认为这段时间的高低位常是 Buy-Side/Sell-Side Liquidity 的重要来源。
    - Watermark（图表水印）：作者在视频中提到在图表上加上“交易轮交易班”的水印，作为推广提示（此处为视频的频道/课程广告指示，按规定本次文本忽略广告内容）。
- 如何配置与使用这些工具（步骤式说明）：
    - 第一步：在你的图表软件上安装/启用 HiLo yesterday/lastweek/lastmonth 工具，并把线型颜色分别设置好，确保能在任意时段清晰看到昨日/上周/上月的大级别高低位。
    - 第二步：启用 ICT Killzone & Pivot 工具，设置时区为纽约时间（或根据你关注的市场时区），并选择要显示的盘别（亚洲、伦敦、纽约）。这些 Killzone 的高低位将作为潜在的 Buy-Side/Sell-Side 流动性来源。
    - 第三步：在日内交易时先观察这些标注的支撑/阻力与价格的相对位置，把这些点作为未来止盈/止损、或入场参考。
    - 第四步：在实际交易前，先在较低时间框架（如 3 分钟、5 分钟）和较高时间框架（如 1 小时、4 小时）切换，确认结构破坏是否伴随强动能，以及在 PD Array 50% 区域是否存在 Order Block / FVG / FEG。
- 时间窗的重要性与解释：
    - 作者重视各盘时段的高低位，因为不同盘区的“主力活动”不同，亚洲盘/伦敦盘/纽约盘的高低点往往能成为什么时候主力会出现回补或清洗流动性的关键位置。举例：亚洲盘高低位在伦敦开盘被突破后，价格回撤触及亚洲盘关键位就可能发生机构订单反应或大幅波动。
    - 因此，把这些时段的高低位放在图上能帮助交易者在结构破坏后更快定位合适的入场与止盈目标，减少无谓的猜测。

## 3.4 多个实盘例子逐笔解析（如何在实战中套用模型）

- 示例一（上个星期的例子）要点解析：
    - 描述：作者在五分钟图上看到价格以强动能跌破昨日第一位（黑色点点线，例为星期四的高低）。价格并非先回探再下，而是提前反转后直接破低，这导致许多想“早做多”的人被打掉止损。随后价格出现强动能的上攻突破前高（三个结构被打破），形成结构转换（structure change）。
    - 操作判断：当出现强动能突破并形成结构转换之后，作者确认转为“要做多”的局面，但不是马上追高，而是寻找 PD Array 50% 以下（便宜区域）、同时查看是否存在 FVG、Order Block 等作为入场区域。视频中指出某个 FVG 已被碰触过，因此失去价值，转而选择旁边另一个尚未被触及的区域作为高概率入场点。
    - 入场方式与风控：作者选择等待价格回落并在某根 K 线触及该区域时进场（现价入场），止损设在离开 Order Block 大约 5-10 点的位置（示例中约 10 个点），止盈设到昨日的高位，最终给出 1:8 的盈亏比（risk-reward）。该笔交易在数小时内完成。
- 示例二（伦敦盘突破亚洲盘高位后的回撤）要点解析：
    - 描述：价格在伦敦盘突破了亚洲盘的高位，但并未持续上涨，反而出现回落触及某个位置后再次下跌，形成结构转换（原来的支撑成为阻力）。此后可在更小时间框架（如 3 分钟）找出 Order Block 并等待回撤触及。
    - 操作方法：作者讲两种操作：一是挂单（在目标区域预先设置限价单），二是等价格真实触及再现价进场。止损同样放在 Order Block 之外，止盈点可设在亚洲盘的低位（示例给出盈亏比约 1:2.4），并指出实际在数小时内即触及目标。
- 示例三（黄金的一周例子）要点解析：
    - 描述：上周五黄金在亚洲盘做了假突破然后出现结构破坏，作者根据此判断做空的偏向，并在 PD Array 或更小时间框架找 Order Block/FVG 入场。视频指出个别笔交易会亏损（即使盈亏比大，也并非每笔都命中），但系统长期执行仍有正收益。
    - 操作与风控：入场后把指引点（或目标）放在亚洲盘的最低位，有时一笔交易的止损会吃掉但无需因此恐惧，寻找下一个机会继续执行规则。作者强调在某个漂亮的例子中，一笔 1:7 的盈亏比在不到 7 小时内完成，显示严格执行条件下系统可生成高收益笔。
- 结论性观察与实战建议：
    - 每一个举例都反复强调两点：一是“必须等待每个交易条件成型（结构破坏、强动能、回撤到高概率区域）”；二是“要严格执行止损与止盈位置，不要凭感觉追单”。
    - 作者还多次提醒：不要因为单笔失败而放弃规则，长期日复一日的重复执行才会显现资金增长（复利）与生活质量的改善。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：结构化入场框架（Structure-based Entry Framework）
    - 核心思想：不追随表面回弹，而是等待结构的明确破坏与强动能确认，然后在有“机构订单痕迹”的高概率回撤区域入场。这个框架把“趋势判断、结构破坏、动能验证、高概率回撤区、止损/止盈”这些元素串成一套可执行步骤。
    - 详细步骤说明：
        1. 趋势与大级别定位：在高时间框架（例如 1 小时或更高）上确认主要趋势（上涨/下跌），并标注大级别支撑/阻力（昨日/上周/上月高低）。
        2. 监测结构破坏：在日内较低时间框架（例如 5 分钟）上关注是否出现强动能突破（例如快速、单向大幅移动）破坏前结构（如前高或前低）。确认“强动能”是关键——若突破缓慢、无力度，则为假信号。
        3. 定位回撤高概率区：在 PD Array 的 50% 以下区域寻找 FEG（Fair Equity Gap / FVG）、Order Block（机构订单区块）或其他 ICT 定义的入场区，这些是价格回撤常被清洗与回补的位置。
        4. 选择入场方式：可挂单（限价）或等待触及后现价入场。两者各有风险：挂单能保证入场价格但可能未触发；现价进入保证参与但价格可能偏差。
        5. 风控布置：止损放在 Order Block 之外或整个结构转换位置之外（示例中多为离开 Order Block 5-10 点）。止盈放在下一重要 Buy/Sell-Side Liquidity（例如昨日/上周/上月高位）。
        6. 复盘与持续优化：每笔交易建立交易日志，记录入场理由、时间段（Killzone）、是否满足强动能、入场方式、止损与止盈位置以及最终结果。长期根据统计数据调整但不随单笔情绪更改规则。
    - 应用原则与限制说明：
        - 强调“强动能才可信”的原则：只有在强动能突破下，结构破坏才具操作价值；低动能破位常为陷阱。
        - 大级别高低位重量更大：不要把单根 K 线或小级别高低位视作主要目标或支撑，作者反复强调要以亚洲/伦敦/纽约盘或昨日/上周/上月的高低位为参考。
        - 时间成本与耐心：该框架要求耐心等待条件成熟，因此不适合追求频繁进出的短线冲动交易者。长期执行与纪律性是框架成功的关键。
- 心智模型二：纪律、概率与长期经营的心态（Discipline, Probability & Long-term Operation Mindset）
    - 核心观点：交易是概率游戏而非确定性预测。每一次交易只是以概率站队而非百分百确定性押注。必须用纪律与风险控制来把长期胜率与盈亏比结合，从而获得长期正期望（positive expectancy）。
    - 详细构成要点：
        1. 接受不确定性：任何一次交易都可能失败；因此不要在单笔失败后情绪化调整规则。作者在视频中示例某些交易亏损但接着又能在下一个机会获得高盈亏比回报。
        2. 固守交易清单（checklist）：在每次交易前逐项核对规则（趋势判断、结构破坏是否为强动能、入场区域、止损位置、止盈目标、时间窗是否合适等）。把这些条目写成纸本清单并严格遵守。
        3. 风险与仓位管理：止损设置要合理，控制每笔风险占账户的比例，避免因单笔爆仓而破坏长期复利计划。视频示范止损往往放在 Order Block 之外 5-10 点，以量化风险。
        4. 统计化思维：长期记录并统计每种信号的命中率、盈亏比与持仓时间，依据数据优化但不随单笔结果改变总体策略。作者强调“长期经营下来，一套规则加日复一日的执行，资金会慢慢变多”，这正是复利与概率思维的体现。
        5. 情绪控制与耐心：等待完备条件需要耐心，不要因为错过一次价格而盲目追进。另一方面，一旦条件满足，应果断执行计划（无论是挂单或现价）。
    - 实际心理策略建议：
        - 把每次交易看作“执行规则的实验”，而非个人能力的证明或否定。
        - 制定每日/每周的操作时间段（例如作者从纽约时间 8 点到 11 点为重点看盘段），避免全天无序盯盘导致情绪消耗。
        - 定期停手复盘：如果连续若干笔出现偏离应暂停并复盘原因，而不是继续在情绪状态下强行交易。

# 总结

本集核心在于把 ICT 的一套概念化、结构化并给出可执行的日内入场模型：在趋势中不追随表面反弹，而是等待强动能导致的结构破坏，然后在 PD Array 的 50% 以下与 FEG/Order Block/FVG 等高概率回撤区入场，止损放在区块之外，止盈瞄准大级别的 Buy/Sell-Side Liquidity。关键要点包括：只信高动能的结构破坏、使用昨日/上周/上月高低位与亚洲/伦敦/纽约时段作为参考、严格的入场/止损/止盈规则，以及长期的纪律与统计化心态。作者认为 ICT 体系并非空洞，源自多家传统理论并经整理后可操作；但成功仍依赖于重复执行、风险管理与耐心。
