# 3. 按照主题来梳理

## 3.1 RSI 的基本介绍

- RSI（相对强弱指标，Relative Strength Index）是一个用于测量股价动能的技术指标，数值范围固定在0到100之间。无论股价如何剧烈波动，RSI的读数永远不会超出这个区间，因此它提供了一个规范化的动能视角。
- 常用阈值包括50、70、30三条重要参照线：当RSI在50或以上时，通常被视为上升趋势（bullish）；当RSI在50以下时，则被视为下降趋势（bearish）。更进一步，RSI达到或超过70被传统上认为处于“超买”区（意即价格相对偏贵，可能面临回调压力）；而RSI降至或低于30则被认为处于“超卖”区（意即价格相对便宜，可能存在反弹机会）。
- 指标的构成逻辑（视频未详尽计算公式，此处仅保留原意不新增事实）：RSI通过比较一定期间内上涨与下跌幅度的平均值来衡量动能的强弱，因此RSI较为敏感于价格的短期加速或减速。50线为中性分界，70/30则为过度扩张或收缩的直观判定点。
- 使用时的基本观念：RSI并非直接给出买入或卖出信号，而是帮助交易者判断当前价格是处于“被高估”还是“被低估”的状态，并提供动能强弱的参考。高RSI不必然马上回调，低RSI也不必然马上反弹；动能延续的可能性存在，因此必须结合趋势结构与价位确认。
- 实务提示：因为RSI数值固定且界定明确，它适合用于比较相同工具不同时间段的动能，或作为多指标体系中的一环。但单凭RSI阈值进行交易有明显风险，需要配合趋势判断与关键价位来提高准确性。

## 3.2 RSI 大部分人的用法以及它的缺点

- 大众化的RSI用法非常直观：当RSI进入“超买”（≥70）区，就卖出或做空；当RSI进入“超卖”（≤30）区，就买入或做多。这种基于70/30阈值的反向操作逻辑在教育内容与网络文章中被广泛传播，但视频指出这种方法存在严重缺陷，导致胜率低、信号不可靠。
- 缺陷一：趋势中RSI长时间保持极端值。举例说明：在明显的下跌趋势中，RSI可能长期处于“超卖”区（低于30），但价格仍持续下跌；相反，在持续的上升趋势中，RSI可能长时间在“超买”区（高于70），价格照样继续上行。因此，当交易者仅凭RSI触及70/30就反向交易，会经常在趋势持续时被套或止损。
- 缺陷二：没有价位与趋势结构确认。RSI只是动能指标，不包含支撑阻力或趋势线等价格结构信息。若不结合关键价位（如趋势线、支撑/阻力、均线等）作确认，RSI信号容易成为“误导信号”，尤其在主力与散户力量不对称时。
- 缺陷三：对不同市场环境敏感度不同。RSI在横盘震荡市中，70/30回转交易可能较有效；但在趋势市中，反向操作代价极高。视频通过示例指出，传统方法无法区分趋势延续与转折的强弱，直接导致低胜率。
- 实务结论：因此，仅靠RSI的超买/超卖阈值进行买卖是不可取的。更有效的做法是将RSI用于识别动能变化（尤其是背离），并结合价格结构或多时间级别确认来过滤信号，降低被趋势“欺骗”的概率。

## 3.3 RSI 背离的完整教学（分类、定义、原理与判读）

- RSI背离的核心定义：当价格（股价高低点）与RSI指标的走势出现不一致（分歧）时，称为RSI背离（divergence）。这种分歧暗示动能正在发生变化，可能预示趋势转变或趋势延续的概率提高。视频将背离分为两大类：趋势转变的背离（reversal divergences）与趋势延续的背离（continuation divergences），每类又细分为顶背离（bearish/top divergence）与底背离（bullish/bottom divergence）两种形态。
- 趋势转变类——顶背离（Top / Bearish Divergence）：
    - 形态特征：处于上升趋势时，价格形成更高的高点（高点比前一个高），但RSI同时形成更低的高点（高点低于前一个高）。即价格继续创新高但动能并未跟随，显示上涨动能减弱。
    - 原理与意义：价格创高而动能不创高，表明买方推动价格上升的力度不足，潜在主力吸筹或散户推动的买盘无法持续支撑更高价位。因此顶背离通常预示上升趋势可能反转向下，后市看跌概率增加。
    - 判读要点：单次顶背离并不意味着立刻反转，需要结合关键价位（如趋势线、前高、均线）来确认。若价格随后跌破重要结构，背离的有效性才得到验证。
- 趋势转变类——底背离（Bottom / Bullish Divergence）：
    - 形态特征：处于下降趋势时，价格形成更低的低点（低点比前一个低），但RSI形成更高的低点（低点高于前一个低）。即价格创低但动能开始回升。
    - 原理与意义：下跌过程中出现底背离，暗示卖压减弱或买家开始介入，动能不再支撑进一步下探，后市反转向上可能性增大。
    - 判读要点：同样要等待价格结构确认（如跌势被打破、形成底部结构或突破下降趋势线）以确认背离有效性。
- 趋势延续类——上升趋势中的背离（Bullish Continuation Divergence）：
    - 形态特征：在上升趋势中，价格低点一个比一个高（高低点序列），但RSI却出现低点低于前一个低点（出现底底低）。也可能看到RSI高点没有创新高，而是呈现下跌，但价格结构仍显示上升架构。
    - 原理与意义：虽然RSI显示短期卖压增加（动能出现疲软），但卖压力度不足以打破价格的上升结构（低点仍被维持或抬高），说明主力仍在支撑上升趋势，抛售多为短线散户，趋势大概率延续向上。
    - 判读要点：这种背离提示的是“修正而非反转”，交易者可视为上升趋势的临时回调信号，若价位结构未被破坏，可继续顺势持有或择机加仓。
- 趋势延续类——下跌趋势中的背离（Bearish Continuation Divergence）：
    - 形态特征：在下降趋势中，价格高点一个比一个低且低点也持续创新低，但RSI的高点比前一个高（出现顶顶高）。即局部买盘虽然出现但不足以扭转下跌结构。
    - 原理与意义：此时短期买力存在但不足以形成更高的高点，代表买方为散户或短线干预，主力仍占优势，下跌趋势大概率会继续。
    - 判读要点：把这种背离当作趋势继续的确认信号，除非关键支撑被突破或有更强的反转证据，否则继续保持空头方向更为稳妥。
- 综合判读方法与注意事项：
    - 背离本身是动能指标发出的“可能性信号”，必须结合价格结构（高低点序列、趋势线、支撑阻力、形态等）来确认有效性。
    - 背离分两个层次：提示趋势“可能要变”或“可能只是回调”。判断依据为：价格是否形成结构性反转（如形成底底低/顶顶高架构被破坏）；若结构未被破坏，则多半是延续类背离。
    - 多时间级别观察：大级别背离暗示大概率方向性改变，但需到小级别寻找入场点与确认；小级别背离若与大级别方向一致，胜率更高。

## 3.4 三大 RSI 最高胜率的交易策略（逐一步骤与判定）

- 策略一：RSI背离 + 关键价位（单时间级别确认）
    - 策略概述：在主趋势中发现RSI背离后，不立即进场，而是等待价格突破或失守事先画好的关键价位（如趋势线、支撑/阻力线、均线等）以确认趋势反转或延续，从而形成双重确认后入场。
    - 具体步骤：
        1. 在当前时间框架（例如小时图或日图）辨识趋势结构（上升或下降），并标注高低点形成的架构（顶顶高/底底高或顶顶低/底底低）。
        2. 识别RSI是否出现背离（顶背离或底背离）。记录背离发生的两个高点或低点的位置与价格结构。
        3. 画出关键价位：上升趋势画支撑或趋势线；下降趋势画阻力或趋势线；也可以使用重要均线（例：20日均线）或明显支撑/阻力区域。
        4. 等待价格行为确认：如果是顶背离，等待价格跌破上升趋势线或形成低于前低点的“底底低”结构后再进空；如果是底背离，等待价格突破下降趋势线或形成高于前高点的结构后再进多。
        5. 风控与出场：以被突破的关键结构为参考位设止损（例如突破后回抽失败处），并依据目标价位或风险报酬比设定止盈。
    - 要点：只在RSI背离与关键价位同时具备的情况下进场，避免单凭背离交易。
- 策略二：大时间级别关键价位 + 小时间级别RSI背离 + 小时间级别关键价位（多级别价位与背离确认）
    - 策略概述：先在大时间级别（天图或周图）标注关键价位（长期趋势线或阻力/支撑区域），当价格回到该区域时，下钻到小时间级别（例如1小时、15分钟）寻找RSI背离与小级别关键价位的配合，从而找到精确入场点并获得三重确认。
    - 具体步骤：
        1. 在大级别图（例如日线或4小时）识别并标注长期关键价位（如长期上升趋势线、重要阻力或均线）。
        2. 等待价格回撤至该大级别关键位附近，此时不要着急进场，切换到更低级别图表（小时图或15分钟）。
        3. 在小级别图上寻找RSI背离（例如顶背离或底背离），同时画出小级别的趋势线或支撑/阻力作为短线关键价位。
        4. 等待小级别价格破位（若空头：跌破小级别趋势线/支撑并形成底底低；若多头：突破并形成顶顶高），以确认小级别背离有效。
        5. 在三重确认（大级别关键位+小级别RSI背离+小级别关键价位破位）之后入场，并设置合适止损与目标位。
    - 要点：多级别配合可以显著过滤假信号，提高成功率；交易者需耐心等待小级别的价格行为信号。
- 策略三：大时间级别RSI背离 + 小时间级别RSI背离 + 关键价位（双重背离确认）
    - 策略概述：当大时间级别（周/日）出现RSI背离，提示高概率趋势疲弱或将反转，但单靠大级别无法精准入场；因此下钻到小级别找相同方向的RSI背离并配合关键价位确认，两级背离同时成立时进场，胜率更高。
    - 具体步骤：
        1. 在大时间级别确认RSI背离（例如周图或日图顶背离），将其作为“潜在趋势反转”的信号来源。
        2. 下到小时间级别（例如日图到4小时，或4小时到1小时），寻找与大级别方向一致的RSI背离（即小级别也出现顶背离或底背离）。
        3. 同时在小级别图上画出关键价位（趋势线、20日均线、头肩顶/底形态的颈线等）。
        4. 等待价格在小级别打破关键价位并形成符合趋势反转的价格结构（例如跌破上升趋势线并形成底底低，或突破支撑并形成顶顶高），以确认双重背离的有效性。
        5. 在确认后入场，设置止损于关键价位外侧，止盈依据大级别结构或预期回调/反弹幅度。
    - 要点：双重背离配合关键价位是极强的确认架构，适用于重要大级别趋势的反转交易；但因等待时间长且机会稀少，需耐心和仓位管理。
