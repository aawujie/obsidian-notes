# 3. 按照主题来梳理

## 3.1 ICT 的定位与本质（Inner Circle Trader）

- ICT 的全名是 Inner Circle Trader（内圈交易者），由 Michael Hatterstown 创立。ICT 的核心思想是市场由大型资金（机构、聪明钱）主导，而非散户。视频反复强调，理解机构背后的思路与行为，能够帮助交易者更精准地判断价格走向、入场位置、止损与出场，从而实现稳定获利。
- 对比“价格行为”（Price Action）：作者 Alan 一直以价格行为为中心，其系统围绕价格行为设计。起初他觉得 ICT 词汇复杂、难懂，但深入研究后发现 ICT 的本质仍是价格行为，只是以更具故事性与逻辑性的框架把市场运作讲清楚。ICT 提供了一套解释价格如何被“输送”（price delivery）到市场各位置的体系，这套体系名为 PDArray（Premium/Discount Array）。
- ICT 的价值：视频指出很多交易员因断章取义学习 ICT 某些策略却无法获利，问题不在于 ICT 无效，而在于没有学完整框架。ICT 吸引众多学员，是因为其在很多人身上确实帮助实现稳定盈利；但要从“看几支影片”到真正能用，需要系统化学习与练习。
- 本集放置在更大教学计划中的角色：这是完整版系列的第一集，后续将按部就班讲解流动性区域、市场结构（Market Profile and Structure）、日内/周线轮廓、诱导与陷阱、反转形态（AMD、CISD、MSS 等结构转换）、海归汤形态、时段策略（亚洲、伦敦、纽约的特定波动）、以及 ICT 的“杀戮时段”与营盘（maker）策略。作者也提供相关线上课程并鼓励订阅频道与加入等候名单。

## 3.2 PDArray（Premium / Discount Array）的定义与实战意义

- PDArray 的基本概念：PD 是 Premium（高价区）与 Discount（低价区）的缩写。PDArray 描述的是价格在某一波段内的输送与分布，核心思想是把整段波动用“50%”作为分界线：从波段低点到高点，超过 50% 的区域被视为“较贵”（P 区），低于 50% 的区域被视为“较便宜”（D 区）。ICT 理论里“聪明钱”通常在高价（P）做空、在低价（D）做多，或在低位累积头寸、在高位分配头寸（高位卖出、低位买入）。
- PDArray 的实战用途：PDArray 可作为一张入场前的“清单”，帮助判断当前价格是否值得入场，避免追涨杀跌。举例：在上升波段，如果价格回撤至波段的 50% 以下，这被视为“便宜区”，优先寻找做多机会；若价格位于 50% 以上，则偏向寻找做空机会或等待更优价位。
- 结合时间框架（Multi-timeframe）：视频强调要在较大时空（如日线或周线）确认 PDArray 的位置，然后在较小时空（小时、15 分）找具体的结构与入场信号。PDArray 是宏观判断的起点，具体的 orderblock、FVG 等工具用于微调入场位与止损/目标。
- 注意与心态：PDArray 帮你设定入场“阈值”——只是因为某个 FVG 存在并不代表可以随时入场，若该 FVG 位于 P 区（较贵）则 ICT 学习者会选择忽略，等待 D 区 的 FVG 或结构确认。作者强调纪律：不盲目追单，若理想位未被触及就放弃，等待下一次机会是成熟交易者的行为。

## 3.3 订单块（Order Block）详解与确认条件

- Order Block 的定义：订单块是机构（聪明钱）下单并引起价格反转或延续的起点区域。多头订单块通常为动能上涨前的最后一根牛 K 线（强阳线），并且要“完全吞噬”前一根熊 K（即实体与影线覆盖）；空头订单块则相反，是动能下跌前吞噬前一根牛 K 的强阴线。画法上常从该 K 线的低影线画到高影线，形成一个区域作为 order block。
- 确认条件（多要素验证）：作者强调不要单纯在某个框上画订单块就用。有效的 order block 通常需要在更高时框（例如小时或四小时）看到：
    - 结构转换（structure change）：趋势从上升转为下跌或反之，即高低点或低高点的切换。
    - 失衡（imbalance）：价格出现加速移动或强力推动的 K 线，体现出供需不对称（有未被触发的订单）。
    - 完全吞噬（engulfing）：形成 order block 的 K 线需完全吞没前一根相对 K 线（包括影线）。
    - 在小时级别确认可以提高成功率：例如作者举例用 4 小时图或 1 小时图观察，看到强 K（快速上升）且之前有横盘，再出现加速向上并完成结构转换，即可标注为 order block。
- 实战流程（简化步骤）：
    - 在高时框（如日线/4H）标注大波段，找到可能的 order block 区域（完全吞噬 K）。
    - 回到小时或更小时框确认失衡、加速 K 线或结构转换存在。
    - 等价格回撤并触及该 order block 区域，同时寻找额外确认（例如 FVG、拒绝块、成交量反应等）再进场。
    - 设置合理止损（超出 order block 区域）与目标（前一结构或多倍盈亏比）。
- 举例说明：作者在图中展示了一个熊吞阳（阴吞羊）的例子，形成 order block 后价格在四天后回到该区域并出现大幅下跌，说明高时间框的 order block 可以提供多日级别的交易机会，实现高盈亏比。

## 3.4 Breaker Block（破坏块）与流动性猎杀的逻辑

- Breaker Block 的定义：破坏块，又称 Breaker Block，是指原本的 order block 被突破并转化为反向的供应/需求区后形成的反向单块。其逻辑是“原先的支撑/阻力被破坏后，变成了阻力/支撑”，是反向主导的一类定单块，常伴随流动性猎杀（liquidity hunt）。
- 形成条件（关键要素）：
    - 有明确的 order block 存在（原始供需区）。
    - 出现“猎杀”（liquidity hunt）：长引线或彻底吞噬前一重要结构，扫掉上方/下方的止损位，触发盘面大量流动性。
    - 价格实体现收盘突破该 order block（closing price breaks the block），并伴随结构转换（新的高低点或低高点成立）。
    - 达成上述后，该被突破区域即成为 Breaker Block，交易者可以依据此做反向交易（与原趋势方向相反）。
- 实战判断与操作流程：
    - 发现上升趋势末端的 order block，观察是否有“第五浪”式的动能尾端（即动能衰竭迹象）。
    - 等待猎杀（强力吞噬，长影线），并确认收盘价突破该 order block、结构转换成立。
    - 价格回补到该被突破区（现为 Breaker Block）后做反向操作（例如原趋势上升被破坏，则做空）。止损设在突破区之外，目标依据结构级别设置，往往能获得良好盈亏比（作者举例有 1:5 的情况）。
- 举例解读：视频中的案例展示，当一个长期上升区域的 order block 被一次强烈吞噬并突破后，价格回测该区域形成 Breaker Block，随后出现显著反向动能，给出高胜率的反向入场机会。猎杀行为会造成短期强烈波动并制造流动性集中区，理解并识别这些行为是捕捉 Breaker Block 的关键。

## 3.5 Fair Value Gap（FVG，公平价缺口）及其变种

- FVG 基本定义：Fair Value Gap（公平价格缺口）指价格短时间快速移动留下的“空白区”，通常由三根 K 线构成：前 K、一个强大实体的中间 K（动能 K），和后 K。中间那根大实体 K 与前后 K 的高低位之间形成未被触碰的区间，这个区间就是 FVG。ICT 认为 FVG 往往会被填补（price tends to fill gaps），因为快速移动可能留下未触发的订单。
- FVG 的识别方法：
    - 找到中间为强实体的 K 线（大阳或大阴），并看它与前后 K 线的高低是否有“空位”。
    - 空位由中间 K 的尾端与前/后 K 覆盖不一致形成（即存在价格未覆盖的区间）。
    - FVG 通常在较大时空下更具价值（例如 1H、4H、日线），但也可用于 15 分、30 分级别做短线机会。
- FVG 的类型：
    - 正向 FVG（FVG）：形成后价格回补该区域，然后继续原方向移动；若该 FVG 位于 PDArray 的合适半区（通常 D 区做多、P 区做空），可作为入场目标。
    - 逆向 FVG（Inverse/IFVG，破坏掉的 FVG）：当后续结构转换导致原 FVG 被反向突破，这个 FVG 变为已被破坏（failed FVG），破坏后再次回测该区仍可成为入场点（反向机会）。
    - 隐含 FVG（Implied FVG）：并非显性三根 K 线形成的缺口，但通过将两处隐性缺口的 50% 连线或计算中点，可构成隐含 FVG。这类在图形上不易察觉，但 ICT 常用“取中线 50%”的方法画出隐含 FVG 区域。
    - 失败/破坏的 FVG：当价格未回补或被反向穿透，原本的 FVG 失去交易价值或成为逆向机会。
- FVG 的实战流程与 PDArray 的结合：
    - 首先以 PDArray 判定该波段是偏向买入（D 区）还是卖出（P 区）。
    - 在合适的 PD 区找到 FVG：若 FVG 位于“便宜”区（50% 以下），做多的价值更高；若位于“昂贵”区则倾向忽视或做空。
    - 等待结构转换确认（例如小时线的结构破坏/转向），再利用 FVG 回补作为实际入场位。
    - 另外常结合 order block 或 breaker block 一同验证：如果 FVG 与 order block 重叠或邻近，入场信号更强。
- 举例与注意事项：视频以比特币、黄金等多图展示 FVG 的形成、回补与失效流程；作者强调不应“只看到 FVG 就追”，而应等待结构性的确认（结构转换）以增加胜率，并依照 PDArray 过滤不合理的 FVG。

## 3.6 其他构成要素：平衡价格区间、拒绝块、真空块与补仓块

- 平衡价格区间（Balanced Price Range）：由两个相反方向的 FVG 重叠形成的区域，代表价格在该区间内已被平衡过，未来价格回测该区往往有高概率产生反应。识别方法是找到两个互向的 FVG（向上与向下缺口）有交集或重叠区域，该区域即为平衡区，可用于寻找高概率的进场点或观察价格是否能穿透。
- 拒绝块（Rejection Block）：其特征是长影线（wick）所覆盖的区域，形成过程通常是价格被引导去创造更低或更高的点位以“扫流动性”（liquidity scan），随后强烈反转。长影线左侧或右侧的整个影线区域被标记为拒绝块，回撤到该区域会常见强烈的拒绝反应。实战上，当遇到拒绝块回测，可在该区域寻找入场并设置紧凑止损。
- 真空块（Void Block / Gap）：指 K 线之间存在显著开盘/收盘价差，形成一个明显的价格缺口。ICT 认为许多真空块会被未来回补，尤其在缺口位于 PDArray 的合理半区时，是很好的补单或做空区域。真空块通常出现在高波动、新闻或市场开盘时段（overnight gap）。
- 补仓块（Replenishment / Refill Block）：出现于趋势延展失败后并伴随结构转换的区域。举例：趋势长期下跌后出现一个阶段性低点不再创新低，随后转为上涨，该区域从最后高位到后续低位之间的区间即为补仓块。其逻辑是机构在趋势转换或动能继续之前，会回补某些未完成的头寸或利润，这个区域未来常会对价格产生吸引力并被回补，从而成为新的交易机会。
- 实战要点与警告：
    - 各类块（区）并非孤立存在，常常结合出现（例如拒绝块内含 FVG，或 order block 与平衡区重合），组合信号更具交易价值。
    - 一碰即进并非好策略：作者反复强调需等结构转换或额外确认（如小时级别动能确认），以防陷入“假的回补”或被猎杀。
    - 多时空结合：在更大时空建立框架（PDArray、周线或日线的关键区），在更小时空寻找入场点与确认，能提高胜率与盈亏比的合理性。

## 3.7 关于流动性、市场结构与交易时段的预告

- 流动性的分类与用途（在未来影片将展开）：视频提到将细分上方/下方流动性、流动性猎杀、流动性真空与流动性缺口等类型。理解流动性在哪里集中（例如常见的止损堆、盘口大挂单区）有助于预测机构可能的扫单行为，从而判断价格短期运动的方向与目标。
- 市场结构（Market Profile and Structure）：作者计划讲解每周轮廓分析、日内结构轮廓、日内方向偏好、造势者做多/做空模型、以及诱导陷阱（诱导散户进入错误方向的行为）。核心是通过高低点结构、动能变化与成交特征判断市场哪一侧更占优。
- 时段策略（Trading Sessions）：ICT 认为不同交易时段呈现不同的算法/波动特征，例如亚洲盘、伦敦盘与纽约盘各有典型的波动模式，作者计划教如何在特定时段制定对应策略；并强调 ICT 有所谓“杀戮时段”与“营蛋策略”（可能指机构在特定时段的集中行动方式），这些会在后续教学中详细说明。
- 学习路线与建议：作者建议先掌握 PDArray 与各构成要素，再学习流动性与时段策略。并提醒：完整学习需要时间与大量图表练习，建议跟随系列系统学习而非只学零散技巧。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：PDArray 为核心的多时空交易框架（Price Delivery Framework）
    - 框架概述：将市场波段划分为 P（Premium，高价区）与 D（Discount，低价区）两部分，以波段低点到高点的 50% 作为分界线。该框架以“机构行为”为出发点，主张机构在高价分配头寸（卖出）、在低价累积头寸（买入），并通过 order block、FVG、breaker 等结构来识别这些机构活动的痕迹。
    - 步骤化流程：
        1. 大时框划分波段：在周线/日线/4H 上识别主要波段，标注波段高低点与 50% 分界线，确定当前价格位于 PDArray 的 P 区还是 D 区。
        2. 寻找潜在供需区：在该大时框下寻找 order block、FVG、平衡区、拒绝块等关键区域作为未来回测的候选位。
        3. 下钻确认时框：回到小时或更小级别，确认失衡（Imbalance）、结构转换（Structure Change）、加速 K 线或猎杀行为作为入场/止损参考。
        4. 等待回撤并观察反应：当价格触及候选区，看是否有价格反应（例如触及 FVG 或 order block 出现拒绝），并结合成交/形态确认。
        5. 进场与风险管理：在确认后设置止损（超出关键区），目标设定基于前结构位或多倍盈亏比，遵循资金管理规则。
    - 关键心态与理由：此框架强调“先有大局观（PDArray）再找细节（order block/FVG）”，避免盲目追随短期形态或情绪化交易，通过多时空确认提升胜率与盈亏比。
- 心智模型一：完整学习与训练心态（Learning & Practice Mindset）
    - 核心观念：任何系统（包括 ICT）若只学片段或表面策略，而不理解底层逻辑与多要素确认，往往难以转化为稳定获利的能力。学习 ICT 应以“完整框架+大量图表练习+纪律”为目标。
    - 实践步骤与习惯：
        1. 系统化学习：按模块学习（PDArray → order block → FVG → breaker → 流动性 → 结构转换 → 时段策略），避免断章取义。
        2. 多图表训练：在历史图表上反复寻找并标注 order block、FVG、拒绝块等，积累“眼力”。多看多标，直到能迅速识别模式。
        3. 记录与复盘：每次模拟或实盘交易都需记录理由、入场条件、止损与结果，定期复盘找出错误与改进点。
        4. 严格纪律：设定明确的入场规则（例如必须在 D 区或结构确认后才入），不追单，不因为 FVG 在价位就盲目进场。若理想位未触及则放弃，等待下一次机会。
        5. 时间与耐心：作者强调 ICT 学习曲线陡峭，需耐心投入时间去看视频、读资料、练习图表，逐步从“模仿”到“理解”到“灵活应用”。
    - 心理建设：把学习看作长期工程，不因短期亏损否定该体系，也不把零散盈利夸大成方法有效的证明。稳定的交易来源于规则化执行与不断优化。

本集作为 ICT 完整系列的开篇，系统介绍了 PDArray 的概念与重要性，并详解了构成 PDArray 的核心元素：订单块（Order Block）、破坏块（Breaker Block）、Fair Value Gap（FVG）及其多种变形、平衡价格区间、拒绝块、真空块与补仓块。作者重复强调两点：一是 ICT 的本质仍是价格行为，但它用更有逻辑性的故事性框架解释机构如何推动价格；二是完整学习并多做图表练习非常关键，片段化学习会导致失败。后续视频将继续讲流动性分类、市场结构、诱导陷阱、反转形态、时段策略与 ICT 的高级杀招。若想长期成为稳定获利的交易者，应遵循多时空框架、严格纪律并保持持续练习。
