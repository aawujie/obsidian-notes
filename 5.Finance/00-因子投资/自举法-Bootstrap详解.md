# 自举法（Bootstrap）——从有限数据中自举不确定性

> Date: 2026-04-30
> 以卡尔曼因子回测为案例

---

## 1. 自举法要解决什么问题

量化回测有个死结：**你永远只有一条历史路径，但你想知道策略的真实分布。**

比如 2020-2024 的卡尔曼动态权重回测跑出了 Sharpe 0.276。但这只是一个样本——如果历史恰好"重演"一次，Sharpe 可能是 0.5，也可能 -0.1。单次回测的数字到底有多可信？

传统方法用 t 检验，前提是收益服从正态分布。但金融数据偏偏不是——厚尾、偏态、波动聚集，t 检验假设不成立。

自举法不假设任何分布。**它直接从数据本身出发，反复重采样，自己造出 1000 条"平行历史"，然后看分布。**

---

## 2. 核心思想

### 2.1 一句话

> 把已有数据当成"总体"，从中反复抽样，用抽样分布来估计统计量的不确定性。

### 2.2 怎么做

```
原始数据: 53 期月度收益率 → [r₁, r₂, r₃, ..., r₅₃]

重采样 1000 次:
  第 1 次: 从 53 个收益率里随机抽 53 个（抽完放回，允许重复）
           → 算一条新的累计曲线 → 算 Sharpe
  第 2 次: 同上
  ...
  第 1000 次: 同上

结果: 1000 个 Sharpe 值 → 画分布 → 看均值、中位数、95% CI、极端尾部
```

**关键点：抽完放回。** 所以同一期数据可能被抽到多次，也可能一次都没被抽到。这模拟了"历史可能不同"的随机性。

### 2.3 为什么叫"自举"

没有任何外部假设，不靠正态分布、不靠理论公式。纯粹用数据本身——靠自己的鞋带把自己提起来。

---

## 3. 数学形式

设原始样本 $X = \{x_1, x_2, ..., x_n\}$，想估计统计量 $\theta$（比如 Sharpe ratio）。

**自举步骤：**

1. 从 $X$ 中有放回地抽取 $n$ 个样本，得到自举样本 $X^*_b$
2. 计算 $X^*_b$ 上的统计量 $\hat{\theta}^*_b$
3. 重复 $B$ 次（通常 $B=1000$ 或更多）
4. 用 $\{\hat{\theta}^*_1, ..., \hat{\theta}^*_B\}$ 的经验分布来估计 $\theta$ 的分布

**自举标准误：**

$$
\text{SE}_{\text{boot}} = \sqrt{\frac{1}{B-1} \sum_{b=1}^B (\hat{\theta}^*_b - \bar{\theta}^*)^2}
$$

**95% 置信区间（百分位法）：**

$$
CI_{95\%} = [\hat{\theta}^*_{0.025}, \hat{\theta}^*_{0.975}]
$$

即 1000 个自举估计值排序后的第 25 个和第 975 个。

## 4. 实战案例：我们的卡尔曼因子策略

### 4.1 实验设置

- **策略：** 卡尔曼动态权重因子组合，与原 5 因子等权基准对比
- **样本：** 53 期月度收益率（2020-2024）
- **自举次数：** $B = 1000$
- **考察指标：** Sharpe、最大回撤、胜率、Kalman vs 等权的 $\Delta$Sharpe

### 4.2 结果：Kalman vs 等权

| 统计量 | 值 | 含义 |
|:---|:---|:---|
| $\Delta$Sharpe 均值 | +0.79 | 1000 次自举里，卡尔曼平均比等权高 0.79 |
| 95% CI | **[+0.29, +1.42]** | 95% 的平行世界里，卡尔曼都优于等权 |
| $\delta > 0$ 比例 | **99.5%** | 1000 次只有 5 次卡尔曼输给等权 |

**结论：卡尔曼动态权重碾压等权——不是运气，是确定结论。**

### 4.3 结果：策略本身的绝对 Sharpe

| 统计量 | 值 | 含义 |
|:---|:---|:---|
| Kalman Sharpe 均值 | +0.28 | 接近实际回测值（0.276） |
| 95% CI | **[-0.15, +0.72]** | 区间跨越了零！ |
| 显著为正？ | ❌ 不显著 | 53 期样本太少 |

**结论：策略方向是对的，但数据量不足以从统计上证明绝对有效性。需要更长回测周期。**

### 4.4 结果：极端尾部风险

| 分位数 | 累计收益 | 含义 |
|:---|:---|:---|
| 中位数（P50） | +35% | 大多数世界是赚的 |
| P5 | -20% | 5% 的平行世界里亏 20% |
| P1 | **-45%** | 最惨的 1% 世界，腰斩 |

**结论：尾巴很厚。需要有止损保护机制。**

### 4.5 结果：权重稳定性

| 指标 | 值 | 含义 |
|:---|:---|:---|
| 符号一致性 | 53%-71% | 同一个因子在不同自举里权重的正负号是否一致 |
| 变异系数 (CV) | 极高 | 权重本身的幅度极不稳定 |

**结论：卡尔曼权重依赖初始条件，路径选择性很强。参数不漂移是好事，但权重本身不是精密估计。**

## 5. 自举法的局限

### 5.1 样本太短时不准

53 期月度数据只有 4.4 年。自举法不能创造新的信息——它只是在反复"翻炒"已有的 53 个点。如果这 53 个点本身不具代表性，翻炒一万次也代表不了真实世界。

**表现：** 我们的 Kalman 绝对 Sharpe CI 跨越零，就是因为 53 期不够。

### 5.2 假设样本独立同分布（i.i.d.）

标准自举法假设每期收益相互独立。但金融数据有时间依赖——波动聚集、自相关、结构性断点。

**解决方案：** 分块自举（Block Bootstrap），把连续几期数据作为一个"块"抽取，保留时间依赖结构。

### 5.3 对尾部估计偏乐观

自举法最多只能重采样到数据中出现过的最极值点。如果历史上没出现过真正的黑天鹅，自举法也估算不出。

**表现：** 我们的 P1 回撤 -45% 可能还偏乐观——真实世界可能有更糟的情况。

---

## 6. 什么时候用自举法

| 场景 | 适合？ | 原因 |
|:---|:---|:---|
| 比较两个策略谁更好 | ⭐ 最合适 | 看差值分布，不管绝对值是否显著 |
| 估计 Sharpe 的置信区间 | ✅ 合适 | 代替 t 检验，不做正态假设 |
| 测压极端场景 | ✅ 合适 | 看 P1/P5 分位，做最坏准备 |
| 样本 < 30 期 | ❌ 不推荐 | 样本太少，重采样无意义 |
| 高频数据 | ⚠️ 需注意 | 可能需要分块自举处理自相关 |

---

## 7. 一句话总结

自举法就是用有限数据反复重采样，造出很多条"平行历史"，从中看策略表现有多稳定、极端风险有多大。

**我们学到的：**

1. **卡尔曼碾压等权是确定的**（99.5% 自举样本成立）
2. **但绝对收益的统计显著性还不够**（CI 跨越零，需要更长回测）
3. **尾部风险不容忽视**（最糟 5% 回撤 > 40%，必须有止损）

## 附录：关键代码逻辑

```python
import numpy as np

# 原始 53 期收益率
returns = np.array([...])  # 53 个值

# 自举 1000 次
n_boot = 1000
n_periods = len(returns)
boot_sharpes = []

for _ in range(n_boot):
    # 有放回抽样
    idx = np.random.choice(n_periods, size=n_periods, replace=True)
    boot_returns = returns[idx]
    # 计算 Sharpe
    sharpe = boot_returns.mean() / boot_returns.std() * np.sqrt(12)
    boot_sharpes.append(sharpe)

# 结果
print(f"均值 Sharpe: {np.mean(boot_sharpes):.3f}")
print(f"95% CI: [{np.percentile(boot_sharpes, 2.5):.3f}, "
      f"{np.percentile(boot_sharpes, 97.5):.3f}]")
```
