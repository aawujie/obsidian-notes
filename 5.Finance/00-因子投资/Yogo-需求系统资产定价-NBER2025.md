## 一、什么是需求系统资产定价（DSAP）

一个研究资产价格与投资者组合、信念和基本面（公司特征与宏观变量）之间关系的框架。使用资产价格、基本面以及组合持仓与流量数据。

核心强调**需求弹性**和**需求变动因素/冲击**，以理解资产价格运动。

> 一种新方法，但并非新理论。DSAP 的发现可能挑战现有理论并指导新理论的构建。

### 关键洞察

- 所有资产定价模型都隐含着一个**随机折现因子（SDF）**和一个资产需求系统
- DSAP 利用组合持仓数据检验同一模型的不同含义
- 某些模型隐含了更现实的需求系统，能同时解释资产价格和组合持仓
- 不必然假设摩擦、中介或市场分割——但这些东西可能隐含更现实的需求系统
- **需求缺乏弹性**——这可能是一个实证发现

---

## 二、为什么需要 DSAP

许多资产定价问题涉及资产供给或需求的变动。例如：

1. **QE/QT** 对国债收益率及其他资产价格的影响？
2. **中美脱钩** 对全球资产价格和汇率的影响？
3. **银行和保险公司的资本监管** 对资产价格的影响？
4. **ESG 投资** 对股票价格和收益横截面的影响？
5. **主动→被动投资转型** 对股票价格和价格信息含量的影响？

> 对这些定量问题的可信回答，需要一个现实的需求系统。

## 三、与早期文献的关系

| 早期方向 | DSAP 的区别 |
|:---|:---|
| 宏观资产需求模型 (Brainard-Tobin 1968) | 大规模微观数据 + 现代识别方法 |
| 市场微观结构 | 同时关注需求变动因素和价格水平；低频识别 |
| 指数效应 (Shleifer 1986) | 对所有资产识别；市场出清反事实 |
| 组合流动与收益 (Coval-Stafford 2007) | 需求冲击对价格的**因果效应** |

## 四、四大支柱

### 4.1 微观基础：资产定价模型

**资产市场：**
- N 种资产，价格 Pn,t，支付 Dn,t+1 = φn,t + ψn,t Ft+1 + νn,t+1
- 期望支付和因子载荷依赖于可观测资产特征 Xn,t

**投资者：**
- I 位投资者，风险厌恶系数 γi，对期望支付存在意见分歧
- 求解 max E[-exp(-γi Ai,t+1)]，满足欧拉方程

**最优组合：**
```
Qi,n,t = −πi,t Pn,t + β'i,t Xn,t + ϵi,n,t
         ↑需求弹性     ↑需求变动因素
```

**均衡：**
- 市场出清 Sn,t = Σ Qi,n,t
- 均衡价格 Pn,t = (1/πt)(β't Xn,t + ϵn,t − Sn,t)
- πt = 总需求弹性，1/πt = 价格冲击

### 4.2 预测：资产与投资者嵌入

**简化形式需求：**
```
Qi,n,t = λ'i,t xn,t + εi,n,t
```
- λi,t：投资者嵌入（Investor Embeddings）
- xn,t：资产嵌入（Asset Embeddings）
- 可通过 PCA 估计为因子模型

**AI 方法应用于经济学：**
- 传统上用公司特征衡量相似性（市值、B/M、行业）
- 投资者还使用难以度量的特征（AI 能力、无形资本、贸易战敏感度）
- 通过组合持仓数据**估计资产嵌入**来恢复这些信息：
  1. 推荐系统：PCA
  2. 浅层神经网络：Word2Vec
  3. Transformer：BERT

**基准测试（ImageNet 式的竞争）：**

| 股票基准 | 固定收益基准 |
|:---|:---|
| 预测相对估值 | 预测信用利差 |
| 解释股票收益联动 | 解释利差变化联动 |
| 预测机构组合决策 | 预测利差波动与违约 |

**嵌入的额外应用：**
- 生成式组合：基于当前持仓推荐股票
- 风险管理：生成压力情景
- 投资者分类、绩效评估、拥挤交易检测

### 4.3 识别：工具变量法估计结构性需求

**核心思想：**

市场出清 → Qi,n = Sn − Σ Qj,n（剩余供给）。要估计投资者 i 的需求弹性，需要其他投资者需求的**外生变动**。

**识别策略五类：**

| 策略 | 示例 | 原理 |
|:---|:---|:---|
| 投资委托 | 全市场基金 vs 银行基金 | 银行基金投摩根大通但不投沃尔玛 → 外生 |
| 指数效应 | Russell 1000/2000 分界 | DID 版本，分界处的需求冲击变化 |
| 分红诱导交易 | 预公布分红再平衡 | 不依赖价格（区别于共同基金流动） |
| 央行购买 | 欧洲央行按资本比例购买 | 政策驱动，非市场驱动 |
| 粒度 IV | Gabaix-Koijen 2024 | 大机构行为的外生冲击 |

**实证发现：跨市场弹性普遍偏低**

- 美国股票：中位数约为 2-3，随时间上升
- 欧元区政府债券：弹性 3.21
- QE 收益率效应：-0.38% 至 -0.83%

### 4.4 反事实分析

均衡价格 pt = p(xt, At, βt, ϵt)：

| 应用 | 方法 |
|:---|:---|
| 2008 年谁制造了波动？ | 家庭贡献 46.9%，小型机构 40.7%，前 30 大机构仅 4.4% |
| 预测股票收益 | 基于特征的期望收益：市值 -0.25, B/M 0.04, 盈利 0.30, 投资 -0.38, β 0.08, 动量 0.24 |
| 评估定价模型 | 总需求弹性确定需求冲击方差；拒绝高弹性模型 |

## 五、未来方向

1. **改进资产需求模型** — 弹性依赖资产特征和嵌入；广延边际替代；基于管理组合基准的评估
2. **识别持续进展**
3. **连接需求变动因素与调查预期** — 哪些投资者有理性注意力有限、诊断性预期、记忆衰减？
4. **解决实证谜题** — 谁推动价值/动量/ESG 的价格变动？
5. **公司金融应用** — 对冲基金持有棕色股票是因为便宜而非偏好；检验迎合理论；企业迎合投资者偏好调整排放、发债条款、资本结构
