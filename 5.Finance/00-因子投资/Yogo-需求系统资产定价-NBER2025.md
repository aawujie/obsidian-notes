# Yogo：需求系统资产定价 — NBER 2025 演讲笔记

> 来源: Motohiro Yogo, NBER LTAM Keynote, 2025-04-19
> 原文: 41 页课件 | 翻译+整理
> 核心方法论: 用持仓微观数据反推机构需求函数 → 解释价格运动

---

## 1. 这个方法要回答什么问题

传统因子模型（Fama-French 五因子、Barra）只能回答"因子跟收益有没有统计关系"，回答不了"谁在买、谁在卖、价格为什么动"。

比如：
- 某天茅台跌 5%，是因为基本面变差？还是某家大机构清仓？
- QE 放水到底通过什么通道传导到股价？
- ESG 投资浪潮到底把"绿色"股票推高了多少？

DSAP 用**组合持仓数据 + 需求系统模型**来回答这些问题。

---

## 2. 核心模型：从投资者行为推导价格

### 2.1 基本设定

N 种资产，I 位投资者。资产 n 的支付 D 由因子 Ft+1 驱动：

```
Dn,t+1 = φn,t + ψn,t·Ft+1 + νn,t+1
```

期望支付 φ 和因子载荷 ψ 都依赖于可观测的公司特征 Xn,t（市值、B/M、行业等），加上不可观测的成分。

投资者是 CARA 效用（指数效用），风险厌恶系数 γi。不同投资者对期望支付和因子载荷**看法不同**（agree to disagree）。

### 2.2 推导出资产需求函数

每个投资者 i 对资产 n 的最优持仓：

```
Qi,n,t = −πi,t·Pn,t + β'i,t·Xn,t + ϵi,n,t
         ────────────   ─────────
         价格响应项        需求变动因素
```

**πi,t = 1/(γi·σ²)** —— 需求价格弹性。γ 越大（越怕风险），弹性越小，价格变动时调仓幅度越小。

**需求变动因素 β'i,t·Xn,t** —— 投资者对特征的偏好。比如某投资者特别偏好低波动率股票，那 low-vol 特征的系数就大。

**ϵi,n,t —— 潜在需求（latent demand）** —— 不可观测部分，模型不能解释的残差。

### 2.3 市场出清 → 均衡价格

```
Sn,t = Σ Qi,n,t  （持仓总和 = 流通股本）

Pn,t = (1/πt)·(β't·Xn,t + ϵn,t − Sn,t)
```

**关键量：1/πt —— 价格冲击系数。** πt 越小（总需求弹性越低），同样的供需失衡会引起更大的价格波动。

## 3. 实证策略：三步走

### 3.1 第一步 — 简化形式需求 + 资产嵌入

不直接估计结构性参数。先把需求写成简化形式：

```
Qi,n,t = λ'i,t·xn,t + εi,n,t
```

- **xn,t：资产嵌入** — 用 PCA 从持仓数据中提取的低维特征向量。把上万只股票压缩到几十维，捕捉机构实际交易行为中隐含的相似性
- **λi,t：投资者嵌入** — 每个投资者在这些"行为维度"上的偏好向量

> 这步的价值：不是用基本面特征（市值、B/M）度量相似性，而是用**交易行为**度量相似性——两只股票被同样类型的机构以同样方式交易，说明市场认为它们"相似"。

**使用工具：** PCA → Word2Vec → BERT，逐步升级复杂度。在 ImageNet 式的基准测试中 PK 可观测特征和文本嵌入（Cohere/OpenAI）。

**我们能复用：** 如果拿到 A 股持仓数据（机构季度报告），用 PCA 提取资产嵌入，把我们的 5 因子信号跟机构行为维度对齐——看哪些因子被哪些机构偏好。

### 3.2 第二步 — 工具变量识别

不能直接回归 Q ∼ P（价格内生于需求）。需要用**工具变量**。

**核心逻辑：**

```
Qi,n = Sn − Σ Qj,n
         └─ 其他所有投资者的持仓 = "剩余供给"
```

要估计投资者 i 的需求弹性，需要**其他投资者需求的外生冲击**——跟你无关、你又控制不了的变化。

**五种识别策略：**

| 策略 | 工具变量 | 为什么外生 |
|:---|:---|:---|
| **投资委托** | 某些基金只能投特定类型股票 | 委托规则不由价格决定，但影响需求 |
| **指数效应** | Russell 1000/2000 分界处补入/剔除 | 分界点之外，基本面没变，需求却变了 |
| **分红诱导交易** | 预公布分红 → 强制再平衡 | 跟股价无关的事件驱动 |
| **央行购买** | ECB 按 GDP/人口比例购债 | 纯政策驱动 |
| **粒度 IV** | 头部大机构的异质行为 | 一家清仓跟你基本面无关，但改变你的"剩余供给" |

**结果：需求弹性普遍偏低。** 美国股票中位数 2-3，欧元区债券 3.21。这意味着**1% 的需求外移大约对应 0.3-0.5% 的价格变动**——需求侧的冲击不可忽视。

**我们能复用：** A 股有沪深港通资金流向数据、QFII 持仓变化——这些可做外生冲击工具变量。把北上资金的大幅流入/流出当作 DSAP 里的"德国投资者"。

### 3.3 第三步 — 反事实分析

有了估计好的需求系统，就可以做"如果……会怎样"：

**2008 年波动谁是元凶？**
把股价变动分解到不同类型的投资者：
- 家庭投资者贡献了 **46.9%** 的方差（散户情绪是最大的波动源）
- 小型机构 **40.7%**
- 前 30 大机构仅 **4.4%**（大机构反而不是波动的来源）

**预测股票收益：**
基于特征的期望收益：市值 -0.25, B/M 0.04, 盈利 0.30, 投资 -0.38, β 0.08, 动量 0.24

## 4. 跟我们当前因子工作的结合点

| DSAP 核心 | 我们已有的 | 差距 |
|:---|:---|:---|
| 资产嵌入（PCA/W2V/BERT） | LASSO/Ridge 因子筛选 | 缺持仓微观数据 |
| IV 识别（委托/指数/分红） | Kalman 动态权重 | 缺外生工具变量 |
| 反事实分析 | Bootstrap 自举法 | 缺投资者维度分解 |
| 评估模型矩条件 | GRS 检验 + EVT | 需要连接需求弹性 |

**最直接的下一步：** 拿到 A 股机构季度持仓数据 → 用 PCA 从持仓里提取行为因子 → 跟我们的基本面因子做正交化 → 把纯 Alpha 从"别人在买"里分离出来。

---

## 5. 一句话总结

DSAP 不是另一个因子模型——它是**从投资者行为的微观数据出发，推导出价格如何被需求驱动，再用工具变量识别因果关系，最后做反事实推演**。这跟传统"跑回归看 IC → 挑因子 → 配组合"的套路是互补的，不是替代的。
