## 第一部分：量化交易究竟是什么，以及其中的角色

大多数人以为量化交易是对市场走向有观点。

**不是。量化交易是关于数学。**

你处理的是统计关系、定价低效和结构性优势——这些优势之所以存在，是因为市场是由人类运行的复杂系统，人类会犯系统性的、可重复的错误。目标不是在任何特定结果上正确。目标是找到数学概率对你有利的情境，正确配置仓位规模，然后将这个过程重复数千次，直到期望值累积成真实收益。

想想赌场的运作方式。赌场不试图预测任何单次下注会赢。它以每笔下注的微小数学优势反复运行游戏，让大数定律完成剩下的工作。量化交易公司以完全相同的方式运作。它们找到优势。它们正确配置仓位规模。它们规模化执行。

这个框架完全适用于预测市场。系统化量化交易员不试图预测某位政治候选人是否会赢得选举。他们试图找到隐含概率与底层数据实际支持之间存在可测量偏差的市场，押注这个偏差，同时跨数百个事件重复操作。工具相同。数学相同。优势来自相同的源头。

下面是角色分类，因为不同角色需要不同的准备。

**量化研究员 (Quantitative Researcher)** 是薪酬最高、要求最严的角色。这些人在海量数据中寻找模式，构建预测模型，设计实际的交易策略。他们需要博士级的数学和统计深度，或者在硬核量化领域真正卓越的本科成就。顶级公司应届总薪酬范围在 **$350,000 到 $650,000**，之后大幅增长。

**量化交易员 (Quantitative Trader)** 将研究员构建的模型在实际市场中实时执行交易。需要快速的概率思维、强大的心算能力，以及在信息不完整的情况下果断决策的压力承受力。这个角色在所有量化职业中薪酬方差最大。卓越的交易员一年可达八位数收入。顶级公司应届薪酬通常在 **$200,000 到 $400,000** 起步，上限无封顶。

**量化开发者 (Quantitative Developer)** 构建让研究成果能在真实市场中交易的基础设施。交易平台、执行引擎、实时数据管道、低延迟系统。需要生产级 C++、Rust 和 Python，达到极高的性能标准。顶级公司应届总薪酬通常在 **$200,000 到 $350,000**。

**风险量化 (Risk Quant)** 专注于模型验证、VaR 计算、压力测试和监管合规。最稳定的量化职业路径，薪酬轨迹最可预测。上限比其他三个角色低，但稳定性显著更高。

目前增长最快的角色是**AI/ML 量化**——使用深度学习构建信号生成系统，大规模处理另类数据，将 ML 模型直接部署到实时交易环境中。这个角色位于量化研究和 ML 工程的交叉点，是 2025-2026 年招聘最激进的领域。

在继续阅读前需要消除的误解：**做这些工作不需要金融学位。** 你需要的是数学能力、编程技能，以及按正确顺序构建基础的纪律。

## 第二部分：数学基础（正确顺序）

从零到量化就绪的路径就像游戏关卡。不能跳级。每个概念都建立在前一个之上。如果你试图跳过基础层直接跳到机器学习或期权定价，你会对许多主题建立表面熟悉度，但对任何一个都没有真正理解。这在量化面试中活不下来。

正确的顺序是五层深度。每一层是其后所有内容的先决条件。

### 第一层：概率论

量化金融中的一切最终都归结为一个问题：**概率是多少，概率对我有利吗？**

如果你不在深层次上理解概率，本文其余内容都不重要。期权定价是概率问题。信号建模是概率问题。做市是概率问题。仓位规模是概率问题。预测市场交易本质上就是概率问题。

本层最重要的概念是**条件思维**。量化交易员不以绝对方式思考。他们以条件方式思考。**在我目前所知道的情况下，这个结果的可能性有多大？**

精确表达这个的公式：

> **P(A|B) = P(A ∩ B) / P(B)**

A 在给定 B 下的概率，等于两事件同时发生的概率除以 B 单独发生的概率。

实践中的应用：假设你正在为经济数据发布构建预测市场的信号。基于历史基准率，市场在发布后剧烈波动的无条件概率是 40%。但在期权隐含波动率在发布前显著升高的日子里，剧烈波动的条件概率上升到 68%。那 68% 是真实可用的信号。无条件的 40% 将信号和噪声混合在一起，不使用条件化就无法分离。

**贝叶斯定理**是本层的另一个核心概念。它告诉你如何在新信息到来时更新你的信念：

> **后验 = (似然 × 先验) / 证据**

你更新后的信念等于：如果你的假设为真，你看到这个新证据的可能性有多大，乘以你之前对假设的信念强度，除以在任何假设下看到这个证据的可能性。当新信息到达时，最快、最准确地更新信念的交易员持续超越其他人。

**期望值和方差**是你在整个量化职业生涯中将不断思考的两个数字。期望值是你在所有情景下的平均结果。方差是你的实际结果可能偏离该平均值的程度。如果你的策略有正期望值，并且你能在方差中存活足够长时间让它累积，你就会赚钱。如果你相对于方差配置过大仓位，你会在期望值有时间发挥作用之前破产。

**本层资源：** Blitzstein & Hwang, *Introduction to Probability*。哈佛免费 PDF。做完第 1-6 章的每一道题。预算 3-4 周，每天专注 2 小时。

### 第二层：统计学

一旦你理解了概率，你需要学会倾听数据。这就是统计学。统计学教给你最重要的一件事是：**大多数看起来像真实信号的东西实际上是噪声。**

你构建了一个策略。回测年化收益 15%。这是真实的优势还是幸运的波动？

**假设检验**告诉你答案。假设零假设——你的策略真实期望收益为零。计算如果这个假设为真，你看到这么强劲结果的可能性有多大。如果你测试 1000 个随机策略，其中 50 个会纯属偶然地在标准 5% 显著性水平下显示出强劲结果。这就是**多重比较问题**。它是回测看起来很棒而实盘交易结果糟糕的最常见原因。

**线性回归**是主力工具。将你的策略收益对已知风险因子做回归，寻找截距项——称为 alpha。如果在考虑所有标准因子后 alpha 为零，你所谓的优势只是对早已被充分理解的因素的伪装暴露。唯一重要的数字是在每个已知因子都被考虑后仍然存活的 alpha。

**本层资源：** Wasserman, *All of Statistics*，第 1-13 章。预算 4-5 周。

### 第三层：线性代数

线性代数是运行量化金融和 ML 中一切的机器。组合构建、主成分分析、神经网络、协方差估计、因子模型——都运行在矩阵数学上。

协方差矩阵捕捉每个资产相对于其他每个资产的运动方式。组合方差坍缩为：

> **方差 = wᵀ Σ w**

其中 w 是权重向量，Σ 是协方差矩阵。这个单一表达式是组合优化和风险管理的数学核心。

**特征值**揭示协方差矩阵内部真正重要的东西。在 500 只股票的组合中，前五个特征向量通常解释 70% 的总方差。其他一切都是噪声。特征分解是因子投资、降维和大规模系统化策略统计架构的基础。

**本层资源：** Gilbert Strang 的 MIT 18.06 课程，MIT OpenCourseWare 完全免费。全部看完。然后做 Strang 的 *Introduction to Linear Algebra* 教材习题。预算 4-6 周。

### 第四层：微积分与优化

量化金融中几乎每个问题最终都归结为**在约束条件下最大化某个目标**。组合构建、模型训练、执行策略——都是优化问题。

**凸优化**在这里至关重要。凸优化问题有唯一的全局解，可以高效找到。大多数组合构建和风险管理问题可以构建为凸规划。理解什么时候问题是凸的以及如何高效求解是该领域的核心实践技能。

**本层资源：** Boyd & Vandenberghe, *Convex Optimization*。Stanford 免费 PDF。做第 1-5 章。预算 4-5 周。

### 第五层：随机微积分

在学随机微积分之前，你可以分析数据和构建统计模型。学了之后，你可以从数学第一性原理推导金融工具如何定价。这是 Black-Scholes 的来源，也是最复杂系统化策略的设计层面。

随机微积分的核心洞见是：**在有随机性的世界里，一个微小随机增量的平方不像在普通微积分中那样可以忽略。** 这一个事实改变了每一个计算，并产生了**伊藤引理**——随机微积分的链式法则。将其应用于期权价格，你就推导出 Black-Scholes 方程：

> **∂V/∂t + ½σ²S²(∂²V/∂S²) + rS(∂V/∂S) − rV = 0**

这个结果的非凡之处在于：**股票的期望收益完全消失了。** 期权价格不取决于你认为股票会走向何方，只取决于它波动多大。这是让现代衍生品定价成为可能的、概念上具有革命性的结果。

**本层资源：** Shreve, *Stochastic Calculus for Finance*，第 1 卷和第 2 卷。黄金标准。预算 6-8 周，不要赶进度。

## 第三部分：编程、HFT 工具和真正重要的技术栈

量化金融中有两种完全不同的编程技能，大多数求职者将其混淆。

第一种是**研究编程**。用干净的 Python 分析数据、构建和回测统计模型、实现 ML 流水线。这是量化研究员和大多数量化分析师每天使用的。

第二种是**生产系统编程**。编写高性能 C++ 或 Rust，以微秒级延迟执行、处理实时市场数据、管理订单簿、在不丢一个 tick 的情况下处理执行逻辑。这是量化开发者和 HFT 工程师构建的东西。

如果你瞄准量化研究员或量化分析师角色，**Python** 是你的主要工具。精通 **pandas** 和 **polars**（polars 在大型数据集上快 10-50 倍）用于数据操作。使用 **numpy** 和 **scipy** 进行数值计算。使用 **xgboost、lightgbm、catboost** 进行表格数据的机器学习。使用 **pytorch** 进行深度学习。使用 **cvxpy** 解决优化问题。使用 **statsmodels** 进行统计检验。

如果你瞄准量化开发者或 HFT 工程角色，**C++ 和 Rust** 是必须的。

**C++** 几十年来一直是高频交易的主导语言。原因：对内存布局的控制、无垃圾回收暂停的确定性性能、以及将代码优化到理论硬件极限纳秒级的能力。在以微秒或亚微秒速度交易的公司，一次糟糕的内存访问模式在滑点上的损失可能比策略赚到的优势更多。相关的 C++ 库：**QuantLib**（衍生品与金融数学）、**Eigen**（高性能线性代数）、**Boost**（通用工具）。

**Rust** 是该领域严肃的新兴竞争者，正在迅速获得采用。Rust 提供与 C++ 相同级别的性能，同时具有在编译时强制执行的内存安全保证，消除了 C++ 代码库中经常出现的整类 bug。**NautilusTrader** 是最先进的开源交易平台之一，使用 Rust 核心处理性能关键组件，配合 Python API 进行研究和策略开发。这种 **Rust + Python** 架构正在成为新系统化交易基础设施的标准模式。**RustQuant** 专门用于 Rust 中的期权定价和量化衍生品工作。

**数据源：** yfinance 免费，学习够用。Polygon.io 约 $200/月，提供低于 20 毫秒的延迟，是严肃零售系统化工作的标准。Bloomberg 终端约 $32,000/年，是机构标准。Finnhub 为早期项目提供免费层。

**回测工具：** NautilusTrader 用于生产级工作。Backtrader 和 vectorbt 是学习概念的更简单起点。

> **作业——揭示一切的面试题：**

以下是最著名的概率问题之一，顶级量化公司在早期筛选中使用。陈述简单，正确求解的深度令人惊讶，直接测试第二部分的**条件思维**。

你反复抛一枚公平硬币，直到连续出现两个正面。抛掷次数的期望值是多少？

在阅读任何其他内容之前自己解一遍。不要去搜答案。设置状态、为每个状态写出方程、求解方程组的过程，正是量化面试官在观察的推理类型。

把你的答案和解题方法写在评论区。这个问题会收敛到一个特定结果，你用来得到结果的方法比答案本身更能揭示你的数学思维。

## 第四部分：面试过程解密

大多数求职者为他们想象的量化面试而准备。现实比大多数人预期的更有结构、要求更高。

在 Citadel 这样的公司，面试流程跨越多个同时进行的轨道。量化软件工程、交易和量化研究轨道各有不同的结构和测试内容。一个认真的求职者在单个招聘季可能经历 **15 到 20 场**独立面试。

最终轮称为 **Super Day**。一天内连续进行**六场 45 分钟**的面试。主题范围从底层 C++ 和系统设计到概率证明、ML 设计问题，再到与团队负责人的行为面试。你需要干净地编码，清晰地推导数学结果，并在每一步大声解释你的推理。

**心算速度**比大多数求职者预期的要重要得多。公司使用 Zetamac 等工具进行早期筛选。**目标是在申请前达到每分钟 50 题以上。**

**Jane Street** 设计的面试题目故意难到一个人不应该能独立解决。他们在测试你如何使用提示。如何在不确定中向前推理。如何在压力下合作。一个叙述自己的思考、考虑边界情况、在继续推理的同时承认不确定性的候选人，将持续优于一个沉默然后给出正确答案却没有解释的候选人。

**绿皮书**——正式书名 *A Practical Guide to Quantitative Finance Interviews*（Xinfeng Zhou 著），是每位拿到顶级量化公司 offer 的候选人最常引用的准备资源。超过 200 道真实面试题，涵盖概率、统计、脑筋急转弯、心算和金融谜题。慢慢做。在看任何提示之前至少花 15 分钟真正尝试每道题。

补充资源：**QuantGuide.io** 用于量化专项练习题，**Brainstellar** 用于面试难度的概率谜题。

编码轮次：刷 **LeetCode Blind 75** 题集，重点理解每类题型的底层模式而非记忆解法。**动态规划**是 Citadel 和 Jane Street 终面中最常见的失败点。

**研究经验**是将最强量化研究候选人和其他人分开的因素。不是课程成绩。是真正的研究——你提出了一个假设，构建了某个东西来测试它，并能精确描述你从这个过程中学到了什么，包括什么失败了以及为什么。

## 第五部分：从零到 $650,000/年的阶梯

**最大的错误是试图纵身一跳。** 没有资历直接申请 Citadel 或 Jane Street，被拒后得出结论说这个领域进不去。

这个领域没有关闭。他们试图跳 18 级台阶，而这个过程需要一步一步走。

**第一步：** 按正确顺序构建第二部分中的数学基础。学术学习轨道和编程实践轨道**同时运行**。不要等数学完美了才开始编码。两者并行发展。

**第二步：** 在任何地方申请之前至少构建**一个真实项目**。用真实历史数据回测一个系统化交易策略，记录你测试的每个假设和决策。向 WorldQuant BRAIN 或 Kaggle 提交一个模型并写下你构建了什么。用 Alpaca 等券商 API 实现一个简单算法。这些项目证明你能将数学知识转化为可以运行的东西。

**第三步：** 获得你的第一个**机构资历**。冷邮件联系研究实验室的博士生，具体请求为正在进行的工作做贡献。担任量化课程的助教。加入研究助理职位。具体头衔远不如有一条真实的技术经验线可以谈论重要。

**第四步：** 用每个资历达到下一个层次。研究实验室 → 打开初创公司面试之门。初创公司资历 → 打开中型公司之门。中型公司 → 打开顶级基金之门。**没有人找到绕过这个阶梯的可靠捷径。**

**第五步：** 在感到准备好之前就申请，并**追踪一切**。每次拒绝都是数据。每次面试都是练习。建立一个表格。追踪每次申请、每次在线评估、每次面试、每个你无法干净回答的问题。在下一次面试前专门去学那个具体的东西。

**第六步：** **公开竞争。** 第四部分中的竞赛是招聘管道，不仅仅是技能建设练习。公司会看排行榜，强劲表现已经直接为之前与这些公司毫无联系的候选人带来了工作 offer。

**数学基础是真正的护城河。** 推导出伊藤引理为什么比普通微积分多一项的能力。知道凸优化方法在真实市场中什么时候会有效、什么时候不会。这种深度将构建真正优势的量化和借用优势的量化区分开来。借来的方法在所有人都采用时过期。数学流利度可以无限地生成新方法。

**在关闭本文之前，写下三件具体的事：** 你现在在阶梯的哪个位置。你当前位置之上下一个具体的台阶是什么。以及你在接下来七天内能采取的最具体的一个行动，向那个下一步迈进。不是一个模糊的意图。是一个有具体截止日期的具体行动。
