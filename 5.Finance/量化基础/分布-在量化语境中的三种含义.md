# "分布"在量化语境中的三种含义

量化研究里"分布"这个词出现频率极高，但指的不是同一件事。搞混了会导致预处理方式错误、风险模型失效、因子评价失真。

---

## 一、因子值的截面分布

**是什么：** 某一天，全市场N只股票的因子值排成一列，看这列数的形状。

**横坐标：** 因子值大小（如机构净买入额，单位亿元）  
**纵坐标：** 股票数量（频率）  
**时间切面：** 固定某一天，看截面

**例子：**
```
某日机构净买入截面分布（271只龙虎榜股票）

数量
 ^
80|  ██
50|  ██ ██
20|  ██ ██ ██ ██          ██
  +--+--+--+--+--+--+--+--+--→ 机构净买入(亿)
    -2  0  1  2  3        10
         ↑                ↑
      大多数堆在这里    华天科技9.8亿
                        华虹11亿（右边长尾）
```

**典型形态：**

| 因子 | 截面分布形态 | 原因 |
|:---|:---|:---|
| 机构净买入额 | 右偏厚尾（t分布） | 大多数接近0，少数极端大值 |
| 北向净买入额 | 接近正态（截断） | 相对均匀，但有上下限 |
| 连续上榜天数 | 几何分布 | 离散计数，每天独立概率 |
| 涨停净买入 | 零膨胀对数正态 | 大量0值 + 右偏连续部分 |
| 外资席位次数 | 泊松/负二项 | 稀疏计数，过度离散 |

**为什么关心：**
因子预处理的所有操作都针对这个分布：
- **去极值**（MAD法）：把右边长尾的极端值压回合理范围
- **标准化**（z-score）：均值0方差1，消除量纲差异
- **正交化**：剔除因子间重叠信息
- **分位数转换**：彻底消除分布形状影响，转成均匀分布

> ⚠️ 注意：如果错误地用正态假设处理右偏厚尾数据，会低估极端值的频率，导致风险模型系统性低估尾部风险。

## 二、因子IC的时序分布

**是什么：** 因子在不同时间段的预测能力序列，看这个序列的统计特征。

**IC定义：** 某期因子值 与 未来N日收益率 的 Spearman 相关系数
$$IC_t = \text{Spearman}(f_t, r_{t \to t+N})$$

**横坐标：** IC值大小（-1到+1之间）  
**纵坐标：** 出现频率  
**时间序列：** 每期算一个IC值，积累成序列

**例子：**
```
机构净买入因子 月度IC序列（假设数据）

IC值
+0.08 |      *   *
+0.05 |  * *   *   * *
+0.02 |*         *     * *
 0    |--------------------→ 时间（月）
-0.02 |              *
-0.05 |

IC均值 ≈ 0.04
IC_IR = IC均值 / IC标准差 ≈ 0.8（一般>0.5算合格）
胜率 = IC>0的期数占比 ≈ 75%
```

**核心评价指标：**

| 指标 | 含义 | 经验阈值 |
|:---|:---|:---|
| IC均值 | 平均预测能力 | >0.03 算有效 |
| IC标准差 | 预测稳定性 | 越小越好 |
| IC_IR | 风险调整后预测力 | >0.5 算合格 |
| 胜率 | IC>0的比例 | >55% 算稳定 |
| IC衰减速度 | 信号持续多久 | 龙虎榜信号通常3-5天衰减 |

**为什么关心：**
因子权重应该由历史IC决定，而不是主观拍定。IC_IR高的因子权重大，IC_IR低的因子权重小——让数据说话。

龙虎榜5个维度的大概预测力排序（基于文献，未验证）：
```
涨停持续性（T+1最强）> 机构净买入 > 北向净买入 > 连续上榜 > 外资席位
```

## 三、收益率分布

**是什么：** 股票（或策略）的收益率序列本身的统计分布。

**横坐标：** 收益率大小（%）  
**纵坐标：** 出现频率  
**用途：** 风险建模、定价、回测假设

**典型形态：左偏厚尾**
```
A股个股日收益率分布（示意）

频率
 ^
    |        ██
    |      ██████
    |    ████████████
    |  ████████████████
    |████████████████████████      ██
    +--+--+--+--+--+--+--+--→ 日收益率
      -10% -5%  0  +5% +10%
        ↑                ↑
    跌停(-10%)          涨停(+10%)
    左边更厚             A股有涨跌停限制
                        右边被截断
```

**和正态分布的差异：**
- **左偏**：大跌比大涨更极端（崩盘比暴涨猛）
- **厚尾**：极端收益率出现频率远高于正态预测
- **A股特殊性**：涨跌停制度人为截断两端，形成混合分布

**为什么关心：**

| 用途 | 正态假设的问题 | 正确做法 |
|:---|:---|:---|
| VaR计算 | 低估极端亏损概率 | 用历史模拟或t分布 |
| 夏普比率 | 隐含正态假设，不适用厚尾 | 补充偏度、峰度指标 |
| 期权定价 | BS模型低估尾部期权价值 | 随机波动率模型 |
| 回测显著性 | 高估策略的统计显著性 | Bootstrap方法 |

## 四、三者对比总结

| 维度 | ① 因子值截面分布 | ② IC时序分布 | ③ 收益率分布 |
|:---|:---|:---|:---|
| **横坐标** | 因子值大小 | IC值（-1到1） | 收益率大小 |
| **时间维度** | 固定某一天 | 时间序列 | 时间序列 |
| **关心原因** | 预处理方式 | 因子有效性评价 | 风险建模 |
| **典型形态** | 右偏厚尾 | 接近正态 | 左偏厚尾 |
| **对应操作** | 去极值/标准化 | IC均值/IC_IR | VaR/最大回撤 |

## 五、实际判断技巧

看到"分布"两字，先问三个问题：

1. **横坐标是什么？** 因子值 / IC值 / 收益率 → 对应三种含义
2. **时间维度怎么切？** 某一天截面 / 时间序列
3. **目的是什么？** 预处理 / 因子评价 / 风险建模

例句辨析：
- "这个因子的分布右偏" → ①因子值截面分布，需要去极值
- "这个因子的IC分布稳定" → ②IC时序分布，因子预测力稳定
- "策略收益率分布左偏" → ③收益率分布，有下行风险
- "因子在不同市场状态下分布不同" → ①或②，需要看上下文

## 六、延伸：为什么三个分布形态不同？

| 分布 | 形态 | 根本原因 |
|:---|:---|:---|
| 因子值截面 | 右偏厚尾 | 信息不对称：少数股票被大量关注，多数被忽视（幂律分布的来源） |
| IC时序 | 接近正态 | 中心极限定理：每期IC是大量个股相关性的平均，趋向正态 |
| 收益率 | 左偏厚尾 | 市场微结构：恐慌性抛售比贪婪性买入更集中，下跌更极端 |
