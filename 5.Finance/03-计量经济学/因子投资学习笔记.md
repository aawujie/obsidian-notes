# 1. 线性代数基础

## 1.1 矩阵与向量运算

### 矩阵加减法

若A = [aij]和B = [bij]都是m×n矩阵，则A ± B = [aij ± bij]

### 矩阵乘法

若A是m×n矩阵，B是n×p矩阵，则AB是m×p矩阵，且(AB)ij = Σ(k=1 to n) aik bkj

### 矩阵转置

若A = [aij]，则A^T = [aji]，即行变列，列变行

### 向量内积

对于向量a, b ∈ R^n，内积为a·b = a^T b = Σ(i=1 to n) ai bi

## 1.2 矩阵的逆与行列式

### 矩阵的逆

对于n×n方阵A，若存在矩阵A⁻¹使得AA⁻¹ = A⁻¹A = I，则A⁻¹称为A的逆矩阵

### 矩阵的行列式

行列式det(A)是一个标量值，只有方阵才有行列式，det(A) ≠ 0当且仅当A可逆

## 1.3 向量空间与线性变换

### 向量空间的定义

向量空间V是满足加法和标量乘法封闭性的集合，需满足8条公理

### 线性变换

函数T: V → W称为线性变换，如果T(αu + βv) = αT(u) + βT(v)，其中α, β是标量，u, v是向量

## 1.4 特征值与特征向量

### 特征值与特征向量的定义

对于n×n矩阵A，若存在标量λ和非零向量v使得Av = λv，则λ称为A的特征值，v称为对应的特征向量

### 特征值分解

对于可对角化的n×n矩阵A，存在A = VΛV⁻¹，其中V是由特征向量组成的矩阵，Λ是对角矩阵，对角元素是特征值

## 1.5 奇异值分解(SVD)

### SVD定义

对于任意m×n矩阵A，都可以分解为A = UΣV^T，其中U是m×m正交矩阵，Σ是m×n对角矩阵(奇异值)，V是n×n正交矩阵

### SVD在因子投资中的应用

- 降维：提取最重要的因子
- 去噪：过滤数据中的噪声
- 协方差矩阵分解：风险模型构建

# 2. 概率统计基础

## 2.1 概率分布

### 正态分布(Normal Distribution)

概率密度函数：f(x|μ,σ²) = (1/√(2πσ²)) × exp(-(x-μ)²/(2σ²))

- μ: 均值参数，决定分布的位置
- σ²: 方差参数，决定分布的离散程度
- 在金融领域广泛应用，如股票收益率建模

### 多元正态分布(Multivariate Normal Distribution)

X ~ N(μ, Σ)，其中μ是均值向量，Σ是协方差矩阵

概率密度函数：f(x) = (1/((2π)^(k/2)|Σ|^(1/2))) × exp(-½(x-μ)^T Σ⁻¹ (x-μ))

### t分布(Student t-Distribution)

当样本量较小且总体标准差未知时，样本均值的标准化统计量服从t分布

t = (x̄ - μ)/(s/√n) ~ t(n-1)，其中n为样本大小，自由度为n-1

### 卡方分布(Chi-Square Distribution)

若Z₁, Z₂, ..., Zₖ相互独立且都服从标准正态分布N(0,1)，则Σᵢ₌₁ᵏ Zᵢ²服从自由度为k的χ²分布

## 2.2 贝叶斯定理

P(A|B) = P(B|A)P(A) / P(B)

- P(A|B): 后验概率，已知B发生条件下A发生的概率
- P(B|A): 似然函数，已知A发生条件下B发生的概率
- P(A): 先验概率，A发生的先验概率
- P(B): 边际似然，证据因子

## 2.3 中心极限定理(CLT)

对于独立同分布的随机变量X₁, X₂, ..., Xₙ，均值为μ，方差为σ²，则当n→∞时：

√n(X̄ - μ)/σ → N(0,1)

即样本均值X̄近似服从N(μ, σ²/n)分布

## 2.4 参数估计

### 矩估计法(Method of Moments)

用样本矩代替总体矩来估计参数的方法

### 最大似然估计(Maximum Likelihood Estimation)

找到使样本出现概率最大的参数值

L(θ|x₁,...,xₙ) = Π f(xᵢ|θ)，最大化似然函数L(θ)或对数似然函数ln L(θ)

# 3. 优化与数值方法

## 3.1 凸优化基础

### 凸集与凸函数

凸集：对于集合C中任意两点x₁, x₂，连接这两点的线段也在集合C中，即：

θx₁ + (1-θ)x₂ ∈ C，∀θ ∈ [0,1]

凸函数：对于定义域内的任意两点x₁, x₂，有：

f(θx₁ + (1-θ)x₂) ≤ θf(x₁) + (1-θ)f(x₂)，∀θ ∈ [0,1]

### 凸优化问题的一般形式

min f₀(x)

s.t. fᵢ(x) ≤ 0, i = 1,...,m

Ax = b

其中f₀, f₁, ..., fₘ均为凸函数

## 3.2 梯度下降法

梯度下降是一种一阶最优化算法，用于寻找函数的局部最小值

### 算法步骤

1. 初始化参数x⁰
2. 重复执行直到收敛：x^(k+1) = x^k - α∇f(x^k)
3. 其中α是学习率，∇f(x^k)是梯度

## 3.3 牛顿法

牛顿法是一种二阶最优化算法，利用了函数的一阶和二阶导数信息

### 算法步骤

4. 初始化参数x⁰
5. 重复执行直到收敛：x^(k+1) = x^k - [∇²f(x^k)]⁻¹∇f(x^k)
6. 其中∇²f(x^k)是海塞矩阵(Hessian Matrix)

## 3.4 拉格朗日乘数法

拉格朗日乘数法用于求解约束优化问题

### 等式约束优化问题

min f(x)

s.t. hᵢ(x) = 0, i = 1,...,m

### 拉格朗日函数

L(x, λ) = f(x) + Σᵢ λᵢ hᵢ(x)

### KKT条件（Karush-Kuhn-Tucker条件）

对于一般约束优化问题：

min f(x)

s.t. gᵢ(x) ≤ 0, i = 1,...,p

hⱼ(x) = 0, j = 1,...,q

- 驻点条件：∇f(x*) + Σᵢ λᵢ∇gᵢ(x*) + Σⱼ μⱼ∇hⱼ(x*) = 0
- 原始可行性：gᵢ(x*) ≤ 0, hⱼ(x*) = 0
- 对偶可行性：λᵢ ≥ 0
- 互补松弛性：λᵢgᵢ(x*) = 0

# 4. 计量经济学与回归分析基础

## 4.1 普通最小二乘法 (OLS)

### 基本原理

- 目标：最小化残差平方和
- 对于模型 y = Xβ + ε，寻找β̂使Σei²最小

### OLS估计量

β̂ = (X^T X)⁻¹ X^T y

### OLS性质

- 线性性：β̂是y的线性函数
- 无偏性：E[β̂] = β
- 有效性（高斯-马尔可夫定理）：在所有线性无偏估计中，OLS具有最小方差

### 经典假设

7. 线性关系：y = Xβ + ε
8. 随机抽样：观测独立
9. 无完全共线性：X列满秩
10. 条件均值为零：E[ε|X] = 0
11. 同方差性：Var(ε|X) = σ²I
12. 正态性（可选）：ε|X ~ N(0, σ²I)

### 在因子投资中的应用

- 估计因子载荷（暴露度）
- 构建因子模型
- 评估因子收益

## 4.2 岭回归 (Ridge Regression)

### 基本原理

- 在OLS基础上添加L2正则化项
- 目标函数：RSS + λΣβj²
- 其中λ是正则化参数

### 岭回归估计量

β̂_ridge = (X^T X + λI)⁻¹ X^T y

### 优点

- 解决多重共线性问题
- 改善预测精度
- 系数收缩，减少过拟合

## 4.3 Lasso回归

### 基本原理

- 使用L1正则化：RSS + λΣ|βj|
- 可以将某些系数压缩至0，实现变量选择

### Lasso估计量

β̂_lasso = argmin{Σ(yi - β0 - Σxijβj)² + λΣ|βj|}

### 优点

- 自动进行变量选择
- 处理高维数据
- 产生稀疏模型

## 4.4 判定系数 (R²)

### 定义

R² = 1 - (SSE/SST) = SSR/SST

- SSE: 残差平方和
- SST: 总平方和
- SSR: 回归平方和

### 解释

- 表示模型解释的变异比例
- R² ∈ [0, 1]，越接近1越好
- 调整R²：考虑自由度影响，避免过度拟合

## 4.5 多重共线性

### 定义

回归变量间存在高度线性相关关系，导致参数估计不稳定

### 检测方法

- 方差膨胀因子(VIF)：VIF > 10表示严重共线性
- 条件指数：> 30表示严重共线性
- 相关矩阵：观察变量间相关系数

### 解决方法

- 岭回归或Lasso回归
- 主成分回归
- 删除相关变量
- 获取更多数据

## 4.6 模型比较与选择

### 信息准则

AIC = 2k - 2ln(L)

BIC = k·ln(n) - 2ln(L)

- 其中k为参数个数，L为似然函数最大值

### 交叉验证

- k折交叉验证
- 留一法交叉验证
- 评估模型泛化能力

## 4.7 关键公式汇总

### OLS标准误

se(β̂) = √[σ̂² · diag((X^T X)⁻¹)]

### t统计量

t = β̂j / se(β̂j)

### F统计量

F = [(SSR_restricted - SSR_unrestricted)/q] / [SSR_unrestricted/(n-k)]

### 调整R²

$R²_adj = 1 - [(n-1)/(n-k)](1-R²)$

## 4.8 实践要点

- 检验模型假设是否满足
- 注意多重共线性问题
- 合理选择模型复杂度
- 重视经济意义而非仅统计显著性

# 5. 因子投资基础理论

## 5.1 多因子模型概述

### 因子模型基本形式

R_it = α_i + β_i1 F_1t + β_i2 F_2t + ... + β_ik F_kt + ε_it

- R_it: 资产i在时间t的收益率
- α_i: 资产i的截距项（异常收益）
- β_ij: 资产i对第j个因子的敏感度（因子载荷）
- F_jt: 第j个因子在时间t的值
- ε_it: 资产i在时间t的特异性收益（无法被因子解释的部分）

### 因子模型的类型

- 统计因子模型：通过统计方法（如PCA）从收益率数据中提取因子
- 宏观因子模型：使用宏观经济变量作为因子（如GDP增长率、通胀率、利率等）
- 基本面因子模型：使用公司基本面指标作为因子（如市盈率、账面市值比、规模等）

## 5.2 风险模型

### 风险分解

总风险 = 系统性风险 + 特异性风险

Var(R_it) = Var(Σβ_ij F_jt) + Var(ε_it)

对于投资组合P，其方差可分解为：

σ²_P = w^T B F B^T w + w^T Ψ w

- w: 资产权重向量
- B: 因子载荷矩阵
- F: 因子协方差矩阵
- Ψ: 特异性风险对角矩阵

## 5.3 因子分类

### 按来源分类

- 风险因子：源于经济风险的因子（如市场、规模、价值等）
- 风格因子：反映投资风格的因子（如成长/价值、动量、质量等）
- 行业/板块因子：特定行业或板块的因子

### 按性质分类

- 宏观因子：宏观经济变量驱动的因子
- 微观因子：基于个股特征的因子

## 5.4 投资组合优化

### 均值-方差优化

min w^T Σ w

s.t. w^T μ ≥ r_min

w^T 1 = 1

- w: 资产权重向量
- Σ: 收益率协方差矩阵
- μ: 预期收益率向量
- r_min: 最小预期收益率要求

### 风险预算

风险预算是在投资组合层面分配风险的过程，确保每个资产或因子的风险贡献符合投资目标。

边际风险贡献：MRC_i = ∂(w^T Σ w) / ∂w_i = (2Σw)_i

风险贡献：RC_i = w_i × MRC_i = 2w_i(Σw)_i

总风险：σ_P = √(w^T Σ w) = Σ_i RC_i

## 5.5 实践要点

- 因子模型的选择应基于经济逻辑和实证表现
- 定期重新校准因子暴露和风险模型
- 注意因子之间的相关性，避免过度集中
- 结合因子择时策略，动态调整因子权重

重点：因子投资通过识别和利用系统性风险源来构建更优的投资组合

# 总结

因子投资是一种基于系统性风险因子构建投资组合的方法，它结合了现代投资组合理论和实证金融研究的成果。通过识别和利用能够解释资产收益差异的风险因子，投资者可以构建更加分散化、风险调整后收益更高的投资组合。

成功的因子投资需要扎实的数学基础，包括线性代数、概率统计、优化理论和计量经济学知识。这些工具不仅帮助我们理解因子模型的内在机制，还使我们能够有效地估计、检验和应用这些模型。

在实践中，因子投资涉及因子识别、模型构建、风险管理和组合优化等多个环节。每个环节都需要仔细考虑数据质量、模型假设和实际应用的限制。持续的监控和调整是确保因子投资策略有效性的关键。
