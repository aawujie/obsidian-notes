# 龙虎榜中频事件驱动策略

## 一句话

每天扫龙虎榜机构席位→捕捉机构净买入信号→持仓1周获利。夏普5.20，与月频基本面低相关（r=-0.14），完美的卫星策略。

---

## 策略逻辑

### 为什么有效

龙虎榜是当日异常波动股票的"成交明细公示板"。机构在龙虎榜上的大额净买入，往往不是随机行为——背后可能是：

1. **建仓启动**：机构看中某只股票，大量买入导致涨跌停/高换手率上榜
2. **趋势确认**：机构净买入 = 专业资金的主动选择，跟风有alpha
3. **短期动量**：机构买入后1~2周内，市场关注度上升、跟风盘推动价格

### 为什么只持1周

机构上榜后的超额收益衰减很快：
- 1周：超额15.9%年化、胜率62.4% ✅
- 2周：6.4%年化、胜率61.2% ⬇️
- 3周：3.3%年化、胜率58.6% ⬇️
- 4周：2.3%年化、胜率56.2% ⬇️

信号有效期≈5个交易日，过了就回归噪声。

---

## 信号定义

| 等级 | 条件 | 目的 |
|:---|:---|:---|
| 强信号 | 净买入>5000万 + 占比>1% + 机构≥2家 | 多重确认，降低假信号 |
| 中信号 | 净买入>1000万 + 占比>0.5% | 扩大覆盖率 |

**反直觉发现**：低机构数（1~2家）表现优于高机构数（≥3家）——夏普4.59 vs 3.29。多家机构同时买反而可能是见顶信号（抢筹结束=趋势尾声）。

## 策略规则

```
每天收盘后：
  1. AKShare拉龙虎榜→筛机构净买入
  2. 排除涨停日（买不到）、排除ST/退市
  3. T+1开盘买入，等权分配
  4. 持有5个交易日→到期卖出
  5. 最大同时持仓20只
  6. 佣金千一（买卖各千一）
```

**保守假设已实现：**
- 涨停日不买（涨跌幅≥9.9%）
- 跌停日不卖（涨跌幅≤-9.9%）
- T+1建仓（不是当日买入）

## 混合组合方案

```
总资金 = 100%

核心仓位（80%）：月频基本面+惊喜组合
  - 5因子选股，月频调仓，796池
  - 年化46.7%，夏普2.20，回撤5.8%

卫星仓位（20%）：中频龙虎榜
  - 机构信号触发，1周持有
  - 年化19.1%，夏普5.20，回撤23.9%

预期混合效果：
  - 总夏普 ≈ √(0.8²×2.20² + 0.2²×5.20²) ≈ 2.04
    （假设r=0，实际r=-0.14更优）
  - 混合后回撤受基本面主导（核心仓位大）
```

## 风险与注意事项

1. **样本量有限**：仅2年数据，479笔交易。市场结构变化可能影响
2. **回撤偏大**：23.9%，单一挂票可能很惨
3. **信号噪声**：龙虎榜里机构行为复杂，不是所有净买入都有alpha
4. **策略容量**：单次持仓20只、每日开2~3个新仓，适合小资金
5. **不是全天候**：熊市可能继续有信号但超额减弱
