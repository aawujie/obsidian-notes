# 量化交易终极框架：尾部风险与生存系统

> 来源：视频课程笔记整理
> 核心主题：厚尾分布 → 仓位优化 → 七层系统架构 → 生存优先

---

## 第十一章：极端风险与尾部建模

### 1. 正态分布是最大的幻觉

| 事件 | 正态假设下的概率 | 现实 |
|:---|:---|:---|
| 3σ事件 | 0.27% | 远更频繁 |
| 5σ事件 | 10⁻⁷（几乎不可能） | 2008/2015/2020 全发生过 |

金融收益具有**显著的厚尾性（Fat-tailed）**。

### 2. 厚尾的数学直觉

**学生分布 R ~ t(v)**：自由度 v 越小，尾部越"厚"。

| 分布 | 5σ概率 |
|:---|:---|
| 正态分布 | ~10⁻⁷（十亿分之一） |
| t(4) 分布 | ~10⁻³（千分之一） |

**尾部概率差一万倍。**

### 3. 厚尾对仓位的毁灭性

经典Kelly：`f* = μ/σ²`，假设方差有限且波动线性。

厚尾下：
- 单次极端亏损概率远高
- 一个 -20% 单日损失 → 抹去数年收益
- 极端值直接威胁资本生存

### 4. 极值理论（EVT）

关注：`P(R < -x)`

- 正态分布：指数衰减（快）
- 厚尾分布：**幂律衰减** `P ~ x^(-α)`（慢得多）

尾部风险被远远低估。

### 5. 实盘尾部来源（结构性溃败）

1. **流动性突然消失**：市场深度骤降
2. **杠杆挤兑**：保证金不足 → 强制平仓潮
3. **强制平仓链反应**：跌→平→更跌→更多平
4. **政策突变**：突发公告改变规则
5. **交易机制异常**：宕机、熔断

### 6. 跳跃扩散模型（Jump-Diffusion）

```
dP_t = μ·dt + σ·dW_t + J·dN_t
```

| 成分 | 含义 |
|:---|:---|
| dW_t | 布朗运动 → 连续波动（"正常"） |
| dN_t | 泊松过程 → 跳跃发生概率 |
| J | 跳跃幅度（可正可负） |

引入跳跃后：方差↑、偏度↑、极端事件概率↑

### 7. 跳跃风险下最优仓位下降

```
E[log(1+Rf)] = μf - ½·f²σ² - λ·f·E[jump_loss]
                                    ↑ 惩罚项
```

即使跳跃概率很小，**最优仓位 f 也会显著下降**。

### 8. 实盘尾部防御

**方法1：极端损失限制（Hard Stop-Loss）**
```
f ≤ L_max / max_predicted_loss
```

**方法2：尾部压力测试**
- 波动率放大X倍
- 相关性→1
- 流动性抽干
- 点差飙升
- 扛不住 → 降杠杆

**方法3：尾部对冲**
- 长波动率策略（Straddles/Strangles）
- 深度虚值期权
- 跨市场对冲
- ⚠️ 平稳期拖累收益，极端期保护资本

### 9. 2020年策略同时爆炸的原因

波动↑ + 相关→1 + 流动↓ + 执行成本↑ + 参数滞后 + 连续亏损 → 强制平仓

**六个因素同时叠加。**

### 10. 生存悖论

```
即使 E[R_t] > 0（长期正期望）
只要 P(R_t = -50%) > 0（存在极端亏损可能）
只要时间足够长 → 策略必然经历毁灭性打击
```

**生存优先于增长最大化。**

## 第十二章：量化交易的统一框架

### 1. 本质不是预测

**本质是**：信息不断到来 → 持续做分布估计 → 在资本约束下动态决策

```
信息处理 → 分布估计 → 资本约束决策（闭环）
```

### 2. 六个核心变量

| 变量 | 含义 |
|:---|:---|
| S | 信号（Signal） |
| Y | 市场观测（Observation） |
| Z | 市场状态（State） |
| V | 真实价值（Value） |
| f | 仓位决策（Position） |
| W | 资本（Capital） |

### 3. 七层系统架构

**第一层：信号生成**
```
S_t ~ S(data_{t-1})
```
信号需要被验证，建立条件分布先验 P(S_t | S)

**第二层：贝叶斯估值更新**
```
P(V_t | S_t, Y_t)
```
信号 + 观测 + 先验 → 后验分布

**第三层：状态识别**
```
P(Z_t | Y_t, V_t)
```
趋势/波动/季节性/事件驱动 → 市场状态切换

**第四层：收益分布构造**
```
R_t ~ f(S_t, Z_t, F_t)
```
不再是简单 μ、σ，而是信号×状态×执行的联合分布

**第五层：仓位函数**
```
f_t = f(S_t, σ²_t, Z_t, W_t)
```
取决于条件均值、条件方差、市场状态、当前资本

**第六层：执行模型**
```
R_real = R - Cost - Adverse Selection
```
理论收益 - 交易成本 - 逆向选择 = 实盘收益

**第七层：资本更新（含约束）**
```
W_{t+1} = W_t(1 + R_real)
```
约束：风险预算 + 生存约束 + 仓位约束

### 4. 为什么七层缺一不可

| 缺少哪一层 | 后果 |
|:---|:---|
| 贝叶斯更新 | 僵化不变，无法适应市场变化 |
| 状态识别 | regime shift 时仓位决策严重错误 |
| 执行建模 | 回测收益无法在实盘实现（幻觉） |
| 资本约束 | Kelly仓位遭遇极端事件→爆仓 |
| 尾部约束 | 统计套利遇极端事件→彻底崩溃 |

### 5. 七层对应实操模块

| 模块 | 对应 |
|:---|:---|
| Alpha引擎 | 多因子模型、多时间尺度分析 |
| 分布估计 | 条件均值/波动率建模、尾部风险估计 |
| 状态识别 | 波动率/相关性/流动性 regime 识别 |
| 执行引擎 | 成交摩擦模型、冲击成本、逆向选择检测 |
| 仓位优化 | Fractional Kelly、风险预算、波动率目标 |
| 在线监控 | 残差检测、漂移检测、尾部压力测试 |
| 资本保护 | 分路风控、自动降仓、强制停机 |

### 6. 关键思想

1. **你交易的是分布，不是预测值**（Trade the distribution）
2. **成交会改变分布**（Execution alters the distribution）
3. **市场状态会改变分布**（Market state changes the distribution）
4. **资本是乘的过程，尾部决定生存**（The tail dictates survival）
5. **系统必须递归更新，持续监控漂移**（Always drift）

### 7. 终极目标

❌ 不是最大收益

✅ **在长期竞争中保持正期望，同时避免灭绝**

## 对照我们当前系统的差距

| 层级 | 我们有什么 | 缺什么 |
|:---|:---|:---|
| 信号生成 | ✅ 5基本面因子 + IC检验 | |
| 贝叶斯更新 | ⚠️ 卡尔曼做了但边际提升小 | 真正的贝叶斯后验框架 |
| 状态识别 | ⚠️ 风控有仓位管理 | 独立的regime识别模块 |
| 收益分布 | ❌ 仍用简单μ/σ | 厚尾建模、EVT |
| 仓位优化 | ✅ risk_manager有止损 | Fractional Kelly、波动率目标 |
| 执行模型 | ⚠️ 加了滑点/涨停约束 | 冲击成本、逆向选择 |
| 资本保护 | ✅ 回撤止损 | 尾部压力测试、自动降仓 |

**最关键的缺失：第3层（状态识别）和第4层（厚尾分布估计）。**
