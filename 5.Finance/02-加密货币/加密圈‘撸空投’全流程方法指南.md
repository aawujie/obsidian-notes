# 2. Overview

视频核心论题与结论：所谓“空投”（AirDrop）是项目方为了吸引用户、奖励早期使用者而发放代币的行为。要想稳定有效地“撸空投”，需要系统化准备工具（浏览器、邮箱、社交账号、钱包等）、理解手续费（Gas fee）与跨链成本、学会发现有潜力的项目并用数据验证、以“真实用户”心态长期、多样化地链上交互、使用任务平台和记录工具管理多账户，最后及时、安全地领取空投并防范钓鱼。成功有时靠运气，但长期看重的是方法、数据与耐心。视频以自身经验与多个平台/项目案例（如StarkNet、Hyperliquid、Arbitrum、Optimism、WarmHall 等）说明了整套流程与注意事项。

# 3. 按照主题来梳理

## 3.1 准备工具与钱包：从浏览器到私钥保管的完整清单

- 要开始撸空投，第一步是把基础工具准备齐全。视频建议在电脑上安装 Google Chrome（Chrome 浏览器），因为大部分链上交互插件（如 MetaMask 小狐狸钱包、OKX Wallet）都是基于 Chrome 插件而优化的。其他浏览器（Firefox、Edge）虽能用，但兼容性多有差异，容易造成交互失败或不便。
- 邮箱方面，首选 Gmail（谷歌邮箱）。许多项目方的白名单和内测邀请都通过 Gmail 发放，国内如 QQ、163 等邮箱有时会接收不到通知或被延迟，所以用 Gmail 是标准配置。不要用不常用或不专业的邮箱，以免错过重要通知或被系统拦截。
- 社交工具必须有两个核心：X（原推特，Twitter）和 Discord（简称 DC）。X 是新项目发布信息、合作和空投预告的一线通道，很多任务也需要绑定或验证 X 账户。Discord 则是早期项目、测试版、Bug 反馈和任务频道的集中地，缺少 Discord 身份会严重影响获取深度空投的机会。
- 钱包（Wallet）是你的数字身份，必须准备且谨慎使用。MetaMask（小狐狸）是以太生态（如 Arbitrum、Base、Optimism 等）常见的标配钱包；非以太生态例如 Solana 则常用 Phantom。如今有多链钱包（如 OKX Wallet），能一次性支持主流链，减少频繁切换网络的麻烦。选择钱包时要考虑链的兼容性与使用便捷性。
- 创建钱包时的安全准则：一定要把助记词（注记词）或私钥离线保存（写在纸上，不要联网拍照、不要存云端）。助记词和私钥相当于银行卡密码，一旦泄露别人可以直接转走资产。切记不要把私钥或助记词上传到任何在线服务或截图存储。
- 小结：工具准备阶段的核心是兼容性、及时接收信息和严格保密。Chrome + Gmail + X + Discord + 一款合适的钱包，配合谨慎的私钥管理，是后续所有操作的基础和前提条件。

## 3.2 Gas fee（手续费）与跨链成本优化：怎么把成本降下来并提高收益率

- Gas fee（链上手续费）是链上操作必须的“通行费”，它以对应链的原生代币支付（例如以太坊主网的 Gas 以 ETH 支付，BNB 链的 Gas 以 BNB 支付）。无论是转账还是使用 dApp，没有 Gas fee 交易就无法上链，因此对空投策略有直接影响，关乎成本和收益率。
- 不同链的费用差别很大：以太坊主网的 Gas 目前有所下降，但一次交互仍需数美元到几十美元不等，因此如果频繁在主网上做操作，成本会把收益吞掉。相对便宜的链包括 Optimism、Base、OP Stack 以及 Solana 等，新兴链的一笔交易可能只需几毛或几分，这使得资金量小的用户也能进行多样化交互以构建“真实用户”画像。
- 三个节省 Gas 的实际方法：
    1. 避免直接使用官方跨链桥：官方跨链桥通常手续费高且步骤复杂，成本容易失控。视频建议用中心化交易所（CEX）的提币功能作为“低成本跨链”方案：先在中心化交易所把资产提到目标链，这样可以省下桥接的高额费用。该方法依赖交易所的入金/提币渠道。
    2. 使用 LayerZero 等跨链工具：这类协议在某些情况下能提供更低成本的跨链 Gas 支付方案（视频提到 LayerZero 为例），是老玩家节省成本的实战技巧之一。
    3. 选择合适的交互时机：Gas fee 在一天内有波动，通常上午 10 点到下午 3 点之间相对便宜（视网络拥堵情况而变化），合理安排交易时间可以节省一部分成本。
- 资金准备建议：如果要在以太坊主网频繁交互，至少要准备几十到几百美元的 ETH 作备用（视频示例建议“几百美元”级别以备多次交互所需）。对于想在低费链上操作的用户，少量资金即可开展高频操作，从而在成本可控的前提下构建良好链上记录。
- 注意：节省成本不能以牺牲安全为代价。比如以为“省费”就使用来路不明的第三方服务，或将私钥交给他人，这些都是风险很高的行为。

## 3.3 如何挑选有潜力的项目：产品、团队、融资与链上数据的使用

- 视频强调：要捞到“大空投”，必须提前发现“潜力项目”。挑选项目的三项核心判断标准是产品力、团队背景和融资情况。光看表面宣传或追风入场往往太晚、收益有限，甚至会被项目方反撸（即付出更多未获回报）。
- 产品力考察：观察项目是否在解决真实问题，用户体验是否优秀，是否有场景可以吸引并留住用户（如 Hyperliquid 的链上衍生品交易就属于强产品力示例：流动性好、交易体验不输给传统交易所、用户留存高）。一个有用且被真实用户接受的产品，未来发币和市值扩张的概率更大。
- 团队背景：团队是否有金融、量化或顶级交易所的从业经验，这类背景通常意味着他们既懂市场也懂技术，产品设计更务实。例如视频中的 Hyperliquid 团队成员多数有华尔街量化或交易所背景，这被视为积极信号。
- 融资与背后资本：查看项目是否获得顶级 VC 支持（如 A16Z、Paradigm 等），有强大资本背书的项目更可能获得更大资源、上市交易所支持以及更好的发行策略，从而空投价值可能更高。若查不到团队信息或融资记录，则要警惕项目质量。
- 数据平台与链上情报站：视频推荐多个数据平台作为免费情报站：
    - DeFiLlama：查看项目的 TVL（总锁仓量），TVL 是衡量项目资金流入和热度的关键指标。TVL 稳步上升通常意味着资金和用户都在持续流入，是潜在大空投的早期信号。
    - RootData：可查询项目团队成员履历、融资轮次与投资机构背景，帮助验证项目背书与专业度。
    - DoomAnalytics（视频提到用于社区统计与交互分析）：可以分析项目交互数据，判断哪些钱包或交互行为真正符合项目方的筛选标准。
- 数据如何应用：当 TVL 与活跃钱包数双双上升时，表明项目在吸引资金与用户，这类趋势通常在代币发行前就会显现。提早在这些阶段参与并做深度交互，往往能在发币时获取较高份额的空投。
- 小结：发现好项目先靠判断产品、团队和融资，再用链上数据平台验证。不要凭感觉或跟风，数据会揭示哪些早期项目值得投入时间做深度交互。

## 3.4 以“真实用户”心态构建交互：频率、多样性与长期性的重要性

- 视频强调“真实用户”心态极其重要。项目方希望奖励那些在早期无人问津时就长期使用其产品的真实用户，而不是机械地批量创建钱包、短期内做大量重复性操作的“空投猎人”。当流量暴增、行为模式高度一致时，项目方很容易把这类地址识别为恶意批量操作并直接排除。
- 交互频率：不要一口气在短时间内做十几笔交易，然后消失。更自然的策略是分散操作，隔几天做一点，模拟真实使用节奏。长期、稳定的活跃度比一次性高频操作更受青睐。项目方通常会查看交互历史的时间跨度与频率来判断真实度。
- 交互多样性：不要只做单一类型操作（比如只 Swap）。应当覆盖更多 dApp 功能：Swap、借贷、质押、参与 NFT 市场、Mint NFT、交易衍生品、跨链、提交治理投票等。多样化的操作能体现你对产品的真实使用，项目方据此判断该地址是否应当纳入空投名单。
- 上链与下层活动结合：对于社交类或治理类项目（如 Farcaster），仅有链上“练上”（on-chain）动作不够，还需在社区（如 X、Discord）有“练下”（off-chain）互动：发推、点赞、评论、参与社区讨论等。上链与社群活动结合更能体现忠实用户画像。
- 费用与链的选择：虽然以太主网操作贵，但许多潜力项目会在 Base、OP、StarkNet、Solana 等低费链上。对于资金不多的用户，建议在这些低费链上坚持做多样化、长期的交互，性价比更高。
- 真实化技巧汇总：
    1. 分散频次：每个钱包把操作分布在若干天或数周内，而不是一日完成；
    2. 多样性操作：涵盖 Swap、借贷、NFT、跨链、参与测试、提交反馈等；
    3. 社区互动：在 X、Discord 上有发言和互动，使链上与链下行为一致；
    4. 模拟正常用户路径：从注册、充值、体验、反馈到常规使用，形成完整的用户生命周期轨迹。
- 数据支持：DoomAnalytics 社区统计显示，超过 60% 的大额空投钱包至少有 10 次以上的多样化交互。这说明频次与多样性成了项目方筛选空投对象的硬标准。StarkNet 的空投就明确把“交互深度”作为评判标准，浅薄的操作往往得不到任何奖励。

## 3.5 空投任务平台、记录与多钱包管理：如何高效不出错地执行策略

- 空投任务平台：许多项目会把空投任务和社交任务发布在专门的平台或聚合站上，视频举例 Galaxy（Galaxy）为常见任务平台。项目方在这些平台上发布的任务包括关注 X、参与测试、Mint NFT、加入 Discord 等。新手往往不知道从哪找任务，聚合平台能集中展示并带有任务指引，便于新人入手。
- 记录与追踪的重要性：当你开始使用多个钱包并参与多个项目时，很容易出现遗漏或重复操作。视频建议必须建立自己的记录体系，保证操作清晰可追溯。具体方法如下：
    1. 链上分析工具：使用 DoomAnalytics、DeFiLlama 等工具去查询项目交互数据和自己的账户排名，理解自己和竞争者之间的差距。某些项目方也会使用这些数据来筛选空投对象，所以你也要学会用这些工具。
    2. Excel（或类似表格）：这是最原始但最实用的方法。建立表格记录每次操作的日期、钱包地址、交互项目、操作类型、链别和费用等。这样能避免漏做或重复，同时便于事后统计每个钱包的“产出”。
    3. 多钱包管理工具：当钱包数量较多，应使用聚合或多账户管理工具（如 Metamask 多账户、OKX Wallet 的账户切换功能，或视频推荐的 dbank 聚合平台）来一键查看所有钱包资产和交互记录，提高效率并避免混乱。
- 多账户操作的风险控制：多钱包并非越多越好，关键在于“每个钱包都要能支撑真实使用的轨迹”。不要为了数量而牺牲质量。每个钱包最好都有一段持续且多样化的使用历史，否则很容易被项目方识别为批量行为而被排除。
- 流程化执行建议：把任务拆成具体步骤并列成清单执行：先在任务平台筛选项目 → 在表格里记录任务与截止时间 → 用多钱包管理工具依次完成并打勾 → 定期在链上分析工具检查自己钱包的分布与深度。这个流程能显著降低失误率并提高长期收益。

## 3.6 领取空投与防骗：快照、领取方式与钓鱼网站的辨别

- 及时关注空投信息源：空投的领取信息通常在项目官网、X、Discord 的官方频道发布。要第一时间知道公告，必须加入项目的官方渠道并开启通知（尤其是 Discord 的公告频道），否则很容易错过最佳领取时机。视频提到很多人因为没进群或看到公告晚一步而错过领取，导致后续代币价格下跌时损失巨大。
- 快照概念：大多数项目会在某个时间点对链上数据做“快照”，按快照时的持仓与交互数据分发空投。例如 Arbitrum 的空投是根据某一时间点之前的交互进行统计。错过快照或在快照之后才开始大量交互，往往无法获得空投或收益大幅降低。因此要关注官方公布的快照时间并提前做好准备。
- 领取方式有两类：
    1. 官网领取（Claim）：项目官网在规定时间内开放领取，用户连接钱包并签名即可 Claim。这里要注意官网链接必须来自官方渠道，避免钓鱼。
    2. 交易所发放：一些项目与交易所达成合作，会直接把空投打到用户在交易所的账户里（如某些情况下项目方直接在中心化交易所分发）。这类领取方法的优点是无需个人签名，但要确认自己的交易所账户是否符合资格。
- 钓鱼网站风险与防范：空投发放期间，钓鱼网站通常以“与官网一模一样”的界面诱骗用户连接钱包并签名，以窃取资产或私钥。防范要点：
    - 一定要通过官方公告的链接进入官网，避免通过搜索或非官方重定向链接进入；
    - 三次核对网址是否为官方域名；不要点开不明链接或社群中未经证实的短链；
    - 永远不要在任何网站直接签署“带有权限转移资产”的交易签名，尤其是第一次看到的合约批准签名；先在链上查询合约并确认；
    - 若不确定，可在社群中等待官方二次确认再操作。
- 领取期限与过期风险：空投通常设置领取期限，过期未领会被回收。视频举例 Arbitrum 第一轮有超过 7000 万枚代币没人认领最终被回收，造成实际价值损失。及时领取并留意公告是避免损失的关键。
- 小结：领取空投的两大要点是信息及时性和安全性。关注官方公告、核对快照时间、选择正确的领取方式并警惕钓鱼网站，才能真正把链上“努力”转化为现实收益。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：从工具准备到兑现收益的“六步执行框架”（可作为长期策略流程）
    1. 工具准备（Prepare）：安装兼容浏览器（Chrome）、注册 Gmail、开通 X（Twitter）与 Discord、选择并创建合适的钱包（MetaMask/OKXWallet/Phantom 等），并把私钥/助记词离线保存。这个阶段确保信息通路和身份准备就绪，是所有操作的前提。
    2. 项目猎取（Discovery）：用数据平台（DeFiLlama、RootData、DoomAnalytics 等）筛选潜力项目，重点关注 TVL、活跃用户增长、团队与融资背景。把潜在目标列入候选清单，优先级排序。
    3. 深度交互（Engage）：以“真实用户”心态在项目上做长期、分散、且多样化的交互（Swap、借贷、NFT、治理、社群互动等），并在社区（X、Discord）参与讨论。频次和多样性是被项目方识别的关键。
    4. 记录追踪（Track）：用 Excel 或专业工具记录每次交互，保持多钱包管理工具同步，定期用链上分析工具检视自己钱包的表现和项目快照时间。
    5. 成本控制（Optimize）：通过选择低费链、在合适时间操作、用交易所提币替代桥等方式降低 Gas 费用，确保每次交互的投入产出比合理。
    6. 领取与兑现（Claim）：密切关注官方公告，按官网或交易所渠道领取空投，核对链接并防范钓鱼，领取后择机在合适场景兑换或交易。务必在领取期限内完成认领。
这个六步框架把视频中散落的建议体系化，强调顺序与闭环：没有准备好工具，就无法及时获知项目；没有记录与成本控制，收益会被费用或失误吞掉；没有及时领取，努力可能化为乌有。
- 心智模型一：长期主义与用户画像心态（Mindset：长期真实用户优先于短期套利者）
    - 核心思想：空投本质是项目对早期真实参与者的奖励。早期“陪伴”和真实使用胜过短期大量的机械化操作。项目方要筛选的是能够代表长期价值支持的人，而不是临时出现、模式化操作的地址。因此在策略上要以长期主义为主，把构建“真实用户画像”当作第一目标。
    - 具体做法与心理要求：
        - 忍耐与节奏感：不要追求一夜暴富，而要把操作分布在更长的时间窗口内，表现出自然使用节奏；
        - 多维参与：不仅仅在链上做交易，也要参与社区讨论与产品反馈，形成上链与下层行为的一致性；
        - 数据驱动而非跟风：用 TVL、活跃钱包数、融资方信息等数据判断项目，而不是被社群舆论或短期爆点牵着走；
        - 风险意识与安全优先：在任何操作中把私钥安全放在第一位，谨防钓鱼和不必要的签名。
    - 预期与心态管理：承认多数努力可能得不到回报（视频提到“九成陪跑，一成奇迹”），但把长期的、系统化的方法视为提高“那一成概率”的路径。用长期复利的视角积累经验、数据与可复用的钱包资产。
- 心智模型二：成本效益与杠杆思维（Optimize for ROI）
    - 核心思想：每一笔链上交互都需要付出 Gas fee 和时间，决策时要考虑边际投入产出比（ROI）。用成本最小化的方法获取最大的链上“可信度”。
    - 操作细节：
        - 选择低费链做高频、多样化操作，避免在高费链反复小额试错；
        - 使用交易所提币或 LayerZero 等方案替代高费桥接，节省跨链成本；
        - 在不同钱包之间平衡投入，确保每个钱包都有“最低可信度”的交互历史，而不是把资源平均分散成大量无法产生信任的小钱包；
        - 用表格和分析工具计量每个项目/钱包的历史产出，放弃那些长期看不到回报或数据上没有成长的项目，把资源向更有数据支撑的目标集中。
    - 目标：把时间和资金集中到那些既有成本可控又有上行潜力的项目上，把碎片化的努力转化为可复用的“优质钱包”和数据积累。

# 总结

撸空投不是盲目的薅羊毛，而是一项需要工具准备、数据驱动和长期经营的系统工程。关键在于：准备好硬件与账号（Chrome、Gmail、X、Discord、钱包与私钥安全）、理解并优化 Gas 成本、用数据筛选有潜力的项目（关注 TVL、活跃用户、团队与融资）、以“真实用户”心态进行多样化且长期的交互、使用任务平台与记录工具管理多钱包，以及在合适时间、安全地领取空投并提防钓鱼。成功有运气成分，但通过框架化与心智模型，可以显著提高中大额空投命中的概率并把收益稳妥兑现。最后，保持耐心与安全意识，长期积累往往决定成败。
