# 1. Metadata

- Title: 币哥的币圈翻身秘籍：从不停亏钱到财务自由
- Author: 币哥

# 2. Overview

本视频的核心论题是分享一套系统化的加密货币投资方法，目标是帮助低收入或想翻身的人在币圈稳定获利直到实现财务自由。结论可以概括为：第一要严格的仓位控制；第二要在自己认知范围内赚钱并跟对“人/平台”；第三要有明确的选币方法（长线与中短线并重），并配合成熟的交易系统（如双均线交易系统）与耐心持有以等待市场周期（牛熊）带来的胜利。

# 3. 按照主题来梳理

## 3.1 仓位控制（把资金分成不同“赚钱大军”）

- 视频把仓位想象成“不同的赚钱大军”，每一队大军有不同任务、风险和收益预期。作者强调仓位控制是最重要的基石，脱离仓位控制去谈盈亏比或赔率是“耍流氓”——意思是没有风险管理的一切策略都不可信。
- 作者的资金分配示例：稳健型大军（占比约60%+10%）包含两部分：现货交易（由双均线交易系统指导，预期年化收益100%，分配60%仓位）和理财（交易所存款或放贷，预期年化收益10%，分配10%仓位）。稳健型大军占比大，因为这是长期基础，目标是稳定的复利与现金流。
- 波动率大军（整体约8%仓位）分为期权高频套利机器人（做空波动率，仓位约6%，预期年化约50%）和波动率机器人（做多/做空波动率之一，仓位约2%，预期年化约300%）。作者指出：预期收益越高的策略，仓位应该越小，因为高收益意味着高风险，盈亏同源。
- 趋势合约与山寨币大军（合计约22%仓位）分两部分：通过双均线交易系统做合约（预期年化300%–500%，仓位20%）以及用双均线和个人认知交易山寨币/小币（预期年化300%–500%，仓位2%）。这里再次体现高收益小仓位的原则。
- 强调不要因为某位老师或博主说某方法“非常好”就把所有资金梭哈。必须知道自己在赚什么钱，理解每一份仓位的风险来源与目的。仓位控制的原则可以总结为：以稳健为基础（大仓位配置低风险/可控策略），用小仓位博取高回报（高风险策略仅占小比例），并确保任何单次失败不会伤及根本（即不会导致总体爆仓或无法继续参与市场）。
- 作者用古代行军比喻，强调“因人而异、因地制宜”——不同策略对应不同市场环境和个人心态，合理分配并定期评估调整是仓位管理的核心操作。

## 3.2 投资逻辑（赚认知内的钱、选好车跟对人）

- 首条投资逻辑是“赚自己认知内的钱，不贪恋认知外的钱”。意思是只做自己能够理解和把握的交易/投资，用长期学习来扩展认知边界。作者认为，偶然在认知外赚到的钱常常会被市场长期的回撤抹去；而持续赚到钱的能力来自于对方法、市场与标的的深刻理解与长期积累。
- 第二条是“选好车、跟对人”。“车”指的是投资标的（Token/项目等），“人”更指的是选择的交易所或生态平台。作者以币安（Binance）举例：早期跟对了平台或持有其平台币（如BNB）的人在上一轮牛市收益巨大。选择交易所不只是看便利，还看长期回馈、费用、产品线与生态成长能力。作者特别推荐抹茶交易所（MEXC，保留原文并在括号给出中文释义），理由是手续费低、现货免手续费、合约maker免手续费等优点，并强调使用推荐链接可获得手续费折扣与赠金（视频中出现的推广内容在本重写的条目中保留为作者观点说明，而非新增事实）。
- 作者把“跟对人”进一步解释为：在牛熊周期里，平台的格局和对用户的回馈能显著影响散户收益。例如某交易所能通过回馈与活动留住用户并在生态中创造大量机会。跟对平台意味着在合适的地方能获取更多的机会、较低的交易成本与被动收益（如持有平台币获得的被动收益）。
- 最后作者用“势能与周期”来强调宏观重要性：他认为市场的大部分胜负（约90%）取决于市场整体的势能与周期，个人因素只占小部分（不到10%）。因此投资策略必须与市场周期配合，长线持有优质标的并熬过熊市以等待下一轮牛市，是提高胜率的重要方法。

## 3.3 选币方法（长线五标的策略、项目评估要点）

- 长线策略：作者用60%的资金做长线现货交易，具体做法是选出5个长期持有的标的，持有至少跨越一个牛熊周期——在熊市买入，牛市卖出。选5个标的的原则不是随便分散，而是基于对标的的深度认知：如果你无法立刻列出心中的5个最佳项目，说明你对市场研究不够深入。作者认为少而精的持仓在熊市中并不会显著降低风险（因为很多主流币在熊市都高度相关并下跌90%+），反而能提高未来的预期回报上限。
- 选币标准第一点：活过一轮牛熊的龙头项目（或具备生存能力的公链/核心项目）。牛市里垃圾币也会涨，但关键是熊市是否能存活并持续开发。公链（Layer 1，保留原文并可理解为公链）通常生存能力更强，能通过裁员、节流和抓住落后机会在熊市中“苟住”并在下一轮牛市中受益。
- 选币标准第二点：从项目本身判断代币增值潜力。作者提到两个关键判断轴：一是该项目是否为细分赛道的龙头或具备垄断地位（例如去中心化交易所Uniswap借贷类Aave等作为示例）；二是项目是否在解决真实痛点（不是伪需求）。判断时要分析项目的TVL（总锁仓量）来源是否真实，以及项目是否能为链上用户提供真正的价值。
- 选币标准第三点：考察代币经济学（Tokenomics）。对公链类代币，作者关注的是代币的流通/消耗场景、发行与释放机制是否与项目价值增长成正比，以及是否有激励长期持有/锁仓的机制。作者把公链比作国家，代币像法定货币或公司的股权：代币如果只具备投票权而没有“分红/价值回流机制”，那么其长期持有价值值得怀疑。部分项目通过分发代币给用户（补贴/激励）来吸引TVL，但如果代币释放过快且项目方没有足够能力托盘，容易陷入“死亡螺旋”——代币持续下跌、项目继续增发代币以补贴，形成恶性循环。因此，好的代币经济学应当使代币释放与项目价值提升同步，并通过规则鼓励锁仓与长期持有。
- 补充判断维度：对于公链还要看互操作性、可扩展性、名气与资源（项目创始人或团队背书的资源）。有名气和资源的公链更容易吸引项目和开发者入驻，提高生态发展的概率；没有名气、没有资源的小项目虽有可能崛起，但概率较小。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：三路“赚钱大军”仓位分配框架（资金配置心智模型）
    - 概念：将全部资金划分为不同功能的“军队”，每个军队承担不同收益与风险目标，整体组合的风险收益由这些子组合的加权平均决定。作者示例：稳健型大军（现货+理财）做为基石，占比最大；波动率大军（期权/波动率策略）用小仓位博取中性收益；趋势合约与山寨币大军用中高仓位但分散在高风险策略上。
    - 实操步骤：
        1. 明确资金总额与可承受的最大回撤（心理与资金双重承受）。
        2. 将资金分成若干功能性子池（如稳健现金流、波动率套利、趋势合约/投机等）。
        3. 给每个子池设定明确的风险上限、预期年化回报区间和仓位比例（例如作者的60%/10%/8%/22%分配概念）。
        4. 为每个子池制定可执行的操作规则（交易系统、止损/止盈规则、持仓期限）。
        5. 定期复盘与再平衡，尤其在市场极端波动时检查是否偏离既定风险配置。
    - 心智要点：不要让任何单一高风险策略占据主体仓位；将高预期收益策略限仓位；把稳健收益当成底座，保证在风暴中不被击垮。
- 框架二：双均线交易系统（中短线操作心智模型）
    - 概念：以不同周期的均线（视频使用20、60、120的MA/EMA为例）在四小时图形成“均线密集”信号，作为开仓或反转的判定点。关键是识别“均线密集”——多条均线彼此靠拢，表明市场成本集中，未来出现较大波动的概率上升。
    - 实操步骤：
        1. 在4小时图上标注主要均线（如20/60/120 MA或EMA）。
        2. 观察是否出现均线密集（多条均线纠缠，像麻绳一样）。
        3. 如果价格站上均线密集并企稳，倾向做多；若价格跌破均线密集并反弹未能站上，倾向做空。
        4. 止损设置：把止损放在均线密集被突破的另一侧（即若多单，止损为价格跌破均线密集；若空单，止损为价格回到均线密集上方）。
        5. 止盈设置：参考前一个均线密集的位置，或重要阻力/支撑区，把止盈放在前端的“均线密集”处，吃取“鱼身”（中间收益），避免追求鱼头鱼尾。
        6. 练就本能反应：通过重复练习把开仓、止损、止盈流程刻在脑中，实现下意识的快速判断与反应。
    - 心智要点：系统化、可重复、纪律化。任何交易方法都需要熟练到成为“本能反应”，并配合严格止损以限制回撤。
- 框架三：长线“少而精”持仓与周期思维
    - 概念：用较大仓位持有少量（作者建议5个）长期优质标的，且持有至少跨越一个牛熊周期。这个框架基于两个前提：市场整体势能（牛熊）对收益的决定性影响远大于单个项目短期表现；多标的并不一定能分散系统性风险，尤其是高度相关的加密资产在熊市共同下跌。
    - 实操步骤：
        1. 设定长线仓位的占比（作者示例为60%）。
        2. 通过研究选出你最有信心的5个标的（龙头优先、具生存力与长期价值场景）。
        3. 在熊市或有利时机加仓，在牛市达到目标后分批卖出实现收益。
        4. 评估持有标的的生存能力：团队是否持续开发，代币经济是否支持长期锁仓，是否存在明确的价值捕获机制。
        5. 坚持周期耐心：即使买在山顶或山腰，只要项目是真正优质并能熬过熊市，下一个牛市仍有机会获得回报。
    - 心智要点：用“等待下一个牛市”的耐心换取长期胜率；少即是多，集中持仓能提高上行潜力而非单纯增加风险。
- 框架四：选币三要素（项目、赛道与代币经济）
    - 概念：综合评估一个代币是否值得长期持有应包含三大要素：项目本身（是否解决真实问题并持续开发）、是否为赛道龙头（或具垄断/领先地位）、代币经济学是否能够把项目价值传递到代币上（包括代币释放节奏、锁仓机制、消耗场景等）。
    - 实操步骤：
        1. 项目验证：看团队是否在熊市仍在开发、社区是否活跃、项目是否解决真实痛点；分析TVL/用户来源是否真实。
        2. 赛道地位：判断该项目在细分赛道内的相对地位与壁垒（是否有网络效应、是否能吸引开发者与用户）。
        3. 代币经济评估：检查代币是否只是投票权还是有实际价值回流（分红/销毁/消耗），代币释放节奏是否与价值增长匹配，是否有激励长期锁仓的机制。
        4. 外部资源：评估项目是否有名气/资源/背书，这会影响生态吸引力与长期发展概率。
    - 心智要点：不要被短期噱头迷惑，优先选择在熊市能存活并逐步累积价值的项目；代币如果没有价值传递机制则不适合长期持有。

# 总结

视频的核心在于把交易和投资看成一个系统工程：严格的仓位分配、以认知边界为界限的获利策略、跟对平台并选对长期标的、辅以可复现的交易系统（如双均线）与周期耐心。作者强调稳健优先、少而精的长线持仓、并用小仓位去博高风险高回报机会。遵循这些原则并通过不断学习提升认知，才能在币圈里把“偶然的收益”转化为长期稳定的盈利能力，最终朝财务自由迈进。
