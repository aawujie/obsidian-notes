# 3. 按照主题来梳理

## 3.1 投机与价值投资的争论与现实起点

- 视频开篇点出一个常见论调：有人批评“年轻人浮躁，应做价值投资，不要搞投机”。演讲者反驳这一观点，引用段永平（知名华人投资大佬）的话：年轻人别指望靠投资赚大钱，因为本金太小（除非是富二代），强调现实与底层逻辑。演讲者认为，许多大佬早期财富是靠投机积累的：当本金很小、资源有限时，投机（高风险高回报的链上博弈）是少数可行路径之一，但要有方法和工具，不是盲目冲。
- 视频把目标定为“教一套打狗大法”（“打狗”在此为俚语，指冲击早期低市值代币以博取暴利），并强调所有关键动作都发生在链上（chain上操作）。观众被假设已经理解“什么是链上操作”，接下来将直接进入具体技法。这个起点说明视频受众是有一定链上基础的投机者或准备入门的年轻人，而非普及性讲解。
- 在这部分，作者强调两点思想基础：一是投机并非不道德或“浮躁”的代名词，而是资金和机会的现实匹配；二是投机必须依赖链上可见的证据（钱包地址、交易行为、合约数据等）与工具支持，因此可被系统化、可被学习，而非纯靠运气或“直觉”。这为后续具体技巧（扫链、识别筹码、跟踪聪明钱、判断内外盘与分段）奠定了思想基础：投机须建立在可观测的链上数据和工具之上，结合时间与纪律执行。
- 另外，开头也提醒观众：不要简单否定投机，也不要无视风险。投机的门槛不只在技术，还在时间投入、心理管理与仓位控制，尤其是早期用户和内盘参与者，需要承受高失败率与长期在线观察的高成本。作者将这些现实条件贯穿于后续策略说明中，提示读者一方面看到高回报可能性，另一方面要有清醒的风险与时间成本评估。

## 3.2 扫链：链上筛选的五步法（识别潜力土狗）

- “扫链”被定义为打狗大法中最核心、最基础的技能，简单来说就是用链上数据工具筛选出“最有实力、最有潜力”的小币种（文中称为“小金狗”或“土狗”）。作者推荐使用的工具包括 GMGN（视频中口播工具名）、AVE.AI、OKLink 等，强调这些工具能让你观察排行榜、筹码分布、地址行为并自动发出警报，从而把海量噪音项目过滤成可跟踪的少数对象。
- 步骤一：看排行榜（以“一小时成交额”排名为主）。作者解释为何选择一小时而非五分钟或24小时：五分钟波动太多、噪音太重；24小时又可能意味着该项目已被全球注意、进入较成熟阶段，可能已经不是买入时机而是卖出信号。因此以一小时为窗口，可以捕捉到短期活跃且未被广泛放大的项目。
- 步骤二：看筹码分布（持有者与大户地址）。核心是辨别是否存在“老鼠仓”或“庄家/主力”及“做市/做事商”钱包。方法包括查看持币地址数量、前几名地址持仓占比、这些地址在其它项目的历史行为等。若某些地址在多个成功金狗项目中反复出现，且持仓量大但操作节奏稳健（长期持有或阶段性拉盘抛售），则可能是“庄家”，值得跟踪；若地址频繁高价买低价卖、交易频繁，则多为做市/做事商，跟随其并不赚钱；若是小量但多次出现的“野装”地址，则多为跟风游资，可以轻量跟随。
- 步骤三：判断聪明钱与老鼠仓。聪明钱榜单能帮你筛选被视作“可靠”的地址，但要警惕“看起来胜率高但其实是老鼠仓”的聪明钱类型：这类地址在公开之前先建仓，价格一旦拉升便快速抛售，造成高胜率但其买入时机不可跟随，跟随会变成接盘侠。识别典型特征：提前在公开市场之前建仓，抛售速度快且与公开信号高度一致。
- 步骤四：跟踪这些地址的实时动态。用工具设置报警（如 GMGN、AVE.AI 的聪明钱追踪），或用 OKLink 深入查看单个地址的来龙去脉，重点观察：这些地址最近买进/卖出的节奏、是否在其它成功项目中是主力、是否存在群体协同行为（多个游资地址聚集）。
- 步骤五：结合社群与社媒线（下一步更详细）。扫链并非仅靠链上数据，还要以最少时间核对社群（Twitter、Telegram、官网），验证叙事是否存在KOL关注、故事是否能激发市场共鸣。总的原则是：先用链上数据缩小候选池，再在社媒层面做快速确认，务必把握时间窗口，因为热门代币在几十分钟内可能涨几倍。

## 3.3 跟踪聪明钱、识别老鼠仓与分类钱包角色

- 这一节集中讲“地址的角色识别”与“如何长期建立跟踪库”的实务技巧。首先强调分类——把链上地址按行为与功能分为三类：庄家/主力（长期持仓、阶段性拉盘）、做事商/做市商（高频作为流动性制造者，交易频繁、买卖节奏与利润不直接相关）、游资/野装（跟风、量小但灵活）。识别这些角色的核心指标包括持仓占比、交易频率、是否多项目重叠出现、历史是否与知名金狗有关联等。
- 实操建议：做一个“优质庄家地址库”是重要的作业之一。方法是：当你用 GMGN 或类似工具发现某地址在多个成功项目中频繁出现在前列且持仓数据稳定时，把这个地址加入你的监控列表。随后对这个地址的每一次交易进行断点记录：买入时间/价格、卖出时间/价格、与哪些社媒事件对应。长期看，你将形成一套自己的“聪明钱跟随表”，这将极大提升你在未来项目中的判断力。
- 关于老鼠仓（内部提前建仓然后抛售套现）特别提醒：老鼠仓会让某些地址看起来胜率极高，但这些地址往往在项目公开之前就已布局，普通人无法复制其买入时点。识别方法包括：该地址在代币公开交易前就有仓位、抛售集中在第一次大涨时、交易时间与公开消息高度同步等。对这类地址的应对策略是“绝不盲目跟买它的仓位”，否则买到就是接盘。
- 工具应用层面补充：AVE.AI、GMGN 可提供聪明钱榜单和报警；OKLink 用于深挖地址历史。利用这些工具时，要注意噪音管理：不要因单一榜单就全部跟随，优先建立证据链（多项目出现、地址之间的协同、与KOL互动等）。此外，若发现多个游资地址聚集在同一项目，这是一个积极信号，因为联合游资的做事能力可能不输单一大庄，但风险仍在，仍需仓位控制。

## 3.4 交易时机：内盘与外盘，以及一段、二段、三段的区分与策略

- 本节解释“内盘”和“外盘”的定义及区别，并延伸到外盘的一段/二段/三段概念。内盘指代币在公平发射或发射平台上首次分发（像视频举例的 Solana 上的 PumpToFan、BN 链的 Fordameme 等），这些内盘代币刚打出来市值极小、流通量有限，是链上淘金的第一线。内盘成功概率低、需要大量时间在线、适合能连续高强度投入时间的人（例如一天可在线18小时、连续多天）。内盘的玩法需极度分散投资和极小仓位，因为很多内盘项目连打满都困难，失败率高。
- 外盘是指代币在发行后的市场流通阶段，通过去中心化交易所（DEX）建立交易对和流动性池（例如在 Solana 的 Raydium 或在 BNB 链的 Pancake）。外盘阶段又可分为一段、二段、三段。
    - 一段：项目刚进入 DEX，仍然未被大量市场验证，需要大量在线观察以辨别谁会跑出来。参与一段需承担高风险但若成功回报巨大（千倍十万倍并非罕见）。入场逻辑类似内盘，但相对成功率更高一些，且仍需快速进出：Meme 币一旦热度衰退价格常常回撤 80%-90% 乃至归零，所以“进得快、跑得快”是关键。
    - 二段：当一些大V（KOL）开始喊单，或者叙事被市场更广泛接受，出现二段行情时项目更有可能成为金狗。二段的决策路径包含三点：核验利好消息的真实性（到 Twitter 上找官方源头验证）、评估当前市值是否已经过高（通过 CoinGecko 或合约地址查市值）、以及观察聪明钱的仓位行为（是布局还是出货）。如果大多数聪明钱在二段更多是买入而非卖出，且利好真实，那么二段仍值得参与，但仓位要谨慎。
    - 三段：到三段往往意味着代币的筹码经历了充分洗牌，持仓结构复杂。如果代币能被讲出“上锁”或上中心化交易所（如 Binance）则有强拉盘效应，尤其是上币安通常带来最大推升（但视频也指出，上币安效果近年已被投票机制、其他因素影响，推升效应不再绝对）。三段的操作需要同时结合一级市场的链上动态（地址活动、项目方动作）与二级市场的图表分析（支撑/阻力、成交量等），一二级结合才能制定买卖、止盈止损策略。

## 3.5 仓位管理、止盈止损与时间纪律

- 仓位管理的核心思想是“越早阶段仓位越小、越后阶段仓位可以越大”。具体建议：
    - 内盘与一段：成功率低且波动极大，因此每个项目下注比例要非常小、分散到多个项目上，以降低单项目爆炸性失败的风险。作者用比喻说这是“修罗场”，只有能长期在线、时间充裕的选手才合适。
    - 二段：若项目已进入二段并得到 KOL 或庄家验证，可以适度增加仓位，但仍需评估市值是否合理与聪明钱是否在继续布局。
    - 同一赛道内的首位与次位投入差别：若赛道第一名实力明显（例如“总统发币”赛道里第一名是假设的“川普币”），可以投入较多仓位；对赛道的第二、第三名则应减少仓位，因为边际赚钱效应递减。类似地，当同一名人（例如某个KOL）多次喊币时，第一次的仓位可大一点，后面越喊越小。
- 止盈与止损纪律：
    - Meme 币的共性是热度衰退极快，因此“进得快、跑得快”是黄金规则。要设置明确的止盈目标并快速兑现，不要恋战。例如价格一旦达到既定倍数或出现资金流出迹象要果断出售。
    - 止损要狠。若判断失误出现明显对头方向的价格动作，千万别扛单，应该快速止损以减少亏损。视频强调：90% 的外盘密币可能只有一段，并不会进入二段或三段，因此容忍强烈回撤的代价高，需要严格止损规则。
- 组合与赛道注意：
    - 分散不仅在项目上，也在赛道上。寻找新的赛道参与比在同一赛道被多次割韭菜更安全。
    - 关注大V或名人炒作的边际效应：第一个被其喊的代币通常赚钱效应最大，后续喊单逐渐减弱，因此仓位策略要随次数递减。
- 时间纪律与群体协作：
    - 打狗讲究 timing（时间把握），很多代币在几十分钟到数小时内完成暴涨，因此个人研究如果耗时太长会错过机会。建议加入高质量的打狗群体，用群体的研究成果互相补充，节省时间并迅速行动。但也要警惕群内噪音与未经核验的信息。

# 4. 框架 & 心智模型（Framework & Mindset）

- 框架一：链上投机六步决策流程（从筛选到执行）
    1. 初筛（扫链）：使用一小时成交额排行榜筛出短期活跃代币，作为候选池。理由是平衡噪音与时效，既避免5分钟的噪音，也避开24小时已被广泛接纳的成熟项目。
    2. 筹码构成分析：查看持币地址分布、前十大地址占比、是否存在重复在成功项目中出现的“庄家”地址或频繁交易的“做市商”地址。用这一分析判断“谁在主导市场”。
    3. 智能钱与老鼠仓辨别：在聪明钱榜单上找出可能的优质地址，但同时识别那些可能是提前布局然后抛售的老鼠仓，避免做接盘侠。
    4. 社媒与叙事验证：在 Twitter（推特）、Telegram 与官网上快速核验项目叙事、KOL 参与度以及社区反响，确认故事性是否成立及传播广度。
    5. 判定内盘/外盘与阶段（1/2/3段）：判断项目处在哪个发行或上涨阶段（内盘、一段、二段、三段），并据此决定仓位上限与是否长期持有。
    6. 执行与风险控制：按照阶段划定仓位、设置止盈止损点，并结合图表分析与链上监控（持续跟踪关键地址）动态调整仓位与出入场点。
以上六步构成一个闭环：从发现到验证到执行再到复盘，所有决策都依赖链上数据与时间纪律，而非纯粹情绪或听信单一大V。
- 心智模型一：可证伪/可观测的投机决策
    - 投机决策应基于可观测的证据链，而非模糊的“感觉”。可观测证据包括榜单数据（成交额、持仓地址分布）、地址历史行为（是否为庄家/做市/游资）、社媒的KOL参与与叙事速度、代币的市值与流通量等。每一步决策都应能指向“为什么买入”和“什么条件下卖出”，并能被后续数据否定（即可证伪）。
    - 这种心智模型要求：如果链上数据显示主力在出货、社媒热度下降或市值已被高估，则及时止损；反之若链上证据显示持续布局、外部利好验证且市值仍合理，则可以放大仓位。该模型强调数据驱动而非情绪驱动，强调设立明确的入场与退出规则，并不断用链上证据验证这些规则是否仍适用。
- 心智模型二：时间即资源（把握时机与群体协作）
    - 在链上投机中，时间是稀缺资源。优秀的打法不是更深度的单兵研究，而是能够短时间内基于数据做出判断并迅速执行。为此，加入或构建高质量的打狗群、共享扫链成果，可以显著提高效率。
    - 具体心态要求：对每一次机会快速判断并行动，对错的成本通过小仓位分散化、严格止损来管理；对看上去“稳赚不赔”的聪明钱保持怀疑；对社群信息保持快速验证的习惯。时间纪律还要求你不要陷入对单个Meme 币的长期执着，能快进快出、跑得比别人快，才能在高度竞争的链上博弈中存活并获利。

# 总结

视频系统地讲解了链上投机的全流程：从扫链（用一小时榜单筛选）到筹码分布分析、聪明钱与老鼠仓识别，再到社媒叙事验证与内盘/外盘的阶段判断（包括一段、二段、三段），最终回到具体的仓位管理与止盈止损纪律。核心思想是：投机并非盲目冲动，而是一套以链上可观测数据与时间纪律为基础的技艺；小本金想要博大钱需要靠谨慎的流程、工具与严格的仓位与时间管理。视频同时提醒：内盘成功率低、需要大量在线时间；外盘一段也高风险但可能回报巨大；二段与三段需要结合链上与二级市场分析并谨慎加仓；任何阶段都要警惕老鼠仓并保持快速止盈止损的纪律。工具与链接作者放在视频下方（需注意识别官方链接以防诈骗）。
