## 一句话

MasterClass = 明星 IP 打包 + 视频订阅，把世界顶尖人物的隐性知识做成付费内容。

## 核心数据（2025）

| 指标 | 数值 |
|:---|:---|
| 年收入 | $247M（2024 年 $155M，YoY +59%） |
| 估值 | $2.8B（2021 年 Series F） |
| 总融资 | $500M（6 轮） |
| 员工 | 775 人 |
| 成立 | 2015 年，旧金山 |
| 课程数 | 200+ 位讲师 |

## 商业模式拆解

### 收入端：100% 订阅制

- **单一产品**：年费会员，无限观看所有课程
- 定价约 $120-180/年（历史上有过 $180/年档位，偶有促销）
- 2018 年订阅占收入 80%，现已 100%（砍掉了单课购买）
- 用 Butter Payments 做支付恢复，挽回 27% 流失收入

### 成本端：内容制作 + 明星分成

核心成本结构：

1. **明星讲师费**：传闻 $100,000 预付 + 课程收入 30% 分成
2. **制作成本**：电影级拍摄（斯科塞斯级别制作），每门课制作费不菲
3. **平台运营**：流媒体技术、支付、客户支持

**关键洞察**：MasterClass 不生产知识，是"知识搬运工"——把已有顶尖人物的经验打包成可消费内容，边际成本递减。

### 增长飞轮

```
明星 IP 吸引用户 → 用户增长 → 订阅收入增长
    ↓                              ↓
更多明星愿意加入 ← 平台影响力扩大 ← 更多预算投制作
```

## 竞争优势

1. **品牌护城河**：200+ 明星 IP 独家合作，复制成本极高
2. **内容资产化**：课程是长期资产，越积越多，边际成本递减
3. **制作门槛**：电影级制作，非普通网课可比
4. **网络效应**：明星越多 → 用户越多 → 更多明星愿意来

## 风险与挑战

1. **明星依赖**：过度依赖头部 IP，一旦续约出问题影响大
2. **增长天花板**：订阅制用户增长有限，ARPU 提升空间小
3. **AI 冲击**：AI 生成内容可能降低制作门槛，削弱其"电影级制作"优势
4. **竞争加剧**：Coursera、Udemy 等平台也在往高端走
5. **退出路径不明**：$2.8B 估值，IPO 压力大但市场环境不佳

## 关键判断

**好生意，但不是无限增长的故事。**

$247M 年收入、$2.8B 估值 ≈ 11x P/S，在 SaaS 里算合理。但订阅制教育内容的天花板比 SaaS 低——用户不会同时订阅 3 个 MasterClass 类产品，且内容消费频次天然低于工具类产品。

长期看，MasterClass 更像一个**内容品牌**而非科技公司，估值逻辑应该对标 Netflix/Disney+ 而非 Salesforce。$2.8B 的估值在当前环境下偏高。
