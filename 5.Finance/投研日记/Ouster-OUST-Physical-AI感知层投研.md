# Ouster (OUST) — Physical AI感知层投研

## 一句话

数字LiDAR传感器公司，定位"Physical AI的感知平台"，卖硬件+软件+融合方案给自动驾驶、工业、机器人、智慧城市。

| 项 | 内容 |
|:---|:---|
| 股票代码 | OUST（Nasdaq） |
| 总部 | 旧金山 |
| CEO | Angus Pacala |
| 成立 | 2020年 |
| 股本 | 62.8M股（2026-02-25） |
| 核心产品 | 数字LiDAR + AI相机 + 感知软件平台 |
| 关键并购 | 2023合并Velodyne（专利库翻倍）；2026-02收购Stereolabs（加AI相机视觉） |

## 业务结构

### 四大垂直市场

| 市场 | 典型场景 | 特点 |
|:---|:---|:---|
| Industrial | 仓库自动化、yard logistics | 当前增长主力 |
| Smart Infrastructure | 智慧交通（BlueCity） | 政府客户，长周期 |
| Robotics | 机器人导航 | 高增长潜力 |
| Automotive | ADAS/自动驾驶 | 长周期设计入围 |

### 产品栈（收购后已不只是LiDAR）

| 层 | 产品 | 说明 |
|:---|:---|:---|
| 传感器层 | LiDAR（OS/DF/Velodyne系列）+ ZED相机（Stereolabs） | LiDAR是收入主力，相机是新增量 |
| 融合层 | Sensor Fusion + AI计算 | LiDAR+相机数据融合，边缘AI推理 |
| 软件层 | Gemini / BlueCity感知平台 | 智慧交通、工业自动化软件方案 |

### 最新产品：REV8

- 原生彩色感知（LiDAR自带颜色，不需要配相机）
- 2倍量程和分辨率提升
- 功能安全认证
- 2026年6月与Benchmark合作量产

### Ouster差异化

1. **数字架构+自研SoC** — 按摩尔定律降成本，非机械扫描
2. **多市场布局** — 不只押汽车（工业/机器人/基建同时推进）
3. **Velodyne合并后专利库最全** — 防御+授权收入
4. **Stereolabs收购** — LiDAR+相机+AI计算，完整感知栈
5. **REV8原生彩色LiDAR** — 技术里程碑，不需要配相机就有颜色

## 投资逻辑

### 看多

- Physical AI（机器人/自动驾驶/智慧城市）趋势明确，LiDAR是核心传感器
- 收入增速快（50%+），毛利率跨过40%门槛

- 累计亏损$9.7亿，何时真正盈利不确定
- LiDAR行业竞争激烈，价格压力持续
- 大客户砍单风险（两个客户各占>10%收入）

- 出货量25,000台/年，规模效应分界线（10万台+）还很远
- 股价波动大（Beta 2.9）
- Q1 2026收入环比下降22%，增长可持续性存疑

## 核心问题

1. **能不能从25,000台/年爬到10万台+？** — 规模效应能否跑通的分界线
2. **Stereolabs整合能否顺利？** — 相机业务能否贡献增量收入
3. **REV8能否打开汽车量产市场？** — 目前收入主要来自工业/基建
4. **EBITDA何时转正？** — 当前-$7M/季，按收窄趋势可能2026下半年-2027

## 个人思考

Ouster的故事是"Physical AI的感知层"——如果机器人/自动驾驶/智慧城市真的爆发，LiDAR就是眼睛，Ouster想做眼睛+大脑的完整栈。

但问题是：LiDAR行业烧了十年钱，没有一家公司证明能稳定盈利。禾赛走量、Luminar走高端、Ouster走多市场，路线不同但都在亏。Ouster的优势是毛利率高（49%）、亏损收窄快、多市场分散风险；劣势是量太小，规模效应还没跑通。

如果Physical AI在2027-2028真的起飞，Ouster可能是受益最大的纯LiDAR标的——因为它已经在工业/机器人/基建有客户基础，不像Luminar死等汽车。但如果起飞时间再推迟，累计亏损$9.7亿+现金消耗会压垮它。

**赌的是时间窗口：Ouster的现金够撑到Physical AI爆发吗？**
