想象一下，沃伦·巴菲特、迈克尔·伯里和斯坦·德鲁肯米勒在同一个房间里，为同一只股票争论不休。

巴菲特关心护城河。伯里想知道什么在悄悄崩溃。德鲁肯米勒在看宏观并计量仓位。

现在，今晚你就可以在自己的笔记本上运行这场争论，代价只是一次 API 调用。这就是我们现在的处境。

两个开源仓库掀起了这一波，星标数量比我说得更清楚。

## 没有人提到的事

这是那些病毒式传播的帖子里没人提到的事。让这些 Agent 指向一个背后没有真实数据的股票代码，它会读取训练内存里的任何东西，然后给你一个自信满满、措辞优美的猜测。

> **模型从来不是护城河。你接在它下方的数据才是。**

所以在 Agent 之前，你要先构建做安静工作的那部分：一个提取真实申报文件的层，永远不让模型凭空编造数字。

> **dgunning/edgartools** ★ 下载量 230 万
> 将每份 SEC 申报文件转化为干净的 Python 对象，并附带 MCP 服务器，让 Claude 读取真实数据。

每家在美上市公司都要向 SEC 申报，而 SEC 通过免费的 EDGAR API 开放全部数据。edgartools 将这些申报文件（10-K、8-K、内幕交易 Form 4、13F 持仓）解析为干净的、带类型的 Python 对象。

无需 API key，无需注册，只需一个邮箱作为身份标识。它被纳入了 Anthropic 的 Claude for Open Source 计划，这是有充分理由的——这引出了改变使用方式的关键部分。

如果你想要一个完整的驾驶舱，OpenBB 是开源的 Bloomberg 终端，几十个数据供应商在一个界面背后，MCP 包含在内。

edgartools 内置了 MCP 服务器。这意味着你不需要 import 然后写胶水代码，而是直接把它作为工具交给 Claude。把这个配置放进 Claude Desktop 或 Claude Code 的配置文件中：

这也是我构建本文所有内容的方式。我没有手写管线代码，我驱动 Claude Code：克隆仓库、搭建环境、接线密钥、调试某份解析异常的文件。Codex 做同样的工作。

> **新的量化技能不是亲自写每一行代码。而是指挥一个 Agent 来写，并确切知道要验证什么。**

## 我在实时数据上跑了一次

四个评分中最简单的是应计比率（accruals ratio），它是 Beneish 模型中权重最大的单一输入：净利润减去经营活动现金流，除以总资产。

造假利润最快的方法就是记入从未以现金形式出现的收入。所以这个比率越高，盈余就越超前于支撑它们的现金。

> **英伟达以 +8.4% 领先。不是因为它在做假账，而是因为超高速增长下，销售确认速度快于现金到账。一个标记不是在喊"欺诈"，而是在低语"去看看"。**

一个诚实的细节：实时运行迫使我发现，苹果和迪士尼将经营活动现金流标记在一个便捷函数遗漏的概念下，所以脚本不得不从标准化字段中抓取。每个真实的管道都有异常申报者的边缘情况。工具只是告诉你它在哪里。

## 预测市场

这是我最感兴趣的部分，因为这套纪律可以干净地迁移到预测市场。

在 Poly 上，"10-K"变成了市场的结算来源加上任何实时数据来结算。Agent 读取这些而不是申报文件，数学变成了"这个隐含概率是由证据支持的还是由叙事支持的"，而优势，再次，在于管道。

这不是理论。超过 30% 的 Polymarket 钱包已经在运行 Agent，而大多数持续盈利的钱包是机器人。

> **Polymarket Toolkit** ★ 开源
> Brier 评分、审计级别 P&L、地址分析——由一位独立交易者使用 Claude Code 和 Codex 构建。

这套工具包是以上所有内容的预测市场版本：polymarket-brier 评分一个交易者的预测实际校准程度，polymarket-pnl 精确到美分重建盈亏，polymarket-profile 读取任何钱包。同样的配方，不同的账本。真实数据进去，有纪律的数学在上面，一个 Agent 写备忘录。

如果你以前读过我的 Poly 分析，现在法证习惯和预测市场习惯终于变成了同一种技能。

## 四层架构

退一步看，是四层。所有人截图的 Agent 是最上面一层。下面三层才是真正的工作，也是真正的优势所在。

而最应该刺痛那些每年花 24,000 美元买终端的人的是：**每一层都是开源的。**

组装顺序就是整个游戏：

**第 1 层：真实数据** — EDGAR 申报文件、Polymarket 账本、来自来源的实时价格，由 Agent 读取，而不是由 Agent 记忆。

**第 2 层：有纪律的数学** — 应计比率、Beneish、Altman、Piotroski、Brier 评分。不是"这看起来好吗"——而是"这个数字在 50 年历史中处于什么分位，以及为什么"。

**第 3 层：推理** — 多头与空头辩论、结构化反对意见、多 Agent 质询。不是让一个模型评估它自己——而是让两个模型互相评估。

**第 4 层：决策** — 基于所有以上内容的趋势、评分和信号，产生一个仓位、一个概率或一个答案。

每个人很快都会拥有相同的模型和相同的著名投资人提示词。把一份 10-K 粘贴到对话框里问"这是一家好公司吗"，会感觉像在做研究，但产生不了任何东西。

领先三步的人把模型接到了 EDGAR，让数学决定什么值得读，然后把模型的智能花在它真正擅长的一件事上：埋在第 94 页的措辞。
