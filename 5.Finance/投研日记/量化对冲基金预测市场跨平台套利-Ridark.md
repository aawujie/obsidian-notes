## 核心

量化基金不关心谁赢选举、谁拿奥斯卡——把预测市场当成碎片化的订单簿网络，利用协整关系和订单流失衡，跨平台价差套利，delta 对冲到零敞口。

## 公开数据集

- 55GB，850M+ 条状态更新，Apache Parquet 格式
- 全 L2 订单簿快照（最深 20 档），100ms 采样间隔
- 跨平台同步时间戳，追溯到 2024 年底

## 方法论一：协整 + OU 均值回归

同一事件在不同平台上的合约，终值必然收敛到 $1 或 $0。局部流动性冲击（大户砸盘）造成临时偏离。

**四步框架**：

1. **协整检验**：构建价差 $S_t = P_{P,t} - \beta P_{K,t} - \mu$，ADF/Johansen 检验确认平稳性
2. **OU 过程建模**：$dS_t = \theta(\mu - S_t)dt + \sigma dW_t$
3. **MLE 校准**：Euler-Maruyama 离散化，在 8.5 亿行数据上提取 $\theta$，$\tau = 1/\theta$ 快于执行延迟 → 可交易
4. **最优开平仓阈值**：求解最优停时问题，最大化期望收益/时间比率

## 方法论二：OBI + 微价格预测

毫秒级别上，宏观协整太慢。直接看流动性分布。

1. **OBI 指标**：$I_t = (V_b - V_a) / (V_b + V_a)$，范围 [-1, 1]
2. **微价格**：$P_{micro} = P_{mid} + I_t \cdot \Delta_{spread} / 2$
3. **跨平台预测**：Polymarket（链上）和 Kalshi（中心化）API 速度不同。Markov 转移矩阵测 $I > 0.8$ 的失衡能否在 200ms 内预测另一平台卖盘清空 → 抢在散户 UI 刷新前执行

## 结论

机构优势不在预测事件，在**过程**——OU 参数校准仓位、OBI 数学关系做微价格预测、延迟优势抢执行。
