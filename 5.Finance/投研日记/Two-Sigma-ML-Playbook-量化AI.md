## 二、为什么用机器学习做金融？

### 金融数据的三大特征

1. **非线性 (Nonlinear)** — 价格与订单簿之间的关系不是线性的
2. **高维 (High-dimensional)** — 订单簿有大量价格层级，每个层级有多个特征
3. **时序依赖 (Sequential)** — 数据是时间序列，过去影响未来

### 机器学习 vs 传统方法

- **预测 (Prediction)**：用深度学习模型预测价格变动方向
- **决策 (Decision)**：强化学习 (Reinforcement Learning, RL) 直接从数据中学习决策策略，最大化目标函数

### 高频数据的优势

- 高频金融数据集包含**数十亿 (billions)** 个数据样本
- 数据量大 → 可以训练大模型（成百上千/百万参数）→ 降低过拟合风险
- 对比：中低频数据量少，需要更小心过拟合

> 个人思考：金融 ML 的核心矛盾是"数据量 vs 信噪比"。高频数据量大但噪声也大；低频数据信噪比稍好但样本不够。Two Sigma 的策略是：用海量高频数据 + 大模型，靠数据量压制过拟合。

## 三、订单簿 (Limit Order Book) 基础

### 核心概念

| 概念 | 英文 | 说明 |
|------|------|------|
| 限价单 | Limit Order | 投资者指定价格买卖 |
| 市价单 | Market Order | 立即以当前最优价成交 |
| 最优买价 | Best Bid | 买方最高出价 |
| 最优卖价 | Best Ask | 卖方最低出价 |
| 中间价 | Mid Price | (Best Ask + Best Bid) / 2 |
| 价差 | Spread | Best Ask - Best Bid |
| 最小价格单位 | Tick Size | 美股为 1 美分 |

### 订单簿动态

订单簿随以下事件持续演化：
- 新限价单提交
- 已有限价单被取消
- 市价单与限价单匹配成交

**高频场景**：一只股票每天可能有**数十万甚至数百万**个订单簿事件。

### 关键认知：预测准确 ≠ 能赚钱

即使模型预测价格方向的准确率 >50%，也不一定盈利。原因：**非零价差 (non-zero spread)** 构成交易成本。

**例子**：
- 模型预测中间价上涨 → 市价买入 @ Best Ask ($10.01)
- 预测正确，中间价确实涨了 → 市价卖出 @ 新 Best Bid
- 结果：**中间价涨了，但交易亏了 $10**（因为买卖之间存在价差）

> 个人思考：这解释了为什么很多看似准确的预测模型在实际交易中不赚钱。价差是市场微观结构中最基本的"手续费"，任何策略必须首先覆盖这个成本。

## 四、案例一：RNN 预测价格变动方向

### 4.1 问题设定

- **数据集**：约 1000 只股票，3 年逐笔 (event-by-event) 高频数据，共**数千亿**样本
- **下采样**：只在价格变化的时间点采样
- **任务**：二分类——预测下一次价格变动是涨还是跌
- **训练**：多 GPU 分布式并行训练

### 4.2 基准模型：线性 VAR (Vector Autoregression)

$$
m_t = \text{线性函数}(m_{t-1}, x_t)
$$

本质上是**线性循环网络**，状态 $m_t$ 是历史数据的线性表示。

### 4.3 LSTM 循环网络

$$
m_t = g(m_{t-1}, x_t; \theta)
$$

$g$ 是神经网络，$m_t$ 是**非线性**记忆状态（memory state）。

LSTM 核心机制：
- **遗忘门 (Forget Gate)**：选择性清除不再有用的记忆
- **输入门 (Input Gate)**：添加新信息到记忆
- 设计动机：让模型能记住序列中很久以前的信息

### 4.4 训练挑战：截断 BPTT (Truncated Backpropagation Through Time)

- **完整 BPTT**：计算成本 ∝ 序列长度 T，对于长序列不可行
- **截断 BPTT**：每次只反向传播 $\tau$ 步（$\tau \ll T$），大幅降低计算成本
- **代价**：不是精确的最陡下降方向，是有误差的近似

### 4.5 梯度消失 (Vanishing Gradient)

类似于深层前馈网络：层数越多，底层梯度越小 → 训练越慢。RNN 中同样存在，使得网络难以记住序列中遥远的信息。

**实证**：MNIST 数据集上，更多层的网络虽然最终准确率相近，但**训练时间显著更长**。

### 4.6 核心发现：通用模型 (Universal Model) vs 个股模型 (Stock-Specific Model)

| 维度 | 通用模型 | 个股模型 |
|------|---------|---------|
| 训练数据 | 数百只股票合并 | 单只股票 |
| 参数量 | 可以很大 | 受限于单只股票数据量 |
| 过拟合风险 | 低（数据多） | 高（数据少） |
| 迁移学习 | 天然支持 | 不支持 |
| 计算成本 | 训练一个模型 | 训练数千个模型 |

**实验结果**：
1. **LSTM 一致优于线性模型**（500 只股票，3 个月外样本测试）
2. **通用模型一致优于个股模型**（直方图显示正向差异）→ 说明订单簿动态在不同股票间存在**普适性 (universality)**
3. **模型可泛化到未见过的股票**：用前 500 只训练，后 500 只测试，准确率仍 >50%
4. **模型稳定性 >1 年**：训练数据截止后 1 年以上的测试期，准确率仍然稳定

> 个人思考：这是整个演讲最重要的洞见——**订单簿的价格形成机制存在跨股票的普适规律**。这类似于 NLP 中预训练大模型的逻辑：在更多数据上训练更大的模型，反而比在小数据上训练专用模型更好。这为"金融大模型"提供了理论基础。

### 4.7 分布式训练架构

- **25 块 GPU** 异步随机梯度下降 (Asynchronous SGD)
- 每轮训练：随机子集数据加载到各机器内存 → 移至 GPU 计算梯度 → 异步发送到参数服务器 → 更新全局模型
- **异步**意味着：机器 i 不需要等机器 j 算完梯度

## 五、案例二：强化学习优化订单执行

### 5.1 问题设定

**最优执行 (Optimal Execution)**：给定要买入/卖出 V 股，如何下单以获得最优成交价？

决策空间：
- 将大单拆成小单
- 选择限价单还是市价单
- 选择下单的时机和数量

### 5.2 Bellman 方程与 RL 的动机

- 理论上，如果知道状态转移概率 $P(x_{t+1}|x_t, a_t)$，可以求解 Bellman 方程得到最优策略
- **现实中**：转移概率未知，且状态空间极高维 → 传统数值方法不可行
- **RL 的解决方案**：直接从观测数据中学习最优策略，不需要知道状态转移概率

### 5.3 简化实验：1 股订单的最优执行

虽然实际中机构关心大单执行，但 1 股是第一步。

**两种策略**：

#### A. 纯市价单策略 (Market Order Only)

- 收到买入 1 股指令
- 在每个离散时间点（1 秒间隔），RL 模型选择：**立即提交市价单** 或 **等待**
- 选择"等待" = 模型预测 Best Ask 会下降，可以更低价格买入
- 如果 Best Ask 是**鞅 (martingale)**（无预测性），则立即执行是最优的
- **基准**：立即执行 → 成本节省 = 0

#### B. 限价单策略 (Limit Order)

- 立即在 Best Bid 提交限价单
- 在每个 1 秒间隔，可选择取消限价单 → 立即提交市价单
- 如果时间 T 内未成交，自动取消并提交市价单
- **模拟方法**：在历史订单簿中逐事件追踪限价单，判断何时会成交

### 5.4 实验设置

- NASDAQ 限价订单簿数据，下采样到 1 秒间隔
- 模型每 1 秒做一次决策
- 1 年训练数据，6 个月测试数据
- 100 只股票
- 时间范围：**10 秒** 和 **60 秒**

### 5.5 结果

1. **RL 市价单策略**：50 只股票上一致提供正的成本节省（以 basis point 计，1 bp = 0.01 美分），但不同股票差异显著
2. **时间范围越长，节省越多**：60 秒 (turquoise) > 10 秒 (purple)
3. **RL 限价单策略**：同样一致正节省
4. **限价单 vs 市价单**：限价单策略略优于纯市价单策略，部分股票优势更显著

> 个人思考：时间范围越长效果越好，说明 RL 模型确实在利用订单簿的短期可预测性。但计算成本很高——需要逐事件模拟订单簿，这是实际落地的主要瓶颈。

## 六、Justin 的学习建议

1. **动手实现**：在大规模数据集上实现所有经典模型，这是学习 ML 的最佳方式
2. **数学理论**：理解 ML 的数学理论有助于指导模型训练和实现
3. **深度学习框架**：PyTorch 或 TensorFlow 是必备技能（个人推荐 PyTorch）
4. **高性能计算 (HPC)**：并行化训练模型的经验很有价值
5. **量化金融课程**：如果想将 ML 应用到金融数据，建议修读相关课程
6. **基础学科**：概率论、统计学、优化、计算机科学——ML 是这四个领域的交叉

## 八、个人总结与思考

### 核心方法论提炼

1. **数据量压倒一切**：高频数据 = 数十亿样本 = 可以训练大模型 = 降低过拟合。这是 Two Sigma 押注高频 ML 的根本逻辑。
2. **通用优于专用**：跨股票训练一个模型比每只股票单独训练更好。这是"金融大模型"的核心洞察。
3. **预测 ≠ 盈利**：必须考虑市场微观结构（价差、流动性），否则准确率再高也没用。
4. **RL 直接学决策**：传统方法需要先预测再决策，RL 端到端直接学策略，更适合高维状态空间。
5. **计算即壁垒**：25 GPU 分布式训练 + 逐事件订单簿模拟 = 巨大的计算成本 = 竞争壁垒。

### 可以进一步研究的方向

- LSTM 之后，Transformer 在高频数据上的表现如何？
- 大单执行（而非 1 股）的 RL 方法
- 订单簿的基础模型 (Foundation Model) 是否可行？
- 中国市场（涨跌停、T+1）的订单簿普适性

- 该演讲中的"通用模型"思路与 QuantSkills 中"因子投资的多资产 pooling"思路一致
- RL 订单执行对应 QuantSkills 中"执行算法"模块
