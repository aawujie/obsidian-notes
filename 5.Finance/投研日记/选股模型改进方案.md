# 龙虎榜选股信号模型改进方案

> 基于 2026-05-31 信号报告的失败复盘和改进实施

## 一、问题诊断

### 1.1 表现回顾

2026-05-31 龙虎榜资金流模型推荐13只标的，命中率仅31%（4/13）：
- 最强信号**华天科技**(85分) 反而跌4.71%
- **雄韬股份**(55分) 跌停
- 多只股票盘中冲高回落

### 1.2 失败共性

| 失败模式 | 涉及标的 | 根因 |
|---------|---------|------|
| 高位追涨 | 华天科技(85)、联特科技(69) | 连续上榜4-5天，短期涨幅过大 |
| 放量滞涨/出货 | 雄韬股份(55)、九安医疗(59) | 大资金流入但价格下跌，疑似出货 |
| 单日爆发无持续 | 横店东磁(55)、金安国纪(45) | 仅上榜1天，涨停后次日无跟随 |
| 内外资分歧 | 华虹公司(46)、沪电股份(42) | 机构净买但北向流出 |
| 大盘股弹性差 | 中兴通讯(55)、京东方A(40) | 资金流入难以驱动短期涨幅 |

### 1.3 根本原因

**现有模型仅基于资金流维度评分**（机构净买入、北向资金、连续上榜、涨停持续、外资席位），完全忽略：
1. 技术面位置（价格是否已在高位）
2. 量价配合关系（资金流入是否伴随价格上涨）
3. 追高风险（连续涨停后的回调压力）
4. 个股止损机制（无硬止损保护）

## 二、改进架构：四层过滤 + 综合评分

```
龙虎榜资金流数据
    │
    ▼
第0层: 原始资金流评分 (保持现有逻辑, 满分100)
    │
    ▼
第1层: 技术面信号过滤 ⚠️ 新增 (满分40, 扣分制)
  - 5日涨幅 >20%扣20, >15%扣15, >10%扣8
  - MA20偏离 >15%扣10, >10%扣5
  - RSI >80扣20, >70扣10
  - 布林带上轨以上扣10
    │
    ▼
第2层: 量价配合验证 ⚠️ 新增 (满分30, 加分制)
  - 放量阳线/缩量阴线比 >1.5加15
  - 尾盘方向正加10
  - 量价正相关加5
  - 放量滞涨扣10
    │
    ▼
第3层: 追高风险控制 ⚠️ 新增 (扣分制, 满分20可为负)
  - 连续涨停≥4扣20, ≥3扣15, ≥2扣10
  - 连续上榜≥4天每天衰减5分
  - 涨停封单比<10%扣10
    │
    ▼
综合评分 = 资金流×0.5 + 技术面×0.3 + 量价×0.2 - 追高风险

信号等级:
  ≥70: 强信号 | ≥50: 中信号 | ≥30: 弱信号 | <30: 过滤
```

## 三、关键验证：新旧模型对比

| 股票 | 旧评分 | 新评分 | 等级变化 | 关键警告 |
|------|--------|--------|---------|---------|
| 华天科技 | **85** (极强) | **27.5** (过滤) | 🔥→🚫 | 5日涨25%+RSI 80超买+布林带突破+偏离MA20 15% |
| 雄韬股份 | **55** (中) | **39.5** (弱) | ⭐→💡 | 量价背离+尾盘跳水+量价负相关+放量滞涨 |
| 理想标的 | 59 (中) | 47.5 (弱) | ⭐→💡 | 无警告，但评分门槛提高，需更强信号才能触发 |

**核心效果**: 华天科技从最强信号直接降为过滤级别，避免了4.71%的损失。雄韬股份从"关注"降为"弱信号"，避开了跌停。

## 四、止损机制

在 `RiskManager` 中新增两个止损方法：

### 个股硬止损
```python
rm.individual_stop_loss("002185.SZ", entry_price=10.0, current_price=9.5)
# → (True, "个股止损: 002185.SZ 亏损-5.00%, 触发-5%止损线")
```

### 时间止损
```python
rm.time_stop_loss("002733.SZ", entry_date, current_date, pnl=-0.04)
# → (True, "时间止损: 002733.SZ 持仓4天, 收益-4.00%未达预期, 强制离场")
```

参数可配置：
- `individual_stop_loss_pct`: 默认5%（可调整为3%/8%）
- `time_stop_days`: 默认3天
- `time_stop_pnl_pct`: 默认-3%

## 六、后续优化方向

1. **市场环境识别**: 集成 `MarketState` 分类器，熊市中资金流信号权重下调
2. **行业轮动**: 同行业多只股票上榜时，优选龙头而非跟风
3. **游资vs机构区分**: 游资席位（东方财富拉萨系）的流入信号应降权
4. **龙虎榜数据T+1延迟**: 信号发出日与数据截止日存在1天延迟，需在评分中考虑隔夜风险
5. **样本外验证**: 用2026-06月新数据回测，统计改进后的命中率和最大回撤

## 七、风险提示

- 龙虎榜数据有T+1延迟，信号基于历史数据
- 新模型提升了过滤标准，可能漏掉部分真机会（降低召回率以换取更高精确率）
- 技术面参数（RSI阈值、涨幅阈值）需要根据市场环境动态调整
- 本报告仅作研究参考，不构成投资建议
