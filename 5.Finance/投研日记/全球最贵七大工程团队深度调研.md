## 二、Jane Street — 全球最赚钱的自营交易公司

### 2.1 薪酬水平

2025 年 Jane Street 录得 **$396 亿净交易收入**，EBITDA $312 亿，3,500 名员工人均创造 **$900 万利润**、**$1,130 万收入**。

历史上 JS 将约 **20% 收入用于薪酬**，据此推算 **2025 年人均薪酬约 $230 万**——这是平均值，不是资深 PM 的数字。

| 级别 | Base | Sign-on | Bonus | **总包(第一年)** |
|------|------|---------|-------|-----------------|
| 应届 SWE | $200K-$250K | $100K-$150K | $100K-$250K | **$350K-$550K** |
| 应届 Quant/DS | ~$300K | -- | -- | **$300K+** |
| 中级 SWE(3-5年) | $250K-$325K | -- | $200K-$600K | **$500K-$1M** |
| 高级 SWE | $300K-$400K | -- | $500K-$2M+ | **$800K-$3M+** |
| 合伙人/PM | -- | -- | -- | **$5M-$50M+** |

- FPGA 工程师岗位公开 base: **$250,000**（不含奖金）
- 数据中心工程师 base 最高 **$225,000**
- 三年内人均收入从 $400 万飙升至 $1,130 万，生产力复合增长惊人

### 2.2 团队规模与结构

- **3,500 人**（2025），约 500+ 软件工程师
- **极度扁平**：没有 CEO，没有正式工程师职级
- 约 **40 名股权合伙人**集体管理公司
- 核心人物：Yaron Minsky(技术负责人)、Rob Granieri(联合创始人)
- 办公室：纽约(HQ)、伦敦、香港、新加坡、阿姆斯特丹、孟买
- 正在大规模招聘数据中心人才，8 个数据中心相关岗位开放

### 2.3 技术栈

- **主语言：OCaml** — 全球最大 OCaml 代码库，3,000 万行
- 一切用 OCaml 写：交易系统、研究代码、监控工具、系统自动化
- **Hardcaml**：OCaml 嵌入式 HDL，用于 FPGA 设计(RTL)
- OCaml 5 多核迁移于 2025 年完成
- 自建工具链：Iron(代码审查/CI/CD)、magic-trace(系统追踪)、Dune(构建系统)
- 扩展 Python/ML/CUDA 使用，与 **CoreWeave 签订 $60 亿云计算合同**
- FPGA 团队自研硬件加速，使用 Hardcaml + Verilog + C
- 赞助 OCaml Labs(Cambridge)、OCaml 编译器开发

### 2.4 企业文化

- **"芝加哥风格"**：重视概率基础和心理数学
- 智力密集但**真正协作**，无等级文化
- SWE 典型工时 **9am-6/7pm**，交易台更长
- **无竞业限制协议**
- 内部有深厚的棋牌游戏文化(Magic: The Gathering、扑克)
- 入职第一年半有系统培训课程(性能工程、增量计算、函数式编程进阶)
- 实习生可质疑资深交易员
- 公司资助大量开源项目和学术研究

### 2.5 招聘标准

- **录取率 <2%**
- SWE 面试**纯考编程**：不考心算、不要求 OCaml、不要求金融背景
- Quant 面试**第一关是心算测试**(8 分钟 60 题)
- 无 GPA 或学位硬性要求，**70+ 所大学**进入实习生项目
- 可以 re-interview(建议等一年)
- 面试语言任选，强调不要临时学 OCaml
- 偏好：好奇心 > 现有知识，智力谦逊 > 炫耀

### 2.6 最新动态(2025-2026)

- **2025 年收入 $396 亿**，超过 JPMorgan 整个交易部门($358 亿)，且仅 3,500 人
- Q1 2026 收入约 $161 亿(同比 +100%)
- 被印度 SEBI 禁止期权交易(涉嫌市场操纵调查)
- OCaml 编译器扩展：模态类型(Modal Types)、Unboxed Types
- CoreWeave $60 亿合同推动 AI/ML 基础设施
- 数据中心建设大规模扩张(纽约、伦敦、芝加哥、香港、孟买)
- 做市份额：~10% 美国股票，ETF 做市全球领先

## 三、Hudson River Trading(HRT) — 增长最迅猛的 HFT 巨头

### 3.1 薪酬水平

HRT 在 2025 年超越 Jane Street 成为 Levels.fyi **应届生薪酬第一名**：平均 $400K。

| 级别 | Base | Sign-on | Bonus | **总包** |
|------|------|---------|-------|---------|
| 应届 L1 | $200K-$250K | $100K-$200K | $100K-$300K | **$400K-$700K** |
| 中级 L2 | ~$289K | -- | ~$212K | **$507K**(中位数) |
| 高级 L3 | ~$313K | -- | ~$259K | **$603K**(中位数) |
| 资深 Staff | $375K-$500K | -- | $1M-$3M+ | **$1.5M-$4M+** |
| Lead/核心 | -- | -- | -- | **$5M-$10M+**(好年份) |

- 公开岗位 listing: 2026 应届生 C++/Python **base $300K**
- 伦敦办公室 152 人平均薪酬 **£652K(~$820K)**，其中交易团队 26 人平均 **£945K(~$1.2M)**
- Q1 2026 人均年化收入 **$2,330 万**，行业内最高

### 3.2 团队规模与结构

- **~1,150 人**(2025 年底)，技术/工程约 **600+ 人**
- **16 个国家**有办公室：NYC(HQ)、芝加哥、Austin、Boulder、西雅图、伦敦、都柏林、新加坡、上海、香港、孟买、首尔
- **单一结构**（非 Citadel 的 pod 竞争模式），跨团队共享
- 三大部门：**Trading Tech**(C++ 70%/Python 30%)、**Research & Development**(Python 70%/C++ 30%)、**Business Units**
- 业务线：Classic(核心 HFT 做市，~50% 利润)、Prism(中频策略，>$20 亿收入)、股票统计套利、量化宏观、系统化信用
- 创始合伙人 **Oaz Nir 于 2025 年 1 月离职**
- 2026 年 4 月从 Citadel Securities 挖来 David Zderic(前亚太低延迟负责人)

### 3.3 技术栈

| 层级 | 技术 |
|------|------|
| **硬件** | FPGA(Verilog/VHDL), ASIC(自研), 定制服务器(超频/液冷) |
| **低延迟** | C++17/20/23, 内核旁路(DPDK/Solarflare), 微波/mmWave 网络 |
| **交易核心** | C++, OCaml(交易逻辑和研究基础设施) |
| **研究** | Python(NumPy/pandas/PyTorch), 自研回测框架 |
| **基础设施** | 定制 Linux(实时内核), PB 级存储, 分布式调度器 |
| **新兴** | Rust(FPGA 邻近系统), Transformer 模型(AI 支出 ~$10 亿/年) |

- 与 **Google Cloud 合作**（2024 年）用于研究计算
- 处理 **100+ TB** 历史和实时市场数据
- **~$10 亿/年 AI 支出**：Transformer 模型、Agentic AI 工作流

### 3.4 企业文化

- **"Built by coders, led by coders"** — 工程师就是产品本身
- **"Truly kind"** — 前量化研究主管 Giuseppe Paleologo 在 Matt Levine 播客上的评价
- 技术人是**真正的一等公民**，没有交易员 vs 工程师的等级
- **扁平层级** — 工程经理也必须写代码并通过同样技术测试
- 工时 **40-50 小时/周**，无限 PTO(真的能用)
- 但 2025-2026 年文化在变化：Oaz Nir 离职、从 Two Sigma 大量招人、协作氛围受影响
- **极度保密** — "在本来就秘密的同行业中异常秘密"

### 3.5 招聘标准

- **录取率 0.1%** — 校园招聘官 Christina Song 透露: 15,000-20,000 份申请，仅录约 **20 名实习生**
- 面试难度 **5/5**(最高)
- C++ 岗位要求：深度 C++ 知识(内存管理、模板、无锁数据结构)、系统级知识(虚拟内存、OS、并发)
- 面试官会评估"teachability"和"collaboration"
- **CTO 级别候选人也要通过同样的编码测试**
- 中国学生录取较多，很多面试官有中国背景
- 不要求金融背景

### 3.6 最新动态(2025-2026)

- **Q1 2026 收入 $64 亿**(同比 **+135%**)，利润 $42 亿(+175%)
- 2025 全年收入 **~$123 亿**(同比 +54%)
- **EBITDA 利润率 70%**
- **净交易资本 $200 亿**(Q1 2026)
- 从 HFT 向**中频策略**扩展(Prism 单元)
- **~$10 亿/年 AI 投资**
- 市场份额：**~20% 美国股票交易量**、**15% 比特币/以太坊现货**
- 做市行业已成"三极格局"：Jane Street($396 亿) > HRT($123 亿) > Citadel Securities($122 亿)
- 首次发债融资(2026 年额外 $6 亿)

## 四、Two Sigma — 工程最受尊重的量化对冲基金

### 4.1 薪酬水平

Two Sigma 是私人合伙企业，无股权，薪酬 = base + 现金奖金。奖金权重极大。

| 级别 | Base | Bonus | **中位数 TC** |
|------|------|-------|--------------|
| L1 应届 SWE | ~$162K-$280K | ~$78K-$300K | **$253K-$350K** |
| L2 | ~$186K | ~$111K | **$297K** |
| L3 | ~$203K | ~$112K | **$315K** |
| L4 高级 | ~$271K | ~$162K | **$433K-$435K** |
| L5 Staff | -- | -- | **$566K** |
| L6 主管 | ~$323K | ~$407K | **$730K-$800K** |

- SWE Manager 中位数: **$504K**
- 公开岗位 base range: $165K-$325K
- Blind 数据：25th percentile $265K, 90th percentile $500K
- **无股权**（私人公司），完全依赖现金奖金
- 奖金部分递延 3-5 年(senior)

### 4.2 团队规模与结构

- **~2,000 人**，技术/工程约 **900+ 人**
- 量化研究员 ~400 人
- 250+ PhD, 650+ 高级学位
- 九大工程垂直领域：Platform、Modeling、Data、Reliability(SRE)、Trading、Enterprise、Infrastructure、Security、Product
- 子团队：Quantitative Components、Fast Engineering(Rust)、Techniques Engineering(ML/AI)、Systematic Macro、Enterprise Platform
- 伦敦 56 名工程师(2 年持平)

### 4.3 技术栈

| 类别 | 技术 |
|------|------|
| **研究语言** | Python(NumPy/SciPy/PyTorch/JAX) |
| **生产后端** | Java(JVM 生态主导) |
| **低延迟执行** | C++ |
| **新一代低延迟** | Rust(Fast Engineering 团队) |
| **数据仓库** | BigQuery(完成迁移) |
| **数据转换** | dbt(SQL CI/CD) |
| **编排** | Kubernetes(多租户，on-prem + 云) |
| **流处理** | Kafka |
| **批量处理** | Apache Spark |
| **FPGA** | 近期引入 |
| **AI/LLM** | PyTorch, JAX, LLM + Agentic AI 探索中 |

- 算力相当于 **Top 5 超算站点**
- 100+ teraflops, 380+ PB 存储(早期)/600+ PB(近期)
- 每天 48,000+ 模拟, 10,000+ 数据源
- 开源贡献：Apache Arrow, Mesos, Spark, Jupyter, Pandas, Cook(批处理调度器), BeakerX

### 4.4 企业文化

- **历史 WLB 极好** — 9-to-7ish，被评为 "chill hedge fund"
- 2024 年 11 月裁员 ~200 人后 WLB 下降，"每个人都要更努力工作"
- **SWE 是一等公民**，不是服务人员
- 架构决策**联邦制**，早期工程师也能影响系统设计
- 学术氛围浓厚：发表论文、赞助会议、Papers We Love NYC
- 5 个学习日/年 + 1 个专业发展会议赞助
- 全额支付医疗和牙科保险
- 混合办公：最少 5 天/月 到办公室
- 文化在恶化：创始人纠纷、CEO 更迭、裁员、VP 级人员流失

### 4.5 招聘标准

1. 简历筛选 → OA(HackerRank) → 技术电话(编程+行为) → Virtual Onsite(编码+系统设计+行为) → 团队匹配
2. 总体难度 **中到高**，"极其挑剔，淘汰绝大多数工程师"
3. 注重代码质量和工程思维，沟通和结构化表达很受重视
4. SWE 岗**不要求 PhD**，但无 PhD 候选人需要在技术面试中明显强于 PhD 基线
5. 实习生包括 Unix 终身成就奖得主、Putnam 奖牌得主、ACM 决赛选手、IMO 奖牌得主
6. 签证赞助从 **125(2025) 降至 18(2026)**，招聘显著减速
7. 不要求金融背景

### 4.6 最新动态(2025-2026)

- **创始人纠纷持续**：John Overdeck 和 David Siegel 多年不说话，已进入仲裁
- **管理层剧变**：
  - 2024 年 8 月两位创始人辞去 co-CEO
  - 2024 年 11 月新 co-CEO 裁员 ~200 人(10%)
  - 2025 年 1 月 SEC 罚款 **$9,000 万**（模型漏洞知情不报 + 违反举报人保护）
  - 2025 年 4 月 Overdeck **重返管理委员会**
  - 2026 年 4 月 co-CEO Scott Hoffman **辞职**（不到 2 年）
- AUM 创新高 **$700 亿**
- $1.2 亿 Eclipse 基金清盘
- 投资业绩仍保持稳健
- 技术方向：Rust 采用、LLM/GenAI 集成、FPGA 引入、系统化宏观扩展
- 多个 VP 级别离职(2025 末-2026 初)

## 五、D.E. Shaw — 最学术的量化巨头

### 5.1 薪酬水平

| 级别 | Base | Sign-on | Bonus | **总包** |
|------|------|---------|-------|---------|
| 应届 Quant Dev | $155K-$180K | -- | -- | **$240K-$335K** |
| 应届 Quant Researcher | $170K-$200K | -- | -- | **$280K-$390K** |
| 应届 SWE (Member Technical) | $134K-$180K | -- | $108K | **$315K-$335K** |
| Project Lead | ~$300K | -- | ~$750K | **$1,050,000** |
| 中级 QR(3-5年) | $200K-$250K | -- | $200K-$450K | **$425K-$675K** |
| 高级 QR | $225K-$295K | -- | $350K-$855K | **$575K-$1.15M** |
| 资深 QR/PM | $350K-$500K | -- | $1M-$5M+ | **$1.5M-$15M+** |

- 实习 SWE: **$25,000/月** + $20K sign-on + 住宿 + 设备补贴，12 周总包 **~$57K-$73K**
- 印度(Member Technical): ₹38.3L($41.8K)中位数

### 5.2 团队规模与结构

- **~2,500+ 人**(2025)，技术开发 **750+ 人**
- DESCO(对冲基金)和 DESRES(科学研究)法律上和运营上独立
- DESRES 专注计算生物化学/分子动力学模拟，自研 Anton 3 超级计算机
- 办公室：NYC(HQ)、伦敦、香港、上海、新加坡、海得拉巴(最大海外办公室)

### 5.3 技术栈

| 类别 | 技术 |
|------|------|
| **研究** | Python(NumPy/pandas/scikit-learn/PyTorch/JAX) |

| **中台服务** | Java |
| **函数式** | OCaml(历史上著名)、Haskell |

- ClickHouse 集群细节(2026 年 5 月公开): 68TB 压缩指标, 平均 530K 记录/秒插入, 峰值 1M+/秒
- 开源贡献：IPython, Jupyter, NumPy, Versioned HDF5, Pyflyby, Cascade(C++硬件模拟框架), PJRmi

- **Jane Street**: CoreWeave $60 亿合同, ML 扩展
- **Two Sigma**: LLM 特征工程(从月到分钟), Agentic AI 研究
- 每家都在大力投资 AI，但方向不同(自营公司做 alpha，银行做效率和风控)

### 10.3 人才战争

- 顶尖自营公司(HRT/JS/DES)以 **$400K-$700K** 应届生总包与 OpenAI/Anthropic 直接竞争
- 但 AI 公司正积极从量化基金挖角量化研究员和交易员
- 银行在薪酬上无法竞争，但提供更稳定、更广的职业路径
- Two Sigma 的创始人纠纷和内部动荡可能是人才外流预警信号

### 10.4 风险因素

- **Two Sigma**：创始人仲裁、CEO 离职、SEC 罚款、人才流失——是最脆弱的
- **Jane Street**：印度监管风险(SEBI 调查)
- **HRT**：文化变化(创始人离职、Two Sigma 员工涌入)
- **D.E. Shaw**：最稳定，几乎没有负面信号
- **银行**：在交易业务上结构性衰退，但技术投资规模本身是护城河
