## 二、三大业务线拆解

SpaceX 的估值支撑从原来两个引擎变成了三个：

### 1. 发射业务（Crown Jewel）

这是 SpaceX 的基石，其他一切的引擎。

- **可重复使用是护城河**：目前的 Falcon 一级可回收，降成本到 ~$1500/kg。Starship 目标是两级全回收
- **Starship V3 是拐点**：两级全回收后，成本降到 < $250/kg。假设火箭无限次复用的话，成本趋近于燃料费
- **发射频率急速攀升**：
  - 2025 年：165 次发射
  - 2-3 年内：数百次/年 → 上千次/年
  - 终极目标：一天 2-3 次发射
- **快速复用是关键**：Fox 说这是「需要相信的东西」——让火箭像航空公司一样高频运行。如果成功，每 KG 成本降低 5 倍以上

> "传统的火箭行业就像：你登上飞机，飞到了加利福尼亚，下飞机后飞机就爆炸了。"

### 2. Starlink 通讯（宽带 + 直连手机）

- **宽带还在极早期**：全球家庭渗透率不到 1%，目标可达数亿用户
- **从 $10B 到 $50B**：银行模型预测 2028 年通讯营收 5 倍增长
- **48 小时搞定一架飞机的 Starlink 改装**：与传统模式需要大型改装、停机几天相比，Starlink 是螺丝刀级别的安装

**直连手机（Direct to Cell）**：
- 主持人吐槽硅谷 Sand Hill Road 连个电话都打不了
- "等 Starlink 直接连手机出来，我们再也不用在那条路上丢电话了"
- 全球电信市场规模巨大，$50B 只需 0.3% 渗透率

### 3. AI 计算（Elon Web Services）

这是节目最大的讨论焦点——**30 天内从零变成全球第四大 AI 云服务商。**

- **xAI 的云计算交易**：
  - 与 **Google** 的交易：每 GW 运营利润超过 Anthropic、Meta、Google、OpenAI
  - 与 **Anthropic** 的交易：利润率仅次于 Anthropic 自身

- **Altimeter 的计算**：Colossus 1 集群的 IRR 达到 **55%**。能在 6-8% 的利率下获得 55% 的 IRR——"我不是最复杂的思考者，但这个算术没问题。"

- **122 天建成 10 万 GPU 集群**：行业通常需要 3-4 年（规划 3 年 + 安装 1 年）。黄仁勋原话："Elon is an end of one"（绝无仅有）

- **市场被颠覆的速度**：一个月前没有人把 SpaceX 视为 AI 云计算竞争者，现在它越过 Oracle、CoreWeave、Nebius 等一众公司，直接成为第四大玩家。Gavin："这太疯狂了，这太不可思议了。"

**溢价逻辑**：
- Google 愿意支付高溢价买 xAI 的地面计算资源，可能还包含一个「太空计算优先权」的看涨期权
- 地主优势：能快速、大规模、集中地建好计算资源的人，拥有定价权

## 三、关键变量拆解

### 变量一：数据中心建设速度

- Elon 建数据中心的速度无人能及。速度 = 成本（每天都要付电工和水管工的工资）
- 在计算短缺的世界里，谁能最快把电力和 GPU 变成收入，谁就是赢家
- Colossus 1 的 55% IRR 已经证明这个模式成立

### 变量二：Pareto 曲线的竞争

- **Pareto 曲线 = 给定成本下能得到多少智能**
- 所有前沿模型收入都会流向 Pareto 最优的玩家
- Cursor 的 Composer 2：用极少的训练量在 Pareto 曲线低端做到主导
- 但 Anthropic 的 Opus 4.7、4.8、Fable、Mythos 在两周内两次更新 Pareto 曲线
- **结论**：谁在 Pareto 曲线上占优，谁就能快速扩大收入。而 SpaceX 既有计算又有模型

### 变量三：轨道数据中心——5 倍成本优势

| 对比 | 地面数据中心 | 轨道数据中心 |
|:---|:---|:---|
| 建设成本/GW | $20-25B | ~$5B |
| 土地 | 稀缺、贵、受限 | 太空无限 |
| 电力 | 瓶颈、通胀 | 太阳能（太空无限） |
| 冷却 | 成本高 | 免费（太空天然制冷） |
| 总包成本 | $60B/GW（含 GPU） | ~$30B/GW（含 GPU） |

- **GPU 成本约 $35B 不变**（地面和太空一样贵）
- **降低成本的是非 GPU 部分**：从 $25B 降到 $5B，约 **5 倍**
- 算力部署成本从 $60B/GW 降到 $30B/GW，且太空运营成本更低

**前提**：Starship V3 两级全回收 + 快速复用。如果卫星失效率不显著高于地面 GPU 故障率，算术成立。

**额外优势**：地面电力和冷却成本大概率是通胀性的，太空是通缩性的。

## 四、被忽视的最大变量：模型能力

### Cursor 收购

这是 Gavin 眼中市场最没关注到的最大上升空间：

- **Cursor**：700-800 人团队，年化营收可能已接近 $10B，增长极快
- 被 xAI 收购后突然获得了此前极度匮乏的计算资源
- **Cursor 有什么**：与 Anthropic 并列，拥有最多私有编码训练数据——超过公开互联网上所有编码数据的总和

### Composer 2.5 的惊艳表现

- Composer 2 基于 Kimi K2.5 基座模型，加 Cursor 私有数据做 RL 微调 → 极低成本就做到了 Pareto 最优
- 然后在 Colossus 2 集群上训练了三周 → Composer 2.5 12 天前成为 Pareto 主导（在他们自己的 Cursor Bench 基准上）
- 这个速度意味着：**当你在 Pareto 曲线上有多个位置时，有计算就能快速扩展**

### Grok 4.3 的训练

- 正在训练中，1.5T 参数
- Cursor 数据被注入到预训练过程，不仅仅是 RL 阶段
- 如果跟随 scaling law，这将比 K2.5 基座更强
- **12 天前已经有 4 家公司站在 Frontier 上**：SpaceX AI、Google（Gemini 3.1 Pro）、Anthropic、OpenAI。SpaceX 是其中之一

### 编码 = 通往 AGI 的最快路径

- Replet 创始人的观点（「苦涩的教训」的延伸）：**如果你真的擅长编码，你就可以写代码做任何事情**
- 编码可能是通往 AGI 和 ASI 的最快路径
- 这使 Cursor 数据的战略价值远超出表面

## 五、AI 行业格局讨论

### 开源 vs 闭源：谁赚走了钱

- **当前现实**：前沿闭源模型拿走了 ~90% 的 AI 经济价值
- **Jensen 的预测**：未来开源模型追上来后，路由层会决定什么任务用什么模型
- **但目前为止**：每一次都说开源会追上，但前沿模型每次都再进一步。当开源学会做长运行 Agent 任务时，前沿模型又解锁了新的能力
- **开源对谁好**：开源越好 = 用到了更多计算 = 对计算提供商越利好。开源的进步对 Nvidia、对计算硬件是牛市信号

**Codex/OpenAI 的 ASIC 风险**：如果开源模型压缩了前沿模型的利润空间，则定制芯片（ASIC）的投入回报将难以支撑。

### Nvidia 的市场份额——不减反增

- 与普遍预期相反，Nvidia 在营收/GW/单位三个维度上都保持了市场份额，甚至有所增长
- Anthropic（不用 Nvidia 的主要玩家）出去后，Nvidia 份额实际上还涨了
- **$10B vs $10B vs $6B**：OpenAI 给 Nvidia $10B，Broadcom 也是 $10B，AMD $6B。但实际落地多少，"我们走着瞧"
- Gavin："我还是会很惊讶如果 27GW 里非 Nvidia 的那部分能占到 10GW。我认为那是个极不可能的结果"
- Jensen 的关键论点：**在用水受限的世界，每瓦特产出的 token 就是收入。** 如果你用别家芯片建工厂，你可能省了芯片钱，但收入少了，利润率更低

### 训练 vs 推理的支出结构

- 推理收入：2027 年预计 ~$300B（主持人认为这个数字被低估）
- 训练支出：约占 35%，不直接产生收入但为下一代模型投入
- Capex 与推理收入的比值正在改善

**Jensen 再次被证明保守**：两年前他预测 $1T capex，当时看起来疯狂——现在看是**低估了**。2027 年 capex 可能接近 **$1.5T**（包括 SpaceX、CoreWeave 等非 Mag 7 玩家）

## 六、ROI 争论

### 从「不会产生收入」到「收入爆炸」

AI 投资的"三段式"叙事演变：

1. **第一阶段**（已被证伪）：前沿实验室永远不会产生有意义的收入
2. **第二阶段**（已被证伪）：即使有收入，利润率也会很差，赚不到钱
3. **第三阶段**（当前争论）：他们在"超额收费"（token maxing），这种利润率无法持续

Gavin 的反驳："最好的证据是——为什么数百万独立企业和消费者都同时选择做同样的事？这些是理性的经济行为者，不是被强迫的。他们都在说'这让我的生活更好、生意更好'。"

### 每 GW 的货币化率正在加速

| 时期 | 每 GW 年化收入 |
|:---|:---|
| 2026 年初（最好情况） | ~$20B |
| 当前（年中） | $30-40B |
| SpaceX Anthropic 交易 | $22-23B |
| SpaceX Google 交易 | $50B |

- 投资人做决策时的回报预期已被**三倍超越**——"意外盈利"
- 对计算的需求远超过物理上能建的供给

### 需求侧还极其早期

- **全球不到 0.2% 的人真正用 AI 的 Agent 能力**
- 主持人自己：一个非技术用户，在 VM 实例里跑 500 个 CPU 核心 + 5 个 GPU 全天候运行。如果拉长到任何有意义的百分比……世界将长期处于计算短缺

## 七、市场观察与仓位管理

### 主持人 Brad 的当前仓位："medium-small"

- 4 月和 5 月市场大涨后，他把仓位从"large"调低到"medium-small"
- 原因：地缘政治（与伊朗战争）、宏观通胀（CPI 4.2%）、市场需要消化预期
- 不是全进全出，是风险收益比的连续调整

### Gavin 怎么想

- 把股票看成"跑步的人"：有些已经爬完陡峭的山，需要休息
- 过去两个月半导体股"不是爬山，是爬悬崖"——它们已经累了
- 别人在 X 上喊"找下一个瓶颈"的游戏已经结束了
- **AI 的季节性**：过去三年夏天 token 消费都趋于平缓（大学生不用 AI 了）
- **但**：当看到 Fable 的能力、看到 Nvidia 下一代的规划，**很难过于看空**

### 宏观悖论

如果年初告诉你：
- 与伊朗开战
- 油价 $100
- CPI 回升到 4% 以上
- 互联网板块跌 15%
- 软件板块跌 8%

正常反应：远离这个市场。但实际结果：**AI 相关组合表现相当不错。** 因为世界低估了 AI 的收入潜力和计算需求。

## 八、大格局

**过去 7 年发生了什么**：
- Mag 7 新增 $1T 营收，对应 $17T 市值
- 而第一个 $1T 营收花了 20+ 年

**接下来 4-5 年**：
- 仅三家公司在加速：SpaceX、Anthropic、OpenAI → 可能再新增 $1T 营收
- 用时可能从 7 年缩短到 4-5 年

**最终**：AI 将改造全球 GDP 的 5-15%。全球 GDP 的 10% = $10T。空间极大。

## 九、总结：SpaceX IPO 的投资逻辑

### 不需要太空就能支撑估值

- 仅地面计算 + Starlink + 发射就能达到 $160B 营收预期
- 当前签下的 Anthropic 和 Google 交易已经显示了远高于假设的货币化率

### 轨道是免费期权

- 成功后：5 倍资本支出缩减
- 不需要现在就相信，这不是 IPO 估值的必要条件

### 模型能力是最被忽视的增量

- Grok 4.3 + Cursor 私有编码数据 → 已进入 Frontier 四强
- 编码可能是通往 AGI 最快路径
- Cursor 团队是「刚被整体装入 SpaceX」的顶级 AI 团队

### 风险

- Starship 两级全回收尚未验证
- 执行风险：能否在 3 年内将发射频率从 165 提到 1000+
- 地缘政治、通胀背景下估值压力
- AI 季节性 + 开源模型可能短期分流 Frontier 收入

> **Brad 的定调**："我不认识另一个企业家或另一个企业能比 SpaceX 对未来有更好的赌注。对于大多数机构投资者来说，这是一个必买、必持有的标的——买完放着，就能同时押注太空和 AI 未来。"
