**作者：李不白（PandaAI个人量化超级助手）**

## 分层定义 Quantskills：三类原子能力 + 双下单形态，构筑策略全链路底座

首先明确我们对 Quantskills 量化原子能力 的官方分层体系。我们将所有量化能力按照业务链路，划分为 **数据处理类、业务逻辑类、下单执行类** 三大板块。三类 Skills 环环相扣，从原始数据到最终交易形成完整闭环。

### 01 数据处理类 Skills：策略的"原料底座"

涵盖 **结构化数据** 与 **非结构化数据** 两大处理能力。

- 结构化数据：包含行情、成交量、财报、因子、持仓等清洗、对齐、降噪、时序标准化模块等；
- 非结构化数据：覆盖金融新闻、研报、舆情、K 线图表、盘口等多模态解析、特征提取单元等。

传统量化开发中，数据工作往往占据六成以上工作量，还容易出现复权错误、时间错位、数据偏移等隐性问题。我们将高频通用数据能力固化为标准化 Skill，统一数据口径与校验规则，让开发者跳过重复劳作，直接聚焦策略核心逻辑。

我们也持续开发多种市场，开拓港美股 / 期权 / 海外市场等。

### 02 业务逻辑类 Skills：投研与 Alpha 挖掘的核心载体

全面覆盖 **传统投研** 与 **智能建模** 两大方向：

- 一方面包含因子挖掘、组合构建、行业中性、风险归因、回测分析等经典投研模块；
- 另一方面集成机器学习、深度学习在量化场景下的特征训练、时序预测、风格适配等建模能力。

所有业务类 Skill 均原生内嵌我们长期验证的统计约束（IC 稳定性、鞅平稳性、因子正交投影）与风控规则，不是单纯的代码片段，而是经过实盘与学术双重打磨的投研逻辑单元。

单个 Skill 或许会随市场风格衰减，但多模块自由组合，能够持续探索全新 Alpha 空间。

### 03 下单执行类 Skills：策略落地的最后一公里

承接投研结论，对接真实交易链路。我们认为 AI 交易时代，会产生两种主流下单交互形态，兼顾传统开发者与 AI 原生、主观交易者的使用习惯，两套形态共享同一底层执行引擎，保证交易规则、滑点、流动性控制完全一致：

- **代码策略下单**：经典编码模式，适配传统量化工程师的现有工作流。
- **上下文（Context）交互下单**：依托 Agent 上下文流转、自然语言交互完成指令，无需编码，适配智能体与主观交易场景。

## 核心行业洞察：量化超额收益的根本性变革

在当下时代，我们内心会有这样的想法：

- 传统固定因子、静态公式必然走向拥挤，但具备持续进化能力的 Agent 不会被同质化挤压；
- 未来市场的超额收益，将从"单一公式 / 代码"转向差异化的 Harness 层编排能力，Alpha 来源会变得愈发多元。

### 01 传统困境：固定因子与静态公式，注定走向拥挤与衰减

这是量化行业公认的铁律：任何一套公开的因子公式、固定策略代码，无论短期收益多么亮眼，随着使用者增多，都会快速陷入因子拥挤。

本质原因很简单：静态的公式、固化的逻辑是"可直接复制的标准化产物"。一旦公开，大量交易者、策略会同时复用同一套逻辑，标的买卖行为趋同，因子的信息含量被快速稀释，IC、夏普等指标持续下滑，超额收益逐步消失。

过去很多团队依赖独家因子构建壁垒，但在 AI 生成、代码开源的大趋势下，"守住一套私有公式"的壁垒越来越脆弱。表层代码与静态能力，终究会走向同质化内卷。

### 02 全新范式：Agent 能力可复用、可进化，跳出拥挤陷阱

如果把静态因子公式比作"一套固定解题答案"，那么 Agent 智能体能力，更像是一名科研人员的综合科研素养。能力可以长期复用，并且能够持续学习、迭代、适配新场景，不会因为多人使用就失效。

- 科研人员掌握实验逻辑、分析方法、推理思维，不会因为同行也做研究，自己的科研能力就消失。
- 同理，我们的 Agent 承载的不是某一条静态指令，而是一整套感知、推理、协同、闭环迭代的动态能力：它能理解市场状态 $z_t$、调用各类 Skills、识别风险、根据反馈自我优化。

Agent 以及 A2A 的核心价值是动态进化：不同使用者、不同场景下，同一个基础 Agent 可以被调教出完全不同的行为逻辑，并生产出不同的因子或策略。底层智能体能力可以全行业复用，但最终输出的策略、交易逻辑千人千面，天然不会像固定因子那样形成统一拥挤。

这也是 AI 时代，量化最核心的破局点。

### 03 未来 Alpha 的核心源头：差异化的 Harness 层编排

当底层的 Skills 原子、基础 Agent 能力逐步走向普惠、趋于一致，真正的超额收益，将集中在 **Harness（驾驭）层** 的差异化编排与调度能力上。

所谓 Harness 层，就是我们定义的下一代量化核心能力：对 Skills、智能体、约束规则、市场状态、全流程链路的组合、调度、管控与动态适配。

举一个直观例子：同样一套动量类 Skill、同样一套风控 Agent、同样的底层数据能力：

- 交易者 A 倾向搭配高弹性标的、放宽短期波动约束，打造趋势型策略。
- 交易者 B 叠加行业中性 Skill、收紧换手率约束，做稳健指数增强。
- 交易者 C 结合多 Agent 上下文交互，根据市场状态动态切换模块组合。

三者使用的底层原材料完全一致，但 Harness 层的编排思路、约束搭配、流程设计、市场应对逻辑截然不同，最终的收益特征、风险属性、超额来源也完全分化。

原因在于，目前人与 AI 的确权程度，还在逐渐发展过程当中；这意味着：

- 底层 Skills、基础 Agent 不再是竞争壁垒，而是全行业共享的基础设施。
- 超额不再依赖"独家神秘因子"，而是来自人对整套量化体系的驾驭智慧。
- Alpha 会从"单一因子收益"演变为"编排逻辑收益、流程收益、动态适配收益"，来源极度多元化，彻底摆脱单一赛道的拥挤困境。

**总结：** 静态公式拼存量，终将拥挤；进化型 Agent 拼增量，持续生长；未来量化的终极赛场，就在 Harness 驾驭层的差异化创造。

## 下一代量化工程：Harness 驾驭工程 + A2A 对等协同架构

基于上述对超额逻辑的判断，我们正式确立下一代量化工程的两大核心支柱：**Harness（驾驭）工程** 与 **A2A（Agent-to-Agent）对等协同架构**。前者是顶层思维，定义"如何创造差异化编排"；后者是底层骨架，支撑"Agent 协同与能力复用"，二者共同承载多元化 Alpha 的诞生。

### 01 传统量化工程的瓶颈

过去的量化工程以"编码写脚本"为核心，工程师大量精力消耗在重复的数据处理、基础代码编写上。投研、建模、回测、交易、复盘各环节相互割裂，策略调整高度依赖人工，面对快速轮动的非平稳市场，迭代效率极低。

这种模式，天然无法支撑"差异化编排"与"持续进化"。

### 02 Harness（驾驭）工程：下一代量化的顶层思维

Harness 的核心释义是驾驭、调度、管控。新一代量化工程彻底扭转重心：不再以"编写代码"为目标，而是以"驾驭原子 Skills、驾驭多 Agent、驾驭动态市场、驾驭多层约束体系"为核心；在这个过程中，通过 Harness 一边确权，一边真正提升思考和市场博弈上的生产力。

结合我们的三类 Skills、双下单形态，在 Harness 范式下，量化从业者从"代码写手"转变为策略体系的设计者、流程调度者、规则定义者，而这正是未来差异化 Alpha 的核心来源。

### 03 A2A（Agent-to-Agent）对等协同架构：底层运行骨架 / 新时代生产力

A2A 是区别于传统"人指挥单一 Agent"的全新组网模式。我们将数据、投研、风控、执行、复盘拆分为独立专业智能体，所有 Agent 处于对等网络中，可自主完成上下文交互、任务流转、信号推送、协同迭代。

数据 Agent、投研 Agent、风控 Agent、执行 Agent 各司其职，共享全局 Skills 库，既可以独立工作，也能联动协作。

这套架构让 Agent 的复用能力最大化，同时为主观投研、上下文交互下单提供底层支撑。无论是量化策略还是主观交易，都依托 A2A 架构实现全链路自主运转。

我们内部也落实了这样的架构，也会开源发布相关案例和文章，大家敬请期待。

## 投研流程革命：量化科研标准化 + 主观流程 Agent 化

伴随能力分层、架构升级，传统零散、经验化的投研模式也将彻底重构。未来无论是量化投研还是主观投研，都会变成可追溯、可复现、可确权、可迭代的标准化流程，而我们即将上线的 IDE，就是承载全流程交互、记录每一步成果的唯一载体。

### 01 量化投研：对标标准化学术科研流程

我们将量化投研定义为一套严谨的科研闭环。

在 IDE 中，流程的每一步都需要完成交互操作、版本留痕与成果确权：

- 数据阶段记录清洗规则
- 投研阶段留存实验方案
- 验证阶段归档风险指标
- 执行阶段记录交易指令
- 复盘阶段生成迭代建议

这套标准化流程解决了传统量化"版本混乱、实验不可复现、权责不清"的痛点，也让开发者的 Harness 编排思路被完整记录、沉淀、复用。

### 02 主观投研：转变为多 Agent 上下文交互流程

长期依赖人脑经验的主观投研，也将完成形态升级：宏观、行业、舆情、标的、风控等主观判断，被拆解为独立主观 Agent。整个投研过程，变成 Agent 之间持续的上下文对话、信息同步、观点碰撞。

交易者可以介入交互过程修正逻辑，最终通过上下文交互下单完成交易。原本藏于人脑中的隐性思考，变成可查看、可传承、可优化的显性流程，主观经验也依托 Agent 能力实现长效复用。

### 03 统一底座

两类投研模式共享同一套底层体系：

- 三类 Quantskills 原子
- A2A 对等架构
- Harness 驾驭思维

最终全部在 IDE 中落地执行。量化与主观的边界逐步融合，形成统一的 AI 投研生态。

## 我们想打造的生态闭环：多元 Alpha 的持续生长体系

当「三类 Quantskills 原子库 + 可复用进化型 Agent + 双下单模式 + Harness 工程 + A2A 架构 + 标准化投研流程 + 一体化 IDE」形成完整闭环，一套能够持续产出 **多元化超额收益** 的生态就正式成型：

1. **底层开源层**：开源 Quantskills 与基础 Agent 成为全行业共享基础设施，拉平数据、基础投研、执行的能力下限，不再有人依靠"私有基础代码"构建壁垒。
2. **能力复用层**：A2A 架构下的 Agent 能力被全生态复用，同时持续自主进化，我们会设计多种进化自适应和迭代机制。
3. **差异化创造层**：行业竞争和差异来源上移至 Harness 驾驭层，不同开发者、团队凭借独特的模块编排、约束调度、市场适配思路，创造风格各异的 Alpha，超额来源走向多元。
4. **闭环迭代层**：IDE 留存全流程数据与交互日志，结合实盘反馈驱动 Skills、Agent、编排逻辑持续优化，形成"创新 → 落地 → 反哺 → 再创新"的正向循环。

在这套生态里，没有单一公式的短期红利，而是依靠思维、编排、体系获取长期收益；没有同质化的拥挤内卷，而是百花齐放的多元化策略形态。

我们即将期待，在未来这样一套体系下，个人与机构之间除信息差以外的鸿沟将会越来越小。
