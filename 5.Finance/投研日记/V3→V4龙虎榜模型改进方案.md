# 龙虎榜 V3 → V4 模型改进方案

> 触发：6/2→6/3 预测复盘中，晋控电力(-8.84%)和新集能源(-3.19%)两笔失败暴露了V3模型的三个结构性缺陷。

---

## 一、V3 模型当前结构

评分维度（满分100）：

| 维度 | 满分 | 规则 |
|:---|:---|:---|
| 机构净买入力度 | 30 | >5亿: 30, >2亿: 20, >0: 10, 净卖出: 0 |
| 北向资金净买入 | 25 | >10亿: 25, >3亿: 18, >1亿: 12, >0: 6, 净卖出: 0 |
| 连续上榜天数 | 20 | ≥5天: 20, 4天: 15, 3天: 10, 2天: 6, 1天: 2 |
| 涨停持续性 | 15 | 净买 >5亿: 15, >2亿: 10, >0: 5 |
| 外资投行席位 | 10 | >2亿: 10, >0: 5, 净卖出: 0 |

数据窗口：6天滚动（如6/2生成：5/28-6/02）

---

## 二、V3 暴露的三个缺陷

### 缺陷 1：无当日反转检测（→ 晋控电力）

**现象**：晋控电力在5/27-5/31连续3天净买入（机构1.68亿+北向7.11亿），6/02当天龙虎榜净卖出3.85亿、换手31%、3连榜。V3在17:17生成时已拿到6/02数据，但因累计值仍为正，照常给了49分。

**根因**：V3只看窗口累计值，不对最新单日做反转检测。

**改进方案 A：加"当日方向检测"过滤层**

在评分计算前，先检查推荐标的最新交易日数据：

| 过滤条件 | 动作 |
|:---|:---|
| 最新日净卖出 > 1亿 | 降一档（强→中，中→弱） |
| 最新日净卖出 > 3亿 | 直接排除 |
| 最新日换手 > 25% + 净卖出 | 直接排除 |
| 最新日换手 > 30% + 连续上榜 ≥ 3天 | 直接排除（晋控电力模式） |

**预期**：晋控电力 6/02当日净卖出3.85亿+换手31%+3连榜 → 被过滤，不会进推荐列表。

### 缺陷 2：无内外资分歧惩罚（→ 新集能源）

**现象**：新集能源机构净买5.36亿（机构满分30），北向净流出-1.4亿（北向0分），总分42照过"中信号"线。但内外资完全相反——机构可能被动配置，北向才是边际定价者。

**根因**：各维度独立加分，不检查维度间矛盾。

**改进方案 B：加"内外资一致性"惩罚维度**

```python
if 机构净买 > 3亿 and 北向净买 < 0:
    一致性惩罚 = -15  # 北向不跟的大机构盘
elif 机构净买 > 0 and 北向净买 < 0:
    一致性惩罚 = -8
elif 机构净买 < 0 and 北向净买 > 3亿:
    一致性惩罚 = -10  # 北向拉、机构跑
else:
    一致性惩罚 = 0
```

**预期**：新集能源 30+0+2+10+0=42 → 扣15分 → 27分（弱信号，不进核心推荐）。

### 缺陷 3：连续上榜是高换手时不加反减

**现象**：连续上榜在V3里是纯正面维度（2天=6分，3天=10分）。但晋控电力3连榜+31%换手+净卖出，连续上榜在这里是筹码松动的信号，不是强势信号。

**根因**：连续上榜的"多头持续性"假设在高换手场景下失效。

**改进方案 C：连续上榜分场景赋分**

```
if 连续上榜 ≥ 3天:
    if 最新日净买入 > 0 and 换手 < 20%:
        得分 = 15  # 真正的持续建仓
    elif 最新日净买入 > 0 and 换手 ≥ 20%:
        得分 = 5   # 可能对倒，减分
    elif 最新日净卖出:
        得分 = -5  # 出货型连榜，惩罚
elif 连续上榜 == 2天:
    if 最新日净买入 > 0:
        得分 = 6
    else:
        得分 = 0
```

**预期**：晋控电力3连榜+净卖出 → -5分（而非+10），总分进一步压低。

## 三、V4 评分体系（新）

| 维度 | 满分 | 变化 |
|:---|:---|:---|
| 机构净买入 | 30 | 不变 |
| 北向净买入 | 25 | 不变 |
| 连续上榜（场景化） | 20 | **改为分场景赋分**（见方案C） |
| 涨停持续性 | 10 | 降低5分，减少对涨停的过度依赖 |
| 外资投行 | 5 | 降低5分，外资席位信息噪音大 |
| **内外资一致性** | **10** | **新增**：同向=10，背离=-10~-15 |
| **时间衰减加权** | **乘数** | **新增**：最新日×1.0，前日×0.7，更早×0.5 |
| **总分** | **100** | 不变 |

**新增过滤层（评分前执行）**：
1. 当日净卖出 > 3亿 → 排除
2. 当日换手 > 30% + 连续上榜 ≥ 3天 + 净卖出 → 排除
3. 当日换手 > 25% + 净卖出 > 1亿 → 降一档

## 四、预期效果

用V4规则回测两笔失败：

| 股票 | V3得分 | V4得分 | 变化 | 是否入推荐 |
|:---|:---|:---|:---|:---|
| 晋控电力 | 49(中) | 被过滤层排除 | 当日净卖出3.85亿+换手31%+3连榜 | ❌ 不推荐 |
| 新集能源 | 42(中) | 27(弱) | 一致性惩罚-15（机构满分+北向流出） | ❌ 不进核心 |

6笔命中标的中，V4规则不影响——它们当日都是净买入，内外资方向一致。

**预期命中率提升**：75% → ~85%（两笔误杀消除，推荐池更干净）。

## 六、风险提示

- 过滤层可能过度剔除：如果某日大量标的净卖出（系统性下跌），过滤会清空推荐池
- 一致性维度阈值（3亿/1亿）需要回测校准
- 时间衰减权重（1.0/0.7/0.5）需要参数扫描
- 回测后再上线，不要在实盘直接切
