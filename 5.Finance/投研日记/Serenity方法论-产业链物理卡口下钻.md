## 谁是Serenity？

海外匿名分析师，**自我定位：追踪无人注意的瓶颈**。今年战绩45%，靠的不是一次性判断，而是一套可复制、可验证的**产业链下钻方法论**。

## 核心方法论：六步下钻法

### 第一步：选超级周期主题
确定当前的大赛道（如AI、大模型）

### 第二步：锁定龙头
找到赛道的龙头（如英伟达），把龙头**当入口，不当终点**

### 第三步：产业链逐层下钻
从龙头 → 芯片 → 衬底 → 设备 → 材料，一层一层往下挖

### 第四步：四问物理约束（每层必问）
1. **谁垄断？**（寡头格局）
2. **扩产多久？**（扩产周期长 = 护城河）
3. **有没有替代？**（替代品 = 水流分流）
4. **下游必须用吗？**（刚需 = 水流必须经过）

### 第五步：找到卡口
"核道收窄的地方"——水流必须从这里通过，绕不开

### 第六步：多维度筛选
产能、订单、验证、估值等综合过滤

## 什么样的卡口才算真正的卡口？

四个硬条件：

| 条件 | 含义 |
|:---|:---|
| 不可替代 | 没有能完全替代的产品或技术 |
| 供给刚性 | 扩产周期长（1-2年），供给弹性低 |
| 寡头垄断 | 全球只有少数几家能做 |
| 无人关注 | 暂时没有被机构过度挖掘，尚未定价 |

形象比喻：**水流必须从收窄的河道通过，你在这里收过路费。**

## 为什么只看物理约束，不看商业叙事？

- 商业叙事（画饼）人人都能讲
- 物理约束是**硬的**：材料、工艺、化学上的限制
- 扩产周期、良率爬坡、有无替代 → 这些物理约束比任何商业叙事都硬

## 典型案例：AI产业链下钻

```
大模型（龙头：英伟达）
  ↓
光互联（瓶颈：大家一窝蜂涌入）
  ↓
关键光源（全球只有两家能量产）
  ↓
特种衬底材料 / 先进封装 / 专业合成设备
  ↳ 卡口：替代不了、扩不出、还寡头、还没人看
```

## 方法论的边界（什么时候不灵）

1. **卡口对线 ≠ 长期都好**：太硬有时反而限制成长空间
2. **顺风期依赖**：顺风放大命中率，逆风时方法论效果打折
3. **不是每个关注点都是物理卡口**：需要自己验证和判断

## 实操流程（用Claude Code落地）

```
1. 选定赛道
2. 用Claude Code通过S.Data拉研报（起步200篇，大赛道1000篇）
3. 逐层拆解产业链
4. 每层问四个物理约束问题
5. 发现关键环节 → 再拉该环节研报200篇
6. 反复讨论验证 → 出卡口清单
7. 人工验证 → 确认真实物理卡口
```

**闭环：** AI拆链找候选 → 套四问筛选 → 人工验证 → 方法论反复论证 → 输出真实卡口

## 核心洞见

- 龙头只是入口，不是终点
- **物理约束 > 商业叙事**
- 水流必须经过的地方，才是真正值得投的地方
- 海量研报（500-1000篇）是产业理解的基础
- 人的判断不可替代：AI提候选，人做验证
