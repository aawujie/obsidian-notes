# 特斯拉FSD入华进展追踪

> 调研日期：2026-05-21

---

## 一、核心结论

特斯拉FSD在华落地的两个关键信号均已**属实**：

1. **Q3 2026全面商用目标**：CFO在Q1财报电话会明确表态
2. **大规模急聘智驾测试岗**：5月18日9城同步上线约90个岗位

但FSD入华历史上多次跳票，Q3能否准时落地仍存变数。

---

## 二、时间线：一再推迟的承诺

| 时间 | 事件 |
|:---|:---|
| 2019年 | FSD在中国开启付费选装（6.4万元），完整功能始终未落地 |
| 2024年9月 | 特斯拉宣布FSD将于2025年Q1登陆中国 |
| 2025年2月 | 推送"城市道路Autopilot"OTA更新（不完全版，仅HW4.0+已购FSD用户） |
| 2025年3月 | 限时体验活动仅持续一周即暂停 |
| 2025年11月 | 马斯克称FSD有望在2026年2-3月获批 |
| 2026年Q1财报 | CFO将时间节点调整至**Q3 2026**（第二次推迟） |

---

## 三、实质性进展（2026年）

### 基础设施就绪

| 进展 | 时间 | 详情 |
|:---|:---|:---|
| 上海AI训练中心 | 2026年2月 | 临港正式运营，数据采集→本地存储→本土训练→部署→迭代全闭环，**数据不出境** |
| 本土数据中心 | 此前建成 | 与AI训练中心协同 |
| 百度地图合作 | 此前达成 | 满足测绘合规要求 |

### 产品就绪

- **FSD V14内测**：已向搭载HW4.0硬件的员工车辆推送
- **车主手册更新**：2026.14版本新增FSD V14完整功能说明（2026年5月初）
- **FSD改名**：中国版称"智能辅助驾驶"（监管要求，L2系统必须含"辅助"字样）

### 团队扩张（2026年5月18日招聘）

| 维度 | 详情 |
|:---|:---|
| 总岗位数 | ~90个自动驾驶核心研发岗 |
| 测试岗占比 | >70%，标注急聘 |
| 覆盖城市 | 北京、上海、广州、深圳、苏州、武汉、成都、天津、重庆 |
| 核心职责 | Autopilot/FSD全功能实车测试、中国特色复杂路况测试路线设计、合规性测试 |
| 硬性要求 | 3年驾龄、年里程>1万公里、近1年无重大事故 |
| 优先条件 | 命令行操作经验或赛车背景 |

## 四、风险与挑战

### 监管层面

- 中国尚未出台《自动驾驶法》，L3仍以试点模式在特定区域运行
- FSD若Q3获批，将成为首个实现大范围商用的外资高阶自动驾驶系统，审批谨慎
- 已被要求改名、限制功能描述

### 技术层面

- 此前"不完全版"FSD评测表现差：懂车帝测试Model Y总计接管24次、违章34次
- 问题集中在交通规则误判：压实线、闯黄灯、机非混行车道识别混乱
- 本地AI训练中心刚起步，中国复杂路况适配仍需大量迭代

### 竞争层面

| 对手   | 态势                              |
| :--- | :------------------------------ |
| 华为乾崑 | 辅助驾驶里程 >104.7亿公里，"10月超越特斯拉全球第一" |
| 小鹏   | 何小鹏公开目标"8月在中国市场全面超越FSD"         |
| 行业   | L2渗透率 69.15%（2026年1-2月），同比+10pp |

### 定价层面

- FSD买断价 6.4万元，国内竞品多以免费或低价策略渗透
- 高昂定价在免费智驾遍地跑的国内市场竞争力存疑
- 官网FSD选装项已新增"稍后推出"字样，部分付费车主不满

---

## 五、投资视角要点

**催化路径**：
- Q3获批 → 短期情绪催化 + 软件订阅收入增量
- FSD V14实测表现超预期 → 估值重估

**风险**：
- 再次跳票（历史规律）
- 中国路况适配不达预期、评测翻车
- 国内竞品先发优势明显，特斯拉窗口期收窄
- FSD定价策略在中国市场能否成立待验证

**全球视角**：
- FSD全球订阅用户 128万（Q1 2026），同比 +51%
- FSD V14.3.3 已在北美推送
- 荷兰已获监管批准，Q2启动欧盟拓展
