## 二、空单 1：通道上边缘做空

### 入场逻辑

- **大背景**：明显下跌通道（熊旗结构，看跌通道）
- 第一波反弹附近形成了收敛箱体
- 两根强势 K 线上破区间，但跟随很弱——"跟随太垃圾了，说明多头不是很占优"
- 有假突破征兆，随后反包拉回
- 三根大阳线反弹到通道上边缘 + 明显阻力位
- **双重确认**：箱体上边缘 + 趋势线上边缘 → 两个开仓条件满足，增强信心

### 持仓与格局

- 直接在通道上边缘进场做空
- 一根大阴 → 第二根大阴直接砸穿 EMA20
- 两根 K 线上影线特别长 → 继续格局
- 三根大阴线打出**缺口** → "打出缺口说明空头有力气，继续格局"
- 反包站不上均线 → 破新低 → 止盈
- 大约在 68 附近止盈

### 关键金句

> "满足你的开仓条件就入场，就这么简单。"
> "打出缺口说明空头有力量。"

## 四、空单 2：阻力区再次做空

### 入场逻辑

- 上方是双顶大双顶结构，关键阻力位没破
- 有一个小缺口未补
- 形成了小钝化（震荡积蓄）
- 多头碰 EMA 之后收得"模棱两可"——看似拒绝但力度太弱，"看似拒绝但没拒绝多少"

### 教学要点

- **不能追多**：止损位不好放，上方有阻力、有 FVG，盈亏比不够
- 果然多单马上被砸——"以为反转了，实际上啥都不是"
- 垃圾 K 线时不要动手："啥都不要干，继续等"
- 不是在关键位置的乒乓是"垃圾乒乓"

### 关键金句

> "你得等啊。你止损放哪里？盈亏比够吗？铁不够了！"

## 五、教学插入：一笔可做的多单（未实际操作）

- 下跌过程中插针后直接接阳线 → "必须进，直接进"
- 止损 10 个点（25 进，止损放 15）
- 连续阳线 → 格局持有
- 有缺口必补："震荡区间外的缺口肯定等它去补"
- M 头出来、15 分钟也到关键位 → "这个时候不走就头铁"
- **结果**：最终止损被打掉——"这就是格局的结果"
- 但同一位置再次开仓："前面这支撑有用，这次还是有用"
- 就 10 个点风险，赚 20 个点 → 高盈亏比

### 关键金句

> "永远不要觉得支撑/阻力突然就没用了。"

## 六、空单 3：关键缺口做空（核心交易）

### 背景

- 多头推动形成牛旗（下跌通道内的牛旗），可能测试起点
- 连续阳线反弹到上方缺口位置
- **空头还在**：缺口位置有明显反应，空头在这里埋伏

### 入场策略

- **分批进场**：
  - 半仓在缺口反应处直接进场
  - 剩下半仓挂在开盘价附近
  - 统一止损，放在上方一点点
- K 线精准接到第二笔挂单
- 高位形成双底 → "高位双底没啥用，可能是骗多"，继续格局
- 回踩后阳线反包不强 → 继续格局
- 一小时级别：上影线超长，明显有拒绝

### 结果

> "这一单就是我那天亏到 34 万，然后一波又赚回来 4 万、5 万的那一单。"

## 七、总结：交易哲学与情绪管理

### 核心技术原则

1. **两个开仓条件确认**：结构位 + 趋势线 / 缺口 / 信号共振
2. **右侧等信号**：不追涨、不追跌，等 K 线收好再动手
3. **高盈亏比思维**：10 个点的止损换 20+ 个点的利润
4. **格局持仓**：缺口不补不走，推动有力量不走
5. **关键位置才交易**：垃圾 K 线、非关键位置的乒乓直接忽略
6. **支撑/阻力可复用**：被打掉止损不意味着支撑/阻力失效
7. **多周期确认**：5 分钟 + 15 分钟 + 1 小时联动

### 情绪管理

> "亏了没关系，前面连续亏了没关系，一定不要让情绪控制你的手。"
> "当你有情绪的时候，睡一觉或者再多等几个小时，把情绪压下去，再找机会干回来。"

### 核心金句

> "就这么简单兄弟们。"

## 八、技术概念速查

| 概念 | 说明 |
|------|------|
| **熊旗** | 下跌趋势中的反弹整理结构，看跌延续信号 |
| **FVG (Fair Value Gap)** | 公允价值缺口，价格跳空形成的未成交区域 |
| **EMA20** | 20 周期指数移动均线，短线趋势参考 |
| **钝化** | 价格在窄幅震荡积蓄能量，等待方向选择 |
| **乒乓** | 窄幅横盘震荡，关键位置才有意义 |
| **M 头** | 双顶形态，看跌反转信号 |
| **牛旗** | 上升趋势中的回调整理结构，看涨延续信号 |
| **缺口** | 价格跳空，震荡区间内的缺口大概率回补 |
| **假突破** | 突破关键位后迅速反转，诱多/诱空陷阱 |
