# 国内如何买到持有 SpaceX 的基金

> 数据截止: 2026-05-13 | SpaceX 估值: ~$350-400B（私有公司）

---

## 核心结论

**SpaceX 未上市，国内没有任何公募 QDII 直接持有它。** 但通过以下渠道可间接获得敞口：

---

## 1. DXYZ（Destiny Tech100）— 最易买、浓度最高

| 项目 | 详情 |
|------|------|
| **代码** | DXYZ（NYSE） |
| **类型** | 封闭式基金（Closed-end Fund） |
| **SpaceX 占比** | **~50%**（38.86% SpaceX I + 11.53% SpaceX II） |
| **其他持仓** | OpenAI、Revolut、Anthropic、CHAOS Industries |
| **NAV** | ~$19.97/股（2025.12），同比 +210% |
| **购买方式** | **富途牛牛、老虎证券、盈透** |

⚠️ 封闭式基金市价可能大幅偏离 NAV（曾溢价/折价 100%+）。

---

## 2. ARK Venture Fund（ARKVX）— 一篮子私募科技

| 项目 | 详情 |
|------|------|
| **代码** | ARKVX |
| **类型** | Interval Fund（非交易所上市） |
| **SpaceX 占比** | **5.8% ~ 11.5%**（按季度浮动） |
| **其他持仓** | xAI、Neuralink、OpenAI、Anthropic、Lambda Labs、Figure AI |
| **年化回报** | 成立以来 ~28%（截至 2025.9） |
| **购买方式** | SoFi App 或 Schwab/Fidelity 账户 |

---

## 3. Baron Funds（BPTRX / BPTIX）— 老牌基金

| 项目 | 详情 |
|------|------|
| **代码** | BPTRX（零售）/ BPTIX（机构） |
| **类型** | 传统共同基金 |
| **SpaceX 占比** | **~8-11%** |
| **背景** | Ron Baron 自 2017 年投资 SpaceX，是 SpaceX 最大共同基金股东之一 |
| **购买方式** | 需要美国券商账户 |

---

## 4. 国内私募 / QDLP 专项基金

- **诺亚财富、宜信、恒天** 等头部机构曾推出 SpaceX 专项 SPV
- 门槛：**100 万 - 500 万人民币起**
- 锁定期：通常 **5-8 年**（等 IPO 或老股转让退出）
- 风险：合规灰色、底层透明度低、流动性极差

---

## 5. 间接关联 — Alphabet（GOOGL）

Google 2015 年投 SpaceX ~$9 亿。但 Google 市值 ~2 万亿，SpaceX 影响微乎其微。**纯象征性敞口。**
