# Anthropic Financial Services 项目全局架构

## 项目定位

**Claude for Financial Services** 是 Anthropic 官方发布的金融服务 AI Agent 参考实现。覆盖投行(IB)、权益研究(ER)、私募股权(PE)、财富管理(WM)、基金行政(Fund Admin)五大垂直领域。所有内容以文件形式存在（Markdown + YAML + JSON），无构建步骤。

核心设计理念：**同一套 system prompt + skills，两种交付方式**——既可以作为 Claude Cowork 插件安装，也可以作为 Managed Agent API 的模板部署。

## 设计哲学

### 1. 单一真相源（Single Source of Truth）
- Skills 的**权威版本**在 `vertical-plugins/<vertical>/skills/`
- Agent 插件中的 skills 是**同步副本**（由 sync-agent-skills.py 维护）
- Agent 的 system prompt 文件（`agents/<slug>.md`）是 Cowork 和 CMA 的**共同引用源**

### 2. 技能/命令/连接器三层体系

| 层 | 形态 | 触发方式 | 示例 |
|---|---|---|---|
| **Skills** | 领域知识+步骤方法的 Markdown | 上下文自动触发 | `dcf-model`, `comps-analysis` |
| **Commands** | 用户显式调用的斜杠命令 | `/comps`, `/earnings` | `/ic-memo`, `/screen` |
| **Connectors** | MCP Server 连接 | Agent 调用 MCP 工具 | FactSet, CapIQ, Daloopa |

### 3. 两层部署模型

| 维度 | Cowork 插件 | Managed Agent |
|---|---|---|
| **运行环境** | Claude Cowork (桌面/Web) | API (headless) |
| **触发方式** | 用户交互 | Steering event |
| **文件产出** | 直接在 Office 中编辑 | 生成 .xlsx/.pptx 文件 |
| **配置方式** | 安装插件 | deploy-managed-agent.sh 部署 |

### 4. 安全模型

所有 Agent 遵循统一的安全约束：
- **外部文档不可信**：Reader 子 Agent 仅拥有 Read/Grep 且无 MCP 访问
- **编排者不写**：只有指定的叶子 worker 持有 Write 权限
- **人工审批关口**：Agent 产出 draft，发布/记账需人类审批
- **Handoff 硬白名单**：跨 Agent 路由经验证的目标白名单

## 关键技术决策

1. **纯文件驱动**：无数据库、无构建步骤、无编译。改动即生效。
2. **OpenPyXL + Office JS 双轨**：Cowork用Office JS直接操作Excel；CMA用Python/openpyxl生成.xlsx文件。
3. **Formula over Hardcode**：所有模型必须以Excel公式构建，禁止Python计算后写入数值。
4. **深度1的子Agent委托**：Orchestrator → leaf workers，不再嵌套。安全原因限制委托深度。
5. **Section-by-Section验证**：每个财务模型都分节构建，每节经用户确认后再继续。
