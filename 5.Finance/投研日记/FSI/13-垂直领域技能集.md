# IB/ER/PE/WM 垂直领域技能集

四大垂直领域插件各自提供领域专用的 slash commands + skills。它们共同依赖 `financial-analysis` 核心插件的数据连接器和基础技能。

---

## 一、Investment Banking（投行）

> 插件：`plugins/vertical-plugins/investment-banking/`

### 命令体系（7个）

| 命令 | 技能 | 产出 |
|------|------|------|
| `/one-pager [company]` | strip-profile | 单页公司profile |
| `/cim [company]` | cim-builder | 保密信息备忘录 |
| `/teaser [company]` | teaser | 匿名单页公司推介 |
| `/buyer-list [company]` | buyer-list | 战略/财务买家universe |
| `/merger-model [deal]` | merger-model | 增厚/稀释M&A分析 |
| `/process-letter [deal]` | process-letter | 投标指引和流程函件 |
| `/deal-tracker` | deal-tracker | 在途交易追踪 |

### 技能详解

**交易材料类**：
- **cim-builder**：起草完整CIM——执行摘要、业务概览、财务分析、市场定位
- **teaser**：匿名单页公司推介——核心卖点、关键财务、交易逻辑
- **process-letter**：投标流程函件——时间表、投标指引、联系方式
- **buyer-list**：买方universe梳理——战略买家（同行业）+ 财务买家（PE基金）
- **datapack-builder**：从CIM和披露文件中提取数据构建数据包

**演示材料类**：
- **strip-profile**：信息密集的单页公司profile——4象限（概览/业务/财务/股权）
- **pitch-deck**：投行Pitch Deck模板填充——含4个参考文件（计算标准、格式标准、slide模板、XML参考）

**交易执行类**：
- **merger-model**：并购增厚/稀释分析——Sources & Uses、Pro Forma财务、价格和协同敏感性
- **deal-tracker**：在途交易追踪——里程碑、待办事项、状态更新

## 二、Equity Research（权益研究）

> 插件：`plugins/vertical-plugins/equity-research/`

### 命令体系（9个）

| 命令 | 技能 | 产出 |
|------|------|------|
| `/earnings [ticker]` | earnings-analysis | 财报季后更新报告 |
| `/earnings-preview [ticker]` | earnings-preview | 财报前情景分析 |
| `/initiate [ticker]` | initiating-coverage | 机构级首发覆盖报告 |
| `/model-update [ticker]` | model-update | 模型数据更新 |
| `/morning-note` | morning-note | 晨会笔记+交易idea |
| `/sector [name]` | sector-overview | 行业格局和主题报告 |
| `/thesis [ticker]` | thesis-tracker | 投资论点维护更新 |
| `/catalysts` | catalyst-calendar | 覆盖范围内催化剂日历 |
| `/screen [criteria]` | idea-generation | 股票筛选和idea挖掘 |

### 技能详解

**核心研究类**：
- **initiating-coverage**：最复杂的单技能——**5个子任务**：
  1. 公司研究（业务模型、竞争地位、管理层）
  2. 财务建模（DCF + 三表 + 情景分析）
  3. 估值（DCF + Comps + SOTP多方法论）
  4. 图表生成
  5. 报告整合
  含 `quality-checklist.md`、`report-template.md`、`valuation-methodologies.md` 参考

- **earnings-analysis**：财报分析——实际vs预期、指引解读、管理层语气、核心变量变化
- **earnings-preview**：财报前瞻——情景分析、关键指标、一致预期对比

**持续维护类**：
- **model-update**：将新数据更新到覆盖模型
- **morning-note**：晨会标准格式笔记——标题驱动因素、预测变化、估值更新
- **thesis-tracker**：投资论点生命周期管理——论点验证/否定/演变记录
- **catalyst-calendar**：催化剂日历——盈利日期、FDA决定、产品发布、监管事件

**发现类**：
- **sector-overview**：行业概览——市场定义、规模、增长驱动力、价值链
- **idea-generation** (`/screen`)：多维度股票筛选+idea挖掘

## 三、Private Equity（私募股权）

> 插件：`plugins/vertical-plugins/private-equity/`

### 命令体系（10个）

| 命令 | 技能 | 产出 |
|------|------|------|
| `/source [criteria]` | deal-sourcing | 公司发现+CRM检查+创始人触达 |
| `/screen-deal [CIM]` | deal-screening | 入站CIM快速pass/fail |
| `/dd-checklist [target]` | dd-checklist | 按工作流生成尽调checklist |
| `/dd-prep [target]` | dd-meeting-prep | 管理层陈述和专家电话准备 |
| `/unit-economics [target]` | unit-economics | ARR cohort/LTV:CAC/NR/收入质量 |
| `/returns [deal]` | returns-analysis | IRR/MOIC敏感性表格 |
| `/ic-memo [deal]` | ic-memo | 投委会备忘录草稿 |
| `/portfolio [fund]` | portfolio-monitoring | 组合公司KPI和偏差追踪 |
| `/value-creation [target]` | value-creation-plan | 交割后100天计划+EBITDA桥 |
| `/ai-readiness [target]` | ai-readiness | 组合公司AI成熟度评估 |

### 完整PE流程覆盖

```
Deal Sourcing → Screening → DD → IC Memo → Close → Value Creation → Portfolio Monitoring → Exit
     ↑              ↑        ↑       ↑         ↑           ↑                  ↑               ↑
  /source     /screen-deal  /dd-*  /ic-memo     |     /value-creation   /portfolio      /returns
                                            model-builder
```

**核心发现**：Anthropic 为PE设计了**从sourcing到exit的全生命周期**技能集，是目前市场上最完整的PE AI工具链参考实现。

**特色技能**：
- **unit-economics**：SaaS/订阅制公司的单元经济学深度分析——ARR cohort、NRR、LTV:CAC、收入质量评分
- **ai-readiness**：评估组合公司AI转型成熟度——数据基础设施、技术债务、人才储备、AI机会图谱
- **value-creation-plan**：交易后100天价值创造计划——EBITDA bridge、运营改进路线图

## 四、Wealth Management（财富管理）

> 插件：`plugins/vertical-plugins/wealth-management/`

### 命令体系（6个）

| 命令 | 技能 | 产出 |
|------|------|------|
| `/client-review [id]` | client-review | 客户会议准备（绩效+谈话要点） |
| `/financial-plan [client]` | financial-plan | 退休/教育/遗产/现金流预测 |
| `/rebalance [portfolio]` | portfolio-rebalance | 配置偏差分析+税务优化再平衡 |
| `/client-report [id]` | client-report | 客户面向的绩效报告 |
| `/proposal [prospect]` | investment-proposal | 潜在客户投资提案 |
| `/tlh [portfolio]` | tax-loss-harvesting | TLH机会识别+洗售管理 |

### 技能说明

- **client-review**：客户会议全面准备——关系摘要、绩效回顾、市场背景、建议议程、谈话要点
- **financial-plan**：全面财务规划——退休预测、教育基金、遗产规划、现金流建模、蒙特卡洛模拟
- **portfolio-rebalance**：智能再平衡——配置偏差检测、税务感知卖出、最小交易成本优化
- **tax-loss-harvesting**：税务亏损收割——识别亏损持仓、洗售规则合规、替代标的选择
- **client-report**：客户绩效报告——时间加权收益、基准对比、归因分析
- **investment-proposal**：新客户提案——需求分析、资产配置建议、预期收益模拟

## 量化投研启示

1. **分层技能体系的组织方式**：shared core (financial-analysis) → vertical specific → agent bundled——量化策略工具也可按此组织：shared core (数据/回测引擎) → strategy specific → agent bundled
2. **initiating-coverage的5任务拆分**：复杂研报分为独立子任务各自执行——量化策略上线也可拆分为数据验证、参数校准、回测、风险评估、部署
3. **PE全生命周期覆盖**的一体化设计：quant multistrategy也需要从信号研究→回测→paper trading→live→监控的全流程
4. **TLH的洗售规则合规自动化**：量化策略的监管合规检查（持仓限额、做空限制等）可类似自动化
5. **financial-plan的蒙特卡洛模拟**：可直接应用于量化策略的VaR/CVaR计算和压力测试
6. **合作伙伴插件模式**：LSEG/S&P的MCP + skills架构展示了如何将第三方数据源封装为自然语言可调用的技能
