# 厚尾建模与正偏态发现：5因子策略EVT实证

> 核心：我们的策略不是"危险"的厚尾，而是"有利"的正偏态——亏损有限，偶尔暴涨

---

## 为什么做EVT

课程笔记里写了一条铁律：**"正态分布是最大的幻觉，尾部风险被远远低估"**。

我们信了这个，一直担心策略遭遇极端亏损。于是用极值理论（EVT）实际测了一下——结果反过来了。

---

## 实证结果：正偏态，不是危险厚尾

### 基本统计

| 指标     | 值        | 含义       |
| :----- | :------- | :------- |
| 月度均值   | ~3%      | 平均每月赚3%  |
| 偏度     | **1.64** | 正偏态！右尾长  |
| 超额峰度   | 2.87     | 比正态更尖    |
| 中位数    | ~2.5%    | 均值 > 中位数 |
| 最大月度亏损 | ~-3%     | 亏损天花板很低  |
| 最大月度盈利 | ~+15%    | 盈利天花板很高  |

### 偏度 = 1.64 意味着什么

偏度 > 0 = 正偏态：
- **右尾长**：少数月份暴涨（+10%~+15%），拉高了均值
- **左尾短**：亏损月份幅度有限（很少超过-3%）
- 均值 > 中位数：因为偶尔的暴涨把均值"拉"高了

## EVT vs 正态：谁低估了风险？

课程说"正态低估尾部风险"。但我们的数据恰好相反：

| 指标 | 正态假设 | EVT真实值 | EVT/正态 |
|:---|:---|:---|:---|
| 95% VaR | -7.69% | **-4.41%** | 0.57× |
| 99% VaR | -12.31% | **-4.48%** | 0.36× |
| 95% CVaR | -10.52% | -4.46% | 0.42× |
| 99% CVaR | -14.60% | -4.49% | 0.31× |

**EVT估计的极端亏损是正态假设的0.36倍**——正态分布反而高估了我们的下行风险。

原因是正偏态：正态假设认为左右对称，左侧应该和右侧一样长。但实际左侧很短，正态就在左侧"画了一条不存在的大尾巴"。

## 跳跃扩散模型是什么

### 标准模型 vs 跳跃扩散

金融建模有两种经典思路：

**纯扩散模型（Black-Scholes / 几何布朗运动）**：

$$dP = \mu \cdot dt + \sigma \cdot dW$$

- 价格变化 = 漂移（$\mu dt$）+ 连续波动（$\sigma dW$）
- 假设价格变化是**连续的**，每天都在小幅波动
- 无法解释突然暴跌/暴涨（比如一天跌10%）
- 分布是对称的正态 → 低估尾部风险

**跳跃扩散模型（Merton 1976）**：

$$dP = \mu \cdot dt + \sigma \cdot dW + J \cdot dN$$

在纯扩散基础上加了第三个分量 **$J \cdot dN$**——跳跃项：

| 符号 | 含义 | 通俗解释 |
|:---|:---|:---|
| $\mu \cdot dt$ | 漂移项 | 日常趋势，平均每月赚3% |
| $\sigma \cdot dW$ | 连续扩散项 | 日常波动，$dW$ 是布朗运动 |
| $J$ | 跳跃幅度 | 跳一次赚/亏多少，服从 $N(\mu_J, \sigma_J^2)$ |
| $dN$ | 跳跃计数 | Poisson 过程，$\lambda$ 是跳跃频率 |

### 直觉理解

把价格运动拆成两部分：

1. **"正常日子"**（$\mu dt + \sigma dW$）：每天都在小幅波动，像河流平稳流淌
2. **"跳跃日"**（$J \cdot dN$）：偶尔出现突变，像洪水决堤——可能暴涨也可能暴跌

跳跃频率 $\lambda = 0.14$ 意味着**约每7个月跳一次**，其余时间都是"正常波动"。

### 跳跃方向决定一切

这是对仓位管理的核心影响：

| 跳跃方向 | $\mu_J$ | 分布形状 | 仓位建议 |
|:---|:---|:---|:---|
| 向下（暴跌） | < 0 | 负偏态，左尾厚 | 降低仓位，保守 |
| 向上（暴涨） | > 0 | 正偏态，右尾长 | 可适度加杠杆 |

课程里默认跳跃为负（暴跌场景），所以结论是"降杠杆"。我们的 $\mu_J = +0.136$，跳跃方向为正——"奖金月"而不是"灾难月"。

### 与EVT的关系

跳跃扩散模型和 EVT 是互补的：

- **跳跃扩散**：从**机制**出发，解释"为什么会出现极端值"（因为跳跃）
- **EVT**：从**统计**出发，测量"极端值有多极端"（VaR/CVaR/尾部形状）

两者结合：跳跃扩散告诉你"有跳跃且方向为正"，EVT 告诉你"因为跳跃为正，左尾比正态假设短得多"。

## 跳跃检验：好的跳跃

跳跃扩散模型 `dP = μ·dt + σ·dW + J·dN` 中，J是跳跃幅度。

| 指标         | 值                 |
| :--------- | :---------------- |
| 跳跃频率 λ     | 0.14次/月（约每7个月跳一次） |
| 跳跃幅度均值 μ_J | **+0.136**（正！）    |
| 跳跃幅度波动 σ_J | 0.059             |

跳跃幅度均值为**正**——这些跳跃是暴涨，不是暴跌。

"好的跳跃"：偶尔一个月赚13%+，就像策略的"奖金月"。这进一步确认了正偏态特征。

课程里写"跳跃风险下最优仓位下降"，那是假设跳跃方向为负（暴跌）。我们的跳跃方向为正，仓位反而可以更激进。

## 正偏态的直觉解释

用一张图说清楚：

![正态 vs 正偏态](/tmp/positive_skew.png)

**正态分布**：左右对称钟形，均值=中位数。3%的月份亏5%，3%的月份赚5%，概率相等。

**正偏态（我们的策略）**：
- 大部分月份小幅盈利（2%~3%）
- 少数月份暴涨（10%~15%），右尾拉长
- 亏损月份很少且幅度小（-1%~3%），左尾截断

简单说：**亏得少，偶尔赚得多**。这是最理想的收益分布形态。

## 对课程笔记的修正

课程讲的是**一般金融市场的厚尾问题**——股票指数、商品期货确实偏左尾（暴跌多）。

但我们的5因子策略是**选股组合**，不是市场指数。选股逻辑天然过滤了最差的股票，所以：
- 持仓池已经排除了基本面恶化的公司
- 惊喜因子捕捉的是超预期公司（正跳跃来源）
- 组合收益的正偏态是策略设计的**结果**，不是巧合

**关键区别**：
| | 市场指数 | 5因子策略 |
|:---|:---|:---|
| 偏度 | 负偏态（暴跌多） | **正偏态（暴涨多）** |
| EVT VaR vs 正态 | 高估（更危险） | **低估（更安全）** |
| 跳跃方向 | 向下（坏跳跃） | **向上（好跳跃）** |
| 仓位建议 | 保守（降杠杆） | **可适度积极** |

## 还要注意什么

正偏态不代表没有风险：
1. **样本量太小**（31个月），一个真正的极端事件还没经历过
2. **Regime切换**：策略在危机期的表现未知（仅31月数据中28%标为危机）
3. **正偏态不等于无左尾**：只是左尾比正态短，不是没有左尾
4. **实盘约束还没验证**：涨停/跌停/滑点可能改变分布形状

## EVT 是什么（极值理论 Extreme Value Theory）

EVT 是专门研究**分布尾部极端事件**的统计框架。正常统计（均值、标准差）关注"中间"，EVT 关注"边缘"——那些罕见但影响巨大的事件。

### EVT 的三大工具

| 工具 | 含义 | 本笔记中的用法 |
|:---|:---|:---|
| **VaR** (Value at Risk) | "最坏情况下亏多少" — 给定置信水平下的最大亏损 | 99% VaR = 亏超过这个的概率只有1% |
| **CVaR** (Conditional VaR) | "如果真到了那1%，平均亏多少" — VaR 之外的平均损失 | 比 VaR 更保守，反映尾部厚度 |
| **GPD / GEV** | 拟合尾部分布的数学模型（广义 Pareto 分布 / 广义极值分布） | 用 GPD 拟合超过阈值的极端亏损，估计形状参数 ξ |

### EVT 的核心定理

**Fisher-Tippett-Gnedenko 定理**：不管原始分布是什么，超过阈值的极端值的分布都会收敛到三种标准形式之一（Gumbel / Fréchet / Weibull），可以用统一的 GEV 分布描述。

形状参数 ξ 决定尾部类型：

| ξ 值 | 尾部类型 | 含义 |
|:---|:---|:---|
| ξ < 0 | Weibull（短尾） | 尾部截断，极端事件有上限 |
| ξ = 0 | Gumbel（轻尾） | 类似正态/指数，尾部衰减快 |
| ξ > 0 | Fréchet（厚尾） | 尾部衰减慢，极端事件概率比正态高很多 |

### 为什么 EVT 重要

传统风险度量假设正态分布，但金融数据几乎都不是正态：

- **市场指数**：负偏态 + 厚尾 → 正态低估暴跌概率 → EVT 能捕捉到"比正态预测更极端的亏损"
- **我们的5因子策略**：正偏态 + 短左尾 → 正态**高估**暴跌概率 → EVT 反过来证明"比正态更安全"

**关键教训**：EVT 不是告诉你"一定更危险"，而是告诉你**真实尾部长什么样**——可能更危险，也可能更安全，取决于 ξ 和偏度方向。
