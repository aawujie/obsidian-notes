**几何平均收益率**（Geometric Average Return），也叫**复合平均收益率**或**几何年化收益率**，是衡量投资长期表现的最准确指标。它反映了资金在多个时期内**复利增长**的平均年化收益率。

### 定义与公式

对于一个有 \( n \) 个时期的投资收益率序列 \( r_1, r_2, \dots, r_n \)（每个 \( r_i \) 是小数形式，如 10% 写成 0.10），几何平均收益率 \( G \) 的计算公式为：

$[G = \left( (1 + r_1)(1 + r_2) \cdots (1 + r_n) \right)^{\frac{1}{n}} - 1]$

或者写成：

$[
1 + G = \sqrt[n]{\prod_{i=1}^{n} (1 + r_i)}
]$

### 示例计算

假设某基金连续3年收益率分别为：+20%、-10%、+30%。

- 第一年：1 + 0.20 = 1.20
- 第二年：1 - 0.10 = 0.90
- 第三年：1 + 0.30 = 1.30

连乘：1.20 × 0.90 × 1.30 = 1.404

开3次方根：$( \sqrt[3]{1.404} ≈ 1.1197)$

几何平均收益率：1.1197 - 1 = **11.97%**

### 与算术平均收益率的对比

同上数据，算术平均收益率 = (20% - 10% + 30%) / 3 = **13.33%**

为什么几何平均更低？因为负收益会“拖累”复利效果。算术平均高估了实际复合增长。

验证实际增长：初始100元 → 120 → 108 → 140.4元，总收益率40.4%，年化复合增长率正好是11.97%（而非13.33%）。

### 为什么量化中必须用几何平均？

- 它才是真正的**年化复合收益率**，能正确反映资金的长期增长速度。
- 算术平均只适用于单期预期收益率，或加权平均预期（例如组合预期）。
- 在业绩评价、基金比较、回测分析、风险调整指标（如夏普比率的年化时）都应使用几何平均。

### 常见变体

- **年化几何收益率**：如果时期不是整年（如月收益率），先算几何平均月收益率，再年化：$( G_{年} = (1 + G_{月})^{12} - 1 )$
- **连续复合收益率**：$(ln(1 + G))$，有时用于更高级模型。

总结：做量化分析、基金评价、长期投资决策时，**永远优先用几何平均收益率**，它才是“真实”的平均回报率。
