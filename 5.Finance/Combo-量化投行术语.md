# Combo：量化投行术语

> combo = combination，量化/投行常见缩写

## 含义

"组合"的口语化缩写。把多个因子、策略、信号混合在一起。

## 常见用法

| 用法 | 含义 |
|:---|:---|
| factor combo | 因子组合（多因子混合） |
| combo backtest | 组合回测（联合回测） |
| 80/20 combo | 80%A + 20%B 混合 |
| IC-weighted combo | 按IC加权组合 |
| equal-weight combo | 等权组合 |

## 我们项目中的实例

| 目录 | 含义 |
|:---|:---|
| `full_market_combo_validation` | 全市场因子组合验证（5因子等权） |
| `eight_factor_combo` | 8因子等权组合 |
| `block_combo` | 大宗交易因子 + 5因子混合 |
| `event_combo` | 龙虎榜 + 融资融券 + 北向三维共振 |
| `mixed_combo` | 基本面5因子 + 龙虎榜混合 |

## 笔记

投行quant文件和代码里到处可见，口语交流中也常用。"做个combo"=做个组合测试。
