## 二、问题起点：多项式乘法

### 2.1 任务定义

给定两个多项式 $A(x)$ 和 $B(x)$，求乘积 $C(x) = A(x) \times B(x)$。

### 2.2 系数表示法

最自然的表示方式：
$$A(x) = a_0 + a_1 x + a_2 x^2 + ... + a_d x^d$$
表示为列表：$[a_0, a_1, a_2, ..., a_d]$

**问题**：
- 两个 $d$ 次多项式相乘，结果为 $2d$ 次
- 使用分配律逐项相乘，复杂度 $O(d^2)$

---

## 三、第一个天才想法：值表示法

### 3.1 关键定理

> **定理**：任意 $d$ 次多项式可由 $d+1$ 个点唯一确定。

**直觉**：
- 2 个点 → 确定唯一的直线（1 次多项式）
- 3 个点 → 确定唯一的二次函数
- 4 个点 → 确定唯一的二次函数

### 3.2 为什么成立？

给定 $d+1$ 个点 $(x_0, y_0), ..., (x_d, y_d)$，满足：
$$a_0 + a_1 x_k + a_2 x_k^2 + ... + a_d x_k^d = y_k$$

写成矩阵形式：
$$\begin{bmatrix} 1 & x_0 & x_0^2 & ... \\ 1 & x_1 & x_1^2 & ... \\ ... \end{bmatrix} \begin{bmatrix} a_0 \\ a_1 \\ ... \end{bmatrix} = \begin{bmatrix} y_0 \\ y_1 \\ ... \end{bmatrix}$$

这个矩阵是 Vandermonde 矩阵，当各 $x_k$ 互不相等时**行列式非零**，矩阵可逆，故存在唯一解。

### 3.3 值表示法的乘法优势

用值表示法乘多项式：
- 选 $2d+1$ 个点
- 各点的值直接相乘
- 复杂度：$O(d)$！

**示例**：
$$A(x) = 2x + 1, \quad B(x) = 3x + 2$$
选 5 个点：$x = 0, 1, 2, 3, 4$

| x | A(x) | B(x) | C(x) = A(x) × B(x) |
|---|------|------|---------------------|
| 0 | 1 | 2 | 2 |
| 1 | 3 | 5 | 15 |
| 2 | 5 | 8 | 40 |
| ... | ... | ... | ... |

得到 C(x) 的值表示，再转换回系数表示即可。

## 五、第二个天才想法：正负配对点

### 5.1 朴素评估的瓶颈

评估 $d$ 次多项式在 $n$ 个点：
- 每个点需 $O(d)$ 次
- 总共 $O(nd) = O(d^2)$（因为 $n \approx d$）

### 5.2 特殊点的选择

考虑 $P(x) = x^2$（偶函数）：
- $P(1) = P(-1) = 1$
- $P(2) = P(-2) = 4$

**洞察**：选正负配对点，一次计算可得到两个值。

对于 $P(x) = x^3$（奇函数）：
- $P(-x) = -P(x)$
- 同样只需计算一半的点

### 5.3 一般多项式的分解

任意多项式 $P(x)$ 可分解为：
$$P(x) = P_e(x^2) + x \cdot P_o(x^2)$$

其中：
- $P_e$：偶次项组成的多项式
- $P_o$：奇次项组成的多项式（提取 $x$ 后）

**关键**：
- $P(x) = P_e(x^2) + x \cdot P_o(x^2)$
- $P(-x) = P_e(x^2) - x \cdot P_o(x^2)$

只需计算 $P_e(x^2)$ 和 $P_o(x^2)$，就能同时得到 $P(x)$ 和 $P(-x)$！

## 六、递归的问题

### 6.1 递归结构

假设评估 $n$ 次多项式在 $n$ 个点（正负配对）：
1. 分成 $P_e$ 和 $P_o$（各 $n/2$ 次）
2. 递归评估它们在 $n/2$ 个点
3. 组合结果得到 $n$ 个值

**复杂度**：$T(n) = 2T(n/2) + O(n) = O(n \log n)$

### 6.2 问题：正负配对的递归断裂

第一层：选正负配对点 $x_1, -x_1, x_2, -x_2$
第二层：需要评估 $P_e$ 和 $P_o$ 在 $x_1^2, x_2^2$

**问题**：$x_1^2$ 和 $x_2^2$ 都是正数，不再正负配对！

## 七、第三个天才想法：复数域扩展

### 7.1 核心洞察

> **唯一解法**：将初始点的选择扩展到**复数域**。

### 7.2 反向推理示例

需求：$n=4$ 个正负配对点 $x_1, -x_1, x_2, -x_2$

递归要求：
- 第二层需 $x_1^2$ 和 $x_2^2$ 正负配对
- 即 $x_2^2 = -x_1^2$

设 $x_1 = 1$，则 $x_2^2 = -1$ → $x_2 = i$（虚数单位）

**结果**：四个点是 $1, -1, i, -i$

### 7.3 更深层洞察

注意到：$x_1^4 = 1, x_2^4 = 1$

> 这四个点恰好是方程 $x^4 = 1$ 的解——**4 次单位根**。

## 八、单位根：完美的评估点

### 8.1 n 次单位根定义

方程 $x^n = 1$ 在复数域有 $n$ 个解，称为 **n 次单位根**。

几何表示：单位圆上均匀分布的 $n$ 个点。

### 8.2 欧拉公式表示

定义：
$$\omega = e^{2\pi i / n}$$

则 $n$ 次单位根为：
$$\omega^0, \omega^1, \omega^2, ..., \omega^{n-1}$$

其中：
$$\omega^k = e^{2\pi i k / n} = \cos\left(\frac{2\pi k}{n}\right) + i\sin\left(\frac{2\pi k}{n}\right)$$

### 8.3 两个关键性质

**性质 1：正负配对**
$$\omega^{k + n/2} = -\omega^k$$

（在单位圆上，相差半圈）

**性质 2：平方递减**
$$\{\omega^0, \omega^1, ..., \omega^{n-1}\}^2 = \{\omega_0^0, \omega_0^1, ..., \omega_0^{n/2-1}\}$$

其中 $\omega_0 = e^{2\pi i / (n/2)} = \omega^2$，即 $n$ 个单位根的平方恰好是 $n/2$ 个单位根！

## 九、FFT 算法

### 9.1 核心逻辑

```
输入：n 次多项式的系数表示（n 为 2 的幂）
输出：在 n 次单位根上的值表示

1. 基例：n=1 → 直接返回（常数多项式）
2. 分解：分成偶次项 P_e 和奇次项 P_o
3. 递归：FFT(P_e) 和 FFT(P_o) 在 n/2 次单位根上
4. 组合：
   y[k] = y_e[k] + ω^k · y_o[k]       (k < n/2)
   y[k+n/2] = y_e[k] - ω^k · y_o[k]   (k < n/2)
```

### 9.2 Python 实现

```python
import cmath

def fft(p):
    """
    快速傅里叶变换
    p: 多项式的系数表示 [a_0, a_1, ..., a_{n-1}]
    返回: 值表示 [P(ω^0), P(ω^1), ..., P(ω^{n-1})]
    """
    n = len(p)
    if n == 1:
        return p
    
    # 定义单位根
    omega = cmath.exp(2 * cmath.pi * complex(0, 1) / n)
    
    # 分成偶次和奇次项
    p_even = p[0::2]   # [a_0, a_2, a_4, ...]
    p_odd = p[1::2]    # [a_1, a_3, a_5, ...]
    
    # 递归调用
    y_e = fft(p_even)
    y_o = fft(p_odd)
    
    # 组合结果
    y = [0] * n
    for k in range(n // 2):
        # ω^k 的作用
        w = omega ** k
        y[k] = y_e[k] + w * y_o[k]
        y[k + n // 2] = y_e[k] - w * y_o[k]
    
    return y
```

## 十、第四个天才想法：逆 FFT

### 10.1 插值问题

从值表示回到系数表示，需要"逆"操作。

### 10.2 矩阵视角

评估可写成矩阵乘法：
$$\vec{y} = DFT \cdot \vec{a}$$

其中 DFT 矩阵：
$$\begin{bmatrix} 1 & 1 & 1 & ... \\ 1 & \omega & \omega^2 & ... \\ 1 & \omega^2 & \omega^4 & ... \\ ... \end{bmatrix}$$

插值即求逆：
$$\vec{a} = DFT^{-1} \cdot \vec{y}$$

### 10.3 惊人发现

$$DFT^{-1} = \frac{1}{n} \begin{bmatrix} 1 & 1 & 1 & ... \\ 1 & \omega^{-1} & \omega^{-2} & ... \\ 1 & \omega^{-2} & \omega^{-4} & ... \\ ... \end{bmatrix}$$

**洞察**：逆矩阵几乎和原矩阵一样，只是：
1. $\omega$ 改为 $\omega^{-1}$
2. 乘以 $\frac{1}{n}$

### 10.4 逆 FFT 实现

```python
def ifft(y):
    """
    逆快速傅里叶变换
    y: 值表示
    返回: 系数表示
    """
    n = len(y)
    if n == 1:
        return y
    
    # 关键：ω 改为 ω^(-1)
    omega = cmath.exp(-2 * cmath.pi * complex(0, 1) / n)
    
    # 分成偶次和奇次项的值表示
    y_even = y[0::2]
    y_odd = y[1::2]
    
    # 递归调用
    a_e = ifft(y_even)
    a_o = ifft(y_odd)
    
    # 组合结果
    a = [0] * n
    for k in range(n // 2):
        w = omega ** k
        a[k] = a_e[k] + w * a_o[k]
        a[k + n // 2] = a_e[k] - w * a_o[k]
    
    # 最后乘以 1/n
    return [x / n for x in a]
```

## 十一、完整的多项式乘法算法

```python
def multiply_polynomials(A, B):
    """
    使用 FFT 进行多项式乘法
    A, B: 系数表示
    返回: A × B 的系数表示
    """
    # 补零到足够长度（乘积次数 + 1，且为 2 的幂）
    n = 1
    while n < len(A) + len(B):
        n *= 2
    A_pad = A + [0] * (n - len(A))
    B_pad = B + [0] * (n - len(B))
    
    # FFT 转换到值表示
    A_val = fft(A_pad)
    B_val = fft(B_pad)
    
    # 值表示下相乘
    C_val = [a * b for a, b in zip(A_val, B_val)]
    
    # IFFT 转回系数表示
    C = ifft(C_val)
    
    # 取实部，去掉多余的零
    result = [c.real for c in C[:len(A) + len(B) - 1]]
    return result
```

## 十六、常见问题

### Q1: 为什么 n 必须是 2 的幂？

简化版 FFT 要求递归时每层正好分成两半。非 2 的幂需用更复杂的算法（如 Bluestein 算法）。

### Q2: ω 是什么？

$\omega = e^{2\pi i / n}$ 是一个复数，角度为 $2\pi/n$，模为 1。它在单位圆上，逆时针旋转 $n$ 次回到起点。

### Q3: 实际多项式系数是实数，为什么输出是复数？

FFT 输出是复数，但逆 FFT 后恢复实数（虚部理论上为 0）。

### Q4: 和传统傅里叶变换的关系？

FFT 是离散傅里叶变换（DFT）的高效算法。视频从多项式视角切入，避开了信号处理背景知识。
