## 一、项目概述

**awesome-math** 是一个精心整理的数学学习资源清单，涵盖从基础入门到高级研究的各个数学分支。所有资源均为免费（付费资源用 💲 标注）。

**项目特点**：
- 覆盖面广：从初等数学到前沿研究
- 资源类型多样：书籍、视频、在线课程、工具、论文
- 兼顾理论与实践：既有严谨教材，也有直观可视化
- 适合自学者：大量免费高质量资源

### 2.3 数学分支详解

#### 基础数学（Foundations）

**关键领域**：
- **证明入门** — Book of Proof、How to Prove It
- **集合论** — Sets, Relations, Functions
- **逻辑学** — Introduction to Logic、Mathematical Logic
- **范畴论** — Category Theory in Context、Seven Sketches in Compositionality
- **类型论** — Proofs and Types、Homotopy Type Theory

> **适合人群**：想从计算转向纯数学的学习者，需要先掌握证明方法。

---

#### 代数（Algebra）

**子领域**：
| 领域 | 推荐资源 |
|------|---------|
| **线性代数** | Linear Algebra Done Right、Immersive Linear Algebra、Interactive Linear Algebra |
| **抽象代数** | Abstract Algebra: Theory and Applications |
| **群论** | Notes on Group Theory |
| **伽罗瓦理论** | Galois Theory (Ian Stewart) |
| **李代数** | Lie Algebras (Shlomo Sternberg) |

**线性代数重点推荐**：
- **Linear Algebra Done Right**（Axler）— 跳过行列式，从向量空间切入
- **Immersive Linear Algebra** — 交互式可视化，网页版
- **Linear Algebra Done Wrong**（Treil）— 传统路线，行列式先行

## 五、使用建议

### 5.1 学习策略

1. **先看视频建立直觉** → 3Blue1Brown、StatQuest
2. **再用教材严谨理解** → 对应领域经典教材
3. **动手练习验证** → Desmos、GeoGebra、Sympy
4. **遇到问题提问** → Mathematics Stack Exchange

### 5.2 资源选择原则

- **入门阶段**：选择有可视化、交互式的资源
- **进阶阶段**：选择有严谨证明的经典教材
- **应用阶段**：结合编程实践（Python + Sympy/Sagemath）

### 5.3 注意事项

- 💲 标注的资源为付费（如 Princeton Companion to Mathematics）
- 教材版本差异：不同教材切入点不同，选择适合自己的风格
- 先打好证明基础再进入纯数学

## 七、总结

**awesome-math 的价值**：
1. **一站式索引** — 不需要到处找资源，一个清单覆盖全领域
2. **免费为主** — 大量高质量免费资源，适合自学者
3. **分层推荐** — 从入门到进阶都有对应资源
4. **持续更新** — GitHub 项目，社区维护

**不足**：
- 清单形式，没有学习路径设计
- 需要自己筛选适合的资源
- 中文资源较少（以英文为主）
