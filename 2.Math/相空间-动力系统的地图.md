# 相空间——动力系统的地图

> 相空间是动力系统理论中最强大的可视化工具。它把时间的流逝压缩成几何，让你只看一张图就能理解系统所有的可能行为。

---

## 一、什么是相空间

### 1.1 换一种眼光

传统上我们这样看数据：

```
时间 → 横轴
变量 → 纵轴
曲线 → 变量如何随时间改变
```

相空间换了一个维度：

```
变量1 → 横轴
变量2 → 纵轴
...
变量n → 第n轴
曲线 → 系统状态如何演化
```

**时间消失了。** 它变成了推动点沿着轨迹运动的隐形力量。

### 1.2 形式定义

$$
\text{相空间} = \{ (x_1, x_2, \ldots, x_n) \mid x_i \in \mathbb{R} \}
$$

其中 $x_i$ 是系统的第 $i$ 个状态变量。空间的维数等于状态变量的个数。

> **核心思想**：相空间中的**每一个点**完整描述了系统在某一瞬时的全部状态。

### 1.3 从 1D 到 nD

| 维数 | 系统 | 相空间 | 可视化 |
|:---|:---|:---|:---:|
| 1D | 细菌种群 | 一条数轴 | 线上的点 |
| 2D | 单摆 | 角度 × 角速度 | 平面 |
| 2D | 捕食者-猎物 | 兔子 × 狐狸 | 平面 |
| 3D | Lorenz 系统 | $(x, y, z)$ | 3D 空间 |
| 4D+ | 神经元完整模型 | 膜电位 + 多离子通道 | 不可视，靠投影/降维 |

## 二、相空间的核心元素

### 2.1 轨迹

系统从一个初始状态出发，沿微分方程规定的方向运动，在相空间中画出一条曲线——这就是**轨迹**（trajectory / orbit）。

$$
\text{初始条件} \;(x_0, y_0) \quad\Longrightarrow\quad \text{轨迹} \; (x(t), y(t))
$$

**关键性质**：
- 轨迹不能相交（同一个状态不能同时走向两个不同方向，确定性系统）
- 轨迹可以无限逼近一点（平衡点），也可以形成闭合回路（极限环）

### 2.2 向量场

相空间中每个点 $(x, y, \ldots)$ 都有一个对应的速度向量：

$$
\vec{v}(x, y) = \left(\frac{dx}{dt},\; \frac{dy}{dt}\right)
$$

```
                        ↑
                     ／  ｜  ＼
                   ／    ｜    ＼
    狐狸 y        ／     ｜     ＼
                ↖       ｜       ↗
              ←  (x,y)  ｜  (x,y)  →
                ↙       ｜       ↘
                   ＼    ｜    ／
                     ＼  ｜  ／
                        ↓
                   —————————————→ 兔子 x
```

画出大量点的向量 = **向量场**。它告诉你站在任意一点，下一步该往哪走。

### 2.3 相图

> **相图 = 向量场 + 典型轨迹**

一张好的相图能让你**一眼看穿系统的全部命运**——不必求解，不必计算，跟着箭头走就行。

## 三、相空间里的特殊结构

### 3.1 平衡点（不动点）

定义：$\frac{dx}{dt} = \frac{dy}{dt} = \cdots = 0$ 的点。

在相图上它是箭头缩成零的地方——**进入就永远出不来**。

| 类型 | 相图特征 | 含义 | 例子 |
|:---|:---|:---|:---|
| **稳定结点** | 周围箭头指向它 | 所有扰动都会恢复 | 阻尼摆的静止位置 |
| **不稳定结点** | 周围箭头背离它 | 任何扰动都会跑远 | 倒立摆的顶点 |
| **鞍点** | 有些方向吸、有些方向推 | 沿特定方向稳定，其余不稳定 | 山顶隘口 |
| **稳定焦点** | 螺旋转进去 | 有阻尼的振荡衰减 | 欠阻尼摆 |
| **不稳定焦点** | 螺旋转出来 | 振荡越来越大 | 颤振系统 |
| **中心** | 完全闭合的椭圆 | 无摩擦、永不衰减 | 理想单摆 |

### 3.2 极限环

**孤立闭合轨道**——不是无限多环中的一个，而是唯一的、稳定的环。

#### 为什么极限环如此重要

在 Lotka-Volterra 最简单的版本里，轨迹围绕平衡点形成无限多个闭合环，每个初始条件对应一个环。这些**不是**极限环——它们没有稳定性结构。

真正的极限环有两个关键特征：

1. **孤立**——周围没有其他闭合轨迹
2. **稳定/不稳定**——微扰后要么被拉回去，要么被推开

#### 稳定的极限环

```
      ⋱  ·
    ·      ·
   ·    →   ·
   ·  ↻   ↻ ·
   ·    ←   ·
    ·      ·
      ·  ⋰
        *平衡点
```

- 环外点 → 螺旋缩进去
- 环内点 → 螺旋胀出来
- **都收敛到同一个环**

#### 这就是神经元的发放

| 概念 | 神经元对应 |
|:---|:---|
| 稳定极限环 | **周期发放（tonic spiking）** |
| 环的周期 | 发放频率 |
| 环的振幅 | 动作电位幅度 |
| 平衡点 | 静息电位 |
| 从平衡点到极限环的跃迁 | **阈下→阈上发放** |

> 神经元的动作电位不是"算出"来的——是动力系统从平衡点被推入极限环的结果。

### 3.3 吸引子

吸引子是相空间中的一个集合，周围所有的轨迹都被拉向它。

| 吸引子类型 | 几何 | 行为 | 例子 |
|:---|:---|:---|:---|
| **不动点** | 点 | 稳态 | 静息电位、市场均衡 |
| **极限环** | 环 | 周期振荡 | 心跳、发放、经济周期 |
| **环面** | 甜甜圈 | 准周期（多频叠加） | 双频率耦合 |
| **奇异吸引子** | 分形 | 混沌 | Lorenz 系统、市场波动 |

> 对于极限环和混沌吸引子：你不必知道初始条件——你只需要知道吸引子的形状。系统的长期行为**由吸引子决定，不由初始条件决定**。

## 四、控制参数与分岔

把模型参数当作**可调的旋钮**：

$$
\frac{dx}{dt} = f(x, y; \; \alpha, \beta, \ldots)
$$

改变参数就是改变相图本身——平衡点会移动、消失，极限环会出生、死亡。相图的拓扑结构发生质变的点叫**分岔**。

> 一个分岔参数可以决定系统是安静（平衡点）还是爆发放电（极限环）。生物系统中这是适应性的基础。

---

## 五、为什么相空间比解公式更强大

| | 求解公式 | 相空间分析 |
|:---|:---|:---|
| 需要 | 解析解 | 微分方程本身 |
| 可行性 | 极少数方程 | **几乎所有方程** |
| 信息 | 精确数值 | 定性行为 + 精确数值 |
| 洞察 | "在 t=5 时 x=3.2" | "系统永远振荡 / 收敛 / 发散" |
| 参数变化 | 重新求解 | 看相图怎么变形 |
| 多初始条件 | 逐个算 | 所有初始条件一张图 |

> 你可以不懂微分方程求解，但你看得懂相图。

## 六、相空间与量化金融

### 6.1 市场状态作为相空间

| 状态变量 | 含义 |
|:---|:---|
| 价格 | $p$ |
| 动量/趋势 | $\dot{p}$ 或移动平均差 |
| 波动率 | $\sigma$（隐含或历史） |
| 价差 | spread |
| 成交量 | volume |

一个 $n$ 维相空间中的每个点 = 一个完整的市场状态快照。

### 6.2 市场体制 = 吸引子

不同市场体制对应相空间中不同吸引子：

| 市场体制 | 相空间表现 |
|:---|:---|
| **趋势市** | 轨迹沿某个方向持续漂移 |
| **震荡市** | 围绕某个平衡区域的准周期运动 |
| **均值回复** | 稳定平衡点的吸引 |
| **崩盘/跳跃** | 轨迹被推向相空间远处 → 可能掉入另一个吸引子 |
| **波动率体制切换** | 分岔——参数 $\sigma$ 跃迁 |

### 6.3 从动力系统到统计推断

HMM（隐马尔可夫模型）在量化中的本质：

> 我们观察价格，猜测它在相空间中的哪个区域（哪个吸引子附近）。

这正是 [HMM 市场状态识别与因子择时](HMM市场状态识别与因子择时.md) 中讨论的核心思想。

### 6.4 随机扰动下的相空间

真实市场有噪声。相空间不再是确定性的光滑向量场：

$$
dx = \mu(x)\;dt + \sigma(x)\;dW_t
$$

变成了**随机微分方程**。相空间中每个点不只是有一个方向，而是有一个**概率分布**。轨迹变成了随机游走——但**吸引子结构仍然存在**。

> 即使在噪声中，系统仍然倾向于围绕吸引子运动。噪声决定了你多快抵达、多快逃逸，但**吸引子决定了你去哪**。

## 七、核心总结

| 概念 | 一句话 |
|:---|:---|
| **相空间** | 以所有状态变量为轴的高维空间，每个点 = 瞬间完整状态 |
| **轨迹** | 系统的演化路径，由微分方程决定 |
| **向量场** | 相空间中每个点的前进方向 |
| **相图** | 向量场 + 关键轨迹 = 系统全部命运的视觉总结 |
| **平衡点** | 系统永远的安息地 |
| **极限环** | 系统永远跳不出的闭环——振荡的几何本相 |
| **吸引子** | 系统最终被拉向的集合，定义长期行为 |
| **分岔** | 参数变化导致相图拓扑结构质变——新行为诞生 |

### 最重要的三件事

1. **相图不求解方程，却能告诉你一切**——因为动力学只为向量场负责
2. **极限环不是预先写好的，是涌现的**——两个简单交互规则就足够产生产生永久振荡
3. **你不需要知道初始条件就能预测长期行为**——只要知道吸引子是谁
