# 微分方程——变化的语言

> Artem Kirsanov · 23分钟 · 动力系统理论入门第一讲
>
> 核心论题：动力系统理论的核心概念（微分方程、平衡点、相图、极限环）不仅不需要数学公式就能理解，更是理解神经元计算的钥匙。

## 一、引言：神经元不是静态机器

神经元不是简单的输入→输出设备，而是**精密的时间计算机**——它对输入的反应不仅取决于当前输入，还取决于 1 毫秒前、1 秒前、甚至几分钟前它处于什么状态。

这种时间上的复杂性，正是大脑能产生如此丰富思维和行为的关键。

描述这类现象的数学分支叫**动力系统理论**（Dynamical Systems Theory），它的语言是微分方程。但大多数直觉不需要公式，看图就够了。

## 二、动力系统基础

### 2.1 状态变量

动力系统理论研究**事物如何随时间变化**。关键是用**状态变量**描述系统在任意时刻的状态。

| 系统 | 状态变量 | 数量 |
|:---|:---|:---:|
| 空间中运动的球 | 位置 (x, y, z) + 速度分量 | 6 |
| 单摆 | 偏离角度 + 角速度 | 2 |
| 细菌种群 | 细菌数量 n | 1 |
| 捕食者-猎物 | 兔子数量 x + 狐狸数量 y | 2 |
| 神经元 | 膜电位 + 离子通道状态 | 多个 |

> 选择哪些变量、丢弃哪些，本质上是**建模的艺术**。所有模型都是对真实世界某一侧面的抽象。

### 2.2 微分方程

$$
\frac{dn}{dt} = k \cdot n
$$

- $dn$：数量的微小变化
- $dt$：时间的微小步长
- 导数 $\frac{dn}{dt}$ **关联了数量与其变化率**

**几何意义**：在 $n$ 随时间变化的图上，导数等于该点切线的斜率。

## 三、数值方法：从无限到有限

### 3.1 为什么要用数值方法

对于 $\frac{dn}{dt} = kn$（指数增长），有解析解 $n(t) = n_0 e^{kt}$，一步到位。

但大多数微分方程——包括神经元动力学方程——**没有解析解**。数值方法可以求解几乎任何微分方程。

### 3.2 有限步长法

| | 连续 | 离散 |
|:---|:---|:---|
| 符号 | $d$ | $\Delta$ |
| 含义 | 无限小 | 有限、可度量 |
| 操作 | 微积分 | 多次乘法+加法 |

**核心思想**：把曲线放大到足够近，它看起来就是一条直线。

**步骤**：

1. 初始状态 → 计算当前变化率
2. $\Delta t$ 时间后 → $n_{\text{new}} = n_{\text{old}} + \frac{dn}{dt} \cdot \Delta t$
3. 用新的 $n$ 重新计算 $\frac{dn}{dt}$
4. 重复

### 3.3 解析解 vs 数值解

| | 解析解 | 数值解 |
|:---|:---|:---|
| 公式 | 有显式公式 | 无显式公式 |
| 跳转 | 可一步到任意时刻 | 必须逐步迭代 |
| 计算量 | O(1) | O(目标时刻/步长) |
| 适用范围 | 少数特殊方程 | **几乎所有方程** |
| 精度 | 精确 | 受步长限制 |

**精度-代价权衡**：步长越小→越精确→越费算力。

### 3.4 参数估计

现实中参数 $k$ 未知，需要从数据中拟合。这也是有限精度过程，不可避免有误差。

## 四、几何直觉：捕食者-猎物模型

### 4.1 耦合微分方程

当我们有多个状态变量且每个变化率依赖所有其他变量时，进入**耦合微分方程**。

**Lotka-Volterra 模型**：

$$
\begin{aligned}
\frac{dx}{dt} &= ax - bxy \quad &\text{(兔子)}\\[4pt]
\frac{dy}{dt} &= cxy - dy \quad &\text{(狐狸)}
\end{aligned}
$$

| 项 | 含义 |
|:---|:---|
| $ax$ | 兔子自然增长（正比于数量） |
| $-bxy$ | 兔子被吃（正比于相遇概率 $x \cdot y$） |
| $cxy$ | 狐狸从猎物获取能量转化为繁殖 |
| $-dy$ | 狐狸自然死亡 |

### 4.2 相空间

不再用横轴=时间、纵轴=数量的传统画法。而是：

> **横轴 = 兔子数量 $x$，纵轴 = 狐狸数量 $y$** — 没有时间轴！

平面上每个点代表系统的**一个状态**。时间是推动状态沿轨迹运动的驱动力。

### 4.3 向量场与相图

每个状态点 $(x, y)$ 都有两个对应的瞬时变化率——可以用**向量**表示：

- 水平分量 = $\frac{dx}{dt}$
- 垂直分量 = $\frac{dy}{dt}$

画出大量点的向量 → **向量场**。向量场 + 轨迹 = **相图**。

> 有了相图，不需要精确计算，跟着箭头走就能获得系统行为的定性直觉。

### 4.4 平衡点

平衡点 = 两个导数同时为零的点。令右侧等于零：

$$
\begin{cases}
ax - bxy = 0 \\
cxy - dy = 0
\end{cases}
$$

解得两个平衡点：

| 平衡点 | 含义 | 稳定性 |
|:---|:---|:---|
| $(0, 0)$ | 两个种群都灭绝 | ❌ 不稳定（稍有兔子就指数增长） |
| $(d/c,\; a/b)$ | 捕食者与猎物平衡共存 | 周围形成极限环 |

在相图上，平衡点是所有箭头缩为零的点——进去了就永远出不来。

### 4.5 极限环

从非零平衡点附近出发，轨迹会形成**闭合循环**——种群围绕平衡点永不停息地振荡。

**关键洞察**：方程中没有任何三角函数、没有显式振荡——极限环是从两个变量简单的交互规则中**涌现**出来的。

- 不同初始条件对应**无限多个**不同大小的环
- 改变参数 $a,b,c,d$ 只改变平衡点位置和环的形状，不改变系统的根本行为
- 加入兔子食物上限后，系统从无限多环变为**唯一稳定平衡点**——所有轨迹收敛到它

## 五、通向神经元

| 概念 | 捕食者-猎物 | 神经元 |
|:---|:---|:---|
| 状态变量 | 兔子、狐狸数量 | 膜电位、离子通道状态 |
| 相互作用 | 捕食 | 离子电流 |
| 平衡点 | $(d/c, a/b)$ | 静息电位 |
| 极限环 | 种群振荡 | **发放（spiking）** |

> 神经元发放的本质，就是动力系统中的极限环——同样的数学框架，同样的几何直觉。

## 核心概念总结

| 概念 | 一句话 |
|:---|:---|
| **动力系统** | 研究事物如何随时间变化的数学框架 |
| **状态变量** | 完全确定系统状态的实数集合 |
| **微分方程** | 关联量值与其变化率的方程（$\dot{x} = f(x)$） |
| **数值求解** | 用有限步长 $\Delta t$ 逐步迭代近似（核心方法） |
| **相空间** | 以状态变量为轴的空间，每个点是系统的一个状态 |
| **向量场** | 每个点上的变化方向箭头 |
| **相图** | 向量场 + 轨迹的完整可视化 |
| **平衡点** | 所有导数=0，一去不回的特殊点 |
| **稳定性** | 微扰后是回归还是逃逸 |
| **极限环** | 从简单规则中涌现的闭合振荡——神经发放的数学本质 |

---

## 关键洞察

1. **微分方程不神秘**——就是 $\text{变化率} = f(\text{当前状态})$，用 d 或 $\dot{x}$ 表示
2. **数值方法是王道**——绝大多数真实世界的微分方程没有解析解，但数值方法全都能解
3. **相图比公式更有洞察力**——定性理解系统行为的利器，不需要精确计算
4. **极限环是涌现现象**——方程里没写振荡，但系统的交互规则自动产生了振荡
5. **神经元就是动力系统**——同样的数学框架，下一级从细胞生物物理入手
