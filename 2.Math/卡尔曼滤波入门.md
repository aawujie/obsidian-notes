# 卡尔曼滤波入门

> 从贝叶斯更新的视角理解卡尔曼滤波——递归最优状态估计

---

## 一、问题定义

假设一个系统，真实状态 x 你观测不到，只能看到带噪声的传感器读数 z。

你有两个信息源：

| 源 | 内容 | 问题 |
|:---|:---|:---|
| 物理模型 | 根据上一步状态推算当前位置 | 模型不完美，预测有误差 |
| 传感器 | GPS/IMU/编码器等实测 | 传感器有噪声、有漂移 |

**如何把两者融合，得到最优估计？**

---

## 二、直觉：贝叶斯更新

```
P(状态 | 新数据) ∝ P(新数据 | 状态) × P(状态 | 历史)
   后验          ≈   似然      ×    先验
```

- **先验** = 上一步 Kalman 输出的状态分布（均值和协方差）
- **似然** = 传感器读数的可信度（测量噪声协方差）
- **后验** = 融合后的新状态估计

每一步都是贝叶斯更新。关键是**递归**——后验变成下一步的先验，循环往复。

---

## 三、核心公式

### 状态空间模型

```
状态方程：x_k = F·x_{k-1} + B·u_k + w_k    (w ~ N(0, Q))
观测方程：z_k = H·x_k + v_k                (v ~ N(0, R))
```

- `F`：状态转移矩阵（比如位置积分：p' = p + v·dt）
- `H`：观测矩阵（从状态空间映射到观测空间）
- `Q`：过程噪声协方差（模型不确定性）
- `R`：测量噪声协方差（传感器不确定性）

### 两步循环

**Predict（预测）：**
```
x̂_k|k-1 = F·x̂_{k-1}      ← 用物理模型推算
P_k|k-1 = F·P_{k-1}·Fᵀ + Q  ← 同时放大不确定性（模型有误差）
```

**Update（校正）：**
```
K = P·Hᵀ·(H·P·Hᵀ + R)⁻¹   ← 卡尔曼增益：谁更可靠？
x̂ = x̂ + K·(z − H·x̂)       ← 用传感器修正预测
P = (I − K·H)·P           ← 缩小不确定性（获得了新信息）
```

---

## 四、卡尔曼增益 K 的直觉

```
K ≈ 模型不确定性 / (模型不确定性 + 传感器噪声)
```

| 情况 | K 值 | 行为 |
|:---|:---|:---|
| 传感器很准（R 小） | → 1 | 几乎直接信传感器 |
| 模型很准（Q 小） | → 0 | 几乎忽略传感器 |
| 两者相当的 | 0.3-0.7 | 加权平均 |

**这就是卡尔曼的正则化**：你不需要手动决定"信数据还是信模型"，K 自动算最优权重。

---

## 五、为什么是"最小均方误差最优"

在三个假设下，Kalman 是**理论上最优的无偏估计器**：

1. 系统是线性的
2. 噪声是高斯分布的
3. 噪声均值为零

满足以上条件时，Kalman 给出的估计在所有线性估计器中均方误差最小（BLUE: Best Linear Unbiased Estimator）。

如果不满足线性假设 → 用 EKF 或 UKF。
如果不满足高斯假设 → 用粒子滤波。

---

## 六、协方差矩阵 P 的故事

P 不是废品——它告诉你在**每个维度上的不确定性有多大**。

```
初始：P 很大（你什么都不知道）
↓ 每次 Predict：P 变大（模型推远了，越推越不确定）
↓ 每次 Update：P 缩小（传感器纠正了）
↓ 稳定后：P → 常数（达到稳态，不确定性不再缩小）
```

如果 P 一直在缩小 → 滤波器收敛，效果好。
如果 P 在发散 → 模型或传感器有问题，需要排查。

---

## 七、为什么递归

你不存历史数据，只需要存**上一步的 x̂ 和 P**。

每一步：
```
(x̂_{k-1}, P_{k-1}) + 新数据 z_k → (x̂_k, P_k)
```

内存 O(1)，计算 O(n³)（矩阵求逆），实时可行。

---

## 八、局限性

| 问题 | 影响 | 解法 |
|:---|:---|:---|
| 非线性系统 | 估计偏差 | EKF / UKF |
| 非高斯噪声（厚尾、跳跃） | 低估风险 | 粒子滤波 |
| Q / R 未知或时变 | P 收敛到错误值 | 自适应 Kalman |
| 模型严重错误 | 发散 | 模型检验 + 重置机制 |
