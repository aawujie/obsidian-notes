# 各种"积"在深度学习中的应用

---

## 先认识所有的积

| 名称 | 符号 | 输入 → 输出 | 一句话 |
|------|------|------------|-------|
| 点积 / 内积 | $a \cdot b$ | 向量 × 向量 → 标量 | 衡量两个向量有多"像" |
| 外积 | $a \otimes b$ | 向量 × 向量 → 矩阵 | 把两个向量"展开"成一张表 |
| 叉积 | $a \times b$ | 向量 × 向量 → 向量 | 求垂直于两者的新向量（3D 图形学用，深度学习几乎不用） |
| 哈达玛积 | $A \odot B$ | 矩阵 × 矩阵 → 矩阵 | 逐元素相乘，形状不变 |
| 矩阵积 | $AB$ | 矩阵 × 矩阵 → 矩阵 | 前向传播的核心运算 |
| 卷积 | $f * g$ | 矩阵 × 核 → 矩阵 | 滑动窗口提取局部特征 |
| 克罗内克积 | $A \otimes B$ | 矩阵 × 矩阵 → 大矩阵 | 量子计算、K-FAC 优化器（进阶用途） |

深度学习日常用到的主要是三个：**点积、哈达玛积、卷积**。

---

## 一、点积 —— 衡量相似度

### 计算方式

两个向量逐位相乘，然后求和：

$$a \cdot b = \sum_i a_i b_i = a_1 b_1 + a_2 b_2 + \cdots$$

几何上等价于：

$$a \cdot b = \|a\| \|b\| \cos\theta$$

- $\theta = 0°$（方向完全一致）→ 点积最大
- $\theta = 90°$（互相垂直）→ 点积 = 0
- $\theta = 180°$（方向相反）→ 点积最小（负数）

**结论**：点积越大，两个向量越"像"。

### 在深度学习里用在哪

**1. Transformer 注意力分数**

$$\text{score}(Q, K) = QK^T$$

每一行 $q_i$ 和每一列 $k_j$ 做点积，得到 token $i$ 对 token $j$ 的"关注程度"。点积越大，注意力权重越高。

```python
# Q: (seq_len, d_k)   K: (seq_len, d_k)
scores = Q @ K.T   # (seq_len, seq_len)，每对 token 的相似度
```

**2. 词向量相似度**

```python
import torch
import torch.nn.functional as F

king   = model["king"]
queen  = model["queen"]

# 余弦相似度 = 点积 / (范数之积)
sim = F.cosine_similarity(king, queen, dim=0)
```

**3. 全连接层（线性层）**

$$h = Wx$$

矩阵乘法的每一行，本质上就是权重向量和输入向量的点积：

$$h_i = w_i \cdot x$$

## 二、哈达玛积 —— 逐元素控制

### 计算方式

两个**形状相同**的矩阵，对应位置相乘：

$$C_{ij} = A_{ij} \times B_{ij}$$

```
A = [1, 2, 3]      B = [4, 5, 6]
A ⊙ B = [1×4, 2×5, 3×6] = [4, 10, 18]
```

和矩阵乘法不同，形状不变，每个位置只和对应位置交互。

### 在深度学习里用在哪

**1. LSTM / GRU 的门控机制**

LSTM 用三个"门"来控制信息流，每个门都是哈达玛积：

$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$$

- $f_t$（遗忘门）：逐元素决定旧记忆保留多少
- $i_t$（输入门）：逐元素决定新信息写入多少
- 每个元素独立控制，不互相干扰

**2. 注意力 Mask**

把不应该被注意到的位置乘以 0（或加上 $-\infty$）：

```python
# mask: 1 保留，0 屏蔽
scores = scores * mask   # 哈达玛积，屏蔽 padding 位置
```

**3. Dropout**

随机把一部分神经元置零，就是哈达玛积：

```python
mask = (torch.rand_like(x) > p).float()
x = x * mask   # 哈达玛积，随机关闭神经元
```

**4. 特征融合（各种门控网络）**

用一个学到的"权重图"逐元素调节特征图的强度：

```python
gate = torch.sigmoid(linear(x))   # 每个位置的权重，0~1
out  = gate * value                # 哈达玛积，按位置增强或抑制
```

## 三、卷积 —— 滑动窗口提取特征

### 计算方式

用一个小矩阵（卷积核 / filter）在输入上滑动，每个位置做点积，输出一个数：

```
输入图像（5×5）      卷积核（3×3）
┌─────────────┐    ┌─────────┐
│ 1  2  3  0  1│   │ 1  0 -1│
│ 4  5  6  0  1│ × │ 1  0 -1│  →  每个窗口位置得到一个数
│ 7  8  9  0  1│   │ 1  0 -1│
│ ...         │    └─────────┘
└─────────────┘
        ↓
   输出特征图（3×3）
```

本质：在每个局部窗口做一次点积，扫描整张图。

### 和矩阵乘法的区别

| | 矩阵乘法（全连接） | 卷积 |
|--|----------------|------|
| 参数共享 | 否，每个位置用不同权重 | 是，同一个核扫全图 |
| 局部连接 | 否，每个输出看全部输入 | 是，每个输出只看局部窗口 |
| 参数量 | 大 | 极小 |
| 适合的数据 | 无结构数据 | 有空间结构的数据（图像、音频） |

### 在深度学习里用在哪

**1. CNN 图像识别**

```python
import torch.nn as nn

conv = nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3, padding=1)
# 64 个不同的 3×3 核，每个核检测一种局部模式（边缘、纹理、颜色…）
```

每一层卷积提取不同层次的特征：
- 浅层：边缘、颜色
- 中层：纹理、形状
- 深层：物体部件、语义

**2. 1D 卷积处理序列**

```python
conv1d = nn.Conv1d(in_channels=256, out_channels=256, kernel_size=3)
# 在序列上滑动，捕捉局部 n-gram 模式
```

**3. 深度可分离卷积（MobileNet）**

把标准卷积拆成两步，大幅减少计算量：
- 深度卷积：每个通道单独卷积（哈达玛积思想）
- 逐点卷积：$1\times1$ 卷积混合通道（矩阵积思想）

---

## 三种积对比

| | 点积 | 哈达玛积 | 卷积 |
|--|------|---------|------|
| 输入形状 | 两个向量 | 两个相同形状的矩阵 | 矩阵 + 小核 |
| 输出 | 一个标量 | 相同形状矩阵 | 特征图 |
| 核心作用 | 衡量相似度 | 逐位置独立控制 | 提取局部模式 |
| 典型应用 | 注意力分数 | 门控、Dropout | CNN、音频处理 |

## 记忆口诀

> **点积问相似**（两向量有多像）
> **哈达玛管门**（每个位置开多大）
> **卷积找局部**（小窗口扫全图）
