## 一、向量与矩阵：数据的载体

### 数据即向量

神经网络处理的所有东西，本质上都是数字列表（向量）或数字表格（矩阵）：

| 数据类型 | 线性代数表示 |
|---------|------------|
| 一张灰度图（28×28） | 784 维向量，或 28×28 矩阵 |
| 一段文字（100 个 token） | 100×768 的矩阵（每个 token 是 768 维向量） |
| 一个 batch（32 张图）| 32×784 的矩阵 |
| 彩色图片（224×224×3） | 三阶张量 |

### 权重即矩阵

每一层神经网络的参数就是一个矩阵：

```
输入层（784 维）  →  隐藏层（256 维）
权重矩阵 W 的形状：784 × 256
偏置向量 b 的形状：256 维
```

整个网络 = 一堆矩阵堆叠在一起。

---

## 二、矩阵乘法：前向传播的核心

### 一层神经网络 = 一次矩阵乘法

$$\text{输出} = W \cdot \text{输入} + b$$

- $W$：权重矩阵（$d_{out} \times d_{in}$）
- 输入：列向量（$d_{in} \times 1$）
- 输出：列向量（$d_{out} \times 1$）

### Batch 处理 = 矩阵乘矩阵

实际训练不是一次处理一个样本，而是同时处理一个 batch：

```
输入矩阵 X：(batch_size × d_in)
权重矩阵 W：(d_in × d_out)
输出矩阵：  (batch_size × d_out)  ← 一次矩阵乘法，所有样本同时算完
```

GPU 的核心优势就是**并行矩阵乘法**，这是深度学习能跑快的根本原因。

### Transformer 注意力 = 三次矩阵乘法

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

- $Q$（Query）、$K$（Key）、$V$（Value）都是矩阵
- $QK^T$：计算每对 token 之间的相似度（矩阵乘法）
- 结果乘以 $V$：加权求和（矩阵乘法）

整个 Transformer 的核心，就是矩阵乘法。

---

## 三、转置：维度对齐的工具

### 为什么需要转置？

矩阵乘法要求"左矩阵的列数 = 右矩阵的行数"。当维度不匹配时，转置是最常用的对齐手段。

注意力机制里的 $QK^T$：
- $Q$：$(n \times d_k)$，$n$ 个 token，每个 $d_k$ 维
- $K$：$(n \times d_k)$
- $K^T$：$(d_k \times n)$
- $QK^T$：$(n \times n)$，每对 token 的相似度得分 ✓

### 转置 = 行列互换

```
原矩阵 A:          转置 A^T:
1  2  3            1  4
4  5  6            2  5
                   3  6
```

## 四、内积与范数：度量相似性

### 内积 = 相似度

两个向量的内积：

$$\langle u, v \rangle = u \cdot v = \sum_i u_i v_i = \|u\| \|v\| \cos\theta$$

- 内积大 → 方向接近 → 语义相似
- 内积 = 0 → 互相垂直 → 完全不相关

**在深度学习中的应用：**
- 注意力分数：$QK^T$ 的每个元素就是一对向量的内积
- 词向量相似度：`king - man + woman ≈ queen` 用的就是向量内积
- 余弦相似度：$\cos\theta = \frac{u \cdot v}{\|u\| \|v\|}$

### 范数 = 向量的"大小"

$$\|x\|_2 = \sqrt{\sum_i x_i^2} \quad \text{（L2 范数，最常用）}$$

**在深度学习中的应用：**

| 应用 | 怎么用范数 |
|------|----------|
| L2 正则化（权重衰减）| 损失函数加 $\lambda \|W\|_2^2$，防止权重过大 |
| Gradient Clipping | 梯度范数超过阈值就缩放，防止梯度爆炸 |
| LayerNorm | 把向量除以自己的范数，归一化到单位球面 |
| 余弦相似度 | 用范数归一化再做内积 |

## 五、线性变换：神经网络的几何解释

### 每一层都在变换空间

从几何角度看，一层神经网络做了什么：

```
输入向量（高维空间中的一个点）
       ↓  乘以权重矩阵（线性变换）
旋转 + 拉伸（SVD 三步：旋转 → 拉伸 → 旋转）
       ↓  加偏置（平移）
       ↓  激活函数（非线性弯曲）
输出向量（变换后的空间中的点）
```

多层堆叠 = 多次变换 = 能表达越来越复杂的形状。

### 为什么需要激活函数？

没有激活函数，多层线性变换等于一层：

$$W_2(W_1 x) = (W_2 W_1)x = W' x$$

两个矩阵乘积还是矩阵，再多层也没用。激活函数引入非线性，让网络能"弯曲"空间。

## 六、特征值：理解训练稳定性

### 特征值 = 某方向上的拉伸倍数

$$Av = \lambda v$$

矩阵 $A$ 作用在特征向量 $v$ 上，只做缩放（$\lambda$ 倍），不改变方向。

### 在深度学习中的作用

**梯度消失 / 爆炸的本质：**

在反向传播时，梯度要乘过很多层的权重矩阵。如果权重矩阵的特征值：
- 普遍 $> 1$ → 梯度越乘越大 → **梯度爆炸**
- 普遍 $< 1$ → 梯度越乘越小 → **梯度消失**

**初始化策略（Xavier / He）的原理：**

精心设计初始权重，让各层矩阵的特征值分布在 1 附近 → 梯度传播稳定。

**谱归一化（Spectral Normalization）：**

把权重矩阵除以它的最大奇异值（最大特征值的平方根），强制让矩阵的"拉伸倍数"不超过 1，常用于 GAN 训练稳定化。

## 七、SVD 与低秩分解：压缩与微调

### 核心思想

任何矩阵都可以分解为：

$$W = U \Sigma V^T$$

奇异值大的分量 = 重要信息，奇异值小的分量 = 噪音或冗余。

### LoRA 的原理

大模型权重 $W$（比如 $4096 \times 4096$）的**更新量 $\Delta W$** 是低秩的：

$$\Delta W \approx B A \quad (B: 4096\times r,\ A: r\times 4096,\ r=32)$$

只训练 $A$ 和 $B$，参数量从 1680 万降到 26 万（节省 98%）。

→ 详见 [[LoRA 原理可视化详解]] 和 [[PEFT 参数高效微调概览]]

### PCA 降维

对数据矩阵做 SVD，取前 $k$ 个最大奇异值方向 → 把高维数据压缩到 $k$ 维，保留最主要的变化方向。

## 八、正定矩阵：优化算法的基础

### Hessian 矩阵正定 → 极小值

损失函数在某点的 Hessian（二阶导数矩阵）正定，说明这是一个局部极小值（碗形曲面）。

### 条件数决定收敛速度

$$\kappa = \frac{\sigma_{max}}{\sigma_{min}}$$

条件数大 → 损失曲面像细长椭圆 → 梯度下降震荡，收敛慢。

各种优化器本质上都是在估计 Hessian 或其对角近似：

| 优化器 | 用到的线性代数 |
|--------|-------------|
| SGD | 一阶梯度（向量） |
| Adam | 对角 Hessian 近似（向量逐元素） |
| L-BFGS | 低秩 Hessian 逆近似（矩阵） |
| 自然梯度 | Fisher 信息矩阵（半正定矩阵） |

→ 详见 [[正定矩阵与优化]]

## 九、张量：矩阵的高维推广

深度学习实际用的不是矩阵，而是**张量**（多维数组）：

| 维度 | 名称 | 例子 |
|------|------|------|
| 1D | 向量 | 一个样本的特征 |
| 2D | 矩阵 | 一个 batch 的特征 |
| 3D | 张量 | 一个 batch 的序列（batch × seq_len × d_model） |
| 4D | 张量 | 一个 batch 的图像（batch × C × H × W） |

张量的各种操作（reshape、transpose、einsum）本质都是线性代数在高维的推广。
