## 高中生也能懂

想象你有一个**保险柜**，里面装了很多物品。现在你要给这个柜子配一把**电子秤**。

问题是：不是所有东西都能上秤。
- 🍎 苹果 → ✅ 能称
- 📱 手机 → ✅ 能称
- 🌧📱 手机 → ✅ 能称\n- 🌧️ "明天会不会下雨" → ❌ 不能称，它不是个东西\n- 👻 鬼魂 → ❌ 不能称，它不存在\n\n**σ-域就是"秤能称的东西清单"**——它规定了柜子里哪些物品有资格被称重。\n\n---\n\n### 一个更数学的故事\n\n你抛一枚硬币，结果可能是正面(1)或反面(0)。\n\n**所有可能结果的集合** Ω = {0, 1}，这叫样本空间。\n\n现在考你：你能回答哪些问题？\n\n| 问题 | 能不能回答？ | 为什么？ |\n|:---|:---|:---|\n| 抛出来是0吗？ | ✅ | 你看到了结果 |\n| 抛出来是1吗？ | ✅ | 你看到了结果 |\n| 抛出来是数字吗？ | ✅ | 0和1都是数字，永远成立 |\n| 下一抛是0吗？ | ❌ | 你没看未来 |\n\n**σ-域就是"你能回答的问题清单"。**\n\n在这个例子里的 σ-域是：\n\n$$\\mathcal{F} = \\{\\emptyset, \\{0\\}, \\{1\\}, \\{0,1\\}\\}$$\n\n翻译成人话：\n- ∅ = "什么都没发生" → 概率 0\n- {0} = "抛出了 0" → 概率 0.5\n- {1} = "抛出了 1" → 概率 0.5\n- {0,1} = "发生了点什么" → 概率 1\n\n这四条就是你能谈概率的全部东西。你不能谈"抛出 2"——因为 2 根本不在样本空间里。\n\n---\n\n### 核心思想\n\n> **σ-域 = 信息边界。边界内的事情你知道，边界外的事情你问不了。**\n\n1. 全集一定在（\"肯定发生了点什么\"总是对的）\n2. 如果知道 A 发生了，就知道 A 没发生（补集也在）\n3. 如果知道"第1天跌了""第2天跌了"……那你也知道"某一天跌了"（可数并也在）\n\n---\n\n### 为什么要搞这么复杂？\n\n因为进入连续世界（股价、温度、时间）之后，样本空间变成整个实数轴。实数比整数复杂得多——实数有无限个，而"实数上大部分子集"是你无法合理定义概率的。\n\n高中数学里你只用离散的骰子/硬币，Ω 是有限的，σ-域就是"所有子集\"——你不用操心。\n\n但大学数学要处理的股价是连续变量：\n\n$$P(\\text{股价恰好等于 100 元}) = 0$$（连续变量某一点的概率永远是 0）\n\n你不能用"数子集"的方式算概率了，需要一个框架来处理"区间"和"无限"。**σ-域就是这个框架的地基。**\n\n## 直觉引入\n\n概率论的基础问题：给事件分配概率之前，先要确定**哪些子集可以被赋予概率**。"}]

不是每个子集都能被度量。考虑实数上的区间 [0,1]——你可以谈"落在 [0.2, 0.5] 的概率"，但如果选取一个不可测的怪异集合，概率公理就会崩溃。

**σ-域就是"可测事件的集合"**。它告诉你：这些子集可以谈概率，之外的不能。

**类比**：
- 测度 → 一把尺子
- σ-域 → 尺子能测量的东西
- 你没法用尺子量"爱"——因为那不在尺子的"域"里

## 定义

设 Ω 为非空集合（**样本空间**）。Ω 上的 σ-域（σ-field / σ-algebra）ℱ 是 Ω 的某些子集构成的集合，满足：

1. **Ω ∈ ℱ**（包含全集）
2. **补封闭**：若 A ∈ ℱ，则 Aᶜ ∈ ℱ
3. **可数并封闭**：若 A₁, A₂, … ∈ ℱ，则 $\bigcup_{i=1}^{\infty} A_i \in \mathcal{F}$

### 由此可推导的性质

- ∅ ∈ ℱ（由 1 + 2：∅ = Ωᶜ）
- **可数交封闭**：$\bigcap_{i=1}^{\infty} A_i = (\bigcup A_i^c)^c \in \mathcal{F}$
- **有限并/交封闭**：取 Aₖ₊₁ = Aₖ₊₂ = … = ∅ 即可
- **差封闭**：A \ B = A ∩ Bᶜ ∈ ℱ

## 例子

### 最小 σ-域：平凡 σ-域

$$\mathcal{F} = \{\emptyset, \Omega\}$$

只知道"什么都没发生"或"发生了点什么"，其他一概不知。

### 最大 σ-域：幂集

$$\mathcal{F} = 2^{\Omega} = \{\text{的所有子集}\}$$

有限样本空间的常见选择。掷骰子 Ω={1,…,6} 时，所有子集都可测。

### Borel σ-域 ℬ(ℝ)

实数上最重要的 σ-域，由所有**开区间**生成：

$$\mathcal{B}(\mathbb{R}) = \sigma(\{(a,b) \mid a < b\})$$

等价定义：由开集/闭集/半开区间/有理端点区间生成，结果相同。

**包含哪些集合？** 所有你"自然"能想到的 ℝ 子集：
- 区间、单点、可数集、康托集
- 开集、闭集、Gδ、Fσ
- 几乎所有的实数子集都在 ℬ(ℝ) 中

**不包含什么？** 极少数需要选择公理构造的"病态"集合（如 Vitali 集合）。这些不可测集需要用量论中的"完备化"来排除。

## 生成 σ-域

对任意集族 𝒞，存在包含 𝒞 的**最小 σ-域**，记作 σ(𝒞)：

$$\sigma(\mathcal{C}) = \bigcap \{\mathcal{F} \mid \mathcal{F} \text{是σ-域}, \mathcal{C} \subseteq \mathcal{F}\}$$

取所有包含 𝒞 的 σ-域的交——它仍然是 σ-域。

**重要例子**：

| 生成元 𝒞 | σ(𝒞) |
|:---|:---|
| 所有开区间 | ℬ(ℝ) |
| {(-∞, x] : x ∈ ℝ} | ℬ(ℝ)（用分布函数定义概率）|
| {A₁, …, Aₙ}（Ω 的有限分割）| 分割生成的有限 σ-域 |

## σ-域流 (Filtration)

随**时间**逐步丰富的 σ-域族 $\{\mathcal{F}_t\}_{t \geq 0}$ 称为 σ-域流：

$$\mathcal{F}_s \subseteq \mathcal{F}_t \quad (s \leq t)$$

**直觉**：ℱₜ 代表"到时间 t 为止你掌握的全部信息"。

### 布朗运动的自然 σ-域流

$$\mathcal{F}_t = \sigma(\{B_s: 0 \leq s \leq t\})$$

ℱₜ 包含所有依赖于 [0, t] 区间布朗路径的事件。随 t 增大，你知道得越来越多。

### 为什么 σ-域流重要

- **适应过程 (adapted)**：Xₜ 的值只依赖于到 t 为止的信息 → Xₜ 是 ℱₜ-可测
- **停时 (stopping time)**：{τ ≤ t} ∈ ℱₜ → "停下来"的决策只用历史信息
- **条件期望**：E[X | ℱₜ] 是"基于到 t 为止的信息对 X 的最佳预测"
- **鞅**：E[Mₜ | ℱₛ] = Mₛ (s < t)，核心是条件期望相对于 σ-域流

## 与概率论的联系

Kolmogorov 公理体系把概率空间定义为三元组：

$$(\Omega, \mathcal{F}, \mathbb{P})$$

- Ω：样本空间
- ℱ：σ-域（可测事件）
- ℙ：ℱ 上的概率测度，满足 ℙ(Ω) = 1 且可数可加

**一句话总结**：σ-域是概率论的"舞台边界"——定义哪些事件有资格参与概率计算，哪些不能。ℱ 选得越小，信息越少（不确定性越大）；ℱ 选得越大，信息越多（颗粒度越细）。

## 在量化金融中的出现

| 概念 | σ-域的角色 |
|:---|:---|
| 股价过程 Sₜ | 自然滤子 ℱₜ = σ(Sₛ, s ≤ t) |
| 停时（止损/止盈）| {τ ≤ t} ∈ ℱₜ |
| 风险中性定价 | ℚ 相对于 ℱ 下的等价测度变换 |
| 动态对冲 | 仓位调整依赖 ℱₜ |
| 信息不对称 | 内幕交易者拥有更大的 σ-域 |
