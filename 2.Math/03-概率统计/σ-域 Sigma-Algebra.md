## 高中生也能懂 🎒

### 保险柜的故事

你有个保险柜，里面装了些东西。你给它配了一把秤，想称重量。

但不是所有东西都能上秤：

- 🍎 苹果 → ✅ 能称
- 📱 手机 → ✅ 能称
- 🌧️ "明天会不会下雨" → ❌ 不能称，它不是个东西
- 👻 鬼魂 → ❌ 不能称，它不存在

**σ-域 = "秤能称的东西清单"** —— 它规定了哪些物品有资格上秤。

---

### 抛硬币的故事

抛一枚硬币，结果：正面(1) 或 反面(0)。

全部可能结果的集合：Ω = {0, 1}，这叫**样本空间**。

现在问：你能回答哪些问题？

| 问题 | 能答吗？ | 原因 |
|:---|:---|:---|
| 抛出来是 0 吗？ | ✅ | 你看到了结果 |
| 抛出来是 1 吗？ | ✅ | 你看到了结果 |
| 抛出来是个数字吗？ | ✅ | 0 和 1 都是数字，永远成立 |
| 下一抛是 0 吗？ | ❌ | 你看不到未来 |

**σ-域 = "你能回答的那些问题的集合"。**

这个例子里 σ-域长这样：

$$\mathcal{F} = \{\emptyset, \{0\}, \{1\}, \{0,1\}\}$$

翻译成人话：

| 集合 | 含义 | 概率 |
|:---|:---|:---|
| ∅ | "什么都没发生" | 0 |
| {0} | "抛出了 0" | 0.5 |
| {1} | "抛出了 1" | 0.5 |
| {0,1} | "发生了点什么" | 1 |

这四条就是**你能谈概率的全部东西**。你不能谈"抛出 2"——因为 2 根本不在样本空间里。

---

### 核心思想（一句话）

> **σ-域 = 你的信息边界。边界内你知道，边界外你问不了。**

三条规则就是三个常识：

1. "发生了点什么"这个事实你一定知道 → **全集在**
2. 如果你知道"下雨了"，就肯定知道"没出太阳" → **补集在**
3. 如果你分别知道"周一跌了""周二跌了""周三跌了"……就肯定知道"这三天里有某天跌了" → **任意并集也在**

---

### 为什么要搞这么麻烦？

高中数学：骰子 6 个面、硬币 2 个面——样本空间是**有限个**，所有子集都能谈概率，σ-域自动就是"所有子集"——你不用操心。

大学数学：股价、温度、时间——样本空间是整个**实数轴**。实数有无穷多个，而且"无穷"这东西比"很多"复杂得多。

更坑的是：

$$P(\text{股价恰好等于 100 元}) = 0$$

连续变量落在**精确一点**的概率永远是 0。你不能用"数子集个数"来算概率了，需要一套能处理"区间"和"无限"的框架。

**σ-域就是这个框架的地基。**

---

## 直觉引入

概率论的基础问题：给事件分配概率之前，先要确定**哪些子集可以被赋予概率**。

不是每个子集都能被度量。实数区间 [0,1] —— 你可以谈"落在 [0.2, 0.5] 的概率"，但如果选了一个病态的不可测集合，概率公理就会崩溃。

**σ-域就是"可测事件的集合"**。

> 类比：测度 = 一把尺子，σ-域 = 尺子能量的东西。你没法用尺子量"爱"——它不在尺子的域里。

## 定义

设 Ω 为非空集合（**样本空间**）。Ω 上的 σ-域（σ-field / σ-algebra）ℱ 是 Ω 的某些子集构成的集合，满足：

1. **Ω ∈ ℱ**（包含全集）
2. **补封闭**：若 A ∈ ℱ，则 Aᶜ ∈ ℱ
3. **可数并封闭**：若 A₁, A₂, … ∈ ℱ，则 $\bigcup_{i=1}^{\infty} A_i \in \mathcal{F}$

### 由此可推导的性质

- ∅ ∈ ℱ（由 1 + 2：∅ = Ωᶜ）
- **可数交封闭**：$\bigcap_{i=1}^{\infty} A_i = (\bigcup A_i^c)^c \in \mathcal{F}$
- **有限并/交封闭**：取 Aₖ₊₁ = Aₖ₊₂ = … = ∅ 即可
- **差封闭**：A \ B = A ∩ Bᶜ ∈ ℱ

## 例子

### 最小 σ-域：平凡 σ-域

$$\mathcal{F} = \{\emptyset, \Omega\}$$

只知道"什么都没发生"或"发生了点什么"，其他一概不知。

### 最大 σ-域：幂集

$$\mathcal{F} = 2^{\Omega} = \{\Omega \text{ 的所有子集}\}$$

有限样本空间的常见选择。掷骰子 Ω={1,…,6} 时，所有子集都可测。

### Borel σ-域 ℬ(ℝ)

实数上最重要的 σ-域，由所有**开区间**生成：

$$\mathcal{B}(\mathbb{R}) = \sigma(\{(a,b) \mid a < b\})$$

等价：由开集/闭集/半开区间/有理端点区间生成，结果相同。

包含你"自然"能想到的所有 ℝ 子集：区间、单点、可数集、开集、闭集……几乎全部。极少数需要选择公理构造的病态集合（如 Vitali 集）不在其中。

## 生成 σ-域

对任意集族 𝒞，存在包含 𝒞 的**最小 σ-域**，记作 σ(𝒞)：

$$\sigma(\mathcal{C}) = \bigcap \{\mathcal{F} \mid \mathcal{F} \text{是 σ-域}, \mathcal{C} \subseteq \mathcal{F}\}$$

取所有包含 𝒞 的 σ-域的交——它仍然是 σ-域。

| 生成元 𝒞 | σ(𝒞) |
|:---|:---|
| 所有开区间 | ℬ(ℝ) |
| {(-∞, x] : x ∈ ℝ} | ℬ(ℝ)（用分布函数定义概率）|
| {A₁, …, Aₙ}（Ω 有限分割）| 分割生成的有限 σ-域 |

## σ-域流 (Filtration)

随时间逐步丰富的 σ-域族 $\{\mathcal{F}_t\}_{t \geq 0}$ 称为 σ-域流：

$$\mathcal{F}_s \subseteq \mathcal{F}_t \quad (s \leq t)$$

**直觉**：ℱₜ 代表"到时间 t 为止你掌握的全部信息"。

### 布朗运动的自然 σ-域流

$$\mathcal{F}_t = \sigma(\{B_s: 0 \leq s \leq t\})$$

ℱₜ 包含所有依赖于 [0, t] 区间布朗路径的事件。随 t 增大，信息越来越多。

### 为什么 σ-域流重要

| 概念 | 与 σ-域流的关系 |
|:---|:---|
| 适应过程 | Xₜ 的值只用 ℱₜ 内的信息 → Xₜ 是 ℱₜ-可测 |
| 停时 | {τ ≤ t} ∈ ℱₜ → "停止"决策只用历史信息 |
| 条件期望 | E[X \| ℱₜ] = "基于当前信息的 X 的最佳预测" |
| 鞅 | E[Mₜ \| ℱₛ] = Mₛ (s < t)，核心是相对于 σ-域流的条件期望 |

## 与概率论的联系

Kolmogorov 公理体系把概率空间定义为三元组：

$$(\Omega, \mathcal{F}, \mathbb{P})$$

- Ω：样本空间
- ℱ：σ-域（可测事件）
- ℙ：ℱ 上的概率测度，满足 ℙ(Ω)=1 且可数可加

> σ-域是概率的"舞台边界"——定义哪些事件有资格参与计算。ℱ 越小 → 信息越少（不确定性大）；ℱ 越大 → 颗粒越细。

## 在量化金融中的出现

| 概念 | σ-域的角色 |
|:---|:---|
| 股价过程 Sₜ | 自然滤子 ℱₜ = σ(Sₛ, s ≤ t) |
| 停时（止损/止盈）| {τ ≤ t} ∈ ℱₜ |
| 风险中性定价 | ℚ 相对于 ℱ 的等价测度变换 |
| 动态对冲 | 仓位调整依赖 ℱₜ |
| 信息不对称 | 内幕交易者拥有更大的 σ-域 |
