## 高中生也能懂 🎒

### 赌场故事

你在赌场玩一个游戏。每轮你可以下注，赢了翻倍，输了归零。

正常赌场：你**长期必输**——因为赔率对庄家有利。

**鞅游戏**：一个特殊的赌局，**长期你不会赢也不会输**——站在任何时刻看，你下一时刻的期望财产 = 当前财产。

$$E[M_{t+1} | \mathcal{F}_t] = M_t$$

这就是鞅。它的名字来自法语 "martingale"，原是 18 世纪一种赌博策略（输了就加倍下注），但数学定义正好相反——**鞅就是没有趋势的公平游戏**。

---

### 正式定义

随机过程 Mₜ 是**鞅**，如果满足：

1. **适应**：Mₜ 对 ℱₜ 可测（每时刻的值基于当时已知信息）
2. **可积**：E[|Mₜ|] < ∞
3. **鞅性质**：E[Mₜ | ℱₛ] = Mₛ，对所有 s < t

**第三条就是一切。**

---

### 三个版本

| 类型 | 条件 | 通俗说法 |
|:---|:---|:---|
| 鞅 | E[Mₜ \| ℱₛ] = Mₛ | 公平游戏，不赚不赔 |
| 下鞅 | E[Mₜ \| ℱₛ] ≥ Mₛ | 对你有利，期望上涨 |
| 上鞅 | E[Mₜ \| ℱₛ] ≤ Mₛ | 对你无利，期望下跌 |

---

### 经典例子

#### 1. 对称随机游走（鞅）

$$S_n = \sum_{i=1}^{n} X_i, \quad X_i = 
\begin{cases}
+1 & \text{概率 } \frac{1}{2} \\
-1 & \text{概率 } \frac{1}{2}
\end{cases}$$

一步期望变化 = 0 → 鞅。

#### 2. 布朗运动（鞅）

$$B_t \sim N(0, t)$$

E[Bₜ | ℱₛ] = Bₛ。布朗运动的每一步期望变化 = 0。

#### 3. 几何布朗运动（**不是鞅**）

$$dS_t = \mu S_t dt + \sigma S_t dB_t$$

E[Sₜ | ℱₛ] = Sₛ · e^{μ(t−s)} ≠ Sₛ。

漂移项 μ > 0 → 股价**不是鞅**，它在**涨**。

---

### 为什么股价不是鞅你还用它

这就是**风险中性定价**的魔法：

存在另一个概率测度 ℚ（等价鞅测度），在 ℚ 下：

$$dS_t = r S_t dt + \sigma S_t dB_t^{\mathbb{Q}}$$

折现后 $$e^{-rt} S_t$$ 是 ℚ-鞅。

**实际世界**（ℙ-测度）：股价在涨，不是鞅。

**定价世界**（ℚ-测度）：折现股价是鞅，期权价格 = 风险中性期望。

---

### 鞅 + 条件期望 = 随机积分

伊藤积分的定义用的是鞅：

$$\int_0^t \theta_s dB_s$$

其中 Bₜ 是布朗运动（鞅），θₛ 是 ℱₛ-适应过程（只能用历史信息）。

这个积分本身也是鞅！

---

### 可选停止定理 Optional Stopping

如果 τ 是有界停时，Mₜ 是鞅：

$$E[M_{\tau}] = E[M_0]$$

**翻译**：即使你可以在任意时刻"叫停"，期望收益仍然是初始值。你不能通过选择停止时间来**系统性地**赢一个鞅游戏。

这个定理在金融中的含义：你没法通过择时（选撤退时间）在无套利市场中白赚钱。

## 在量化金融中

| 概念 | 鞅的角色 |
|:---|:---|
| 无套利 | 折现资产价格在 ℚ 下是鞅 = 无套利条件 |
| Black-Scholes | 期权价值 = E^ℚ[折现收益] |
| Delta 对冲 | 组合过程是鞅：无风险 + 无套利 |
| 最优停时 | 美式期权：选 τ 使 E^ℚ[折现收益] 最大化 |
| 统计套利 | 残差序列是否鞅 → 能否预测 |
