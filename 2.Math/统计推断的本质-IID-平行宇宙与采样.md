# 统计推断的本质 — IID、平行宇宙与采样

## 核心洞察

> <span style="color:rgb(255, 77, 77)"><b>统计推断的本质是在找 IID（独立同分布）的样本。平行宇宙是理想情况，Bootstrap 是模拟技巧，截面数据是量化里最接近的近似。</b><br></span>
## 1. IID 的两个条件

统计推断的所有经典方法（t 检验、回归、ANOVA）都建立在 IID 假设之上。拆开看：

| 条件                          | 含义            | 时序数据               | 截面数据    | 平行宇宙     |
| :-------------------------- | :------------ | :----------------- | :------ | :------- |
| **Independent**             | 每个样本不含其他样本的信息 | ❌ 自相关、波动率聚集        | ⚠️ 部分满足 | ✅ 自然满足   |
| **Identically Distributed** | 所有样本来自同一 DGP  | ❌ regime switching | ✅ 基本满足  | ✅ 物理定律相同 |

### 时序数据为什么不是 IID

- <span style="color:rgb(255, 77, 77)"><b>不独立</b></span>：$r_t$ 与 $r_{t-1}$ 有自相关
- <span style="color:rgb(255, 77, 77)"><b>不同分布</b></span>：2015 杠杆牛、2018 去杠杆、2020 疫情、2023 AI 驱动——DGP 在不同 regime 之间切换
- **后果**：直接用 OLS 做时序回归，标准误被低估，p 值被高估，假阳性泛滥

### 截面数据为什么更接近 IID

- 同一时刻的不同股票，<span style="color:rgb(255, 77, 77)">共享同一个市场环境 </span>→ **同分布**
- <span style="color:rgb(255, 77, 77)">不同股票之间不完全独立</span>（行业 beta、因子暴露），但远比时序独立 → <span style="color:rgb(255, 77, 77)"><b>近似独立</b></span>
- 这就是 Fama-MacBeth 的核心逻辑：<span style="color:rgb(255, 77, 77)"><b>把时序问题转化为截面问题</b></span>

## 2. 平行宇宙 — 真 IID 的理想

### 什么是平行宇宙

<span style="color:rgb(255, 77, 77)">同一个数据生成过程（DGP），平行运行多次，每次产生一个独立观测。</span>这就是 IID 的完美实现。

### 为什么不可得

<span style="color:rgb(255, 77, 77)">现实中我们只有一个历史</span> —— 我们既不能重跑历史，也不能观测平行宇宙。统计推断就是在**只有一个时间线的条件下，估计多个时间线会产生什么结果**。

### 统计推断的平行宇宙解释

$$
\text{观测到的统计量} = \text{真实参数} + \text{抽样误差}
$$

- 真实参数：在所有平行宇宙中的平均值
- 抽样误差：我们恰好落在的这个宇宙与平均值的偏差
- p 值：在零假设为真的平行宇宙中，出现比我们观测到的更极端结果的概率

## 3. 模拟 IID 的采样方式

既然真 IID 不可得，统计学家发明了各种逼近技巧：

### 3.1 Bootstrap（自助法）— 用重采样模拟平行宇宙

**核心思想**：把历史样本当作 DGP 的经验分布，从中有放回抽取，模拟"如果历史重演 n 次"。

```
原始样本：X₁, X₂, ..., Xₙ
Bootstrap 样本：随机有放回抽取 n 个

本质：在经验分布下构造平行宇宙
```

**优势**：
- 不需要假设母体分布
- 自然给出置信区间（用 bootstrap 分位数）
- 对任何统计量都适用

**局限**：
- 不能处理时序依赖（原始样本打乱了时间结构）
- 对极端值敏感（一个异常值会被反复抽到）

### 3.2 Block Bootstrap（分块自助）— 保留局部结构

时序有自相关，不能打乱顺序。**分块**保留局部依赖：

```
原始序列：[X₁, X₂, X₃ | X₄, X₅, X₆ | X₇, X₈, X₉]
             块1          块2          块3

Bootstrap：随机抽取块 → [块3, 块1, 块2, 块1, ...]
```

- 块内保留时序依赖
- 块间破坏依赖 → 近似独立
- 块大小选择：太小破坏依赖不够，太大样本量不够

### 3.3 时序交叉验证

```
普通 CV：   随机打乱 → 分 K 折 → 每折轮流做验证集
时序 CV：   保持顺序 → 滑动窗口 → 只向前看，不向后看
```

- 训练集时间 < 验证集时间
- 避免"用未来预测过去"的信息泄露
- 每一折的样本量可能不同（非平衡）

### 3.4 截面化 — 量化里的黄金标准

把时序问题转化为截面问题：

| 方法 | 思路 | 例子 |
|:---|:---|:---|
| Fama-MacBeth | 每月做一次截面回归，然后对时间序列取平均 | 估计因子溢价 |
| 截面 IC | 每期计算因子与收益的截面相关性，然后对 IC 序列做 t 检验 | 检验因子有效性 |
| 分层回测 | 每期按因子值分组，计算各组收益，观察单调性 | 因子效果可视化 |

**截面化的优势**：同一时刻的不同股票 ≈ 同一 DGP 下的平行观测。

## 4. 完整框架

```
统计推断的目标：找到 IID 同分布的样本
│
├─ 路线 A：真正的 IID
│   ├─ 平行宇宙（理想，不可得）
│   ├─ 截面数据（最佳近似）← 同一时刻，不同股票
│   └─ 随机实验（A/B test，可控环境）
│
├─ 路线 B：模拟 IID
│   ├─ Bootstrap → 用重采样模拟"平行宇宙"
│   ├─ Block Bootstrap → 保留时序局部结构，破坏全局依赖
│   └─ 截面化 → 把时序问题转化为截面问题
│
└─ 路线 C：直面非 IID
    ├─ 时序模型（GARCH、状态空间）→ 显式建模依赖
    ├─ 稳健标准误（Newey-West）→ 修正自相关
    └─ 贝叶斯方法 → 不依赖 IID 假设
```

---

## 5. 对量化研究的启示

1. **不要对时序收益率直接做 t 检验** — 用 Newey-West 修正自相关
2. **截面因子检验是黄金标准** — Fama-MacBeth 天然利用截面 IID 近似
3. **Bootstrap 是小样本的救星** — 不需要假设分布，自然给出置信区间
4. **Block Bootstrap 处理时序依赖** — 保留局部结构，模拟平行宇宙
5. **样本量足够时，非 IID 的后果可控** — 大样本 + 稳健标准误 ≈ 近似 IID
