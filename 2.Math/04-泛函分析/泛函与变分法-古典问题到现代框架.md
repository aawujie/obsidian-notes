# 泛函与变分法：从古典问题到现代框架

> 本文是泛函与变分法系列的第一篇，从历史动机出发，建立泛函与变分的基本直觉，推导欧拉-拉格朗日方程，并分析经典案例。

---

## 1. 历史起点：最速降线问题

1696年，约翰·伯努利 (Johann Bernoulli) 向欧洲数学界发起挑战：

> **在垂直平面内，给定两点 A 和 B（A 高于 B），求一条曲线，使得质点仅受重力从 A 沿曲线滑到 B 所需时间最短。**

这不是求一个数，而是**求一整条曲线**。牛顿、莱布尼茨、洛必达、伯努利兄弟都给出了正确解答——**摆线 (cycloid)**。

这个问题标志着**变分法 (Calculus of Variations)** 的诞生。它的核心特征与普通微积分完全不同：

| 维度 | 普通微积分 | 变分法 |
|------|-----------|--------|
| 输入 | 数 $x \in \mathbb{R}^n$ | 函数 $y(x) \in \mathcal{F}$（函数空间） |
| 输出 | 数 $f(x) \in \mathbb{R}$ | 数 $J[y] \in \mathbb{R}$ |
| 微小改变 | 微分 $dx$ | 变分 $\delta y$（整个函数的扰动） |
| 极值条件 | $f'(x) = 0$ | $\delta J = 0$ |
| 解 | 点 $x^*$ | 函数 $y^*(x)$ |

---

## 2. 泛函：函数的函数

### 2.1 严格定义

**定义**：设 $\mathcal{F} = \{y(x)\}$ 是一个函数空间（如 $C^1[a,b]$），映射

$$J: \mathcal{F} \to \mathbb{R}, \quad y \mapsto J[y]$$

称为**泛函 (functional)**。泛函吃进一个函数，吐出一个实数。

### 2.2 典型例子

| 泛函 | 表达式 | 物理意义 |
|------|--------|----------|
| 弧长 | $J[y] = \int_a^b \sqrt{1 + (y')^2}\,dx$ | 曲线的长度 |
| 势能 | $J[y] = \int_a^b \rho g y(x)\sqrt{1+(y')^2}\,dx$ | 悬链线的势能 |
| 时间 | $J[y] = \int_a^b \frac{\sqrt{1+(y')^2}}{\sqrt{2gy}}\,dx$ | 最速降线的时间 |
| 面积 | $J[y] = \int_a^b 2\pi y\sqrt{1+(y')^2}\,dx$ | 旋转曲面面积 |
| Dirichlet能量 | $J[u] = \int_\Omega \frac{1}{2}|\nabla u|^2\,dx$ | 膜的能量 |

### 2.3 线性泛函 vs 非线性泛函

- **线性泛函**：$J[\alpha y_1 + \beta y_2] = \alpha J[y_1] + \beta J[y_2]$
  - 例：$J[y] = \int_a^b y(x)\,dx$，$J[y] = y(0)$（Dirac delta）
- **非线性泛函**：绝大多数物理泛函都是非线性的
  - 例：$J[y] = \int_a^b (y')^2\,dx$，$J[y] = \int_a^b \sqrt{1+(y')^2}\,dx$

## 3. 变分：函数的微分

### 3.1 变分的定义

设 $y(x)$ 是"候选函数"，$\eta(x)$ 是任意满足 $\eta(a)=\eta(b)=0$ 的光滑函数。构造**扰动函数族**：

$$y_\epsilon(x) = y(x) + \epsilon \eta(x)$$

其中 $\epsilon$ 是一个小参数。**变分** $\delta y$ 定义为：

$$\delta y := y_\epsilon(x) - y(x) = \epsilon \eta(x)$$

### 3.2 泛函的变分（一阶变分）

泛函 $J[y]$ 的一阶变分 $\delta J$ 定义为：

$$\delta J := \left.\frac{d}{d\epsilon} J[y + \epsilon \eta]\right|_{\epsilon=0}$$

**直觉**：$\delta J$ 衡量的是"把曲线 $y(x)$ 轻轻捏一下，泛函值变化了多少"。

### 3.3 极值的必要条件

如果 $y(x)$ 是泛函 $J$ 的极值点（极大或极小），那么对**任意**扰动 $\eta$，都应有：

$$\delta J = 0 \quad \text{（对所有允许的 }\eta\text{）}$$

这完全类比于 $f'(x^*) = 0$：在极值点，任何方向的一阶变化都为零。

## 4. 欧拉-拉格朗日方程：从泛函极值到微分方程

### 4.1 推导

考虑最简单形式的泛函：

$$J[y] = \int_a^b F(x, y(x), y'(x))\,dx, \quad y(a)=A,\; y(b)=B$$

计算一阶变分：

$$\begin{aligned}
\delta J &= \left.\frac{d}{d\epsilon} \int_a^b F(x, y+\epsilon\eta, y'+\epsilon\eta')\,dx\right|_{\epsilon=0} \\[4pt]
&= \int_a^b \left(\frac{\partial F}{\partial y}\eta + \frac{\partial F}{\partial y'}\eta'\right) dx
\end{aligned}$$

对第二项分部积分（利用 $\eta(a)=\eta(b)=0$）：

$$\int_a^b \frac{\partial F}{\partial y'}\eta'\,dx = \left[\frac{\partial F}{\partial y'}\eta\right]_a^b - \int_a^b \frac{d}{dx}\!\left(\frac{\partial F}{\partial y'}\right)\eta\,dx = -\int_a^b \frac{d}{dx}\!\left(\frac{\partial F}{\partial y'}\right)\eta\,dx$$

代入得：

$$\delta J = \int_a^b \left[\frac{\partial F}{\partial y} - \frac{d}{dx}\!\left(\frac{\partial F}{\partial y'}\right)\right]\eta(x)\,dx = 0$$

由**变分法基本引理**（若 $\int_a^b f(x)\eta(x)dx = 0$ 对所有 $\eta$ 成立，则 $f(x) \equiv 0$），得到：

$$\boxed{\frac{\partial F}{\partial y} - \frac{d}{dx}\!\left(\frac{\partial F}{\partial y'}\right) = 0}$$

这就是**欧拉-拉格朗日方程 (Euler-Lagrange Equation)**，变分法最核心的工具。

### 4.2 展开形式

将全导数 $\frac{d}{dx}$ 展开：

$$F_{y'y'} \cdot y'' + F_{y'y} \cdot y' + F_{y'x} - F_y = 0$$

这是一个二阶常微分方程。注意：$F_{y'y'} \neq 0$ 时方程才是二阶的（称为**正则问题**）；若 $F_{y'y'} = 0$，则退化为一阶方程。

### 4.3 特殊情形与首次积分

| 条件 | 简化 | 首次积分 |
|------|------|----------|
| $F$ 不显含 $y$ | $\frac{d}{dx}F_{y'} = 0$ | $F_{y'} = C$ |
| $F$ 不显含 $x$ | Beltrami恒等式 | $F - y'F_{y'} = C$ |
| $F$ 不显含 $y'$ | $F_y = 0$ | 退化为代数方程 |

**Beltrami恒等式**是最常用的特殊情况：当被积函数 $F(y, y')$ 不显含 $x$ 时，直接使用一阶方程：

$$F - y'\frac{\partial F}{\partial y'} = \text{const}$$

这比解二阶 EL 方程更简单。

## 5. 经典案例

### 5.1 最短路径（两点间直线）

$F(y, y') = \sqrt{1 + (y')^2}$，$F$ 不显含 $y$，故 $F_{y'} = \frac{y'}{\sqrt{1+(y')^2}} = C$，解得 $y' = \text{const}$ → **直线**。

### 5.2 最速降线（摆线）

$F(y, y') = \sqrt{\frac{1+(y')^2}{2gy}}$，$F$ 不显含 $x$，用 Beltrami 恒等式：

$$\sqrt{\frac{1+(y')^2}{2gy}} - y' \cdot \frac{y'}{\sqrt{2gy(1+(y')^2)}} = C$$

化简得 $y(1+(y')^2) = \text{const}$，解为**摆线**：

$$x = a(\theta - \sin\theta), \quad y = a(1 - \cos\theta)$$

### 5.3 最小旋转曲面（悬链面）

$F(y, y') = 2\pi y\sqrt{1+(y')^2}$，$F$ 不显含 $x$，Beltrami 恒等式给出：

$$y\sqrt{1+(y')^2} - y' \cdot \frac{y \cdot y'}{\sqrt{1+(y')^2}} = C \;\Longrightarrow\; \frac{y}{\sqrt{1+(y')^2}} = C$$

解得 $y = c\cosh\left(\frac{x - x_0}{c}\right)$，即**悬链线**绕 $x$ 轴旋转得到的**悬链面**。

### 5.4 Dirichlet 能量与 Laplace 方程

对于多元函数 $u(x_1, \ldots, x_n)$，泛函：

$$J[u] = \int_\Omega \frac{1}{2}|\nabla u|^2\,dx$$

其 Euler-Lagrange 方程为：

$$\frac{\partial F}{\partial u} - \sum_{i=1}^n \frac{\partial}{\partial x_i}\!\left(\frac{\partial F}{\partial u_{x_i}}\right) = 0 - \sum_i \frac{\partial}{\partial x_i}(u_{x_i}) = -\Delta u = 0$$

即 **Laplace 方程 $\Delta u = 0$**。这是连接变分法与偏微分方程的关键桥梁。

## 6. 函数空间与拓扑

### 6.1 为什么需要函数空间？

在前面的推导中，我们隐含地假设了 $y \in C^1[a,b]$，$\eta \in C^1[a,b]$。这是**古典变分法**的设定：在连续可微函数空间中寻找极值。

但这一设定有两个问题：
1. **极小化序列可能收敛到一个不可微的函数**（在 $C^1$ 中不封闭）
2. **$C^1$ 不是完备的**（在 $C^1$ 范数下 Cauchy 列不一定收敛到 $C^1$ 函数）

### 6.2 从古典到现代

现代变分法（20世纪）的关键突破就在于**更换函数空间**：

$$C^1[a,b] \;\longrightarrow\; W^{1,p}(a,b) \quad \text{(Sobolev 空间)}$$

在 Sobolev 空间中，导数以**弱导数 (weak derivative)** 的意义存在，空间是完备的（Banach 空间），且具有紧嵌入性质。这使得"直接方法"成为可能。

## 7. 总结：一个完整的思维框架

```
物理/几何问题
     │
     ▼
写出泛函 J[y] = ∫ F(x, y, y') dx   ← 建模：把"目标"写成积分
     │
     ▼
变分 δJ = 0                         ← 必要条件：极值点的一阶变化为零
     │
     ▼
Euler-Lagrange 方程                  ← 把泛函极值问题转化为微分方程
     │
     ▼
解微分方程 → 极值函数 y*(x)          ← 得到最优解
```

这个框架统一了物理学中的**最小作用量原理**、几何学中的**测地线问题**、工程中的**最优控制问题**，以及现代机器学习中的**变分推断**。
