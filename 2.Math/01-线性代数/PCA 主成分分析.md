## 什么是 PCA？

**主成分分析 (Principal Component Analysis)** 是一种经典的**降维技术**，用于：

- 🔍 发现数据中的主要模式
- 📉 减少特征数量，同时保留大部分信息
- 🎨 数据可视化（将高维数据降到 2D/3D）
- 🧹 去噪和特征提取

---

## 核心思想

PCA 的目标是找到数据的**主成分**——这些是数据方差最大的方向。

**直观理解：**

1. 找到数据变化最大的方向 → **第一主成分 (PC1)**
2. 找到与 PC1 正交且变化次大的方向 → **第二主成分 (PC2)**
3. 依此类推...

---

## 数学原理

### 步骤分解

1. **标准化数据**：将每个特征缩放到 **均值为 0，方差为 1**
2. **计算协方差矩阵**：衡量特征间的**相关性**
3. **谱分解**：对协方差矩阵进行特征值分解
4. **选择主成分**：按特征值大小排序，选择前 k 个
5. **投影**：将数据投影到新的主成分空间

### 关键公式

**协方差矩阵：**
$$\Sigma = \frac{1}{n-1} X^T X$$

**特征分解（谱分解）：**
$$\Sigma v = \lambda v$$

其中：
- $\lambda$ = 特征值（表示该方向的方差大小）
- $v$ = 特征向量（表示主成分的方向）

**方差解释率：**
$$\text{Explained Variance Ratio} = \frac{\lambda_i}{\sum \lambda}$$

---

## 谱分解 vs 特征值分解

| | 特征值分解 | 谱分解 |
|---|---|---|
| **适用矩阵** | 任何可对角化矩阵 | **实对称矩阵** |
| **形式** | $A = PDP^{-1}$ | $A = Q\Lambda Q^T$ |
| **特征向量** | 线性无关，不一定正交 | **标准正交** |
| **逆矩阵** | 需要计算 $P^{-1}$ | $Q^{-1} = Q^T$ |

> 💡 PCA 的协方差矩阵是实对称矩阵，所以用的是**谱分解**，性质更好！

---

## 正交矩阵的性质

PCA 中的主成分矩阵 $Q$ 是**正交矩阵**，满足 $Q^T Q = I$。

### 行列式的意义

| $\det(Q)$ | 变换类型 | 保持手性 |
|---|---|---|
| $+1$ | **纯旋转** | ✅ 保持（右手系→右手系） |
| $-1$ | **旋转 + 反射** | ❌ 翻转（右手系→左手系） |

> ⚠️ 正交矩阵 ≠ 一定是旋转，可能是旋转 + 反射！

### 正交矩阵的作用

> **"建立一个新的坐标系，而这个坐标系的基就是正交矩阵的列向量"**

**为什么正交矩阵适合做基变换？**

1. **保距**：$\|Qx\| = \|x\|$（长度不变）
2. **保角**：变换后向量间夹角不变
3. **计算简单**：$Q^{-1} = Q^T$（转置即逆）

## 如何选择主成分数量？

使用**累积方差解释率**来决定保留多少个主成分。

**经验法则：**

- 保留累积方差 ≥ **95%** 的主成分
- 或使用**肘部法则**（scree plot）找拐点

## 实战代码（sklearn）

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# 1. 标准化数据（重要！）
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 2. 创建并拟合 PCA
pca = PCA(n_components=0.95)  # 保留 95% 方差
X_pca = pca.fit_transform(X_scaled)

# 3. 查看结果
print(f"原始维度：{X.shape[1]}")
print(f"降维后维度：{X_pca.shape[1]}")
print(f"方差解释率：{pca.explained_variance_ratio_}")
```

---

## 注意事项

1. **一定要先标准化**：PCA 对方差敏感，不同量纲的特征会影响结果
2. **PCA 假设线性关系**：对于非线性数据，考虑 Kernel PCA
3. **可解释性降低**：主成分是原始特征的线性组合，可能难以解释
4. **信息损失**：降维必然损失信息，权衡维度减少和信息保留

## 应用场景

| 场景 | 说明 |
|---|---|
| 🖼️ 图像压缩 | 减少像素维度，保留主要特征 |
| 🧬 基因数据分析 | 从高维基因表达数据中找模式 |
| 📊 数据可视化 | 将高维数据降到 2D/3D 便于观察 |
| 🧹 去噪 | 去除低方差成分（通常是噪声） |
| 🚀 加速机器学习 | 减少特征数量，提高训练速度 |
| 🔍 特征工程 | 发现隐藏的相关性结构 |

---

## 扩展阅读

- **Kernel PCA**：处理非线性数据
- **Incremental PCA**：处理超大数据集
- **Sparse PCA**：获得更稀疏、可解释的主成分
- **LDA**：有监督的降维方法

> 💡 **提示**：PCA 是无监督方法，不需要标签。如果需要结合类别信息进行降维，可以考虑 LDA (Linear Discriminant Analysis)
